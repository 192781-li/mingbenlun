## 项目简介

践演论（Enactics）是一个在直觉主义线性逻辑中加入运行权类型（Ag_lv/Ag_tr）和明性类型（Cl）的新数学框架。

### 核心定理

| 定理ID | 名称 | 数学陈述 | 哲学对应 |
|--------|------|---------|---------|
| T001 | 星星之火可以燎原 | ρ(pC)>1时明性级联正概率存活 | 一个真正的共产主义者就能改变历史 |
| T006 | 生命不可资本化 | !(νF)≇ν(!F) | 活劳动不能被还原为死劳动 |
| T020 | !不保持终止余代数 | 不存在η:νF→!νF | 生命不可被复制为静态状态 |

### 6条永久原则

1. **永久ID一旦确定，永不改变** —— 定理引用用T001格式
2. **先查文献，再声称新颖性** —— 没查文献不许说"新的"
3. **先证弱版，能升回的再升** —— 先证满射↠/retraction⇒/双模拟≈
4. **Coq编译通过才算证明** —— 纸面证明不算
5. **哲学、数学、对应关系三者清晰区分** —— 不说"证明了生命不可资本化（T001）"
6. **工具自动检查，不靠人自觉** —— 每次commit前自动跑检查器

## 平台战略

### GitHub = 单一事实来源（权威版本）

**所有代码、论文、文档、工具的权威版本在GitHub。**

- AI直接在GitHub上操作：clone → 读 → 改 → commit → push → PR
- 全自动：pre-commit hook、检查器、验证脚本
- 版本控制：每一行修改都有记录，可diff/merge/revert

### 飞书 = 协同和发布层

- 实时协同编辑、讨论、头脑风暴
- 给人看的发布版、总结报告
- 手机端查看和讨论

**飞书上讨论好的内容，最终同步到GitHub作为权威版本。**

详见 [践演论多AI协作规范](践演论多AI协作规范.md)。
