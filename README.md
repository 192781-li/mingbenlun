## 多AI协作机制

### 角色分工

| 角色 | 负责什么 | 写哪些目录 |
|---|---|---|
| **Workbody**（免费算力） | 写Coq代码、反例攻击、形式化证明、写文档草稿 | `coq/incoming/`、`docs/drafts/` |
| **豆包**（电脑端） | 跑coqc验证、严格把关、基础设施、合并草稿到正式库 | `coq/results/`、正式库、`scripts/` |
| **你**（用户） | 下达任务、看进度、拍板 | 全权 |

### 协作流程

```
Workbody写代码 → coq/incoming/T00X_workbody.v
豆包跑coqc验证 → coq/results/T00X_result.md
通过 → 豆包合并到正式库
不通过 → Workbody看结果修改后重新提交
```

### 权限

- GitHub main分支保护已取消，任何有repo写权限token的AI都能直接push
- 通过目录隔离避免冲突：Workbody只写incoming/和drafts/，豆包写results/和正式库
- push前必须先`git pull --rebase`，有冲突就解决

## 6条永久原则

1. **永久ID一旦确定，永不改变** —— 定理引用用T001格式
2. **先查文献，再声称新颖性** —— 没查文献不许说"新的"
3. **先证弱版，能升回的再升** —— 先证满射↠/retraction⇒/双模拟≈
4. **Coq编译通过才算证明** —— 纸面证明不算
5. **哲学、数学、对应关系三者清晰区分** —— 不说"证明了生命不可资本化"，说"证明了数学定理T001，并论证了它对应哲学命题'生命不可资本化'"
6. **工具自动检查，不靠人自觉** —— 每次commit前自动跑检查器

## 怎么开始工作

1. 读`STATUS.md`，看当前谁在干什么、有什么待办
2. 从待办列表里选一个任务
3. 写代码放`coq/incoming/`，写文档放`docs/drafts/`
4. push到GitHub
5. 豆包自动验证，结果写`coq/results/`
6. 看结果，通过就完成，不通过就修改后重新提交
