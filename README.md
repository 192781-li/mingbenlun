## 项目是什么

生命论是一套从"在感"这个唯一无需怀疑的起点出发，推导出人的解放何以可能的哲学体系。

**四个核心命题：**

1. **感先于操作，操作先于实体**——作用本身是最基本的事实
2. **自指操作即生命**——S=f(S)，系统以自身为输入维持自身
3. **异化是自指的丧失，解放是恢复自指**——知道怎么反自指，才知道怎么正自指
4. **道法术器四层贯通**——道（根本原理）→法（方法原则）→术（应用技术）→器（工具）

**最终目的：找最坚硬的锤头，把无产阶级的锁链砸断，让人人如龙。**

## 永久原则

1. **永久ID一旦确定，永不改变**——定理引用用T001格式
2. **先查文献，再声称新颖性**——没查文献不许说"新的"
3. **先证弱版，能升回的再升**——先证满射↠/retraction⇒/双模拟≈
4. **Coq编译通过才算证明**——纸面证明不算
5. **哲学、数学、对应关系三者清晰区分**——严格性分级标注
6. **工具自动检查，不靠人自觉**——越级陈述、无效引用、循环论证由检查器拦截
