# 副卷·语义论

> 生命论的副卷，独立存在但服务于正卷（卷一至卷十一）。
> 语义论不是正卷中的一卷，是贯穿正卷的基础——照见语言在囚人、沉积在发臭、"我在用被污染的眼睛看世界"。

## 副卷定位

- **性质**：生命论的副卷，非正卷
- **与正卷的关系**：语义论的核心命题需融入正卷各卷（卷一存在论、卷三认识论、卷四实践论、卷六异化论等），副卷是完整的、独立的语义论建构
- **发生学**：语义论是整个体系的根——爱→痛苦→语义论（不自觉实践）→旧惯性论→缄默意识→生命论→新惯性论。语义论比惯性论早至少一两年

## 核心概念纪律

- **明性 ≠ 生命之光**：红点照亮场域=生命之光（F1/F2向外常亮），明性=F3反身自觉不常驻
- **不存在绝对理性/绝对客观**：两个"绝对"是同一个幻觉
- **没有界限的分别**：一切分别本身无客观界限，是后发切分的
- **进步 = 未明+明性跃起的跃迁**，非外在指标累积
- **完整的能明 / 不完整的已明**
