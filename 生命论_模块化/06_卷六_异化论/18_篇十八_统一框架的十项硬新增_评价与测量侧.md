### 18.1 退出能力 E_i：形式退出权 ≠ 实际退出能力

[L] 库内已有"自由=约束来自自己"的哲学层，但没有制度变量化的退出概念。[D]

\[
E_i = \text{从现有关系退出/拒绝/改变的}\ \textbf{有效}\ \text{能力}
\]

形式上的退出权（法律写着你随时可以辞职、可以离开）≠ 实际退出能力。实际退出能力受以下变量影响：

- 储蓄（有没有钱撑过空窗期）；
- 社保（有没有安全网）；
- 替代就业机会；
- 住房（换工作是否意味着流离）；
- 医疗（健康是否锁死你在现有工作）；
- 技能（离了这份工作还能干什么）；
- 家庭负担（养家压力是否取消了退出选项）；
- 集体组织（工会/互助是否提供集体退出力量）；
- 法律保护（退出后是否受报复）。

**退出能力是自由的操作论落实**：自由不是"法律允许你走"，是"你真的能走"。一个没有 E_i 的劳动者，形式上自由、实质上被锁死。E_i 与迁移总稿"自由时间 T_free"互补：**E=退出维，T_free=时间维**——自由的两个独立坐标。

### 18.2 所有权五元：加 P_exit

所有权不是一元（"这东西是我的"），是五元：[D]

\[
\vec{P} = (P_{pos},\ P_{ctrl},\ P_{use},\ P_{surplus},\ P_{exit})
\]

| 元 | 含义 |
|---|---|
| \(P_{pos}\) | 占有（possession）：名义上归谁 |
| \(P_{ctrl}\) | 控制（control）：实际决定如何使用 |
| \(P_{use}\) | 使用（use）：实际使用收益 |
| \(P_{surplus}\) | 剩余（surplus）：剩余归谁 |
| \(P_{exit}\) | **退出/转让**（exit）：能否退出、转让 |

**五元拆解的意义**：所有权争论经常卡在"公有还是私有"——但真正的要害是五元各自归谁。名义国有（\(P_{pos}\) 归国家）而 \(P_{ctrl},P_{surplus}\) 归官僚层，与私有制在操作结构上无异。**退出权 \(P_{exit}\) 是与 18.1 的 \(E_i\) 配套的**：所有权没有退出维，控制者可以无限锁死使用者。

### 18.3 异化量向量化 A⃗：否 A=1−M

异化不是一个数，是六维向量：[D]

\[
\vec{A} = (A_{control},\ A_{time},\ A_{meaning},\ A_{feedback},\ A_{social},\ A_{environment})
\]

- \(A_{control}\)：控制权丧失度；
- \(A_{time}\)：时间被占用度；
- \(A_{meaning}\)：意义丧失度；
- \(A_{feedback}\)：反馈断裂度；
- \(A_{social}\)：社会联结断裂度；
- \(A_{environment}\)：环境损害度。

**明确否 A=1−M**（量纲不成立）：异化不是"意义不足"的补集。一个人可以意义满满（虔诚的奴役者）而异化深重——异化的每一维是独立的，不可用一个标量"1−意义"表达。这直接回应了库内台账"第一编硬伤②：A 仍待定义"——六维候选定义在此，是否采纳归作者；采纳后硬伤②关闭。

### 18.5 操作权三分向量化：纠错权不入加法式

操作权用向量而非加法标量：[D]

\[
\vec{O} = (O_p,\ O_o,\ O_s) \quad;\quad O^* = \Sigma w_i O_i
\]

**明言 "O=O_p+O_o+O_s 加法式量纲不严谨"**——三个维度的单位不同，直接相加是范畴错误。

**关键收敛**：纠错权 \(O_c\) 不入加法式——它作为**正交评价维**进入评价函数（纠错能力是 F_econ 的一维）。这与库内 S01 总稿记法自动对齐，三分/四分之争据此收敛：**三分向量做结构、纠错权做评价维**。一字定音归作者。

### 18.8 三桥结构：政经卷总纲题眼

批次04 把整条政经链提炼为三座桥：[D]

1. **劳动 ↔ 操作**：劳动是被社会分工组织的生命操作（卷六篇一之二）；
2. **剩余 ↔ 操作权**：剩余价值是被占有的操作成果（卷六篇二、篇十四）；
3. **资本 ↔ 自指转移**：资本增殖是借生命自指完成的伪自指（卷六篇四、篇十五）。

三桥 + 五层结构（本体/主体/经济/制度/历史）＝政经卷的总纲题眼：每一层都有对应的桥，每一座桥都是主链的一个环节。
