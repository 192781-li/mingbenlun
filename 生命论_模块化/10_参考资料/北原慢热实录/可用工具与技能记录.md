## byted-mediakit-video（视频内容处理工具集）

**Skill路径**：byted-mediakit-video
**前置依赖**：需先读取 byted-mediakit-shared/SKILL.md 执行统一前置检查
**输入要求**：可访问的视频URL或本地视频文件（不能直接处理需要登录态的平台URL，需先下载到本地）

### 工具列表

| 工具 | 用途 | 适用场景 |
|------|------|---------|
| probe-video-metadata | 探测视频URL元信息（时长、分辨率等） | 获取视频基本信息 |
| asr-subtitles | 从音轨中识别语音，输出带时间戳的字幕 | 提取视频中的说话内容、对白 |
| video-ocr | 识别视频画面中的文字（硬字幕、标题、弹幕） | 提取画面上的文字信息 |
| video-understand-router | 通用视频内容分析，输出结构化理解结果 | 整体内容理解、标签生成、内容审核 |
| analyze-video-storyline | 剧情故事线分析，按时间轴输出剧情片段+高光故事线 | 长视频/电影/短剧的剧情分析 |
| analyze-video-highlights | 高光片段提取，输出时间戳、打分、OCR文本、画面描述 | 短视频/游戏/短剧的高光提取 |
| segment-scenes | 自动切分场景，输出时间轴+独立视频片段 | 场景切分 |
| enhance-video / enhance-video-fast / enhance-video-generative | 画质增强（去噪、色彩、清晰度、超分、修复） | 视频画质优化 |
| erase-video-subtitle / erase-video-pro | 擦除画面硬字幕 | 字幕去除 |
| matte-greenscreen-video / matte-portrait-video | 绿幕/人像抠像 | 背景替换 |
| generate-highlights-microdrama / minigame | 高光混剪生成 | 短视频二次创作 |

### 对本项目最有用的工具（优先级排序）

1. **asr-subtitles**：提取视频语音内容（音乐分析、访谈视频、解说视频）
2. **video-understand-router**：整体内容理解（快速了解视频内容）
3. **video-ocr**：画面文字识别（字幕、标题、弹幕、歌词）
4. **probe-video-metadata**：视频元信息探测
5. **analyze-video-storyline**：长视频/电影剧情分析

### 使用注意事项

- 必须先有本地视频文件或公开可访问的URL，不能直接处理抖音/B站等需要登录态的平台URL
- 调用前需先读取 byted-mediakit-shared/SKILL.md
- Cloud模式，需联网
