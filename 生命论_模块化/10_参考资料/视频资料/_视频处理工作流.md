# 视频资料高质量处理工作流

> 目标：对有价值的视频，同时获取完整文本、结构性分析和关键画面，产出一份可独立阅读的 markdown 档案。

## 三级处理策略（按视频价值分级）

### L1：快速文本提取（抖音短视频、图文类）
- **工具**：`web.fetch` 直接抓取抖音分享链接
- **产出**：完整文案文本
- **适用**：5分钟以内的口播/图文视频、论点单一的视频
- **耗时**：1次工具调用，约10秒
- **失败回退**：web.fetch拿不到文本 → 走L2

### L2：完整转写（B站视频、长视频、有画面信息的视频）
- **工具**：doubao-video-extract skill
  1. `python3 scripts/minutes/social_video_to_minutes.py "<url>" --run-lark`（下载+转音频+妙记转写）
  2. 从妙记产物获取完整逐字稿（含时间轴）
- **产出**：`transcript.txt`（逐字稿）+ `doubao_transcript.md`（豆包文档格式）
- **适用**：10分钟以上视频、需要精确引用的视频、B站无字幕视频
- **耗时**：下载+转写约3-10分钟（取决于视频长度）
- **注意**：抖音反爬时走作者微博/其他平台同步发布

### L3：完整档案（高价值视频、系列视频、需要反复引用的视频）
在L2基础上增加：

#### 3a. 关键帧提取
```bash
# 场景切换检测抽帧（适合叙事类、影像类视频）
ffmpeg -i input.mp4 -vf "select='gt(scene,0.4)',showinfo" -vsync vfr frames/keyframe_%03d.jpg

# 按时间间隔均匀抽帧（适合讲座、口播类）
ffmpeg -i input.mp4 -vf "fps=1/60" frames/frame_%03d.jpg  # 每分钟1帧

# 根据逐字稿中的关键时间点精确抽帧
ffmpeg -ss 00:03:25 -i input.mp4 -frames:v 1 frames/moment_01.jpg
```

#### 3b. 结构分析
基于逐字稿+关键帧，AI产出：
- **一句话概括**：这个视频在说什么
- **论证结构**：核心论点→分论点→论据→结论（树状或链状）
- **叙事手法**：怎么讲的（开头钩子、节奏、情绪曲线、画面语言）
- **金句摘录**：原话+时间戳
- **关键画面**：截图+时间戳+画面描述（为什么这帧重要）
- **与生命论的对接点**：哪些论点/结构/意象可以接入生命论框架
- **存疑与批判**：哪些地方有问题、需要进一步核实

#### 3c. 档案格式
```markdown
# [视频标题]

- **平台**：B站/抖音/微博
- **作者**：
- **链接**：
- **时长**：
- **处理日期**：
- **处理级别**：L3
- **本地文件**：视频路径、逐字稿路径、关键帧目录

## 一句话概括

## 论证结构

## 完整逐字稿

## 金句摘录
> 原话 —— 时间戳

## 关键画面
![描述](frames/xxx.jpg)
*时间戳 | 画面描述 | 为什么重要*

## 叙事手法分析

## 与生命论的对接

## 存疑与批判
```

## 处理优先级判断

| 信号 | 级别 |
|------|------|
| 用户说"很有意义""很重要""归档" | L3 |
| 涉及核心理论论点（唯物主义、阶级、革命等） | L2或L3 |
| 系列视频（如创日系列、万宜电台系列） | 首期L3建立模板，后续L2 |
| 音乐/影像类（需要感受画面和氛围） | L3（关键帧重要） |
| 信息核实类（确认一个事实） | L1 |
| 用户说"看看就行""了解一下" | L1 |

## 效率原则

1. **先L1再升级**：先用web.fetch拿文本，判断价值后再决定是否L2/L3
2. **关键帧不贪多**：L3最多10-15帧，选场景切换点和逐字稿标注的关键瞬间
3. **批量处理**：同一系列视频批量下载、批量转写，不逐个等待
4. **妙记异步**：上传妙记后不阻塞，先处理其他任务，轮询取结果
5. **抖音走捷径**：抖音纯口播视频web.fetch能拿到文本就不下载视频
6. **B站优先妙记**：B站视频直接--run-lark，不自己转写

```
│       ├── keyframe_01.jpg
│       └── ...
```
