## 这本书在干什么

这本书在做一件事：**从"在感"这个唯一无需怀疑的起点出发，推导出人的解放何以可能。**

不是在书斋里做哲学，是在找锤头——找最坚硬的锤头，把无产阶级的锁链砸断。

## 核心逻辑（三句话）

1. **感先于操作，操作先于实体。** 你此刻在读这些字，你感到了——这是最直接的事实，比"我思""物质"都直接。感展开为操作，操作沉淀为实体。不是先有一个"东西"然后它"作用"，是作用本身就是最基本的事实。
2. **自指操作即生命。** 系统以自身为输入、输出又返回自身以维持自身——呼吸维持身体，身体维持呼吸；劳动维持社会，社会维持劳动。这就是S=f(S)，就是νF₂（生产性自指，每步都有产出且永不停机）。生命不可被资本化（!-模态不穿透νF₂，T001）。

3. **知道怎么反自指，才知道怎么正自指。** 反自指不是"自指太强"，是自指的丧失——四规定性逐一坍塌，寄生结构消耗宿主。资本、癌细胞、官僚制、经文化，都是反自指。解放就是恢复自指：操作权回归劳动者，明性解蔽，N>1（生产性大于消耗）。

## 全书结构（道法术器四层贯通）

道生法，法生术，术生器。器载术，术载法，法载道。

```
卷首·命经（文言凝练，十二篇）
    ↓
【道】根本原理（卷1-3）
卷一·存在论——起点：在感
卷二·操作论——感展开为操作（四规定性、惯性论）
卷三·认识论——操作产生认识（缄默意识、真理标准）
    ↓ 道展开为法
【法】方法原则（卷4-7）
卷四·实践论——个人修养与操作方法（明性修养、明性辩证法）
卷五·群己论——认识社会结构（人的本质、阶级、国家）
卷六·异化论——分析社会病态（商品、资本、反自指六阶段）
卷七·解放论——社会治疗方向（解放路径、自由人联合体）
    ↓ 法应用为术
【术】各领域应用技术（卷8-10）
卷八·格物论——自然领域（科学哲学、技术、医学、心理学）
卷九·人文论——人文领域（历史、道德、艺术、宗教）
卷十·传统论——传统资源批判继承（周易、中医、儒家、道家）
    ↓ 术物化为器
【器】工具（卷11）
卷十一·践演论——操作论的数学形式化（PTC公理、PTL语言、定理证明器）
```

**1-7卷（道+法）是核心，必须串起来：** 从个人的感出发，到个人的操作，到个人的认识，到个人怎么修养，到个人在社会中怎么被异化，到社会和个人怎么解放。先个人后社会——因为生命论的起点是"在感"，是第一人称的、个人的。

**8-11卷（术+器）是应用，按需查阅：** 各领域的具体技术和工具，根基在道和法。不懂道而用法是盲法，不懂法而用术是拙术，不懂术而造器是死器。

## 怎么读

**第一次读（抓住核心）：**
卷首命经 → 卷一存在论 → 卷二操作论 → 卷六异化论 → 卷七解放论

**深入读（完整链条）：**
按卷序通读1-7卷，道法术器依次展开。

**查资料：**
直接翻对应领域的卷（术+器，卷8-11），遇到根基问题回到道+法（卷1-7）。

## 几个关键概念

| 概念 | 一句话 |
|---|---|
| 在感 | 唯一无需怀疑的起点。你感到了，这就是事实。 |
| 操作先于实体 | 不是先有东西然后它作用，是作用本身就是最基本的事实。 |
| 自指 S=f(S) | 系统以自身为输入维持自身。这就是生命的存在方式。 |
| νF₂ | 生产性自指的数学表达。每步都有产出且永不停机。 |
| !-模态 | 沉积/资本化。把活的过程压成可复制可丢弃的死数据。 |
| T001 | !νF ≇ ν!F——生命不可被资本化。沉积不保持生产性过程。 |
| 反自指 | 自指的丧失。寄生结构消耗宿主。资本、癌细胞、官僚制。 |
| 四规定性 | 自指闭环得以存在的四个逻辑必要条件：边界生成、内生目的、操作再生、环境互动。 |
| 惯性论 | 操作在时间中沉积为惯性。好惯性服务生命，坏惯性锁死生命。 |
| 明性 | 感递归到自觉。人不仅活，还知道自己在活。可被遮蔽，需要解蔽。 |
| N值 | 自指生产性。N<1异化（消耗大于产出），N=1稳态，N>1创造。 |
| M=α·T·N | 生命意义公式。意义=明性系数×稳态基准×生产性。 |
| 践演论 | 操作论的数学形式化。用线性逻辑/类型论把操作的结构变成可证明的定理。 |

## 这本书的立场

- 站在劳动者一边，反对一切把活人变成手段的操作关系。
- 立场不变，判断可错。具体判断全部可改、可讨论。

- 理论为生命服务。阳主阴从——活操作是阳，概念、制度、理论是阴，阴为阳服务。谁拿概念压活人，那不是理论的胜利，是异化。
- 这本书是可错的，作者也是可错的。但有一件事不错：一个普通人，被一个死去几十年的战士感动，然后接过他没解开的结，试着用自己的方式往下解。这就是继承。
