# 副卷 语义论——操作如何沉积为可说的世界

> 本卷是《生命论（明本论）》的**副卷**，不是与十一正卷并列的第十二正卷。它的地位是衍生的、服务性的：语义论的工作是为第一哲学清理语言的地基——照见语言如何囚人、沉积如何发臭、人如何"正在用被污染的眼睛看世界"，从而保证正卷的每一个核心概念（操作、在感、感应、异化、明性）都经过语义校准，不被旧语言的实体化惯性偷偷带回老路。

**为什么把它单独立为副卷。** 语义论在作者思想的发生史上其实最早：在提出惯性论、缄默意识、生命论之前的一两年，作者已经在不自觉地实践语义论——品味自己说的话是不是真想说的，体会亲人为何既爱又伤害、表达为何不达意。它的发生学链条是：**爱 → 痛苦 → 语义论的不自觉实践 → 旧惯性论 → 缄默意识 → 生命论 → 新惯性论。** 它不是体系建成后补的工具，是整条河最早的泉眼之一。但在写作次序上，它服务于正卷建构，因此不抢占正卷的位置，而以副卷形态独立展开，将来可不断扩充专门研讨语义问题的篇目。

**本卷与正卷的关系。** 卷一存在论立"操作先于实体"，卷三认识论立"客观是主观操作沉积的二阶指称"，卷六篇十一做修正主义的名实分析——语义论副卷为这些地方提供统一的语言批判方法；反过来，正卷的操作本体论是语义论全部命题的存在论根据。两者互证，不互相替代。

**本卷篇目。**
- 篇一　语义论总纲：定义、四层内核、与分析哲学/训诂学/解构主义的区分、两大命题与方法论总纲；
- 篇二　偶然成序、言说属人、符号归实践：语义论的存在论奠基（由"必然/偶然—言说有效性—印度河文明符号系统"三段口述贯通而成，含二十三个节点、三重还原、四象限操作模型、明性不常驻的结构论证）。

阅读时把握一条总纲：**没有脱离生命操作的绝对，一切"绝对"都是沉积的僭越；语义论就是照见这个僭越的学问。**
