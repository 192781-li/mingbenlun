## 一、问题

T002：!Ji ⊬ Sheng（迹不能推出生，自由只能在实践中确立）

S04提出三种证明方式：
1. **元理论证明**：在Coq外部证明"不存在从!Ji到Sheng的闭项"
2. **Coq内部证明**：在Coq中证明`¬(!Ji(A) → Sheng(A))`
3. **设计事实**：不证明，因为Sheng只能通过self_ev假设引入，空上下文中没有Sheng的闭项

---

## 二、S01研判：选项3为主，选项2为辅

### 2.1 哲学判断：T002是存在论基本事实，不是需要证明的定理

T002的核心是：**感是第一性的，不能被推导。** 你不能从知识（迹/!Ji）推出活着（生/Sheng），就像你不能从历史记录复活一个死人。

这不是一个需要证明的定理，是类型系统的设计事实——Sheng的引入规则只有self_ev（假设引入），没有任何引入规则从其他类型构造Sheng。只要这个设计成立，T002自动成立。

### 2.2 但可以做一个归纳证明来验证设计事实

虽然T002本质上是设计事实，但可以在Coq内部做一个归纳证明来**验证**这个事实确实成立：

```coq
(* T002：空上下文中不存在TSheng类型的闭项 *)
Theorem T002_no_closed_sheng : forall A,
  ~ (exists t, typed nil t (TSheng A)).
```

**证明方法**：对`typed Gamma t T`的推导做归纳。

每一种typed引入规则要么：
- 需要非空上下文（变量引用需要Gamma中有对应类型）
- 产生的类型不是TSheng（并行组合、输入、输出等产生的类型是TUnit或其他）
- 而TSheng的唯一引入方式是self_ev假设，这需要Gamma中有TSheng A

所以在空上下文（nil）中，不可能有TSheng类型的闭项。

### 2.3 证明的前提条件

这个归纳证明需要：
1. `typed`关系是Inductive定义的（可以对其做归纳）
2. 所有typed引入规则都可以被枚举和检查
3. TSheng没有公理级别的引入规则（没有`Axiom : typed nil t (TSheng A)`）

**S04需要确认**：当前Layer1/Layer2中typed的定义是否满足这些条件。如果typed中有Admitted的引理或公理引入了TSheng，证明就会失败。

### 2.4 更强的版本：!Ji不能推出Sheng

上面的证明只说了"空上下文中没有Sheng闭项"。T002的完整陈述是"!Ji不能推出Sheng"，即：

```coq
Theorem T002 : forall A,
  ~ (exists t, typed (cons (TBang (TJi A)) nil) t (TSheng A)).
```

即在"只有一个!Ji(A)假设"的上下文中，也不能构造出Sheng(A)。

这个证明更复杂，需要证明：即使有!Ji(A)假设，也没有任何规则能从!Ji(A)得到TSheng(A)。因为：
- !Ji支持dereliction（!Ji → Ji），但Ji ≠ Sheng
- !Ji支持contraction和weakening，但不产生Sheng
- 没有promotion规则（!Ji → Sheng），这是故意不定义的

所以即使有!Ji假设，也不能构造Sheng。

## 三、给S04的执行建议

1. **先做简单版本**：证明空上下文中无TSheng闭项（对typed做归纳）
2. **再做完整版本**：证明只有!Ji假设的上下文中也无TSheng闭项
3. **如果归纳证明太复杂**：退回到选项3，把T002作为设计事实注释说明，不形式化证明
4. **关键检查**：确认typed关系中没有Admitted的公理引入了TSheng
5. **self_ev的形式**：当前self_ev是Definition，如果改为Axiom/Parameter，T002的证明方式会不同。建议保持Definition，因为self_ev不是"存在一个Sheng"的公理，而是"如果有Sheng假设就能使用Sheng"的定义。

## 四、和self_ev定义的关系

当前self_ev定义：
```coq
Definition self_ev (A : ty) : Prop :=
  forall Gamma, typed Gamma (PVar 0) -> exists Gamma', get Gamma' 0 = Some (Some (TSheng A)).
```

这个定义说的是"如果变量0是良类型的，那么存在一个上下文其中变量0是TSheng"。这和T002的关系是：
- self_ev不创建Sheng，它只是说"如果有Sheng假设，就能使用它"
- T002说的是"没有Sheng假设时，不能从其他东西构造Sheng"
- 两者一致：self_ev是使用规则，T002是不可推导性

S01之前质疑self_ev应该是Parameter/Axiom，但现在看，Definition形式是合理的——self_ev不是"存在Sheng"的本体论承诺，而是"有Sheng就能用"的使用规则。本体论承诺（感是被给予的）体现在类型系统设计中（Sheng只能通过假设引入），不需要单独的公理。
