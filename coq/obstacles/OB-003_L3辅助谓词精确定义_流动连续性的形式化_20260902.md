## 一、阻碍描述

L3第二阶段（根本性修正版）中，7个核心辅助谓词当前都是Parameter占位：

| 谓词 | 含义 | 用于 |
|------|------|------|
| sheng_continuous P Q | Sheng流动连续（归约前后是同一个流动过程） | reduce_self |
| sheng_discontinuous P Q | Sheng流动不连续（流动被截断，他者插入） | reduce_alien |
| deposits_ji P Q | 归约过程中产生了迹（!Ji） | reduce_self |
| has_ji P | 进程中已经有迹 | is_Ming |
| still_sheng P | Sheng仍在流动，没有被截断 | is_Ming |
| ji_covers_sheng P | 旧迹覆盖了新生（代码化占了主导） | is_Jia |
| sheng_residue P | Sheng有残余（没有完全被覆盖） | is_Jia |

这些谓词的精确定义是L3完整证明（jia_has_residue、T005、subject_reduction）的前提。

**本质问题**：在pi演算的离散进程语法中，怎么表达"生命的流动连续性"这个哲学概念？

pi演算的进程是离散的、步骤化的（P → Q → R...），而生命的流动是连续的。怎么在离散的步骤中表达连续性？

## 二、S01初步哲学研判

### 2.1 核心思路：流动连续性 = Sheng类型变量在归约序列中的持续存在

在pi演算中，"Sheng在流动"可以表达为：**TSheng类型的变量在归约过程中持续出现，没有消失或被替换。**

- **连续**：归约前后，TSheng类型的变量是同一个（或通过重命名关联），没有消失
- **不连续**：归约后，原来的TSheng变量消失了，或者被一个不同来源的TSheng变量替换了

这个思路的哲学依据：Sheng是线性的、不可复制的。如果归约前后TSheng变量是同一个（通过线性资源的传递），那就是同一个流动过程的不同时刻——连续。如果TSheng变量消失了或被替换了，那流动就被截断了——不连续。

### 2.2 各谓词的初步定义方向

#### sheng_continuous P Q

```
sheng_continuous P Q 当且仅当：
存在一个TSheng类型的变量x，x在P中自由出现，且x（或其重命名）在Q中自由出现。
即：Sheng资源在归约中被传递了，没有消失。
```

哲学含义：同一个生在流动，从P流到Q。

#### sheng_discontinuous P Q

```
sheng_discontinuous P Q 当且仅当：
P中有TSheng类型的变量x，但Q中x消失了（或被一个不同来源的TSheng变量替换了）。
即：Sheng资源在归约中被截断了。
```

哲学含义：生的流动被打断了，上一刻的生和下一刻的生不是同一个。

#### deposits_ji P Q

```
deposits_ji P Q 当且仅当：
P中没有TJi类型的变量（或没有某个特定的TJi变量），但Q中有。
即：归约过程中产生了新的迹。
```

哲学含义：生在流动中留下了痕迹。

#### has_ji P

```
has_ji P 当且仅当：
P的上下文中存在至少一个TJi类型的变量。
```

哲学含义：这个进程有历史、有沉积。

#### still_sheng P

```
still_sheng P 当且仅当：
P中存在至少一个TSheng类型的变量，且它是自由的/活跃的（没有被束缚或废弃）。
```

哲学含义：生还在流动，没有停止。

#### ji_covers_sheng P

```
ji_covers_sheng P 当且仅当：
P中TJi类型变量的数量（或权重）超过TSheng类型变量的数量（或权重）。
或者更精确地：P的归约行为主要由TJi变量驱动，而不是由TSheng变量驱动。
```

哲学含义：旧的代码（迹）主导了当前的操作，新的感被覆盖了。

#### sheng_residue P

```
sheng_residue P 当且仅当：
P中至少存在一个TSheng类型的变量（即使它被TJi覆盖了）。
```

哲学含义：生没有完全消失，总有残余——这是逆转的可能。

### 2.3 需要深入讨论的问题

1. **"同一个变量"怎么定义？** pi演算中变量通过重命名（renaming）和代换（substitution）变化。归约前后的"同一个Sheng"是通过变量的线性传递来追踪的吗？还是需要更复杂的追踪机制？

2. **ji_covers_sheng的"覆盖"怎么量化？** 是简单的数量比较，还是需要表达"迹主导了归约行为"？后者更哲学，但更难形式化。

3. **流动连续性和subject reduction的关系**：如果sheng_continuous定义为TSheng变量的持续存在，那reduce_self保持类型（subject_reduction_self）是不是自动成立？因为线性资源的传递本身就保持类型。

4. **self_ev和这些谓词的关系**：self_ev（被抛入的感）是Sheng的引入方式，而sheng_continuous是Sheng的流动方式。两者是什么关系？self_ev是不是流动的起点？
