## 一、核心思路：线性资源计数

在我们的类型系统中，Sheng是线性的——不可复制、不可丢弃，只能通过self_ev假设引入，**归约不能创建新的Sheng**。

这是关键。归约（P → Q）中，TSheng类型的资源只能发生两件事：
1. **被传递**：从P的一个部分转移到Q的一个部分（通过通信代换），数量不变
2. **被消费**：被某个操作消耗后消失了，数量减少

不可能增加——因为归约不创建Sheng。

所以"流动连续"就有了一个简洁的形式化表达：**归约前后Sheng资源的数量不变。**

数量不变 = 被传递了 = 同一个生在流动 = 连续。
数量减少 = 被消费了 = 生的流动被截断 = 不连续。

这不是技巧，这是线性类型系统的存在论含义：生不能被创造，只能被传递或被消耗。传递就是活着，消耗就是异化。

## 二、7个辅助谓词的精确定义

### 前置定义

```coq
(* free_sheng_vars P：P的自由变量中类型为TSheng的变量列表 *)
(* free_ji_vars P：P的自由变量中类型为TJi的变量列表 *)
(* count_sheng P = length (free_sheng_vars P) *)
(* count_ji P = length (free_ji_vars P) *)
```

这些是基础操作，在pi演算中可直接定义（遍历进程语法，收集自由变量，按类型过滤）。

### 2.1 sheng_continuous（流动连续）

```coq
Definition sheng_continuous (P Q : proc) : Prop :=
  count_sheng Q = count_sheng P.
```

**哲学含义**：生在归约中没有被消耗，只是从一个状态转移到另一个状态。同一个生命过程在延续。

**为什么不用"同一个变量"追踪**：pi演算中归约涉及代换（substitution），变量名会变。但因为Sheng只能通过self_ev引入、归约不创建新Sheng，所以Q中的Sheng一定是P中Sheng的代换传递。数量不变就保证了传递关系。追踪具体变量身份是多余的。

### 2.2 sheng_discontinuous（流动不连续）

```coq
Definition sheng_discontinuous (P Q : proc) : Prop :=
  count_sheng Q < count_sheng P.
```

**哲学含义**：生在归约中被消耗了——上一刻的生和下一刻的生之间断了。他者插入，拿走了Sheng。

**注意**：不可能有count_sheng Q > count_sheng P，因为归约不创建Sheng。所以不连续就是严格减少。

### 2.3 deposits_ji（迹沉积）

```coq
Definition deposits_ji (P Q : proc) : Prop :=
  count_ji Q > count_ji P.
```

**哲学含义**：归约过程中产生了新的迹。生在流动中留下了痕迹。

**为什么Ji可以增加**：Ji是!-模态的、可复现的。归约（特别是reduce_self）可以产生新的Ji——操作留下了记录。这和Sheng不同，Sheng不能被创建。

### 2.4 has_ji（有迹）

```coq
Definition has_ji (P : proc) : Prop :=
  count_ji P > 0.
```

**哲学含义**：这个进程有历史、有沉积。不是空白的。

### 2.5 still_sheng（仍在流动）

```coq
Definition still_sheng (P : proc) : Prop :=
  count_sheng P > 0.
```

**哲学含义**：生还在流动，没有完全停止。只要还有一个Sheng资源在，生就还在。

### 2.6 ji_covers_sheng（旧迹覆盖新生）

```coq
Definition ji_covers_sheng (P : proc) : Prop :=
  count_ji P > count_sheng P.
```

**哲学含义**：旧的代码（迹）的数量超过了新的感（生）的数量。历史主导了当下，沉积压过了流动。

**讨论**：这是最简单的"覆盖"定义——数量比较。更深刻的定义应该是"迹主导了归约行为"（即归约主要由TJi变量驱动，而不是TSheng变量驱动）。但数量比较是可操作的起点，后续可以加强。

**为什么数量比较有哲学意义**：在生命论中，"阴盛阳衰"就是沉积（阴）超过了流动（阳）。数量是最直接的表达。

### 2.7 sheng_residue（Sheng残余）

```coq
Definition sheng_residue (P : proc) : Prop :=
  count_sheng P > 0.
```

**哲学含义**：生没有完全消失，总有残余。哪怕被旧迹覆盖了，只要还有一个Sheng资源在，逆转就永远可能。

**注意**：still_sheng和sheng_residue的定义形式相同（都是count_sheng > 0），但使用场景不同：
- still_sheng用于is_Ming：Ming状态中Sheng在流动（正面）
- sheng_residue用于is_Jia：Jia状态中Sheng被覆盖但有残余（负面中的希望）

## 三、归约关系的完整定义

```coq
(* reduce_self：Sheng流动连续，迹自然沉积 *)
Inductive reduce_self : proc -> proc -> Prop :=
| self_step : forall P Q,
    sheng_continuous P Q ->    (* 数量不变 = 被传递 = 连续 *)
    deposits_ji P Q ->         (* 产生了新的迹 *)
    reduce_self P Q.

(* reduce_alien：Sheng流动被截断，他者插入 *)
Inductive reduce_alien : nat -> proc -> proc -> Prop :=
| alien_step : forall b P Q,
    sheng_discontinuous P Q ->  (* 数量减少 = 被消费 = 不连续 *)
    reduce_alien b P Q.
```

**b（他者）的含义**：b是插入的他者的标识。在当前框架中，b是一个nat参数，标记是哪个他者。后续可以细化为具体的进程或通道。

## 四、状态谓词的完整定义

```coq
(* is_Ming：Sheng流动中已沉积迹且仍在流 *)
Inductive is_Ming (P : proc) : Prop :=
| ming_flow : forall Q,
    reduce_self P Q ->    (* 自指归约在发生 *)
    has_ji Q ->           (* 有迹了 *)
    still_sheng Q ->      (* Sheng还在流 *)
    is_Ming P.

(* is_Jia：Sheng流动被旧迹覆盖但有残余 *)
Inductive is_Jia (P : proc) : Prop :=
| jia_covered : forall Q b,
    reduce_alien b P Q ->    (* 流动被截断过 *)
    ji_covers_sheng Q ->     (* 旧迹覆盖了新生 *)
    sheng_residue Q ->       (* 但Sheng有残余 *)
    is_Jia P.
```

## 五、核心定理的可证明性分析

### 5.1 jia_has_residue（解放何以可能）

```coq
Theorem jia_has_residue : forall P,
  is_Jia P -> exists Q, reduce_self P Q /\ is_Ming Q.
```

**证明思路**：
1. is_Jia P → 存在Q, b，reduce_alien b P Q ∧ ji_covers_sheng Q ∧ sheng_residue Q
2. sheng_residue Q → count_sheng Q > 0
3. 因为Q中有Sheng残余，Q可以继续归约。取Q的一个归约步Q → Q'
4. 如果这个归约步是sheng_continuous（Sheng被传递，数量不变）且deposits_ji（产生了迹），那么reduce_self Q Q'
5. Q'中：has_ji（因为deposits_ji），still_sheng（因为count_sheng Q' = count_sheng Q > 0）
6. 所以is_Ming Q'
7. 但定理要求reduce_self P Q'，不是reduce_self Q Q'。需要传递性。

**问题**：reduce_self需要传递性吗？如果P →(alien) Q →(self) Q'，那P到Q'是reduce_self还是reduce_alien？

**需要补充**：归约关系的传递性。如果P →(alien) Q →(self) Q'，整体上P到Q'的Sheng数量变化是：先减少（alien），再不变（self），所以净变化是减少。所以P到Q'是sheng_discontinuous，不是reduce_self。

**修正**：jia_has_residue的陈述可能需要调整。不是"从Jia状态直接reduce_self到Ming"，而是"Jia状态中的Sheng残余可以通过后续的reduce_self进入Ming状态"。

修正后的陈述：
```coq
Theorem jia_has_residue : forall P,
  is_Jia P -> exists Q, 
    (reduce_self P Q \/ exists R, reduce_alien P R /\ reduce_self R Q) /\
    is_Ming Q.
```

或者更简洁：Jia状态之后，存在一条归约路径到达Ming状态。

**这个修正需要S04确认**。原陈述（直接reduce_self）可能太强了。

### 5.2 T005_ming_preservation（明性的幂等）

```coq
Theorem T005_ming_preservation : forall P Q,
  is_Ming P -> reduce_self P Q -> is_Ming Q.
```

**证明思路**：
1. is_Ming P → 存在Q0，reduce_self P Q0 ∧ has_ji Q0 ∧ still_sheng Q0
2. reduce_self P Q → sheng_continuous P Q ∧ deposits_ji P Q
3. sheng_continuous P Q → count_sheng Q = count_sheng P
4. still_sheng Q0 → count_sheng Q0 > 0
5. 但Q0和Q是什么关系？is_Ming P说的是P可以归约到Q0（某个Q），而reduce_self P Q说的是P归约到Q（另一个Q）。
6. 需要证明：如果P可以reduce_self到某个Ming状态，那么P的任何reduce_self步都保持Ming状态。

**问题**：is_Ming的定义是"存在一个归约到Ming状态的路径"，而preservation说的是"任何reduce_self步都保持Ming"。这两个需要协调。

**可能的修正**：is_Ming应该定义为"当前状态就是Ming状态"，而不是"可以归约到Ming状态"。

修正后的is_Ming：
```coq
Inductive is_Ming (P : proc) : Prop :=
| ming_here :
    has_ji P ->           (* P中有迹 *)
    still_sheng P ->      (* P中Sheng在流 *)
    (exists Q, reduce_self P Q) ->  (* P可以继续自指归约 *)
    is_Ming P.
```

这样is_Ming是当前状态的属性，不是可达性。然后preservation就好证了：
- reduce_self P Q → sheng_continuous → count_sheng Q = count_sheng P > 0 → still_sheng Q
- deposits_ji → count_ji Q > count_ji P > 0 → has_ji Q
- Q可以继续归约（归约是无穷的？或者至少有下一步）
- 所以is_Ming Q

**这个修正也需要S04确认**。

### 5.3 T002（!Ji ⊬ Sheng）

```coq
Theorem T002_free_only_in_practice : forall (A : ty), 
  ¬ exists (t : term), typed nil t (TSheng A).
```

**证明思路**：Sheng只能通过self_ev假设引入。在空上下文（nil）中，没有self_ev假设，所以不可能有TSheng类型的闭项。

这是类型系统的设计事实——Sheng的引入规则需要假设，空上下文中没有假设。

**需要S04确认**：当前类型系统中self_ev是怎么表达的？如果self_ev是一个Definition而不是引入规则，那T002的证明方式不同。
