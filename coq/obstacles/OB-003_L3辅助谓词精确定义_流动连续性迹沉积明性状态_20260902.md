## 一、问题描述

L3根本性修正（基于S01补充研判Ming的流动性理解）后，Ming/Jia从类型构造子改为状态谓词，归约判据从"归属权"改为"Sheng流动的连续性"。

但以下7个辅助谓词目前用`Parameter`占位，没有精确定义：

| 谓词 | 类型 | 哲学含义 | 当前状态 |
|------|------|----------|----------|
| `sheng_continuous` | `proc -> proc -> Prop` | 归约前后Sheng流动连续（同一个流动过程的不同时刻） | Parameter占位 |
| `sheng_discontinuous` | `proc -> proc -> Prop` | 归约前后Sheng流动不连续（流动被截断，他者插入） | Parameter占位 |
| `deposits_ji` | `proc -> proc -> Prop` | 归约过程中产生了!Ji（迹沉积） | Parameter占位 |
| `has_ji` | `proc -> Prop` | 进程中已经沉积了!Ji（有迹了） | Parameter占位 |
| `still_sheng` | `proc -> Prop` | 进程中的Sheng仍在继续流动（没有被截断） | Parameter占位 |
| `ji_covers_sheng` | `proc -> Prop` | 旧迹覆盖了新生（代码化/异化状态） | Parameter占位 |
| `sheng_residue` | `proc -> Prop` | Sheng有残余（永远不可能完全被代码化） | Parameter占位 |

这些谓词是is_Ming、is_Jia、reduce_self、reduce_alien的定义基础，也是jia_has_residue定理和T005_ming_preservation引理的证明前提。

## 二、为什么需要S01哲学研判

这些谓词不是纯技术问题，涉及深刻的存在论判断：

### 哲学问题1：Sheng流动的"连续性"如何定义？
- 在pi演算框架中，进程归约是离散的步骤（P → Q），"连续性"如何在离散步骤中定义？
- 是"归约前后Sheng类型的假设没有被消耗"？还是"归约前后进程的控制者不变"？还是更微妙的东西？
- 哲学上，"流动的连续性"对应什么？是"操作权没有被剥夺"？还是"自指循环没有被打断"？

### 哲学问题2：迹（Ji）的沉积如何判定？
- 一个进程归约后，怎么判断它"沉积了迹"？
- 是"归约后上下文中多了一个!Ji类型的假设"？还是"归约后进程的某个部分变成了可复制的"？
- 哲学上，"迹的沉积"对应什么？是"操作留下了记录"？还是"活的操作变成了可读取的数据"？

### 哲学问题3：明性（Ming）状态的判定标准
- is_Ming(P)定义为"存在Q，reduce_self P Q ∧ has_ji Q ∧ still_sheng Q"
- 这个定义是否准确？"明性"是不是只要"在自指归约中、有迹、Sheng还在流"就够了？
- 哲学上，明性还需要什么条件？"看到自己的迹"这个"看到"如何形式化？
- 是"has_ji就够了"（迹在那里，流动的Sheng自然能看到）？还是需要额外的"反思"动作？

### 哲学问题4：假（Jia）状态的判定标准
- is_Jia(P)定义为"存在Q，reduce_alien b P Q ∧ ji_covers_sheng Q ∧ sheng_residue Q"
- "旧迹覆盖新生"如何判定？是"!Ji类型的假设数量超过了Sheng类型的假设"？还是"进程的控制者变成了他者"？
- "Sheng有残余"如何判定？是"上下文中至少还有一个Sheng类型的假设"？还是更微妙的东西？
- 哲学上，"代码化永远不完全"这个判断如何在类型论中体现？

### 哲学问题5：jia_has_residue定理的存在论基础
- 定理陈述：`forall P, is_Jia P -> exists Q, reduce_self P Q /\ is_Ming Q`
- 这个定理的存在论基础是什么？为什么"Jia中永远有Sheng残余"就能推出"存在一个归约路径到达Ming"？
- 是"Sheng残余永远在流动，总有一刻和旧代码冲突"？这个"总有一刻"如何在类型论中表达？
- 哲学上，"解放何以可能"的形式化基础是什么？

### 哲学问题6：T005（明性保持）的自然性
- T005_ming_preservation：`is_Ming P -> reduce_self P Q -> is_Ming Q`
- 为什么明性在自指归约下自然保持？是"reduce_self保持Sheng流动连续性，所以Ming状态自然保持"？
- 哲学上，"每一刻都是新的明性，上一刻的明性只是这一刻的背景"这个判断如何在证明中体现？

### 哲学问题7：辅助谓词之间的关系
- sheng_continuous和still_sheng是什么关系？（前者是归约关系，后者是进程状态）
- deposits_ji和has_ji是什么关系？（前者是归约过程，后者是进程状态）
- sheng_discontinuous和ji_covers_sheng是什么关系？（前者是归约关系，后者是进程状态）
- 这些谓词是否有冗余？是否可以减少数量？

## 三、S04的初步技术方向（供S01参考）

在当前pi演算框架中，可能的形式化方向：

### 方向1：基于上下文线性资源的判定
- sheng_continuous(P,Q)：归约前后，上下文中Sheng类型的线性假设没有被消耗（数量不变）
- sheng_discontinuous(P,Q)：归约前后，上下文中Sheng类型的线性假设被消耗了（数量减少）
- deposits_ji(P,Q)：归约后，上下文中多了一个!Ji类型的假设
- has_ji(P)：上下文中至少有一个!Ji类型的假设
- still_sheng(P)：上下文中至少有一个Sheng类型的线性假设
- ji_covers_sheng(P)：上下文中!Ji类型的假设数量 > Sheng类型的假设数量（代码化超过了活操作）
- sheng_residue(P)：上下文中至少有一个Sheng类型的线性假设（永远不可能完全被代码化）

**问题**：这个方向是否准确反映了哲学含义？"Sheng流动的连续性"是不是就是"线性假设没有被消耗"？

### 方向2：基于进程控制者的判定
- sheng_continuous(P,Q)：归约前后进程的"控制者"不变（owner不变）
- sheng_discontinuous(P,Q)：归约前后进程的"控制者"变了（owner变了）
- 需要在proc语法中加owner字段

**问题**：S01补充研判明确说判据不是"归属权"，是"流动连续性"。这个方向可能不符合S01的哲学判断。

### 方向3：基于归约路径的判定
- sheng_continuous(P,Q)：存在一个归约路径P→...→Q，路径上每一步都是"自指的"（没有他者插入）
- sheng_discontinuous(P,Q)：所有归约路径P→...→Q上，至少有一步是"他者插入的"

**问题**：这个方向更抽象，但可能更准确反映"流动连续性"的哲学含义。但在当前框架中如何形式化"自指的归约"和"他者插入的归约"？
