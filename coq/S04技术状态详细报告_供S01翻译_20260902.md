## 二、substitution_lemma的具体困境（TASK-S04-008）

### 2.1 引理陈述

```coq
Theorem substitution_lemma : forall Gamma T y Q,
  typed (Some T :: Gamma) Q -> get Gamma y = Some (Some T) ->
  typed Gamma (subst_var y 0 Q).
```

**白话翻译**：如果在上下文"Some T :: Gamma"中，进程Q是良类型的，并且Gamma中第y个变量的类型是T，那么把Q中的第0个约束变量代换成y之后，得到的进程在Gamma中仍然是良类型的。

**这是pi演算类型系统的标准引理**，几乎所有pi演算的形式化都需要证明它。它是subject_reduction（主体归约）证明的核心前提之一。

### 2.2 当前证明思路（DeepSeek的方案）

DeepSeek选择的证明思路是：**对typed关系（H）进行归纳**，而不是对proc结构（Q）进行归纳。

证明包含6个辅助引理：
1. `subst_name_neq`：如果n≠k且n≤k，那么subst_name m k n = n（代换不影响这个变量名）
2. `subst_name_gt`：如果k<n，那么subst_name m k n = n-1（变量名减1）
3. `subst_name_eq`：subst_name m k k = m（代换点变成m）
4. `subst_var_fresh`：如果变量k不在Q的自由变量中，那么subst_var m k Q = Q（代换不影响进程）
5. `subst_var_ren`：代换和重命名在约束变量情况下交换
6. `ren_xik_typed`：用xik k重命名保持类型

主定理对typed关系的7条规则（ty_zero/ty_var/ty_tau/ty_out/ty_in/ty_par/ty_res/ty_rep）逐条归纳。

### 2.4 需要哲学研判的问题

1. **代换引理的存在论意义是什么？**
   - 在生命论的操作本体论中，"把一个变量代换成另一个变量"意味着什么？
   - 变量是什么？是操作的占位符吗？代换是不是"一个操作被另一个操作替代"？
   - 为什么代换之后类型保持不变？这在存在论上意味着什么？

2. **证明结构的哲学基础是什么？**
   - 对typed关系归纳 vs 对proc结构归纳，这两种归纳方式在哲学上有什么区别？
   - typed关系是"操作的规范性"，proc结构是"操作的实体性"。对哪一个归纳更符合"操作先于实体"原则？
   - 标准pi演算证明通常对typed关系归纳，但生命论的形式化是不是应该有不同的选择？

3. **有没有更简单的证明思路？**
   - 650行是不是因为证明思路本身就歪了？
   - 能不能利用已有的ren_typed（重命名保持类型）引理，把代换归约为重命名？
   - 代换和重命名在哲学上是什么关系？代换是不是"一次性的重命名"？
   - 如果代换可以归约为重命名，那证明是不是可以大大简化？

4. **代换引理和subject_reduction的哲学关系是什么？**
   - subject_reduction说的是"归约保持类型"，代换引理说的是"代换保持类型"。
   - 归约和代换在哲学上是什么关系？归约是不是"操作的自我展开"，代换是不是"操作的相互替代"？
   - 为什么代换引理是subject_reduction的前提？这在存在论上意味着什么？

## 三、L3类型规则设计的具体技术状态（TASK-S04-009）

### 3.1 L3的目标

L3是生命论形式化的核心层，要在L1/L2的pi演算基础上，加入生命论特有的四个核心概念：
- **Sheng（生）**：正在发用的生，生生不息，线性的、不可复制的
- **Ji（迹）**：生留下的迹，迹非履，!-模态的、可复制的，但不能变回生
- **Jia（假）**：假借他者名义运行，假自指，没有直接消去规则
- **Ming（明）**：生+看到自己的迹=明明德，存在论状态，幂等是retraction不是同构

同时加入两个归约关系：
- **reduce_self（自指归约）**：操作的结果回到自身，保持Sheng
- **reduce_alien（异化归约）**：操作的结果流向他者，Sheng变成Ji

### 3.3 需要哲学研判的6个问题

#### 问题1：Sheng（生）的引入消去规则

**技术问题**：
- 引入规则：什么情况下一个进程"拥有生"？是`PAgLvStep`（正在进行一步操作）才有生吗？还是所有进程都有生？
- 消去规则：生用完之后变成什么？是消失了，还是转化为Ji（迹）？
- 线性性：生为什么是线性的、不可复制的？

**哲学问题**：
- "正在发用的生"在存在论上是什么？是操作的当下性吗？
- 生的不可复制性是不是源于"时间的不可逆性"？你不能把"正在做"复制成两份，因为做的过程是唯一的、一次性的。
- 生的消去是不是"生的沉积"？操作完成后，活的生变成了死的迹？
- 生和操作（proc）是什么关系？是不是所有操作都有生，还是只有"自指的操作"才有生？

#### 问题2：Ji（迹）的引入消去规则

**技术问题**：
- 引入规则：迹是如何产生的？是生的沉积吗？`deposit`操作把Sheng变成!Ji？
- 消去规则：迹可以被读取（dereliction）、复制（contraction）、忽略（weakening），但不能变回生（没有promotion规则）。
- !-模态：迹的可复现性。!本身是中性的，资本化是异化形态。

**哲学问题**：
- "迹非履"——迹是操作留下的痕迹，但迹不是操作本身。这个存在论鸿沟在类型规则中如何体现？
- 为什么迹可以被复制？因为迹已经"死了"，不再有时间的当下性，所以可以被反复读取。
- 为什么迹不能变回生？因为时间不可逆，你不能从脚印变回正在走的脚。这个"不可逆性"在存在论上的根据是什么？
- !-模态的中性是什么意思？可复现性本身不是坏事，没有可复现性就没有历史、没有知识、没有文明。资本化是可复现性在特定社会关系下的异化。这个区分在类型规则中如何体现？

#### 问题3：Jia（假）的引入消去规则

**技术问题**：
- 引入规则：假是如何产生的？是他者假借我的名义运行吗？`Jia(b,a,B)`表示b假借a的生在运行？
- 消去规则：假为什么没有直接的消去规则？伪装不能直接揭开，只能通过明性（Ming）的坍缩（retraction）间接恢复。
- 假是类型构造子还是归约关系？异化是状态还是过程？

**哲学问题**：
- "假自指"——假不是外在暴力，是自指结构内部的畸变。b假借a的名义运行，a还以为是自己在运行。这个"自欺"结构在存在论上是什么？
- 为什么假没有直接的消去规则？因为假已经渗入了自指循环本身，你不能用"被假污染的自指"去揭开假，就像不能用自己的手把自己从泥潭里拉出来。只能通过明性的坍缩——看到自己的迹，发现迹不对，才能间接恢复。
- 假和异化是什么关系？异化是不是"假的普遍化"？当整个社会关系都是假的时候，异化就成了常态。
- 假是类型构造子（静态的异化状态）还是归约关系（动态的异化发生）？还是两者都是——阳（过程）和阴（沉积）的关系？

#### 问题4：Ming（明）的引入消去规则

**技术问题**：
- 引入规则：明是什么？`Ming(A) = Sheng(A) ⊗ !Ji(A)`，生+看到自己的迹=明明德。这个公式对吗？
- 消去规则：明的幂等是retraction不是同构（`Ming(Ming(A)) -> Ming(A)`，但反过来不成立）。
- 明是存在论状态还是认识论属性？

**哲学问题**：
- "明明德"——明不是"我知道了"（认识论的清晰性），而是"我不仅在生，我还能看到自己的迹"（存在论状态）。这个存在论状态在类型规则中如何体现？
- 为什么明的幂等是retraction不是同构？因为"对明的明"不等于"明"——你可以反思自己的明性，但反思本身不是明性，反思只是迹。明性是活的，反思是死的。活的可以产生死的，但死的不能产生活的。
- `Ming(A) = Sheng(A) ⊗ !Ji(A)`这个公式对吗？明是不是"生+迹"的简单组合？还是说明是一种"看到迹的生"，是生的一种高阶状态？
- 明和f³反射是什么关系？f³是"对反思的反思"，明是不是f³的完成态？

#### 问题5：双归约关系（reduce_self vs reduce_alien）

**技术问题**：
- reduce_self（自指归约）：操作的结果回到自身，`S -> f(S)`，保持Sheng。
- reduce_alien（异化归约）：操作的结果流向他者，`S -> f(b,S)`，b抽走了Sheng，剩下的只有Ji。
- 如何在proc语法中判断一个归约是self还是alien？判据是什么？
- 这两个归约关系在存在论上是并列的还是有先后的？

**哲学问题**：
- 自指归约是不是"操作的自我展开"？S=f(S)，操作的结果回到操作本身，这是自指循环的正常运行。
- 异化归约是不是"操作的他者展开"？S=f(b,S)，操作的结果被他者抽走，自指循环被打断，活的生变成死的迹。
- 判据是不是"操作结果的流向"？结果回到自身→self，结果流向他者→alien。这个判据在存在论上充分吗？
- 这两个归约是并列的吗？还是说异化归约是自指归约的"畸变"——本来应该回到自身的结果，被他者截走了？如果是畸变，那异化归约是不是在存在论上后于自指归约？
- 异化归约中，"b抽走了Sheng"——b是如何抽走的？是暴力夺取还是a自愿给予？还是说在异化关系中，a已经分不清"自愿"和"被迫"了？

#### 问题6：T002和T005的定理陈述

**技术问题**：
- T002：`!Ji ⊬ Sheng`（迹不能推出生）。在纯!-模态系统中，无法构造Sheng类型的项。
- T005：`Ming(Ming(A)) -> Ming(A)`（明的幂等是retraction）。

**哲学问题**：
- T002："你不能从脚印变回正在走的脚"——自由只能在实践中确立。这个定理的存在论意义是不是"知识（迹）不能推出实践（生）"？你知道再多的道理，也不能代替你正在做。这个"推不出"是不是线性vs非线性的存在论鸿沟？
- T002的证明思路：假设!Ji能推出Sheng，那么利用!-模态的contraction，可以复制这个推导，得到两个Sheng，这与Sheng的线性性矛盾。这个证明在哲学上是不是说"如果知识能推出实践，那实践就可以被复制，但实践是不可复制的，所以知识不能推出实践"？
- T005："对明的明不是明"——反思明性不等于明性本身。这个retraction在哲学上是不是说"你可以知道你在明，但知道你在明不是明"？明是活的状态，知道是死的迹。
- T005为什么不是同构？因为`Ming(A) -> Ming(Ming(A))`不成立——你不能从"明"推出"对明的明"，因为明不一定会反思自身。明可以是"缄默的明"——你在明，但你不知道你在明。只有当你看到自己的迹时，明才被"明明"。
