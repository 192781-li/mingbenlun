### 1.2 按S01研判修改Layer3.v
**新增基础操作**：
- `shift_down`：绑定器下的自由变量shift（变量0被绑定，n+1→n）
- `free_vars`：收集进程的自由变量（de Bruijn表示，处理PIn/PRes绑定器）
- `is_sheng_type`/`is_ji_type`：判断变量在上下文中是否为TSheng/TJi类型
- `count_sheng Gamma P`：P的自由变量中类型为TSheng的数量
- `count_ji Gamma P`：P的自由变量中类型为TJi的数量

**7个辅助谓词从Parameter改为Definition**（基于线性资源计数）：

| 谓词 | 精确定义 | 哲学含义 |
|------|----------|----------|
| sheng_continuous | count_sheng Q = count_sheng P | 数量不变=被传递=连续=活着 |
| sheng_discontinuous | count_sheng Q < count_sheng P | 数量减少=被消耗=不连续=异化 |
| deposits_ji | count_ji Q > count_ji P | 产生了新的迹=操作留下了记录 |
| has_ji | count_ji P > 0 | 有历史、有沉积 |
| still_sheng | count_sheng P > 0 | 生还在流动 |
| ji_covers_sheng | count_sheng P < count_ji P | 阴盛阳衰=旧迹覆盖新生 |
| sheng_residue | count_sheng P > 0 | 生有残余=逆转永远可能 |

**归约关系修正**（带上下文参数）：
- `reduce_self Gamma P Q`：sheng_continuous + deposits_ji
- `reduce_alien Gamma b P Q`：sheng_discontinuous

**is_Ming修正**（从可达性改为当前状态）：
- 旧定义：存在Q，reduce_self P Q ∧ has_ji Q ∧ still_sheng Q
- 新定义：has_ji P ∧ still_sheng P ∧ (exists Q, reduce_self P Q)
- 三要素：有迹（历史）、仍在流（活）、可继续自指归约（未来）

**jia_has_residue陈述修正**（原陈述太强）：
- 旧陈述：is_Jia P → exists Q, reduce_self P Q ∧ is_Ming Q
- 新陈述：is_Jia P → exists Q, (reduce_self P Q ∨ exists R, reduce_alien P R ∧ reduce_self R Q) ∧ is_Ming Q
- 修正原因：如果P→(alien)Q→(self)Q'，整体Sheng数量净减少，不是reduce_self
