- 引入`sheng_activation_possible`公理：
  ```coq
  Axiom sheng_activation_possible : forall (Gamma : ctx) (P : proc),
    count_sheng Gamma P > 0 ->
    ~ (forall Q, ~ reduce_self Gamma P Q).
  ```
- 哲学含义：只要还有生的残余，就不可能所有路径都是异化的。觉醒的可能性永远存在——不是必然觉醒，是不可能完全没有觉醒的可能。

     - 可继续归约：再次用sheng_activation_possible + NNPP
  4. 构造路径：P ->(alien b) Q ->(self) Q'
- 哲学意义：解放何以可能的形式化证明。Jia中Sheng残余永远在流动，总有一刻和旧代码冲突，明性在裂缝里自然亮起。

### 步骤3：T005_ming_preservation证明完成
- commit：6520f89
- 证明策略：
  1. is_Ming P -> has_ji P /\ still_sheng P /\ exists Q0, reduce_self P Q0
  2. reduce_self P Q -> sheng_continuous P Q /\ deposits_ji P Q
  3. still_sheng Q：sheng_continuous -> count_sheng Q = count_sheng P > 0
  4. has_ji Q：deposits_ji -> count_ji Q > count_ji P > 0
  5. 可继续归约：sheng_activation_possible + NNPP -> exists Q', reduce_self Q Q'
  6. 所以is_Ming Q
- 哲学意义：明性的幂等是自然事实——每一步reduce_self后is_Ming保持。上一刻的明性沉积为这一刻的Ji背景，但这一刻的Sheng仍然是活的、流动的。不需要单独的retraction定理，明性就在感的流动里面。

### 步骤4：OB-006——reduce_self/reduce_alien改为Definition，subject_reduction证明完成
- commit：fe14152
- 关键架构修正（OB-006）：
  - 旧：reduce_self/reduce_alien是独立的Inductive归约关系（只基于资源计数）
  - 新：reduce_self/reduce_alien是L2的reduce关系的子关系（分类）
    ```coq
    Definition reduce_self (Gamma : ctx) (P Q : proc) : Prop :=
      reduce P Q /\ sheng_continuous Gamma P Q /\ deposits_ji Gamma P Q.

    Definition reduce_alien (Gamma : ctx) (b : nat) (P Q : proc) : Prop :=
      reduce P Q /\ sheng_discontinuous Gamma P Q.
    ```
- 哲学依据：reduce_self/reduce_alien不是独立的归约关系，是对L2的reduce步的分类（自指归约vs异化归约）。归约本身是L2的语法归约，分类是基于Sheng流动的连续性。
- subject_reduction_self证明：
  ```coq
  Proof.
    intros Gamma P Q H Ht.
    destruct H as [Hred [Hsc Hdj]].
    eapply subject_reduction. exact Ht. exact Hred.
  Qed.
  ```
- subject_reduction_alien证明：
  ```coq
  Proof.
    intros Gamma b P Q H Ht.
    destruct H as [Hred Hsd].
    eapply subject_reduction. exact Ht. exact Hred.
  Qed.
  ```
- 同步修改：jia_has_residue和T005证明中的inversion改为destruct。

## 四、关键定理证明思路总结

### jia_has_residue（解放何以可能）
**核心洞见**：不是"必然解放"（决定论），是"解放永远可能"（反决定论）。
- sheng_activation_possible公理保证：有Sheng残余 → 不可能完全没有reduce_self路径
- 经典逻辑NNPP将"不可能不存在"转化为"存在"
- 从Jia状态出发，经过alien→self路径，到达Ming状态

### T005_ming_preservation（明性保持）
**核心洞见**：明性的幂等不是一个需要证明的定理，是Sheng流动性的自然推论。
- reduce_self保持Sheng连续（数量不变）
- reduce_self沉积Ji（数量增加）
- 所以明性状态（有迹+仍在流+可继续归约）自然保持
- 不需要单独的retraction操作，明性就在感的流动里面

### subject_reduction_self/alien（双归约类型保持）
**核心洞见**：归约的分类不影响类型保持。
- reduce_self/reduce_alien是L2 reduce的子关系
- L2的subject_reduction已经证明了reduce保持类型
- 所以子关系自然保持类型
