# coq/results/

> 豆包跑coqc验证的结果放这里。Workbody可以看，知道自己写的代码通过没有。

## 规则
- 只有豆包往这里写文件
- 文件名格式：`T00X_result.md`（定理ID_result.md）
- 每个结果文件包含：验证时间、是否通过、错误信息（如果失败）、建议
- Workbody看完结果后，修改 `../incoming/` 里的代码，重新提交

## 结果文件模板
```markdown
# T00X 验证结果

> 验证时间：2026-08-27
> 验证者：豆包

## 状态
✅ 通过 / ❌ 失败

## 错误信息（如果失败）
（coqc的错误输出）

## 建议
（怎么修改）
```
