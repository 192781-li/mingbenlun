附录七 操作范畴论：生命论的数学基础

本附录概述生命论核心命题的形式化证明。完整论文见 references/operational_category.pdf（v2.1，23页，52定理，5猜想），验证脚本见 scripts/。

数学是阴，哲学是阳。数学不证明哲学是对的——数学证明的是自洽性：你的哲学在形式上没有结构性硬伤。真正的裁判是践演。

一、为什么要数学化

生命论的核心命题——"生命不可资本化（T001）""实践先于理论""异化是运行权被夺走"——在纯哲学语言中是论断，别人可以说"这是你的看法"。数学化把这些论断变成公理系统中的定理：如果你接受公理（操作先于实体、资源敏感、自指存在），你就必须接受结论。反驳它要先推翻公理，而公理直接扎在"在活着"这个践演事实上。

这和马克思做的事一脉相承。马克思在《资本论》中用数学语言（价值形式、剩余价值率、利润率趋向下降）把"资本剥削人"从道德义愤变成科学分析。这里用范畴论和线性逻辑，把"生命不可资本化（T001）"从哲学论断变成可检验的形式定理。

二、核心工具

2.1 线性逻辑：资源敏感

线性逻辑和经典逻辑的根本区别：资源不能随便复制和丢弃。

  • 线性蕴含 $A \multimap B$：消耗 $A$ 产生 $B$，$A$ 没了

  • 张量 $A \otimes B$：同时拥有 $A$ 和 $B$

  • 加法 $A \oplus B$ / $A \& B$：选择/合取

  • 感叹号 $\bang A$：$A$ 可被任意复制和丢弃（沉积/资本化）

$\bang$ 就是资本化的逻辑对应：把一次性的、消耗性的东西变成可无限复制的死物。公理3（指数余单子）补充了Seely同构：$\bang(A \& B) \cong \bang A \otimes \bang B$，$\bang \top \cong I$——这是沉积的乘法结构。

2.2 范畴论：变换的科学

范畴论不研究"东西是什么"，研究"东西之间怎么变换"。

  • 对称幺半闭范畴（SMCC）：对象可并列（$\otimes$），有线性函数空间（$\multimap$）

  • 余单子 $\bang$：沉积/复制/存储，对应资本化

  • 迹（trace）：把反馈线藏起来——$f: A \otimes X \to B \otimes X$ 有反馈线 $X$，迹 $\mathrm{Tr}^X(f): A \to B$ 把 $X$ 藏起来

  • 不动点：$\mu F$（归纳，有限终止）和 $\nu F$（余归纳，无限生产）

2.3 Geometry of Interaction（GoI）：执行的语义

GoI（吉拉德，线性逻辑发明者）把证明解释为带反馈回路的连线网络。执行就是让信号在反馈回路中跑。

关键创新：余归纳GoI。标准GoI要求幂零性（反馈有限步终止），但生命过程永不停机。用生产性（productivity，每步都有产出）替换幂零性，处理无限生命过程。

2.4 生产性迹范畴（PTC）

这是本文构造的新范畴论概念。一个PTC是SMCC，配备流对象 $A^\omega = \nu X.(A \otimes X)$ 和行为映射 $\mathrm{beh}(f, x_0): A^\omega \to B^\omega$，满足四条公理：

  1. Yanking：反馈线直接穿过等于没反馈
  2. Tightening：前后处理不影响反馈
  3. Composition：两个反馈盒子串联 = 行为函数复合
  4. Productivity：完全的转移产生完全的因果流函数

$\mathbf{Rel}$（关系范畴）、$\mathbf{Hilb}^\omega$（无限维Hilbert空间，严格压缩条件下）、$\mathbf{Coh}^\omega$（相干空间，条件推论）是PTC的三个实例。标准迹的输出在原范畴中（$A \to B$），生产性迹的输出在流范畴中（$A^\omega \to B^\omega$）——它对应Joyal-Street-Verity 1996年Int-构造的余归纳版本。

三、公理系统

公理 内容 哲学对应

四、核心定理与哲学对应

4.1 种子定理：无自然收缩（定理1）

数学：不存在自然变换 $A \to \bang A$。

证明：若存在，则复合给对角化 $A \to \bang A \to A \otimes A$，与公理2矛盾。

哲学：这是全文的种子。定理6/16/17/18/20/23/38都是它的派生。一句话：在一个资源敏感的世界里，你不能无中生有地复制自己。

4.2 生命流不可资本化（定理16/17/20）

数学：对生命函子 $F_2(X) = A \multimap (X \otimes B)$（接收 $A$，产出 $B$ 和新自我 $X$）：

  • $\bang \nu F_2 \to \nu(F_2 \bang)$ 不存在（定理16，内层！）

  • $\bang \mu F_2 \to \mu(F_2 \bang)$ 不存在（定理17，有限情形）

  • $\bang$ 不提升到流处理器（T001，$\mathbf{Rel}$ 中构造性证明；一般PTC为猜想5）

证明思路：要证 $\bang(A \multimap (X \otimes B)), A \vdash \bang X \otimes B$，结论是张量，最后一步必须拆上下文。四种拆法全部失败：空上下文无中生有、promotion不能作末步、类型不匹配。没有第五种。

哲学：资本可以拿走生命的产出 $B$（工资、产品、数据），可以杀死生命（$S \to I$），但不能把生命的持续展开本身变成可复制的东西。不是技术限制，是结构限制。

资本要不然杀了生命，要不然只能无限接近于掠夺生命的全部。但是生命每在资本掠夺它全部的下一刻，就产生了新的自我。

4.3 2×2矩阵：什么能复制，什么不能（定理14）

非交互（$F_1$，数据流） 交互（$F_2$，生命过程）
有限（$\mu$） ✓ 可复制（文本、录像） ✗ 不可复制为过程（可记录为数据，但记录≠过程）
无限（$\nu$） ✓ 可复制（无限数据流） ✗ 不可复制（生命流）

分界不是有限/无限，是交互/非交互。注12是全文最漂亮的自我修正：早期"$X$在$G$中任意出现即阻止分配律"是错的，反例 $F(X) = X \multimap B$ 的 $Q = D(X) \wedge P(B) = \top$ 完全正确；二分法被精化为"仅当 $X$ 在 $\multimap$ 后件或 $\oplus$ 分支"。

4.4 异化 = 运行被沉积模型接管（定理31/32）

数学：

  • 定理31：当 $\bang$ 模型的反馈覆盖了生命自身的反馈，状态停止更新——$S_{n+1} = S_n$
  • 定理32：维持运行与沉积模型的区分，是 $f^2$ 以上层级的操作

哲学：异化不是"感到陌生"，是你的自指循环还在转，但转的是别人给的内容。你以为自己在判断，其实是系统在替你判断；你以为自己在感受，其实是媒体在替你感受。$S = f(S)$ 还在运行，但 $f$ 不是你的。

"异化""明性"是[诠释]命名，数学定理本身只说"状态停止更新"。

4.5 f-层级与明性（定理33）

数学：$f^3$ 是不动点——不需要 $f^4$。

  • $f^1 \to f^2$：从无模型到有模型（质变）

  • $f^2 \to f^3$：从被模型支配到看见模型是模型（质变）

  • $f^3 \to f^4$：不是质变——$f^3$ 已能对象化任何模型，包括它自己的模型

哲学：明性不是可以继续升级的状态，是一种操作。一旦你能看见模型是模型，你就能递归地看见"看见模型"也是模型。见山还是山之后没有第四段。$\alpha$ 只取 ${1, 2, 3}$。

4.6 慢性死亡（定理40）

数学：$N < 1$ 时，几何级数收敛：$\sum_{n=0}^{\infty} N^n = \frac{1}{1-N} < \infty$。

哲学：当净方向 $N < 1$（异化率 $l' = (1-N) \times 100\% > 0$），生命的意义总量是有限的——不是突然死亡，是慢慢耗尽。每天磨损一点，每天少一点，总量有限。这就是"慢性死亡"：日日死而不自知。

4.7 生命过程超越有限证明（定理44）

数学：设 $A, B$ 可数无限，流处理器集合基数为连续统 $\mathfrak{c}$，而有限证明集合可数。故存在不可被有限证明穷尽的生命过程。

哲学：哥德尔不完备定理的生命论对应——任何有限的形式系统都不能穷尽一个无限生命过程的真理。不是不可知论，是生命总比理论丰富。

4.8 资本/病毒同构与寄生体自毁（定理28/29）

数学：

  • 定理28：两类 $\bang$-寄生结构（病毒复制与资本增殖）范畴同构
  • 定理29：$\bang$-寄生体随宿主削弱而增长枯竭——越接近完全转化，线性资源 $A$ 供给越少；极限 $S = I$ 时 $A = 0$，无增长

哲学：资本和病毒是同一个数学结构——为生存而生存的空转。它必须保存宿主才能增长，但它的趋势是把宿主变成自己（$F_2 \to F_1$），这最终杀死宿主。反生命系统最丑恶的来源，就是它为了生存而生存。

4.9 量子对应（定理35/45/46）

数学：

  • 定理35：量子不可克隆定理（T009） = $\bang$ 不穿透在 $\mathbf{FdHilb}$ 中的显现
  • 定理45/46：$\mathbf{Hilb}^\omega$ 在严格压缩条件下（$|U_{22}| < 1$）构成PTC

哲学：线性逻辑是量子计算的类型论基础。$\bang$-分配对应"经典复制"——只对经典数据有效，对量子过程无效。生命作为交互计算过程 $A \multimap (X \otimes B)$，与量子态一样不可复制。

六、定理级别约定

论文采用三级标注：

  • [定理]：从公理严格证明，标题/陈述/证明中禁含未定义哲学名词

  • [条件推论]：在明确可验证条件下成立（如"当 $\mathcal{C}$ 满足状态唯一可追踪性"），条件在猜想节有对应条目

  • [诠释]：数学结构的哲学解读，"异化""明性""资本"等命名只出现在这一级

这个纪律保证了：数学部分是干净的，哲学部分是诚实的——你知道哪句话是证明的，哪句话是解读的。

八、数学与哲学的关系

  1. 哲学选公理：生命论说"操作先于实体""生命是自指操作""实践先于理论"——这些决定了公理选择
  2. 数学检验自洽：形式化暴露了纯哲学看不见的结构问题
  3. 数学产生新洞见：2×2矩阵、迹=测量=实际从属三者同一、$f^3$ 不动点——这些是形式化中发现的
  4. 践演是裁判：数学是安检不是法庭，最终裁判是实践

一句话：生存是 $\bang$ 的空转，生命是 $\nu F_2$ 的展开；定理16/17/20证明了这两者之间不存在箭头——生命在结构上就超越了生存，而 $\nu$ 的最大性就是"完整"的数学定义。
