# 第一部分：历史主观题7大题型

## 题型1：概括/说明类

### 识别标志
设问动词：**概括、指出、说明、简述、概述、归纳、总结**
常见问法："概括XX的特点""指出XX的依据""说明XX的变化""概述XX的历程"

### 答题骨架
```
① 分点提取材料信息（材料优先，70%答案来自材料）
② 补充课本相关要点
③ 每点一句话，史论结合，只陈述不评价
```

### 得分要点
- 材料优先：逐句读材料，划关键词
- 分点作答：按角度分（政治/经济/思想/时间/空间），不要一段到底
- 角度要全：特点题至少3个角度，变化题写"从…到…"
- 用词精准：用历史学科语言，不用大白话

### 失分陷阱
- ❌ 照抄材料原文（要概括转化）
- ❌ 只写一个角度
- ❌ 加入评价（概括题只陈述）
- ❌ 漏点（材料每句话基本对应一个得分点）

### 摸底卷对应
- 23(1)：分析文明三要素为何不能作为普遍标准→说明类
- 27(1)：概述欧洲民族主义发展历程→概述类
- 25(1)：说明人民群众的作用→说明类

---

## 题型2：原因/背景类

### 识别标志
设问动词：**分析、简析、为什么、原因、背景、条件、因素**
常见问法："分析XX出现的原因""简析XX的历史背景"

### 答题骨架
```
① 政治因素：制度/政策/阶级/革命/战争
② 经济因素：生产力/生产关系/经济结构/贸易
③ 思想文化因素：思想解放/科技/教育/社会思潮
④ 外部因素：国际环境/外来影响/文明交流
（材料优先，再补课本，按分值决定写几点）
```

### 得分要点
- 多维分析：政治+经济+思想文化+外部，至少3个维度
- 根本原因vs直接原因：根本原因写经济/生产力层面；直接原因写导火索
- 内因vs外因：中国史注意区分内部因素和外部冲击
- 时代特征：把事件放在大时代背景下

### 失分陷阱
- ❌ 只写一个维度
- ❌ 原因和结果混淆
- ❌ 空泛无史实（只写"经济发展"，不写什么经济）
- ❌ 根本原因和直接原因写反

---

## 题型3：影响/意义类

### 识别标志
设问动词：**影响、作用、意义、危害、贡献、后果**
常见问法："简析XX的历史影响""分析XX的历史作用"

### 答题骨架
```
① 积极影响：对当时+对后世+对本国+对世界
② 消极影响/局限性：时代局限+阶级局限+负面后果
③ 总结：放在历史长河中评价
```

### 得分要点
- 一分为二：积极+消极，除非题目明确只问积极
- 多层影响：对当时政治经济思想+对后世制度文化+对世界文明
- 史论结合：每个影响点配史实支撑
- 区分程度："推动了""促进了"vs"决定了""标志着"

### 失分陷阱
- ❌ 只写积极不写消极
- ❌ 影响和原因混淆
- ❌ 夸大程度
- ❌ 空泛（只写"影响深远"）

## 题型4：评析/评述/评价类（重灾区，重点掌握）

### 识别标志
设问动词：**评析、评述、评价、简评、谈谈你的看法**

**三个词的区别（考场极易搞混）：**

| 词 | 结构 | 重点 |
|---|---|---|
| **评析** | 述 + 析 | 先叙述事实，再分析原因/利弊 |
| **评述** | 述 + 评 | 先叙述史实，再做价值判断 |
| **评价** | 只评 | 直接一分为二，不需要大段叙述 |

### 答题骨架（以评析为例）
```
第一步【述】：概括对象是什么（1-2句话）
第二步【析积极】：正面作用/进步性（配史实）
第三步【析消极】：局限性/弊端（配史实）
第四步【小结】：放在特定时代背景下总体评价
```

**有限定视角时（如"以史为鉴"），第四步必须落到视角：**
```
第四步【鉴】：从XX视角看，有何经验教训/启示/借鉴意义
```

### 得分要点
- 必须有"述"：不能上来就评价
- 必须有史实：每个评价点配具体史实
- 一分为二：积极+消极
- 时代性：放在当时历史条件下评价
- 限定视角必须回应

### 失分陷阱（核心问题）
- ❌ 跳过"述"直接批判（F3阻塞F1）
- ❌ 没有史实，全是空论（像哲学论文）
- ❌ 只批判不肯定
- ❌ 不回应限定视角
- ❌ 循环论证（用题目给的标准证明题目给的标准）

### 摸底卷对应
- 23(2)：任选标准评析→评析题（1/6分，失分重灾区）
- 24：从以史为鉴视角评析古代盛世→评析题+限定视角
- 25(2)：述评资产阶级和人民群众的关系→评述题

## 题型5：阐述/论述类（含历史小论文）

### 识别标志
设问动词：**阐述、论证、论述、说明、小论文、自拟论题**

### 答题骨架
```
第一步【亮观点】：总论点（一句话，明确立场）
第二步【分论点1】：角度1 + 史实 + 分析解释
第三步【分论点2】：角度2 + 史实 + 分析解释
第四步【分论点3】：角度3 + 史实 + 分析解释（按分值决定）
第五步【回扣】：总结升华，呼应总论点
```

**小论文变体（自拟论题）：**
```
第一步【拟论题】：从材料中提炼明确论题（具体可论证，不宽泛）
第二步【论证】：2-3个史实，每个史实=史实叙述+分析论证
第三步【总结】：升华论题，指出历史规律/启示
```

### 得分要点
- 观点明确：一句话说清，不模棱两可
- 史论结合：每个分论点配史实，史实后必须有分析（"这说明…"）
- 逻辑闭环：分论点围绕总论点，结尾回扣
- 小论文论题要具体："唐宋经济重心南移推动文化繁荣"√，"中国历史悠久"×

### 失分陷阱
- ❌ 有观点无论据
- ❌ 有史实无论证（只罗列不分析）
- ❌ 逻辑断裂
- ❌ 小论文论题太宽泛

### 摸底卷对应
- 26：阐述东西方经济技术交流→阐述题

## 题型6：比较类

### 识别标志
设问动词：**比较、对比、异同、相同点、不同点、区别、联系**

### 答题骨架
```
① 相同点：角度1 + 角度2 + 角度3
② 不同点：
   - 背景：A… vs B…
   - 内容：A… vs B…
   - 影响：A… vs B…
   - 性质：A… vs B…
③ 总结：比较后的结论（为什么有这些异同/说明了什么）
```

### 得分要点
- 分维度对比：按维度对比，不先写A再写B
- 相同点和不同点都写（题目说"异同"）
- 对比要对应：A的背景对应B的背景
- 总结升华：比较后得出结论

### 失分陷阱
- ❌ 分开写（先A全部再B全部，忘记对比）
- ❌ 只写不同不写相同
- ❌ 维度不对应
- ❌ 没有总结

---

## 题型7：启示/认识类

### 识别标志
设问动词：**启示、认识、看法、借鉴、经验、教训、智慧**

### 答题骨架
```
① 基于前面史实的升华（不脱离材料）
② 唯物史观视角：生产力与生产关系/经济基础与上层建筑/人民群众
③ 现实关照：对今天的启示/借鉴意义
④ 分点作答，每点一句话
```

### 得分要点
- 不能脱离材料：基于题目史实
- 升华不抄材料：从史实中提炼规律
- 唯物史观：用生产力/阶级/人民群众视角
- 积极正面：写经验/智慧/借鉴

### 失分陷阱
- ❌ 脱离材料
- ❌ 抄材料
- ❌ 空喊口号
- ❌ 消极负面

# 第二部分：F1/F2/F3训练体系

## 三层定义

| 层级 | 名称 | 定义 | 训练目标 |
|------|------|------|---------|
| **F1** | 感·题感 | 看到题0.5秒内识别题型，写出答题骨架 | 条件反射，不思考 |
| **F2** | 应·分析 | 在骨架内填充史实和因果链 | 史论结合，有血有肉 |
| **F3** | 自指·元认知 | 后置审查答案，找失分点 | 自我监控，不前置 |

## F1训练法
- 每天10道题，只做"圈动词→判题型→写骨架"
- 每题30秒，不写具体答案
- 21天形成条件反射

## F2训练法
- 三遍重写法的第二遍
- F1骨架+F2史实填充
- 不做哲学批判，在结构内组织内容

## F3训练法
- 三遍重写法的第三遍
- 用F3视角审查自己的答案
- 检查：①有没有跳框架？②史实准不准？③有没有循环论证？④得分点全不全？

## 铁则
- **F1永远先行**：拿到题先识别题型写骨架，不读材料细节
- **F3永远后置**：只能用来检查答案，不能用来质疑题目前提
- **F3不阻塞F1**：看到题不许想"这个题的前提是不是循环论证"，先拿分再说

## 三遍重写法
```
第一遍：纯F1（只写题型+骨架，不填史实）
第二遍：F1+F2（骨架内填充史实，不做批判）
第三遍：F1+F2+F3（完整答案+自我审查）
```

# 第三部分：历史知识输入（3层记忆法）

## 第1层：时间线骨架（先搭起来）

### 中国古代史
- 先秦（夏商周→春秋战国）：制度萌芽、百家争鸣
- 秦汉：大一统、中央集权确立、儒学正统
- 魏晋南北朝：分裂、民族融合、佛教传播
- 隋唐：盛世、科举制、三省六部、开放繁荣
- 宋元：商品经济、市民文化、民族政权并立→统一
- 明清：君主专制顶峰、商品经济发展、闭关锁国、西学东渐

### 中国近现代史
- 1840-1919：侵略与反抗、近代化探索（洋务→维新→辛亥→新文化）
- 1919-1949：新民主主义革命（建党→国共合作→土地革命→抗战→解放）
- 1949-1978：社会主义建设（巩固→改造→探索→曲折）
- 1978-至今：改革开放、中国特色社会主义

### 世界史
- 古代：古希腊罗马、中世纪
- 近代：文艺复兴→宗教改革→启蒙运动→资产阶级革命→工业革命
- 现代：两次世界大战→冷战→多极化→全球化

**这层不用背细节，记住"每个时代的核心特征"就行。**

## 一、必须默写的公式清单

### 三角函数
- sin²α + cos²α = 1
- sin(α±β) = sinαcosβ ± cosαsinβ
- cos(α±β) = cosαcosβ ∓ sinαsinβ
- sin2α = 2sinαcosα
- cos2α = cos²α - sin²α = 2cos²α - 1 = 1 - 2sin²α
- 正弦定理：a/sinA = b/sinB = c/sinC = 2R
- 余弦定理：a² = b² + c² - 2bc·cosA
- 面积：S = ½ab·sinC

### 数列
- 等差通项：aₙ = a₁ + (n-1)d
- 等差求和：Sₙ = n(a₁+aₙ)/2 = na₁ + n(n-1)d/2
- 等比通项：aₙ = a₁·q^(n-1)
- 等比求和：Sₙ = a₁(1-qⁿ)/(1-q) (q≠1)

### 导数
- C' = 0
- (xⁿ)' = nx^(n-1)
- (sinx)' = cosx
- (cosx)' = -sinx
- (eˣ)' = eˣ
- (lnx)' = 1/x
- (uv)' = u'v + uv'
- (u/v)' = (u'v - uv')/v²

### 概率统计
- 期望：E(X) = Σxᵢpᵢ
- 方差：D(X) = E(X²) - [E(X)]²
- 二项分布：X~B(n,p)，E(X)=np，D(X)=np(1-p)
- 卡方：χ² = n(ad-bc)²/[(a+b)(c+d)(a+c)(b+d)]

### 向量
- a·b = |a||b|cosθ = x₁x₂ + y₁y₂
- |a| = √(x²+y²)
- a⊥b ⟺ a·b = 0
- a∥b ⟺ x₁y₂ = x₂y₁

## 三、基础概念（理解，不用背定义）

- 函数：定义域（x的取值范围）、值域（y的取值范围）
- 单调性：x增大y增大→增函数；x增大y减小→减函数
- 奇偶性：f(-x)=f(x)→偶函数（关于y轴对称）；f(-x)=-f(x)→奇函数（关于原点对称）
- 导数几何意义：函数在某点的导数=该点切线的斜率
- 古典概型：基本事件有限且等可能，P(A)=A包含的基本事件数/总基本事件数
- 条件概率：P(B|A)=P(AB)/P(A)
- 向量：有大小有方向的量，数量积是一个数（不是向量）

**概念不用背定义，要能"用自己的话说出来"。说不出来就是没理解。**
