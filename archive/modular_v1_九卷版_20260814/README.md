## 四、三条铁律（落笔前逐条过）

1. **术语铁律**：绝不说"物质自己会活/物质是活的"。根只有一句——
   **生命是活的，故生命物质才是活的**。运行 `python verify_iron_rule.py 某文件.md` 校验。
2. **数据铁律**：凡数字、统计、学者年份、定理出处，须联网核验并带可核查出处
   （URL/arXiv/PMID），不冒充事实。来源机构立场须标明。
3. **立场铁律**：不装中立；碰"客观/技术/中立"必先跑四步查法；
   追立场机制**先查 AI 自己**。
