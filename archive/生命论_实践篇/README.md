# 生命论·实践篇

## 定位

生命论不只是哲学理论，更是可操作的实践指南。本卷收录生命论在具体领域的实践验证与操作方法——从认知操作到应试应对，从学习方法到通用操作论。

**核心命题**：在反自指系统中，人可以保持自指运行权，可以用系统的规则达到自己的目的，可以不被同化为工具。这不是理论推论，是践演出来的。
