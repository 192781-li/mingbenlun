# 网页应用

## 何时用app_builder_agent

- 交互式概念图谱
- 可操作的量论计算器（M值、H值）
- 章节导航/阅读器
- 明性辩证法五步引导工具
- 其他需要用户交互的网页工具

## 使用规则

1. 先读doubao-app-builder技能的SKILL.md
2. arch_type选择：
   - `jspage`：静态展示页、简单交互（默认）
   - `html`：3D/游戏场景
   - `fullstack`：需要数据库、数据持久化
3. user_prompt要具体：功能、布局、数据、交互逻辑
4. 生命论相关应用用衬线字体、深色或米白主题，不花哨
