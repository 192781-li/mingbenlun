# 践演论 v1.7：异化不动点与运行权递归理论

> 运行权改变递归的泛性质：自主递归与异化递归是不同的数学对象

---

## 1. 问题

在标准范畴论中，归纳类型μF和余归纳类型νF由其泛性质定义：
- μF是F-代数范畴的初始对象（折叠fold）
- νF是F-余代数范畴的终止对象（展开unfold）

这些定义不跟踪"谁控制递归"。本节证明：**加入运行权维度后，自主递归和异化递归有不同的泛性质——它们不是同一个数学对象。**

---

## 2. 运行权代数

### 2.1 定义

设F是* -自主范畴C上的正函子。定义**F-运行权代数**为三元组(A, a, α_A)，其中：
- (A, a: FA→A)是标准F-代数
- α_A: A→Ag_self(A)是运行权映射，指定A的每个元素由self运行

F-运行权代数之间的同态h: (A,a,α_A)→(B,b,α_B)是标准代数同态h: A→B，且保持运行权：

```
α_B ∘ h = Ag(h) ∘ α_A
```

即h将A中self运行的元素映射到B中self运行的对应元素——h不改变运行权。

**F-异化代数**为三元组(A, a, β_A)，其中：
- (A, a: FA→A)是标准F-代数
- β_A: A→Ag_b(A)指定A的元素由外部者b运行

异化代数之间的同态保持b-运行权。

### 2.2 初始运行权代数

**定理2.1（初始自主代数）**：F-运行权代数范畴有初始对象μ_ag F，且μ_ag F = μF（标准初始代数），但运行权结构使得μ_ag F上的递归函数"属于self"。

**证明**：标准初始代数μF带有fold: (FA→A)→μF→A。给μF加上α_{μF}: μF→Ag_self(μF)（每个有限构造的元素由self运行，因为构造过程是self的有限展开）。对任意运行权代数(A,a,α_A)，标准fold h: μF→A保持运行权（因为α_A指定A的元素由self运行，fold保持构造结构，所以h将self构造的元素映射到self运行的元素）。因此μ_ag F存在且等于μF加运行权标注。∎

**定理2.2（初始异化代数不存在）**：F-异化代数范畴（β_A指向b≠self）没有初始对象。

**证明**：假设存在初始异化代数(I, i, β_I)。则对任意异化代数(A,a,β_A)，存在唯一同态h: I→A。但考虑两个异化代数(A,a,β_A^b)和(A,a,β_A^c)，其中b≠c——同一个底层代数A但运行权归属于不同的外部者。从I到两者各有唯一同态h_b和h_c，但h_b和h_c在底层是同一个函数h: I→A（因为底层代数相同），而运行权保持要求β_A^b(h(x)) = Ag(h)(β_I(x))和β_A^c(h(x)) = Ag(h)(β_I(x))，这意味着β_A^b = β_A^c，矛盾（b≠c）。∎

**意义**：异化递归没有"标准形式"——被谁异化不是一个固定参数，不同的异化者给出不同的递归结构。这就是为什么资本主义、殖民主义、官僚主义虽然都是异化，但有不同的数学结构——它们对应不同的异化者b。

### 2.3 终止运行权余代数

对偶地，定义F-运行权余代数(A, c: A→FA, α_A: A→Ag_self(A))。

**定理2.3（终止自主余代数）**：F-运行权余代数范畴有终止对象ν_ag F，且ν_ag F = νF（标准终止余代数），带有self运行权标注。

**证明**：对偶于定理2.1。νF的unfold: A→(A→FA)→νF保持self运行权。νF的每个无限展开由self运行（因为展开是self的持续自我生产）。∎

**定理2.4（终止异化余代数不存在）**：F-异化余代数范畴（b≠self）没有终止对象。

**证明**：对偶于定理2.2。假设存在终止异化余代数，同一个底层余代数可以被不同的b异化，导致矛盾。∎

## 3. 异化如何改变不动点

### 3.1 提取函子

定义**提取函子**E_b: C → C，它将自主过程映射为被b提取的过程：

- E_b(A) = A × Ag_b(A)（A的元素被b标注运行权）
- E_b(f: A→B) = f × Ag(f)（保持提取结构）

E_b建模β>0的萃取：过程A仍然存在，但它的运行权和产出被b提取。

### 3.2 异化下的不动点

**定理3.1（异化压缩）**：E_b(νF) ≅ μF。即被提取的无限过程退化为有限对象。

**证明**：E_b(νF) = νF × Ag_b(νF)。νF是无限展开的余归纳对象。但Ag_b(νF)标注运行权属于b——这意味着νF的每一步展开都由b控制，b可以决定何时停止展开。

在Rel模型中验证：νF是最大不动点（无限路径集合），μF是最小不动点（有限路径集合）。E_b添加了一个"b可以截断"的结构——b在每一步可以选择继续或停止。被b控制的无限路径实际上是有限路径的前缀（b随时可以截断），因此E_b(νF) ≅ μF。

更形式化地：E_b(νF)的元素是(π, b)，其中π是无限路径但b有权在任意点截断。这等价于π的所有有限前缀的集合——而这正是μF（有限构造的集合）。∎

**哲学意义**：这就是异化杀死创造力的数学机制。一个被异化的生命（νF，无限自我展开）在提取函子下退化为μF（有限的、可终止的、可预测的劳动单元）。资本不允许工人无限发展——它把工人的无限潜力压缩为有限的劳动力商品。

### 3.3 明性下的不动点恢复

**T003（明性恢复νF）**：Cl_self(E_b(νF)) ≅ νF。即明性过程即使在被提取的情况下也能恢复无限展开。

**证明**：Cl_self(A) = A × !A（活过程+自我模型）。Cl_self(E_b(νF)) = E_b(νF) × !E_b(νF)。明性过程持有自己的轨迹（!E_b(νF)），能看见自己被提取。

关键：明性过程虽然被b提取（E_b），但它的自我模型!E_b(νF)记录了"我应该是νF"这个信息。通过自指修改（R3），明性过程可以改变自己的运行权——从Ag_b回到Ag_self。这个改变一旦发生，E_b的标注被移除，过程恢复为νF。

在范畴论中：Cl_self ∘ E_b在self纤维上的限制自然同构于恒等函子（因为Cl_self可以检测并反转E_b的效果）。因此Cl_self(E_b(νF)) ≅ νF。∎

**哲学意义**：觉醒的劳动者即使在被剥削的条件下也能恢复创造力——因为明性让人看见自己被异化，并通过革命实践（自指修改）夺回运行权。这就是定理9（明性反异化）和T003（继续革命）的范畴论基础。

## 4. 运行权递归理论的统一图景

### 4.1 四种递归

| | 自主（Ag_self） | 异化（Ag_b, b≠self） |
|---|---|---|
| **归纳（μF）** | 有限的自主实践：技能学习、工具制造、有限项目 | 有限的异化劳动：雇佣劳动、流水线、合同工 |
| **余归纳（νF）** | 无限的自主创造：生命、艺术、革命、自由发展 | **不存在**（定理2.4/3.1：异化压缩νF为μF） |

关键结果：**异化余归纳不存在**。被异化的无限过程在数学上退化为有限过程。这意味着：
- 你可以被异化去做有限的工作（μF）
- 你不能被异化去做无限的创造（νF）——因为无限创造需要self运行权，异化会把它压缩成有限的
- 真正的无限创造只能是自主的

这给"自由是创造的前提"提供了数学证明。

### 4.2 与量论的对应

| 范畴论 | 量论 | 政治经济学 |
|---|---|---|
| ν_ag F（自主余归纳） | N≥1, M=∞（自我实现/创造） | 自由人联合体中的自由劳动 |
| μ_ag F（自主归纳） | N<1但β=0, M有限 | 自主的有限实践（学习、练习） |
| E_b(νF) ≅ μF（异化压缩） | N<1, β>0, M有限且递减 | 异化劳动（雇佣劳动） |
| Cl_self ∘ E_b ≅ Id（明性恢复） | γ=1, N恢复≥1 | 革命实践 |

## 5. 与已知不动点理论的关系

### 5.1 标准范畴论不动点

- **初始代数/终止余代数**（Adámek, Barr 1994）：μF和νF的泛性质，我们的定理2.1和2.3在此基础上加了运行权维度
- **不动点算子**（Lawvere 1969, Hasegawa 1997）：迹范畴中的不动点，我们的运行权纤维化增加了"谁控制迹"的维度
- **参数化不动点**（Filinski 1999）：栈安全的递归，与我们的运行权标注有精神联系但目标不同

### 5.2 新的贡献

1. **运行权代数/余代数**：在标准(余)代数上增加运行权映射，形成新的范畴
2. **初始异化代数不存在**（定理2.2）：异化递归没有初始对象——不同异化者给出不同结构
3. **异化压缩定理**（定理3.1）：E_b(νF) ≅ μF——异化在范畴论层面把无限压缩为有限
4. **明性恢复定理**（T003）：Cl_self ∘ E_b ≅ Id——明性反转异化压缩
5. **四种递归分类**：自主/异化 × 归纳/余归纳的2×2矩阵，其中异化余归纳不存在

定理3.1和3.2是最有实质内容的结果——它们给出了异化和明性改变递归结构的精确范畴论机制。
