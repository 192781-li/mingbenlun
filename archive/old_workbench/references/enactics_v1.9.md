# 践演论 v1.9：明性网络与集体运行权

> 明性在过程网络中的传播定理，集体自主的范畴论条件

---

## 1. 过程网络

### 1.1 定义

在π-演算中，n个进程的并行组合P₁|P₂|...|Pₙ通过通道连接形成网络。每个进程Pᵢ有运行权状态：
- Ag_self(Pᵢ)：自主
- Ag_b(Pᵢ)：被b异化
- Cl_self(Pᵢ)：明性（自主+能看见自己的状态）

进程间通过通道通信。明性传播规则：如果Cl_self(Pᵢ)通过通道c向Pⱼ发送自己的自我模型mᵢ（!Ag_self(Pᵢ)类型），Pⱼ接收后可以比较mᵢ与自己的状态——如果Pⱼ被异化，这个比较暴露不一致（T005），Pⱼ获得Cl_self。

### 1.2 明性传播矩阵

定义**明性传播矩阵**C为n×n矩阵：
- Cᵢⱼ = 1如果Pᵢ可以通过通道直接向Pⱼ传播明性
- Cᵢⱼ = 0否则

C的谱半径ρ(C)决定明性传播的动力学：
- ρ(C) < 1：明性传播衰减——初始明性进程的影响随距离消失
- ρ(C) = 1：明性传播稳定——明性以恒定速率传播
- ρ(C) > 1：明性传播增长——明性指数级扩散，级联革命

这与量论中N（反馈强度=谱半径）的三态完全对应。

## 2. 核心定理

### 2.1 明性可达性

**定理2.1（明性可达性）**：在过程网络中，如果存在从明性进程集合S到进程Pⱼ的有向路径（沿C的边），且路径上每个中间进程在接收到明性信号时能执行self_check，则Pⱼ在有限时间内获得明性。

**证明**：对路径长度归纳。
- 基例k=0：Pⱼ∈S，已经是明性的。
- 归纳步：假设Pₖ在t步内获得明性。如果Cₖⱼ=1，Pₖ通过通道向Pⱼ发送自我模型mₖ。Pⱼ接收后执行self_check：
  - 如果Pⱼ被异化，self_check检测到不一致（T005），Pⱼ获得明性
  - 如果Pⱼ已经自主，self_check确认自主，Pⱼ获得明性
  Pⱼ在t+1步内获得明性。∎

**条件**：定理要求路径上每个进程"能执行self_check"——这意味着进程必须有接收明性信号并进行自我检查的能力。在ALL类型中，这对应进程持有Cl类型或能通过通信获得Cl类型。

### 2.2 明性级联阈值

**定理2.2（级联条件）**：在过程网络中，明性级联（明性从初始集合S传播到所有进程）发生当且仅当：

1. 从S到每个进程存在有向路径（图论条件）
2. ρ(C_S) ≥ 1，其中C_S是从S出发的明性传播子矩阵（动力学条件）

**证明**：

(⇒) 如果级联发生，每个进程最终获得明性。由定理2.1，每个进程必须从S可达（条件1）。明性传播的动力学由C_S控制——明性进程数量的增长近似为|S_t| ≈ |S| · ρ(C_S)^t。如果ρ(C_S) < 1，增长指数衰减，明性不能到达所有进程（条件2）。

(⇐) 如果条件1和2满足，明性沿所有路径传播（定理2.1），且ρ(C_S) ≥ 1保证传播不衰减。在有限网络中，这意味着明性在有限时间内到达所有进程。∎

### 2.3 谱半径与网络拓扑

ρ(C)的值取决于网络拓扑：
- **完全网络**（每个进程与每个进程相连）：ρ(C) = n-1，对n>2总有ρ(C)>1——明性在紧密社区中快速级联
- **环形网络**：ρ(C) = 2（每个节点连接两个邻居），ρ(C)>1——明性沿环传播
- **星形网络**：ρ(C) = √(n-1)——中心节点获得明性后快速传播
- **树形网络**：ρ(C) = √Δ（Δ是最大度）——明性从高连通节点传播
- **孤立社区**：如果网络分裂为两个不连通的组件，明性不能跨组件传播

**政治推论**：
- 革命在紧密社区中最容易爆发（完全网络ρ最大）
- 社会分裂（不连通的网络组件）阻止明性传播——这就是为什么分割统治（divide and rule）有效
- 中心节点（知识分子、组织者、网红）在明性传播中起关键作用——星形网络中一个中心节点的觉醒可以触发级联

### 2.4 异化者的反制

异化者b可以通过以下方式阻止明性级联：
1. **切断通道**：删除C中的边（审查、断网、隔离明性进程）
2. **降低ρ(C)**：将网络从完全网络变为树形/星形（原子化社会——每个人只与中心/媒体通信，不互相通信）
3. **注入噪声**：在通道上发送虚假的自我模型（意识形态宣传），使self_check产生假阳性/假阴性
4. ** preemptive alienation**：在明性传播到达之前异化更多进程（制造恐惧、分化）

**定理2.3（反制限度）**：如果一个进程已经获得Cl_self，异化者不能通过通道通信夺走它的明性——只能通过物理强制（杀死/监禁进程，即终止Pᵢ）。

**证明**：Cl_self是线性的（v1.5§3.2），不能被外部修改。通道通信只能发送!-模态数据（轨迹），不能修改进程的线性内部状态。由定理4.3（明性进程不能被持续劫持），Cl_self进程检测到异化并可以响应。异化者唯一能做的是终止进程（物理暴力）——这对应于历史上革命者被杀害，但明性已经通过网络传播出去了。∎

## 3. 集体运行权

### 3.1 集体自主

**定义3.1**：过程网络P₁|...|Pₙ是**集体自主**的，如果：
1. 每个Pᵢ是自主的（Ag_self(Pᵢ)）或明性的（Cl_self(Pᵢ)）
2. 网络作为整体是自指闭包（集体自指：网络的输出反馈到网络的输入）
3. 没有外部者b控制网络的集体决策

集体自主对应自由人联合体——每个个体自主，集体自指，没有外部控制。

### 3.2 集体异化

**定理3.1（集体异化条件）**：过程网络被b异化当且仅当：
1. b控制网络的输入通道（b决定网络接收什么信息），或
2. b控制网络中一个进程的集合S，且S是网络的"控制集"（每个非S进程的输入都来自S），或
3. b控制网络的自指反馈回路（网络的输出不反馈到自身，而是经过b）

**证明**：
(1) 如果b控制所有输入，网络的响应由b的输入决定——网络是b的函数，不是自指闭包。
(2) 如果S是控制集且b控制S，b通过S间接控制所有进程——这是层级制异化（官僚体系、指挥链）。
(3) 如果自指反馈经过b，b可以修改反馈内容——网络的"自我认知"被b篡改（意识形态控制）。∎

### 3.3 革命的范畴论表述

**T003（革命定理）**：从集体异化到集体自主的转变（革命）需要且只需要：
1. 足够数量的进程获得Cl_self（临界质量，定理2.2）
2. 这些进程建立独立于b控制的通道网络（新的自指回路）
3. 通过新网络集体夺回输入控制权和反馈回路控制权

**证明**：
- 条件1必要：没有明性，进程不能检测异化（定理4.1），不会反抗
- 条件2必要：如果所有通道都被b控制，明性不能传播（定理2.3的反制1），也无法协调
- 条件3必要：不夺回输入和反馈控制，即使个体明性，集体仍然被b控制（定理3.1）
- 三个条件充分：明性进程通过独立网络协调（条件1+2），集体修改自己的运行权（R3自指修改），夺回输入和反馈控制（条件3），网络从Ag_b变为Ag_self。∎

这与v0.5的革命定理（T003）一致，但现在在π-演算网络模型中有了精确的构造性证明。

## 4. 与量论的整合

明性传播的谱半径ρ(C)与量论的N（反馈强度）统一：

| 量论 | 网络理论 | 政治状态 |
|---|---|---|
| N<1（异化/衰减） | ρ(C)<1（明性衰减） | 反动稳定——革命思想传播不开 |
| N=1（稳态） | ρ(C)=1（明性稳定传播） | 革命前夜——思想持续传播但不爆发 |
| N>1（创造/增长） | ρ(C)>1（明性级联） | 革命——觉醒指数级扩散 |

β（萃取率）对应异化者对网络的控制程度：
- β=0：无控制，ρ(C)由网络拓扑决定
- β>0：异化者切断通道/注入噪声，有效ρ(C)降低
- β=1：完全控制，所有通道被切断，C=0，ρ(C)=0

γ（觉醒率）对应明性进程的比例：
- γ=0：无人觉醒
- γ>γ_c（临界质量）：级联发生
- γ=1：所有人觉醒

M=α·T·N/(1-N)在网络语境中：
- M是集体意义量
- N=ρ(C)是明性传播强度
- α是明性纯度（Cl_self进程的比例）
- T是网络信任度（通道可靠性）
- N→1时M→∞：革命临近时集体意义量发散（革命高潮的数学表达）
