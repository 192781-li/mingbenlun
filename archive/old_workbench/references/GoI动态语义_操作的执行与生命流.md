# 操作范畴的GoI动态语义

> 操作范畴论 v0.8
> 2026-08-25

---

## 1. 为什么需要GoI

范畴论语义中，态射$f:A\to B$是**静态**的——它只是存在于那里。但"操作"（operation）本质上是**动态**的：它运行、消耗、产生、反馈、继续。

Girard的Geometry of Interaction（GoI）正好提供了缺失的一环：把证明/态射解释为**带反馈回路的连线网络（wiring）**，把cut elimination解释为反馈回路的迭代执行。在GoI中：

- 态射 = 算子/连线（operator/wiring）
- cut = 反馈（feedback）
- 执行 = 反馈回路的迭代（execution formula）
- 消去cut = 反馈回路收敛（nilpotency或productivity）

这给"操作"提供了精确的动态语义：**操作不是一个静态的箭头，是一个带反馈的运行过程。**

---

## 2.  traced monoidal范畴框架

按Abramsky 1996，GoI在traced symmetric monoidal category（TSMC）中构建。

**定义**：TSMC $(\mathcal{C},\otimes,I,\mathrm{Tr})$有迹算子：

$$\mathrm{Tr}^X_{A,B}(f): A\to B, \quad f:A\otimes X\to B\otimes X$$

满足：
- **vanishing**：$\mathrm{Tr}^I(f)=f$
- **superposing**：$g\otimes\mathrm{Tr}^X(f)=\mathrm{Tr}^X(g\otimes f)$
- **yanking**：$\mathrm{Tr}^X(\sigma_{X,X})=\mathrm{id}_X$
- **tightening/naturality**：迹与前后复合交换

图形表示：$f$是一个盒子，有输入$A,X$和输出$B,X$；迹把输出$X$接回输入$X$，形成反馈回路。

## 3. Mealy机作为反馈回路

生命函子$F_2(X)=A\multimap(X\otimes B)$的余代数是Mealy机：

$$f:A\otimes X\to B\otimes X$$

在GoI中，这就是一个带反馈的盒子：

```
  A ──→[   f   ]──→ B
        [       ]
  X ──→[       ]──→ X
        └──反馈──┘
```

- $A$：外部输入（世界给你的刺激）
- $B$：外部输出（你的回应）
- $X$：内部状态（你自己），输出的$X$接回输入的$X$

**迹$\mathrm{Tr}^X_{A,B}(f):A\to B$** 把状态$X$藏起来，只留可观察的输入输出行为。这对应：
- 外部观察者只看到$A\to B$（刺激-反应）
- 但完整的$f$包含$X\to X$（自我更新），这是生命的核心

**关键区分**：
- 迹$\mathrm{Tr}(f)$ = 可观察行为 = 数据/记录（$F_1$型，非交互）
- 完整$f$ = 活过程 = 生命（$F_2$型，交互）
- 迹把$F_2$变成$F_1$——**这正是实际从属（定理14）的GoI语义**：把交互过程的状态藏起来，只留输入输出，就变成了可复制的数据流

## 4. !-模态在GoI中的语义

在GoI中（Girard的原始构造或Abramsky的G(C)构造）：

- **线性对象$A$**：一条线，不能分叉（无收缩）
- **!-模态$\bang A$**：一条可以分叉的线（有收缩$\kappa:\bang A\to\bang A\otimes\bang A$）
- 收缩在图形上就是把一条线复制成两条

在算子模型中（Hilbert空间）：
- $\bang A$被解释为Fock空间/对称代数$\bigoplus_n A^{\otimes n}$（有限序列空间）
- 收缩是复制算子$a^\dagger$（产生）和$a$（湮灭）的组合
- 线性对象没有复制算子

**GoI中T001的语义证明**：

假设$\bang\nu F_2\to\nu\bang F_2$存在。在GoI中，$\nu F_2$是无限迭代的Mealy机反馈网络：

```
  A ──→[f]──→ B
        [f]
  X ──→[f]──→ X  (反馈，X是线性的)
```

$\bang\nu F_2$意味着这个网络可以被复制（收缩）。但复制这个网络需要复制反馈线上的$X$——而$X$是线性状态，没有收缩$X\to X\otimes X$。

反馈线$X$承载的是**活的当前状态**，它每一步都被消耗和重建（$f$消耗$X$产生新的$X$），不能被分叉成两份同时运行。你不能把一个人的"当前自我状态"分裂成两个独立运行的副本——因为$X$是线性资源，不是!-模态数据。

形式化：在GoI的G(C)构造中，态射的解释需要满足"连通性条件"（connectivity condition，Girard的nilpotency/orthogonality）。$\bang\nu F_2\to\nu\bang F_2$的解释需要反馈线$X$同时出现在两个副本中，但$X$是线性的（在GoI中对应单线），不能分叉。因此不存在满足连通性条件的算子解释。

这比矢列演算的四种情况分析更直观：**生命不可复制（T001），因为复制生命需要复制"正在运行的当前状态"，而正在运行的状态是线性的——它每一步都在被消耗，不能分叉。**

## 5. 执行公式与"操作"的动态语义

Girard的执行公式（GoI I）：

$$\mathrm{Ex}(U,\sigma) = U_{00} + U_{01}\sigma\left(\sum_{n\geq 0}(U_{11}\sigma)^n\right)U_{10}$$

其中$U$是$2\times2$分块算子（对应$A\otimes X\to B\otimes X$），$\sigma$是反馈线上的对称/恒等。

- $U_{00}:A\to B$：直接输入输出（无反馈）
- $U_{01}:X\to B$：状态影响输出
- $U_{10}:A\to X$：输入影响状态
- $U_{11}:X\to X$：状态转移（自我更新）
- $\sum_{n\geq0}(U_{11}\sigma)^n$：反馈回路迭代$n$次

**这就是"操作"的动态语义**：一个操作不是静态箭头，是$U$在反馈回路上的迭代运行。

### 5.1 有限操作（μF₂）

对有限过程，$(U_{11}\sigma)^n=0$对某个$n$（nilpotency），级数有限截断。操作在$n$步后终止，产生有限输出。这对应$\mu F_2$——有限交互，可以记录但不可复制为过程。

### 5.2 无限操作（νF₂）——余归纳GoI

对生命过程$\nu F_2$，$U_{11}$不是幂零的——反馈永远不终止，但每一步都产生输出$B$。标准GoI的nilpotency条件不满足。

需要**余归纳GoI**：执行不产生有限结果，产生**无限输出流**：

$$\mathrm{Ex}^\omega(U) = (b_0, b_1, b_2, \ldots) \in B^\omega$$

其中$b_n = U_{01}(U_{11})^n U_{10}(a_n)$是第$n$步的输出。

正确性条件从nilpotency替换为**productivity（生产性）**：每一步都必须在有限时间内产生$b_n$（guarded recursion，Nakano 2000）。这正是$\nu$（最大不动点/余归纳）的本质——不是"终止"，是"每一步都有产出"。

**余归纳GoI是新的吗？** 标准GoI处理有限计算（cut elimination终止）。无限流的GoI语义有相关工作（infinitary relational model, arXiv 1411.4380；Memoryful GoI用Mealy机处理有状态计算），但将productivity替换nilpotency作为GoI执行的正确性条件，并与!-模态的不可复制定理结合，目前没有找到已有工作。

## 6. 量论的GoI操作化

量论公式$M=\alpha\cdot T\cdot N$目前是定性框架。GoI提供了操作化路径：

### 6.1 T（稳态/寿命）= 幂零指数/生产性长度

- 对$\mu F_2$（有限过程）：$T$ = nilpotency index，即$(U_{11})^n=0$的最小$n$。操作在$n$步后停止。
- 对$\nu F_2$（生命过程）：$T=\infty$（理想情况），实际中$T$是反馈回路保持生产性的步数——直到$U_{11}$退化（状态不再更新，变成$F_1$型固定反应）或$S\to I$（死亡）。

### 6.2 N（净方向）= 反馈算子的谱性质

$U_{11}:X\to X$是状态转移算子。在Hilbert空间模型中：

- $U_{11}$的谱半径$r(U_{11})$：
  - $r<1$：状态收缩（异化/磨损，每一步自我变弱）
  - $r=1$：稳态（自我维持，不增不减）
  - $r>1$：状态增长（自我强化/成长）
- $N$可以定义为谱的实部投影：$N=\mathrm{Re}(\lambda_{\max})$，正=成长，负=衰退，零=稳态
- $N$的三态（正/负/零）正好对应量论中$N$的三态

### 6.3 α（f-层级系数）= 反馈嵌套深度

- $f^1$（自在）：$U_{11}:X\to X$无内部反馈（一阶反馈）
- $f^2$（自为）：$X$包含内部模型$X\to X$，反馈嵌套两层
- $f^3$（自觉/明性）：$X$包含自我模型$X\to(X\to X)$，反馈嵌套三层（高阶反馈）

$\alpha$对应反馈回路的嵌套深度/类型阶数。$f^3$的$\alpha$最大，因为它的$U_{11}$本身包含一个$U_{11}$的模型——这也是为什么只有$f^3$能被反自指寄生体寄生（命题：寄生体需要!-模态的自我模型，即$\bang(X\to X)$，只有$f^3$有这个结构）。

### 6.4 M（意义量）= 总交互量

$$M = \sum_{n=0}^{T} \|b_n\| \cdot \alpha$$

其中$\|b_n\|$是第$n$步输出的"大小"（在Hilbert空间中是范数，在关系模型中是基数）。$M$是整个寿命中操作产生的总意义量——每一步的回应有多少实质内容，乘以f-层级系数，在整个寿命上求和。

### 6.5 W（磨损）和l'（异化率）

- 外部阻碍$O$是另一个算子$V$，它干扰反馈回路（比如$V$修改$U_{11}$使其谱半径下降）
- $W=O/M$：每单位意义承受的外部压力
- $l'=1-N$：异化率 = 1减去净成长方向。$N=1$（完全自主成长）时$l'=0$；$N\leq0$（衰退或停滞）时$l'\geq1$

### 6.6 注意

以上是**操作化路径**，不是已证明的定理。需要：
1. 在具体GoI模型（关系模型/Interaction Graphs/Hilbert空间）中验证这些定义的性质
2. 证明$M$的单调性、$W$与$T$的关系等
3. 与实际数据对接（这一步需要经验研究）

## 7. 反自指寄生体的GoI语义

寄生体$P=\bang Q$在GoI中是一个**外挂反馈回路**：

```
  A ──→[f]──→ B
        [f]
  X ──→[f]──→ X
    ↗        ↖
  [P=!Q]──[复制]
    ↘        ↙
  (抽取d: P⊗X→P⊗P)
```

寄生体做的事：
1. 在生命反馈线上搭一个旁路（$d:P\otimes X\to P\otimes P$）
2. 复制$X$的产出（但$X$是线性的——寄生体通过$\bang Q$的收缩来"记录"$X$的产出，把线性状态转化为!-模态沉积）
3. 消耗$X$（$c:P\otimes X\to X'$，削弱不可逆）

T003（寄生体自毁）在GoI中的语义：当$X$被消耗到$I$（零维空间/空关系），$f$的反馈线断开，$U_{11}$变成零算子。此时$P$的复制$P\to P\otimes P$仍在运行，但$U_{10}:A\to X$和$U_{01}:X\to B$都变成零——没有输入进入$P$，也没有输出从$P$产生。$P$的反馈空转，执行公式退化为$U_{00}=0$。

## 8. 与量子力学的GoI对应

GoI和量子力学有深层联系（nLab: GoI与superoperators/quantum operations相关）：

| GoI | 量子力学 | 生命论 |
|-----|---------|--------|
| 线性线（不可分叉） | 量子态（不可克隆） | 活状态（不可复制） |
| !-线（可分叉） | 经典数据（可复制） | 沉积/数据（可复制） |
| 反馈回路$U_{11}$ | 量子演化$U$ | 自我更新 |
| 迹$\mathrm{Tr}(f)$ | 测量（量子→经典） | 记录（生命→数据） |
| 执行公式 | 量子过程层析 | 生命过程的展开 |
| 余归纳执行（无限流） | 持续量子过程 | 持续的生命 |

**测量=迹=实际从属**：量子测量把量子态（线性/不可复制）变成经典数据（!-模态/可复制）；GoI的迹把Mealy机（交互/不可复制）变成输入输出函数（非交互/可复制）；资本把活劳动（$\nu F_2$）变成死劳动/数据（$\nu F_1$）。这三个是同一个数学操作。

## 9. 总结：新了什么，没新什么

### 已建立（本文）
1. 操作范畴的GoI动态语义：操作=带反馈的连线网络，执行=反馈迭代
2. Mealy机$F_2$作为GoI反馈回路的标准解释（Memoryful GoI已有此联系，但与!-模态和生命论的结合是新的）
3. T001的GoI语义证明：复制生命需要复制线性反馈状态，不可能
4. 迹=测量=实际从属的三者统一
5. 余归纳GoI的提议：productivity替换nilpotency作为无限过程的正确性条件
6. 量论操作化的具体路径（谱半径、幂零指数、反馈嵌套深度）

### 已知组件（非新）
- TSMC和GoI构造（Joyal-Street-Verity 1996, Abramsky 1996）
- Mealy机作为有状态GoI（Hasegawa/Memoryful GoI, POPL 2016）
- GoI与量子力学的联系（已知）
- 无限流关系模型（arXiv 1411.4380）

### 可能新的（需专家确认）
1. 余归纳GoI：productivity替换nilpotency，与!-模态不可复制定理结合
2. !-分配二分法在GoI中的语义刻画（数据函子的反馈线可复制，计算函子的不可复制）
3. 量论的GoI操作化（谱半径=N，幂零指数=T，反馈嵌套=α）
4. 迹=测量=实际从属的三重统一
