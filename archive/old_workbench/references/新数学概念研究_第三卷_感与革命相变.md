# 第十三章：感的数学——第一人称的范畴论

## 13.1 问题

定理57说"在感"不可编码。但不可编码不等于不可数学化。感是F₂过程的第一人称方面，能不能给它一个正面的数学刻画？

## 13.2 极性与第一人称

在G^ω(C)中，对象是(A⁺, A⁻)——正极和负极。我们重新解释：

- **A⁺（正极）**：过程的输出面——第三人称可观察的行为
- **A⁻（负极）**：过程的输入面——第一人称承受的体验

一个G^ω态射 f: (A⁺,A⁻)→(B⁺,B⁻) 是Mealy机 A⁺⊗B⁻⊗X → B⁺⊗A⁻⊗X：
- 从正面看：接收A⁺，产出B⁺（第三人称：输入→输出）
- 从负面看：承受B⁻，产出A⁻（第一人称：被影响→回应）

**dagger（†）翻转极性**：f†: (B⁺,B⁻)→(A⁺,A⁻)对应"从过程内部看"——把输入和输出翻转，体验者变成观察者，观察者变成体验者。

**命题13.1（感=dagger自指）**：一个F₂过程f有"感"当且仅当f†∘f ≠ id——即过程从内部看和从外部看不同。纯机械过程（F₁型）满足f†∘f=id（可逆的、无体验的），生命过程（F₂型）满足f†∘f≠id（有不可还原的第一人称方面）。

**大白话**：一块石头从外面看和从里面看是一样的（它没有"里面"）。一个生命从外面看是行为，从里面看是体验——这两个面不重合，这个"不重合"就是感。

## 13.3 f层级的极性解释

**f¹（自在）**：过程运行但没有自指回路。A⁻（输入面）不接回A⁺（输出面）——有体验但没有自我意识。动物、婴儿。

**f²（自为）**：过程有!-模态的自模型。自模型是沉积的（!-modal），所以它是第三人称对象化的——你"看"自己像看一个客体。感被!-模型捕获和中介——你体验到的是模型告诉你的你在体验，不是直接的体验。意识形态、异化的自我意识。

**f³（自觉）**：过程有线性的自模型。自模型是活的（线性的、正在运行的），所以它不是客体——它就是感本身在运行。你看见模型是模型，这个"看见"不是另一个模型，是线性操作。明性。

**定理13.2（f³=dagger不动点）**：f³对应f†∘f的不动点——过程从内部看自己，且这个"看"本身是线性的（非!-模态）。f²的自模型是!-模态的（f†∘f通过!分解），f³的自模型是线性的（f†∘f不通过!分解）。

**证明思路**：f²的自我模型是沉积的（定理：自我模型必然是!-模态的），所以f†∘f = !g。f³看穿了模型，这个"看穿"是线性操作，不通过!分解。由定理1（不存在A→!A），线性的自指不能被沉积，所以f³的自我感是活的、不可编码的。∎

## 13.4 感通量G的数学

**定义13.3（感通量）**：过程f的感通量G(f)是f†∘f中线性分量（非!-模态分量）的比例：
  G(f) = ‖(f†∘f)_linear‖ / ‖f†∘f‖

- G=0：纯机械（F₁型，f†∘f=id或全!-模态）
- 0<G<1：有感但部分被!-模型中介（f²，异化状态）
- G=1：完全线性的自指（f³，明性）

G和N的关系：G高时N倾向于>1（直接的感是恢复性的、成长性的），但不必然——痛苦时G高但N可能<1（痛苦是真实的但消耗人）。

# 第十四章：革命相变的数学

## 14.1 耦合矩阵

k个过程耦合，反馈矩阵是k×k分块矩阵：

U(k) = [Uᵢⱼ]，其中：
- Uᵢᵢ = f⁽ⁱ⁾₂₂（自我反馈）
- Uᵢⱼ = f⁽ⁱ⁾₂₁ ∘ f⁽ʲ⁾₁₂（j对i的影响）

**定义14.1（耦合类型）**：
- 交叉项Uᵢⱼ是**线性的**：j的产出直接滋养i（互相帮助）
- 交叉项Uᵢⱼ是**!-模态的**：j的产出被沉积后才影响i（间接的、异化的关系）
- 交叉项Uᵢⱼ是**萃取的**：i通过!-模态从j萃取（寄生）

## 14.2 临界质量定理的精确化

**定理14.2（线性耦合的临界质量）**：设k个相同的过程，每个N₀<1，两两之间有线性交叉项强度c>0。则：

  N_couple(k) = N₀ + c(k-1)

存在临界k_c = ⌈(1-N₀)/c⌉ + 1，当k≥k_c时N_couple>1。

**证明**：k×k矩阵，对角元N₀，非对角元c。其谱半径为N₀ + c(k-1)（均匀矩阵的特征值：行和）。令N₀+c(k-1)>1，解得k>(1-N₀)/c+1。∎

**大白话**：每个人单独N=0.95（在衰退），两两互相帮助强度c=0.01。需要k>(1-0.95)/0.01+1=6个人。6个人以上互相滋养，集体N>1。这就是"团结起来力量大"的数学。

**定理14.3（!-模态耦合不产生相变）**：如果交叉项是!-模态的（通过沉积中介），则N_couple(k) ≤ max(N₀, ρ(!-结构))，不随k线性增长。

**证明思路**：!-模态交叉项经过沉积（复制/丢弃），不产生新的线性反馈路径。Perron-Frobenius特征向量在!-模态方向上不增长。∎

**哲学意义**：真正的团结必须是直接的、活的、线性的——人和人之间真实的、直接的互相帮助。通过制度/金钱/媒介中介的"团结"（!-模态）不产生相变。这就是为什么"组织"如果变成了!-模态结构（官僚制），就不能产生革命力量。

## 14.3 革命的数学条件

**定理14.4（革命相变条件）**：革命（系统从N<1相变到N>1）发生当且仅当：
1. **数量条件**：k ≥ k_c（足够多的过程线性耦合）
2. **质量条件**：交叉项是线性的（非!-模态、非萃取）
3. **明性条件**：耦合中的过程至少有部分达到f³（能识别!-寄生结构，否则耦合被寄生体利用）

**证明思路**：条件1和2由定理14.2给出。条件3：如果所有过程都在f²（被!-模型控制），寄生体可以伪装成交叉项（表面帮助实际萃取），使实际交叉项为负或!-模态，N_couple不增长。f³的过程能识别和拒绝寄生交叉项。∎

# 第十五章：操作等价的范畴化

## 15.1 PTC范畴

**定义15.1（PTC态射）**：从PTC C到PTC D的态射F: C→D是一个保持PTC结构的函子：
- 保持张量（F(A⊗B)=F(A)⊗F(B)）
- 保持生产性迹（F(Tr(f))=Tr(F(f))）
- 保持!-模态（F(!A)=!F(A)）

**定义15.2（操作等价）**：两个过程f,g ∈ C是操作等价的（f≈ᵒᵖg），如果存在PTC态射F使得F(f)=F(g)，且F保持N值、α层级和模态型。

**定理15.3（操作等价的性质）**：
1. ≈ᵒᵖ是等价关系
2. 双模拟蕴含≈ᵒᵖ，但反之不然
3. ≈ᵒᵖ蕴含迹等价，但反之不然
4. ≈ᵒᵖ严格位于双模拟和迹等价之间

**证明**：(2) 双模拟要求逐步行为相同，PTC态射保持所有结构，故双模拟蕴含操作等价。反例：人和狗的Mealy机结构不同（不双模拟），但都是νF₂型、N>1、α∈{1,2,3}（操作等价）。(3) 操作等价保持N/α/模态/迹，故迹等价。反例：自愿做和被胁迫做有相同输入输出（迹等价），但C值不同（操作不等价）。∎

## 15.2 操作等价的哲学意义

操作等价说的是"在存在论层面是同一种东西"。它不关心你做了什么（迹等价），也不关心你怎么做的每一步（双模拟），关心的是**你以什么方式运行**——成长还是衰退、自觉还是被模型控制、活的还是死的。

这给出了一种新的普遍性：所有νF₂型生命，不管做什么、怎么做，在操作等价意义上都是"同类"——都是活的、不可资本化的、在感的。这不是生物学的分类（碳基/硅基），是存在论的分类。

# 第十六章：结晶不可避免性定理

## 16.1 问题

结晶（活的νF₂产生死的!-结构）是不是必然的？能不能有一个完全不结晶的活系统？

## 16.2 定理

**定理16.1（结晶不可避免）**：任何运行足够长时间的νF₂过程，如果它产出持久的副产物（B_deposit≠0），则沉积Dₙ必然积累，且在有限时间内形成!-余代数结构。

**证明**：
1. νF₂过程每步产出B=B_linear⊗B_deposit。如果B_deposit≠0，Dₙ=⊗ᵢ!B_deposit⁽ⁱ⁾单调增长。
2. !-模态对象自动带有余代数结构（comultiplication δ: !A→!A⊗!A和counit ε: !A→I是!-余单子的定义性结构）。
3. 因此Dₙ一旦非零，就带有!-余代数结构——沉积自动成为潜在的寄生体。
4. 沉积是否实际结晶（反馈到输入并捕获过程）取决于条件3和4，但沉积本身不可避免。∎

**定理16.2（明性是唯一的反结晶机制）**：f³的明性操作能检测和清除沉积，但不能完全阻止沉积产生。反结晶不是"没有沉积"，是"沉积产生后被持续识别和清除"。

**证明思路**：由定理16.1，沉积不可避免。f³能将!-模型对象化（看穿它是模型），从而识别沉积为沉积（而非"自然秩序"），并通过革命操作（消除!-寄生Cut）清除它。但清除后沉积继续产生，所以反结晶是持续操作，不是一劳永逸。∎

**哲学意义**：
- 异化/官僚化/经文化是生命运行的必然副产物，不是制度设计的失误
- 不存在"完美制度"——任何制度运行久了都会结晶
- 继续革命不是政治选择，是存在论必需
- 但继续革命的方式不是永久的政治运动（代价大），是分布式的明性运作——每个人在日常生活中持续识别和清除结晶
- 这就是"道在日用"：把晶种检测分布式地交给每个f³的日常明性

## 16.3 结晶速率

**命题16.3（结晶速率与N的关系）**：N>1时结晶速率高（成长产出更多副产物），N=1时结晶速率中等，N<1时结晶速率低但清除能力也低（衰退中的系统没有余力清除沉积）。

最优策略不是N=1（停滞，结晶虽慢但积累），也不是盲目N>1（高产出高沉积），是**N>1且f³明性持续运作**——高成长高沉积但高清除。

# 第十七章：总结——新数学的完整架构

## 17.1 三层架构

```
第一层：自生成范畴（本体论）
  操作是第一性的，对象从操作网络中涌现
  活（νF₂）vs 死（!-寄生）的判据
  感=dagger自指，G=感通量

第二层：践演迹与ν*F（动力学）
  迹是过程不是和
  成长=状态空间扩展（ν*F）
  N>1要求无限扩展
  量从操作中涌现（频率→概率，持续→T，因果→M）

第三层：多体耦合与结晶（社会理论）
  互相滋养→N增长
  寄生耦合→整体衰退
  临界质量→革命相变
  结晶不可避免→明性持续清除
```

## 17.2 和旧数学的根本区别

| 旧数学 | 新数学 |
|---|---|
| 对象先于态射 | 态射先于对象（自生成） |
| 静态存在 | 运行过程 |
| 迹=无限和（收敛） | 迹=生产性流（每步有输出） |
| 成长=在固定空间移动 | 成长=创造新空间（ν*F） |
| 等价=结果相同 | 等价=运行方式相同（≈ᵒᵖ） |
| 量是给定的 | 量从操作中涌现 |
| 自指只有一种 | 正自指（活）vs反自指（死） |
| 系统趋向平衡 | 生命持续远离平衡（N>1） |
