## 2. 形式化
### 2.1 异步π-演算
使用**异步**π-演算语法（输出不阻塞，无需握手即可发生）：
```
P ::= 0 | x̄⟨y⟩ | x(y).P | τ.P | P|Q | (νx)P | !P
```
异步语义：输出x̄⟨y⟩是原子动作，不等待输入方就绪即可发生。这确保环境不能通过"不读a"来阻塞P_e的输出。
**Image-finiteness**：π-演算在有限步内的转移数有限（!P每步至多展开一次，和式有限），故深度≤t的执行树有限可枚举。
### 2.2 Provenance因果语义
标准LTS把同构子进程的τ转移合并、结构等价抹掉位置信息，"因果祖先"在其中不可定义。我们采用**provenance语义**（Boreale-Nicola 1995 proved transitions / Crafa-Varacca-Yoshida 2012事件结构）：
- 每个转移带有provenance标签，记录它由哪个前缀产生
- 因果依赖：动作α因果依赖于β，如果β在α之前且α引用了β引入的名字，或α在β的前缀之下
- provenance转移在有限树上可判定，且一致可判定（不依赖具体执行路径）
**定义2.1（内部因果）**：在执行轨迹中，通道a上的输出动作ā⟨y⟩是**内部引起的**，如果它在provenance因果森林中的所有祖先都是τ动作（P自己的内部选择），没有输入动作x(y)（来自环境的刺激）。
### 2.3 AGENCY定义
**定义2.2（AGENCY）**：
```
AGENCY = {(P, a) : ∀E, P|E的每条极大路径上a-输出无穷多次，
                   且每个a-输出都是内部引起的}
```
两个条件：
1. **因果条件**：所有a-输出的因果祖先全为τ（不是对环境输入的反应）
2. **活性条件**：在每条极大路径上，a上输出无穷多次（系统永远自我维持，不死、不沉默）
活性条件排除了"空洞为真"问题：一个只做一次内部输出然后死锁的进程，虽然因果条件成立，但活性条件失败。
### 2.4 AGENCY在Π₂中
**引理2.1**：AGENCY ∈ Π₂。
**证明**：定义判定谓词R(P,E,t,s,a)：
> R = "在P|E的所有长度≤s的执行路径上：(i) [0,s]内每个a-输出的因果祖先全为τ；(ii) 每条长度为s的路径在[t,s]内至少有一次a-输出"

R一致可判定：image-finiteness保证深度s的执行树有限；provenance语义保证因果检查可判定。

AGENCY等价于：
```
∀E ∀t ∃s R(P,E,t,s,a)
```
- ∀E：所有环境（可数域，π-演算进程可枚举）
- ∀t：所有时间点
- ∃s：存在一个视界s，在s步内因果条件成立且[t,s]内有输出

这是∀∀∃Δ₀ = Π₂的标准形式。

活性条件用König引理保证："每条极大路径在t后有无穷多输出"等价于"∃s，每条s-路径在[t,s]内有输出"（有限分支树中，如果每条极大路径在t后有输出，则存在一致界s）。∎
### 2.5 关键：为什么不是Π₁
如果只有因果条件（∀E∀t SC），那是∀∀Δ₀ = Π₁。但Π₁命题不能是Π₂-完全的（否则Π₂=Π₁，算术层谱坍塌）。活性条件加入了∃s，使整个命题成为∀∀∃Δ₀ = Π₂。这正是"持续自我维持"超越"所有输出内部引起"的地方——前者是无穷性质，后者是有限视界性质。

## 3. Π₂-困难性
### 3.1 归约
从TOTAL（Π₂-完全）归约：
**TOTAL = {e : ∀x, φ_e(x)停机}**
给定图灵机e，构造异步π-演算进程P_e：
```
P_e = (νc)(Runner_e(c) | Reporter(c, a))
Runner_e(c) = c̄⟨0⟩.RunSeq_e(c, 0)
RunSeq_e(c, k) = [模拟φ_e(k)；若停机则c̄⟨halt⟩.RunSeq_e(c, k+1)；若不停机则永远等待]
Reporter(c, a) = c(halt).ā⟨halt⟩.Reporter(c, a)
```
P_e行为：
1. Runner依次模拟φ_e(0), φ_e(1), φ_e(2), ...
2. 每次φ_e(k)停机，通过私有通道c通知Reporter
3. Reporter在a上异步输出（不阻塞），然后继续等待
4. 如果φ_e(k)不停机，Runner永远等待，c上无信号，a上不再有输出
### 3.2 归约正确性
**引理3.1**：e ∈ TOTAL 当且仅当 (P_e, a) ∈ AGENCY。
**证明**：
(⇒) 假设e∈TOTAL。
- **因果条件**：a上每个输出由c上的信号触发，c上的信号由Runner内部模拟φ_e(k)（τ链）触发。c是(νc)私有通道，环境E不能在c上通信。P_e除a外无自由名，不在a上接收输入。因此E无法向a-输出注入外部因果——所有a-输出的祖先全为τ。
- **活性条件**：φ_e对所有输入停机，Runner依次完成每个φ_e(k)，Reporter在a上输出无穷多次。异步语义下输出不阻塞，E无法通过"不读a"阻止输出。
- 两个条件在所有E中成立（E无法影响P_e的内部行为）。

(⇐) 假设e∉TOTAL，存在k使φ_e(k)不停机。
- Runner在模拟φ_e(k)时永远等待，c上不再有信号。
- Reporter等待c，a上不再有输出。
- 取E=0（空环境），P_e|0在a上可观察地沉默——活性条件失败（不是τ-沉默：Runner内部可能仍有τ，但a上无输出）。
- 因此(P_e, a) ∉ AGENCY。

注意：活性必须是"a上输出无穷多次"而非"τ-活跃"——卡在φ_e(k)上的P_e内部τ可能永不停止，但a上沉默，这正是"失去自我维持"。活性也不能是"有界间隙"（∃L∀t在[t,t+L]内有输出），因为φ_e(k)的停机时间无界，即使e∈TOTAL，相邻输出间隙也无界。∎
**定理1.1**：由引理2.1（∈Π₂）和引理3.1（Π₂-困难），AGENCY是Π₂-完全的。∎

## 5. 意义
### 5.1 与停机问题的关系
| 问题 | 复杂性 | 神谕需求 |
|---|---|---|
| HALT（停机） | Σ₁-完全 | 不可判定 |
| TOTAL（全函数） | Π₂-完全 | 需要Σ₁神谕 |
| AGENCY（运行权） | Π₂-完全 | 需要Σ₁神谕 |
AGENCY与TOTAL递归同构（v1.6定理2.1证明）："一个系统是否永远自己运行自己"和"一个程序是否对所有输入停机"是同一个计算问题。
### 5.2 践演意义
- 自我模型m_A是!-模态的（有限/递归可枚举，Σ₁）
- Ag(A,A)是Π₂命题
- Σ₁理论不能证明Π₂-完全命题（算术分层定理）
- 这给践演不完备性定理提供了独立的计算复杂性证明：不是因为系统不够强，是因为"自由"本身的复杂性就是Π₂
### 5.3 Π₂政治哲学
- "A是自由的"=∀情境∀时刻，A自我控制=Π₂命题——只能证伪不能证实
- "A被压迫"=∃情境∃时刻，A被控制=Σ₁命题——一个实例就够
- "继续革命"=维持Π₂性质的数学要求——必须在每个情境每个时刻持续验证

- **停机问题**（Turing 1936）：Σ₁-完全
- **TOTAL问题**：Π₂-完全（经典结果）
- **π-演算活性问题**：Π₂-完全（"某条件在所有路径上永远成立"）
