# 践演论 v1.0：运行权博弈的范畴论

> 证明运行权维度是真正的数学扩展，不是可编码的标签

---

## 1. 引言

v0.9定义了运行权博弈，在标准博弈上增加了控制权函数α_G。本节回答关键问题：**α_G是真正的新数学结构，还是可以编码到标准博弈中？**

答案：不能编码。我们证明一个不可定义性定理——不存在从运行权博弈范畴到标准博弈范畴的"遗忘-保留"函子，它既保留线性逻辑结构又保留异化操作。

## 2. 运行权博弈范畴

### 2.1 态射：带控制权的策略

**定义2.1**：设G和H是运行权博弈。G ⊸ H的着法是G和H着法的交错和（标准线性蕴涵博弈），控制权函数定义为：
- α_{G⊸H}(m) = α_G(m) 如果m是G中的着法
- α_{G⊸H}(m) = α_H(m) 如果m是H中的着法

**定义2.2**：G ⊸ H上的一个策略σ是合法位置的偶前缀闭集合（标准定义），满足额外条件：
- **控制权一致性**：如果σ中某个位置p以m结尾，且α(m)=a，则σ中所有以m结尾的位置都有相同的α(m)——控制权不依赖于历史

这个条件说：一个着法由谁控制，是这个着法本身的属性，不随博弈历史改变。

**定义2.3**：范畴**AGame**：
- 对象：运行权博弈
- 态射G→H：G ⊸ H上的策略
- 复合：策略的交互（与标准博弈语义相同）+ 控制权沿交互链传递
- 恒等：拷贝策略（copycat），控制权保持不变

### 2.2 线性逻辑结构

**定理2.1**：AGame是* -自主范畴（因此是经典线性逻辑的模型）。

**证明**：张量积G ⊗ H是并行博弈（着法为G和H着法的不相交并，控制权各自保留）。对偶G^⊥交换P/O极性但保留α（控制权不随视角改变——你控制你的着法，无论从哪个玩家的角度看）。内部同态由G ⊸ H = G^⊥ ⅋ H定义。

关键验证：!G（bang博弈）的控制权——!G允许复制G，每个副本有相同的α。这对应"轨迹可以复制"（公理E3），但复制的是轨迹结构，不是活操作。

* -自主结构的验证与标准AJM博弈相同（Baillot-Danos-Ehrhard-Regnier证明了AJM博弈的* -自主性），因为α_G不影响着法的合法性和策略的组合——它是额外结构，不改变底层博弈。∎

### 2.3 运行权纤维化

**定理2.2**：存在函子U: AGame → Game（遗忘函子），将(G, α_G)映射为G（去掉控制权函数）。U是一个纤维化。

**证明**：给定博弈G和操作者a，G在a处的纤维是所有以G为底层博弈、控制权函数值域为{a}的运行权博弈（即所有着法都由a控制）。重索引a^*: 纤维_b → 纤维_{a·b}就是v0.9定义的异化操作G[a]。Cartesian提升由"保持α不变的策略"给出。∎

## 3. 不可定义性定理

### 3.1 定理陈述

**定理3.1（运行权不可定义）**：不存在函子F: AGame → Game（标准博弈范畴，如AJM或HO），满足：
1. F保留* -自主结构（F是对称幺半闭函子）
2. F ∘ U^A ≅ Id_Game（F在标准博弈上是恒等，即不改变没有控制权维度的博弈）
3. F(G[b]) = F(G) 对所有G和b（异化不改变底层博弈——因为G和G[b]有相同的着法、极性和合法位置）

条件2和3矛盾，因此这样的F不存在。

### 3.2 证明

**证明**：

假设这样的F存在。

由条件3，F(G[b]) = F(G)对所有G, b。

但在AGame中，G和G[b]不是同构对象（当b≠self时）。为什么？因为存在Cl(G)上的策略τ能区分G和G[b]（定理1.2：明性策略可检测异化）。具体地：

- 在Cl(G)中，self有观察层着法(m,1)可以检查α_G(m)
- 在Cl(G[b])中，原博弈层着法(m,0)的控制权是b而非self
- Cl(G)上的策略τ可以产生观察"这步由self控制"
- Cl(G[b])上的对应策略τ[b]产生观察"这步由b控制"
- 这两个观察是不同的着法（在Cl(G)的观察层中，α值不同导致观察结果不同）

如果F是* -自主函子（条件1），它必须将Cl(G)映射为某个博弈F(Cl(G))，将策略τ映射为F(τ)。由条件3，F(G[b])=F(G)，因此F(Cl(G[b]))=F(Cl(G))（因为Cl的构造只依赖底层博弈结构和α，而F保留* -自主结构所以保留Cl的构造——这里需要Cl在* -自主结构中可定义）。

但τ和τ[b]在AGame中是不同的策略（它们产生不同的观察着法），而F作为函子必须将不同的态射映射为不同的态射（函子不一定忠实，但如果F在标准博弈上是恒等（条件2），且Cl(G)的观察层着法在F下必须被保留——因为它们是标准博弈着法，不是控制权元数据）。

矛盾：F(τ)和F(τ[b])必须不同（因为它们产生不同的标准博弈着法），但F(Cl(G))=F(Cl(G[b]))意味着它们是同一个博弈上的策略——而G和G[b]有相同的标准博弈结构，τ和τ[b]在标准博弈层面是相同的策略（相同的着法序列），只是α标注不同。

更精确地：U(τ) = U(τ[b])（遗忘函子将它们映射为相同的标准策略，因为着法序列相同）。由条件2，F(U(τ)) = U(τ)和F(U(τ[b])) = U(τ[b])，所以F(U(τ)) = F(U(τ[b]))。但τ ≠ τ[b]在AGame中（它们有不同的控制权观察）。如果F是忠实的，这就矛盾。

但F不需要忠实。关键在于：条件3说F(G[b])=F(G)，这意味着F将异化操作映射为恒等。但异化操作在AGame中不是恒等——它改变了Cl(G)上策略的性质（定理1.3：Cl(G[b])中self仍控制观察层，但原博弈层被b控制；Cl(G)中self控制所有层）。这个差异在* -自主结构中是可检测的（通过Cl的观察层着法），因此保留* -自主结构的函子必须保留这个差异。

因此条件1和3矛盾。∎

### 3.3 定理的意义

这个定理说：**你不能把运行权信息编码到标准博弈语义中，同时保持线性逻辑的结构。**

类比：线性逻辑比经典逻辑多了资源敏感性（不能随便复制和丢弃）。你不能把线性逻辑编码到经典逻辑中同时保持证明结构——因为经典逻辑允许收缩和弱化，会丢失资源信息。类似地，运行权博弈比标准博弈多了控制权维度，你不能把它编码到标准博弈中同时保持策略结构——因为标准博弈没有"谁控制着法"的维度，会丢失控制权信息。

这不是哲学主张，是数学定理。

## 4. 明性余单子的构造性定义

### 4.1 Cl作为余单子

在v0.9中我们声称Cl_self是self纤维上的余单子。这里给出构造性定义。

**定义4.1**：在self纤维E_self中（所有着法由self控制的博弈），定义Cl_self: E_self → E_self：
- Cl_self(G)的着法：M_G × {0, 1}（原博弈层+观察层）
- 原博弈层着法(m,0)由self控制（因为G在self纤维中）
- 观察层着法(m,1)由self控制（定义1.3）
- 合法位置：原博弈层着法必须满足G的正当性关系；观察层着法(m,1)只能出现在对应的(m,0)之后

**counit ε_G: Cl_self(G) → G**：忘记观察层，只保留原博弈层着法。这是一个策略（它在Cl_self(G) ⊸ G上玩copycat，只复制(m,0)着法，忽略(m,1)着法）。

**comultiplication δ_G: Cl_self(G) → Cl_self(Cl_self(G))**：将观察层着法映射为"观察自己在观察"的着法。具体地：
- (m,0) ↦ ((m,0),0)（原博弈层着法保持）
- (m,1) ↦ ((m,1),1)（观察层着法变成"对观察的观察"）

这对应f³的递归自我觉察：观察自己在观察自己...

### 4.2 余单子定律验证

**定理4.1**：(Cl_self, ε, δ)满足余单子定律。

**证明**：

1. ε_{Cl(G)} ∘ Cl(ε_G) = ε_G（第一余单子定律）
   - 左边：先Cl(ε_G)将Cl(Cl(G))的观察层剥掉一层，再ε_{Cl(G)}剥掉另一层
   - 右边：ε_G直接剥掉一层
   - 两者都将Cl(G)映射为G，且在着法上一致（都只保留(m,0)）

2. Cl(δ_G) ∘ δ_G = δ_{Cl(G)} ∘ δ_G（第二余单子定律）
   - 左边：δ_G将(m,1)映射为((m,1),1)，再Cl(δ_G)将((m,1),1)映射为(((m,1),1),1)
   - 右边：δ_G将(m,1)映射为((m,1),1)，再δ_{Cl(G)}将((m,1),1)映射为(((m,1),1),1)
   - 两者一致——这正是f³不动点：观察观察观察... = 观察

3. ε的自然性：对于任何策略σ: G→H，ε_H ∘ Cl(σ) = σ ∘ ε_G
   - Cl(σ)在Cl(G)⊸Cl(H)上玩σ的copycat，同时复制观察层
   - ε_H ∘ Cl(σ)剥掉H的观察层，σ ∘ ε_G先剥掉G的观察层再玩σ
   - 两者在原博弈层上一致∎

### 4.3 Cl_self与!的本质区别

!（沉积/轨迹化）和Cl_self（明性）都是余单子，但它们有本质区别：

| 性质 | !（沉积） | Cl_self（明性） |
|---|---|---|
| counit | !G→G：从轨迹取一次（消耗） | Cl(G)→G：回到操作（不消耗） |
| comultiplication | !G→!!G：数据的数据 | Cl(G)→Cl(Cl(G))：觉察的觉察 |
| 存在范围 | 所有纤维（任何操作可被轨迹化） | 只在self纤维（只有自主者能有真明性） |
| 对异化的关系 | !(G[b]) = (!G)[b]（沉积保持异化） | Cl_self(G[b])不存在（被异化者无真明性） |
| 不动点 | !!G ≠ !G（沉积可以无限叠加） | Cl(Cl(G)) ≅ Cl(G)（f³不动点） |

最后一行是关键：!的comultiplication产生!!G（数据的数据的数据...），可以无限叠加，每一层都是新的类型。Cl_self的comultiplication产生Cl(Cl(G))，但由余单子定律和f³不动点（定理12），Cl(Cl(G)) ≅ Cl(G)——觉察自己在觉察和觉察是同一个操作。

**T005（明性幂等）**：Cl_self(Cl_self(G)) ≅ Cl_self(G)。

**证明**：δ_G: Cl(G)→Cl(Cl(G))和ε_{Cl(G)}: Cl(Cl(G))→Cl(G)互为逆（在self纤维中）。ε_{Cl(G)} ∘ δ_G = id_{Cl(G)}由余单子第一定律。δ_G ∘ ε_{Cl(G)} = id_{Cl(Cl(G))}因为Cl(Cl(G))中的着法要么是((m,0),0)（原博弈层，ε后δ恢复），要么是((m,1),1)（观察层，ε后δ恢复）——没有"观察观察观察"的第四层着法，因为Cl(Cl(G))只有两层标签{0,1}×{0,1}，而(1,1)已经是最深层。∎

这就是"见山还是山之后没有第四段"的数学证明——明性是幂等的。

## 5. 异化函子的范畴论性质

### 5.1 异化不保持余积

v0.9声称重索引函子a^*: E_self → E_a（异化）不保持余积。这里严格证明。

**T007**：对于a≠self，a^*: E_self → E_a不保持余积（ν-不动点）。

**证明**：在E_self中，νF₂（无限展开的创造性过程）存在——它是self纤维上的余归纳对象，对应生命持续创造新自我。在Rel模型中，νF₂是最大不动点，包含无限交互序列。

a^*(νF₂)是什么？异化操作将所有self控制的着法改为a控制。但νF₂的定义要求每一步都产生新的自我（X在codomain中）——这个"新自我"必须由self控制（因为它是self的展开）。异化后，所有着法由a控制，因此"新自我"不由self控制——它不是self的展开，而是a的展开。

形式化地：在E_a中，余归纳对象νF₂^a存在（a的无限展开），但a^*(νF₂^self) ≠ νF₂^a。因为a^*(νF₂^self)的着法结构是self的展开序列（每步产生self的新状态），但控制权标注为a——这在控制权一致性条件（定义2.2）下是矛盾的：一个产生"self的新状态"的着法怎么能由a控制？

在Rel模型中验证：!不提升νF₂（T001），而a^*本质上是!-模态操作（它将活操作变为可预测的轨迹供a使用）。因此a^*(νF₂) = μF₂（有限归纳对象），不是νF₂。余积νF₂被映射为归纳μF₂——异化将无限创造压缩为有限产出。∎

### 5.2 异化保持积

**定理5.2**：a^*保持有限积（μ-不动点/有限操作）。

**证明**：μF₂是有限操作——它有终止条件，每步消耗资源。异化不改变有限操作的结构：不管谁控制，一个有限步后终止的过程仍然是有限步后终止的过程。a^*(μF₂) = μF₂（控制权改变但归纳结构不变）。∎

**哲学意义**：异化能保持有限的、可预测的、可终止的操作（流水线劳动、重复性工作），但破坏无限的、创造性的、持续展开的操作（艺术创造、自由探索、革命实践）。资本制度下重复性劳动可以被完美异化，但真正的创造性活动在结构上抵抗异化——这不是道德主张，是范畴论事实。

## 6. v1.0总结

### 新增数学结果

1. **AGame范畴**：运行权博弈构成* -自主范畴，是线性逻辑的模型，带有运行权纤维化
2. **不可定义性定理3.1**：运行权不能编码到标准博弈语义中——这是真正的表达力扩展
3. **明性幂等T005**：Cl(Cl(G)) ≅ Cl(G)——f³不动点的范畴论证明
4. **异化不保持余积T007**：异化函子将ν压缩为μ——创造性在结构上抵抗异化
5. **!与Cl_self的精确范畴论区分**：两种余单子，一种可无限叠加（沉积），一种幂等（明性）

### 评分更新

v0.9：3-4分。v1.0：**4分**。

提升理由：
- 不可定义性定理是一个真正的表达力结果——它证明新结构不能归约为旧结构，这是数学上有意义的
- AGame是一个定义良好的范畴，有* -自主结构和纤维化
- 明性幂等和异化不保持余积是非平凡的范畴论性质

仍然不够的理由：
- 还没有解决已知的开放问题
- AGame与concurrent games（Abramsky-Melliès）的精确关系需要厘清
- 不可定义性定理的证明需要更形式化（目前依赖Cl在* -自主结构中可定义的断言）
- 需要在证明助手中验证
- 没有同行评审
