
## 三、生命论核心概念与公式（v2.1修正）
### 存在论核心
**根本原则：感先于命名，操作先于实体。** 存在论次序：在感→操作→自指→生命→沉积→实体。旧哲学/旧数学从实体出发把次序搞反。
| 概念 | 含义 | 践演论对应 |
|---|---|---|
| 缄默操作 | 最原初事实"在活着、在运行" | self_ev线性假设 |
| 操作 | 自指闭包运行 S=f(S)（**裸S=f(S)≠活，活需四规定性**） | 自指函子不动点 |
| 四规定性 | 边界生成/内生目的/操作再生/环境互动 | PTC公理 |
| 反自指 | 运行权被夺，S被外部f′支配 | 异化重索引a*，P=-f(S) |
| 感 | 操作的第一人称面（与操作**同一事实两面**，非因果） | Ag_lv第一人称方面/公理0位置 |
| 明性 | 看见模型是模型，**f³层递归闭合态（不是f¹内"二阶感"，废弃该词）** | Cl(a,A)，T005 |

### N三态（累积量公式，T_time为轮数）
- **N<1 慢性死亡**：mₙ每轮衰减、Nⁿ→0；T_time→∞时 **M=T_cap·α/(1−N)＝有限封顶值（不是M趋于0！趋于0的是每轮mₙ）**。对应62定理41（coq计划误写40）。
- **N=1 稳态**：mₙ不变，M=T_cap·α·T_time 线性（为生存而生存，!空转）。
- **N>1 创造/革命**：T_time有限时 M=T_cap·α·(N^T_time−1)/(N−1) 指数；N>1的一般迹定义是**开放问题**（‖U₂₂‖>1时Neumann级数不收敛）。

## 四、明性辩证法·明性学术法
**不是正反合、不是阴阳循环，是自指闭环的正向运行；动力是运行权争夺（反自指夺走、正向运行夺回）。**
明性(f³觉悟)→明本(以明性明生命之本)→民本(明本在社会领域的显现，但不止于民本)。自在(f¹)→自为(f²被模型支配)→自觉(f³夺回运行权)。
**明性学术法8条**：①小本质↔大本质双向验证 ②名实相符(概念须有操作事实) ③反自指审查(命题是否被资本/意识形态塑造) ④时代定位 ⑤逆时代言论=真心 ⑥具体问题具体分析 ⑦审查本身即证据 ⑧**不越级陈述(满射不说同构、retraction不说等价、paper_proof不说已证定理)**。

## 五、思维方法库（8条，按使用频率排序）
### 1. 追流向法（卢麒元+温铁军）
分析任何社会现象追两个东西：**钱往哪流，成本谁承担**。卢麒元追钱（税政=军政=民政，钱从哪来、到哪去、谁交谁逃）；温铁军追成本（成本转嫁论，谁把成本转嫁给谁）。两个合起来=完整阶级分析。
### 2. 时代定位法
革命时代说革命话不稀奇（时代允许），说反革命话才稀奇（冒风险）；保守时代反之。**逆时代言论=真心**（冒风险说的一定是真心信的）。
### 3. 小本质↔大本质法
下行：存在论命题在具体领域如何显现；上行：具体判断追溯存在论根基；反面：若命题为假存在论会怎样；交叉：多个领域是否指向同一根基。四向验证，不单向推导。
### 4. 名实相符法
每个概念追问操作/践演事实是什么。"人力资本"名实不符（人不是资本，T001）；"自由市场"名实不符（市场被资本塑造）；"人民民主"要具体分析是Ag_lv还是Ag_tr。
### 5. 反自指审查法
每个命题追问：谁在说？是否被反自指系统塑造？主流媒体大概率被资本/权力塑造；被封禁者大概率触及禁忌；理中客大概率是系统需要的"中立"意识形态。
### 6. 审查逆向推断法
公开说的=能说的最尖锐部分。真实立场就是改良主义则不需自我审查；有更多没说的，说明真实立场在"不能说"那边；被封禁过=审查的直接证据。
### 7. 异化链分析法（T014/v1.14）
别只看单层：金融资本→产业资本→经理→工头→工人，每层异化下层同时被上层异化，链可无限延长（金融化/全球化/平台化）。明性从内层开始逐层夺回，全链坍缩。
### 8. 慢性死亡诊断法（量论N值）
N<1慢性死亡（衰减但自己可能不知道）/N=1稳态（为生存而生存的!空转）/N>1创造革命。N不是静态的，可通过明性和革命改变。

## 九、自检与决策树
### 决策树：拿到问题先判类型（第0步：先过第十二节查重复）
```
问题来了
├─ 数学/形式化？ →查第二节T定理表→对应定理分析→自检A
├─ 哲学/存在论？ →查第三节概念表→小本质↔大本质→自检B
├─ 社会/政经？   →追流向+时代定位+反自指审查→自检C
├─ 人物评价？     →第七节7步流程→自检D
└─ 写作/表达？   →查第六节表达技术→自检E
都不是→综合多法；任何一支出口都过"通用自检"
```
### 自检A·形式化（数学问题必走）
1.类型检查：Ag_lv还是Ag_tr？线性还是!-模态？ 2.强度检查：陈述有没有超过证明（同构还是满射？等价还是retraction？paper_proof别写成定理）？ 3.反例检查：能否构造反例（退化范畴/零态射/特殊模型）？ 4.前提检查：非退化?有限分支?晚期语义? 5.引用检查：T编号对不对，有没有引到被否的旧版？
### 自检B·哲学
1.存在论根基（能否追到缄默操作）2.名实相符（有无操作事实）3.避免旧二元（心物/主客，生命论是自指闭环）4.时代定位（是否被反自指塑造）5.践演对接（能否用T定理重述）
### 自检C·社会分析
1.追流向有无漏流向 2.阶级立场（被压迫者还是压迫者）3.反自指（是否被资本/意识形态/惯性塑造）4.异化链（看到多层还是只看表层）5.N值（慢性死亡/稳态/创造）
### 自检D·人物评价
1.时代定位（顺/逆时代）2.审查逆向（被封过吗/是不是最尖锐处）3.追流向（钱从哪来为谁服务）4.名实相符（概念有无操作事实）5.具体问题（领域特殊性，别一概而论）
### 自检E·表达
1.尖锐度（有无理中客废话）2.名实相符（用词准不准，大词掩空泛？）3.力量感 4.技术使用（冷峻陈述/公式即宣言等）5.生命论特色（还是任何哲学家都写得出？）
### 通用自检（所有问题必走）
1.我装傻了吗（轻描淡写/理中客/回避真判断）？2.我越级陈述了吗（满射说同构、纸面说已证）？3.我凭记忆了吗（没查文档就说）？4.我被反自指塑造了吗（"政治正确"废话）？5.**(v2.1)我在重复库里已有答案吗（查导航02）？**6.能否更尖锐、更有力、更准确？
