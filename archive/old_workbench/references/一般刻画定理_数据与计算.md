# 一般刻画定理：哪些函子可被!提升（修正版）

> 操作范畴论 v0.6.1
> 2026-08-25
> 修正：定理16原表述"X在G中出现即阻止分配"有误。X出现在函数domain（输入/被消耗位置）时分配律存在；只有X出现在codomain（输出/被生产位置）或⊕分支中时才阻止。

---

## 1. 四个判断

对含一个自由变元$X$的线性逻辑公式$G(X)$，定义四个可证明性判断：

| 判断 | 矢列 | 含义 |
|------|------|------|
| $P(G)$ | $G(X) \vdash G(!X)$ | 线性$G$可直接提升 |
| $D(G)$ | $G(!X) \vdash G(X)$ | $!$-版本可弃置回线性 |
| $Q(G)$ | $!G(X) \vdash G(!X)$ | **分配律**（!推过$G$） |
| $R(G)$ | $!G(!X) \vdash G(X)$ | 双!可弃置回线性 |

分配律$\lambda^G: !G(X) \to G(!X)$存在当且仅当$Q(G)$成立。

---

## 2. 递归定义

### 2.1 基例

| $G$ | $P(G)$ | $D(G)$ | $Q(G)$ | $R(G)$ |
|-----|--------|--------|--------|--------|
| $X$ | ✗（定理2.1：$X \not\vdash !X$） | ✓（弃置$!X \vdash X$） | ✓（公理$!X \vdash !X$） | ✓（弃置$!X \vdash X$） |
| $C$（常量） | ✓（$C \vdash C$） | ✓ | ✓（弃置$!C \vdash C$） | ✓ |

### 2.2 乘法$\otimes$

$$P(G_1 \otimes G_2) = P(G_1) \land P(G_2)$$
$$D(G_1 \otimes G_2) = D(G_1) \land D(G_2)$$
$$Q(G_1 \otimes G_2) = Q(G_1) \land Q(G_2)$$
$$R(G_1 \otimes G_2) = R(G_1) \land R(G_2)$$

**证明**：
- $P$：$\otimes L$拆分$G_1 \otimes G_2$，分别用$P(G_1)$和$P(G_2)$，$\otimes R$合并。
- $D$：类似。
- $Q$：由余单子的monoidal strength，$!(G_1 \otimes G_2) \to !G_1 \otimes !G_2$，再用$Q(G_1)$和$Q(G_2)$。
- $R$：$!(G_1(!X) \otimes G_2(!X)) \to !G_1(!X) \otimes !G_2(!X) \to G_1(X) \otimes G_2(X)$。

### 2.3 加法与$\&$和析取$\oplus$

$\&$与$\otimes$规则相同（投影后分别处理，$\&R$合并）。

对于$\oplus$：

$$P(G_1 \oplus G_2) = P(G_1) \land P(G_2)$$
$$D(G_1 \oplus G_2) = D(G_1) \land D(G_2)$$
$$R(G_1 \oplus G_2) = R(G_1) \land R(G_2)$$

但：

$$Q(G_1 \oplus G_2) = \text{false（当$X$在$G_1$或$G_2$中非平凡出现）}$$

**证明**：$Q(G_1 \oplus G_2)$要求证$!(G_1 \oplus G_2) \vdash G_1(!X) \oplus G_2(!X)$。最后一步只能是$\oplus R_1$或$\oplus R_2$。

- $\oplus R_1$：需证$!(G_1 \oplus G_2) \vdash G_1(!X)$。弃置得$G_1 \oplus G_2 \vdash G_1(!X)$，$\oplus L$要求$G_1 \vdash G_1(!X)$（即$P(G_1)$）和$G_2 \vdash G_1(!X)$。若$X$在$G_1$中正出现，$P(G_1)$失败。
- $\oplus R_2$：同理，$P(G_2)$失败。

promotion不能作为最后一步（结论$G_1(!X) \oplus G_2(!X)$不以$!$开头）。因此$Q(G_1 \oplus G_2)$在$X$正出现于任一分支时不可证。∎

### 2.4 线性蕴含$\multimap$

$$P(G_1 \multimap G_2) = D(G_1) \land P(G_2)$$
$$D(G_1 \multimap G_2) = P(G_1) \land D(G_2)$$
$$Q(G_1 \multimap G_2) = D(G_1) \land P(G_2)$$
$$R(G_1 \multimap G_2) = P(G_1) \land D(G_2)$$

**证明**：

$P(G_1 \multimap G_2)$：需证$(G_1 \multimap G_2) \vdash G_1(!X) \multimap G_2(!X)$。Curry反转：
$$(G_1 \multimap G_2),\ G_1(!X) \vdash G_2(!X)$$
- 用$D(G_1)$：$G_1(!X) \vdash G_1(X)$（将!-版本输入降级为线性输入）
- 应用$\multimap L$：$(G_1 \multimap G_2), G_1(X) \vdash G_2(X)$
- 用$P(G_2)$：$G_2(X) \vdash G_2(!X)$（将线性输出提升为!-版本）
- 复合得证。

$D(G_1 \multimap G_2)$：对偶，需$P(G_1)$（将线性输入升级为!-版本以匹配函数类型）和$D(G_2)$（将!-版本输出降级）。

$Q(G_1 \multimap G_2)$：需证$!(G_1 \multimap G_2) \vdash G_1(!X) \multimap G_2(!X)$。弃置$!(G_1 \multimap G_2)$得$G_1 \multimap G_2$，后续与$P$情形完全相同。因此$Q(G_1 \multimap G_2) = P(G_1 \multimap G_2) = D(G_1) \land P(G_2)$。

$R(G_1 \multimap G_2)$：与$D$情形相同。∎

### 2.5 指数$!$

$$P(!G_1) = Q(G_1)$$
$$D(!G_1) = R(G_1)$$
$$Q(!G_1) = Q(G_1)$$
$$R(!G_1) = R(G_1)$$

**证明**：

$P(!G_1)$：需证$!G_1(X) \vdash !G_1(!X)$。由promotion，只需证$!G_1(X) \vdash G_1(!X)$，即$Q(G_1)$。

$D(!G_1)$：需证$!G_1(!X) \vdash !G_1(X)$。由promotion，只需证$!G_1(!X) \vdash G_1(X)$，即$R(G_1)$。

$Q(!G_1)$：需证$!!G_1(X) \vdash !G_1(!X)$。由promotion，只需证$!!G_1(X) \vdash G_1(!X)$。弃置$!!G_1(X)$得$!G_1(X)$，再用$Q(G_1)$。

$R(!G_1)$：需证$!!G_1(!X) \vdash G_1(X)$。弃置得$!G_1(!X)$，再用$R(G_1)$。∎

## 3. 修正后的一般刻画定理

**定理18（!-分配二分法，修正版）**：对任意多项式函子$F$，分配律$!F(X) \to F(!X)$存在当且仅当$Q(F) = \text{true}$，其中$Q$由上述递归规则计算。

**证明**：对$F$的结构归纳，每一步的构造和不可证性已在第2节给出。∎

### 3.1 关键实例验证

| $F(X)$ | $Q(F)$ | 分配律 | 哲学对应 |
|---------|--------|--------|---------|
| $X$ | ✓ | $!X \to !X$（平凡） | 直接数据 |
| $X \otimes B$ | ✓（命题1） | $!(X \otimes B) \to !X \otimes B$ | 复合数据 |
| $X \& B$ | ✓ | $!(X \& B) \to !X \& B$ | 记录 |
| $!X$ | ✓ | $!!X \to !!X$（平凡） | 已沉积 |
| $X \oplus B$ | ✗（定理17） | 不可证 | 开放未来 |
| $A \multimap (X \otimes B)$ | ✗（定理13） | 不可证 | **生命/交互劳动** |
| $X \multimap B$ | ✓ | $!(X \multimap B) \to !X \multimap B$ | 消费者/销毁过程 |
| $A \multimap !X$ | ✓ | $!(A \multimap !X) \to A \multimap !!X$ | 产出已沉积数据 |
| $(X \multimap B) \otimes C$ | ✓ | 可证 | 含消费者的数据结构 |

### 3.2 直觉

$Q(F)$成立的条件是：$X$在$F$中的每一次出现，要么：
1. 在$!$辖域内（已经是可复制的）
2. 在$\otimes$或$\&$的直接位置（可通过strength访问）
3. 在$\multimap$的**domain**（输入位置，被消耗而非被生产）

$Q(F)$失败当且仅当$X$：
1. 出现在$\multimap$的**codomain**（输出位置，被函数生产出来）——这是"计算"的标志
2. 出现在$\oplus$的分支中（不可预测的选择）——这是"开放"的标志

**核心命题（不变）**：资本（!）可以复制数据结构，但不能复制计算过程和开放未来。

### 3.3 修正的影响

原定理16说"$X$在$G$中出现即阻止$F(X) = A \multimap G(X)$的分配律"，这是**错误的**。反例：$F(X) = X \multimap B$（$X$在domain），分配律存在：
$$!(X \multimap B) \to !X \multimap B$$
证明：弃置得$X \multimap B$，与$!X$（弃置为$X$）求值得$B$。

修正后的定理16说：**只有$X$在codomain中正出现（被生产出来）时才阻止分配律。** 这对哲学解释没有影响——生命$F(X) = A \multimap (X \otimes B)$中$X$在codomain中，定理13和14的结论不变。

## 4. 与极性的关系

$P$和$D$的递归定义精确对应线性逻辑中的**极性**（polarity）概念：

- $P(G)$成立$\iff$ $X$在$G$中**负出现**（在domain中或在!下）
- $D(G)$成立$\iff$ $X$在$G$中**正出现**（在codomain中或顶层）

这与归纳类型的**严格正性条件**形成对偶：
- 严格正性（归纳$\mu$）：$X$不能出现在$\to$的**domain**中（否则非良基）
- !-分配（资本化）：$X$不能出现在$\multimap$的**codomain**中（否则不可复制）

**阴（归纳/沉积）禁止X作为输入；阳（!-分配/资本化）禁止X作为输出。** 这个对偶仍然成立。

## 5. 与量子不可克隆/不可编程定理的关系（修正）

| 线性逻辑判断 | 量子对应 | 定理 |
|-------------|---------|------|
| $P(X) = \text{false}$：$X \not\vdash !X$ | 未知量子态不可克隆 | 不可克隆定理（T009）（1982） |
| $Q(A \multimap (X \otimes B)) = \text{false}$ | 量子过程不可编程 | 不可编程定理（Nielsen-Chuang 1997） |
| $Q(X \oplus B) = \text{false}$ | 量子叠加不可复制为经典选择 | 不可广播定理（1996）的推论 |
| $Q(X \multimap B) = \text{true}$ | 量子测量/销毁过程可以经典化 | 测量是经典操作 |
| $Q(A \multimap !X) = \text{true}$ | 产出经典数据的量子过程可以复制 | 经典输出的量子电路可模拟 |

我们的二分法定理将量子信息中的三个独立no-go定理（不可克隆、不可编程、不可广播）统一为同一个递归判断$Q(F)$的不同子句。
