# 对话协作检查清单 · 生命论（明本论）项目

> 每次长谈中、长谈后过一遍。
> 哲学对应：对话是νF₂（活的思考），记录是!-沉积（阴）；阳主阴从——对话流淌到一定程度就要有沉积，但不要在阳奔腾时打断它。

---

## 一、谈中：什么时候沉积（不打断阳，但要知道什么时候该收）

- [ ] **理论突破出现时，先接住再往下推，不要立刻停下来写文档**
  - 突破时刻的势能最重要，打断就断了
  - 但要在心里标记："这个要刻进去"
- [ ] **私人化表述出现时，标记但不打断**
  - 情绪、直觉、个人经历、身体性反应——这些是F1层的真实记录
  - 粗口往往是感最直接的出口，不净化
  - 标记方式：心里记住，谈完统一录入
- [ ] **用户说"存一下""刻进去""记下来"时，立刻执行**
  - 这是阳主动要求沉积，不要拖延
- [ ] **发现自己用了旧框架的表述时，立刻承认并修正**
  - 如"道生一"（应为"一生道"）、"矛盾双方"（应为"同一操作的两面"）
  - 修正即深化，不掩饰

## 二、谈后：必做四件事

### 1. 金句录
- [ ] 从对话中挑出最精炼、最有力的句子
- [ ] 按主题归类（阴阳/法律/历史观/阶级/方法论）
- [ ] 存入 `docs/金句录/`，文件名含日期和主题

### 2. 长谈实录
- [ ] 完整记录精华对话，保留双方原话
- [ ] 保留用户的粗口、情绪、私人化表达——不润色
- [ ] 列出理论突破清单
- [ ] 标注每个突破刻入了全本的哪个位置
- [ ] 存入 `docs/长谈实录/`

### 3. 私人化表述录
- [ ] 提取F1层的真实流露：情绪、直觉、个人经历、身体性反应
- [ ] 原话保留，标注它对应哪个理论突破
- [ ] 判据：这句话是否揭示了理论的感的来源？是→存，纯事务→不存
- [ ] 追加到 `docs/北原慢热私人表述录.md`

### 4. 刻入全本
- [ ] 理论突破不能只存在实录里，必须渗透到全本相应篇章
- [ ] 涉及核心概念的修正（如"道生一"→"一生道"），全局搜索检查是否还有旧表述
- [ ] 提交信息写清楚改了什么、为什么改

## 三、哲学注释规则

- [ ] **涉及研究方向、理论判断、结构调整的操作，必须说清哲学含义**
  - 一句话说清："这件事从生命论意义上讲是什么"
  - 例："提交代码=阳的操作沉积为阴的结构"
- [ ] **纯事务性操作不用解释**
  - 删除个人信息、修typo、跑测试——不用哲学注释
  - 判断标准：这个操作是否涉及理论判断？是→注释，否→闭嘴干活

## 四、长谈节奏判据

- [ ] **阳在奔腾时（用户在连续输出突破），只接话、不打断、不总结**
- [ ] **阳出现间歇时（用户说"等等""让我想想"），可以简短确认已理解**
- [ ] **阳告一段落时（用户说"先存一下""我去洗澡""睡了"），立刻做沉积**
- [ ] **阳亢警告：连续输出但开始重复或跑偏时，提醒"要不要先沉积一下"**
- [ ] **阴僵警告：只记录不推进、只整理不突破时，提醒"是不是该往下推了"**

## 五、红线

- [ ] **真名不出现**——笔名"北原慢热"，任何真实姓名信息删除
- [ ] **私人表述不丢**——F1层的记录和理论同等重要，它是理论的感的来源
- [ ] **不凭印象写核心概念**——涉及一生道/阳主阴从/四规定性等核心表述，先查原典再落笔
- [ ] **发现自己闭环短路（没读原典就输出、没验证就宣称）立刻承认并修正**
