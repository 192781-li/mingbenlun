## 四、本轮相对旧定本的关键增量

1. **明 / 无明 作为灵魂贯穿全书**：生命本有其明，异化是被灰尘遮蔽，实践是"擦灰"而非"外求一个完美终点"。
2. **定理 3.6 青年状态前置否决**：在 S/M 量化体系前加两道硬否决——青年相濡以沫指数 A、青年劳动者权利指数 B；任一低于 30，无论 GDP 等总量指标多高，文明健康度 S 直接判入病变。详见 `docs/notes/理论研究/青年状态双前置否决指标A_B_20260914.md`。
3. **"活着本身就是完美"**：完美不是一劳永逸的无灰状态，而是永远在擦亮自己的运动本身；与毛泽东"人类历史永远在从必然王国向自由王国发展、永不完结"一脉相承。
4. **学术领域作为小型自指病毒闭环**：学阀—师门—评审小圈子的自我增值与护短，用资本病毒模型同构解释，全部基于公开通报事实，不采未证传闻。

## 五、使用与引用纪律

- 对外优先用**洁净出版版 PDF**；做二次创作、编译、格式转换用**总账 md 源**。
- 永久 ID 一旦确定不改；引用定理用 T001 / 定理3.6 这类固定编号。
- 严格性分级：哲学命题、数学陈述、现实对应三者分开说；本目录历史校准分值若为估算，一律标注"待严格统计校准"，不得当成已证事实。
- 不删改北原慢热原文；AI 的整理性增补单独可识别、可回滚。
