## 一、从体制内到体制外：一个财政官员的觉醒

### 1.1 出身与学历

卢麒元，原名卢欣，字麒元。祖籍四川，生于山西，就读于东北，工作于北京，现居香港。

1987年，卢麒元从东北财经大学财政学毕业。这一年，他22岁，进入了财政部文教司。

这是一个典型的"体制内起点"——财政学专业，财政部工作，根正苗红。如果沿着这条路走下去，他可能成为一个体制内的财政官员，平稳地晋升，安稳地退休。

但他没有。

### 1.2 财政部五年：亲历转型的现场

1987-1992年，卢麒元在财政部文教司工作。

这五年，正是中国从计划经济向市场经济转型的关键时期。财政改革是整个转型的核心——怎么收税、怎么花钱、怎么分配、怎么处理中央和地方的关系。

卢麒元在这个核心现场，亲历了一切。他看到了：
- 财政体制怎么一步步从"统收统支"变成"分灶吃饭"
- 税制怎么一步步从"以利代税"变成"以税代利"
- 中央和地方的财政关系怎么一步步调整
- 财政资金怎么一步步从"按计划分配"变成"按市场分配"

更重要的是，他看到了**这些改革背后的人**——谁在推动改革，谁在改革中获利，谁在改革中受损。

这五年的体制内经历，给了他两样东西：
1. **内部视角**——他知道财政系统内部怎么看问题，知道内部数据，知道问题出在哪
2. **幻灭感**——他看到了改革的真相，看到了谁在获利、谁在受损，看到了"改革"名义下的剥削和掠夺

这两样东西，决定了他后来的道路。

### 1.3 南巡之后：转战金融

1992年，邓小平南巡，中国进入了新一轮的改革开放高潮。

就在这一年，卢麒元离开了财政部，进入了中国经济开发信托投资公司（中经开）。

这是一个关键的转向——从体制内的财政官员，变成了资本市场的从业者。

为什么做这个选择？可能是因为他看到了：
- 财政改革已经走到了尽头，真正的权力已经转移到了资本市场
- 要理解中国经济的真相，必须深入资本市场
- 要为人民战斗，必须懂资本的逻辑，才能找到资本的命门

在中经开之后，他又去了香港华财集团（1995年起任董事总经理），然后是香港沃德国际资产管理顾问公司（至今任董事局主席）。

这条路：财政部 → 中经开 → 香港华财 → 香港沃德，是典型的"体制内 → 市场 → 体制外"路径。

但和大多数走这条路的人不同——大多数人走这条路是为了赚钱、为了成为精英、为了加入既得利益集团——卢麒元走这条路，是为了**理解资本、找到资本的命门、为人民战斗**。

### 1.4 1999年：两篇文章暴露了他的立场

1999年，卢麒元写了两篇重要文章：
- 《香港的超级地租》
- 《回到一九八三年》

在《香港的超级地租》中，他分析了1994年分税制如何制造了超级地租——少数人通过地租剥削多数人。

在《回到一九八三年》中，他分析了1995年联系汇率如何制造了金融新贵——少数人通过金融手段掠夺多数人。

这两篇文章，已经暴露了他的立场：
- 他不是在为资本说话，是在为被剥削的人民说话
- 他不是在赞美改革，是在揭露改革名义下的剥削
- 他不是在为既得利益集团服务，是在为人民战斗

这一年，他34岁。从这一年开始，他的道路已经清晰了——他将用自己的学识，为人民战斗，为反修防修战斗。

## 二、斗士的武器：直接税、人民宪政、反官僚垄断资本主义

### 2.1 直接税：向资本开刀

卢麒元最广为人知的主张，就是直接税改革。

他喊了很多年：房产税、遗产税、赠予税、离境税、资本利得税，组合拳。

为什么这么执着于直接税？因为他看到了：
- 中国税制偏重间接税，最终转嫁给普通百姓
- 资本增值存量资产税收缺位
- 劳动重税资本轻税：月薪两万个税45% vs 炒股赚两亿资本利得20% vs 囤房翻三倍零税

这不是简单的"税制优化"，这是**阶级立场**——直接税是向资本开刀，是让资本为它的剥削付出代价，是遏制资产阶级法权的核心工具。

2013年12月30日，他发表了《广义税赋论》，深刻阐述税赋与国家政权之间的关系。他说："自古以来，税赋就是国家政权的核心。"

在南南论坛的演讲中，他把税政改革称为"不流血的革命"——好的税政是好的军政和民政的前提。

直接税，是他向资本开出的第一刀。

### 2.2 人民宪政：把主权拿回到人民手里

如果说直接税是"术"，那么人民宪政就是"道"——是他整个思想体系的核心。

2022年，他发表了《社会主义十问》，系统阐述了人民民主宪政的完整框架。

核心结构：**主权与治权分离**。
- 人民主权（立法权+财产权）——人民直接持有，绝对不能代为行使
- 人民治权（司法权+行政权）——人民授权执政组织行使，受人民监督、管理、弹劾

为什么必须这样？因为他看到了一个铁律：
> "任何组织并不天然拥有人民性，执政组织更不可能永葆人民性。曾经拥有人民性的组织，一旦拥有资产阶级法权，必然会逐渐地丧失人民性，这是不以人的意志为转移的客观规律。"

这就是他对"执政组织异化"的深刻洞察——执政组织掌握了主权（立法权+财产权），就一定会被资产阶级法权腐蚀，一定会丧失人民性，一定会变成精英专政，一定会导致资本主义复辟。

怎么解决？**把主权直接拿回到人民手里**——执政组织只行使治权（司法+行政），不行使主权（立法+财产）。这样，执政组织就没有资产阶级法权可以掌握，就不会被腐蚀。

这就是人民宪政的核心逻辑。

他还明确指出：
- 人民民主专政是革命时期的临时性措施，社会转型完成后必须用宪政代替专政
- 毛泽东做了两件事：人民民主专政（成功）、人民民主宪政（未成功）
- 文革是用和平方式实现执政组织人民性再造的尝试，但缺乏理论和组织准备，走向了无政府主义
- 现在，完成毛泽东未竟的第二件事，建立人民民主宪政，是新社会主义者的历史使命

人民宪政，是他为防止资本主义复辟开出的根本药方。

### 2.3 反官僚垄断资本主义：点破国家机器的阶级属性

2023年，卢麒元在抖音视频中明确提出了"官僚垄断资本主义"的概念。

他说：
> "中国出现了官僚垄断资本主义这个问题在全世界早有表演，但是作为一种历史的必然它还是发生了。我们现在可以给官僚垄断资本主义一个基本的定义，实际上是体制内官僚阶层利用中国宪法赋予他的特殊的权利，它包括政治权利、经济权利和文化权利，完成了个人或者是以个人为主体的集团对执政党主权，执政党是代人民持有的主权的僭越和私有化。"

这个判断，直接点破了国家机器的阶级属性：
- 不再是"为人民服务"的执政组织
- 是官僚阶层僭越和私有化了人民主权
- 国家机器已经变成了官僚垄断资产阶级的工具

他还指出：
- 中国政治主权相当一部分被官僚垄断资产阶级僭越和控制，包括立法权、司法权和行政权
- 执政精英本身无害，但持有资产阶级法权后立刻异化为社会公害
- 建议通过集约化和数字化解决中国政治主权问题

这个判断，比"直接税"和"人民宪政"更尖锐——它直接点破了"现在的国家机器是什么"这个最敏感的问题。

这也是他被封禁的重要原因——点破了官僚垄断资本主义，就等于点破了既得利益集团的本质，就等于向整个官僚垄断资产阶级宣战。

反官僚垄断资本主义，是他向既得利益集团开出的最狠一刀。

### 2.4 经济主权：守住人民的钱袋子

卢麒元的另一个核心主张，是经济主权。

他把经济主权分为三个部分：
- 财政主权：核心是立法权，财政立法权基本上就是一个国家宪政的水平
- 金融主权：人民币发行权、铸币权
- 要素主权：自然资源、公共设施、战略性资产

他最执着的，是人民币发行权。他说：
> "人民币发行权，是共和国的立法权，也是共和国的核心主权，更是中华民族和中国人民的共同主权。同时，人民币发行权，也是共和国的生存权和发展权。"

他指出：
- 1995年汇改迫于现实无奈放弃了部分主权
- 现在必须坚决收回
- 我国确实需要一场关于人民币发行立法的全民大讨论

他还反资本外逃：
- 比特币是中国资本外逃的工具
- 2.5万亿美元借给美国救助美国，是对人民财富的掠夺
- 外汇储备结构必须调整，减少美债，收购实物战略资产

经济主权，是他为守住人民的钱袋子开出的防线。

## 四、思想体系：道法术器中的"法"

### 4.1 在人民解放事业中的位置

卢麒元的思想，在道法术器框架中，属于"法"的层面。

- **道**（哲学/存在论/根本真理）：生命论——为什么运行权必须在人民手里
- **法**（制度设计/法律/政治经济学）：卢麒元——具体怎么用制度保障人民主权
- **术**（实践方法/操作层面）：温铁军——具体怎么操作、怎么落地
- **器**（工具/技术/具体手段）：崔永元——用什么工具战斗

卢麒元的"法"，是连接"道"和"术"的关键——没有"法"，"道"就是空的哲学，"术"就是零碎的操作。

他的核心贡献，就是把"人民必须掌握运行权"这个哲学真理，转化成了"人民主权+人民治权分离"的制度设计，转化成了"直接税+人民宪政+反官僚垄断资本主义"的具体主张。

### 4.2 核心思想的十个维度

1. **人民宪政**——主权与治权分离，人民直接掌握立法权+财产权，执政组织只行使司法+行政
2. **直接税**——房产税+遗产税+赠予税+离境税+资本利得税，向资本开刀，遏制资产阶级法权
3. **反官僚垄断资本主义**——点破国家机器的阶级属性，官僚阶层僭越和私有化了人民主权
4. **经济主权**——财政主权+金融主权+要素主权，收回人民币发行权，反资本外逃
5. **反超级地租**——揭露1994年分税制制造的超级地租，反房地产剥削
6. **500年殖民历史三阶段论**——古典殖民→现代殖民→新殖民，解构当代殖民体系
7. **三农问题新解**——三农应分开，2.9亿农民工既不属城也不属乡，后毛泽东时代积累方式更狠
8. **新社会主义**——人民直接享有政治主权+经济主权，社会主义本质是人民民主宪政
9. **左翼使命**——发起思想解放运动、再造执政组织人民性、建立人民民主宪政，和平方式
10. **执政组织人民性再造**——思想+组织+制度三个维度，剥夺执政组织的资产阶级法权，归还人民主权

这十个维度，构成了一个完整的制度设计体系——从根本制度（人民宪政）到具体政策（直接税），从国内问题（官僚垄断资本主义、超级地租、三农）到国际视野（殖民三阶段论），从理论（新社会主义）到实践（左翼使命、人民性再造）。

### 4.3 与生命论的深度互补

生命论和卢麒元的思想，是同一个真理的两个层面：

| 生命论（道） | 卢麒元（法） |
|------------|------------|
| 运行权必须在生命主体手里 | 人民主权必须在人民手里 |
| 任何系统垄断运行权就一定会异化 | 执政组织掌握资产阶级法权就一定会丧失人民性 |
| 自指正向运行=生命自己掌握运行权 | 人民民主宪政=人民自己掌握主权 |
| 反自指六阶段 | 人民民主专政→精英代主→精英专政→资本主义复辟 |
| 明性=生命主体自己感受判断操作 | 人民直接立法=人民自己感受判断操作公共事务 |
| 反生命=为生存而生存 | 资产阶级法权=执政组织被资本腐蚀为资本增殖服务 |
| 量论=衡量生命意义量 | 直接税=衡量并调节资本对劳动的剥削程度 |
| 两个世界理论 | 500年殖民三阶段论 |

一个回答"为什么必须这样"，一个回答"具体怎么做到"。

合在一起，就是完整的人民解放、反修防修的理论体系。
