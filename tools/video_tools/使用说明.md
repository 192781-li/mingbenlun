# 视频文案提取工具 · 使用说明

> 所有分站通用。一条命令提取抖音/B站视频的完整文案。

## 快速开始

```bash
cd /path/to/mingbenlun
python3 tools/video_tools/video_transcriber.py "视频链接"
```

输出文件在 `./video_output/` 目录下，包含：
- 带时间轴版本（每句话标注起止时间）
- 纯文本版本（适合阅读/引用）

## 支持平台

| 平台 | URL格式 | 提取方式 | 耗时 |
|---|---|---|---|
| 抖音 | `v.douyin.com/xxx` 或 `www.douyin.com/video/xxx` | 先搜B站CC字幕→无则下载转写 | 几秒~2分钟 |
| B站 | `bilibili.com/video/BVxxx` 或 `b23.tv/xxx` | 优先CC字幕→无则需手动 | 几秒 |

## 智能优先级

抖音视频会自动走以下优先级：

1. **B站搜索**：用视频描述在B站搜相同视频，找到且有CC字幕→直接提取（几秒）
2. **下载转写**：B站没有→下载抖音视频→提取音频→faster-whisper转写（几分钟）

这意味着：**大部分从B站搬运到抖音的视频，几秒就能出文案，不用下载转写。**

## 依赖

首次运行会自动安装：
- `faster-whisper`（语音转写）
- `opencc-python-reimplemented`（繁体转简体）
- `playwright`（抖音页面解析，需系统有chromium）

系统依赖：
- `ffmpeg`（音频提取）
- `chromium`（playwright用，云电脑已装在 `/usr/local/bin/chromium`）

## 注意事项

1. **抖音视频通常没有公开字幕**，必须走下载+whisper转写，7分钟视频约需2分钟
2. **whisper模型默认small**，平衡速度和准确率。需要更高准确率可改脚本顶部 `WHISPER_MODEL = "medium"`
3. **人名可能识别有误**（如"燕妮"识别成"烟雾"），上下文可推断
4. **B站CC字幕**是UP主上传的字幕，质量通常比whisper高
5. **云电脑IP可能被B站限制**，如搜索失败会自动降级到下载转写
