# 视频文案提取工具 · 使用说明 v2.0

> 所有分站通用。一条命令提取抖音/B站视频的完整文案。
> v2.0：融合原 bilibili_transcriber.py，B站无字幕时支持yt-dlp下载转写，支持批量处理。

## 快速开始

```bash
cd /path/to/mingbenlun
python3 tools/video_tools/video_transcriber.py "视频链接或BV号"
```

输出文件在 `./output/` 目录下，每个视频生成三个文件：
- `BV号_标题.txt` — 纯文本（适合阅读/引用）
- `BV号_标题_时间戳.txt` — 带时间戳（每句话标注起止时间）
- `BV号_标题.json` — 结构化数据（含segments数组）

## 支持平台

| 平台 | URL格式 | 提取方式 | 耗时 |
|---|---|---|---|
| B站 | `bilibili.com/video/BVxxx` / `b23.tv/xxx` / 直接BV号 | 优先CC字幕→无则yt-dlp下载+whisper转写 | 几秒~几分钟 |
| 抖音 | `v.douyin.com/xxx` / `www.douyin.com/video/xxx` | 先搜B站CC字幕→无则下载转写 | 几秒~2分钟 |

## 智能优先级

### B站视频
1. **CC字幕**：有UP主上传的字幕→直接提取（几秒）
2. **yt-dlp下载转写**：无CC字幕→下载音频→faster-whisper转写（几分钟）

### 抖音视频
1. **B站搜索**：用视频描述在B站搜相同视频，有CC字幕→直接提取（几秒）
2. **下载转写**：B站没有→下载抖音视频→提取音频→whisper转写（几分钟）

## 命令行参数

```bash
# 单个视频
python3 video_transcriber.py "https://www.bilibili.com/video/BV1xx411c7mD"

# 直接用BV号
python3 video_transcriber.py BV1xx411c7mD

# 批量处理（文件中每行一个URL）
python3 video_transcriber.py --batch urls.txt

# 指定输出目录
python3 video_transcriber.py "URL" --output my_videos

# 只提取CC字幕，无字幕则跳过（不下载转写）
python3 video_transcriber.py "URL" --subtitles-only

# 选择whisper模型（tiny/base/small/medium/large，默认small）
python3 video_transcriber.py "URL" --model medium
```

## 依赖

首次运行会自动安装：
- `requests`（HTTP请求）
- `faster-whisper`（语音转写）
- `opencc-python-reimplemented`（繁体转简体）
- `playwright`（抖音页面解析，需系统有chromium）

系统依赖：
- `ffmpeg`（音频提取）
- `yt-dlp`（B站音频下载，`pip install yt-dlp`）
- `chromium`（playwright用，云电脑已装在 `/usr/local/bin/chromium`）

## 注意事项

1. **B站CC字幕**是UP主上传的字幕，质量通常比whisper高
2. **whisper模型默认small**，平衡速度和准确率。需要更高准确率用 `--model medium`
3. **人名可能识别有误**（如"燕妮"识别成"烟雾"），上下文可推断
4. **抖音视频通常没有公开字幕**，必须走下载+whisper转写
5. **yt-dlp下载B站音频**需要网络通畅，如失败可手动下载后用whisper转写
6. **所有输出自动繁体转简体**（opencc）
