## 第一遍：库里理解——骨架与核心命题

### 道论在做什么

对老子"道生一，一生二，二生三，三生万物"做存在论修正：

| | 序列 | 起点性质 |
|---|---|---|
| 老子 | 道（无）→一→二→三→万物 | 道=先在实体（无） |
| 生命论 | **一（在感）→道（运转方式）→二（阴阳两面）→万物（直接展开，无三）** | 一=践演事实（非实体） |

### 三个核心命题

1. **一生道**："生"这件事本身从一开始。一=在活着/在感（践演事实，非实体）；在感一旦发生，就有消耗-产生、发用-凭依、阳-阴这套运转方式=道。道不是在感之前的本源，是在感自身的运转方式。"一生道"不是先后关系——"先后/关系/同一"都是在感之后才有的逻辑工具，不能拿感之后的尺子量感本身（"用尺子量尺子"）。
2. **道养一**：道不是一的主人，是一的运转方式。一靠自己的运转方式维持自己（呼吸维持身体、身体维持呼吸的自指循环）。"无为"=不妄为、不逆递归强为；"上善若水"=弱的东西在正确递归结构中反复迭代可以穿石。
3. **一指万物**：不是"展开为万物"（宇宙生成论），是"指向万物"（存在论）。感有意向性、总感着什么；万物在感中显现——**感点亮万物，不是感创造万物**。

### 关键结构

- 阴阳是同一操作的两个面向（阳=发用面/动，阴=凭依面/静/体），不是两个实体，因此不需要"第三物"交合，故**无三**。健康=阳主阴从，异化=阴主阳从。
- 旧形而上学（老子的道 / 黑格尔绝对精神 / 旧唯物物质）都把本源设为**先在实体**，陷入"实体从哪来"的无限滚动；生命论起点"在感"不是实体、是践演事实——怀疑它本身就在感，故无需怀疑、无需"它从哪来"的论证。

## 第二遍：关联映射——新的概念连接

### 1. "一生道"是立宗第一命题的存在论原版
立宗（20260912）说"一元论超越旧一元/二元，一是活操作本身"；道论的"一"=在感（践演事实、非实体），正是立宗那个"活操作"。两处的"一"是同一个：不是名词性本原（道/物质/精神/绝对），是活的践演事实。

### 2. "一→道→二"= 立宗"内含阴阳的活一"的展开
立宗："操作天然含阴阳，所以是内含阴阳的活一"；道论把它展开为 一（在感）→道（运转方式）→二（阴阳两面）。道=一的运转方式，二=一的两面，不是三个东西，是同一活操作的三个表述层。这解释了为什么归根是"一元"而非"二元"——二（阴阳）从来是一的面向，不是两个实体。

### 3. "道养一"= "操作维持操作者"的自指结构
卷二第一命题"不是谁在操作，是操作维持着操作者（操作者在操作中生成）"；"道养一"是其道论表达：一靠自己的运转方式维持自己，即自指闭包 S=f(S)。

### 4. "一指万物·存在论非宇宙论"= 方法论"描述而非创造"的存在论根基
方法论总纲："本源不是我创造的，是我描述的"；道论："感点亮万物，不是感创造万物"。同构：感（一）不是造物主，是万物显现/可理解的条件；正如理论家不创造本源、只描述本源。这是"描述而非创造"在宇宙观层面的对应。

### 5. "无三"从存在论上解释了立宗为何"超越旧二元论"
老子需要"三"作中介让两个实体（阴阳）结合——这正是旧二元论的困境：两外在对立实体需要第三方搭桥。生命论因阴阳本是一的两面，不需三。**旧二元论需中介弥合对立，操作一元论里对立本是同一操作的内部环节，无中介。**

### 6. 1.6对比表 = 黑格尔批判的存在论版
表中黑格尔"绝对精神自我展开"= 用户所批"名词性本原展开自己→你什么也不是"；生命论"一的感指向万物"= 用户"从操作出发"。与 PR#76 黑格尔批判、立宗"避免五症结"直接协奏。

### ★ 新连接：个体存在论序列与社会解放论同构

| 个体存在论（道论） | 社会解放论（生命论） |
|---|---|
| 一（在感/活操作） | 人民作为活的操作主体（立宗一元） |
| 道（阴阳运转机制） | 组织方式/操作机制（四步推演的机制） |
| 二（阴阳相扶） | 阳主阴从、阴阳相扶（推演第4步） |
| 万物（操作直接展开） | 人民在共同事务中实际操作=掌权=解放 |

并且"道养一"与毛"最大的权利是管理国家"同构：一靠自己的运转维持自己 = 人民靠自己的操作管理自己的上层建筑，不靠外部救世主/恩赐（管理权而非被动享受福利）。

## 第三遍：深度补全——缺口与待深化问题

### 缺口
- **缺口1（道与二的关系）**：道是"运转方式"，二是"阴阳两面"，二者几乎是同一件事（道就是阴阳的运转）。那"一→道→二"为何要分两步？如何区分"道"与"二"而不重蹈老子"三"那种多余中介？
- **缺口2（意向性与F层级）**："一指万物"的"指"（意向性）属 F1（在感的指向）还是已进入 F2（感应、指向他者）？"万物"含他者，"指"是否已是 F2 雏形？这可能正是澄清"人称面相↔F1/F2/F3对应"（立宗遗留问题）的钥匙。
- **缺口3（道的异化）**："道养一"讲了健康态，但"道"一旦沉积僵化、反过来骑到一头上（"道役一"/阴夺阳位）怎么办？这与拟写的结晶028（反异化机制自身可被异化）是同一类问题，出口可补。

### 待深化问题清单
1. "道"与"二（阴阳）"的区分如何不成为多余中介？
2. "一指万物"的意向性属 F1 还是已涉 F2？能否据此打通人称-F对应？
3. "道"自身僵化（道役一）的机制与出口，与结晶028如何协奏？
4. "一生道"序列↔"人民操作→管理权→阴阳相扶→解放"的正式对应表能否立为稳定文件？

### α=f³ 深度补全：活一的三动作「立—持—开」

> **"一"的三层保持，正是一个活操作自指闭包的三个动作：**
> - **一生道 = 自我立**："生"从一开始，不待外部本原；
> - **道养一 = 自我持**：以自己的运转方式维持自己，不靠外力；
> - **一指万物 = 自我开**：向世界显现、指向他者，而非封闭自守。
>
> **立—持—开三合，才是"活一"的完整定义。** 它对立于实体本原——实体只是"被摆在那里"，没有立/持/开的动作。
>
> 这个结构在个体是存在论，放大到社会就是人民的 **自我组织（立）→ 自我管理（持·管理权）→ 自我解放（开）**。由此，立宗第一命题、道论、毛"管理权最大"、解放论被同一个"活一·立持开"结构整齐协奏。

**本次深读的真正增量**：把道论从"对老子的修正"提升为"活一的操作结构（立—持—开）"，并打通个体存在论与社会解放论；同时为立宗遗留的"人称↔F层级"问题找到可能的入口（意向性=自我开=F1向F2的过渡）。
