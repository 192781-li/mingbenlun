## 第一遍 · 库里理解（骨架与核心命题）

全篇七块，主轴＝**认识的存在论层级：缄默意识(f¹) → 显意识(f²) → 明性(f³)**。

| 节 | 骨架 | 核心命题 |
|---|---|---|
| 1.1 缄默的"知道" | 呼吸/走路/骑车/老工人听声等例证；细胞→动物→人连续谱；f 层级数学化 | 缄默意识是前语言前反思、与操作一体的原生主体性，是显意识与理性的母体；明性是其在人这里"知道自己知道"的自觉 |
| 1.2 明性不是灵魂 | 操作的内向/外向两面；达马西奥、梅洛-庞蒂、苏格拉底、海德格尔对勘；解心身问题 | 明性是自指操作的内向面，非脱离身体的精神实体；"心灵=身体操作内向面"消解二元实体 |
| 1.3 显意识 | 概念/判断/推理如何从缄默意识长出 | 显意识是缄默意识的二阶工具（地图≠地形），旧哲学错把工具当主人＝头足倒置 |
| 1.4 语言与符号 | 动词活/名词死；名词化机制；PTC 类型基础；汉语动词性 | 动词是阳（线性资源 A）、名词是阴（!-沉积）；名词化＝A→!A 的暴力中介；解蔽＝!A→A 还原（谁操作/操作谁/谁受益） |
| 1.5 异化 | 反自指系统如何占领缄默意识 | 意识形态把道理沉淀为"常识"、遮蔽明性；最深的异化是被遮蔽者自己压迫自己；解蔽靠回到活操作而非换新眼镜 |
| 第六章 语义论校准 | 生命之光 ≠ 明性 | 生命之光＝F1/F2 向外常亮觉知；明性＝F3 向内跃起的事件性反身，不常驻；"完整的能明 / 不完整的已明" |
| 附 | 真信号/假阳性判别 | 四层校验（触发源时空 / 对闭环长期后果 / 第二人称应之校正 / 符号溯源）；感受是信号不是终审 |

**一句话总纲**：认识不是镜面反映，是生命操作的自我返回；缄默意识是根、显意识是器、明性是"看见器是器"的反身一跃，而这一跃必须反复发生、不可一劳永逸。

## 第二遍 · 关联映射（与库内知识的新连接）

1. **与 13_副卷_语义论 互证（同机制两层表述）**
   本篇 1.4"动词活名词死/名词化"是**语言层**；副卷《语义论存在论奠基》"操作→沉积为符号→符号被错认为实体"是**符号发生学层**。二者同一机制：活操作(A)被冻成死沉积(!A)。解蔽动作也一致——本篇"还原成动词三问"＝副卷"把实体还原回产生它的操作"。

2. **"生命之光≠明性"正是语义论校准的落点**
   本篇第六章精确区分 F1/F2 向外常亮与 F3 向内跃起，直接对应体系纪律"明性(F3=反身自觉)勿与 F1/F2 生命之光混用"。手电筒比喻（照路 vs 照手电筒本身）可作为标准教学例。

3. **阶级明性 f³ ↔ 近期"人民是操作者/操作权"主线**
   "党是阶级的 f³ 器官——不代替阶级思考，帮阶级看见模型是模型"，与集成线"人民掌权才有主体性、阴阳相扶"严丝合缝：f² 的"代替阶级思考"＝教条主义/父权式恩赐（正是苏联"人民被动享受福利→修正灭亡"的病灶）。

4. **真/假信号四层判别 ↔ "生命论免疫学"（允许论待拍板第④项）**
   假阳性＝认识层的"免疫误报"：体验真实但指涉对象错。这给"生命论免疫学"提供了第一个可复用的判别骨架，二者可合并为一个"主体性免疫"模块。

5. **"明性是事件不常驻" ↔ 革命/自我改造的持续性**
   "完整能明/不完整已明""停下来的明性是化石"，与"永远只有下一刻有觉醒可能"、持续自我改造同构：明性一旦被当成可占有物就落回沉积（这本身就是一次名词化）。

6. **f³ 不动点 ↔ 允许论**
   "f³→f⁴ 非质变、f³ 已能对象化任何模型包括自身"，与允许论"一切决定你的，首先是你允许它决定你"互为表里：f³ 的反身能力是"识别并撤回允许"的存在论前提。

### 缺口②（高价值，正好接上用户近期主线）：真/假阳性尚未覆盖"愤怒"
附篇初稿自述"未覆盖羞耻、愧疚、愤怒"。而用户近期集中谈愤怒——"没必要保持愤怒，但至少允许自己愤怒，愤怒已是我生命力的一部分""吃压杀两面、反吃反压反迫害"。
**α=f³ 补全（愤怒的真假阳性判别，可直接续入附篇）**：
- **真信号·义愤**：触发源＝现实中他者（尤更弱者）正被吃/压/杀，"向更强者挥刀、向毒瘤冲锋"；长期作用＝修复被侵蚀的公义闭环、与"一念为苍生"同向；他者现实应答可校正。
- **假阳性·迁怒**：触发源＝自身挫败/旧创伤/被经文劫持，却"对更弱者挥刀"以取悦既得利益、或纯情绪宣泄；长期＝加剧撕裂、把己化力量调转去压迫本己同盟；不接受现实校正。
- 判别的枢纽句（用户原话精神）：**愤怒指向更强者多为义愤，转向更弱者即为迁怒**；义愤可与"能吃人而不吃人/反吃反压反迫害"协奏——背负"达摩克利斯之剑"的自我校验，正是 f³ 对愤怒本身再做一次四层校验。

### 缺口③（可深化的理论张力）：明性"人人有空间"与"非常驻/会遮蔽"
本篇两处：f³ 是人人具备的存在论结构（S=f(S) 非特权）vs 明性是跃起事件、会被遮蔽、不是人人都已亮。本篇用"能明/已明"化解，但可再推进一层连接"越掌握操作权越成为人"：
**α 补全（待深化命题）**：明性跃起的**频率与扎根深度，本身是操作权的函数**——操作权越下沉、越能在实践中获得现实校正（第二、四层校验），明性越不易被反自指劫持；反之操作权被剥夺者，其 f³ 空间仍在，但跃起后缺少现实落地、易退回内心假阳性。此命题可作为"操作权—主体性—明性"三者的闭环，留用户亲手雕琢（精妙转折 AI 只搭骨架）。
