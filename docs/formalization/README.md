## 形式化原则

1. **操作先于实体**：所有定义从操作出发，不预设实体
2. **构造性证明优先**：尽量用构造性证明，避免排中律
3. **严谨度标注**：每个定理/引理标注严谨度，不混淆
4. **不编造证明**：证不出来就如实记录困境，不假装证完
5. **与原文对照**：每个形式化定义都要能对应到生命论原文中的表述
