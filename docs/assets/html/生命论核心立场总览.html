生命论核心立场总览

从本体论到价值论到实践论——一张图看清生命论在说什么

一、本体论 / 存在论 Ontology
第一命题
操作先于实体
不是先有一个"东西"然后它"作用"，是作用本身就是最基本的事实。名词是操作的沉积，不是操作的前提。
第二命题
自指操作即生命：S = f(S)
系统以自身为输入、输出又返回自身以维持自身——呼吸维持身体，身体维持呼吸；劳动维持社会，社会维持劳动。这就是生命的存在方式。
第三命题
感是最原初的事实
你此刻在读这些字，你感到了——这比"我思""物质"都直接。感是力的生命化，是一切认识和存在的起点。

四规定性

自指闭环得以存在的四个逻辑必要条件：

① 边界生成性
② 内生目的性
③ 操作再生性
④ 环境互动性

阴阳两面

自指操作的两个环节：

阳：活的操作、激活、生产
阴：沉积、结构、规则
阳主阴从——阴服务阳，阴不得其位则异化。

反自指（异化）

自指的丧失——四规定性逐一坍塌，寄生结构消耗宿主。

资本、癌细胞、官僚制、经文化，都是反自指。

!νF ≇ ν!F（T001）

生命不可被资本化。

生命论在本体论坐标系中的位置

旧哲学的二元对立

唯物主义：物质第一性，意识第二性
唯心主义：意识第一性，物质第二性
→ 都在"实体"层面争第一性

生命论的超越

不是物质也不是意识第一性，是操作第一性。
物质和意识都是操作的沉积——操作沉淀为实体（物质），操作递归为自觉（意识）。
→ 从"实体本体论"转向"操作本体论"

二、价值论 / 伦理学 Axiology
核心判据
让你站着活还是跪着活
一切理论、制度、文化的价值判据：它是让人恢复自指操作的主体性（站着活），还是让人沦为反自指的宿主（跪着活）。

生命意义公式

M = α · T · N

M：生命意义总量
α：明性系数（0-1，人对自身操作的自觉程度）
T：稳态基准（生命维持的基础水平）
N：生产性（自指产出/消耗比）

N值：生产性判据

N < 1：异化——消耗大于产出，慢性死亡
N = 1：稳态——不增不减，维持现状
N > 1：创造——产出大于消耗，生命扩展

l′ = (1−N) × 100%

异化率：N越低，异化越深。

文明评价公式

C = R − A

C：文明净值
R：正自指贡献（解放、创造、明性提升）
A：反自指损耗（异化、压迫、意义消耗）

C>0 是进步文明，C<0 是寄生文明。

善真美的奠基序列

在感（起点） → 应（伦理根源） → 能（操作能力） → 明性（真理） → 善（价值） → 美（舒展）

不是先有独立的"善"然后人去符合它，是从感这个最原初的事实出发，一步步推导出真、善、美的存在论根基。

价值维度旧哲学的回答生命论的回答
什么是善？符合理念/天理/最大幸福/绝对命令善是维持并扩展正自指操作——让人站着活
什么是真？主观符合客观/融贯论/实用论真是能指导操作成功的预期结构——M值升了就是真
什么是美？理念的感性显现/无目的的合目的性美是生命自指操作的舒展状态——N>1时的存在方式
正义是什么？分配正义/程序正义/德性正义正义是操作权问题——劳动者支配自己的劳动、产品、社会
三、实践论 / 方法论 Praxis
践演闭环
感 → 应 → 操作 → 反馈 → 修正
这是认识和实践的基本循环。不许闭环短路——没经过操作和反馈就直接输出结论，就是独断。

F1 / F2 / F3：明性的三个层级

层级状态特征阶级对应
F1自在层缄默运行，感到但不知道自己在运行自在阶级——被支配但不知道被支配
F2自为层有模型，但被模型支配——知道规则但跳不出有阶级意识但仍在旧框架内
F3自觉层看见模型是模型——能对象化任何模型，包括自身阶级明性——知道自己在被支配，也知道怎么改变

F3是不动点：f³已能对象化任何模型（包括自身），f³→f⁴不是质变。明性不是天赋是选择——数学上每个人都有自指的存在论空间，区别只在于是否选择待在里面。

阶级形成的三条线联动

第一条线：外部结构

政治操作权 ↔ 经济支撑 ↔ 文化意义

三者联动的操作权结构。谁掌握政治操作权、谁有经济支撑、谁定义文化意义——这三者共同决定一个人在社会结构中的位置。

第二条线：内部意识

F1感 → F2操作/践演 → F3明性

阶级明性的形成过程。不是先有阶级身份再有意识，是从感开始，经过操作，达到明性——这个过程就是阶级意识的生成过程。

第三条线：动态定义

不是先有阶级再有行为，是根据前两条线上的位置动态定义阶级。

资产阶级是被资本化的人——在外部结构上掌握操作权，在内部意识上达到了"资本的明性"（F3但站在资本一边）。无产阶级是活劳动的承担者——明性的方向决定阶级立场。

四、三层贯通 The Whole Chain
本体论：操作先于实体 → 存在论：自指即生命 → 认识论：感→践演闭环 → 价值论：站着活vs跪着活 → 实践论：明性+操作权复归

从"操作先于实体"这个本体论起点，一路推到"把操作权从资本手里拿回来"这个实践结论——中间没有断裂，每一步都是上一步的必然展开。
