哲学立场总表

本体论 · 价值论——所有立场一览，先讲清楚领域在问什么，再看各家怎么答

一、本体论 / 存在论 Ontology

这个领域到底在问什么？

本体论问的是：世界/存在根本上是什么？

不是问"世界上有什么东西"（那是具体科学的事），是问"存在本身的性质是什么"——是物质还是精神？是固定的实体还是流动的过程？是独立于人的客观实在，还是依赖于人的认识？

核心问题：存在的本原是什么？存在的方式是实体还是过程？存在和思维的关系是什么？

对这个问题的回答，决定了你后面所有哲学立场的基本方向——你说世界是物质的，认识论就不可能是"回忆理念"；你说存在先于本质，价值论就不可能是"发现客观的善"。

唯物主义路线 唯心主义路线 中间/超越路线 生命论
立场 路线 核心主张（世界根本上是什么） 代表人物 认识论推论 根本盲区
机械唯物主义 唯物 世界=物质微粒的集合，按机械运动规律运转。人是机器的一个齿轮。 霍布斯、洛克、拉美特利、18世纪法国唯物论 感觉反映论，白板说——人心是一张白纸，经验在上面写字。 还原论解释不了生命和意识；把质的差异还原为量的差异；历史观上是唯心的。
辩证唯物主义 唯物 物质在实践中存在，内部矛盾推动运动发展。不是摆在那里的东西，是你在改变它的过程中才真正存在的。 马克思、恩格斯、列宁、毛泽东 能动反映论——实践→认识→再实践→再认识，循环上升。 "物质第一性"仍预设了实体本体论；实践标准可能沦为权力标准；对"操作先于实体"未明说。
气一元论 唯物 太虚即气，气聚为万物，气散为太虚。一物两体，变化日新。 张载、王夫之、戴震 见闻之知+德性所知，内外合。 气的概念直观，缺乏精确形式化；辩证思维偏笼统，未达系统理论。
客观唯心主义 唯心 世界背后有一个客观的理性/理念/绝对精神在运转，你的任务是认识它、服从它。 柏拉图、黑格尔、程颐、朱熹 理性回忆/概念推演——真理是对客观理念的认识。 理念/理容易脱离现实，变成压迫人的抽象力量；头足倒置。
主观唯心主义 唯心 世界没有自己的意义，意义是你赋予的；你有多强的意志，世界就有多大可塑性。 贝克莱、尼采、叔本华 直觉/体验/内省——真理是主体的创造。 个体意志难以主体间验证；容易走向唯我论或精英主义。
理本体论 唯心 未有天地之先，毕竟也只是理。理在事先，理生气。 程颐、朱熹（程朱理学） 格物致知，积累贯通，即物穷理。 理的超越性脱离实际，"存天理灭人欲"压抑个体；易成为统治意识形态。
心本体论 唯心 宇宙便是吾心，吾心即是宇宙。心外无物，心外无理。 陆九渊、王阳明（陆王心学） 致良知，不假外求，事上磨练。 易流于空疏，主观标准难验证；"良知"的普遍性缺乏存在论根基。
存在主义 中间 存在先于本质。没有任何东西替你决定你是谁，这既是你的自由也是你的诅咒。 海德格尔、萨特、加缪 情绪揭示存在，反思前的我思——焦虑、畏、烦是存在的基本情态。 自由绝对化导致虚无；缺乏社会结构分析；个人决断容易变成盲目的选择。
实用主义 中间 别争论世界本质上是什么——你说这个东西是"真的"，它在实践中能产生什么不同效果？实在是实践中塑造的效果。 皮尔士、詹姆斯、杜威 探究理论——观念是解决问题的工具，真理=效果。 回避根本问题，平庸化；"有用即真理"可能沦为强权即真理。
过程哲学 中间 没有什么东西"是"什么，一切都在"成为"什么；你抓住的任何固定本质，都已经是过程的一个切片。 怀特海、柏格森 摄受关系，直觉与理性互补。 过程概念模糊，缺乏精确性；难以建立稳定的规范性。
虚无主义 中间 无本原，无意义，荒谬。你说的那些"本质""真理""意义"，全都是人编出来给自己壮胆的。 尼采（宣告虚无主义到来）、福柯、德里达 知识=权力，解构——一切真理宣称都是权力操作。 解构一切后无建设性；拆穿之后怎么办没有答案；容易滑向犬儒。
生命论（操作本体论） 生命论 不是物质也不是意识第一性，是操作第一性。操作先于实体——物质和意识都是操作的沉积：操作沉淀为实体（物质），操作递归为自觉（意识）。自指操作S=f(S)就是生命的存在方式。 北原慢热 践演闭环——感→应→操作→反馈→修正。感是最原初的事实，比"我思""物质"都直接。 形式化仍在施工中；量论参数待实证标定；社会应用需大规模实践检验。
二、价值论 / 伦理学 Axiology / Ethics

这个领域到底在问什么？

价值论问的是：什么是好的？什么是应该的？人应该追求什么？

不是问"你喜欢什么"（那是个人偏好），是问"好坏善恶有没有客观标准？价值的来源是什么？判断一个行为/制度/社会好不好，依据是什么？"

核心问题：价值是客观的还是主观的？善恶的标准是什么？正当与善哪个优先？个人与集体的关系怎么处理？

价值论和本体论是连在一起的——你说世界有客观的理/理念，善就是对它的符合；你说世界没有客观意义，善就是主体自己的创造；你说世界是物质的辩证运动，善就是推动矛盾向进步方向转化。

功利主义 义务论 德性论 马克思主义 东方伦理 虚无/超越 生命论
立场 类型 价值来源 善恶标准 代表人物 根本盲区
功利主义 功利 快乐/幸福是唯一的善，痛苦是唯一的恶。价值来自感受。 最大多数人的最大幸福。一个行为是善的，当且仅当它产生的总体幸福大于痛苦。 边沁、密尔、西季威克 可以为了多数人的幸福牺牲少数人（电车难题）；幸福的质和量难以比较；可能沦为多数暴政。
义务论（道义论） 义务 理性本身颁布的道德律。价值来自理性存在者的尊严。 可普遍化原则——你只按照你同时愿意它成为普遍法则的准则行动。人是目的不是手段。 康德、罗斯 规则僵化，无法处理义务冲突；形式化缺乏实质内容；"绝对命令"在现实中难以操作。
德性伦理学 德性 人的卓越/德性（arete）。价值来自品格的完善。 不是问"我该做什么"，是问"我该成为什么样的人"。中道——在过度和不及之间的平衡点。 亚里士多德、阿奎那、麦金太尔 德性列表依赖特定文化传统；缺乏对行为的直接指导；"好人做坏事"怎么解释？
自由主义 义务 个人自由和权利。价值来自个体的自主选择。 正当优先于善——每个人都有平等的自由权利，只要不伤害他人就可以追求自己的善。 洛克、密尔、罗尔斯、诺齐克 原子化个人预设；形式平等掩盖实质不平等；"权利"缺乏存在论根基；社群维度缺失。
社群主义 德性 社群的共同善。价值来自文化传统和社群实践。 善优先于正当——脱离社群的"个人"是抽象的，正义标准内在于特定社群的实践。 麦金太尔、桑德尔、泰勒 文化相对主义风险；传统可能是压迫性的；如何处理跨社群的价值冲突？
实用主义伦理 功利 实践效果。价值来自解决问题的能力。 善就是在具体情境中有效解决问题、促进生长。道德是实验性的，随情境调整。 杜威、詹姆斯 缺乏终极标准；"有效"本身需要定义；可能沦为机会主义。
存在主义伦理 超越 自由选择本身。价值来自个体的决断和承担。 存在先于本质——没有先验的善，你通过选择创造价值，但必须为选择承担全部责任。 萨特、加缪 选择标准缺失，"怎么选都行"；绝对责任导致焦虑；缺乏社会维度。
马克思主义伦理 马克思 人的自由全面发展。价值来自社会实践和历史进步。 善就是推动生产力发展和人的解放；消灭剥削、消灭异化，实现"每个人的自由发展是一切人自由发展的条件"。 马克思、恩格斯、毛泽东 "历史进步"的标准需要具体化；可能以历史必然性名义压制个体；社会主义实践中的教训需正视。
儒家伦理 东方 仁/天理/良知。价值来自天道在人身上的体现。 仁为核心，礼为规范，孝悌为本。己所不欲勿施于人。修身齐家治国平天下。 孔子、孟子、朱熹、王阳明 等级制（三纲）压抑个体；亲亲相隐与普遍正义冲突；传统礼制与现代社会不兼容。
道家伦理 东方 道/自然。价值来自顺应自然、无为而治。 上德不德——最好的道德是不刻意讲道德。无为、不争、知足、返璞归真。 老子、庄子 消极避世倾向；"自然"概念模糊；缺乏积极的社会改造方案。
佛教伦理 东方 解脱/涅槃。价值来自断除烦恼、觉悟成佛。 诸恶莫作，众善奉行，自净其意。慈悲为怀，不杀生，不执着。 释迦牟尼、龙树、慧能 出世倾向，对世俗社会改造动力不足；"空"的概念易被误解为虚无；因果报应说可能维护现状。
虚无主义 虚无 无。没有客观价值，一切价值都是人的虚构。 没有善恶标准——上帝死了，一切皆许可。要么自我创造价值（超人），要么消极颓废。 尼采（宣告者）、部分后现代主义 价值真空导致绝望或强权；"创造价值"本身需要标准；社会凝聚力瓦解。
生命论价值论 生命论 生命的自指操作本身。价值来自正自指操作的维持和扩展。 让你站着活还是跪着活。善是维持并扩展正自指操作（M值提升、N>1、操作权在劳动者手里）；恶是反自指（异化、压迫、意义消耗）。正义是操作权问题，不是分配问题。 北原慢热 M值/N值的社会测量仍需实证标定；"站着活"的个体差异需处理；国际层面的价值冲突需进一步理论化。
三、认识论 Epistemology

这个领域到底在问什么？

认识论问的是：人怎么认识世界？知识从哪里来？什么是真理？

不是问"你知道什么"，是问"你怎么知道你知道的是真的"——认识的来源是什么？感觉还是理性？真理的标准是什么？有没有普遍必然的知识？

核心问题：知识的来源是什么？真理的标准是什么？认识的边界在哪里？
立场 知识来源 真理标准 代表人物 根本盲区
经验论 感觉经验。人心是白板，经验在上面写字。 感觉经验的证实——知识必须能还原为感觉印象。 洛克、贝克莱、休谟 归纳问题（休谟）：从有限经验推不出普遍必然；容易走向怀疑论或唯心论。
唯理论 理性/天赋观念。真正的知识来自理性推演，感觉是混乱的。 理性的清楚明白——真理是自明的、可推演的。 笛卡尔、斯宾诺莎、莱布尼茨 天赋观念缺乏经验验证；纯形式推演推不出关于世界的新知识；独断论风险。
先验论 经验材料+先天认知形式。知识是心灵用先天范畴整理经验材料的结果。 普遍必然性来自先天形式，经验内容来自感觉——两者结合才是知识。 康德 物自体不可知；先天范畴的来源未解释；割裂了现象和本体。
辩证唯物主义认识论 实践。认识是在实践基础上主体对客体的能动反映。 实践是检验真理的唯一标准。实践→认识→再实践→再认识，循环上升。 马克思、毛泽东 "实践标准"可能被权力绑架；"反映论"仍预设了主客二分；对缄默意识维度关注不足。
实用主义认识论 探究过程。知识是解决问题的工具。 真理=效果——一个观念是真的，当且仅当它在实践中有效。 皮尔士、杜威 "有效"本身需要标准；可能走向相对主义；真理和有用不能完全等同。
现象学 本质直观。回到事情本身，通过现象学还原把握本质。 明证性（Evidenz）——直观中被给予的东西是明证的。 胡塞尔、海德格尔 本质直观的主体间性问题；还原方法的可操作性存疑；容易走向先验唯心论。
生命论认识论 感。感是最原初的事实——比"我思""物质"都直接。认识是感→应→操作→反馈→修正的践演闭环。 真理=能指导操作成功的预期结构。M值升了就是真，降了就是假。缄默意识是一切认识的母体，明性是感递归到自觉。 北原慢热 缄默意识的形式化仍在探索；预期结构的量化需实证；个体差异和社会共识的关系需深化。
四、三层怎么连起来 How They Connect

本体论、认识论、价值论不是三个独立的东西，是一条链：

本体论（世界是什么） → 认识论（怎么认识） → 价值论（什么是好） → 实践（怎么做）

上一层决定下一层的可能性空间。你说世界是物质的，认识论就不可能是"回忆理念"；你说存在先于本质，价值论就不可能是"发现客观的善"。

很多哲学争论看起来在争"怎么做"（实践层面），其实根子在"世界是什么"（本体论层面）。把争论拉回本体论，分歧就一目了然——你们根本不在一个世界里。

生命论的做法：从"操作先于实体"这个本体论起点，推出"感→践演闭环"的认识论，推出"站着活vs跪着活"的价值论，推出"操作权复归"的实践结论——中间没有断裂，每一步都是上一步的必然展开。
