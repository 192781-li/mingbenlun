## 三、维护规范

1. **所有HTML可视化文件统一存放在 `docs/assets/html/`**，不要散落在notes或其他目录
2. **新建可视化后必须更新本索引**
3. **可视化内容必须与模块化正文一致**，正文更新后可视化要同步更新
4. **可视化中的引用必须有出处**（马克思原文需标注卷次页码，视频需标注来源）
5. **命名规范**：`主题_类型.html`，如`阶级形成三条线联动_可视化.html`
