## 一、核心命题

**真正的理论推导，应该从操作的必要条件出发，而不是从既成定义出发循环。**

- 不问"X的定义是什么"，而问"要达成Y，操作上必须有什么"
- 范畴是操作的工具，不是操作的主人
- 定义是操作的沉积物，沉积物不能反过来成为操作的绝对标准

---

## 二、两种路径的对比

### 2.1 传统路径：定义循环（循环论证）

```
从少数案例提炼定义 → 用定义衡量一切 → 定义本身不受检验（因为它是标准）
```

**结构**：
1. 观察少数案例，提炼出"X=有A、B、C"
2. 宣布这是X的普遍定义
3. 用这个定义衡量所有案例：有A、B、C的就是X，没有的就不是X
4. 定义本身不被质疑，因为它是"衡量标准"

**问题**：
- 定义的来源（少数案例）不具有普遍性，但被当成了普遍标准
- 不符合定义的案例被排除，而不是促使定义被修正
- 范畴冻结了，不能随操作的发展而更新
- 本质上是用过去的操作沉积物，支配现在和未来的操作

### 2.2 明本论路径：操作必要条件推导

```
问"要达成Y，操作上必须有什么" → 从操作的必要条件推导出范畴 → 范畴受操作检验，可被新操作超越
```

**结构**：
1. 不预设X的定义，而是从一个具体的操作目标Y出发
2. 分析：要达成Y，在操作上必须具备哪些条件
3. 这些必要条件的总和，就是X的操作性定义
4. 当操作发展了、Y变化了，X的定义也随之更新

**优势**：
- 范畴来源于操作，而不是来源于少数案例的归纳
- 范畴本身受操作检验，可以被修正和超越
- 不会出现"定义衡量一切"的循环
- 范畴是活的，随操作的发展而发展

## 三、四个应用实例

### 3.1 文明标准

**传统路径有两套循环论证，一套比一套深**：

**第一套（西方）：文明三要素**
- 从西亚北非文明提炼出"文明三要素"（文字、青铜器、城市）
- 用三要素衡量所有文明：没有的就"不算文明"
- 高考题标准答案也只是说"三要素不具有普遍性"，但没有给出替代方案

**第二套（中国/苏联教材体系）：历史规律的嵌套循环**
- 不是简单的"生产力决定生产关系"，而是更深层的嵌套循环：
  1. 一切文明必须符合"历史规律"
  2. 历史规律必须符合"唯物史观"
  3. 唯物史观本身是一套被苏联教材强化改造过的庸俗唯物主义，不受检验
- 这是双重循环：先用唯物史观定义历史规律，再用历史规律衡量文明，而唯物史观本身作为绝对真理不被质疑
- 不符合"历史规律"的文明，要么被说成"还没进入文明"，要么被说成"特殊情况"，总之不允许挑战规律本身
- 本质：用一套被教条化的理论，裁定所有文明的合法性，而理论本身不受操作检验

**明本论路径（操作必要条件推导）**：
- 不问"文明的定义是什么"，也不问"文明符不符合历史规律"，而问"要支撑数百万人的复杂协作、标准化生产、公共工程、城市建设，操作上必须有什么"
- 推导：必须有承载从简单到复杂、从具体到抽象、双向贯通的符号操作沉积系统
- 这个系统不一定是文字（印度河文明可能没有成熟文字），但必须能承载行为含义、协调大规模操作、传递跨代经验
- 结论：文明的本质不是"有文字/青铜器/城市"，也不是"符合某套历史规律"，而是"有能支撑复杂协作的操作沉积系统"

### 3.2 革命

**传统路径（定义循环）**：
- 从法国大革命、十月革命提炼出"革命=武装夺取政权"
- 用这个定义衡量一切：不搞武装斗争就不是革命
- 革命变成一个固定范畴，和"夺权"绑定

**明本论路径（操作必要条件推导）**：
- 不问"革命的定义是什么"，而问"要让生命从操作权被剥夺中解放出来，操作上必须有什么"
- 推导：必须有持续的践演，让生命重新成为操作主体
- 当操作权全面回归生命后，"革命"作为"夺回操作权"的特殊范畴就失去了存在根据，自然消解
- 结论：革命的本质不是"武装夺权"，而是"生命夺回操作权的持续践演"；操作权回归后，革命消融于生活

### 3.3 人的本质

**传统路径（定义循环）**：
- 从亚里士多德开始："人是理性的动物"
- 后来各种定义："人是政治动物""人是会劳动的动物""人是符号动物"
- 每个定义都试图用一个属性穷尽人的本质，然后用这个属性衡量"谁算人"

**明本论路径（操作必要条件推导）**：
- 不问"人的本质定义是什么"，而问"一个具体的人，在操作上是怎么成为他自己的"
- 推导：人的本质=既定事实与每时每刻操作的递归结果。既定事实包括本人过去操作的沉积和一切非本人所能左右的人与物之间的操作史
- 结论：人的本质不是一个固定属性，而是一个持续的操作过程；每个人的本质都是具体的、历史的、由操作生成的

### 3.4 自由

**传统路径（定义循环）**：
- 自由主义："自由=选择权"（能选A还是B）
- 传统社会主义："自由=认识必然"（掌握了规律就自由了）
- 两个定义互相打架，因为都从定义出发，而不是从操作出发

**明本论路径（操作必要条件推导）**：
- 不问"自由的定义是什么"，而问"一个生命要能自主地存在和发展，操作上必须有什么"
- 推导：自由=操作权，即主体能否参与、修改、终止、重新生成规定自身生存的操作
- 结论：自由不是抽象的选择权（形式自由），也不是对必然的认识（认识论自由），而是实实在在的操作主体性

## 四、存在论基础

这个方法论不是一个实用技巧，它有严格的存在论基础：

1. **操作先于实体**：世界的基本单元不是实体（物、概念、定义），而是操作。实体是操作的沉积物。
2. **定义是沉积物**：任何定义、范畴、概念，都是过去操作的沉积。沉积物有相对独立性，但不能反过来成为操作的绝对标准。
3. **反自指的风险**：当定义脱离操作、反过来支配操作时，就发生了反自指——操作的产物夺取了操作的主导权（阴夺阳位）。定义循环就是反自指在认识论层面的表现。
4. **明性（F3）的作用**：明性就是持续反思范畴与操作的关系，不让范畴冻结操作。从定义循环中突破出来，本身就是明性的体现。
5. **践演的持续生成**：操作是持续的，范畴也必须持续生成。从操作必要条件推导，就是让范畴随操作的发展而更新，而不是让范畴固定下来。

## 五、西方哲学的根本局限

从柏拉图开始，西方哲学的主流路径就是"从定义出发"：

- 柏拉图：理念是真实的，具体事物是理念的摹本。定义（理念）先于操作。
- 亚里士多德：本质是实体的属性，定义就是揭示本质。
- 近代认识论：笛卡尔的"我思"、康德的"先天范畴"，都是从主体的固有结构出发，而不是从操作出发。
- 分析哲学：语言的意义就是用法（维特根斯坦后期已经接近操作论了），但大多数分析哲学仍然在做"概念分析"，即从定义出发澄清定义。

**明本论的突破**：把"从定义出发"翻转为"从操作出发"。这不是一个认识论技巧的改变，而是本体论层面的翻转——操作先于实体，所以操作的必要条件先于实体的定义。

马克思已经开始了这个翻转（"实践是检验真理的唯一标准"），但马克思主义传统中经常滑回"从定义出发"。最典型的是苏联教材强化改造版的庸俗唯物主义：它构建了一个嵌套循环——一切文明必须符合"历史规律"，历史规律必须符合"唯物史观"，而唯物史观本身作为绝对真理不受检验。生产力决定论变成教条、"社会主义=公有制"变成固定公式，都是这个嵌套循环的表现。明本论把这个翻转彻底化了：不仅真理标准是操作，连范畴的生成也是操作。

> "根据我们唯物史观认为你没有什么，你就不可能怎么样。你如果要达成什么，你不承认有什么、不承认具备某种逻辑且一以贯之进行某种操作，那他就是非理性的，且是非科学的。"

> "必然其实是一连串具备共性的偶然所构成的，而那些偶然又有具体的人去操作它。"

> "没有这个沉积，人的操作简直就是无根浮萍，他是立不住，也无法支撑这数百万的人口的。"
