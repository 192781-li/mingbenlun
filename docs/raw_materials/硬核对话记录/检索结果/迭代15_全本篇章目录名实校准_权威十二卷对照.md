## 三、研究过程与发现（均实测）
### 3.1 找到权威：manifest.json 是"卷结构唯一数据源"
`生命论_模块化/manifest.json` 自述"卷结构唯一数据源，正文跨卷引用使用卷名而非卷号"，与 `docs/notes/全本结构/全本卷篇章结构.md` 完全一致，确定**权威为十二卷体系**：卷首命经／卷一存在论／卷二操作论／卷三认识论／卷四实践论／卷五群己论／卷六异化论／卷七解放论／卷八格物论／卷九人文论／卷十传统论／卷十一践演论／附录。模块化实体目录 90+ 篇与之对应。

### 3.2 三套体系辨析，避免拿错尺子
- A 十二卷权威体系（manifest＋全本结构＋模块化实体）；
- B flashpoints 现状（9个目录位、8个有内容、21篇）；
- C 对话/合订本叙述里的"八卷说（含辩证法/社会论/革命论卷）"——实测在 manifest、全本结构、模块化目录中**均不存在对应卷**，是未落地为工程结构的叙述设想。结论：B 是 A 的残缺错号镜像，校准应让 B 向 A 对齐，不能用 C 去修 B。

### 3.3 逐篇核对（21篇全量，证据=每个文件头"来源"标注）
- 仅卷一存在论 3 篇编号正确；
- **其余18篇卷号全错**：认识论（权威03）被编02、群己论（05）编03、异化论（06）编04、解放论（07）编05、实践论（04）编06（顺序也乱）、格物论（08）编07、人文论（09）编08；
