# 人到底有没有"智的直觉"？

## ——康德与牟宗三的世纪之争：物自身、良知呈现、两层存有论，以及一个最尖锐的批评

> 这是整个现代新儒家哲学最核心、最烧脑、最有争议的论点。康德说：人没有智的直觉，只有上帝有，所以物自身不可知。牟宗三说：人有智的直觉，良知就是，所以物自身可知、道德形上学可能。这一分歧直接决定了：中国哲学是否比康德更进一步、现代性危机是否有解、"良知自我坎陷"是否站得住。
>
> 本文把康德的原始立场、牟宗三的倒转、牟宗三的完整论证、学界最尖锐的批评（杨泽波"三个环节"）、更深层的困境（黄敏的分析）全部拆解，最后给出一个公允的判断。

---

## 第一章　问题的提出：一个词引发的世纪之争

"智的直觉"（intellectual intuition / intellektuelle Anschauung），这个词在康德哲学里是一个"极限概念"——人没有，只有上帝可能有。但在牟宗三这里，它变成了整个哲学体系的拱顶石——人有，良知就是。

这不是一个小分歧。这是一个"哥白尼式倒转"级别的分歧：

- **如果人没有智的直觉**（康德立场）：物自身永远不可知，道德法则只能是"设准"（postulate），上帝存在、灵魂不朽是"悬设"，形上学不可能成为"科学"，人是有限的存在者。
- **如果人有智的直觉**（牟宗三立场）：物自身可知（在良知呈现中），道德法则是"呈现"（presentation）而非设准，上帝、灵魂可以被收摄进"自由无限心"，道德形上学可能，人"虽有限而可无限"。

牟宗三自己说："人有没有智的直觉"是他和康德"最重大的一点不同"，也是"中西哲学传统的根本差异"所在。

这个争论从20世纪中叶持续到今天，参与的学者包括：牟宗三、唐君毅、徐复观（新儒家阵营）；李明辉、卢雪崑（辩护牟宗三）；杨泽波、邓晓芒、黄敏、陈迎年（批评或质疑牟宗三）。这是中国哲学界最深刻、最持久的学术争论之一。

下面从头讲起。

---

## 第二章　康德的原始立场：物自身不可知，人没有智的直觉

### 一、现象与物自身的区分

康德在《纯粹理性批判》（1781/1787）中做了一个著名的区分：

- **现象（Phaenomena / Erscheinung）**：事物显示在我们心灵中的样子，是我们通过感性直观（时空形式）接受刺激、再经知性范畴（因果、实体等）综合而成的认识对象。现象是可知的，科学知识的对象就是现象。
- **物自身（Ding an sich / Noumenon）**：事物"就其自身而言"的样子，独立于我们的认识条件。物自身刺激我们的感官产生现象，但物自身本身不可被认识。

康德的基本观点：我们对事物的认识仅仅是现象，物自身不可被认识。可被认识的现象的范围就是现象界，不可被认识的物自身的范围就是本体界。

### 二、为什么物自身不可知

因为人的认识有两个根本限制：

1. **人的直观是"感性的"（sinnlich），不是"智的"（intellektuell）**：人的直观必须依赖于物自身对感官的刺激，在时空形式中接受杂多。没有对象刺激，人就没有直观内容。
2. **人的知性是"推论的"（diskursiv），不是"直觉的"（intuitiv）**：人的知性必须通过概念对感性直观提供的材料进行思维和综合，不能直接创造对象。

用康德的话说："直观无概念则盲，思维无内容则空。"人的认识必须是感性直观 + 知性概念的合作，缺一不可。

### 三、什么是"智的直觉"

与"感性直观"相对，"智的直觉"（intellektuelle Anschauung）被康德定义为一种假设性的认知能力：

- 它的直观活动本身就**创造对象**——不需要外部对象刺激，直觉活动自身就能提供杂多、实现存在
- 它是**纯智的**，不是感触的——不通过时空形式
- 它是**直觉的**，不是推论的——不使用概念范畴
- 它直接把握**物自身**，不是现象

康德直接把它叫做"**本源的直观**"（intuitus originarius），与"派生的直观"（intuitus derivativus）相对。"本源"意味着：它本身就是对象存在的来源，不需要从外部接受。

### 四、为什么人没有智的直觉

因为人是**有限的存在者**：
- 人的直观必须接受外部刺激（派生的），不能自己创造对象（本源的）
- 人的知性必须用概念思维，不能直接创造
- 如果人有智的直觉，人就成了上帝——能凭直觉创造万物

所以康德说：智的直觉"我们无法证明它属于任何存在者，或许只有上帝才有"。对人而言，智的直觉是一个"极限概念"（Grenzbegriff）——用来划清认识的界限，防止认知的僭越，本身不是人能拥有的能力。

### 五、物自身的"消极意义"与"积极意义"

康德区分了物自身的两种意义：

- **消极意义（negative meaning）**：物自身仅仅是"不是我们感性直观的对象"的某物——一个"空洞的"限制概念，用来标明认识的界限。这是康德主要使用的意义。
- **积极意义（positive meaning）**：物自身是"一种非感性直观（即智的直觉）的对象"。但因为人没有智的直觉，所以积极意义的物自身对人来说是不可知的，只是一个"思想上的可能性"。

康德明确说：我们只能在消极意义上使用物自身概念，不能在积极意义上使用——因为积极意义预设了智的直觉，而人没有。

### 六、物自身在实践理性中的"价值意味"

但康德在《实践理性批判》中，从另一个角度给了物自身一种"价值意味"：

- 人作为**现象**服从自然因果律（被决定的）
- 人作为**物自身**是自由的（自由意志）
- 同一个意志，被设想为现象而遵循自然法则，与被设想为物自身而为自由，并不矛盾

康德说："对象是以双重意义而观之，而作为现象与作为物自身。"（BXXVII）这为实践理性留出了地盘——自由、道德、上帝、灵魂不朽，都属于"物自身"领域，虽然不可认识，但可以"思想"（denken），并且在实践中是"实在的"。

但注意：康德这里的物自身仍然是**消极意义上的**——它不是人能"直觉"到的对象，而是实践理性的"设准"（Postulat）。人不能"认识"自由，但可以"思想"自由，并且在道德实践中"体认"自由。

这就是康德的完整立场。下面看牟宗三如何"倒转"它。

---

## 第三章　牟宗三的"倒转"：人有智的直觉，物自身是价值概念

### 一、牟宗三的核心判断

牟宗三对康德的批评集中在一点：**康德因为没有中国哲学传统作背景，所以不承认人有智的直觉，这导致他的物自身概念"不稳定""不充分""只有消极意义"。**

牟宗三说：

> "康德亦实未明朗地决定说物自身是一个价值意味底概念，他说物自身常是与事实问题不分的。"

牟宗三的判断：
1. 物自身应该是一个**价值意味的概念**，不是事实概念
2. 人**有**智的直觉（良知就是），所以物自身有**积极意义**
3. 康德因为不承认人有智的直觉，所以物自身只能是消极的、空洞的、不稳定的

### 二、为什么物自身必须是"价值意味"的概念

牟宗三的论证非常精密：

如果物自身是一个**事实概念**（即"事物的客观原样"），那么：
- 现象与物自身的区分就只是"主观性与客观性"的区分
- 人能不能认识物自身就只是一个"认识程度"问题
- 随着人的认识能力提高，总有一天可以认识物自身
- 这样现象与物自身的区分就是"暂时的""可超越的"
- 那么康德的"超越的区分"（transcendental distinction）就不充分了

但康德要的是"超越的区分"——现象与物自身的区分不是程度上的，而是**性质上的、绝对的封限**。要使这个区分成立，物自身就不能是"客观原样"（事实概念），而必须是一个**价值意味的概念**——它标志的是"事物在智的直觉下的样子"，与"在感性直观下的样子"（现象）有本质区别。

牟宗三说：

> "物自身不是一个认知上所认知的对象之'事实上的原样'之事实概念，而是一个高度价值意味的概念。"

### 三、为什么人有智的直觉

牟宗三的论证来自中国哲学传统，尤其是儒家：

1. **良知是"呈现"，不是"设准"**：在道德实践中，良知（本心仁体）会当下呈现自己——"见父自然知孝，见兄自然知悌，见孺子入井自然知恻隐"。这不是一个"假设"，而是一个"呈现"。
2. **良知的自我体认不需要范畴**：人对本心仁体的体认是直接进行的，完全不需要借助时空、范畴这些认识形式。这是一种"非感性的、非范畴的"直觉。
3. **这种直觉就是"智的直觉"**：既然它不需要感性刺激、不需要范畴、直接把握本体（良知），那它就是康德所说的"智的直觉"。
4. **所以人有智的直觉**：康德因为没有中国哲学传统，看不到这一点，所以把智的直觉只归给上帝。

牟宗三说：

> "试设想我们实可有一种智的直觉，我们以此直觉觉物自体，觉真我（真主体，如自由意志等）……我们在此直觉之朗现上，岂尚须于范畴来决定吗？"

### 四、"人虽有限而可无限"

由此，牟宗三提出了一个著名命题：**"人虽有限而可无限。"**

- 康德说：人是有限的存在者，没有智的直觉，物自身不可知
- 牟宗三说：人在认识层面是有限的（感性直观 + 范畴），但在道德实践层面可以"无限"——良知呈现就是智的直觉，人可以通过道德实践"上通本体界"，与天地万物为一体

这就是儒家"人人皆可以为尧舜""满街都是圣人"的哲学表达。

### 五、物自身的"积极意义"

因为人有智的直觉，所以物自身不再是消极的、空洞的限制概念，而是有了**积极意义**：

- 对**无限心（良知、智的直觉）**而言，事物是"物自身"——事物如其所如地存在，是"本来面目""自尔独化"
- 对**有限心（知性、感性直观）**而言，事物是"现象"——事物被时空范畴所决定，是认识对象

牟宗三说：

> "现象与物自身之分是对应主体而言，对应认识心而言，即为现象，对应知体明觉而言，即为物自身。"

这就把康德的"超越区分"从"不可知的界限"变成了"同一主体的两种观法"——物自身不再是彼岸，而是"良知朗现下的事物"。

## 第四章　牟宗三的完整论证：从良知呈现到两层存有论

### 一、"一心开二门"

牟宗三借用佛教《大乘起信论》"一心开二门"的架构，建立了他的哲学体系：

- **一心**：自由无限心（良知、本心仁体、智的直觉）
- **二门**：
  - **真如门**（无执的存有论 / 本体界）：自由无限心直接呈现，物自身如如存在，道德实践、成圣成佛
  - **生灭门**（执的存有论 / 现象界）：自由无限心"自我坎陷"为知性（有限心），执持自己为认知主体，把对象推出去为现象，成就科学知识、民主政治

### 二、无执的存有论（本体界）

在无执的层面：
- 主体是**自由无限心**（良知、智的直觉）
- 对象是**物自身**——事物在明觉感应中如如存在，"本来面目""自尔独化"
- 认识方式是**智的直觉**——不通过时空范畴，直接把握本体
- 这是**道德实践的领域**——成圣、成佛、成真人，"人虽有限而可无限"

牟宗三说：

> "对无限心（智心）而言，为物自身；对认识心（识心、有限心）而言，为现象。由前者，成无执的（本体界的）存有论，由后者，成执的（现象界的）存有论。"

### 三、执的存有论（现象界）

在执的层面：
- 主体是**知性**（有限心、识心）——由自由无限心"自我坎陷"而成
- 对象是**现象**——由知性之执"绉起"或"挑起"，被时空范畴所决定
- 认识方式是**感性直观 + 知性范畴**——康德所说的人的认识
- 这是**科学知识、民主政治的领域**

牟宗三说：

> "知性，认知主体是由自由无限心之自我坎陷而成，它本身本质上就是一种'执'。它执持它自己而静处一边，成为认知主体，它同时亦把'物之在其自己'之物推出去而视为它的对象，因而亦成为现象。现象根本是由知性之执而执成的。"

### 四、"良知自我坎陷"的机制

这是从无执到执的关键机制（我们在之前的长文里已经详细讲过，这里简要回顾）：

1. 良知（自由无限心）本来在无执层面，直接与物自身相通
2. 但要成就科学民主，良知必须**主动自我否定、自我降格**——"坎陷"自己
3. 坎陷后，良知"退藏于密"，成为知性的"支持者"和"超越的主宰"
4. 知性（有限心）执持自己为认知主体，把对象推出去为现象，成就科学知识
5. 认知完成后，良知再出来做价值判断，主宰科学的运用
6. 这样良知就从"直接的道德主体"升进为"能主宰自身与认知主体之进退的更高道德主体"——"最大之仁兼涵仁与智"

### 五、两层存有论的完整图景

```
                    自由无限心（良知、智的直觉）
                           │
              ┌────────────┴────────────┐
              │                         │
        无执的存有论               自我坎陷
        （本体界）                     │
              │                    执的存有论
        智的直觉                 （现象界）
        物自身（如相）               │
        道德实践、成圣            感性直观+范畴
                                   现象
                                   科学、民主
              │                         │
              └────────────┬────────────┘
                           │
              良知退藏于密，主宰认知主体之进退
              "最大之仁兼涵仁与智"
```

这就是牟宗三的完整哲学体系。它的根基就是：**人有智的直觉**。如果这个根基动摇，整个两层存有论、良知坎陷、道德形上学都会动摇。

## 第五章　学界最尖锐的批评：杨泽波的"三个环节"

杨泽波（复旦大学教授，牟宗三研究专家）是对牟宗三批评最系统、最尖锐的学者之一。他的核心观点：**牟宗三将道德之心创生的存有对象称为"物自身"，源于对康德"智的直觉"概念的误解。**

杨泽波的批评分为三个彼此相连的环节。

### 第一个环节：误解了康德"智的直觉"的概念

杨泽波指出，康德的"智的直觉"有一个最基本的含义，牟宗三从一开始就没有从这个角度进入：

**康德的智的直觉 = "本源的直观"（intuitus originarius）**

- 与"派生的直观"（intuitus derivativus）相对
- 意指：**不需要外部对象刺激，本身就可以提供杂多的直观**
- 人的直观是"派生的"——必须有对象刺激才能产生质料
- 上帝的直观是"本源的"——直觉活动本身就创造对象、提供质料

康德在《纯粹理性批判》中强调：人的认识必须始于直观，直观一方面有时间空间这些形式，另一方面有对象的刺激以提供质料。没有形式，质料得不到整理；没有对象刺激，无法形成质料。

**牟宗三的误解**：牟宗三不是从"本源vs派生"的角度理解智的直觉，而是从"**是否需要范畴（包括时空）**"的角度理解。

牟宗三的逻辑：
1. 人的认识必须借助范畴，受范畴影响，认识一定有所变形，所以只能停留于现象，无法达到物自身
2. 如果可以证明有一种认识不需要范畴，那么它就是智的直觉
3. 中国哲学中，对本心仁体的体认是直接进行的，完全不需要范畴
4. 所以这种不需要范畴的思维方式就是智的直觉
5. 所以人有智的直觉

杨泽波指出，这个逻辑的问题在于：**康德的智的直觉的核心是"本源的"（自己创造对象），而不是"不需要范畴"。** 不需要范畴只是智的直觉的一个特征，不是它的本质。牟宗三把"不需要范畴"当成了智的直觉的本质，这是误解。

杨泽波引用了牟宗三自己的一段回忆来证明这个误解的起源：

> "三十年前，我在西南联大哲学系有一次讲演，讲建立范畴、废除范畴。当时听者事后窃窃私语，范畴如何能废除呢？……我当时亦如通常一样，未能注意及康德随时提到智的直觉，与直觉的知性，我只随康德所主张的时空以及范畴只能应用于经验现象而不能应用于物自身……而宣说此义。现在我细读康德书，知道两种知性，两种直觉的对比之重要……但在神智处，范畴无任何意义，范畴即可废除。假若在人处亦可有此直觉的知性、智的直觉，范畴亦可废除。"

杨泽波说，这段材料的核心就在八个字："**建立范畴，废除范畴**"。牟宗三一生都围绕这个思路——有智的直觉就不需要范畴，不需要范畴就能达到物自身。但这恰恰是从"是否需要范畴"的角度理解智的直觉，而不是从"本源vs派生"的角度。

### 第二个环节：以"自觉"证"觉他"

杨泽波指出，牟宗三讲良知"呈现"有两个方面：

- **自觉**：本心仁体遇事当下表现自己，向人发布命令，告知是非对错。人通过"内觉"能力觉知本心仁体正在呈现。这是**对内部本体的体认**。
- **觉他**：道德之心不甘寂寞，面对外部对象总要呈现自身，将自身的价值和意义影响它们，使其染上道德的色彩，创生道德的存有，使天地万物成为存在。这是**对外部对象的影响**。

杨泽波说，"自觉"和"觉他"缺一不可，前者对象指内，后者对象指外。

**牟宗三的逻辑瑕疵**：直接以"自觉"证"觉他"。

- "自觉"（对本心仁体的体认）确实是直接进行的，不需要借助范畴——从宽泛意义上可以说是一种"直觉"
- 但不能由此证明"觉他"（道德之心影响外部对象、创生存有）的思维方式就是智的直觉，其对象就是物自身

为什么？因为"觉他"的本质是**将道德之心的内容影响外部对象，将自身的价值和意义附加在对象之上**。既然附加了道德内容，对象就已经"染上了道德的色彩"，不再是"物之在其自己"，不能称为"物自身"了。

杨泽波举了一个非常生动的例子：

> 牟宗三强调，人有智的直觉，以智的直觉看此花树，因为不受范畴的影响，所以花树是物自身，是花树之"本来面目"，是其"自尔独化"。
>
> 这里的问题极为严重。按照常规的理解，花树在山中"自开自落"才是其"本来面目"，才是其"自尔独化"，才是物自身。人看到花树就会以自己的道德之心的内容影响它，哪怕这种影响是以道德目的实现的，这时的花树怎么能说是其"本来面目"，怎么能说是其"自尔独化"，怎么能说是物自身呢？

这个批评非常有力：**物自身的本义是"事物之在其自己"，不受主体影响。但道德之心"觉他"恰恰是在影响事物、给事物附加道德价值。被影响了的事物怎么还能叫"物自身"？**

杨泽波提出，道德之心创生的存有对象应该叫"**善相**"（事物染上了道德之相），而不是"物自身"。相应地，两层存有应该是"善相的存有"和"识相的存有"，而不是"物自身的存有"和"现相的存有"。

### 第三个环节：混淆了"范畴之无执"和"化境之无执"

这是杨泽波指出的更深一层的混淆，过去很少有人谈到。

牟宗三讲"无执"有两个意义：

- **范畴之无执**：人的认识必须经由范畴，这是一种"执"（执于范畴）。如果不要范畴，就做到了无执。
- **化境之无执**：牟宗三诠释孟子"大而化之之谓圣"时提出"化境"概念。圣人达到化境后，"大而化之"（把大化掉，大无大相），一切均是自然之自己，没有任何相可见。道德达到一定境界后，会出现"无心为善而成善，无心无德而为德"，外面一点显不出道德样子。这也是"无执"。

**牟宗三的滑转**：以"化境之无执"证明"范畴之无执"。

杨泽波指出：
- 人的境界上升到化境后，确实可以做到"无执"——外面丝毫显不出道德的样子
- 但这与"范畴之无执"不是同一个问题
- 道德之心创生存有，是将道德之心的价值和意义投射到外部对象之上，使其染上道德的色彩
- 既然染上了道德的色彩，即使它是由圣人实现的、毫无造作、混然天成，但对于对象而言，仍然被附加了道德的内容，仍然是一种"执"，而不是"无执"

换句话说：**圣人的"化境"是主体的境界（无心为善），但对象仍然被赋予了道德内容（善相）。不能因为主体达到了化境，就说对象也是"无执"的、是"物自身"。**

牟宗三经常以"无相"（道德而无道德之相）说明道德之心创生的存有对象也是"无相"，进而将其规定为"物自身"。杨泽波说，这是混淆了主体的"无相"和对象的"无相"。

### 杨泽波批评的总结

杨泽波的三个环节构成了一个完整的批评链条：

```
环节1：误解智的直觉的本质
       （把"本源的"误解为"不需要范畴的"）
              ↓
环节2：以"自觉"证"觉他"
       （对本体的直接体认 ≠ 对对象的道德创生）
              ↓
环节3：混淆"范畴之无执"与"化境之无执"
       （主体的化境 ≠ 对象的无执）
              ↓
结论：道德之心创生的对象是"善相"，不是"物自身"
      两层存有应是"善相/识相"，不是"物自身/现象"
```

这个批评非常尖锐，也非常有说服力。但它不是唯一的批评。下面看黄敏从另一个角度的分析。

## 第六章　更深层的困境：黄敏的分析——从认识论到存有论的滑转

黄敏（中南财经政法大学哲学院）从另一个角度分析了牟宗三的困境。她的核心观点：**牟宗三对康德物自身的诠释，关键出自海德格尔转引的一段康德《遗稿》片段；牟宗三的"误读"在于把康德在自然形而上学中讨论的消极限定义的物自身，转化为由价值主体保证的物之在其自己，由此取消了物自身的事实意涵，走向了康德批判的传统形而上学本体论老路。**

### 一、关键文献的来源：海德格尔转引的康德《遗稿》

黄敏做了一个非常重要的文献考证：牟宗三在《智的直觉与中国哲学》《现象与物自身》中反复引用的一段关键文字——

> "物自身之概念与现象之概念间的区别不是客观的，但只是主观的。物自身不是另一个对象，但只是关于同一对象的表象之另一面相。"

——这段文字出自**海德格尔《康德与形而上学疑难》一书转引的康德《遗稿》（Opus Postumum）片段**，而海德格尔的引用又出自E. Adickes的解述，并非康德《遗稿》原文。黄敏翻查了英文和德文版的《遗稿》，均未见到此段文字。

这意味着：牟宗三整个两层存有论的"关键段落"，可能是一个**二次转引、甚至三次转引**的文字，其真实性和准确性都存疑。

### 二、牟宗三对物自身的两方面转化

黄敏指出，牟宗三对康德物自身义的转化集中于两点：

**第一，取消物自身的事实意涵，将物自身变为积极意义的"物之在其自己"。**

- 康德的物自身：主要是消极意义的限制概念，有事实意涵（事物的客观原样，虽然不可知）
- 牟宗三的物自身：取消了事实意涵，变成了由价值主体（良知）保证的"物之在其自己"，有积极意义
- 后果：一切事物在存有论中丧失了现象与物自身的严格界限

**第二，突出物自身是主体也是本体，物自身用来指人时，被赋予儒学道德价值意涵。**

- 康德：人作为物自身是自由主体，但这是实践理性的"设准"，不是"直觉"到的对象
- 牟宗三：人作为物自身是"自由无限心"（良知），可以在道德实践中"呈现"，可以被智的直觉把握
- 后果：自由无限心通过"一心开二门"实现两层存有的转化

### 三、根本困境：走向了康德批判的传统形而上学

黄敏的核心判断：

> 取消物自身的消极限定意义，由认识论转向存有论的物自身，实际上走向了另一种康德批判的传统形而上学本体论路数中。

康德的整个"批判哲学"就是要反对传统形而上学的僭越——传统形而上学试图用理性认识本体（物自身、上帝、灵魂、自由），但这超出了理性的能力，导致"先验幻相"。康德的方案是：把本体界留给实践理性（道德、信仰），但不允许理论理性去"认识"本体。

牟宗三的做法恰恰是：**通过肯定人有智的直觉，把本体界（物自身、自由无限心）变成了可以"直觉"、可以"认识"的对象，从而建立了一种"道德的形上学"——本体界的存有论。** 这在黄敏看来，正是康德批判哲学所要反对的传统形而上学老路。

黄敏引用阿利森（Allison）的观点：康德在实践理性中给予人类一个通往理知世界的入口，但这个入口的优先性"**必须在价值论的意义上而不是在存在论的意义上来诠释**……并不存在任何入口（认识的或其他类型的），通往一个存在论上更高阶的存在者"。

换句话说：康德允许在实践理性中"思想"自由、上帝，但不允许在存有论上"建构"一个本体界。牟宗三恰恰做了后者——把价值意味的物自身滑转为存有论意味的本体。

### 四、黄敏的公允之处

黄敏的分析不是简单否定牟宗三。她承认：

1. 牟宗三对物自身"价值意味"的理解，是康德实践理性运用的题中之义——康德在《实践理性批判》中确实把人作为自由主体赋予了物自身意涵
2. 牟宗三的"误读"可以说是一种"**有意的误读诞生了一种积极的创造**"——他通过改造康德，建立了中国哲学现代转化的体系
3. 但必须看到：这种创造偏离了康德批判哲学的本意，走向了传统形而上学本体论

这是一个非常公允的判断：牟宗三不是"不懂康德"，而是"有意地改造康德"，但这种改造有其代价——走向了康德批判的老路。

## 第七章　公允的判断：是误解还是创造？

现在把所有材料放在一起，给出一个公允的判断。

### 一、牟宗三确实"偏离"了康德的本意

从严格的康德研究角度看，牟宗三确实偏离了康德：

1. **智的直觉的本质**：康德的智的直觉核心是"本源的"（自己创造对象），牟宗三把它理解为"不需要范畴的"。这是杨泽波指出的关键误解。
2. **物自身的意义**：康德的物自身主要是消极意义的限制概念，有事实意涵；牟宗三把它变成了积极意义的、由价值主体保证的"物之在其自己"，取消了事实意涵。
3. **人有没有智的直觉**：康德明确说人没有，只有上帝可能有；牟宗三说人有（良知就是）。
4. **本体界可否"认识"**：康德说本体界不可认识，只能"思想"；牟宗三说可以通过智的直觉"直觉"本体，建立"无执的存有论"。
5. **走向了传统形而上学**：黄敏指出，牟宗三的"道德形上学"在某种意义上走向了康德批判哲学所要反对的传统形而上学本体论老路。

从这些角度看，说牟宗三"误解了康德"是有充分依据的。

### 二、但牟宗三不是"不懂康德"，而是"创造性地改造康德"

另一方面，牟宗三对康德的理解非常深入——他花了几十年研究康德，翻译了《纯粹理性批判》（《康德纯粹理性之批判》），对康德的细节非常熟悉。他的"偏离"不是因为不懂，而是因为**他有自己的哲学目标**：

1. **他要为中国哲学争取"合法性"**：在康德的框架里，中国哲学（儒释道）讲的"本心""良知""般若""玄智"都没有位置——因为康德不承认人有智的直觉。牟宗三要证明：中国哲学讲的这些东西恰恰就是智的直觉，中国哲学比康德更进一步。
2. **他要建立"道德的形上学"**：康德的形上学是"道德的神学"（moral theology）——道德需要上帝存在作为设准。牟宗三要建立"道德的形上学"（moral metaphysics）——道德本身就可以形上学，不需要上帝，因为良知就是本体、就是智的直觉。
3. **他要回应现代性危机**：如果人没有智的直觉、物自身不可知，那么价值理性就没有本体论根基，工具理性就会吞没一切，人就会被关进铁笼。牟宗三要通过肯定人有智的直觉，为价值理性找到本体论根基，为人的"自作主宰"找到根据。

从这些角度看，牟宗三的"偏离"是一种**创造性的诠释**——他用康德的概念框架，讲中国哲学的内容，回应现代性的问题。这不是简单的"误解"，而是"六经注我"式的哲学创造。

### 三、最公允的说法

最公允的说法是：

> **牟宗三在"照着康德讲"的层面有误解（智的直觉的本质、物自身的事实意涵），但在"接着中国哲学讲"的层面有创造（道德形上学、两层存有论、良知坎陷）。他的误解和创造是一体两面的——正因为他要创造中国哲学的现代体系，所以他必须"误读"康德，把康德的极限概念变成中国哲学的核心概念。**

这就像王阳明"误解"了朱熹，但创造了心学；像海德格尔"误读"了康德，但创造了基础存在论。哲学史上的大创造往往伴随着"创造性的误读"。

但杨泽波、黄敏的批评也不是没有意义——他们提醒我们：
- 不能把牟宗三的"物自身"等同于康德的"物自身"
- 不能把牟宗三的"智的直觉"等同于康德的"智的直觉"
- 牟宗三的体系有其内在的困难（善相vs物自身、存有论的僭越）
- 评价牟宗三应该看他"接着中国哲学讲"的创造性，而不是看他"照着康德讲"的准确性

### 四、一个关键的区分：两种"智的直觉"

卢雪崑（新亚书院教授，辩护牟宗三）提出了一个重要的区分：

> 儒家就本心明觉而言的"智的直觉"，并不是康德就认识机能而言的知性的直观能力，"故此必须与康德所言的'理智的直观'区别开来。明乎此，则可知，牟先生依中国哲学而论的'人可有智的直觉'与康德依批判而提出的'人不能有理智的直观'是根本不同的哲学问题。"

这个区分很重要：
- **康德的"智的直觉"**：认识论概念——一种认识能力（本源的直观，自己创造对象）
- **牟宗三的"智的直觉"**：实践哲学/形上学概念——一种道德实践中的本体呈现（良知朗现，直接把握本体）

两者虽然用了同一个词，但问题域不同。康德问的是"人能不能认识物自身"，牟宗三问的是"人能不能在道德实践中呈现本体"。这两个问题的答案可以不同——人在认识论上不能认识物自身（康德对），但人在道德实践中可以呈现本体（牟宗三对）。

如果接受这个区分，那么牟宗三和康德的"分歧"就没有那么大——他们在不同的层面讲不同的问题。牟宗三的贡献是把康德只在实践理性中"设准"的自由，变成了在道德实践中"呈现"的本体，这确实是中国哲学对康德的"调适上遂"。

但杨泽波会反驳：即使接受这个区分，牟宗三把道德之心创生的外部对象称为"物自身"仍然是问题——因为那是"善相"，不是"物之在其自己"。

这个争论至今没有定论。

## 第八章　这个争论的真正意义：和现代性危机的关系

这个看似纯粹学术的争论，实际上有非常深刻的现实意义。它直接关系到我们之前讲的"现代性危机"和"理性铁笼"。

### 一、如果人没有智的直觉（康德立场）

- 物自身不可知，本体界是"设准"而非"呈现"
- 价值理性没有本体论根基——道德法则是"理性的事实"，但无法被"直觉"到本体
- 工具理性可以无限膨胀，因为没有一个"本体"来限制它、主宰它
- 人是有限的，无法"上通本体界"，只能在现象界做工具理性的计算
- **结果：理性铁笼难以打破，现代性危机难以解决**——这正是韦伯的悲观

### 二、如果人有智的直觉（牟宗三立场）

- 物自身可知（在良知呈现中），本体界是"呈现"而非"设准"
- 价值理性有本体论根基——良知就是本体，就是智的直觉，可以在道德实践中朗现
- 工具理性可以被价值理性主宰——良知坎陷出知性，但良知始终是主人，可以主宰认知主体之进退
- 人"虽有限而可无限"——可以通过道德实践上通本体界，与天地万物为一体
- **结果：理性铁笼可以打破，现代性危机可以解决**——这正是新儒家的乐观

### 三、争论的核心：价值理性有没有"本体论根基"

这个争论的核心，实际上是一个非常古老的问题：**价值、道德、意义，有没有一个客观的、本体论的根基？还是说，它们只是人的"约定""建构""主观选择"？**

- 康德的立场：价值有"实践理性"的根基，但没有"理论理性"的本体论根基——物自身不可知，自由是设准
- 牟宗三的立场：价值有"道德形上学"的本体论根基——良知就是本体，物自身可知（在实践中）
- 韦伯的立场：价值没有公共的本体论根基——祛魅之后，价值多神，每个人自己选择
- 虚无主义的立场：价值根本没有根基——一切都是权力意志、社会建构

新儒家的全部努力，就是要在"祛魅"的现代世界里，为价值重新找到一个本体论根基——这个根基就是"良知""本心仁体""自由无限心"，就是"智的直觉"。

如果牟宗三成功了，那么现代性危机就有解——人可以通过道德实践"呈现"本体，主宰工具理性，打破铁笼。
如果牟宗三失败了（如杨泽波、黄敏的批评），那么我们就回到了康德和韦伯的困境——价值没有本体论根基，人只能在"诸神之争"中孤独抉择，铁笼难以打破。

### 四、这个争论对我们每个人的意义

这个争论不只是哲学家的事。它关系到我们每个人的生活：

- 你相不相信，在你的内心深处，有一个"良知"可以直接呈现，告诉你什么是对、什么是错？
- 你相不相信，道德不只是"社会约定""文化建构""功利计算"，而是有一个本体论的根基？
- 你相不相信，人虽然有限，但可以通过道德实践"上通"某种超越的东西，获得意义和力量？
- 你相不相信，在一个被工具理性、效率计算、消费主义支配的世界里，人仍然可以"自作主宰"，不被关进铁笼？

如果你相信，你就站在牟宗三一边（虽然你可能不接受他的全部论证）。
如果你不相信，你就站在康德、韦伯、甚至虚无主义一边。

这不是一个可以"证明"的问题——它本身就是一个"实践"的问题，需要你在生活中去"体证"。正如牟宗三所说，智的直觉不是"理论"可以证明的，它是在道德实践中"呈现"的。

---

## 第九章　结语：一个没有定论但极其重要的争论

这个争论至今没有定论。

- 新儒家阵营（牟宗三、唐君毅、徐复观、李明辉、卢雪崑）坚持：人有智的直觉，道德形上学可能，这是中国哲学对世界哲学的贡献
- 批评阵营（杨泽波、邓晓芒、黄敏、陈迎年）指出：牟宗三误解了康德的智的直觉，物自身应该保留事实意涵，道德之心创生的对象是"善相"不是"物自身"，牟宗三走向了康德批判的传统形而上学老路
- 中间立场：牟宗三在"照着康德讲"的层面有误解，但在"接着中国哲学讲"的层面有创造；他的"智的直觉"和康德的"智的直觉"是不同问题域的概念，不必强求一致

但无论站在哪一边，都必须承认：

1. **这是20世纪中国哲学最深刻、最有原创性的理论尝试之一**——牟宗三试图用康德的概念框架，把中国哲学（儒释道）的核心洞见讲清楚，建立一个能回应现代性危机的现代哲学体系。这个尝试本身就极其了不起。

2. **这个争论触及了哲学最根本的问题**——价值有没有本体论根基？人能不能"上通"本体？道德是"设准"还是"呈现"？这些问题从柏拉图、康德到今天，一直没有定论，但每一次严肃的争论都在推进人类的自我理解。

3. **这个争论有深刻的现实意义**——它关系到我们如何面对现代性危机、如何在工具理性膨胀的世界里守住价值、如何做一个"自作主宰"的人。它不是书斋里的文字游戏，而是对"人应该如何活"这个根本问题的严肃回答。

4. **牟宗三的最大贡献可能不是"答案"，而是"问题"**——他让我们重新思考：在一个祛魅的、理性化的、工具理性膨胀的现代世界里，中国哲学（乃至一切非西方哲学）有没有自己的声音？能不能为人类的未来提供不同于西方现代性的另一种可能？

这个问题，比"人有没有智的直觉"这个具体答案，更重要。

## 附录：关键概念与原文索引

### 康德关键原文

1. **现象与物自身的区分**："对象是以双重意义而观之，而作为现象与作为物自身。"（《纯粹理性批判》BXXVII）
2. **智的直觉的定义**："一种直观，它本身就使对象的存在被给予……这种直观似乎只能属于原始存在者。"（B72）
3. **人没有智的直觉**："我们的知性是一种推论的能力，它必须通过概念……而一种直觉的知性，我们无法证明它属于任何存在者。"
4. **物自身的消极意义**："本体的概念是一个极限概念……它只在消极的使用中是不可缺少的。"
5. **实践理性中的自由**："同一个意志，被设想为现象而遵循自然法则，与被设想为物自身而为自由，并不矛盾。"

### 牟宗三关键原文

1. **人有智的直觉**："吾人必须依中国的传统肯定'人虽有限而可无限'以及'人可有智的直觉'这两义。"（《现象与物自身》序）
2. **物自身是价值概念**："'物自身'不是一个认知上所认知的对象之'事实上的原样'之事实概念，而是一个高度价值意味的概念。"
3. **良知是呈现**："良知是呈现，不是设准。"（熊十力语，牟宗三继承）
4. **两层存有论**："对无限心（智心）而言，为物自身；对认识心（识心、有限心）而言，为现象。由前者，成无执的（本体界的）存有论，由后者，成执的（现象界的）存有论。"
5. **良知坎陷**："知体明觉之自觉地自我坎陷即是其自觉地从无执转为有执。自我坎陷就是执。"
6. **最大之仁兼涵仁与智**："此道德主体，须暂忘其为道德的主体……然后再施其价值判断……此时人之道德主体，遂升进为能主宰其自身之进退，并主宰认识的主体自身之进退……此即所谓'最大之仁兼涵仁与智'。"（1958宣言第八节）

### 杨泽波批评关键原文

1. **智的直觉的本义**："智的直觉原指'本源的直观'，意即不需要外部对象刺激即可形成质料的直观，牟宗三则将其理解为一种不需要时空和范畴的思维方式。"
2. **花树之喻**："花树在山中'自开自落'才是其'本来面目'……人看到花树就会以自己的道德之心的内容影响它……这时的花树怎么能说是其'本来面目'，怎么能说是物自身呢？"
3. **善相**："天地万物受到道德之心的影响便有了道德之相，这种道德之相即为'善相'……两层存有应是'善相'的存有和'识相'的存有，而不应是'物自身'的存有和'现相'的存有。"

### 黄敏分析关键原文

1. **关键文献来源**：牟宗三反复引用的"物自身之概念与现象之概念间的区别不是客观的，但只是主观的"出自海德格尔转引的康德《遗稿》片段，而海德格尔的引用又出自Adickes的解述，并非康德原文。
2. **两方面转化**："第一，取消物自身的事实意涵，将物自身变为积极意义的物之在其自己……第二，突出物自身是主体也是本体，物自身用来指人时，被赋予儒学道德价值意涵。"
3. **根本困境**："取消物自身的消极限定意义，由认识论转向存有论的物自身，实际上走向了另一种康德批判的传统形而上学本体论路数中。"
4. **公允判断**："也可以说一种有意的误读诞生了一种积极的创造。"
