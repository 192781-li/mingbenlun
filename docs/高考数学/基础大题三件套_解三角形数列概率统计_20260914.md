# 第一部分：解三角形

## 1.1 核心公式（精确，不遗漏条件）

### 1.1.1 正弦定理
- 内容：在△ABC中，`a/sinA = b/sinB = c/sinC = 2R`（R是外接圆半径）
- 变形（最常用）：
  - `a = 2R sinA，b = 2R sinB，c = 2R sinC`
  - `sinA = a/(2R)`
  - **边角互化**：a:b:c = sinA:sinB:sinC
- 适用：已知"两角一边"或"两边一对角"

### 1.1.2 余弦定理
- 内容：
  - `a² = b² + c² - 2bc·cosA`
  - `b² = a² + c² - 2ac·cosB`
  - `c² = a² + b² - 2ab·cosC`
- 变形（求角）：
  - `cosA = (b²+c²-a²)/(2bc)`
- 适用：已知"三边求角"或"两边夹一角"
- **记忆法**：求哪条边，对面是哪个角，那条边平方=另两边平方和 - 2倍另两边乘夹角余弦

### 1.1.3 三角形面积公式
- `S = (1/2)ab·sinC = (1/2)bc·sinA = (1/2)ac·sinB`
- 口诀：**两边乘起来，乘夹角正弦，除以2**
- 底高公式：S=(1/2)×底×高

### 1.1.4 三角形内角关系（隐藏条件，必用）
- `A+B+C = π（180°）`
- 推论：sin(A+B)=sinC，cos(A+B)=-cosC
- 大边对大角：a>b ⟺ A>B ⟺ sinA>sinB
- 两边之和大于第三边

### 1.1.5 常用结论
- 直角三角形：勾股定理，sin=对边/斜边
- 等边三角形：三边等，三角都是60°
- 等腰三角形：两底角相等

## 1.2 题型分类与解题模板（5类）

### 解1：已知两角一边（正弦定理）
**识别**：给两个角+任意一条边
**步骤**：
1. 用A+B+C=π求第三个角
2. 正弦定理 a/sinA=b/sinB 列比例
3. 求未知边

**例题**：△ABC中，A=45°，B=60°，a=2，求b。
- 定题型：两角一边→正弦定理
- 步骤：C=180°-45°-60°=75°；由a/sinA=b/sinB → 2/sin45°=b/sin60° → b=2·sin60°/sin45°=2·(√3/2)/(√2/2)=√6
- 答案：b=√6

### 解2：已知两边一夹角（余弦定理）
**识别**：给两条边和它们夹的角
**步骤**：
1. 余弦定理直接求第三边
2. 需要角再用余弦定理/正弦定理

**例题**：△ABC中，b=3，c=4，A=60°，求a。
- 定题型：两边夹一角→余弦定理
- 步骤：a²=b²+c²-2bc·cosA=9+16-2·3·4·(1/2)=25-12=13 → a=√13
- 答案：a=√13

### 解3：已知三边求角（余弦定理变形）
**识别**：三条边都给，求某个角
**步骤**：
1. cosA=(b²+c²-a²)/(2bc)
2. 由cos值定角（背特殊角余弦）

**例题**：△ABC中，a=√7，b=2，c=3，求A。
- 步骤：cosA=(b²+c²-a²)/(2bc)=(4+9-7)/(2·2·3)=6/12=1/2 → A=60°
- 答案：A=60°

### 解4：求面积
**识别**：求三角形面积
**步骤**：
1. 找到"两边+夹角"，用S=(1/2)ab sinC
2. 若夹角未知，先用正/余弦定理求出
3. 代入计算

**例题**：△ABC中，a=4，b=6，C=30°，求面积。
- 步骤：S=(1/2)ab sinC=(1/2)·4·6·sin30°=(1/2)·24·(1/2)=6
- 答案：S=6

### 解5：边角混合/恒等变换综合（大题第一问高频）
**识别**：条件里既有边又有角的关系式
**核心动作：统一**——要么全化成角（用正弦定理 a=2RsinA），要么全化成边（用余弦定理/正弦定理）
**步骤**：
1. 观察式子，决定"角化边"还是"边化角"
2. 出现sinA、sinB齐次式（次数相同）→ 用正弦定理换成a、b
3. 出现cos和边的平方 → 用余弦定理
4. 化简后求解

**例题**：△ABC中，a·cosB = b·cosA，判断三角形形状。
- 定题型：边角混合→边化角
- 步骤：由正弦定理 a=2RsinA，b=2RsinB，代入：2RsinA·cosB=2RsinB·cosA → sinAcosB=sinBcosA → sinAcosB-sinBcosA=0 → sin(A-B)=0 → A=B（三角形内角范围内）→ 等腰三角形
- 答案：等腰三角形

## 1.3 解三角形易错点（8条）
1. 正弦定理适用"两边一对角"时可能有**两解**（锐角/钝角），用大边对大角判断
2. cosA公式分子是(b²+c²-a²)，**被求角对的边是减项**，别减反
3. 面积公式别忘1/2和sin
4. A+B+C=π是隐藏条件，sin(A+B)=sinC（不是-sinC）
5. 特殊角三角函数值要背熟：sin30=1/2，sin45=√2/2，sin60=√3/2，cos同理
6. 边角互化必须是**齐次式**（每边次数相同）才能用正弦定理
7. 求角时cos为负→角是钝角，别默认锐角
8. 最后结果检查"两边之和大于第三边"

# 第二部分：数列

## 2.1 核心公式（精确，不遗漏条件）

### 2.1.1 等差数列
- 定义：aₙ₊₁ - aₙ = d（公差，常数）
- 通项：`aₙ = a₁ + (n-1)d`
- 推广：aₙ = aₘ + (n-m)d
- 中项：若a,b,c成等差，则 2b=a+c（b是等差中项）
- 前n项和：
  - `Sₙ = n(a₁+aₙ)/2`
  - `Sₙ = na₁ + n(n-1)d/2`
- 重要性质：
  - m+n=p+q → aₘ+aₙ=aₚ+a_q
  - Sₙ, S₂ₙ-Sₙ, S₃ₙ-S₂ₙ 仍成等差

### 2.1.2 等比数列
- 定义：aₙ₊₁/aₙ = q（公比，q≠0常数）
- 通项：`aₙ = a₁·qⁿ⁻¹`
- 中项：若a,b,c成等比，则 b²=ac
- 前n项和：
  - **q=1时**：Sₙ = na₁（特殊情况，必讨论！）
  - **q≠1时**：`Sₙ = a₁(1-qⁿ)/(1-q) = a₁(qⁿ-1)/(q-1)`
- 重要性质：m+n=p+q → aₘ·aₙ=aₚ·a_q

### 2.1.3 aₙ与Sₙ的关系（万能桥梁，必背）
- `aₙ = Sₙ - Sₙ₋₁（n≥2）`
- `a₁ = S₁（n=1时单独算！）`
- **铁律：用Sₙ求aₙ，必须分n=1和n≥2讨论，最后验证能否合并**

### 2.1.4 求和六法（方法论核心）
1. **公式法**：等差/等比直接套求和公式
2. **错位相减法**：等差×等比型数列（如aₙ=n·2ⁿ）
3. **裂项相消法**：能拆成两项之差（如1/[n(n+1)]=1/n-1/(n+1)）
4. **分组求和法**：拆成几个可求和的部分分别求和
5. **倒序相加法**：首尾对称（等差求和公式的来源）
6. **并项求和法**：相邻两项结合（含(-1)ⁿ类）

---

## 2.2 题型分类与解题模板（6类）

### 数1：基本量计算（知三求二）
**识别**：给a₁、d/q、n、aₙ、Sₙ中的几个，求其余
**步骤**：
1. 判定等差还是等比
2. 通项+求和公式列方程
3. 解方程组

**例题**：等差数列{aₙ}中，a₂=5，a₅=14，求a₁和d。
- 步骤：a₂=a₁+d=5；a₅=a₁+4d=14；两式相减3d=9→d=3，a₁=2
- 答案：a₁=2，d=3

### 数2：求通项公式（大题第一问核心）
**方法A：公式法**——判定等差/等比直接写
**方法B：累加法**——aₙ₊₁-aₙ=f(n)型
  - aₙ=a₁+Σ（从k=1到n-1）f(k)
**方法C：累乘法**——aₙ₊₁/aₙ=f(n)型
  - aₙ=a₁·∏f(k)
**方法D：Sₙ法**——给Sₙ表达式
  - n=1时a₁=S₁；n≥2时aₙ=Sₙ-Sₙ₋₁；验证n=1是否满足n≥2的式子

**例题**：已知数列{aₙ}前n项和Sₙ=n²+n，求aₙ。
- 定题型：给Sₙ求aₙ
- 步骤：n=1时a₁=S₁=2；n≥2时aₙ=Sₙ-Sₙ₋₁=(n²+n)-[(n-1)²+(n-1)]=n²+n-(n²-n)=2n；验证n=1时2×1=2=a₁ ✓，可合并
- 答案：aₙ=2n（是等差数列）
- **易错**：不验证n=1就下结论，是数列第一大易错点

### 数3：等差等比判定与证明
**识别**：证明{aₙ}是等差/等比数列
**步骤**：
- 证等差：算 aₙ₊₁-aₙ，证明它是与n无关的常数
- 证等比：算 aₙ₊₁/aₙ，证明它是与n无关的常数（且aₙ≠0）

### 数4：求和——裂项相消（最高频考法）
**识别**：通项是分式，分母是两个相差常数的式子乘积
**常见裂项**（背下来）：
- 1/[n(n+1)] = 1/n - 1/(n+1)
- 1/[(2n-1)(2n+1)] = (1/2)[1/(2n-1) - 1/(2n+1)]
**步骤**：
1. 把通项裂成两项之差
2. 逐项写出，中间项全部抵消
3. 只剩首尾，计算结果

**例题**：求 1/(1·2)+1/(2·3)+…+1/[n(n+1)]
- 步骤：原式=(1-1/2)+(1/2-1/3)+…+(1/n-1/(n+1))=1-1/(n+1)=n/(n+1)
- 答案：n/(n+1)

### 数5：求和——错位相减（等差×等比型）
**识别**：通项 = 等差数列 × 等比数列（如aₙ=(2n-1)·(1/2)ⁿ）
**步骤**：
1. 写出Sₙ
2. 两边乘公比q，得qSₙ，**错位对齐一行**
3. 两式相减，中间成等比数列
4. 用等比求和公式算中间部分
5. 整理得Sₙ

### 数6：数列性质/最值
- 等差数列前n项和Sₙ是关于n的二次函数（无常数项），最值看开口和对称轴
- aₙ正负变号处，Sₙ取最值

## 2.3 数列易错点（10条）
1. **用Sₙ求aₙ必须讨论n=1**（a₁=S₁），并验证能否合并
2. 等比求和**必须分q=1和q≠1**，q=1时Sₙ=na₁
3. 等比数列公比q≠0，等比数列各项不为0
4. 通项aₙ=a₁+(n-1)d是(n-1)不是n
5. 裂项时注意系数，1/[(2n-1)(2n+1)]裂出来要乘1/2
6. 错位相减后是(1-q)Sₙ，最后要除以(1-q)
7. 下标运算：aₙ₋₁的下标n-1，代入时整体替换别错
8. 证明等比要说明aₙ≠0
9. n必须是正整数，求最值时n取整数
10. 求和结果代n=1验证（应等于a₁）

# 第三部分：概率统计（文科/新高考基础难度）

## 3.1 核心公式（精确，不遗漏条件）

### 3.1.1 概率基础
- 古典概型：`P(A) = A包含的基本事件数 / 总的基本事件数`（每个基本事件等可能）
- 概率范围：0≤P(A)≤1
- 对立事件：`P(A) + P(Ā) = 1`，即 P(Ā)=1-P(A)
- **"至少一个"用对立事件**：P(至少一个)=1-P(全不)
- 互斥事件：P(A∪B)=P(A)+P(B)（不能同时发生）

### 3.1.2 排列组合基础（数基本事件数用）
- 分类加法：做一件事有几类办法，各类方法数相加
- 分步乘法：做一件事分几步，每步方法数相乘
- 排列Aₙᵐ=n!/(n-m)!（有顺序）
- 组合Cₙᵐ=n!/[m!(n-m)!]（无顺序），Cₙᵐ=Cₙⁿ⁻ᵐ
- **判断排列还是组合：交换两个元素顺序，结果变了就是排列，没变就是组合**

### 3.1.3 统计基础
- 平均数（均值）：x̄=(x₁+x₂+…+xₙ)/n
- 中位数：排序后中间的数（偶数个取中间两个平均）
- 众数：出现次数最多的数
- 方差：`s² = (1/n)Σ(xᵢ-x̄)²`（衡量波动，越小越稳定）
- 标准差：s=√(s²)

### 3.1.4 统计图表
- 频率分布直方图：**小矩形面积=频率**，所有面积之和=1；纵轴是"频率/组距"
- 频率=频数/总数
- 茎叶图：保留原始数据，看中位数/分布

### 3.1.5 随机变量与分布列（新高考/理科要求，文科了解）
- 分布列：列出X所有取值及对应概率，**所有概率之和=1**
- 期望（均值）：`E(X) = Σ xᵢpᵢ`
- 方差：`D(X) = Σ [xᵢ-E(X)]²pᵢ`
- 性质：E(aX+b)=aE(X)+b；D(aX+b)=a²D(X)
- 二项分布X~B(n,p)：E(X)=np，D(X)=np(1-p)

## 3.2 题型分类与解题模板（6类）

### 概1：古典概型求概率（选择/大题第一问）
**步骤**：
1. 判断是否等可能（古典概型前提）
2. 数总基本事件数N（用列举法/排列组合，**不重不漏**）
3. 数事件A包含的事件数n
4. P(A)=n/N，化最简分数

**例题**：从1,2,3,4中任取2个不同的数，求两数之和为偶数的概率。
- 步骤：总取法C₄²=6种：(1,2)(1,3)(1,4)(2,3)(2,4)(3,4)；和为偶数需同奇偶：(1,3)(2,4)共2种；P=2/6=1/3
- 答案：1/3
- **易错**：列举要有序（固定第一个，配第二个），别漏别重

### 概2：对立事件（"至少"问题）
**步骤**：
1. "至少一个"→ 算对立事件"一个都没有"
2. P(至少一个)=1-P(全不)

**例题**：3道选择题每题4选项随机猜，求至少猜对1题的概率。
- 步骤：每题猜错概率3/4，三题全错(3/4)³=27/64；P(至少对1题)=1-27/64=37/64
- 答案：37/64

### 概3：统计图表分析
**步骤**：
1. 读图：横轴、纵轴、单位、标题
2. 直方图：面积=频率，频率×总数=频数
3. 求均值/中位数按定义算

**例题**：频率分布直方图中某组[60,70)的"频率/组距"=0.02，组距10，样本容量100，求该组频数。
- 步骤：频率=0.02×10=0.2；频数=100×0.2=20
- 答案：20

### 概4：数字特征计算（均值/方差）
**步骤**：
1. 均值按公式求和除以n
2. 方差：先求均值，再算每个偏差平方的平均
3. 比较稳定性：方差小的更稳定

### 概5：分布列与期望（大题）
**步骤**：
1. 确定X的所有可能取值
2. 逐个求每个取值的概率（用古典概型/独立事件）
3. 列分布列表，**验证概率和=1**
4. E(X)=Σxᵢpᵢ

**例题**：袋中2红1白球，不放回取2个，设取到红球数X，求E(X)。
- 步骤：X可取0,1,2。
  - P(X=0)=取到0红（即2白），但只有1白球，不可能→0
  - P(X=1)=C₂¹C₁¹/C₃²=2/3
  - P(X=2)=C₂²/C₃²=1/3
  - 检验：0+2/3+1/3=1 ✓
  - E(X)=0×0+1×(2/3)+2×(1/3)=4/3
- 答案：E(X)=4/3

### 概6：回归/独立性检验基础（了解）
- 线性回归方程 ŷ=bx+a 必过样本中心点(x̄,ȳ)
- 相关系数r：|r|越接近1线性相关越强
- 独立性检验K²：K²越大越有把握认为两变量有关（套公式算，对照临界值表）

## 3.3 概率统计易错点（10条）
1. 古典概型前提：每个基本事件**等可能**
2. 列举基本事件不重不漏，用固定顺序法
3. "至少"用对立，别硬分类
4. 分布列概率之和必须=1（写完必验证）
5. 直方图纵轴是"频率/组距"，面积才是频率
6. 方差带平方，单位是原单位平方；标准差才和原数据同单位
7. 中位数要先排序，偶数个取中间两数平均
8. 排列看顺序、组合不看顺序，先判断再套公式
9. 不放回 vs 有放回：不放回总数递减，有放回总数不变
10. 概率结果化最简分数

```
11. 期望：E(X)=Σxᵢpᵢ；分布列概率和=1
12. 直方图：面积=频率，频数=频率×总数
```
