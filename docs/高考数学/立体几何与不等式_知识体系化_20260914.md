# 第一部分：立体几何

## 1.1 核心公式（精确，不遗漏条件）

### 1.1.1 空间几何体的表面积与体积（必背）

| 几何体 | 体积公式 | 表面积/侧面积 |
|--------|---------|--------------|
| 柱体（棱柱/圆柱） | V = S底·h | 圆柱侧=2πrh，全=2πr²+2πrh |
| 锥体（棱锥/圆锥） | V = (1/3)S底·h | 圆锥侧=πrl（l母线），全=πr²+πrl |
| 台体 | V=(1/3)h(S上+S下+√(S上S下)) | —— |
| 球 | V = (4/3)πR³ | S = 4πR² |

- **柱体体积=底面积×高；锥体体积=柱体的1/3**（同底同高时）
- 圆柱侧面展开是矩形：长=底面周长2πr，宽=高h
- 圆锥侧面展开是扇形：母线l=√(r²+h²)

### 1.1.2 三视图
- 正视图（从前看）、侧视图（从左看）、俯视图（从上看）
- **长对正、高平齐、宽相等**
- 由三视图还原几何体：先看俯视图定底面，再看正/侧视图定高
- 看得见的棱画实线，看不见的画虚线

### 1.1.3 点线面位置关系公理（证明题根基）
- 公理：不共线三点确定一个平面；两平面交于一条直线
- **线面平行**判定：平面外一条直线与平面内一条直线平行 → 线面平行
  - （线线平行⇒线面平行）
- **线面垂直**判定：一条直线垂直于平面内**两条相交直线** → 线面垂直
- **面面平行**判定：一个平面内两条相交直线都平行于另一平面 → 面面平行
- **面面垂直**判定：一个平面过另一个平面的一条垂线 → 面面垂直
- 性质定理：
  - 线面平行⇒该直线平行于交线
  - 线面垂直⇒垂直于平面内所有直线
  - 两平面垂直⇒一个平面内垂直于交线的直线垂直于另一平面

### 1.1.4 空间向量法（建系，大题通用武器）
- 建系原则：找三条两两垂直的棱作x,y,z轴，交点为原点
- 方向向量：直线方向向量 a；平面法向量 n
- **线面平行**：直线方向向量⊥平面法向量（a·n=0），且线不在面内
- **线面垂直**：直线方向向量∥平面法向量（a=λn）
- **面面平行**：两平面法向量平行（n₁∥n₂）
- **面面垂直**：两平面法向量垂直（n₁·n₂=0）
- 求平面法向量：设n=(x,y,z)，与面内两个不共线向量分别点乘=0，解方程组（令其中一个坐标为1）
- 空间角（第二问，了解）：
  - 异面直线角：cosθ=|a·b|/(|a||b|)
  - 线面角：sinθ=|a·n|/(|a||n|)
  - 二面角：cosθ=±(n₁·n₂)/(|n₁||n₂|)，符号看图形

## 1.2 题型分类与解题模板（6类，前4类必拿）

### 立1：三视图求体积/表面积（小题必拿）
**步骤**：
1. 三视图还原几何体（柱/锥/球/组合体）
2. 从三视图读底面尺寸和高
3. 套体积/表面积公式

**例题**：某几何体三视图都是边长为2的正方形（正视图含一条对角线），该几何体是棱长2的正方体切去一半的三棱柱，求体积。
- 步骤（以正方体为例）：若为棱长2的正方体，V=2³=8
- 答案：正方体体积8（具体按还原图形，方法是先还原再套公式）
- **易错**：俯视图定底面面积，正视图定高；注意"切去""挖空"部分要扣除

### 立2：几何体体积表面积计算（小题）
**步骤**：
1. 判断几何体类型
2. 找底面、高、半径、母线
3. 套公式，注意锥体的1/3

**例题**：圆锥底面半径r=3，高h=4，求体积和侧面积。
- 步骤：母线l=√(r²+h²)=√(9+16)=5；V=(1/3)πr²h=(1/3)π·9·4=12π；侧面积=πrl=15π
- 答案：V=12π，侧面积=15π
- **易错**：圆锥侧面积用母线l不是高h；体积别忘1/3

### 立3：线面/面面平行证明（大题第一问，几何法）
**证明线面平行的两条路**：
- 路径A（找平行线）：在平面内找一条直线，证明它和已知直线平行（常用中位线、平行四边形）
- 路径B（建系）：方向向量·法向量=0
**步骤（几何法）**：
1. 取中点/连辅助线，构造中位线或平行四边形
2. 由中位线性质得线线平行
3. 一线在面内、一线在面外，用判定定理得线面平行

**例题**：在四棱锥P-ABCD中，底面ABCD是平行四边形，E是PA中点，求证：CE∥平面PBD（典型中位线题）。
- 思路：取PD中点（或PB中点），连辅助线，构造中位线，证CE与平面内某线平行
- 模板：取……中点M，连接……，由三角形中位线，EM∥AD且EM=AD/2，又BC∥AD……得平行四边形，从而CE∥面内线，CE⊄面PBD ⇒ CE∥平面PBD
- **易错**：必须交代"该直线不在平面内"（CE⊄平面PBD），判定定理条件要写全

### 立4：线面/面面垂直证明（大题第一问）
**证线面垂直**：证明直线垂直于平面内**两条相交直线**
**步骤**：
1. 在平面内找两条相交直线
2. 分别证明已知直线与它们垂直（用勾股逆定理、等腰三线合一、已知垂直条件）
3. 两线相交⇒线面垂直

**例题**：证明PA⊥平面ABC，已知PA⊥AB，PA⊥AC，AB∩AC=A。
- 步骤：∵PA⊥AB，PA⊥AC，AB⊂平面ABC，AC⊂平面ABC，且AB∩AC=A（两条相交直线），∴PA⊥平面ABC
- **关键**：必须是**两条相交**直线，平行的不行；"相交"要点明

### 立5：建系求法向量/证明位置关系（向量法第一问）
**步骤**：
1. 找两两垂直的三线建系，写各点坐标
2. 求相关向量（终点减起点）
3. 求平面法向量（设n=(x,y,z)，列两个点乘=0方程，令一个变量为1）
4. 用向量点乘判断平行/垂直

**例题**：已知A(0,0,0)，B(2,0,0)，C(0,2,0)，P(0,0,2)，证明PA⊥平面ABC。
- 步骤：PA向量=A-P=(0,0,-2)，平面ABC在z=0上，法向量n=(0,0,1)；PA=(0,0,-2)=-2n，方向向量与法向量平行⇒PA⊥平面ABC
- **易错**：坐标写错全盘错，建系后逐点核对；法向量方程令z=1时要保证z能取1（若z必须为0则令x或y为1）

### 立6：空间角/距离（第二问，了解拿步骤分）
- 会建系、会求法向量，套空间角公式即可写步骤
- 本阶段不强求结果，写出建系和向量就有分

## 1.3 立体几何易错点（10条）
1. 锥体体积忘1/3（最高频低级错误）
2. 圆锥侧面积用母线l=√(r²+h²)，不是高h
3. 球的表面积4πR²、体积4/3πR³，系数别混
4. 证线面垂直必须是"两条**相交**直线"，要写交点
5. 证线面平行要交代"直线不在平面内"
6. 三视图"长对正、高平齐、宽相等"，虚线是看不见的棱
7. 建系找两两垂直的棱，坐标逐点核对
8. 向量=终点坐标-起点坐标，方向别反
9. 求法向量时令一个坐标为1，注意该坐标能否为1
10. 二面角锐钝看图形，公式算出的是余弦绝对值，要结合图定正负

# 第二部分：不等式

## 2.1 核心公式（精确，不遗漏条件）

### 2.1.1 一元二次不等式（与二次函数、方程联动）
- 对 ax²+bx+c>0（a>0），设方程ax²+bx+c=0两根x₁<x₂：
  - **大于取两边**：x<x₁ 或 x>x₂
  - **小于取中间**：x₁<x<x₂
- 若Δ<0（无实根）且a>0：ax²+bx+c恒正，>0解集为R，<0解集为空
- **前提：先把二次项系数化为正**（a<0时两边乘-1，不等号变向）

### 2.1.2 基本不等式（均值不等式，重点）
- `a+b ≥ 2√(ab)`（a>0，b>0）
- 变形：`ab ≤ (a+b)²/4`
- **等号成立条件：a=b**（必须写，最高频扣分点）
- 口诀：**一正、二定、三相等**
  - 一正：a,b都是正数
  - 二定：求和的最小值要让积为定值；求积的最大值要让和为定值
  - 三相等：验证a=b能否取到
- 常用结论：
  - x+(1/x) ≥ 2（x>0），等号x=1
  - a/b+b/a ≥ 2（ab>0）

### 2.1.3 重要不等式链
- a²+b² ≥ 2ab（对任意实数，等号a=b）
- √(ab) ≤ (a+b)/2 ≤ √[(a²+b²)/2]（几何平均≤算术平均≤平方平均，a,b>0）

### 2.1.4 绝对值不等式（基础）
- |x|<a（a>0）⟺ -a<x<a
- |x|>a（a>0）⟺ x>a 或 x<-a
- |a|-|b| ≤ |a±b| ≤ |a|+|b|（三角不等式）

### 2.1.5 不等式性质
- 同向可加：a>b，c>d ⟹ a+c>b+d
- 正数同向可乘：a>b>0，c>d>0 ⟹ ac>bd
- 乘负变号：a>b，c<0 ⟹ ac<bc
- 取倒数（同号）：a>b>0 ⟹ 1/a<1/b

## 2.2 题型分类与解题模板（5类）

### 不1：解一元二次不等式
**步骤**：
1. 二次项系数化为正
2. 求对应方程的根（因式分解/求根公式）
3. "大于取两边，小于取中间"
4. 写成解集

**例题**：解 x²-5x+6>0。
- 步骤：x²-5x+6=(x-2)(x-3)=0，根2,3；大于取两边 → x<2或x>3
- 答案：{x|x<2或x>3}

### 不2：基本不等式求最值（高频小题）
**识别**：正数、求最小值/最大值、出现和与积
**步骤（凑定值）**：
1. 判断"一正"
2. 凑"二定"：乘1法、拆项、配系数，让一边为定值
3. 用a+b≥2√ab
4. **验证"三相等"**，写等号条件

**例题**：已知x>0，求 x+4/x 的最小值。
- 步骤：一正x>0满足；x+4/x ≥ 2√(x·4/x)=2√4=4；等号当x=4/x即x=2时成立
- 答案：最小值4，当x=2取得

**例题（乘1法）**：已知x>0,y>0，x+y=1，求1/x+1/y最小值。
- 步骤：1/x+1/y=(1/x+1/y)(x+y)=2+y/x+x/y ≥ 2+2√(y/x·x/y)=4；等号x=y=1/2
- 答案：最小值4

### 不3：恒成立问题（与函数最值联动）
- f(x)≥a恒成立 ⟺ f(x)min≥a
- f(x)≤a恒成立 ⟺ f(x)max≤a
**步骤**：转化为求函数最值（导数或基本不等式）

### 不4：解绝对值不等式
**步骤**：
1. |x|<a → -a<x<a；|x|>a → x>a或x<-a
2. 含两个绝对值：分段讨论（找零点分区间）或几何意义

**例题**：解 |x-2|<3。
- 步骤：-3<x-2<3 → -1<x<5
- 答案：(-1,5)

### 不5：不等式比较大小/性质判断
- 作差法：a-b>0⟺a>b
- 特殊值法（选择题）：取满足条件的特殊数验证选项

## 2.3 不等式易错点（10条）
1. 解一元二次不等式前先把二次项系数化为正
2. "大于取两边、小于取中间"的前提是a>0
3. 基本不等式必须"一正二定三相等"，**等号条件必写**
4. 用基本不等式凑不出定值就不能直接用
5. a²+b²≥2ab对全体实数，a+b≥2√ab只对正数
6. 乘负数不等号变向
7. |x|>a是"或"（两边），|x|<a是"且"（中间）
8. 恒成立⟺最值问题，注意是≥还是>
9. 乘1法：整体乘(x+y)=1，展开后再用不等式
10. 等号取不到时，基本不等式给的是界不是最值，要另想办法
