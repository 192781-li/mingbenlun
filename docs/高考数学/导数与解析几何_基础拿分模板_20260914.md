# 第一部分：导数（主攻：求导、切线、单调区间）

## 1.1 核心公式（精确，不遗漏条件）

### 1.1.1 基本初等函数求导公式（必背，每天默写）
- 常数：`(C)' = 0`
- 幂函数：`(xⁿ)' = n·xⁿ⁻¹`
- 特例：(x)'=1，(x²)'=2x，(1/x)'=-1/x²，(√x)'=1/(2√x)
- 指数：`(eˣ)' = eˣ`；`(aˣ)' = aˣ·lna`
- 对数：`(lnx)' = 1/x`；`(logₐx)' = 1/(x·lna)`
- 正弦：`(sinx)' = cosx`
- 余弦：`(cosx)' = -sinx`（**有负号，别漏**）

### 1.1.2 求导运算法则
- 加减：`(u±v)' = u'±v'`
- 乘法：`(uv)' = u'v + uv'`（前导后不导+前不导后导）
- 除法：`(u/v)' = (u'v - uv')/v²`（**分子是减号**）
- 常数倍：(Cu)'=Cu'

### 1.1.3 复合函数求导（链式法则）
- `[f(g(x))]' = f'(g(x))·g'(x)`（**外层导×内层导，一层一层剥**）
- 例：(sin2x)' = cos2x·2 = 2cos2x
- 例：(e²ˣ⁺¹)' = e²ˣ⁺¹·2 = 2e²ˣ⁺¹

### 1.1.4 导数的几何意义（切线题的根）
- **f'(x₀) = 曲线在x=x₀处切线的斜率**
- 切线方程（点斜式）：`y - f(x₀) = f'(x₀)(x - x₀)`
- 切点(x₀, f(x₀))既在曲线上，又在切线上

### 1.1.5 导数与单调性（单调区间题的根）
- **f'(x) > 0 ⟺ f(x)单调递增**
- **f'(x) < 0 ⟺ f(x)单调递减**
- f'(x)=0的点是"驻点"（可能是极值点）

### 1.1.6 极值判定
- 求f'(x)=0的根x₀
- 看x₀左右f'(x)符号：
  - 左正右负 → 极大值
  - 左负右正 → 极小值
- 最值：闭区间[a,b]上，比较"所有极值点函数值"和"端点值"，最大的是最大值

## 1.2 题型分类与解题模板（5类，前3类必拿）

### 导1：求导运算（送分，所有题的前置）
**步骤**：
1. 先写**定义域**（含ln、分式、根号必须写）
2. 判断函数结构，选对应公式
3. 复合函数一层层剥，别漏内层导数
4. 化简

**例题**：求f(x)=x³-2x²+3x-1的导数。
- 步骤：f'(x)=3x²-4x+3（逐项求导，常数-1导数为0）
- 答案：f'(x)=3x²-4x+3

**例题**：求f(x)=x·lnx的导数。
- 步骤：乘法法则 (uv)'=u'v+uv'，u=x，v=lnx → f'(x)=1·lnx+x·(1/x)=lnx+1
- 答案：f'(x)=lnx+1

### 导2：求切线方程（第一问高频，必拿）
**识别关键词**：切线、在点P处的切线、斜率
**步骤（四步铁律）**：
1. 求导 f'(x)
2. 代入切点横坐标，求斜率 k=f'(x₀)
3. 求切点纵坐标 y₀=f(x₀)
4. 点斜式 y-y₀=k(x-x₀)，整理

**例题**：求曲线f(x)=x²在点(1,1)处的切线方程。
- 定题型：切线题
- 步骤：f'(x)=2x；k=f'(1)=2；切点(1,1)；y-1=2(x-1) → y=2x-1
- 答案：y=2x-1

**例题（过点型，注意区别）**：过点(0,0)作曲线y=eˣ的切线，求切线方程。
- 关键：点(0,0)不在曲线上，要**设切点**(x₀,eˣ⁰)
- 步骤：设切点(x₀,eˣ⁰)，斜率k=eˣ⁰；切线过(0,0)：0-eˣ⁰=eˣ⁰(0-x₀) → -eˣ⁰=-x₀eˣ⁰ → x₀=1；切点(1,e)，k=e；y-e=e(x-1) → y=ex
- 答案：y=ex
- **易错**："在点P处"P是切点；"过点P"P不一定是切点，要设切点

### 导3：求单调区间（第一问最高频，必拿）
**识别关键词**：单调区间、单调性、讨论单调性
**步骤（五步）**：
1. 写**定义域**
2. 求导 f'(x)
3. 令f'(x)=0，求驻点（解不出就因式分解）
4. **用驻点把定义域分段，列表判断每段f'(x)正负**
5. 正→递增区间，负→递减区间

**例题**：求f(x)=x³-3x的单调区间。
- 定题型：单调区间
- 步骤：
  1. 定义域R
  2. f'(x)=3x²-3=3(x²-1)=3(x+1)(x-1)
  3. 令f'(x)=0 → x=-1或x=1
  4. 分段判断：
     | 区间 | (-∞,-1) | (-1,1) | (1,+∞) |
     |------|---------|--------|--------|
     | f'(x) | + | - | + |
     | f(x) | 递增 | 递减 | 递增 |
  5. 递增区间(-∞,-1)和(1,+∞)；递减区间(-1,1)
- 答案：增区间(-∞,-1)、(1,+∞)；减区间(-1,1)
- **易错**：多个增区间用逗号/和连接，**不能用∪**（不连续）；定义域优先

### 导4：求极值/最值（第一问中频）
**步骤**：
1. 定义域→求导→f'(x)=0求驻点
2. 列表看左右符号变化定极值
3. 闭区间最值：极值与端点值一起比较

**例题**：求f(x)=x³-3x在[-2,2]上的最值。
- 步骤：驻点x=-1（极大）、x=1（极小）；f(-1)=2，f(1)=-2；端点f(-2)=-2，f(2)=2；比较得最大值2，最小值-2
- 答案：最大值2，最小值-2

### 导5：含参单调性讨论（第二问难度，了解即可，不强求）
- 当f'(x)含参数a时，驻点位置随a变化，需按a分类
- **本阶段战略跳过**，只保证前4类全对

## 1.3 导数易错点（10条）
1. **第一步永远写定义域**（lnx要求x>0，分式分母≠0，根号≥0）
2. (cosx)'=-sinx有负号
3. 除法法则分子是u'v-uv'（减号）
4. 复合函数别漏乘内层导数（链式）
5. "在点P处"vs"过点P"：后者要设切点
6. 多个单调区间用"和"连接，不用∪
7. f'(x₀)=0不一定是极值点（还要左右变号），但极值点处f'=0
8. 闭区间最值要和端点值比较
9. 解f'(x)=0优先因式分解，别硬用求根公式
10. 含eˣ、lnx的求导结果别化简错，(lnx)'=1/x

# 第二部分：解析几何（主攻：直线、圆、圆锥曲线第一问）

## 2.1 核心公式（精确，不遗漏条件）

### 2.1.1 直线
- 斜率：`k = (y₂-y₁)/(x₂-x₁)`（x₁≠x₂）；k=tanα
- 点斜式：y-y₀=k(x-x₀)
- 斜截式：y=kx+b
- 一般式：Ax+By+C=0
- 两直线平行：k₁=k₂；垂直：**k₁·k₂=-1**
- 点到直线距离：`d = |Ax₀+By₀+C|/√(A²+B²)`

### 2.1.2 圆
- 标准方程：`(x-a)²+(y-b)²=r²`，圆心(a,b)，半径r
- 一般方程：x²+y²+Dx+Ey+F=0（D²+E²-4F>0），圆心(-D/2,-E/2)
- 直线与圆：
  - 相交：d<r（弦心距d，**弦长=2√(r²-d²)**）
  - 相切：d=r
  - 相离：d>r

### 2.1.3 椭圆（标准形式，必背a,b,c关系）
- 标准方程：`x²/a² + y²/b² = 1`（a>b>0，焦点在x轴）
- **关系：a² = b² + c²**（a最大）
- 离心率：`e = c/a`（0<e<1）
- 长轴长2a，短轴长2b，焦距2c

### 2.1.4 双曲线
- 标准方程：`x²/a² - y²/b² = 1`（焦点在x轴）
- **关系：c² = a² + b²**（c最大，注意和椭圆相反！）
- 离心率：e=c/a（e>1）
- 渐近线：y=±(b/a)x

### 2.1.5 抛物线
- y²=2px（p>0）：焦点(p/2, 0)，准线x=-p/2
- **抛物线上点到焦点距离 = 到准线距离**（定义，常用）

### 2.1.6 联立+韦达定理（解几大题通用武器）
- 直线y=kx+m代入曲线方程，消y得关于x的一元二次方程：Ax²+Bx+C=0
- **韦达定理**：`x₁+x₂ = -B/A`，`x₁x₂ = C/A`
- **判别式**：Δ=B²-4AC（相交Δ>0，相切Δ=0，相离Δ<0）
- 弦长公式：`|AB| = √(1+k²)·|x₁-x₂| = √(1+k²)·√[(x₁+x₂)²-4x₁x₂]`

## 2.2 题型分类与解题模板（5类，前3类必拿）

### 解几1：求曲线标准方程（第一问必考，必拿）
**识别**：求椭圆/双曲线/抛物线方程
**步骤**：
1. 设标准方程（先判断焦点在哪个轴）
2. 把已知条件翻译成关于a,b,c的方程
3. 结合a,b,c关系（椭圆a²=b²+c²，双曲c²=a²+b²）
4. 解出参数，代回

**例题**：椭圆焦点为(±3,0)，且过点(4,0)，求椭圆方程。
- 定题型：求椭圆方程
- 步骤：焦点在x轴，c=3；过(4,0)说明长轴顶点，a=4；由a²=b²+c² → 16=b²+9 → b²=7；方程 x²/16+y²/7=1
- 答案：x²/16+y²/7=1

### 解几2：直线与圆（小题/第一问）
**步骤**：
1. 找圆心、半径
2. 算圆心到直线距离d
3. d与r比较定位置关系；弦长用2√(r²-d²)

**例题**：圆x²+y²=4，求直线y=x被圆截得的弦长。
- 步骤：圆心(0,0)，r=2；d=|0-0|/√2=0（直线过圆心）；弦长=直径=4
- 答案：4

### 解几3：离心率计算
**步骤**：
1. 把条件转化为a,b,c的齐次关系
2. 结合a,b,c关系消元
3. e=c/a，求比值

**例题**：椭圆x²/a²+y²/b²=1（a>b>0），若b=c，求离心率e。
- 步骤：a²=b²+c²=2c² → a=√2c → e=c/a=1/√2=√2/2
- 答案：e=√2/2

### 解几4：联立韦达标准流程（大题第一问/第二问起步，拿步骤分）
**识别**：直线与圆锥曲线相交于A、B两点
**标准流程（背下来，按步写就有分）**：
1. 设直线方程 y=kx+m（斜率不存在时单独讨论x=t）
2. 联立：代入曲线方程，**消去y**
3. 整理成 Ax²+Bx+C=0
4. **写判别式Δ>0**（保证有两个交点，列出参数范围）
5. **韦达定理**：x₁+x₂=-B/A，x₁x₂=C/A（写到这里就有步骤分）
6. 第二问要什么（弦长/面积/定点），再用韦达结果代换——**本阶段写到第5步即可**

**例题（只做第一问）**：直线y=x+1与椭圆x²/4+y²=1交于A、B，求x₁+x₂和x₁x₂。
- 步骤：联立，y=x+1代入：x²/4+(x+1)²=1 → x²/4+x²+2x+1=1 → 5x²/4+2x=0 → 5x²+8x=0；x₁+x₂=-8/5，x₁x₂=0
- 答案：x₁+x₂=-8/5，x₁x₂=0

### 解几5：弦长/面积（第二问难度，会多少写多少）
- 弦长|AB|=√(1+k²)·√[(x₁+x₂)²-4x₁x₂]
- 三角形面积 S=(1/2)·底·高，或用弦长作底、点到直线距离作高
- **本阶段不强求，写出韦达和公式就有过程分**

## 2.3 解析几何易错点（10条）
1. 椭圆a²=b²+c²（a最大），双曲线c²=a²+b²（c最大），**别记反**
2. 焦点在x轴还是y轴，先判断再设方程
3. 设y=kx+m时，**斜率不存在的情况（竖直线x=t）要单独讨论**
4. 联立后必须写Δ>0，否则可能没有两个交点
5. 韦达定理 x₁+x₂=-B/A（**有负号**），x₁x₂=C/A
6. 弦长公式别漏√(1+k²)
7. 消元时计算要慢，代入后先整理再定A、B、C
8. 抛物线焦点和准线：y²=2px焦点(p/2,0)，符号看开口
9. 离心率范围：椭圆0<e<1，双曲线e>1，抛物线e=1
10. 点在曲线上⟺坐标满足方程（求方程题的根本）
