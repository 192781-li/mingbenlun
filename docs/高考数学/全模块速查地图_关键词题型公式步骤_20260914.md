> S06高考数学分站 · 精品速查总图 · 2026-09-14

> 用法：这是**考前5分钟和刷题卡住时**翻的总图。看到题，先在"关键词雷达"里扫到信号，顺着"题型→公式→第一步"走。

## 〇、解题总流程（刻进肌肉）

```
拿到题
 │
 ├─① 读动作：求什么？(值/范围/方程/证明/最值)
 │
 ├─② 关键词雷达：扫到下面表里的词 → 锁定模块和题型
 │
 ├─③ 调公式：从该题型公式列取（默写库）
 │
 ├─④ 走步骤：按"第一步"起手，分觉拆成小动作，一步一行
 │
 └─⑤ 查检验：定义域？端点？符号？代回？概率和=1？等号条件？
```

**考场取舍**：单题卡3分钟先跳；压轴第二问战略放弃，第一问必写。
