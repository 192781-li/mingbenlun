## 第二章 生命论解题法：一套动作打所有题

### 2.1 总原则：操作先于实体

很多人学数学的顺序错了：先背一堆"知识实体"（定义、定理），再去做题，结果知识是散的、题是懵的。

**正确顺序（操作先于实体）**：
1. 先看题在"让你做什么动作"（求值？证明？求范围？画图？）
2. 动作对应固定的操作流程（题型模板）
3. 在执行操作的过程中，调用需要的公式（实体为操作服务）
4. 做完复盘，公式和知识在操作中被真正掌握

> 类比：学骑车不是先背力学原理，是先蹬起来；平衡感（知识）在蹬车（操作）中长出来。数学同理。

### 2.2 解题四步法（每道题都走这四步，写在草稿最上面）

```
第一步：定题型 —— 这是什么题？（看到关键词→匹配题型编号）
第二步：调公式 —— 用什么公式/定理？（从默写库里取）
第三步：走步骤 —— 按模板一步步执行（分觉：拆成最小动作）
第四步：查检验 —— 代回验证、查定义域、查端点、查符号
```

**示例演示**（体会四步法怎么跑）：
> 题：已知向量a=(2,m)，b=(1,-3)，a⊥b，求m。
- 第一步定题型：看到"a⊥b"→向量垂直题（向3）
- 第二步调公式：垂直→点乘为0：x₁x₂+y₁y₂=0
- 第三步走步骤：2×1+m×(-3)=0 → 2-3m=0 → m=2/3
- 第四步查检验：代回，a·b=2-3×(2/3)=0 ✓

### 2.3 小本质递归：从一个公式长出一棵树

每个模块都找到它的"小本质"（最小的那颗种子），所有复杂方法都是从种子递归长出来的。

- **三角模块的小本质**：`sin²α+cos²α=1` 和单位圆 → 递归长出诱导公式、和差角、二倍角、解三角形
- **数列模块的小本质**：`后项-前项=公差d（等差）`、`后项/前项=公比q（等比）` → 递归长出通项、求和、递推
- **导数模块的小本质**：`导数=瞬时变化率=切线斜率` → 递归长出切线、单调区间、极值最值
- **解几模块的小本质**：`点在曲线上⟺坐标满足方程` → 递归长出联立、韦达、弦长

> **用法**：复习一个模块时，先默写它的小本质，再自己尝试"推导生长"出下游公式。推不出来的地方，就是你没掌握的地方——这比盲目刷题精准十倍。

### 2.4 分觉：大题拆小问，小问拆步骤

"分觉"=把一个看起来很大的难题，切分成一个个你能独立完成的小动作。

- 一道大题 = 第(1)问 + 第(2)问（**第(2)问不会，第(1)问照样写、照样拿分**）
- 一个小问 = 若干步骤（哪怕最终算不出，把"设、列、代"的步骤写出来，拿过程分）
- **空题=0分，写了正确步骤=步骤分**。这是60→90的关键心态：永远不空题。

## 第三章 审题：90%的"不会"其实是"没读懂"

### 3.1 审题三遍法

- **第一遍（读动作）**：题目要我求什么？（求值/求范围/证明/求方程/求最值）
- **第二遍（圈条件）**：把每个已知条件圈出来，翻译成数学语言
  - "在……上"→ 代入方程
  - "相切"→ 联立后判别式Δ=0 / 导数=斜率
  - "恒成立"→ 最值问题
  - "至少/至多"→ 概率补集或分类
- **第三遍（找桥梁）**：已知和未知之间，靠哪个公式/定理连接？

### 3.2 条件翻译对照表（看到中文→写数学式）

| 题目中文表述 | 翻译成数学操作 |
|-------------|---------------|
| 点P在曲线C上 | P坐标代入C的方程，等式成立 |
| 两曲线相切 | 联立方程，判别式Δ=0 |
| 函数在x=a处取极值 | f'(a)=0（且左右导数变号） |
| 单调递增 | f'(x)≥0恒成立（解不等式） |
| 恒成立/对任意x都成立 | 转化为最值：f(x)≥0恒成立⟺f(x)min≥0 |
| 存在x使得成立 | f(x)max≥0（能取到即可） |
| 三角形中已知两边一角 | 正弦/余弦定理 |
| 等差数列 | aₙ₊₁-aₙ=d（常数） |
| 向量共线/平行 | x₁y₂-x₂y₁=0 |
| 向量垂直 | x₁x₂+y₁y₂=0 |
| 概率"至少一个" | 1 - 对立事件概率 |
| 最大值/最小值 | 导数找极值点，或基本不等式 |

## 第四章 选填速解八法（选择填空抢分利器）

> 选择填空题**只要结果、不要过程**，能用巧办法10秒解决，绝不硬算3分钟。

### 方法1：特值法（最常用）
- 适用：含参数、比较大小、判断恒成立的题
- 操作：取一个满足条件的特殊值（0、1、-1、端点、特殊角），代入直接看结果
- 例：判断"对任意x>0，f(x)>g(x)"是否成立 → 取x=1代入验证，不成立则直接排除

### 方法2：排除法
- 操作：结合定义域、值域、符号、趋势，先排除明显错的选项
- 例：求一个正数结果，选项里有负数先划掉；奇函数在x=0处（若有定义）必为0

### 方法3：数形结合
- 操作：能画图就画图（函数图像、数轴、几何图、韦恩图），答案在图上"看"出来
- 高频：集合运算画数轴、函数零点画图像看交点、距离最值画几何图

### 方法4：极端化/边界法
- 操作：让变量取边界值（0、最大、最小、重合、垂直/平行），看结果趋势
- 例：动点问题，让点动到端点位置，答案往往就显出来

### 方法5：验证法（代入选项）
- 操作：把四个选项逐个代回题干，满足的就是答案（解方程类选择题神器）

### 方法6：估算法
- 操作：不需要精确值时，估算数量级、范围，锁定唯一选项

### 方法7：对称性/结论法
- 操作：记住高频小结论（如奇函数在对称区间单调性相同、偶函数相反），直接用

### 方法8：直接法（常规推导）
- 当以上巧办法都不适用，老老实实四步法，但只写关键步骤，不恋战

> **选填时间纪律**：单题超过3分钟没思路，先标记跳过，全部做完再回来。选填总时长控制在45分钟内。

## 第五章 大题通用框架与书写规范

### 5.1 大题拿分三原则
1. **按问拿分**：第(1)问独立于第(2)问，先稳稳拿下
2. **步骤说话**：高考按步骤给分，"设、列、化、算、答"五步写全
3. **结论醒目**：每问最后一行写"∴……"明确结论

### 5.2 各类大题的标准开头（背下来，上场直接写）

**三角大题**：
```
解：(1) f(x) = ……（先用公式化简为 Asin(ωx+φ)+B 形式）
    由 ……公式得 f(x) = √2 sin(2x+π/6)+1
    （再求周期/单调区间/最值）
```

**数列大题**：
```
解：(1) 设{aₙ}公差为d（公比为q）
    由 aₙ=a₁+(n-1)d，代入已知条件列方程
    解得 a₁=…，d=…
    ∴ aₙ=…
```

**概率大题**：
```
解：(1) 设事件A="……"
    总的基本事件数 N=…，A包含的基本事件数 n=…
    ∴ P(A)=n/N=…
```

**立几大题**：
```
(1) 证明：取……中点，连接……（几何法）
   或：以……为原点建立空间直角坐标系（向量法）
   则各点坐标为……
```

**导数大题**：
```
解：(1) f(x)的定义域为……（第一步必写定义域！）
    f'(x)=……
    令f'(x)=0，解得x=…
```

**解几大题**：
```
解：(1) 由题意设曲线方程为……
    ∵点……在曲线上，代入得……
    联立……，由韦达定理 x₁+x₂=…，x₁x₂=…
```

### 5.3 书写红线（避免无谓丢分）
- 定义域第一行写（导数题、对数题、分式题）
- 设未知数要写"设……"
- 单位、角度制/弧度制别混
- 概率结果化到最简分数
- 最后结论带"∴"或"答："

## 第六章 错题三归因系统（不笼统说"粗心"）

### 6.1 三类归因，对症下药

| 归因 | 表现 | 对策 |
|------|------|------|
| **公式没记住** | 看到题不知道用什么公式，或公式记错 | 回默写库，该公式抄10遍，第二天再默 |
| **题型没识别** | 公式都会，但看不出这是什么题、走什么流程 | 回题型表，把"关键词→题型"绑定重记，找3道同类题强化 |
| **计算错误** | 思路全对，算错数/符号/抄错 | 计算专项：放慢、分步、每步回查；建"计算错误类型本" |

### 6.2 错题本标准格式（每道错题这样记）
```
【题目】……
【我的错解】……（原样保留错误，别擦）
【错误归因】公式没记住 / 题型没识别 / 计算错误（三选一）
【正确解法】按四步法写完整
【根因一句话】……（例如：垂直公式记成了平行公式）
【同类强化】再做2道同题型
```

> **生命论视角**：错题不是失败，是"反身自觉"（照见自己操作的漏洞）。每道错题都让你的操作闭环更紧。怕错题、掩错题，才是真的停步。

## 第七章 计算准确率训练（17分选手的隐形重灾区）

### 7.1 计算错误的五个高发点
1. **符号**：去括号变号、负负得正、移项变号
2. **分式**：通分漏乘、约分错、分母为零
3. **根式**：√(a²)=|a|（不是a！）、分母有理化
4. **指数对数**：对数真数>0、换底公式、log运算方向
5. **抄错**：上一行到下一行抄错数/字母

### 7.2 训练方法
- **一步一行**：不跳步，每步只做一个运算
- **回头看**：每算3步，回看前一步对不对
- **双轨验算**：关键结果用另一种方法/代回验证
- **每日10题计算基本功**：分数运算、因式分解、解方程，限时训练

## 第十章 生命论数学观：你和数学的关系

1. **数学是操作的流，不是静态的知识堆**。每道题都是一次操作，做一次就熟练一分。
2. **小本质递归**：抓住每个模块最小的种子公式，自己推导生长，知识才是活的。
3. **分觉**：大目标切成小动作，大题切成小问，小问切成步骤，没有"大到做不出"的题。
4. **反身自觉**：错题照见操作漏洞，归因精准（公式/题型/计算），不拿"粗心"糊弄自己。
5. **先闭环再优化**：先让60分的操作稳定跑通，再递归到90、100+。不求一步到位，求每步扎实。
6. **你不是"数学差的人"，你是"操作还没练熟的人"**。17分只代表过去的操作量，不代表你的上限。
