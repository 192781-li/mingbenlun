## 二、选择/填空基础题（送分题）

### 题型1：三角函数定义与求值

**识别关键词**：已知sinα/cosα/tanα中的一个，求另外两个；α是第几象限角。

**解题步骤模板**：
1. 用平方关系求未知的sin或cos：$\sin^2\alpha + \cos^2\alpha = 1$
2. **关键**：根据α所在象限确定正负号（一全正二正弦三正切四余弦）
3. 用商数关系求tan：$\tan\alpha = \frac{\sin\alpha}{\cos\alpha}$

**易错点**：
- 忘记看象限直接写正负号 → 必须先判断象限
- 平方开方后忘记± → 开方一定有±，由象限定符号

**典型例题**：
已知 $\cos\alpha = -\frac{5}{13}$，α是第三象限角，求sinα和tanα。

解：
1. $\sin^2\alpha = 1 - \cos^2\alpha = 1 - \frac{25}{169} = \frac{144}{169}$
2. 第三象限sin为负 → $\sin\alpha = -\frac{12}{13}$
3. $\tan\alpha = \frac{\sin\alpha}{\cos\alpha} = \frac{-12/13}{-5/13} = \frac{12}{5}$

---

### 题型2：诱导公式化简求值

**识别关键词**：角里有π、π/2、2π、负号；要求化简或求值。

**解题步骤模板**：
1. 负角转正角：用 $\sin(-\alpha)=-\sin\alpha$，$\cos(-\alpha)=\cos\alpha$
2. 大角化小角：用 $\sin(2k\pi+\alpha)=\sin\alpha$ 化到0~2π
3. 用诱导公式化到锐角：奇变偶不变，符号看象限
4. 查特殊角值表

**口诀**：负化正，大化小，化到锐角再查表。

**易错点**：
- 奇变偶不变用错 → 看π/2的系数，奇数变函数名，偶数不变
- 符号看象限时把α当成钝角 → 永远把α看成锐角来判断符号

**典型例题**：
求 $\sin\frac{7\pi}{6}$ 的值。

解：
1. $\frac{7\pi}{6} = \pi + \frac{\pi}{6}$（π的系数是1，偶数，函数名不变）
2. π+π/6在第三象限，sin为负
3. $\sin\frac{7\pi}{6} = -\sin\frac{\pi}{6} = -\frac{1}{2}$

---

### 题型3：三角函数性质（周期/奇偶/单调）

**识别关键词**：求周期、判断奇偶性、求单调区间、求对称轴/对称中心。

**解题步骤模板**：

**求周期**：
- y=Asin(ωx+φ) 或 y=Acos(ωx+φ)：$T = \frac{2\pi}{|\omega|}$
- y=Atan(ωx+φ)：$T = \frac{\pi}{|\omega|}$

**判断奇偶性**：
- 代入-x，看f(-x)=f(x)（偶）还是f(-x)=-f(x)（奇）
- 快捷判断：y=Asin(ωx+φ)，φ=kπ时是奇函数，φ=π/2+kπ时是偶函数
- y=Acos(ωx+φ)，φ=kπ时是偶函数，φ=π/2+kπ时是奇函数

**求单调区间**：
1. 把ωx+φ看成一个整体t
2. 记住sint的递增区间 $[-\frac{\pi}{2}+2k\pi, \frac{\pi}{2}+2k\pi]$，递减区间 $[\frac{\pi}{2}+2k\pi, \frac{3\pi}{2}+2k\pi]$
3. 解不等式 $-\frac{\pi}{2}+2k\pi \leq \omega x+\varphi \leq \frac{\pi}{2}+2k\pi$，求出x的范围
4. **注意**：如果ω<0，先用诱导公式把ω变成正的，或者记住"负的要反过来"

**易错点**：
- 周期公式记错 → sin/cos是2π/ω，tan是π/ω
- 求单调区间时忘记ω的正负 → ω<0时单调性反转
- 单调区间不写k∈Z → 必须写k∈Z

**典型例题**：
求函数 $y = 2\sin(2x - \frac{\pi}{3})$ 的单调递增区间。

解：
1. 令 $t = 2x - \frac{\pi}{3}$
2. sint的递增区间：$-\frac{\pi}{2}+2k\pi \leq t \leq \frac{\pi}{2}+2k\pi$
3. 代入：$-\frac{\pi}{2}+2k\pi \leq 2x - \frac{\pi}{3} \leq \frac{\pi}{2}+2k\pi$
4. 三边加π/3：$-\frac{\pi}{6}+2k\pi \leq 2x \leq \frac{5\pi}{6}+2k\pi$
5. 除以2：$-\frac{\pi}{12}+k\pi \leq x \leq \frac{5\pi}{12}+k\pi$
6. 所以递增区间为 $[-\frac{\pi}{12}+k\pi, \frac{5\pi}{12}+k\pi]$，k∈Z

### 题型4：正弦型函数图像变换

**识别关键词**：由y=sinx经过怎样的变换得到y=Asin(ωx+φ)；或者描述变换过程求解析式。

**解题步骤模板**：

**已知变换过程求解析式**：
1. 按变换顺序逐步替换x
2. 左右平移：x→x±a（左加右减）
3. 横向伸缩：x→ωx（横坐标变为1/ω倍）
4. 纵向伸缩：整体×A
5. 上下平移：整体±b

**已知解析式反推变换过程**：
1. 化为标准形式：y=Asin[ω(x+φ/ω)]+b（**必须把ω提出来**）
2. 读出参数：A（纵伸）、ω（横缩1/ω）、φ/ω（平移量）、b（上下移）
3. 按顺序描述（推荐先平移后伸缩）

**铁律**：先伸缩后平移时，平移量是φ/ω，不是φ！必须先提ω。

**易错点**：
- 平移量不除ω → 先提ω再看平移
- 左右搞反 → 左加右减，用最高点验证
- 变换顺序搞混 → 先平移后伸缩和平移量不同

**典型例题**：
函数 $y = \sin(2x + \frac{\pi}{3})$ 的图像可由y=sinx的图像经过怎样的变换得到？

解（先平移后伸缩，推荐）：
1. y=sinx 向左平移 $\frac{\pi}{3}$ → y=sin(x+$\frac{\pi}{3}$)
2. 横坐标压缩为原来的 $\frac{1}{2}$ → y=sin(2x+$\frac{\pi}{3}$)

解（先伸缩后平移）：
1. y=sinx 横坐标压缩为原来的 $\frac{1}{2}$ → y=sin2x
2. 向左平移 $\frac{\pi}{6}$（不是π/3！）→ y=sin[2(x+$\frac{\pi}{6}$)] = sin(2x+$\frac{\pi}{3}$)

### 题型5：正弦型函数求解析式

**识别关键词**：给出图像或几个关键点，求y=Asin(ωx+φ)的解析式。

**解题步骤模板**：
1. **求A**：$A = \frac{\text{最大值}-\text{最小值}}{2}$（如果有上下平移，还要算b）
2. **求ω**：从周期T求，$\omega = \frac{2\pi}{T}$。周期从图像上找：相邻两个最高点（或最低点）之间的距离是一个周期；最高点到相邻最低点是半个周期。
3. **求φ**：代入一个已知点（通常用最高点或最低点），解方程。
   - 最高点：$\omega x + \varphi = \frac{\pi}{2} + 2k\pi$
   - 最低点：$\omega x + \varphi = -\frac{\pi}{2} + 2k\pi$
4. **验证**：代入另一个点验证是否正确。

**易错点**：
- A只看最大值不看最小值 → A=(max-min)/2
- 周期找错 → 最高点到最低点是半个周期，不是一个
- 求φ时k的取值不注意 → 通常取k=0，然后验证

**典型例题**：
函数y=Asin(ωx+φ)（A>0, ω>0, |φ|<π/2）的图像过点(0,1)，最高点为(π/6, 2)，求解析式。

解：
1. A=2（最高点纵坐标）
2. 过(0,1)：2sinφ=1 → sinφ=1/2 → φ=π/6（因为|φ|<π/2）
3. 最高点(π/6,2)：ω·π/6 + π/6 = π/2 → ω·π/6 = π/3 → ω=2
4. 解析式：y=2sin(2x+π/6)
5. 验证：x=0时y=2sin(π/6)=1 ✅

## 三、大题第一问（必拿分）

### 题型6：三角恒等变换化简+求周期/最值/单调区间

**识别关键词**：给出f(x)=asin²x+bsinxcosx+ccos²x的形式，要求化简并求周期、最大值、单调区间等。

**这是高考三角函数大题的标准第一问，10-12分，必须全拿！**

**解题步骤模板（三步法）**：

**第一步：降幂**
- $\sin^2x = \frac{1-\cos2x}{2}$
- $\cos^2x = \frac{1+\cos2x}{2}$
- $2\sin x\cos x = \sin2x$（如果系数不是2，先凑出2）

降幂后得到：$f(x) = a\sin2x + b\cos2x + c$ 的形式

**第二步：辅助角公式**
$$a\sin2x + b\cos2x = \sqrt{a^2+b^2}\sin(2x+\varphi)$$
其中 $\tan\varphi = \frac{b}{a}$，φ的象限由a、b符号决定。

常见特殊值要秒出：
- sinx+cosx = √2 sin(x+π/4)
- √3sinx+cosx = 2sin(x+π/6)
- sinx+√3cosx = 2sin(x+π/3)

化简后得到：$f(x) = A\sin(2x+\varphi) + c$

**第三步：求性质**
- 周期：$T = \frac{2\pi}{2} = \pi$
- 最大值：A+c，最小值：-A+c
- 单调区间：把2x+φ看成整体，套sint的单调区间

**易错点**：
- 降幂公式分子搞反 → sin²是(1-cos2x)/2，cos²是(1+cos2x)/2，sin减cos加
- 辅助角公式φ的象限不看 → a>0,b>0在第一象限；a>0,b<0在第四象限
- 求单调区间时忘记+c不影响单调性 → +c只是上下平移，单调区间不变
- 最大值忘记加c → 最大值是A+c，不是A

**典型例题**：
已知 $f(x) = 2\sin^2x + 2\sqrt{3}\sin x\cos x - 1$，求：
(1) 化简f(x)；
(2) 求f(x)的最小正周期和最大值。

解：
(1) 第一步降幂：
$2\sin^2x = 2 \cdot \frac{1-\cos2x}{2} = 1-\cos2x$
$2\sqrt{3}\sin x\cos x = \sqrt{3}\sin2x$
$f(x) = (1-\cos2x) + \sqrt{3}\sin2x - 1 = \sqrt{3}\sin2x - \cos2x$

第二步辅助角：
$\sqrt{3}\sin2x - \cos2x = 2\sin(2x - \frac{\pi}{6})$
（验证：2sin(2x-π/6)=2(sin2x·√3/2 - cos2x·1/2)=√3sin2x-cos2x ✅）

所以 $f(x) = 2\sin(2x - \frac{\pi}{6})$

(2) 周期：$T = \frac{2\pi}{2} = \pi$
最大值：2（当2x-π/6=π/2+2kπ时）

### 题型7：解三角形（正弦/余弦/面积）

**识别关键词**：在△ABC中，已知边和角，求其他边和角；求面积；判断三角形形状。

**解题步骤模板**：

**第一步：判断用正弦还是余弦**

| 已知条件 | 用什么定理 |
|---------|-----------|
| 两角一边（AAS/ASA） | 正弦定理 |
| 两边及其中一边的对角（SSA） | 正弦定理（注意可能两解） |
| 两边及夹角（SAS） | 余弦定理 |
| 三边（SSS） | 余弦定理 |

**正弦定理**：$\frac{a}{\sin A} = \frac{b}{\sin B} = \frac{c}{\sin C} = 2R$

**余弦定理**：
$a^2 = b^2 + c^2 - 2bc\cos A$
$\cos A = \frac{b^2+c^2-a^2}{2bc}$

**面积公式**：$S = \frac{1}{2}ab\sin C = \frac{1}{2}bc\sin A = \frac{1}{2}ac\sin B$

**第二步：求未知量**
- 用内角和：A+B+C=π
- 用正弦或余弦定理求其他边和角

**第三步：求面积（如果要求）**
- 选择合适的面积公式（两边及夹角）

**SSA型解的个数判断**（已知a,b,A）：
- a < bsinA：无解
- a = bsinA：一解（直角）
- bsinA < a < b：两解
- a ≥ b：一解

**易错点**：
- 正弦定理比值写成R → 是2R，不是R
- 余弦定理符号记错 → 是减号2bccosA
- 面积公式用错角 → S=½ab sinC，用的是a、b两边的夹角C
- SSA不判断解的个数 → 先判断a与bsinA的关系
- 三角形内角和记错 → 是π（180°），不是2π

**典型例题**：
在△ABC中，已知a=2, b=√2, A=45°，求B、C和c。

解：
1. 判断解的个数：bsinA = √2·sin45° = √2·√2/2 = 1。因为a=2 > b=√2，所以只有一解。
2. 正弦定理求B：$\frac{2}{\sin45°} = \frac{\sqrt{2}}{\sin B}$ → $\sin B = \frac{\sqrt{2}·\frac{\sqrt{2}}{2}}{2} = \frac{1}{2}$
   因为a>b，所以A>B，B只能是锐角 → B=30°
3. 求C：C=180°-45°-30°=105°
4. 正弦定理求c：$\frac{c}{\sin105°} = \frac{2}{\sin45°}$
   $\sin105° = \sin(60°+45°) = \frac{\sqrt{6}+\sqrt{2}}{4}$
   $c = \frac{2·\frac{\sqrt{6}+\sqrt{2}}{4}}{\frac{\sqrt{2}}{2}} = \sqrt{3}+1$

答案：B=30°, C=105°, c=√3+1

## 四、选择/填空中档题（争取拿分）

### 题型8：三角恒等变换综合求值

**识别关键词**：已知sinα、cosα、tanα中的一个或几个关系，求另一个复杂表达式的值；已知α+β或α-β的三角函数值。

**解题步骤模板**：
1. 先化简要求的表达式（用和差角、二倍角公式展开）
2. 看已知条件能求出什么
3. 整体代入（不要硬求每个角的值）
4. 注意角的范围，确定正负号

**常用技巧**：
- 已知sinα+cosα的值，平方可得sin2α：$(sinα+cosα)^2 = 1+sin2α$
- 已知tanα，求齐次式（分子分母都是sin和cos的同次幂），分子分母同除以cos的最高次幂
- 角的配凑：α = (α+β) - β，2α = (α+β) + (α-β)

**易错点**：
- 平方后忘记正负号 → 平方会丢符号，必须看角的范围
- 齐次式次数判断错 → 常数项看成0次，sin²和cos²都是2次
- 角的配凑想不到 → 记住α=(α+β)-β这种基本配凑

**典型例题**：
已知 $\tan\alpha = 2$，求 $\frac{\sin\alpha + \cos\alpha}{\sin\alpha - \cos\alpha}$ 的值。

解：
分子分母同除以cosα（因为tanα=2，所以cosα≠0）：
$\frac{\sin\alpha + \cos\alpha}{\sin\alpha - \cos\alpha} = \frac{\tan\alpha + 1}{\tan\alpha - 1} = \frac{2+1}{2-1} = 3$

### 题型9：三角函数图像与性质综合

**识别关键词**：给出y=Asin(ωx+φ)的图像或性质，综合考查周期、单调、对称、最值等多个知识点。

**解题步骤模板**：
1. 先求解析式（如果没给）：A→ω→φ
2. 把ωx+φ看成整体t
3. 逐个分析性质：
   - 周期：T=2π/ω
   - 对称轴：t=π/2+kπ，解x
   - 对称中心：t=kπ，解x，对称中心为(x,0)
   - 单调区间：套sint的单调区间解不等式
   - 最值：t=π/2+2kπ时最大，t=-π/2+2kπ时最小
4. 注意k∈Z

**易错点**：
- 对称中心的纵坐标写错 → y=Asin(ωx+φ)的对称中心纵坐标是0（如果没有上下平移）
- 对称轴和对称中心搞混 → 对称轴是直线x=...，对称中心是点(...,0)
- 单调区间解不等式时方向搞反 → 仔细解，注意除以正数不改变方向

**典型例题**：
函数 $y = 2\sin(2x - \frac{\pi}{6})$ 的图像的一条对称轴是？

解：
对称轴满足 $2x - \frac{\pi}{6} = \frac{\pi}{2} + k\pi$
$2x = \frac{2\pi}{3} + k\pi$
$x = \frac{\pi}{3} + \frac{k\pi}{2}$
取k=0，一条对称轴为 $x = \frac{\pi}{3}$

## 六、每日默写清单（题型版）

每天默写以下内容，错一个抄10遍：

1. 同角关系：$\sin^2\alpha+\cos^2\alpha=1$，$\tan\alpha=\frac{\sin\alpha}{\cos\alpha}$
2. 诱导公式口诀：奇变偶不变，符号看象限
3. 正弦型函数周期：$T=\frac{2\pi}{\omega}$
4. 降幂公式：$\sin^2\alpha=\frac{1-\cos2\alpha}{2}$，$\cos^2\alpha=\frac{1+\cos2\alpha}{2}$
5. 二倍角：$\sin2\alpha=2\sin\alpha\cos\alpha$，$\cos2\alpha=2\cos^2\alpha-1=1-2\sin^2\alpha$
6. 辅助角公式：$a\sin x+b\cos x=\sqrt{a^2+b^2}\sin(x+\varphi)$，$\tan\varphi=\frac{b}{a}$
7. 正弦定理：$\frac{a}{\sin A}=\frac{b}{\sin B}=\frac{c}{\sin C}=2R$
8. 余弦定理：$a^2=b^2+c^2-2bc\cos A$
9. 面积公式：$S=\frac{1}{2}ab\sin C$
