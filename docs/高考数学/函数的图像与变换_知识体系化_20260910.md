## 二、基本初等函数图像（画图地基）

### 2.1 一次函数 y = kx + b

| k的符号 | 图像特征 | 单调性 |
|---------|---------|--------|
| k > 0 | 从左下到右上的直线，过(0,b) | 单调递增 |
| k < 0 | 从左上到右下的直线，过(0,b) | 单调递减 |
| k = 0 | 水平线 y=b | 常数函数 |

**画图要点**：两点确定一条直线，通常取(0, b)和(-b/k, 0)。

### 2.2 二次函数 y = ax² + bx + c

**化为顶点式**：$y = a(x-h)^2 + k$，其中 $h = -\frac{b}{2a}$，$k = \frac{4ac-b^2}{4a}$

| a的符号 | 开口方向 | 顶点 | 对称轴 | 单调性 |
|---------|---------|------|--------|--------|
| a > 0 | 向上 | (h, k)最低点 | x = h | (-∞,h)减，(h,+∞)增 |
| a < 0 | 向下 | (h, k)最高点 | x = h | (-∞,h)增，(h,+∞)减 |

**画图要点**：先定顶点和对称轴，再画与y轴交点(0,c)，再根据对称性画与x轴交点（如果有）。

### 2.3 反比例函数 y = k/x

| k的符号 | 图像所在象限 | 单调性 |
|---------|-------------|--------|
| k > 0 | 一、三象限 | 每个象限内单调递减 |
| k < 0 | 二、四象限 | 每个象限内单调递增 |

**渐近线**：x轴和y轴都是渐近线，图像无限接近但不相交。

### 2.4 指数函数 y = a^x (a>0, a≠1)

| a的范围 | 图像特征 | 过定点 | 单调性 | 函数值分布 |
|---------|---------|--------|--------|-----------|
| a > 1 | 从左下到右上，x轴为渐近线 | (0,1) | 递增 | x>0时y>1，x<0时0<y<1 |
| 0<a<1 | 从左上到右下，x轴为渐近线 | (0,1) | 递减 | x>0时0<y<1，x<0时y>1 |

### 2.5 对数函数 y = log_a x (a>0, a≠1)

| a的范围 | 图像特征 | 过定点 | 单调性 | 函数值分布 |
|---------|---------|--------|--------|-----------|
| a > 1 | 从左下到右上，y轴为渐近线 | (1,0) | 递增 | x>1时y>0，0<x<1时y<0 |
| 0<a<1 | 从左上到右下，y轴为渐近线 | (1,0) | 递减 | x>1时y<0，0<x<1时y>0 |

**指数与对数的关系**：y=a^x 与 y=log_a x 互为反函数，图像关于直线y=x对称。

### 2.6 幂函数 y = x^α

**五种常见幂函数图像特征**：

| 函数 | 定义域 | 过定点 | 奇偶性 | 第一象限单调性 |
|------|--------|--------|--------|--------------|
| y=x | R | (0,0),(1,1) | 奇 | 递增 |
| y=x² | R | (0,0),(1,1) | 偶 | 递增 |
| y=x³ | R | (0,0),(1,1) | 奇 | 递增（更陡） |
| y=x^(1/2) | [0,+∞) | (0,0),(1,1) | 非奇非偶 | 递增（更缓） |
| y=x^(-1) | {x\|x≠0} | (1,1) | 奇 | 递减 |

**幂函数共性**：所有幂函数在(0,+∞)上都有定义，都过点(1,1)。

## 三、图像变换（核心）

### 3.1 平移变换

**左右平移（x上操作）**：

$$y = f(x) \xrightarrow{\text{向左平移}a\text{个单位}} y = f(x+a)$$

$$y = f(x) \xrightarrow{\text{向右平移}a\text{个单位}} y = f(x-a)$$

**口诀：左加右减**（加在x旁边，向左移；减在x旁边，向右移）

**上下平移（整体上操作）**：

$$y = f(x) \xrightarrow{\text{向上平移}b\text{个单位}} y = f(x) + b$$

$$y = f(x) \xrightarrow{\text{向下平移}b\text{个单位}} y = f(x) - b$$

**口诀：上加下减**（加在函数外面，向上移；减在函数外面，向下移）

**为什么左加右减是反的？（理解了就不会忘）**

取最高点说话。y=f(x)的最高点在x=x₀。y=f(x+a)的最高点要求x+a=x₀，所以x=x₀-a。x变小了=点往左跑了。所以x旁边加正数→图像左移。

**⚠️ 易错点：x前面有系数时，平移量要除以系数！**

例：y = sin(2x + π/3) 是由 y = sin2x 怎么平移得到的？

**错误**：向左平移π/3（直接看括号里的+π/3）

**正确**：先提系数：y = sin[2(x + π/6)]，所以向左平移π/6

**铁律：平移量 = 括号里的常数 / x的系数。先提系数，再看平移。**

### 3.2 伸缩变换

**横向伸缩（x上操作）**：

$$y = f(x) \xrightarrow{\text{横坐标变为原来的}\frac{1}{\omega}\text{倍}} y = f(\omega x) \quad (\omega > 0)$$

- ω > 1：横向压缩（变窄），周期变为原来的1/ω
- 0 < ω < 1：横向拉伸（变宽），周期变为原来的1/ω

**纵向伸缩（整体上操作）**：

$$y = f(x) \xrightarrow{\text{纵坐标变为原来的}A\text{倍}} y = A \cdot f(x) \quad (A > 0)$$

- A > 1：纵向拉伸（变高）
- 0 < A < 1：纵向压缩（变矮）

**口诀：横除纵乘**（横向变换除以倍数，纵向变换乘以倍数）

### 3.3 对称变换

**关于x轴对称**：

$$y = f(x) \xrightarrow{\text{关于}x\text{轴对称}} y = -f(x)$$

（每个点的y坐标取反，x坐标不变）

**关于y轴对称**：

$$y = f(x) \xrightarrow{\text{关于}y\text{轴对称}} y = f(-x)$$

（每个点的x坐标取反，y坐标不变）

**关于原点对称**：

$$y = f(x) \xrightarrow{\text{关于原点对称}} y = -f(-x)$$

（x和y都取反，相当于先关于x轴对称再关于y轴对称）

**关于直线y=x对称（反函数）**：

$$y = f(x) \xrightarrow{\text{关于}y=x\text{对称}} y = f^{-1}(x)$$

（x和y互换，只有一一对应的函数才有反函数）

### 3.4 翻折变换（绝对值变换）

**y = |f(x)|（下翻上）**：

- 保留x轴上方的图像不变
- 将x轴下方的图像沿x轴翻折到上方
- 本质：f(x)≥0时|f(x)|=f(x)；f(x)<0时|f(x)|=-f(x)

**y = f(|x|)（右翻左）**：

- 保留y轴右侧的图像不变
- 将y轴右侧的图像沿y轴翻折到左侧
- 本质：x≥0时f(|x|)=f(x)；x<0时f(|x|)=f(-x)
- 结果：y=f(|x|)一定是偶函数（关于y轴对称）

**⚠️ 注意区分**：
- |f(x)|：绝对值加在函数值上 → 下翻上
- f(|x|)：绝对值加在自变量上 → 右翻左

## 四、图像变换的顺序问题（高频易错）

### 4.1 两种标准顺序

**顺序一：先平移，后伸缩（推荐，不容易错）**

y = f(x) → 向左平移a → y = f(x+a) → 横坐标压缩为1/ω → y = f(ωx + a)

这种顺序下，平移量直接是a，不需要除以ω。

**顺序二：先伸缩，后平移（容易错）**

y = f(x) → 横坐标压缩为1/ω → y = f(ωx) → 向左平移a → y = f[ω(x+a)] = f(ωx + ωa)

这种顺序下，平移量是a，但最终括号里的常数是ωa，所以如果已知最终式y=f(ωx+φ)，要反推平移量，必须φ/ω。

### 4.2 已知最终式反推变换过程

**例**：y = sin(2x + π/3) 是由 y = sinx 经过怎样的变换得到的？

**方法一（先平移后伸缩）**：
1. y = sinx 向左平移π/3 → y = sin(x + π/3)
2. 横坐标压缩为原来的1/2 → y = sin(2x + π/3)

**方法二（先伸缩后平移）**：
1. y = sinx 横坐标压缩为原来的1/2 → y = sin2x
2. 向左平移π/6（不是π/3！）→ y = sin[2(x + π/6)] = sin(2x + π/3)

**关键结论**：平移量取决于变换顺序。先平移后伸缩，平移量是φ；先伸缩后平移，平移量是φ/ω。

## 五、常见题型与解题步骤模板

### 题型1：图像变换求解析式

**解题步骤**：
1. 确定原函数 y = f(x)
2. 按题目给出的变换顺序，逐步替换
   - 平移：x→x±a（左右），整体±b（上下）
   - 伸缩：x→ωx（横向），整体×A（纵向）
   - 对称：x→-x（y轴），整体→-整体（x轴）
3. 化简最终表达式
4. 验证：取一个特殊点，看变换前后是否对应

**⚠️ 易错**：先伸缩后平移时，平移量要除以系数。

---

### 题型2：已知变换后的解析式，反推变换过程

**解题步骤**：
1. 将最终式化为标准形式 y = A·f[ω(x ± a)] ± b
   - 关键：把ω提出来，写成ω(x±a)的形式
2. 对照原函数 y = f(x)，读出各个参数：
   - A：纵向伸缩倍数
   - ω：横向伸缩倍数（1/ω）
   - a：左右平移量（左加右减）
   - b：上下平移量（上加下减）
3. 按顺序描述变换过程（通常先平移后伸缩，或先伸缩后平移）
4. 验证：按描述的过程重新算一遍，看是否得到最终式

---

### 题型3：识别函数图像（选择题高频）

**解题步骤（排除法）**：
1. **看定义域**：排除定义域不符的选项
   - 有分母→分母≠0
   - 有对数→真数>0
   - 有偶次根式→被开方数≥0
2. **看奇偶性**：
   - 奇函数→关于原点对称
   - 偶函数→关于y轴对称
   - 非奇非偶→不对称
3. **看特殊点**：代入x=0, x=1等特殊值，看函数值是否与图像匹配
4. **看单调性**：求导或根据基本函数性质判断增减趋势
5. **看极限/渐近线**：x→±∞时函数值的趋势，是否有渐近线
6. **综合排除**：逐步排除错误选项，剩下的就是答案

**口诀**：定义域→奇偶性→特殊点→单调性→极限，五步排除法。

---

### 题型4：利用图像解方程

**解题步骤**：
1. 将方程化为 f(x) = g(x) 的形式
2. 在同一坐标系中画出 y = f(x) 和 y = g(x) 的图像
3. 找出两个图像的交点
4. 交点的横坐标就是方程的解
5. 如果求交点个数，数交点个数即可

**适用场景**：超越方程（指数、对数、三角混合）、求根的个数、判断根的范围。

---

### 题型5：利用图像解不等式

**解题步骤**：
1. 将不等式化为 f(x) > g(x) 或 f(x) < g(x) 的形式
2. 在同一坐标系中画出 y = f(x) 和 y = g(x) 的图像
3. 找出两个图像的交点（交点是不等式的分界点）
4. 观察哪个图像在上方：
   - f(x) > g(x)：取f(x)图像在g(x)上方对应的x范围
   - f(x) < g(x)：取f(x)图像在g(x)下方对应的x范围
5. 写出解集（注意端点是否可取）

---

### 题型6：翻折变换（绝对值函数）

**解题步骤**：
1. 判断是 |f(x)| 还是 f(|x|)
2. |f(x)|：先画y=f(x)，再把x轴下方的部分翻折到上方
3. f(|x|)：先画y=f(x)在y轴右侧的部分，再沿y轴翻折到左侧
4. 利用翻折后的图像解决问题（求值域、单调区间、零点个数等）

## 六、易错点清单

| 编号 | 易错点 | 错误表现 | 正确做法 |
|------|--------|----------|----------|
| 1 | 左加右减搞反 | 认为x旁边加正数应该向右移 | x旁边加正数→向左移（左加右减），用最高点验证 |
| 2 | 平移量不除系数 | y=sin(2x+π/3)认为是向左平移π/3 | 先提系数：y=sin[2(x+π/6)]，平移量是π/6，不是π/3 |
| 3 | 平移和伸缩顺序混淆 | 不考虑顺序直接说平移量 | 先平移后伸缩→平移量是φ；先伸缩后平移→平移量是φ/ω |
| 4 | 上加下减搞反 | 认为函数外面加正数应该向下移 | 函数外面加正数→向上移（上加下减），方向和直觉一致 |
| 5 | 横向伸缩倍数搞反 | y=f(2x)认为横坐标拉伸为2倍 | y=f(2x)横坐标压缩为原来的1/2（ω>1压缩，0<ω<1拉伸） |
| 6 | 对称变换搞反 | y=f(-x)认为是关于x轴对称 | y=f(-x)关于y轴对称；y=-f(x)关于x轴对称；y=-f(-x)关于原点对称 |
| 7 | 翻折变换混淆 | |f(x)|和f(|x|)分不清 | |f(x)|下翻上（绝对值加在函数值上）；f(|x|)右翻左（绝对值加在自变量上） |
| 8 | 图像识别不看定义域 | 直接看形状选答案 | 第一步先看定义域，排除定义域不符的选项 |
| 9 | 图像识别不验证特殊点 | 凭感觉选 | 代入x=0, x=1等特殊值验证 |
| 10 | 解不等式不看端点 | 交点处是否可取搞不清 | f(x)>g(x)时交点不可取（严格大于）；f(x)≥g(x)时交点可取 |
| 11 | 幂函数与指数函数混淆 | 把y=2^x当成幂函数 | 幂函数y=x^α（底数是自变量）；指数函数y=a^x（指数是自变量） |
| 12 | 反函数图像对称记错 | 认为关于y轴对称 | 互为反函数的两个函数图像关于直线y=x对称 |

## 七、典型例题

### 例题1：图像变换求解析式（基础题）

**题目**：将函数 y = sinx 的图像向左平移 π/3 个单位，再将横坐标压缩为原来的1/2，求所得图像的函数解析式。

**解答**：

**第一步：向左平移π/3**

y = sinx → y = sin(x + π/3)（左加，x旁边加π/3）

**第二步：横坐标压缩为原来的1/2**

y = sin(x + π/3) → y = sin(2x + π/3)（横向压缩，x→2x）

**答案**：y = sin(2x + π/3)

**验证**：原函数最高点在x=π/2。
- 平移后最高点在x=π/2 - π/3 = π/6
- 压缩后最高点在x=(π/6)/2 = π/12
- 验证：y=sin(2·π/12 + π/3)=sin(π/6+π/3)=sin(π/2)=1 ✅

**易错点提醒**：这道题是先平移后伸缩，平移量直接是π/3，不需要除以2。如果是先伸缩后平移，平移量就是π/6了。

---

### 例题2：反推变换过程（基础题）

**题目**：函数 y = 2sin(2x - π/6) + 1 的图像可由 y = sinx 的图像经过怎样的变换得到？

**解答**：

**第一步：化为标准形式**

y = 2sin(2x - π/6) + 1 = 2sin[2(x - π/12)] + 1

**第二步：读出各个参数**

- 纵向伸缩：A = 2（纵坐标拉伸为2倍）
- 横向伸缩：ω = 2（横坐标压缩为1/2）
- 左右平移：a = π/12（向右平移π/12，因为是减号）
- 上下平移：b = 1（向上平移1）

**第三步：描述变换过程（先平移后伸缩）**

1. y = sinx 向右平移 π/12 个单位 → y = sin(x - π/12)
2. 横坐标压缩为原来的1/2 → y = sin(2x - π/12)

等等，这里有问题！先平移π/12再压缩，得到的是y=sin(2x - π/12)，不是y=sin(2x - π/6)。

**重新分析**：如果先平移后伸缩，要得到y=sin(2x - π/6)，平移量应该是π/6（因为先平移后伸缩，平移量不除ω）。

让我重新来：

**方法一（先平移后伸缩）**：
1. y = sinx 向右平移 π/6 → y = sin(x - π/6)
2. 横坐标压缩为1/2 → y = sin(2x - π/6)
3. 纵坐标拉伸为2倍 → y = 2sin(2x - π/6)
4. 向上平移1 → y = 2sin(2x - π/6) + 1 ✅

**方法二（先伸缩后平移）**：
1. y = sinx 横坐标压缩为1/2 → y = sin2x
2. 向右平移 π/12 → y = sin[2(x - π/12)] = sin(2x - π/6)
3. 纵坐标拉伸为2倍 → y = 2sin(2x - π/6)
4. 向上平移1 → y = 2sin(2x - π/6) + 1 ✅

**答案**：有两种等价的变换顺序：
- 方法一：右移π/6 → 横缩1/2 → 纵拉2倍 → 上移1
- 方法二：横缩1/2 → 右移π/12 → 纵拉2倍 → 上移1

**易错点提醒**：这道题的关键是平移量取决于变换顺序。先平移后伸缩，平移量是π/6；先伸缩后平移，平移量是π/12。两种顺序都对，但平移量不同。

### 例题3：识别函数图像（基础题）

**题目**：函数 f(x) = $\frac{e^x + e^{-x}}{e^x - e^{-x}}$ 的图像大致是（ ）

**解答**：

**第一步：看定义域**

分母 $e^x - e^{-x} \neq 0$，即 $e^x \neq e^{-x}$，即 $x \neq -x$，即 $x \neq 0$。

所以定义域是 $(-\infty, 0) \cup (0, +\infty)$，x=0处无定义。

**第二步：看奇偶性**

$$f(-x) = \frac{e^{-x} + e^{x}}{e^{-x} - e^{x}} = \frac{e^x + e^{-x}}{-(e^x - e^{-x})} = -f(x)$$

所以f(x)是奇函数，图像关于原点对称。

**第三步：看特殊点和趋势**

当x > 0时，$e^x > e^{-x}$，所以分母 > 0，分子 > 0，所以f(x) > 0。

当x → 0⁺时，$e^x \approx 1+x$，$e^{-x} \approx 1-x$，分子≈2，分母≈2x→0⁺，所以f(x)→+∞。

当x → +∞时，$e^x$主导，分子≈$e^x$，分母≈$e^x$，所以f(x)→1。

所以在x>0时，f(x)从+∞递减到1（因为f(x)>1，验证：f(x)-1 = $\frac{2e^{-x}}{e^x-e^{-x}}$ > 0）。

根据奇函数对称性，x<0时，f(x)从-1递增到-∞。

**答案**：图像关于原点对称，x>0时在y=1上方从+∞递减趋近于1，x<0时在y=-1下方从-1递增趋近于-∞。

**易错点提醒**：
- 不要忘记定义域（x≠0）
- 奇偶性判断要算f(-x)，不要凭感觉
- 极限趋势要分别看x→0和x→∞

### 例题4：翻折变换（中档题）

**题目**：已知函数 f(x) = x² - 2x - 3，画出 y = |f(x)| 和 y = f(|x|) 的图像，并分别求它们的单调递增区间。

**解答**：

**第一步：先画 y = f(x) = x² - 2x - 3**

化为顶点式：f(x) = (x-1)² - 4

开口向上，顶点(1, -4)，对称轴x=1。
与x轴交点：x²-2x-3=0 → (x-3)(x+1)=0 → x=-1, x=3。
与y轴交点：(0, -3)。

f(x)在(-∞,1)递减，在(1,+∞)递增。
f(x)<0的区间：(-1, 3)；f(x)≥0的区间：(-∞,-1]∪[3,+∞)。

**第二步：画 y = |f(x)|（下翻上）**

- 保留x轴上方的部分：(-∞,-1]和[3,+∞)不变
- 将x轴下方的部分(-1,3)沿x轴翻折到上方
- 翻折后，原来的最低点(1,-4)变成最高点(1,4)

**y=|f(x)|的单调递增区间**：
- (-1, 1)：翻折后，原来递减的部分变成递增
- (3, +∞)：原来就递增，保持不变

所以单调递增区间是 (-1, 1) 和 (3, +∞)。

**第三步：画 y = f(|x|)（右翻左）**

- 保留y轴右侧(x≥0)的部分：f(x)在x≥0的部分
- 将y轴右侧的图像沿y轴翻折到左侧(x<0)
- 结果：y=f(|x|)是偶函数，关于y轴对称

x≥0时，f(|x|)=f(x)=(x-1)²-4，在[0,1)递减，在(1,+∞)递增。
x<0时，f(|x|)=f(-x)=(-x-1)²-4=(x+1)²-4，在(-∞,-1)递减，在(-1,0)递增。

**y=f(|x|)的单调递增区间**：
- (-1, 0)：左侧翻折后的递增区间
- (1, +∞)：右侧原有的递增区间

所以单调递增区间是 (-1, 0) 和 (1, +∞)。

**答案**：
- y=|f(x)|的单调递增区间：(-1, 1)∪(3, +∞)
- y=f(|x|)的单调递增区间：(-1, 0)∪(1, +∞)

**易错点提醒**：
- |f(x)|和f(|x|)是两种完全不同的翻折，不要混淆
- |f(x)|是下翻上（改函数值），f(|x|)是右翻左（改自变量）
- 求单调区间时要注意翻折后单调性的变化

### 例题5：利用图像解方程（中档题）

**题目**：方程 $2^x = x + 2$ 的解的个数是______。

**解答**：

**第一步：化为 f(x) = g(x) 的形式**

令 f(x) = 2^x，g(x) = x + 2。

方程的解 = 两个函数图像交点的横坐标。

**第二步：画 y = 2^x 的图像**

指数函数，底数2>1，单调递增，过(0,1)，x轴为渐近线。

**第三步：画 y = x + 2 的图像**

一次函数，斜率1，截距2，过(0,2)和(-2,0)。

**第四步：找交点**

代入特殊值：
- x = 0：f(0)=1, g(0)=2 → f(0) < g(0)
- x = 1：f(1)=2, g(1)=3 → f(1) < g(1)
- x = 2：f(2)=4, g(2)=4 → f(2) = g(2) → 交点！x=2是一个解
- x = 3：f(3)=8, g(3)=5 → f(3) > g(3)

所以在x>0时，从f(0)<g(0)到f(2)=g(2)到f(3)>g(3)，说明在(0,2)之间还有一个交点（因为f从下方穿过g到上方）。

再看x<0：
- x = -1：f(-1)=1/2, g(-1)=1 → f(-1) < g(-1)
- x = -2：f(-2)=1/4, g(-2)=0 → f(-2) > g(-2)

所以在x<0时，从f(-2)>g(-2)到f(-1)<g(-1)，说明在(-2,-1)之间有一个交点。

再看x→-∞时，f(x)=2^x→0，g(x)=x+2→-∞，所以f(x)>g(x)。

**第五步：总结交点个数**

- x<0：1个交点（在(-2,-1)之间）
- x>0：2个交点（一个在(0,2)，一个在x=2）

等等，x=2是一个交点，(0,2)之间还有一个交点，那x>0有2个交点。加上x<0的1个，总共3个交点。

但是让我再验证一下(0,2)之间的交点：
- x=0: f=1, g=2, f<g
- x=1: f=2, g=3, f<g
- x=2: f=4, g=4, f=g

从x=0到x=2，f一直小于g，直到x=2才相等。那(0,2)之间没有交点啊！

让我重新算：
- x=0: f=1, g=2, f<g
- x=1: f=2, g=3, f<g
- x=2: f=4, g=4, f=g
- x=3: f=8, g=5, f>g

所以x>0时，f从下方开始，在x=2处追上g，然后超过。所以x>0只有1个交点（x=2）。

那x<0呢？
- x=-2: f=1/4, g=0, f>g
- x=-1: f=1/2, g=1, f<g
- x→-∞: f→0, g→-∞, f>g

所以x<0时，从x→-∞时f>g，到x=-2时f>g，到x=-1时f<g，说明在(-2,-1)之间有一个交点。然后x→0⁻时f→1, g→2, f<g。

所以x<0有1个交点，x>0有1个交点（x=2），总共2个交点。

等等，让我再仔细看x>0的情况。f(x)=2^x是指数增长，g(x)=x+2是线性增长。在x=2处相交，之后f增长更快，所以x>2时f>g。那x在(0,2)之间f<g，没有交点。

所以总共2个交点：一个在(-2,-1)，一个在x=2。

**答案**：2个解。

**易错点提醒**：
- 不要凭感觉说有几个交点，要代入特殊值验证
- 指数函数和一次函数的交点个数要仔细分析
- 注意x→±∞时的趋势

## 八、方法论结晶

### 8.1 图像变换的统一原理

**输入端变换 → 图像反向；输出端变换 → 图像同向。**

- 加在x旁边（输入端）：左加右减（反向）
- 加在函数外面（输出端）：上加下减（同向）
- x乘ω（输入端）：横向压缩为1/ω（反向）
- 函数乘A（输出端）：纵向拉伸为A倍（同向）

**这个原理解释了为什么左加右减是反的，而上加下减是正的。**

### 8.2 图像识别五步排除法

1. 定义域 → 排除
2. 奇偶性 → 对称特征
3. 特殊点 → 代入验证
4. 单调性 → 趋势判断
5. 极限/渐近线 → 趋势判断

**按这个顺序排除，90%的图像识别选择题都能解决。**

### 8.3 数形结合思想

**方程的解 = 图像交点的横坐标**
**不等式的解集 = 图像上下方对应的x范围**
**函数的零点 = 图像与x轴的交点**

遇到超越方程（指数、对数、三角混合）、求根的个数、判断根的范围时，优先考虑数形结合。

### 8.4 平移量的铁律

**先平移后伸缩 → 平移量 = φ**
**先伸缩后平移 → 平移量 = φ/ω**

**已知最终式 y = f(ωx + φ)，反推平移量时，必须先提ω写成 f[ω(x + φ/ω)]，平移量是 φ/ω，不是φ。**
