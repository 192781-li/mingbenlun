# 信息获取手册

> 本手册规定各类平台、各类信息的最高效、最准确获取方法。
> 核心原则：没有"没法获取"，只有还没想到办法。信息必须真实，宁可多源交叉验证，不可凭单一来源下结论。

---

## 一、视频内容获取

### 1.1 抖音

**首选方法**：doubao-video-extract 技能
```bash
cd /home/user/.super_doubao/super-doubao-runtime/workspace/.skills/doubao-video-extract
# 纯文本/逐字稿/总结（抖音快速路径，不需要下载视频）
python3 scripts/minutes/social_video_to_minutes.py "<分享文本或链接>" --run-lark
# 只下载视频
python3 scripts/minutes/social_video_to_minutes.py "<分享文本或链接>" --media-mode video
```
- 抖音支持纯文本快速路径，直接拿逐字稿/总结，不需要下载视频再转写
- 分享文本可以直接粘贴整段（含"复制打开抖音"等文字），脚本会自动提取链接

**备选方法**：
- web.fetch 抖音分享链接 → 拿到标题、描述、统计数据
- general_search 搜视频标题/作者 → 找到文字版、转载版、评论区总结
- 浏览器打开抖音网页版 → 需要登录时让用户扫码

### 1.2 B站（哔哩哔哩）

**首选方法**：doubao-video-extract 技能
```bash
python3 scripts/minutes/social_video_to_minutes.py "<BV号或链接>" --run-lark
```
- B站有公开Web API，稳定性好
- 支持下载视频、提取字幕、生成逐字稿

**备选方法**：
- B站短链（b23.tv）会自动跳转，web.fetch 可获取标题和描述
- general_search 搜"标题+B站" → 找到文字稿、评论区、相关讨论
- B站字幕可以通过API直接获取（如果UP主上传了字幕）

### 1.3 微信视频号

**难点**：视频号是封闭生态，没有公开API，doubao-video-extract 不直接支持。

**获取方法（按优先级）**：
1. **web.fetch 视频号链接** → 可拿到封面图、标题、描述、作者、发布时间（如阳和平视频号案例）
2. **搜索跨平台转载** → 视频号内容经常被搬运到抖音、B站、微博、公众号。用 `general_search` 搜"作者名+关键词+视频"，大概率找到同一内容的其他平台版本
3. **搜索相关文字内容** → 视频号作者通常在其他平台有文字版（讲座实录、公众号文章、访谈记录）。搜"作者名+主题"找到完整文字版
4. **浏览器打开** → 用 open_url_in_browser 打开视频号链接，可观看视频内容
5. **请用户协助** → 如果以上都不行，请用户描述视频内容或转发文字稿

**实战案例**：阳和平视频号"我姥姥的教育理念"→ web.fetch拿到封面和标题 → 搜索"阳和平 姥姥 教育理念" → 找到人民食物主权网站的完整讲座实录 → 获取完整内容

### 1.4 快手

**首选方法**：doubao-video-extract 技能（同抖音流程）

### 1.5 微博视频

**获取方法**：
1. web.fetch 微博链接 → 拿到正文、图片、视频描述
2. general_search 搜"微博正文关键词" → 找到转载、截图、讨论
3. 浏览器打开微博 → 需要登录时让用户扫码

### 1.6 通用视频获取兜底链

任何平台视频都按以下顺序尝试：
1. doubao-video-extract 技能（支持抖音/快手/B站/直链）
2. web.fetch 链接 → 拿元数据
3. general_search 搜标题/作者/关键词 → 找跨平台转载和文字版
4. 浏览器打开 → 直接观看/截图
5. 请用户协助（登录/描述/转发）

## 二、音乐信息获取

### 2.1 歌词

**优先级排序**：
1. **网易云音乐**（中文歌最全）
   - 直接搜索"歌名 歌手 歌词"
   - web.fetch 网易云歌曲页面 → 拿到歌词
   - API：`https://music.163.com/api/song/lyric?id={歌曲id}&lv=1&tv=1`（lv=原文，tv=翻译）
2. **QQ音乐**（港台/流行歌全）
   - 搜索"歌名 歌手 QQ音乐 歌词"
3. **Genius.com**（英文歌/说唱最权威，有注解）
   - web.fetch `https://genius.com/歌手-歌名-lyrics`
4. **豆瓣音乐**（独立/小众/中文摇滚）
   - 搜索"歌名 豆瓣" → 乐评和讨论
5. **乐队官网/Bandcamp**（独立乐队最准确）
6. **163MusicLyrics**（开源工具，整合网易云+QQ音乐，支持批量、LRC格式）

**歌词准确性验证**：
- 中文歌：网易云为主，QQ音乐交叉验证
- 英文歌：Genius为主，AZLyrics交叉验证
- 小众/独立/方言：找乐队官方发布的歌词本、Bandcamp、实体唱片内页扫描
- 多个来源不一致时，以官方发布（乐队官网、实体歌词本、官方账号发布）为准

### 2.2 专辑/乐队/乐手资料

**权威来源排序**：
1. **Discogs**（discogs.com）——全球最权威的音乐数据库，专辑版本、乐手变动、厂牌、发行时间最准确
2. **MusicBrainz**（musicbrainz.org）——开源音乐百科，结构化数据，乐手变动时间线清晰
3. **AllMusic**（allmusic.com）——专业乐评和乐队传记
4. **Metal Archives**（metal-archives.com）——金属乐最权威，阵容变动、歌词主题、专辑评分
5. **豆瓣音乐**——中文语境下的乐评和专辑信息
6. **Rate Your Music**（rateyourmusic.com）——流派归类和评分
7. **乐队官网/官方社交账号**——第一手信息
8. **维基百科/百度百科**——入门参考，需交叉验证

**乐手变动信息**：
- Discogs 的 "Members" 部分有时间线
- Metal Archives 的 "Lineup" 分Current/Last/Live/Past，带年份
- 乐队官方传记、采访中确认变动原因
- 中文乐队：豆瓣、微博官方账号、乐迷群讨论

### 2.3 高质量采访

**搜索策略**：
- 搜"乐队名 interview"或"乐队名 采访"
- 搜"乐队名 专访 site:douban.com"或"site:zhihu.com"
- 搜"乐队名 访谈 site:bilibili.com"（视频采访）
- 英文乐队：搜"band name interview site:pitchfork.com"或"site:rollingstone.com"或"site:nme.com"
- 中文乐队：搜"乐队名 专访 网易/腾讯/搜狐音乐"
- 播客采访：搜"乐队名 podcast"或"乐队名 播客"

## 三、人物信息获取与验证

### 3.1 基本信息（姓名、出生日期、籍贯、学历）

**权威来源排序**：
1. **维基百科**（中文+英文）——有引用来源，可追溯
2. **Wikidata**（wikidata.org）——结构化数据，出生日期精确
3. **百度百科**——中文人物覆盖广，但可被编辑，需验证
4. **官方网站/官方简历**——大学教师页、机构官网、政府官网
5. **权威媒体报道**——新华社、人民日报、南方人物周刊等
6. **学术数据库**——学者查知网/Google Scholar个人页

**验证原则**：
- 出生日期至少两个独立来源一致才确认
- 中国人物优先查官方简历（大学官网、政府官网）
- 有争议的人物，不同来源可能给出不同信息，要标注分歧
- 百度百科可改，不作为唯一依据

### 3.2 人物经历/事件

**获取方法**：
1. general_search 搜"人物名+事件关键词"
2. 搜"人物名 采访/访谈/自传/回忆录"——第一人称叙述最真实
3. 搜"人物名 site:zhihu.com"或"site:weibo.com"——找到当事人或知情人发言
4. 学术文献：scholar_search 搜"人物名"——找到学术研究中的记载
5. 官方档案/公开文件：政府公告、法院文书、企业工商信息
6. 交叉验证：至少3个独立来源一致才确认事实

### 3.3 人物言论/观点

**严格原则**：
- 说"某某说过什么"必须有出处——视频、文章、书籍、采访
- 搜索时用引号精确匹配：`"人物名" "关键词"`
- 区分"本人说的"和"别人转述的"
- 区分"原话"和"概括"
- 找不到出处就说"未找到确切出处"，不编造
- 网络名言经常被张冠李戴，必须验证

### 3.4 历史事件

**来源优先级**：
1. 一手资料：档案、文件、当时的报道、当事人回忆录
2. 学术研究：peer-reviewed论文、专著
3. 权威媒体调查报道
4. 多来源交叉验证
5. 官方结论保持存疑（用户明确要求），但不必写相反的，标注"官方说法，存疑"

## 四、文字平台内容获取

### 4.1 知乎

- web.fetch 知乎问题/回答链接 → 可拿到正文（部分需要登录）
- general_search 搜"关键词 site:zhihu.com" → 拿到搜索摘要
- 浏览器打开知乎 → 需要登录时让用户扫码
- 知乎专栏文章 web.fetch 通常可直接获取

### 4.2 豆瓣

- 豆瓣电影/读书/音乐页面 web.fetch 可获取简介、评分、短评
- 豆瓣影评/乐评：web.fetch 评论页
- 豆瓣小组讨论可能需要登录
- 移动端JSON API（m.douban.com）比PC端限制少

### 4.3 微信公众号文章

- web.fetch 公众号文章链接（mp.weixin.qq.com）→ 通常可直接获取正文
- 视频号链接（weixin.qq.com/sph/）→ 只能拿到元数据，内容按视频方法获取
- 搜"文章标题/关键词 site:mp.weixin.qq.com" → 找到特定文章
- 搜狗微信搜索（weixin.sogou.com）可搜公众号文章

### 4.4 微博

- web.fetch 微博链接 → 拿到正文和图片
- general_search 搜"关键词 site:weibo.cn" → weibo.cn比weibo.com限制少
- 浏览器打开 → 需要登录时让用户扫码

### 4.5 学术内容

- scholar_search（学术搜索工具）→ 论文、专著、引用
- general_search 搜"关键词 filetype:pdf" → 找到PDF文档
- 知网/Google Scholar/百度学术
- 图书馆数字资源

### 4.6 政府/官方信息

- 中国政府网（gov.cn）、各部委官网
- 国家统计局（stats.gov.cn）——统计数据
- 裁判文书网（wenshu.court.gov.cn）——法院判决
- 企业信用信息公示系统——企业工商信息

## 五、通用搜索策略

### 5.1 搜索关键词构造

- **精确匹配**：用引号 `"完整短语"`
- **指定站点**：`关键词 site:zhihu.com`
- **指定文件类型**：`关键词 filetype:pdf`
- **排除干扰**：`关键词 -广告 -推广`
- **组合搜索**：一次并行搜3个不同角度的query
- **中英文双搜**：中文搜一遍，英文搜一遍，信息更全

### 5.2 信息验证三原则

1. **多源交叉**：至少2-3个独立来源一致才确认
2. **追溯一手**：找到信息的原始出处，不依赖转载
3. **标注不确定性**：有分歧的信息要标注"来源A说X，来源B说Y"

### 5.3 搜索失败时的兜底

1. 换关键词（同义词、英文名、缩写）
2. 换搜索引擎/平台（百度→Google→知乎→微博→B站）
3. 换语言（中文→英文→日文）
4. 从相关人物/事件侧面切入
5. web.fetch 直接打开可能的URL
6. 浏览器打开页面人工查看
7. 请用户提供更多线索
