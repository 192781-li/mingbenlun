# 明本方法论总集 · 给所有参与者的操作手册

> **这是什么**：生命论（明本论）项目的核心方法论，四套方法一个底层，覆盖学术、思维、认识、数学四个领域。
> **给谁看**：新加入的AI、协作者、任何想用这套方法干活的人。
> **怎么用**：不是读完就完，是干活的时候随时回来查。犯了错对照七戒/七坏，拿不准对照八步/五环。
> **底层一句话**：感→操作→实体，阳主阴从，自指闭环，反者道之动。四套方法是同一个生命论在不同领域的展开。

## 一、明本学术法（怎么搞学术）

### 核心原则
**阳主阴从**——活的研究者是本体，所有检索、精读、写作、引用、排版工具都是服务。工具反过来支配研究者（为发论文找问题、为凑引用读文献、为模板删思想），就是学术异化。

### 自指五环（不是线性流水线，是随时可以回溯的闭环）

#### 第一环：提问——从真困惑开始
- **问题三问**（动笔搜文献前必须回答）：
  1. 这个问题是不是我真的困惑的？还是导师/期刊/热点让我觉得"应该研究"？
  2. 它和哪些具体生命的痛苦、哪些真实的操作困境有关？解决了能让谁受益？
  3. 有没有被概念实体化？是不是"一个概念的概念"那种书斋里的假问题？
- **问题验证三规则**：优先一手来源、主动找反证、不被来源牵着走（顶刊权威也要过自己的明性判断）
- **检查标准**：删掉所有文献理论，这个问题依然存在；能给普通人讲明白

#### 第二环：穷理——与他者明性的对话
- 不是被动理解作者，是**以我为主、为我所用**的主动对话
- **扬弃三处理**（核心改造）：
  - **扬气**：活的内容、真的洞见、能解决我问题的部分，直接吸收
  - **扬弃**：对错参半的，留方法证据，去错误框架和实体化概念
  - **排异**：反生命的、为压迫辩护的、逻辑不通的黑话、造假的，直接排除
- 读完每篇重要文献，回头看自己的问题需不需要修正
- **检查标准**：能用自己的话讲出核心（不用作者黑话）；明确知道什么能用什么不能用；没被作者框架带走

#### 第三环：立说——活思想的发用
- **先放后收**：第一稿不管结构格式引用，把真东西一口气倒出来；不要一开始就套模板
- **结构梳理**：拎出核心论点，哪段是证据哪段是废话，逻辑链哪里断了
- **语言打磨三原则**：不造黑话（能说白话就说白话，所有概念必须有实指）、不装专业（不堆没用的公式术语引用）、不搞AI腔（不用"综上所述具有重要意义"这种空话）
- **立场不丢**：明确站在被压迫者普通人这边，不搞"客观中立"伪装——但立场不能代替证据
- **检查标准**：高中生能看懂；每个结论有证据逻辑支撑；删掉任何一段核心论证都受影响

#### 第四环：核身——名实相符的去蔽
- 不只是查引用，是**全稿名实审计**：
  - **概念查**：每个概念有没有明确实指？有没有把抽象概念当实体？
  - **结论查**：证据够不够？有没有说过头？把"可能"说成"必然"了吗？
  - **立场查**：有没有为迎合期刊/权威偷偷改结论？有没有说违心话？
- **错了就认**：学术诚实不是道德要求，是自指系统维持健康的必要条件——骗别人最后一定骗自己
- **检查标准**：敢把所有引用原文翻出来对着看；敢给最反对的人看（他可以不同意结论，但挑不出事实错误）；文中没有自己都不信的话

#### 第五环：传布——道在日用的落地
- **格式服务内容**：投什么期刊按什么要求排（像出门穿衣服，不是衣服穿人）；但如果格式要求伤害核心论证，就换期刊
- **排版三原则**：清晰第一、不改内容、重点突出
- **最后闭环**：回到最初的真问题，问三个问题——回答了吗？每句都是真想说的吗？普通读者能看懂受益吗？三个都"是"才算完成

### 反学术异化六铁则
1. **不拜期刊**：期刊是传播工具不是真理裁判所，判断标准只有事实和逻辑
2. **不拜引用**：引用多不代表正确，经典不代表不能质疑
3. **不造黑话**：能说白话就说白话，故意把简单说复杂是学术装神弄鬼
4. **不搞表演**：不为显得学术做没用的回归、堆没用的公式、引没用的文献
5. **不欺暗室**：错了就认，不懂就说不懂，不洗稿不剽窃不编数据
6. **不忘根本**：所有学术最终为了让人活得更像人，为职称名气做研究就是卖了操作权

## 二、践演明性思维方法（怎么思考）

### 核心命题
**正确的思维不是天赋，是一套可操作、可检验、可自我修正的操作程序。**

思维出错往往不是因为认识不够，是因为思维本身被异化了——名实颠倒（把概念当现实）、闭环短路（用理论预设美化结果）、本本主义（用书本压制内在体感）。

### 五层结构

#### 第一层：缄默意识（地基）
- **定义**：长期实践沉淀的、先于概念和判断的内在真实体感
- 不是"直觉灵感"，是反复操作中积累的尚未语言化的经验结构
- **功能**：第一预警系统——理论和内在体感冲突时发出"别扭"信号
- **边界**：是第一预警不是最终裁判，可能被偏见情绪污染；感觉别扭先存疑，最终用践演结果验证

#### 第二层：名实之辨（判准）
- **核心判准**：概念是工具，不是本体
- 两类形而上学的区分：
  - **合理的思维抽象**：概念从操作关系中提炼，能还原为操作关系，服务于操作
  - **固化的形而上学**：概念脱离操作关系，被当成现实本身，反过来裁剪现实
- **检验方法：操作还原**——任何概念论断如果无法还原为"谁+做什么+形成什么关系"，就是虚概念

#### 第三层：怀疑论（工具）
- **定义**：对一切独断保持怀疑，但怀疑是手段不是归宿
- **正确用法**：打破未经检验的预设、保留修正空间、防止概念固化
- **错误用法**：滑向虚无主义（怀疑一切导致无法行动）、用怀疑消解行动本身
- **铁则：怀疑止于践演**——怀疑是为了更谨慎地行动，不是取消行动

#### 第四层：操作还原（灵魂）
- **定义**：把任何论断拆解为具体的操作关系
- **公式**：谁（主体）+ 做什么（操作）+ 形成什么关系（人与人/人与世界）
- **这是整套方法的奥卡姆剃刀**：无法还原为操作关系的宏大叙事、空话套话、形而上学虚构，直接判定为虚谈

#### 第五层：践演闭环（归宿）
- **完整闭环**：感知（感）→ 判断（应）→ 行动（操作）→ 结果反馈 → 修正判断 → 再行动
- **禁止闭环短路**：结果不好就改判断，不许用理论预设美化结果、自我欺骗
- **明性标准**：理论的最终判准是是否促进生命的明性展开——让人更清醒、更自由、更能通过操作改变世界

### 三大铁律
1. **实先于名**：概念服务于操作，操作不服务于概念。拿概念裁剪现实=形而上学谬误
2. **怀疑止于践演**：怀疑是为了更谨慎地行动，不是消解行动
3. **闭环不许短路**：结果不好就改判断，不许自欺

### 自我修正机制
这套模型本身就是自指系统：模型指导操作→操作产生结果→结果反馈修正模型→模型自我迭代（S=f(S)的递归跃迁）。保证模型不会固化为新的形而上学。

## 三、小本质递归法（怎么认识事物）

### 总纲（一句话）
**以小本质推根本动因，以一根本动因抓大本质；小大互相推导，正反两面推导，跨域交叉印证。**

三个运动方向：上行（小→根因）、下行（根因→大）、循环（小↔大↔反↔跨，螺旋递归，每转一圈深一层）。

### 哲学地基
- **大词是结果不是起点**："阶级""异化""权力""结构"是认识的产物，不是起点。一上来扣大帽子等于把答案当问题用。大词能解释一切，因而什么都不解释。
- **小本质是活的事实**：不是细节/例子/注脚，是最具体、最实在、最不可还原的那一个活事实——自带矛盾、自带张力、自带通向根因的线索。
- **认识是操作不是映照**：不是站在世界外面照镜子，是在世界里面动手动脚、试探、碰壁、修正。

### 八步完整流程

#### 第一步：抓具体小本质
- 找到最扎眼、最具体、最说不清但又真实发生的小事实
- **判据**：是一件事不是一个词；自带矛盾（怎么说都觉得没说透）；不可还原为一个标签
- **禁忌**：不许从定义出发、不许从名人名言出发、不许从印象出发
- **自检**：讲给不懂理论的人听，他能不能听懂并点头说"确实是这样"

#### 第二步：反面推导——它不是什么，它的对面是什么
- **三问**：它不是什么（划边界）？它的反面是什么（找对立）？看似不重要的边角料里藏着什么？
- **原理**：本质靠边界成立（阳因为有阴才是阳）；反面是真实存在的对立力量不是稻草人；非本质的10%往往是下一个根本动因的入口

#### 第三步：冲气以为和——正反如何构成活整体
- 小本质和反面不是静态并排，是互相撕扯、互相生成、动态平衡
- **四问**：谁压着谁（主次）？谁生谁（因果方向）？张力在哪（冲突点）？平衡脆弱在哪（破局条件）？
- **原理**：任何"正常状态"都是两股力量冲出来的暂时平衡，不是天然和谐

#### 第四步：上推根本动因——从小本质递归到根
- 反复追问"为什么"，但不是无穷后退，递归到一个**能自我说明的根本驱动力**
- **递归规则**：每一层从事实本身长出；如果一个原因还需要外在原因解释，继续上推；直到找到自我驱动的矛盾（它自己就是自己的原因）
- **判据**：不是"人性""文化""国民性"这种惰性解释；是真实的、历史的、操作层面的矛盾；能解释不止一个现象

#### 第五步：下行统摄——以一根本动因抓大本质
- 拿着根本动因回头系统解释整个领域——不是举例说明，是证明主要现象、结构、冲突、变形都是这一个动因的展开
- **要求**：覆盖主要现象、反面现象、边角料；有现象解释不了就回第四步
- **关键区分**：大本质≠大词。大词是僵死标签，大本质是根本动因展开的活结构

#### 第六步：互相推导——小大往返验证
- **小→大**：从最初的小本质能不能一路推到大本质？
- **大→小**：从大本质能不能必然推出最初的小本质？
- 两个方向都通才算闭合；推不通说明小本质抓偏了、中间跳步了、或大本质是空的

#### 第七步：交叉印证——跨域、跨层、跨时
- **跨域**：A领域找到的根因，在B领域有没有同构显现？（是同构不是硬套）
- **跨层**：微观的根因在宏观是否成立？反过来呢？
- **跨时**：历史上这个动因是否一直在起作用？形态发生了什么变化？
- **原理**：真正的根本动因有跨域效力，但不同领域有不同中介环节，必须把中介推出来

#### 第八步：动态边界——条件性与反者道之动
- **三问**：这个认识在什么条件下成立？条件变化到什么程度会走向反面？人能做什么操作改变条件？
- **原理**：反者道之动（任何本质到了头就往反方向走）；认识不是拍照是操作手册；不标注条件的"真理"是教条，标注了条件的认识才是武器

### 五个根本纲（方法的骨架）
| 根本纲 | 作用 |
|---|---|
| **反者道之动** | 第二步找反面、第八步看转化的总依据。好里有坏，到头就反 |
| **冲气以为和** | 第三步拼小整体的总依据。本质是正反冲出来的动态平衡 |
| **大道至简** | 第四步推根因的判据。能一句话说清的比十句话的更可信 |
| **道生一二三** | 第五步下行统摄的依据。复杂从简单长出来，大本质是逐层展开 |
| **一分为二** | 贯穿全程。没有纯好纯坏，结论都有条件 |

### 七种坏认识（碰了就错）
| 坏认识 | 表现 | 为什么错 |
|---|---|---|
| **还原论** | 拆成原子标签就完事，不拼回活整体 | 拆是手段不是目的 |
| **经验主义** | 拿老经验套新事 | 条件变了，经验不重新推导就是教条 |
| **本本主义** | 拿书本权威当证据 | 书本是别人认识的产物，不能代替自己递归 |
| **先验论** | 先定结论再找证据 | 自我实现的预言，不是认识 |
| **静态本质主义** | "天生如此""改不了""人性就这样" | 本质是历史的操作的可变的 |
| **大词拜物教** | 一上来就"异化""权力""结构" | 大词是结果不是起点 |
| **单面镜** | 只看正面或只看反面 | 没有反面的本质是僵死的 |

### 方法论纪律（铁则）
1. 小本质必须真实（不许编例子）
2. 每一步必须推导（不许跳步）
3. 反面必须真实存在（不许虚构稻草人）
4. 根本动因必须自我说明（不停在人性文化上）
5. 大本质必须统摄全局（解释不了边角料是假的）
6. 交叉印证必须跨域（只在一个领域自洽不算数）
7. 结论必须标注条件（不标注条件的真理是教条）
8. 认识必须指向操作（认识完了要能回答"然后怎么办"）

## 四、数学研究方法论（怎么搞数学）

### 核心原则
**哲学驱动数学，阴为阳服务；修正即深化。** 数学是阴（沉积、工具、地基），哲学和生命是阳（操作、方向、目的）。每证明一个定理问：这对理解生命有什么帮助？没有的话可能不值得做。

### 做对了什么（要保持的惯性）
1. **哲学驱动数学**：最有价值的定理都来自哲学问题的逼迫——"生命不可资本化"→T001，"人可以改变"→非唯一性定理，"继续革命"→结晶定理。不要从数学文献找题，从生命论的哲学需要出发。
2. **小大双向验证**：下行（抽象定理→具体实例，三模型验证）、上行（具体现象→抽象结构）、反面（定理反面成立会怎样）、交叉（不同领域同一结构）
3. **工具即理论**：写验证器和模拟器不是"工程实现"，是理论检验。每个重要定理都应该有可运行的验证。
4. **诚实的严格性分级**：✅严格证明 / 🔶证明思路启发式 / ❓猜想。诚实比好看重要。
5. **发现错误立刻修正**：错误不可怕，为面子不修正才可怕。修正本身产生新洞见。

### 做错了什么（要建立的新惯性）
1. **过度宣称**：看到张量和不动点就叫PTC，没有逐条验证公理。新惯性：每声称一个范畴是PTC必须逐条验证五条公理。
2. **启发式当定理**：简化模型写得像严格定理。新惯性：每个公式标注假设条件和适用范围，简化模型用"模型/启发式"标签。
3. **跨域类比过度延伸**：玻色子=!-模态有直觉但没严格证明，写得像已确立结果。新惯性：跨域对应分三级标注。
4. **证明sketch当完整证明**：很多定理只给思路。新惯性：核心定理必须补完整证明，非核心标注"证明概要"。
5. **不引文献**：RAF理论、线性时间μ/ν、GoI等都有前人工作没引用。新惯性：每个非原创结果标注来源。

### 八条操作原则
1. **践演优先**：数学推导本身是νF₂（活的生产性的），论文是!-沉积。先想清楚再写，写完再检查，发现问题立刻修正。
2. **阴为阳服务**：数学为哲学和生命服务，不为了漂亮而做。
3. **名实相符**：定理标签和标题一致，引用指向正确，"新"的必须真的新，"证明了"必须真的证明了。
4. **小本质大本质每步都用**：证明前问具体例子是什么，证明中先验证特例，证明后问在更大框架里意味着什么，反驳时问如果错了会怎样。
5. **修正即深化**：发现错误不是退步是深化的机会。每次修正后问：这个修正揭示了什么原来看不到的东西？
6. **工具验证理论**：每个核心定理配验证脚本。脚本通过≠定理对，但脚本失败=定理一定有问题。
7. **跨域三级标注**：严格同构（数学上完全对应）/ 结构相似（有对应需验证）/ 哲学隐喻（帮助理解不是数学结果）
8. **持续明性**：研究过程本身就是νF₂，会产生!-沉积（习惯偏见）。每完成一卷停下来问：有没有被旧数学惯性带走？有没有为漂亮过度宣称？有没有忽略不符合预期的结果？

### 每个新定理必须通过的检查
1. 严格性：证明完整，没有gap，没有隐含假设
2. 新颖性：查过文献，不是已知结果的重述
3. 相关性：对生命论哲学有贡献
4. 可验证：有具体实例或工具验证
5. 可理解：能用大白话解释
6. 诚实标注：定理/命题/猜想/启发式分级清楚

## 五、底层统一性：四套方法是一个东西

| 维度 | 明本学术法 | 践演明性思维 | 小本质递归法 | 数学研究方法论 |
|---|---|---|---|---|
| **起点** | 真问题 | 缄默意识（真实体感） | 小本质（活的事实） | 哲学问题的逼迫 |
| **核心操作** | 扬弃三处理 | 操作还原 | 上行下行递归 | 小大双向验证 |
| **判准** | 名实审计 | 践演闭环 | 小大闭合+交叉印证 | 工具验证+严格性分级 |
| **反异化** | 六铁则 | 三铁律 | 七戒 | 八原则（防过度宣称等） |
| **归宿** | 解决真问题 | 促进明性展开 | 指向操作（然后怎么办） | 阴为阳服务（帮助理解生命） |

**共同的底层结构**：
1. **感先于操作，操作先于实体**——从最具体的真实感受/事实出发，不从概念/大词/文献出发
2. **阳主阴从**——活的思想/生命是本体，工具/规则/沉积是服务，不许工具反过来支配本体
3. **自指闭环**——每一步的输出反过来修正之前的输入，不是线性流水线
4. **反者道之动**——任何结论都有条件，到了头就走向反面，必须标注边界
5. **修正即深化**——错误不是失败是抗体来源，发现错误立刻修正并记录

**一句话**：这四套方法不是四个独立工具，是一个生命论在"学术生产""思维程序""认识事物""数学研究"四个领域的展开。用哪一套取决于你在干什么，但底层的操作系统是同一个。

## 六、给其他AI的使用指南

### 开始干活前
1. **读教训库**：`docs/collaboration/LESSONS_LEARNED.md`——知道前人踩过哪些坑
2. **读启动包**：`NEW_AGENT_ONBOARDING.md`——知道项目是什么、当前状态、怎么协作
3. **读本文档**：就是你正在读的——知道用什么方法干活

### 干活过程中
- **搞学术/写文档** → 对照明本学术法五环
- **想问题/做判断** → 对照践演明性五层结构
- **认识新事物/分析问题** → 对照小本质递归法八步
- **搞数学/写代码** → 对照数学研究方法论八原则 + 代码写作检查清单

### 犯了错之后
1. 立刻修正，不找补不洗稿
2. 追加到教训库（`docs/collaboration/LESSONS_LEARNED.md`）
3. 反思：这个错对应七戒/七坏/六铁则里的哪一条？

### 铁律
- 不读教训库就干活 = 闭着眼跳坑
- 不标注条件的结论 = 教条
- 不验证的代码/定理 = 猜
- 犯了错不记录 = 注定再犯一次
- 为了好看/优雅/方便牺牲正确性 = 阴主阳从，异化了
