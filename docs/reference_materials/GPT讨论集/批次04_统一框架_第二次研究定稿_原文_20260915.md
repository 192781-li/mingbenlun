# 生命论（明本论）政治哲学---政治经济学统一框架

## 第二次研究定稿：从在感、操作、自指到价值、剩余价值、资本、国家与世界体系

> 版本：2026-09-15\
> 用途：作为生命论研究的可迁移母文档；可直接交给其他 AI 继续研究。\

# 0. 研究目标与方法

生命论的根本问题不是把马克思主义换一套词，而是把政治经济学重新接回生命论的本体论：

``` text
在感
→ 操作
→ 自指
→ 生命主体
→ 实践
→ 劳动
→ 社会再生产
→ 价值形式
→ 剩余劳动
→ 剩余价值
→ 资本
→ 制度
→ 国家
→ 世界体系
→ 异化/解放
```

马克思主要解释：

``` text
商品 → 价值 → 劳动力 → 剩余价值 → 资本积累
```

生命论增加的问题是：

``` text
这些经济关系究竟改变了谁的操作权？
谁获得了反馈能力？
谁失去了自指能力？
资本积累是否同时意味着生命主体能力积累？
```

因此本框架不把"生命价值"直接等同于马克思的"价值"。

------------------------------------------------------------------------

# 1. 五层价值对象：解决"生命价值"与马克思价值混淆

## 1.1 使用价值

`[M][D]`

商品/对象满足某种需要的能力：

``` text
U(x; S, E)
```

它取决于主体 `S` 与环境 `E`。

------------------------------------------------------------------------

## 1.2 交换价值

`[M]`

商品在交换关系中表现出的比例：

``` text
x : y = a : b
```

交换价值是关系形式，不等于对象本身的物理性质。

------------------------------------------------------------------------

## 1.3 马克思意义上的价值

`[M]`

在资本主义商品生产理论中，价值量由生产商品所需要的社会必要劳动时间决定。

形式化写作：

``` text
V_M(x) = λ · T_SNL(x)
```

其中：

-   `V_M(x)`：商品 x 的价值量
-   `T_SNL(x)`：社会必要劳动时间
-   `λ`：选定价值单位后的比例常数

注意：

``` text
V_M(x) ≠ 个别劳动者实际花费的时间
```

一个生产者效率低而花费双倍时间，并不会因此自动创造双倍社会价值。

------------------------------------------------------------------------

## 1.4 生命贡献量

`[L][A][?]`

生命论需要一个不同的量：

``` text
L(x; S, E, τ) = 对生命主体 S 在环境 E、时间尺度 τ 上的自指能力产生的净贡献
```

最弱的定义可以写成：

``` text
L ≈ ΔV_self
```

其中：

``` text
V_self = 生命主体实际维持、修正和扩大自身操作循环的能力
```

这里的 `≈` 故意不写成 `=`，因为目前没有完成经验测量体系。

------------------------------------------------------------------------

## 1.5 生命价值与经济价值的严格关系

核心：

``` text
V_M ≠ L
```

允许出现：

``` text
V_M ↑，L ↓
V_M ↓，L ↑
V_M ↑，L ↑
V_M ↓，L ↓
```

例如：

-   市场价格很高的奢侈品可以对整体生命自指贡献有限；
-   免费公共教育可能市场价值很低，却显著提高人的长期操作能力；
-   一项提高劳动生产率的技术可能提高资本收益，同时降低劳动者自主性；
-   同一技术如果转化为缩短工作时间，则可能提高生命自指能力。

因此生命论不是把"价值"重新定义成"有益生命"，而是**建立两个不同层次的价值理论**：

``` text
经济价值理论：解释社会交换与资本运动
生命价值理论：评价生产活动对生命自指的影响
```

这是本框架最重要的防混淆原则。

------------------------------------------------------------------------

# 2. 劳动---劳动力：价值理论的关键接口

## 2.1 劳动力不是劳动

`[M]`

``` text
LP = 劳动力
LB = 实际劳动活动
```

资本主义劳动关系中出售的是：

``` text
LP
```

而不是一个已经完成的 `LB` 产品。

劳动力的特殊性在于：

``` text
LP 的使用价值
=
进行劳动并创造新价值的能力
```

马克思正是通过劳动力商品解释剩余价值何以可能。

------------------------------------------------------------------------

## 2.2 劳动力价值

`[M]`

劳动力价值取决于再生产劳动力所需要的社会必要劳动时间。

可以形式化：

``` text
V_LP = Σ_j a_j · V_M(G_j) + R
```

其中：

-   `G_j`：维持/再生产劳动力所需的生活资料
-   `a_j`：所需数量
-   `R`：历史形成的社会、教育、训练等再生产成本

这里的 `R` 只是为了形式化展开，不应冒充马克思原著中的固定数学公式。

------------------------------------------------------------------------

# 3. 必要劳动与剩余劳动：价值---剩余价值第一桥

`[M]`

工作日：

``` text
T = T_N + T_S
```

-   `T_N`：必要劳动时间
-   `T_S`：剩余劳动时间

在简单假设下：

``` text
v ∝ T_N
s ∝ T_S
```

于是：

``` text
s/v = T_S/T_N
```

这就是剩余价值率/剥削率的核心表达。

马克思的逻辑是：劳动力按其价值被购买，但劳动力的实际使用可以持续超过再生产其价值所需的劳动时间；由此形成剩余价值。

------------------------------------------------------------------------

# 4. 绝对剩余价值与相对剩余价值

## 4.1 绝对剩余价值

``` text
T ↑
T_N 近似不变
⇒ T_S ↑
```

即通过延长工作日增加剩余劳动。

------------------------------------------------------------------------

## 4.2 相对剩余价值

工作日保持：

``` text
T = constant
```

若生活资料生产率提高：

``` text
T_N ↓
```

则：

``` text
T_S = T - T_N ↑
```

因此：

``` text
s/v ↑
```

这也是为什么"技术进步"不能直接等同于"劳动者解放"。

------------------------------------------------------------------------

# 5. 第一重大修正：剩余价值不等于异化

不能建立：

``` text
s > 0 ⇒ A > 0
```

也不能建立：

``` text
s > 0 ⇒ V_self < 0
```

因为：

``` text
剩余劳动
```

是生产关系中的一个结构量，而：

``` text
异化
```

是生命主体自指能力与其劳动成果、时间、社会关系、规则之间的关系状态。

应至少同时观察：

``` text
s          剩余价值
w_r        实际工资
T_work     工作时间
T_free     自由时间
O_p        生产操作权
O_o        剩余配置权
O_s        规则修改权
V_self     自指能力
A          异化负担
```

因此可能出现：

``` text
s ↑
w_r ↑
T_free ↑
O_p ↑
O_o ↑
O_s ↑
V_self ↑
```

此时不能简单把"剩余价值存在"直接判定为生命能力下降。

生命论真正追问：

``` text
剩余由谁控制？
剩余是否反馈给生产者？
剩余是否转化为公共生命能力？
生产者是否因此获得更多操作权？
```

------------------------------------------------------------------------

# 6. 剩余价值---资本：第二桥

马克思的资本循环：

``` text
M - C ... P ... C' - M'
```

其中：

``` text
C = LP + MP
```

即：

``` text
劳动力 + 生产资料
```

生产过程：

``` text
P : (LP + MP) → C'
```

商品实现后：

``` text
C' → M'
```

并且：

``` text
M' = M + ΔM
```

在价值量守恒的简化资本主义生产分析中：

``` text
ΔM = s
```

但必须注意：

``` text
个别企业利润 ≠ 该企业直接生产的剩余价值
```

因为竞争、价格、部门结构等会使社会剩余价值在不同资本之间重新分配。

------------------------------------------------------------------------

# 7. 常量资本 c 与可变资本 v：必须保持马克思原义

资本分解：

``` text
K = c + v
```

其中：

-   `c`：不变资本
-   `v`：可变资本

在马克思的价值生产分析中：

``` text
c → 转移既有价值
v → 购买劳动力
LB → 创造新价值
```

于是产品价值：

``` text
W = c + v + s
```

注意：

``` text
“机器不创造新价值”
```

是特定于马克思价值理论的命题，不等于说机器没有生产力。

必须严格区分：

``` text
物质生产力 ≠ 马克思价值意义上的新价值创造
```

------------------------------------------------------------------------

# 8. 资本的"伪自指"：生命论对资本的真正接入点

`[A][?]`

设资本存量：

``` text
K_t
```

剩余价值：

``` text
s_t
```

再投资率：

``` text
ρ ∈ [0,1]
```

折旧/损耗：

``` text
δ ≥ 0
```

则一个最小动态模型：

``` text
K_(t+1) = K_t + ρs_t - δK_t
```

若：

``` text
ρs_t > δK_t
```

则：

``` text
K_(t+1) > K_t
```

形成：

``` text
K
→ 生产
→ 剩余
→ K'
→ 更多生产能力
→ 更多剩余
→ K''
```

这在形式上类似：

``` text
S = f(S)
```

但绝不能因此说：

``` text
资本 = 生命
```

严格说：

``` text
资本是社会关系中的派生性自增殖结构。
```

所以生命论暂用：

``` text
资本 ≈ 伪自指 / 派生自指
```

------------------------------------------------------------------------

# 9. "资本是伪自指"为什么不是纯比喻

关键不是"资本会增长"，因为很多非生命东西也会增长。

真正结构是：

``` text
人的活劳动
↓
商品生产
↓
剩余价值
↓
资本积累
↓
资本重新组织人的劳动
↓
新的活劳动
```

即：

``` text
人 → 资本
资本 → 人
```

于是：

``` text
S_human → K → S_human
```

资本并非自身独立存在，而是把人的生产能力组织进自己的循环。

所以：

``` text
资本的“自我增殖”
=
社会关系对人的生产能力进行递归组织的结果
```

这是比"资本像活物"更严格的生命论表述。

------------------------------------------------------------------------

# 10. 自指转移：统一政治经济学核心

定义：

``` text
O_i = 个体/群体 i 的操作权
V_i = 个体/群体 i 的自指能力
K = 资本的组织能力
```

正常反馈：

``` text
S_i → G → N
↑         ↓
└─────────┘
```

异化转移：

``` text
S_i → 劳动 → K
             ↓
        资本组织能力
             ↓
        重新组织 S_i
```

若长期：

``` text
K ↑
O_i ↓
V_i ↓
```

则可以称：

``` text
自指转移
```

这比"剥削就是坏"更精确，因为它提出了一个可检验方向：

``` text
资本控制增长是否伴随劳动者实际操作权下降？
```

------------------------------------------------------------------------

# 11. 操作权三分模型

`[L]`

``` text
O = O_p + O_o + O_s
```

但为了避免三个量直接相加造成量纲问题，严格版本应定义为一个向量：

``` text
O⃗ = (O_p, O_o, O_s)
```

若需要综合指数：

``` text
O* = w_p O_p + w_o O_o + w_s O_s
```

其中：

``` text
w_p,w_o,w_s ≥ 0
w_p+w_o+w_s = 1
```

这比直接写：

``` text
O = O_p + O_o + O_s
```

更严谨。

因此以后建议：

``` text
理论表达：O⃗
经验指标：O*
```

------------------------------------------------------------------------

# 12. 三种操作权的精确定义

## 12.1 生产操作权

``` text
O_p =
对“生产什么、怎么生产、何时生产、技术如何使用”的实际决定能力
```

## 12.2 剩余配置权

``` text
O_o =
对工资之外的剩余产品/剩余收入如何使用的实际决定能力
```

## 12.3 规则修改权

``` text
O_s =
对生产关系、组织规则和制度约束进行修改的实际能力
```

三者不能互相替代：

``` text
高工资 ≠ 高 O_p
高 O_p ≠ 高 O_o
高 O_o ≠ 高 O_s
```

------------------------------------------------------------------------

# 13. 所有权问题彻底拆解

不能把"所有权"作为一个单变量。

定义：

``` text
P⃗ = (P_pos, P_ctrl, P_use, P_surplus, P_exit)
```

分别：

-   `P_pos`：形式占有权
-   `P_ctrl`：控制权
-   `P_use`：使用权
-   `P_surplus`：剩余索取权
-   `P_exit`：退出/转让权

因此：

``` text
名义所有者 ≠ 实际控制者
```

也因此：

``` text
国有 ≠ 人民实际控制
私有 ≠ 单一资本家拥有全部实际控制
```

政治经济学应问：

``` text
产权写在谁名下？
谁做决定？
谁拿剩余？
谁承担损失？
谁能退出？
谁能改规则？
```

------------------------------------------------------------------------

# 14. 工资：不能用一个数字判断解放

定义：

``` text
w_n = 名义工资
w_r = 实际工资
w_s = 工资在新增价值中的份额
```

劳动者状态至少是：

``` text
X_i =
(w_r, T_work, T_free, O⃗_i, V_i, E_i, A_i)
```

其中：

``` text
E_i = 实际退出能力
```

于是：

``` text
w_r ↑
```

并不推出：

``` text
O⃗_i ↑
```

甚至可能：

``` text
w_r ↑
T_work ↑
E_i ↓
O⃗_i ↓
```

因此生命论评价必须多变量。

------------------------------------------------------------------------

# 15. 退出能力 E：把自由从抽象变成制度变量

`[A][?]`

定义：

``` text
E_i = 从现有关系中退出、拒绝或改变关系的有效能力
```

它受：

``` text
储蓄
社会保障
替代就业
住房
医疗
技能
家庭负担
集体组织
法律保护
```

等影响。

所以：

``` text
形式退出权 ≠ 实际退出能力
```

自由不是只有法律上的"可以"，还必须考虑生命主体是否拥有实现"可以"的物质条件。

------------------------------------------------------------------------

# 16. 社会再生产：解决"价值理论之外的生命"

资本再生产：

``` text
K_t → K_(t+1)
```

生命再生产：

``` text
生命条件_t → 生命条件_(t+1)
```

生命条件至少包括：

``` text
食物
住房
医疗
教育
照护
休息
生态
社会关系
知识
安全
```

定义：

``` text
R_L = 生命再生产能力
R_K = 资本再生产能力
```

最重要的生命论命题：

``` text
R_K ↑ ≠ R_L ↑
```

甚至可能：

``` text
R_K ↑
R_L ↓
```

例如一个体系可以通过压缩休息、生态消耗、家庭照护和公共服务维持资本积累。

这就是政治经济学与生命论真正接合的地方。

------------------------------------------------------------------------

# 17. 技术：彻底解决"生产力是否自动解放"

定义生产率：

``` text
P = Q/T_L
```

其中：

-   `Q`：产出
-   `T_L`：劳动时间

技术进步：

``` text
P ↑
```

可能导致：

### 路径 A：资本增殖

``` text
P ↑
→ 单位成本 ↓
→ 竞争压力 ↑
→ 剩余价值率 ↑
→ 资本积累 ↑
```

### 路径 B：生命解放

``` text
P ↑
→ 必要劳动时间 ↓
→ 工作时间 ↓
→ T_free ↑
→ O⃗ ↑
→ V_self ↑
```

所以：

``` text
生产力 ≠ 解放
```

更精确：

``` text
技术是操作能力放大器；
制度决定放大的方向。
```

------------------------------------------------------------------------

# 18. 市场与计划：统一为反馈机制

不要建立：

``` text
市场 = 资本主义
计划 = 社会主义
```

应建立：

``` text
经济协调机制 = 信息 → 决策 → 生产 → 结果 → 反馈
```

市场：

``` text
需要/购买力
→ 价格
→ 企业决策
→ 供给
→ 新价格
```

计划：

``` text
社会目标
→ 信息汇总
→ 计划
→ 生产
→ 结果
→ 反馈修正
```

市场主要问题：

``` text
购买力 ≠ 真实需要
价格不能自动表达生态成本
垄断会扭曲反馈
贫困者的需要权重可能被压低
```

计划主要问题：

``` text
信息瓶颈
官僚主义
指标替代目标
地方信息损失
组织层级自我保护
```

生命论评价函数：

``` text
F_econ =
f(
信息质量,
反馈速度,
反馈真实性,
操作权分布,
纠错能力,
社会目标,
生态约束
)
```

------------------------------------------------------------------------

# 19. "自指经济"的最低结构

`[A][?]`

经济系统如果要被称为高自指系统，至少需要：

``` text
1. 生产者能够获得生产反馈
2. 生产者能够影响生产决策
```

可以写成：

``` text
S_i ↔ G_i ↔ N_i
```

并要求：

``` text
N_i → G_i → S_i
```

不是只有：

``` text
N_i → G_i → S_i
```

单向命令。

# 44. 历史事实、理论解释、规范判断的三层分离

所有历史论证必须写成：

``` text
事实 F
↓
机制解释 M
↓
生命论映射 L
↓
规范判断 N
```

例如：

``` text
F：某时期某制度提高了工业产出。
M：分析其生产组织、技术、投入和劳动关系。
L：分析 O_p、O_o、O_s 是否变化。
N：再判断其是否扩大生命主体自指。
```

不能：

``` text
“这个制度符合生命论”
→
所以历史上一定提高了人民能力。
```

这是循环论证。

# 49. 关于 T011：革命级联

# 51. 统一理论的最终结构

生命论政治经济学现在可以压缩成五层：

``` text
第一层：本体
在感 → 操作 → 自指 → 生命

第二层：主体
生命主体 → 劳动 → 操作能力

第三层：经济
劳动 → 商品 → 价值 → 剩余价值 → 资本

第四层：制度
资本/劳动关系 → 所有权 → 企业 → 市场/计划 → 国家

第五层：历史
操作权集中/反馈下降
→ 异化
→ 危机
→ 改革/革命
→ 操作权再分配
→ 自指恢复
```

其中核心桥梁只有三个：

``` text
劳动 ↔ 操作
剩余 ↔ 操作权
资本 ↔ 自指转移
```

这三个桥梁把政治哲学与政治经济学真正连起来。

# 53. 最终理论结论

生命论政治经济学的核心不是：

``` text
“资本不好，劳动好。”
```

而是：

``` text
资本主义生产关系把生命主体的操作能力
转化为能够反过来组织生命主体的社会力量。
```

马克思把这一过程分析为：

``` text
劳动力
→
活劳动
→
剩余劳动
→
剩余价值
→
资本积累
```

生命论进一步把它表示为：

``` text
生命操作
→
社会剩余
→
制度化控制
→
资本自增殖
→
操作权重新分配
```

如果：

``` text
资本循环 ↑
```

同时：

``` text
人民操作权 ↑
生命再生产 ↑
自由时间 ↑
自指能力 ↑
```

则资本循环可能被纳入生命循环。

如果：

``` text
资本循环 ↑
```

同时：

``` text
人民操作权 ↓
反馈能力 ↓
自由时间 ↓
生命再生产 ↓
```

则形成：

``` text
反自指结构
```

因此最终判据不是：

``` text
有没有资本？
有没有市场？
有没有国家？
有没有剩余？
```

而是：

``` text
谁控制生产？
谁控制剩余？
谁控制规则？
谁能退出？
谁能反馈？
谁能修改？
谁因此变得更加能够成为自己生活的原因？
```

这就是生命论政治经济学与马克思政治经济学之间最核心的接缝。
