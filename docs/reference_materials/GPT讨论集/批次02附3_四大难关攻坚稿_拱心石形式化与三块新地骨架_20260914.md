# 难关一（P0-1）：资本"伪自指"的 !-余代数形式化对接

> 目标：把 GPT 拱心石 K_{t+1}=F(K_t,S_t) 从[?]推进到**有完整定义、命题链、S04 转写规格**，并同时解 GPT 断口①（V(S) 循环定义）。

## 1.1 对象就位（全部来自库内，非新造）〔L〕

- 宿主生命 H = **νF₂**：余归纳最大不动点、生产性自指，每步产出 B_t 且永不停机（总纲32-36）。
- 资本 K 是 **!-余代数**（结构映射 K→!K，"为复制而复制"），自身无 F2 代谢（卷六04第二阶段）。
- **T001**：! 不穿透 νF₂——不存在把整条生命流变成可复制死物的态射；但存在逐步截取 π_t：νF₂→B_t，! 可把**每步产出** B_t 沉积为可复制死物（=工资产出数据，总纲63）。
- 宿主动态 **N_{t+1}=(1−β+γ)N_t**：β=萃取率（K 从 B_t 抽走的比例），γ=回注率（宿主自我修复比例）；N=ρ(F) 为自指生产性。

## 1.2 核心定义〔A〕（这是拱心石的严格化）

**定义（伪自指寄生结构）**：一个 !-余代数 K 称为宿主 H 的**伪自指寄生结构**，当且仅当同时满足：

- **(D1) 依赖**：K 的复制映射 K→!K 的输入端必须接截取 π_t(H)，即 K_{t+1} 的存在以 H 的当步产出为输入；
- **(D2) 净萃取**：β>γ，即每步净抽走宿主的自指生产性，使 N 单调趋降；
- **(D3) 不可自养**：切断 π_t(H) 后，K→!K 无法维持（T001：! 自身无代谢）。

"伪"字的精确含义见命题 P2：K 表面是自指不动点，实为**借来的不动点**。

## 1.3 命题链（S04 据此逐条证）

- **P1 慢性死亡〔对接定理40〕**：β>γ ⟹ N_t 单调收敛到 N_*<1，且宿主意义总量 M_总=αT·ΣN^n=**αT/(1−N_*)<∞**（几何级数收敛=总量有限的慢性死亡）。
- **P2 伪自指≠真自指〔核心新命题，?〕**：K 在现象层满足 K=F(K)（钱生钱，G→!G），看似不动点；但由 D1+T001，该不动点的**存在性依赖外部 νF₂**，它不是 ν 型生产性最大不动点，而是被 ! 截取驱动的余代数。真自指 νF₂ 每步**生产**，伪自指 K 每步**截取他者生产**——形式差别就在"产出 B_t 来自自身代谢还是来自绑定的宿主"。
- **P3 宿主亡则寄生亡〔对接 T001 推论〕**：N→0 ⟹ π_t(H) 产出→0 ⟹ K→!K 失输入 ⟹ K 崩。资本不能在宿主死后存活。
- **P4 "倾向而非必然"的严格根据〔解 GPT 第76节〕**：β>γ **不是** K 的定义自动推出的，而是在特定生产关系（劳动力成为商品、原始积累暴力——对接定理1：不存在 A→!A 的自然态射，活劳动变商品必须有暴力中介）下达成的**稳态**。改变生产关系可使 β≤γ，故资本只有反自指**倾向**，无逻辑必然——这与卷六04反历史目的论闭合。

## 1.4 顺手解掉 GPT 断口①（V(S) 循环定义）〔A〕

GPT 原缺陷：判 K 是伪自指需先测 V(S)，V(S) 却只能靠"劳动者受损"后果反推＝用结果定义原因。
本稿破法：**判定前移到结构层**。D2 的 β>γ 是可从**生产关系结构直接读出**的量（谁占有生产资料、剩余流向谁、回注渠道是否存在），配合 N=ρ(F) 与操作权四维可行空间（见难关四），**不必等到"受损感"出现**即可先验判定。于是因果方向被纠正：先识别 β>γ 的伪自指结构（因），再预测 N 趋降、V(S) 受损（果）。

# 难关二（P1-3）：S=f(S) → 社会必要劳动 → 价值实体 的演绎树

> 补 GPT 断口②：现在"生命论⊇马克思"只是逐概念类比；本稿把顶端到价值实体接成一条**演绎链**。L4-L6 基本是〔M〕，L0-L3、L7 是〔L/A〕生命论新增的顶盖与收口。

- **L0〔L〕** 生命 S=f(S)=νF₂，是生产性自指，靠每步操作维持自身。
- **L1〔L+A〕** 四规定性（边界生成/内生目的/操作再生/环境互动）逻辑地要求：生命必须**持续与环境交换操作**才能维持，停止操作即停止自指（死亡）。→ 操作是存在的第一事实（操作先于实体）。
- **L2〔A〕** 活操作（阳）沉淀于被改造对象＝产品（阴）。产品是生命操作的沉积，这是"凝结"的存在论本义。
- **L3〔A〕** 多人共存→社会分工：每个生产者的操作是**局部/私人操作**，他无法直接知道自己的操作是否被他人需要、能否被承认为**社会总操作**的一部分。
- **L4〔M〕** 交换是社会承认机制：私人操作经交换被社会承认；不同产品可交换，说明背后有同质可通约的共同物。
- **L5〔M〕** 劳动二重性：同一次操作，作为有特定形态的**具体操作**创造各异使用价值；抽去形态，都是人类生命操作（脑/神经/手/时间）的耗费＝**抽象操作（抽象劳动）**，这是唯一同质可通约者。
- **L6〔M〕** 价值实体＝对象化的抽象劳动；价值量＝**社会必要劳动时间**（社会正常条件、平均熟练与强度下的必要耗费），非个别时间。
- **L7〔A，生命论收口〕** 于是价值的存在论本质＝**被社会承认、凝结、可通约的生命操作**。剥削＝无偿占有他人生命操作的凝结物；资本＝把这种凝结物!-化为可复制死物并反夺操作权（与难关一闭合）。

**演绎而非类比的关键**：L0→L3 是生命论公理，L4→L6 是马克思，L7 把两者焊死——任一步不可跳过，跳过就退回"对照表"。这棵树成立，"生命论⊇马克思"才从声明变成推导。**待 S01 审定 L1-L3、L7 的措辞强度。**

# 难关三（P1-1）：价值冲突仲裁——V_L 与 W（生命价值）谁决定价格

> 库内 01a 已立两据：①效用不能当价值实体（边际效用循环：价由效用定、效用又用愿付价量）；②供求只定**偏离**、劳动定**重心**（供求一致时供求什么也说明不了）。本稿据此把 GPT 的 L_v **精确插接**，而非另立第四种价值。

## 3.1 定位〔A〕

- W=O/M（总纲，客体对特定主体的实际生命价值）与 GPT 的 L_v 落在**使用价值/需求侧**，是 U 的生命论深化，**不是与 V_L 并列的价值实体**。（落实符号表：L_v 并入 W 谱系。）

## 3.2 传导链（补 GPT 缺的间接机制）〔A〕

W/L_v 上升（某类生命操作更被需要）
→ 主体需求结构改变
→ 市场价格 p **短期偏离** V_L（围绕重心波动）
→ 价格信号引导劳动/资本在**部门间重新配置**
→ 该部门投入的社会必要劳动改变 → **价值重心 V_L 本身移动**。

## 3.3 仲裁规则（一句话）〔A〕

**静态截面/价格现象看 W（需求定波动）；长期/价值重心看 V_L（劳动定重心）。** 二者不是两个对立的价格理论，是同一过程的两个时间尺度：W 决定重心**往哪移**，V_L 决定任一时刻重心**在哪**。

## 3.4 为什么这同时赢了两场辩论〔A〕

- 对"价值根子受主观需要影响"：**成立**，但成立在需求侧与重心迁移机制上，不在价值实体上——主观需要不能凭空创造价值，它只能指挥社会劳动往哪里投。
- 对边际效用论：W 由生命操作扩展能力 O/M **独立定义**，不再用愿付价格反定义，**拆掉了边际效用的循环论证**（01a 1.4.2 的批判被补强）。
- 结论：生命论不是在劳动价值论和效用论之间和稀泥，而是**用时间尺度把二者分层安置**，实体层唯劳动，需求层归生命价值。**待 S01 写定稿正文。**

# 难关四（P1-4）：操作权四维的正交化（用"阶"分，消解重叠）

> 解 GPT 断口④：Op_c 纠错权与 Op_r 规则权为何看起来重叠？因为没分**作用阶次**。

## 4.1 一阶操作权（作用于生产活动，按对象切分，互斥并列）〔A〕

| 权 | 作用对象 | 内容 |
|---|---|---|
| Op_p 生产操作权 | **生产过程** | 生产什么、怎么生产、如何组织 |
| Op_o 分配操作权 | **产出/剩余** | 产品与剩余如何分 |
| Op_r 规则操作权 | **制度规则** | 游戏规则如何制定 |

三者对象互不重叠（过程／产出／规则），天然正交。

## 4.2 二阶操作权（元权，按阶次切分）〔A〕

- **Op_c 纠错权**：作用对象不是任何物，而是**上面三种权本身**——当一阶三权失灵或被篡夺时，改变、召回、重启一阶权力结构的权。
- Op_c 与 Op_r 的"重叠错觉"由此消解：Op_r 在一阶**制定**规则；Op_c 在二阶**判断这套规则及掌权者是否需要被纠正**。一个是玩游戏、一个是改游戏/换玩家，阶次不同，维度不同，故正交。

## 4.3 与明性 f³ 严格同构〔A，本稿最漂亮的一接〕

- Op_p/o/r 对应 f¹/f² 层（在操作、在为操作建模）；**Op_c 对应 f³**——对自身操作结构的反身自觉与纠正。
- 推论：**Op_c=0 的制度＝社会层面 f³ 缺失**，必然 f² 错认固化（经文化、官僚化、拜物教），与总纲"把明性关掉就是经文化完成"完全闭合。
- 民主的生命论定义随之精确：民主＝一阶三权广泛分布 **且** 二阶纠错权真实可达。只有投票（一阶分配）而无召回/纠错（Op_c=0），是形式民主、是 f³ 被摘除的民主。

## 4.4 回头加固难关一〔A〕

V(S)（生命自指能力）的独立测度因此有了四维操作化：**V(S) 由 (Op_p, Op_o, Op_r, Op_c) 张成的可行能力空间度量**——前三维看一阶操作空间大小，第四维看二阶自我纠错是否可达，全部可从制度结构读出，不依赖"受损感"。断口①在此被彻底封住。
