# 第一部分（P1-2）：剩余价值 sv 与生命操作剩余 Sur_O 的严格关系

## 1. 两个概念的精确定义〔M〕+〔A〕
- **sv（剩余价值）〔M〕**：雇佣劳动关系中，劳动者超出必要劳动 t_n 的剩余劳动 t_s 所形成、并以**价值形式**被资本无偿占有的部分，sv/v=t_s/t_n。
- **Sur_O（生命操作剩余）〔A〕**：生命总操作中，**超出维持该生命系统自身再生产所必需、且其成果被他者/结构占去**的部分。它不以"是否雇佣、是否形成商品价值"为界。
- 关系一句话：**sv ⊂ Sur_O**——剩余价值是生命操作剩余在"雇佣商品生产＋价值形式"这个特定历史关系下的**一个子集**。GPT 的 S_V=f(S_O,社会关系)[?] 由此获得明确方向（见3）。

## 2. Sur_O 的四种形态（分类学，对接库内）〔A+L〕

| 形态 | 机制 | 是否形成sv | 库内依据 |
|---|---|---|---|
| **a 雇佣剩余** | 工厂/办公室雇佣劳动中 t_s 被资本占有 | 是，直接=sv | 卷六02〔M〕 |
| **b 再生产外部化剩余** | 家务、育儿、照护、情感劳动，维持劳动力再生产却无酬、不进商品价值 | 否，但**压低劳动力价值 v** | 〔A〕（见3机制） |
| **c 行为剩余（数字无偿劳动）** | 用户点击/社交/内容/注意力被平台提取为数据商品，"产消合一"prosumer，无雇佣合同 | 被平台**间接价值化** | 卷六06"行为剩余/监视资本主义/数字剥削蔓延到闲暇"〔L〕 |
| **d 纯耗散剩余** | 官僚内耗、形式主义、被迫等待、无意义折腾，不被任何一方价值化 | 否，直接拉低 N | 对接 l′=(1−N)〔A〕 |

## 3. 核心机制：b 是 sv 的隐性地基〔A，补 GPT 缺环〕
无偿家庭照护不创造商品价值，但它**替资本承担了劳动力再生产成本**，使劳动者无需用工资购买这些照护，从而**压低 v（可变资本/劳动力价值）**。在总劳动时间给定时，v 被压低 ⟹ t_s 相对扩大 ⟹ **sv 升高**。即：

**sv = f(Sur_O, 生产关系)，且 ∂sv/∂(b 类无偿照护) > 0。**

这正是 GPT 标[?]的函数关系的**明确方向与机制**：非价值形式的生命操作剩余，通过"再生产成本外部化"这个中介，反哺了价值形式的剩余价值。历史上这部分主要由女性承担——它把妇女解放、照护社会化与剩余价值理论焊在一起，而不是外加的道德议题。

## 4. c 类的精确定位〔A+L〕
c 不是 b（它被平台价值化了），也不是经典 a（无雇佣合同、无工资、发生在闲暇）。它是**a 在数字时代的隐形延伸**：平台用 !-模态截取用户 νF₂ 的每步产出 B（总纲 T001 的逐步截取），数据成为生产资料（卷六06）。故 c 的剥削率不能用 t_s/t_n 算（无工作日边界），要用"用户活动产出被平台占取的比例 / 用户获得的回流"度量，本质仍是 β>γ（难关一模型）。

## 5. d 类与 N 的对接〔A〕
d 不进入任何人的利润表，但它真实消耗生命操作、无任何沉淀回流，是 **N<1 最直接的来源**：操作产出为零回流 ⟹ 反馈矩阵谱半径下降 ⟹ l′ 上升。GDP 可能因 d 而虚增（折腾也产生"业务量"），但 M 下降——这是"GDP≠M"的一个微观机制。

## 6. 解放的四个战场（"夺回操作权"由此具体化）〔A〕
- 对 a：工时、工资、劳动过程控制权（经典）；
- 对 b：照护社会化、家务共担、承认再生产劳动（妇女解放的经济论根据）；
- 对 c：数据确权、算法透明、平台社会所有（卷六06数字社会主义条件）；
- 对 d：反形式主义/官僚主义，把无意义操作还给生命。
**只讲"剥削剩余价值"只覆盖 a；生命论用 Sur_O 四态把战场补全。** 待 S01 定稿、S03 为 c/d 设计度量。

# 第二部分（P1-7）：量论 α/T/N/σ 的操作化测量框架

> 最高纪律〔L：总纲方法论声明〕：M=αTN 目前是**哲学-启发式框架，不是可精确计算的工程公式**；给不出可重复测量方法却声称能算出精确数值，就是数字学。本部分只给**可重复的代理指标路线**，不填一个编造数字。

## 7. 总策略：先判方向，再求数值〔A〕
总纲指出当前价值在定性——**N<1 是恶、M 不能用 GDP 算、T 有界 N 无界**。故第一阶段不追求算出 M 的绝对数值，只追求两件可达成的事：①判定 N 相对 1 的**方向**（盈余/持平/亏损）；②测定各量的**变化趋势**。绝对值是长期科学工作。

## 8. 逐量路线（按可测性排序，先易后难）

### 8.1 N=ρ(F)——最可形式化，优先做〔A，S03+S04〕
- 定义已硬：操作网络反馈矩阵 F 的**谱半径**。把社会/组织建成有向加权图：节点=操作单元，边权重=一个单元的操作产出回流到另一单元的比例，ρ(F) 可由矩阵直接算。
- 代理数据源：投入产出表、组织信息流图、**时间利用调查**（一个人操作的产出有多少回流到自身/共同体）。
- 可达成判据：ρ(F)>1/=1/<1 对应净创造/持平/净耗散，无需绝对标定即可横向、纵向比较。**这是唯一已有严格数学定义、可立刻动手的量。**

### 8.2 T（原生稳态基准，0–100 有界）〔A，S03〕
- 有生理基础：睡眠、代谢、自主神经平衡、慢病率等可由公共卫生/可穿戴数据做**群体层**代理；个体层谨慎。
- 红线：**不能用主观幸福感替代 T**（幸福感混入了 M/α，会循环）；T 只刻画"无异化干扰下的生理稳态基线"。利托那韦 I/II 型晶种类比提示：T 测的是"远离平衡的活稳态"，不是"稳定/平静"。

### 8.3 α（自指递归实现深度，(0,1]，变量）——最难，最后做〔A〕
- 关键洞察：**α 不能靠态度自陈测量**——被经文化压到 f² 的人会自评"很清醒/很幸福"，自陈无效。
- 只能用**结构条件＋压力下行为**反推三类中介：① f² 符号识破能力（批判性认知/媒介素养的**行为**测试，非问卷立场）；② "敢"（F2→F3 的实践发动：在真实压力下是否仍表达异议、采取行动的比率）；③ 集体"应"的支撑（结社自由度、组织化可得性）。
- α 是变量不是身份常量：用同一群体在条件变化前后的行为指标差来测**变化**，比测绝对值可靠。

### 8.4 σ（尺度耦合损耗）〔A，随 N 一起做〕
比较同一活动在个体/社区/国家尺度的损耗：组织层级数、信息传递失真率、决策往返次数。σ=1 仅在个体尺度；尺度越大 σ 越低，但**不同国家 σ 不同，禁止跨国用未校正 σ 做单一排名**。

## 9. 测量红线（违反即数字学）〔A+L〕
1. 禁止用 GDP 代 M（总纲明令，d 类折腾也抬 GDP）；
2. 禁止用主观自陈代 α；
3. 禁止忽略 σ 做跨国单一分值排名；
4. 任何指标必须公开算法、可重复，否则只作定性；
5. 区分官方统计与学者估计，查不到标"待核实"，不补默认值。

## 10. 移交与边界
- N=ρ(F) 的矩阵计算交 S03/S04（可立刻起步，最硬）；T 交 S03 对接公共卫生数据；α 交 S01 定哲学含义后由 S03 设计行为指标。
- **本部分不声称已解决测量，只给出不违反总纲纪律的可行路线图。**
