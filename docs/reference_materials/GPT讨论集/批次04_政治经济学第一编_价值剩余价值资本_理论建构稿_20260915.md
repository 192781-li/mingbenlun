## 本编目标

不是把马克思的"价值"改名为"生命价值"，而是在承认马克思政治经济学基本分析对象的前提下，建立一个更高层次的"生命—操作—价值—资本"关系模型。

---

## 一、政治经济学的根本问题

### 1.1 [L] 政治经济学最终研究的不是"钱"，而是生命如何组织自己的物质再生产

生命必须持续进行：

```
生命 → 操作 → 生产 → 消费 → 再生产
```

个人如此，家庭如此，社会如此，文明亦如此。

因此：

> **经济 = 生命进行物质再生产的社会化操作结构**

经济制度真正决定的问题不是单纯的"谁有多少钱？"而是：

- 谁进行生产？
- 谁决定生产什么？
- 谁控制生产资料？
- 谁取得生产结果？
- 谁决定剩余如何使用？
- 谁能够改变这些规则？

因此生命论将政治经济学的核心问题归结为：

> **谁拥有操作权？**

---

## 二、必须首先区分五种"价值"

这是整个理论必须解决的第一个重大问题。过去如果直接说"生命价值"，很容易与马克思的"价值"发生概念混淆，因此必须拆开。

### 2.1 [M] 使用价值

商品具有满足某种需要的能力：

```
x → U(x)
```

其中 `U(x)` = 商品满足某种需要的能力。

例如：面包可以提供食物；房屋可以提供居住；药物可以治疗疾病；机器可以提高生产能力。

### 2.2 [M] 交换价值

商品之间能够形成一定的交换比例：

```
x : y = a : b
```

交换价值表现为不同商品之间的数量关系。

### 2.3 [M] 价值

马克思政治经济学中的价值，不等于"这个东西对生命有多重要"。价值的量由生产该商品所需要的社会必要劳动时间决定。

可形式化为：

```
V_M(x) ∝ T_SNL(x)
```

其中：
- `V_M(x)`：马克思意义上的价值
- `T_SNL(x)`：社会必要劳动时间

关键在于：不是某一个具体劳动者实际花了多少时间，而是在社会平均生产条件、平均劳动熟练程度等条件下生产该商品所需要的劳动时间。

因此：

```
T_individual ≠ T_SNL
```

一个效率极低的人生产一件商品花十小时，并不会因此创造十小时价值。

### 2.4 [L] 生命贡献

生命论必须建立自己的第四层概念：

```
L(x; S, E)
```

表示某一物、制度、劳动过程或社会关系对于生命系统 S 在环境 E 中维持和扩大自指能力的贡献。

因此：

```
L(x; S, E) = ΔV_self-reference
```

即：`L(x; S, E) ≡ 该对象对生命自指能力变化的贡献`

这里的 L 不是马克思意义上的价值。

### 2.5 [L] 生命价值与经济价值可以分离

这是生命论政治经济学非常重要的一步：

```
V_M ≠ L
```

甚至可能：

```
V_M ↑, L ↓    或者    V_M ↓, L ↑
```

例如：
- 金融投机可能产生巨大经济收益，却未必扩大社会生命的自指能力
- 公共教育、照护、基础科学可能具有极高生命贡献，却未必按照市场价值充分体现

因此不能简单说"有经济价值的东西就是有生命价值的东西"，也不能反过来说"生命价值就是马克思的价值理论"。

正确关系应该是：

> **经济价值是社会生产交换体系中的特殊量；生命贡献是生命系统层面的更高阶评价变量。**

---

## 三、劳动与劳动力必须严格区分

这是理解剩余价值的关键。

### 3.1 [M] 劳动力不是劳动

```
劳动力 ≠ 劳动
```

- 劳动力：`LP = 劳动的能力`
- 劳动：`L_b = 劳动力实际发生的活动`

资本家购买的是 `LP`，而不是已经完成的劳动。

劳动力的特殊之处在于：

> **劳动力的使用可以创造超过其自身价值的价值**

这正是剩余价值产生的理论入口。

---

## 四、劳动力商品为什么特殊

假设维持一个劳动者正常生活以及下一代劳动力再生产所需要的社会必要劳动量为 `T_N`，则劳动力价值可以抽象表示为：

```
V_LP ∝ T_N
```

但资本家购买劳动力之后，让劳动者工作：

```
T = T_N + T_S
```

其中：
- `T_N`：必要劳动时间
- `T_S`：剩余劳动时间

劳动者在 `T_N` 中创造相当于自身劳动力价值的价值。但是在 `T_S` 中：

> 劳动者继续创造价值，而这些价值并不以工资形式返还给劳动者

于是产生：`S = 剩余价值`

---

## 五、剩余价值的形式化

马克思最核心的关系可以写成：

```
s / v = T_S / T_N
```

其中：
- `s`：剩余价值
- `v`：可变资本
- `T_S`：剩余劳动时间
- `T_N`：必要劳动时间

因此 `s > 0` 意味着劳动者创造的价值超过了劳动力自身价值。

进一步：

```
新创造价值 = v + s
```

而资本主义生产资料中的已有价值在马克思理论中主要通过生产过程转移，而不是凭空创造新的价值。

---

## 六、绝对剩余价值与相对剩余价值

设：`T = T_N + T_S`

### 6.1 [M] 绝对剩余价值

如果 `T_N = constant`，而 `T_S ↑`，则 `T ↑`。

例如：8h → 10h，而必要劳动仍然为 4h，则 `T_S: 4h → 6h`。

因此 `s/v = T_S/T_N` 从 `4/4 = 1` 变成 `6/4 = 1.5`。

### 6.2 [M] 相对剩余价值

如果生产率提高，使维持劳动者生活所需的必要劳动时间下降：`T_N ↓`，而工作日不变 `T = constant`，则：

```
T_S = T - T_N
```

因此 `T_N ↓ ⇒ T_S ↑`。

例如：`T = 8h`，原来 `T_N = 4h, T_S = 4h`；生产率提高以后 `T_N = 3h, T_S = 5h`，于是 `s/v = 5/3` 而不是原来的 `4/4 = 1`。

---

## 七、生命论第一次介入：剩余价值 ≠ 生命价值损失

这里必须非常谨慎。不能简单写：

```
s > 0 ⇒ L < 0
```

这是错误的。因为现实中可能存在：

```
s ↑, w_r ↑, T_work ↓, O_i ↑
```

即：企业剩余增加；实际工资提高；工作时间下降；劳动者参与决策能力提高。

因此：

> **剩余价值关系与生命异化不是同一个变量。**

马克思的剥削分析回答的是：剩余劳动如何被占有。

生命论进一步追问：这种占有关系是否导致生命主体自身操作能力、自我决定能力和反馈能力下降？

所以应该建立：

```
剥削关系 ≠ 异化程度
```

但二者可能存在系统性关系。

---

## 八、资本的真正定义

现在进入第二个核心：`剩余价值 → 资本`

资本不是简单的钱，也不是机器，也不是财富。

### 8.1 [M] 资本是能够自行增殖的价值

资本运动可以表示为：

```
M — C ⋯ P ⋯ C' — M'
```

其中 `M' = M + ΔM`，而在总体系的简化分析中 `ΔM = s`。

于是：`M → M + ΔM`

资本的核心不是"拥有某种东西"，而是：

> **价值增殖运动**

---

## 九、为什么资本看起来像一个"自指系统"

这里是生命论真正可以进入马克思政治经济学的位置。

设资本 `K_t`，资本经过生产、剩余价值实现和再投资以后：

```
K_{t+1} = K_t + ρ·s_t − δ·K_t
```

其中：
- `ρ`：再投资比例
- `s_t`：该周期实现的剩余价值
- `δ·K_t`：损耗、贬值等

如果 `ρ·s_t > δ·K_t`，那么 `K_{t+1} > K_t`，资本就形成：

```
K_t → 生产 → 剩余价值 → K_{t+1} → 更多生产 → 更多剩余价值
```

这已经非常接近生命论所谓的 `S = f(S)`。

---

## 十、但是资本不是生命

这一点必须写死。不能因为资本具有循环、自我扩张结构，就说"资本就是一种生命"——这是概念偷换。

资本的"自我运动"依赖：

```
劳动 + 生产资料 + 制度 + 产权关系 + 能源 + 自然环境 + 社会组织
```

因此：

> **资本具有类似自指的增殖结构，但资本不是独立生命主体。**

生命论可以把它称为：

> **资本 = 伪自指结构** 或 **资本 = 社会关系中的派生自指结构**

---

## 十一、为什么说"伪自指"

真正生命：

```
S → 操作 → S'
```

其目的、边界、维持过程至少部分由生命自身产生。

资本则是：

```
K → 组织人的劳动 → 产生剩余 → K'
```

所以真正发生的是：

```
人的自指能力 → 生产 → 剩余 → 资本自我扩张
```

于是产生一个非常关键的转换：

> **人的自指 ⟶ 资本的伪自指**

这就是生命论理解资本异化的核心入口。

---

## 十二、资本的"自我扩张"与人的"自我扩张"可能发生冲突

设：
- `K_t` = 资本扩张能力
- `V_i(t)` = 劳动者 i 的自指能力

则存在一种可能：

```
dK/dt > 0    同时    dV_i/dt < 0
```

例如：劳动强度提高；工作时间增加；决策权下降；技能被机器/流程分割；工作意义降低；失去对生产过程的控制。

于是：`K ↑` 但是 `V_i ↓`

这正是生命论所定义的反自指关系。

---

## 十三、反自指的政治经济学定义

此前生命论已经给出：如果某结构 P：

1. 使用 S 的操作能力
2. 消耗 S 的自指能力
3. 同时依赖 S 继续存在

则 **P 是对 S 的反自指结构**。

形式化：

```
V(S) = 主体自指能力
若 dV(S)/dt < 0，同时 P = f(S)，并且 P 的持续存在要求 V(S) > 0
则 P → S 构成反自指关系
```

资本主义资本积累可以成为这种关系的一种特殊历史形式。

注意：

> **资本 ≠ 必然在任何情况下都完整符合反自指定义**

必须考察具体制度安排。

---

## 十四、因此生命论不能简单提出"消灭资本"，而必须问三个问题

1. **谁控制生产？**
2. **谁取得剩余？**
3. **谁有权改变生产规则？**

因此此前的 `O = O_p + O_o + O_s` 可以正式进入政治经济学。

其中：
- `O_p`：生产操作权——谁决定生产什么、如何生产、什么时候生产、使用什么技术、工作如何组织
- `O_o`：剩余配置权——谁决定剩余去哪、投资什么、消费多少、公共支出多少、分红多少
- `O_s`：结构操作权——谁决定所有权制度、劳动制度、企业制度、税制、市场规则、政治规则

因此：

```
O = O_p + O_o + O_s
```

---

## 十五、生命论对"剥削"的重新定义

马克思首先从剩余劳动占有分析剥削。生命论可以进一步定义：

> **剥削 = 对他人生产性操作能力所产生剩余的系统性占有**

但是还必须增加一个判断：

> **异化剥削 = 剩余占有 + 操作权持续单向转移 + 反馈能力下降**

因此不能只测 `s`，还要测 `O_i` 以及 `V_i`。

---

## 十六、一个非常重要的判别式

对于一个经济制度，可以同时观察：

```
Δs, Δw_r, ΔO_i, ΔV_i, ΔT_free
```

其中：
- `Δs`：剩余价值变化
- `Δw_r`：实际工资变化
- `ΔO_i`：操作权变化
- `ΔV_i`：自指能力变化
- `ΔT_free`：自由时间变化

于是：

| 情形 | 变量组合 | 判断 |
|---|---|---|
| A | `s↑, w_r↑, O_i↑, T_free↑` | 不能简单判定为"生命被资本吞噬" |
| B | `s↑, w_r↑, O_i↓, T_free↓` | 可能出现：物质生活改善 + 操作权异化 |
| C | `s↑, w_r↓, O_i↓` | 剥削与反自指同时增强 |
| D | `s↑, w_r↑, O_i↑, T_free↑, V_i↑` | 剩余生产本身并不必然与生命解放冲突 |

这会迫使生命论避免一种简单的"反资本主义 = 反剩余"的逻辑。

---

## 十七、技术必须放进这个模型

技术提高生产率：`Productivity ↑`，可能导致 `T_SNL ↓`，因此单位商品价值 `V_M(x) ↓`。但社会总产量可能 `Q ↑`。

所以：

> **单位价值下降 ≠ 社会财富下降**

这是非常重要的。

### 技术有两条完全不同的道路

**道路一：资本化**
```
技术 → 生产率提高 → 剩余生产扩大 → 资本积累 → 劳动控制增强
可能：K ↑, O_i ↓
```

**道路二：生命化**
```
技术 → 生产率提高 → 必要劳动时间下降 → 工作时间下降 → 自由时间增加 → 人的自指能力扩大
可能：T_work ↓, T_free ↑, V_i ↑
```

因此：

> **技术本身不解放人。技术只是扩大了可能性空间。真正决定方向的是：技术控制权 + 剩余分配权 + 操作权**

---

## 十八、工资不能作为唯一的阶级判断标准

工资 `w` 只是劳动者取得收入的一种形式。因此：

```
w ↑ ≠⇒ O_i ↑
```

甚至可能：`w ↑, O_i ↓`。所以高工资的劳动者仍然可能没有生产操作权。

反过来：`w ↓` 也不能自动推出 `O_i ↓`。例如某些合作社、公共组织或早期集体生产形式中，收入与操作权之间可能并不呈简单对应。

所以生命论的经济正义指标不能只是 `Income`，而应至少包括：

```
J = f(w_r, O_p, O_o, O_s, T_free, V_i)
```

这是一个待进一步形式化的理论函数，目前不能假装它已经是经验科学定律。

---

## 十九、资本积累

资本不是产生一次剩余就结束。它会把剩余重新投入：

```
M — C — P — C' — M'
然后 M' → M'' → M'''
```

于是：`K_0 < K_1 < K_2 < K_3 ...`

这就是资本积累。

生命论可以进一步提出：

> **资本积累的关键问题不是"资本是否增长"，而是"资本增长是否同步扩大生命主体的自指能力"。**

因此存在两个方向：
- **正向积累**：`K ↑` 同时 `V_human ↑`
- **反自指积累**：`K ↑` 同时 `V_human ↓`

所以：

```
资本积累 ≠ 生命积累
```

---

## 二十、再生产：政治经济学必须从"生产"进入"生命再生产"

资本主义不是每天重新开始。它必须不断再生产资本，同时也必须再生产劳动力。因此：

```
资本再生产 ≠ 生命再生产
```

生命再生产包括：

```
食物 + 住房 + 教育 + 照护 + 休息 + 医疗 + 社会关系 + 生态条件
```

因此生命论提出：

> **生命再生产 = 维持并扩大生命自指能力所需条件的再生产**

于是 `K_reproduction` 与 `L_reproduction` 可能一致，也可能发生冲突。

极端情况下：`K ↑↑` 而 `L ↓`，系统仍可能在一段时间内继续运行。这就是生命论判断经济制度的重要切入口。

---

## 二十一、利润、利息、地租

马克思第三卷进一步分析：`s` 不会简单地直接表现为某一个资本家的"剩余价值"。剩余价值会在不同资本关系之间进行分配，表现为：

```
利润 + 利息 + 地租
```

因此：`s → p + i + r`

在抽象意义上：`p` 利润；`i` 利息；`r` 地租。

但不能写成 `p = s`，因为竞争和资本流动会使不同部门的资本获得平均利润等形式的重新分配。

因此：

> **剩余价值的生产 ≠ 剩余价值最终在个体之间的分配**

这一区分对于后面分析金融资本非常重要。

---

## 二十二、金融资本

表面上：`M → M'`，似乎 `Money → More Money`，好像钱自己产生钱。

但从整个社会再生产看，金融收益最终必须依附于某种现实基础：

```
劳动 + 生产 + 税收 + 租金 + 未来剩余 + 资产转移
```

因此生命论应当拒绝"钱自己创造价值"，而采用：

> **金融资本表现为价值增殖关系的高度抽象化。**

当 `F_t ≫ Y_t`，且金融索取权的增长持续脱离现实生产和生命再生产能力时，可以进一步研究：

> **金融化是否形成新的反自指结构？** [?]

但这仍然必须进行具体经验研究，不能预设答案。

## 二十三、所有权必须拆成四种权力

"所有权"本身太粗。生命论建议拆成：

```
P = P_pos + P_ctrl + P_use + P_surplus
```

分别为：
- `P_pos`：占有权
- `P_ctrl`：控制权
- `P_use`：使用权
- `P_surplus`：剩余索取权

这样就可以解释很多传统政治经济学难以一眼区分的现象。

例如：某企业名义上属于全民，但如果普通劳动者 `O_p ≈ 0, O_o ≈ 0, O_s ≈ 0`，那么：

> **名义全民所有 ≠ 人民实际操作权**

这正好与生命论此前的"自指转移"理论连接。

## 二十四、国家进入政治经济学

国家可以：
- `State → Tax → Redistribute`
- `State → Own → Produce`
- `State → Regulate → Capital`

因此：

```
国家所有 ≠ 人民所有
```

国家具有自己的组织能力 `O_state`，人民具有 `O_people`。两者可能：
- `O_state ↑, O_people ↑`（一致）
- `O_state ↑, O_people ↓`（自指转移）

后者就是生命论所谓**自指转移**：

```
S_i → G → State
原本存在反馈：State → G → S_i
后来变成：State → G → S_i，但 S_i ↛ G
```

最终：国家越来越能够自我运行，人民却越来越不能决定国家运行。

这就是生命论判断官僚化的核心指标之一。

## 二十五、市场与计划

生命论不能采用 `市场 = 资本主义`，因为 `市场 ≠ 产权制度`。同样 `计划 ≠ 社会主义`。真正应该研究的是反馈机制。

### 市场
```
需求 → 价格 → 生产 → 供给 → 价格变化
```
- 优点：反馈速度快
- 缺点：`购买力 ≠ 需要`，因此市场反馈的是"有效需求"，而不是所有人的真实需要

### 计划
```
社会目标 → 计划 → 生产 → 反馈 → 修正计划
```
- 优点：可以主动纳入公共需要、长期目标、战略资源、生态约束
- 缺点：如果反馈链条过长，或者 `O_local ↓`，则可能出现信息失真、官僚主义、指标异化、目标替代、对地方实际情况反应迟钝

所以生命论最终标准不是 `Market vs Planning`，而是：

> **反馈质量 + 操作权 + 信息真实性 + 纠错能力 + 社会目标**

---

## 二十六、社会主义的生命论定义

因此生命论不应把社会主义定义成"国家拥有所有生产资料"，而应定义为：

> **社会主义 = 生产、剩余与制度规则的操作权逐渐社会化**

即：`O_p ↑, O_o ↑, O_s ↑` 对于普通生产者和社会成员。

所以：

> **社会主义的核心不是"谁在名义上拥有"，而是"谁实际上能够决定"。**

---

## 二十七、共产主义的生命论定义

进一步：

> **共产主义 = 生命主体的自指能力高度展开，而系统性异化与强制性操作权集中趋于最低。**

目标变量可以表示为：

```
O_people → Max
A → Min
T_free → Max
V_self → Max
T_necessary → Min
```

注意：这不是说"所有人什么都不做"，而是：必要劳动时间下降，自由活动空间扩大，生产者对自身生产与社会规则的控制扩大。

## 二十八、政治经济学与生命论的真正连接

到这里，原来的 `劳动 → 剩余价值 → 资本` 可以被扩展为：

```
生命 → 劳动 → 劳动力 → 生产 → 价值 → 剩余劳动 → 剩余价值 → 资本 → 积累
```

然后加入生命论：

```
→ 操作权集中 → 自指转移 → 异化 → 反馈衰减 → 危机
```

再进入政治实践：

```
→ 操作权重构 → 反馈恢复 → 生命自指能力扩大 → 解放
```

于是：

> **政治经济学 = 生命在物质生产关系中的自指与反自指运动**

这句话可以暂时作为生命论政治经济学的核心定义。

## 二十九、目前已经形成的"三层价值结构"

建议以后正式固定成：

| 层级 | 变量 |
|---|---|
| 生命层 | `L(S, E)` |
| 经济层 | `V_M(x)` |
| 交换层 | `E(x, y)` |

再加上 `U(x)`（使用价值），形成两条不同的评价路径：

```
U → E → V_M
U → L
```

最终：

```
经济价值 ≠ 生命价值
```

但：**经济价值是生命生产活动的一种历史性社会形式。**

## 三十、目前最重要的理论突破

到这里，生命论政治经济学真正开始与"把马克思术语换成生命术语"区分开了。

它不是"劳动创造生命价值"，而是：

> **马克思研究：劳动如何形成价值，劳动力如何形成剩余价值，剩余价值如何形成资本。**
>
> **生命论进一步研究：这些价值运动如何改变生命主体的操作权、自指能力和社会反馈结构。**

因此二者关系不是 `马克思 → 生命论替代`，而是：

> **马克思政治经济学 + 生命本体论 → 生命论政治经济学**

其中最核心的新增变量是：
- `O = 操作权`
- `V(S) = 生命主体的自指能力`

于是我们终于有能力提出一个比"收入是否平等"更深入的问题：

> **生产者创造的社会能力，最终是否反过来扩大了生产者自身的操作能力？**

如果 `ΔO_producer > 0`，则生产能力越来越成为生产者自己的能力。

如果 `ΔO_producer < 0` 同时 `K ↑`，那么就出现：

> **生产力增长 + 生产者自指能力下降**

这正是生命论要解释的异化生产力。
