# 北原慢热 × ChatGPT 讨论总集 · 索引

> 用途：汇集北原慢热（作者）与 ChatGPT 关于生命论（明本论）的全部讨论。
> 双轨制：每一批次同时保留【原文】（原样收录，不改一字，含口语）与【整理】（结构化、标注层级、映射库内位置）。
> 原则：AI 会忘，库不会忘；陆续倒入、分批入库，最终汇成总集。

## 四层标注铁律（所有整理稿必须区分，禁止混成一层）

| 标记 | 层级 | 含义 |
|---|---|---|
| **[M]** | 马克思原论 | 马克思本人的概念、命题、原文论证（引用须可追溯） |
| **[L]** | 生命论自论 | 生命论自己的理论：在感/操作/自指/反自指/四规定性/操作权等 |
| **[A]** | AI 推导 | ChatGPT（或明旭）在 [M][L] 基础上做出的推导，需作者审定 |
| **[?]** | 待证明命题 | 尚未证成、需要后续论证或形式化的命题 |

> **硬化稿四类标注（轮24《理论硬化稿v1.0》0节自立的纪律，与上表对应）**：[M] 马克思原论、[L] 生命论已有、[D] 生命论推导（≈上表 [A]，作者审定后可升 [L]）、[U] 未证假说（≈上表 [?]）。硬化稿纪律更严：**[D] 不得伪装成 [M]，[U] 不得伪装成已证规律**；任务是保留马克思解释成功的关系，再找其在生命—操作—自指层的更一般结构。整理硬化稿及其后续成果一律用 [M][L][D][U]。
