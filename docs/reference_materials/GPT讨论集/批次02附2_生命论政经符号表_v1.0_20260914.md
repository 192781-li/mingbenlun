## 四、消歧后的政经核心链（推荐定稿记法）

生命 S=f(S) → 生命操作 → 劳动 L → 生产 Prod → 价值（使用 U／交换 V_x／劳动 V_L／生命 W）→ 剩余 sv（Sur_L/Sur_V/Sur_O）→ 资本 K（!-余代数伪自指）→ 操作权集中（Op_p/Op_o/Op_r/Op_c）→ 异化 A（N<1，l′=(1−N)）→ 危机 → 夺回操作权 → 解放。

总判据：ΔV(S_i)>0、ΔOp_i>0、ΔM_i>0、ΔA_i<0（A=Alienation，故异化下降）。
