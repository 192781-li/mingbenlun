## 二、整理

### 1. 阶段定位 [L]

第一阶段目标：**把政治经济学做成完整理论**，不是术语替换（把马克思概念换成"生命"说法），而是逐环节回答"为什么"，完成生命论对政治经济学的**重新奠基**。

### 2. 七连问（问题链，本阶段必须逐题作答）

1. 价值是什么？
2. 劳动为什么产生价值？
3. 劳动力为什么能产生剩余价值？
4. 剩余价值为什么转化为资本？
5. 资本为什么能形成自我扩张？
6. 这种扩张为什么反过来削弱人的自指能力？
7. 什么条件下生产资料、市场、国家、技术能重新服务于生命？

> 攻坚核心（ChatGPT 标注"最关键"）：**价值 → 剩余价值 → 资本** 这三环必须真正打通。

### 3. 骨架链（13 环节）

```
生命 → 劳动 → 劳动力 → 生产 → 价值 → 剩余价值 → 资本
→ 积累 → 异化 → 自指转移 → 危机 → 操作权再分配 → 解放
```

- 前段（1-7）：**资本的生成**——从生命如何一步步走到资本
- 后段（8-13）：**资本的瓦解与回归**——积累如何导致异化、自指转移、危机，以及操作权再分配与解放

### 4. 四层区分（铁律，对应总集索引）

- [M] 马克思原论：劳动价值论、剩余价值、资本积累、危机理论的原典论证
- [L] 生命论自论：生命/操作/自指/反自指/操作权的重新建模
- [A] AI 推导：ChatGPT 把 [M] 与 [L] 焊接的推导（须作者审定）
- [?] 待证明命题：如"价值实体=生命操作沉积""资本=反自指的 !-模态寄生"等，需论证或形式化

### 5. 计划产出

《生命论政治经济学·定稿基础版》**第一部分：价值—劳动—劳动力—剩余价值—资本**，含公式、马克思原论对照、生命论重新建模。
