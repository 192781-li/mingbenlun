# 崔之元辨析

**辨析日期**：2026年8月24日
**辨析方法**：辨析四原则+大跃退框架+名实相符+时代定位+被和谐后逆向推断

---

## 一、基本背景

- 1963年生于北京
- 国防科技大学系统工程本科，1995年芝加哥大学政治学博士
- 曾任教于MIT政治学系（1995-2002），现任清华大学公共管理学院教授（百人计划引进）
- 哈佛大学法学院高级访问研究员，康奈尔大学法学院杰出访问讲座教授
- 被称为中国"新左派"代表人物之一，和汪晖、王绍光、甘阳齐名
- 2003年在乌有之乡发表《自由社会主义与中国未来——小资产阶级宣言》，2020年还在乌有之乡发访谈

## 二、核心主张

### 1. "小资产阶级社会主义"/"自由社会主义"

他自己明确说："我和传统的马克思主义有比较大的分歧了。我认为中国的整个实践和理论，虽然没有明确说，但实际上已经是'小资产阶级社会主义'。"

受英国经济学家詹姆斯·米德影响，主张：
- **劳资合股企业**——工人和资本家合伙，工人拥有"劳动股"，和资本股按同一比率分红
- **社会红利**——全体人民从国有资产收益中获得分红
- 目标不是无产阶级专政，而是"让更多人民拥有财产性收入"

### 2. "第二次思想解放"（1994年）

反对把"国际惯例"和"市场教条"当圣旨，认为中国改革需要制度创新。90年代新自由主义狂飙时敢站出来批判，有进步意义。

### 3. 重庆模式的主要理论阐释者

2009-2011年连续发三篇文章系统阐释重庆经验：
- 2009年《社会主义市场经济的优势：国资增值与藏富于民》（《文化纵横》）
- 2010年《"重庆经验"进行时：国资增值与藏富于民并进》（《政治经济学评论》）
- 2010年《重庆"十大民生工程"的政治经济学》（《中共中央党校学报》）

提炼重庆模式核心：国资增值与藏富于民并进——国企增值的同时民生投入增加。把重庆模式作为"小资产阶级社会主义"的实践样板。

2015年福山来清华演讲，汪晖主持，崔之元当评议人，汪晖特意介绍崔之元"近年来关注重庆经验"——他是学院左翼圈子里重庆模式的代言人。

薄熙来倒台后，他没有公开否定重庆模式，没有被清算（只是学者不是官员），不再高调谈论但思路没变，后来转向"管资本为主、员工持股和社会分红"。

### 4. "中国人民永久信托基金"（2008年）

把部分国有资产设立为永久信托基金，全体人民作为受益人享有财产性收入。和卢麒元的社会分红主张有相似之处。

### 5. 对前30年的评价

肯定前30年实现了工业化、文化普及、基础设施、人均寿命；认为文革打破了计划经济后期的僵化格局，为改革开放奠定了基础。但指出前30年的"失"在于未能充分摆脱教条约束，不和"大民主"相结合的生产资料公有制不能保证劳动人民当家做主。

## 三、辨析

### 辨析四原则

| 原则 | 判断 |
|------|------|
| 是否触及资本主义根本矛盾？ | **没有。** 劳资合股是在资本主义框架内改良，不消灭资本主义，不否定资本，只要求资本分一点给工人 |
| 是否有阶级分析？ | **有，但模糊了。** 明确说目标不是无产阶级专政，而是"小资产阶级社会主义"，把无产阶级小资产阶级化，模糊了无产阶级和资产阶级的根本对立 |
| 立场是革命还是辩护？ | **改良主义。** 所有主张都是在现有体制内改良，不触及政权性质和所有制根本 |
| 理论是否指向实践？ | **有实践指向，但都是改良实践。** 重庆模式、国资改革、社会分红，都是现有框架内的制度调整 |

### 大跃退框架

他不承认后30年是资本主义复辟，认为是"小资产阶级社会主义"的实践。**这一条过不了关——不承认大跃退，就不是毛派。**

### 名实相符

他说中国实际上已经是"小资产阶级社会主义"，但实际上私有制经济占GDP60%以上，雇佣劳动是主要劳动形式，资本对劳动的剥削普遍存在。把实际的资本主义叫做"小资产阶级社会主义"，是名实不符——用好听的名字掩盖实际的阶级关系。

### 时代定位

他在清华任教，没有被封禁，文章能在主流媒体发表。在保守时代，能公开说的话是经过审查后的话。他的"小资产阶级社会主义"能在清华讲、能在主流媒体发，说明它不威胁现有体制——因为它是改良主义的，不是革命的。

对比卢麒元——被彻底封禁过，在小平台上才敢说"人民民主宪政"。一个被封禁，一个在清华任教，这本身就说明了立场的差异。

### 重庆模式辨析（三层）

1. **薄熙来个人**——腐败、滥用职权，官方已有定论
2. **重庆模式的政策内容**——国资增值、公租房、户籍改革、民生投入、打黑，政策方向有左翼色彩，不能因薄熙来倒了就全盘否定
3. **崔之元的理论阐释**——问题在这。重庆模式没有改变所有制，没有改变阶级关系，只是在分配上做调整。工人还是雇佣劳动者，没有掌握运行权；民生投入增加了，但政权性质没变，人民没有掌握主权。这是改良，不是革命。而且重庆模式的"国资增值"很大程度上靠土地财政和城市扩张，不可持续

## 四、和卢麒元的对比

| 维度 | 卢麒元 | 崔之元 |
|------|--------|--------|
| 核心主张 | 人民宪政（主权与治权分离）、直接税、反官僚垄断资本主义 | 小资产阶级社会主义、劳资合股、社会分红 |
| 对资本主义的态度 | 根本批判，要消灭官僚垄断资本主义 | 在资本主义框架内改良，劳资合伙 |
| 对政权的态度 | 人民掌握主权，执政组织只行使治权 | 不触及政权性质，在现有体制内改良 |
| 实践后果 | 被彻底封禁 | 在清华任教，主流媒体能发文 |
| 阶级立场 | 人民立场，无产阶级立场 | 小资产阶级立场，模糊阶级对立 |
| 和马列毛的关系 | 继承马列毛，做毛主席未竟的第二件事 | 自己承认和传统马克思主义"有比较大的分歧" |

## 五、和生命论的关系

表面相似：都关注人民福祉，都批判新自由主义，都主张社会分红。

根本层次不同：
- **生命论**：人民必须掌握运行权（主权），存在论层面的根本要求
- **崔之元**：人民拥有财产性收入，分配层面的改良要求

"劳资合股"在生命论框架下更有问题——工人和资本家"合伙"，本质上是让工人接受被剥削的地位，只是分一点残羹剩饭。运行权还是在资本手里，工人只是多拿了一点钱，但没有掌握自己的运行权。这不是解放，是招安。

## 六、新左派的定位

"新左派"是90年代"新左派vs自由主义"论战中的学院派学者群体：
- **汪晖**——清华文科资深教授，新左派领袖，现代性、中国革命研究，理论资源是西方后现代和世界体系理论
- **崔之元**——清华公共管理学院教授，小资产阶级社会主义、重庆模式
- **王绍光**——香港中文大学荣休教授，《民主四讲》、国家能力、人民民主
- **甘阳**——中山大学教授，"通三统"（儒家+毛泽东+邓小平）

新左派整体是**同路人**——批判新自由主义，但大多不触及资本主义根本矛盾，不承认大跃退，立场是改良不是革命。他们和乌有之乡那种"老左派"/毛派有交集但不是一回事。

## 七、最终判定

**四类角色：同路人**

- 批判新自由主义，肯定前30年，研究经济民主，主张社会分红——立场倾向人民，不是敌人
- 但明确和传统马克思主义划清界限，主张改良主义，不触及资本主义根本矛盾，不承认大跃退——不是同志
- 立场公开一致，没有投机——不是可疑分子
- 真诚的改良主义者，但也仅此而已

**道法术器位置：法的层面（改良主义的制度设计）**

社会分红、国资信托基金等具体方案可作为革命成功后的制度参考，但"小资产阶级社会主义""劳资合股"的理论框架不能作为指导思想——它不触及根本。

**一句话定位**：崔之元是受过完整西方学术训练、真诚想为人民做点事的改良主义学者。他比自由派强一万倍，但他和卢麒元之间隔着一条革命和改良的鸿沟。是同路人，可以一起走一段，但不能拉进同志的队伍。
