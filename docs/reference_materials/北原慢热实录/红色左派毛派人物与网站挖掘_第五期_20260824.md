## 一、彭湃——术的真正先驱（纠正梁漱溟的错误定位）

**身份**：中国农民革命运动先导者，海陆丰苏维埃政权创始人，"农民运动大王"

**经历**：
- 1896年10月出生，广东省海丰县人
- 早年赴日本求学，1918年入日本早稻田大学政治经济科
- 在日本留学期间接受了社会主义思想，参加中国留学生爱国运动
- 1921年5月回国，加入中国社会主义青年团，在家乡海丰创办社会主义研究社和劳动者同情会，传播马克思主义
- 1922年夏，毅然只身深入农村，了解农民疾苦，发动农民组织起来
- 1924年转为中国共产党党员
- 1928年11月当选中央政治局委员，任中共中央农委书记、中共中央军委委员
- 1929年8月24日因叛徒出卖被捕，8月30日在上海被反动派秘密杀害，年仅33岁

**核心事迹**：
1. **焚田契闹革命**——当众烧掉自家地契，把田分给佃户，毅然决然地背叛自己的剥削家庭。他出身于大地主家庭，但选择了革命道路，遭到几乎所有家人的反对
2. **脱下长衫到农村去**——脱下洋装换上粗布衣，被农民亲切接受。"脱下洋装换上粗布衣，被农民亲切..."
3. **六人农会**——1922年7月，和张妈安等6人成立海陆丰第一个农会——"六人农会"，从此点燃农民运动的火种
4. **农民运动燎原**——到次年7月，农会扩展到陆丰、惠阳等10县，彭湃相继组建了惠州农民联合会和广东省农会，发展了几十万名农会会员
5. **海陆丰苏维埃政权**——领导建立了中国第一个农村苏维埃政权——海丰、陆丰县苏维埃政府
6. **《没收土地案》**——主持制定的《没收土地案》，是中国共产党制定的最早的两部土地改革法案之一，具有革命的彻底性和首创性
7. **《海丰农民运动》**——撰写的《海丰农民运动》一书，成为从事农民运动者的必读书
8. **做群众工作的典范**——彭湃作为中国共产党早期的重要领导人、杰出的农民运动先驱，也是做群众工作的典范

**历史地位**：
- 被毛泽东同志称为"农民运动大王"
- 早期中国共产党人中开展农民运动的领袖只有三位：毛泽东、彭湃、方志敏
- 很多革命志士和共产党人将彭湃视为自己的老师，称他为"农民运动的先驱"
- 在中国共产党农民运动史上起到了开拓者、实践者、探索者的作用
- 2009年被评为"100位为新中国成立作出突出贡献的英雄模范人物"

**在道法术器中的位置**：术的层面——农民运动的具体操作方法（六人农会、焚田契、做群众工作、土地改革法案），是术的真正先驱，不是梁漱溟那种改良主义者

**四类角色判定**：**同志**（革命先烈）
- 触及社会根本矛盾（土地革命、农民运动、阶级斗争）
- 有阶级分析（背叛剥削家庭，站在农民一边）
- 立场是革命的（武装起义、建立苏维埃政权、土地革命）
- 理论指向实践（《海丰农民运动》、《没收土地案》、群众工作方法）
- 用生命实践了革命理想，年仅33岁牺牲

**评价**：彭湃是中国农民运动的真正先驱，是术的层面的真正奠基人。他出身大地主家庭，但当众烧掉自家地契，背叛剥削阶级，脱下长衫到农村去，和农民打成一片。他创建了中国第一个县级苏维埃政权，制定了最早的土地改革法案，撰写了农民运动的必读书。他做群众工作的方法至今仍有借鉴意义。他年仅33岁就为革命牺牲，是真正的无产阶级革命家。

**纠正之前的错误定位**：之前把梁漱溟列为"术的先驱"是错误的。梁漱溟是改良主义者，主张教育救国、文化复兴，不触动地主土地所有制，他的乡村建设实验在30年代就失败了。彭湃才是术的真正先驱——他用革命的方法解决农民问题，用阶级斗争的方法推翻地主阶级，用土地革命的方法让农民成为土地的主人。彭湃和毛泽东、方志敏一起，是中国农民运动的三位真正领袖。

## 二、晏阳初——改良主义者，不是革命者

**身份**：平民教育运动代表人物，"世界平民教育之父"

**经历**：
- 一生心怀"教育救国"抱负，以"除天下文盲、做世界新民"作为毕生追求
- 中国近现代平民教育和乡村改造的倡导者和实践者
- 第一个将中国本土发明创造的平民教育、乡村建设经验传播到全世界并生根发芽取得卓越成效的教育家
- 被誉为世界平民教育之父
- "走出象牙塔，跨进篱笆墙"
- 办中国乡村建设学院，探索"即讲、即学、即习、即能"的教学体系
- "南陶北晏"之称（陶行知和晏阳初）
- 与梁漱溟、陶行知、卢作孚并称"乡建四杰"

**核心观点**：
- 教育救国——认为中国的落后是因为教育造成的，要拯救中国必先革新教育
- 平民教育——从社会底层做起，面向大众普及教育
- 乡村建设——通过教育和乡村改造实现救亡图存、民族复兴
- 不触动地主土地所有制——改良主义路线，不搞阶级斗争和土地革命

**历史评价**：
- 平民教育运动只是昙花一现，最终归于失败
- 其爱国主义的"内核"以及平教工作者的奉献精神值得肯定
- 但改良主义路线无法解决中国的根本问题——不触动地主土地所有制，不搞阶级斗争，就无法真正解放农民

**在道法术器中的位置**：需要辨析——表面上是术的层面（平民教育方法），但本质上是改良主义，不是革命的术

**四类角色判定**：**同路人**（爱国主义者，但不是革命者）
- 没有触及社会根本矛盾（不触动地主土地所有制，不搞阶级斗争）
- 没有阶级分析（用教育替代阶级斗争）
- 立场是改良不是革命（教育救国，在现有体制内改良）
- 理论指向实践但实践是改良主义的（平民教育运动最终失败）
- 爱国主义精神值得肯定，但改良主义路线无法解决中国的根本问题

**评价**：晏阳初是真诚的爱国主义者和教育家，他的平民教育运动有其历史价值，他的奉献精神值得尊敬。但他的改良主义路线——不触动地主土地所有制，不搞阶级斗争，用教育替代社会革命——注定无法解决中国的根本问题。平民教育运动最终归于失败，证明了改良主义道路在中国走不通。他是同路人，不是同志。

**历史地位**：

## 四、萨米尔·阿明——依附理论的旗手，第三世界的理论家

**身份**：埃及-法国经济学家，依附理论重要代表人物

**核心贡献**：
1. **依附理论**——关注全球资本主义体系中的财富两极分化，认为资本在核心国家积累是以牺牲外围国家为代价的，这种两极分化是全球资本主义的内在特征，不是可以纠正的缺陷
2. **自主中心式积累vs依附式积累**——将发达资本主义国家的资本积累称为"自主中心式积累"，将不发达国家的资本积累称作"依附式积累"。落后国家的积累是依附式而不是自主中心式，其发展是"欠发达的发展"
3. **脱钩理论（delinking）**——最独特的政策建议，外围国家应该与全球资本主义体系脱钩，追求自力更生的发展和南南区域合作。只有减少对核心经济体的依赖，才能实现真正的发展
4. **外围资本主义**——扩展分析，认为外围的资本主义生产方式不是核心资本主义的延迟版本，而是一种结构上不同的形式，特征是与前资本主义生产方式的衔接、出口导向、剩余被外部行为者挪用而不是国内再投资

**核心观点**：
- 全球资本主义体系的两极分化是内在的、不可纠正的
- 核心国家的富裕建立在外围国家的贫困之上
- 外围国家的"发展"是"欠发达的发展"——越发展越欠发达
- 脱钩是外围国家实现真正发展的唯一道路
- 南南合作是替代全球资本主义体系的方向

**在道法术器中的位置**：法的层面——从政治经济学层面分析全球资本主义体系的剥削机制，为两个世界理论提供学术支撑

**四类角色判定**：**同志**（国际马克思主义者）
- 触及资本主义根本矛盾（全球资本主义体系的剥削机制）
- 有阶级分析（核心vs外围，本质上是国际资产阶级vs国际无产阶级）
- 立场是革命的（脱钩理论、南南合作，挑战全球资本主义体系）
- 理论指向实践（为第三世界国家提供发展战略）
- 一生为第三世界人民的解放事业奋斗

**评价**：萨米尔·阿明是当代最重要的马克思主义经济学家之一，是依附理论的旗手，是第三世界的理论家。他的分析深刻揭示了全球资本主义体系的剥削机制——核心国家的富裕建立在外围国家的贫困之上，这种两极分化是内在的、不可纠正的。他的"脱钩理论"为第三世界国家指明了真正的发展道路——与全球资本主义体系脱钩，追求自力更生和南南合作。他的理论和用户的两个世界理论高度契合——压迫世界vs受压迫世界，本质上就是核心vs外围。他是真正的国际马克思主义者，是同志。

## 五、伊曼纽尔·沃勒斯坦——世界体系理论的创始人

**身份**：美国社会学家，世界体系理论创始人

**核心贡献**：
1. **世界体系理论**——将依附理论扩展为世界体系理论，不分析个别双边关系，而是将整个全球资本主义体系视为一个单一单元，有其自身的逻辑和动态
2. **核心-半外围-外围三层结构**——资本主义世界体系分为三个层次的国家：核心国家（资本密集型生产）、半外围国家（缓冲矛盾）、外围国家（廉价劳动力和原材料）。增加了"半外围"类别，解释一些国家如何能够工业化并在体系内崛起
3. **资本主义历史化**——将资本主义历史化，起源于16世纪的欧洲，不是永恒的自然秩序
4. **霸权周期**——世界体系理论也是霸权理论——单一核心国家周期性地主导世界体系（荷兰→英国→美国）
5. **康德拉季耶夫周期**——纳入长周期分析
6. **全球阶级斗争**——核心国家是全球资产阶级，外围国家是全球无产阶级。阶级斗争是国际性的，不仅是国内的

**核心观点**：
- 资本主义世界体系是一个单一的、历史的、不平等的体系
- 核心-半外围-外围的三层结构是稳定的，但个体国家可以在层级间流动
- 资本主义不是永恒的，它有起源也终将有终结
- 霸权国家周期性更替，但体系本身不变
- 正统马克思主义者批评世界体系理论淡化了内部阶级动态

**在道法术器中的位置**：法的层面——从历史社会学层面分析全球资本主义体系的结构和动态，为两个世界理论提供历史纵深

**四类角色判定**：**同路人**（新马克思主义者）
- 触及资本主义根本矛盾（全球资本主义体系的不平等结构）
- 有一定的阶级分析（核心=全球资产阶级，外围=全球无产阶级），但被正统马克思主义者批评淡化了内部阶级动态
- 立场是批判的，但不够革命（世界体系理论更多是分析框架，不是革命战略）
- 理论指向实践，但主要是学术分析
- 一生为批判全球资本主义体系奋斗

**评价**：沃勒斯坦是当代最重要的新马克思主义社会学家之一，是世界体系理论的创始人。他的分析深刻揭示了全球资本主义体系的结构和动态——核心-半外围-外围的三层结构、霸权周期、康德拉季耶夫周期等。他的理论和用户的两个世界理论有契合之处，但也有区别——沃勒斯坦的三层结构（核心-半外围-外围）比用户的两个世界（压迫世界vs受压迫世界）更复杂，但本质上都是分析全球资本主义的不平等结构。沃勒斯坦的理论更多是学术分析框架，缺少革命战略，所以他是同路人，不是同志。

## 六、大卫·哈维——新马克思主义地理学的旗手

**身份**：新马克思主义地理学家，城市理论家

**核心贡献**（基于已有知识）：
1. **空间理论**——将马克思主义理论引入地理学，分析空间在资本主义积累中的作用
2. **资本积累理论**——分析资本主义如何通过空间扩张和时间修复解决过度积累危机
3. **新自由主义批判**——系统批判新自由主义的本质和后果
4. **城市权利理论**——提出"城市权利"概念，分析城市空间中的阶级斗争
5. **弹性积累**——分析福特主义到弹性积累的转变

**核心观点**：
- 资本主义通过空间扩张和时间修复解决过度积累危机
- 新自由主义是资本阶级反攻的产物，不是自然的经济秩序
- 城市空间是阶级斗争的重要场域
- 城市化是资本积累的重要机制
- 不平衡地理发展是资本主义的内在特征

**在道法术器中的位置**：法的层面——从地理学和城市理论层面分析资本主义的空间剥削机制，为生命论的异化分析提供空间维度

**四类角色判定**：**同路人**（新马克思主义者）
- 触及资本主义根本矛盾（空间剥削、新自由主义、城市异化）
- 有阶级分析（城市空间中的阶级斗争）

### 核心发现

1. **彭湃是术的真正先驱**——纠正了之前把梁漱溟列为"术的先驱"的错误。彭湃用革命的方法解决农民问题，是中国农民运动的三位真正领袖之一（毛泽东、彭湃、方志敏）
2. **晏阳初和陶行知需要区分**——晏阳初是改良主义者，不触动地主土地所有制，平民教育运动最终失败；陶行知是党外布尔什维克，被毛泽东誉为"伟大的人民教育家"，被周恩来称为"一个无保留追随党的党外布尔什维克"，立场更革命
3. **国际马克思主义者中有真正的同志**——萨米尔·阿明（依附理论、脱钩理论）和巴迪欧（共产主义捍卫者）是真正的同志，一生为被压迫人民的解放事业奋斗
4. **沃勒斯坦和哈维是同路人**——他们的理论有价值，但更多是学术分析框架，缺少革命战略，被正统马克思主义者批评淡化了阶级斗争
5. **两个世界理论的国际学术支撑**——阿明的依附理论（核心vs外围）和沃勒斯坦的世界体系理论（核心-半外围-外围），都为用户的两个世界理论（压迫世界vs受压迫世界）提供了国际学术支撑
