## 五案例的共性结论

1. **自指强 ≠ 能持续**：巴黎公社证明自指结构若无边界防卫能力，仍会被消灭（→ 边界防卫第五条件，已补入卷二·篇三 1.7）。
2. **高层自指 ≠ 基层自指**：苏联证明国家层面自指能力增强，不等于基层个体自指能力同步增强（→ 新理论命题2，见《核心新理论命题1-7》）。
3. **反馈机制本身会异化**：毛时代证明纠错机制可能被操纵走向反面，没有一劳永逸的"正确制度"。
4. **经济操作权 ≠ 完整生命自指**：1978后中国证明市场反馈扩大操作权，但不自动等于完整生命自指。
5. **互联 ≠ 自指**：全球资本主义证明高度互联可以同时是操作权极不均衡的他律网络（→ 世界自指 W\*，已补入卷七·篇九）。
