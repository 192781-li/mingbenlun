# 生命论核心新理论命题 · 1-7

> 来源：2026-09-14 知识总包对齐（总包第五十二节）；S05 信息分站组装为成组命题清单
> 性质：目前最重要的新理论命题——库内各卷散见其思想，此处按总包组装为成组清单，便于引用与检验

## 命题 1：自指不是制度名称，而是关系结构的性质

民主不自动等于自指，社会主义不自动等于自指，国家不自动等于自指，市场不自动等于自指；资本主义也不是简单一个静态"东西"。必须问：**谁拥有操作权？谁能反馈？谁能改变规则？谁承担后果？**

## 命题 2：高层自指能力增长 ≠ 低层生命自指能力增长

这是解释苏联等历史经验的重要命题（N→G→Si 增强而 Si→G→N 减弱 → 高层与基层自指脱节）。

## 命题 3：自指系统必须具有边界防卫和持续存在能力

从巴黎公社历史压力测试发现（自指强但缺乏防卫 → 被消灭）。

## 命题 4：全球互联 ≠ 世界自指

真正世界自指要求：全球共同反馈 + 全球共同操作 + 全球规则可修改（→ W\* = F({Gi},应,操作,反馈,纠错)，已补入卷七·篇九）。

## 命题 5：继续革命不是永恒运动，而是持续扩大基层操作权和持续检测高层异化

革命不是周期性政治运动的重复，是日常的、制度化的、递归式的自我纠错。

## 命题 6：革命的成功标准不是推翻旧制度，而是长期提高普通人的生命自指能力

政权改变是手段不是目的；生命论尺度上，成功的标准是 L（生命自指能力）是否长期上升。

## 命题 7：理论本身必须接受实践反驳

如果生命论不能被实践纠正，它本身就可能变成反自指结构（→ L＞S 公理，已补入卷七·篇二 1.8）。
