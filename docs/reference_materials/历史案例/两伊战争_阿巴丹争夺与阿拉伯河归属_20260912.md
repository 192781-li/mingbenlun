# 两伊战争：阿巴丹争夺与阿拉伯河归属

> 2026-09-12 ｜ 历史案例 ｜ 1980–1988，围绕阿拉伯河主权与胡齐斯坦出海口的八年战争
> 定位：外部历史事实材料。与明本论的关联见末节，关联点留待北原慢热雕琢，不代定调。

---

## 一、地理格局：争夺的基础

幼发拉底河、底格里斯河在伊拉克古尔奈汇流成**阿拉伯河**（Shatt al-Arab，伊朗称阿尔万德河 Arvand），全长约204公里，其中约102公里为两伊界河，向东南注入波斯湾。伊朗最长、唯一可通航的**卡伦河**自东北流来，在霍拉姆沙赫尔汇入阿拉伯河。

出海口这片狭小区域集中了双方石油命脉：

| 地点 | 位置 | 战略价值 |
|---|---|---|
| **阿巴丹** | 阿拉伯河中的阿巴丹岛（西临阿拉伯河、对岸即伊拉克，东靠卡伦河巴赫曼希尔出水道），南距波斯湾约50公里 | 战前**世界最大炼油厂**，日炼约62.8万桶，平民约30万 |
| **霍拉姆沙赫尔** | 卡伦河汇入阿拉伯河处、阿巴丹西北约5–12公里 | 伊朗战前最大干货港；海路至巴士拉18海里、至阿巴丹11海里、至法奥38海里 |
| **巴士拉** | 阿拉伯河西岸（伊拉克侧） | 伊拉克第二大城、南部石油命脉 |
| **法奥半岛** | 伊拉克最南端、阿拉伯河西岸，距巴士拉约90公里 | 扼阿拉伯河入海口 |
| **马吉努岛** | 巴士拉以北 | 富藏石油 |

## 二、归属权之争：战争根源

- **1975年以前**：阿拉伯河以**伊朗一侧浅水线（伊朗河岸）**为界，整条河主权归伊拉克，伊朗通航受制。
- **1975-03-06《阿尔及尔协议》**：阿尔及利亚总统布迈丁斡旋，伊拉克（萨达姆时任革命指挥委员会副主席）与伊朗巴列维国王签约，改以**主航道中心线（thalweg）**划界，阿拉伯河由伊拉克独占变两国共享；伊朗承诺停止支持伊拉克库尔德武装，并答应划约300平方公里陆界土地给伊拉克（事后未完全兑现）。伊拉克视此协议为"丢面子"。
- **1979年**：伊朗伊斯兰革命，霍梅尼建立政教合一政权，号召占伊拉克人口约55%的什叶派推翻萨达姆，矛盾激化。
- **1980-09-17**：萨达姆宣布废除阿尔及尔协议、收回全部阿拉伯河主权；**1980-09-22战争爆发**。

---

## 三、争夺时间线：地点来回易手

### 1. 1980 伊拉克突袭入侵
- 9.22空袭并地面入侵胡齐斯坦省。
- **霍拉姆沙赫尔战役**（9.22–11.10）：伊拉克9.28/10.14攻入，约2000正规军+2000革命卫队逐街巷战，**双方各约7000人死亡**，伊朗改称"血城(Khuninshahr)"，11.10伊拉克基本占领。惨重伤亡使其不敢强攻阿巴丹。
- **阿巴丹围城**：11.3伊拉克坦克抵阿巴丹被革命卫队+空军挡在城外，在卡伦河以南造三角突出部切断补给、围城约11–12个月始终未克，伊朗夜间用小船经水道/海上运补。
- 1980.10末–11初伊拉克占领伊朗约2万平方公里、深入80–90公里，控制阿拉伯河东岸狭长地带。

### 2. 1981.9 阿巴丹解围
伊朗集中10余万兵力发动阿巴丹反击战，激战3天把围城伊军赶过卡伦河，解除阿巴丹之围。炼油厂与城市大部被毁、平民几乎全逃。

### 3. 1982.5 收复失地、反攻入伊
1982.3"胜利行动"；4.20起约10万人"耶路撒冷圣城行动"经25天于**1982.5收复霍拉姆沙赫尔**，伊朗基本收复全部失地。萨达姆求和愿回战前状态，霍梅尼拒绝，反攻入伊拉克、围攻巴士拉。

### 4. 1985–1987 相持拉锯（战场转伊拉克一侧）
- 1985年伊朗攻占马吉努岛。
- 1986年伊朗突袭占领法奥半岛，控制河口约两年。
- 1987.1–2"卡尔巴拉5号"（第六次巴士拉战役，战争最大规模），突破巴士拉以东四道防线仍未占城。

### 5. 1988 伊拉克终局反攻
- **1988-04-17"斋月行动"**：约34–48小时闪电收复被占两年的法奥半岛（战争转折点）。
- 5月收复萨拉姆杰，6月收复马吉努岛、祖拜达特，把伊朗军队基本逼回境内，战线回到接近1980战前。
- 1988-07-14伊朗接受安理会598号决议，**1988-08-20正式停火**。

## 四、最终归属

| 地点 | 最终归属 | 战争中易手 |
|---|---|---|
| 阿巴丹 | 伊朗 | 被围11月未陷 |
| 霍拉姆沙赫尔 | 伊朗 | 1980陷→1982收复 |
| 巴士拉 | 伊拉克 | 六次被攻未陷 |
| 法奥半岛 | 伊拉克 | 1986失→1988收复 |
| 马吉努岛 | 伊拉克 | 1985失→1988收复 |
| 阿拉伯河 | 主航道中心线为界 | 回到1975安排 |

打了8年，边界几乎回到原点：阿拉伯河最终仍按主航道中心线为界（事实上回到1975框架），阿巴丹、霍拉姆沙赫尔归伊朗，巴士拉、法奥、马吉努归伊拉克。

## 五、伤亡与经济损失（口径分列）

### 伤亡
| 口径 | 死亡 | 受伤 |
|---|---|---|
| 央视/人民网常用 | 约100万 | 约170万 |
| 分国（央视） | 伊拉克约18万、伊朗约70万 | 伊拉克25万、伊朗110多万 |
| 上外中东所 | 伊拉克25万（一说40万）、伊朗28万 | 伊朗约42万 |
| 难民 | 超300万无家可归 | — |

### 经济损失
- 直接战费约2000亿美元；军费+经济损失合计5000亿–9000亿美元（不同口径）。
- 军费占GDP一度伊朗60%、伊拉克164%。
- **伊拉克**：战前外汇盈余近400亿，战后外债约800亿（其中400多亿军火债、300多亿阿拉伯国家贷款，欠科威特约140亿）。
- **伊朗**：外债约450亿。

### 钱烧在哪
双方石油富国狂买先进武器（约150万兵力、近6000辆坦克、近1000架飞机，"用先进武器打落后战争"）；互相摧毁石油设施（阿巴丹炼油厂、袭船战、导弹袭城战）；化学武器；伊朗人海战术（少年排雷）；石油收入暴跌（伊拉克战时不及战前1/5）。

---

## 六、连锁后果

伊拉克战后外债800亿还不上、又想夺油田，直接导致**1990年入侵科威特**，进而引发1991海湾战争。萨达姆1980年想靠速战夺回阿拉伯河，结果把自己拖进十年两场战争。
