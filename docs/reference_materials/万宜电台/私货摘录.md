## 一、斯大林失踪？朱可夫出山搞枪指挥党？

### 关键私货：

1. **"枪指挥党"**：朱可夫主义被设定为"枪指挥党"——党指挥枪的反转。万宜评论："历史上他是一个墙头草……说好听点叫职业军人，说不好听点就是没有明确的意识形态立场。"

2. **"单向的资源倾斜不等于民族平等"**：苏联民族问题的分析——主体民族长期承担援助边疆的大头却没有优待，容易产生"付出多、保障不足"的感受。解决方案：不按民族身份划分，按发达/落后地区划分。

3. **苏维埃内耗**：多个苏维埃势力（朱可夫、崔可夫、日丹诺夫）本无核心矛盾却被强制敌对——"为什么还要让苏联出现国防力量的自我消耗？"

4. **对mod制作者的评价**："根正苗红的资本主义战士，纯正的新自由主义接班人"——美国秒德国是制作组预设的历史线。

5. **加里宁主义**：世界观默认的共产主义形态不是斯大林主义而是加里宁主义——名义上的国家元首以老资历威望起关键作用。

### 关键私货：

1. **"妥协的艺术"**：温和社民里贝斯"以开放信仰自由之名平反了教会，以政治自由之名平反了民粹，以经济自由之名平反了共和"——和稀泥引发左派不满。

2. **"资本家改名叫朋友"**："资本家这个词不好听，改名叫朋友。富家孩子们学经济学，像他们爸爸一样负责管理人民的资产，我们从中抽取一点点合理的管理费用，很公平。"

3. **"钱是第一生产积极性"**：用钱买科研加成、工厂数量、企业资质、军官加成——物质刺激全套。

4. **"只要每个人手里都有钱，谁还在乎工厂属于谁"**：不追求平等，只追求货币稳定——这是对福利国家/消费主义最精确的概括。

5. **"可持续性的竭泽而渔"**："只要我们剥削的速度赶得上他们恢复的速度，这就不叫竭泽而渔，这叫可持续性发展。"

6. **"这个世界上唯有利润是神圣的"**：利益挂帅国策。

7. **"如果不能消灭他们，就买下他们"**：通过资助安插人手，把工会变成"喊口号维护生产效率的摆设"。

8. **"谁说资本家不能拥护革命"**：企业控制所有媒体，最终"复兴十月革命"建立苏维埃资本主义企业同盟——革命被彻底收编。

9. **"人人持枪，那是天下大乱达到天下大治"**：法国内战各势力都有5万步枪。

10. **工团主义失败分析**："工团、雅各宾、索雷尔、无政府在议会上相互攻伐……法兰西公社变成了喧嚣的巴别塔。"——左派内耗导致革命失败。

## 三、二战但是假如德国左转了一些些？
- 视频：BV1CVohBPEvv，时长11:34，mod：Fight For The Fatherland
- 内容：德国十一月革命后，走施特拉塞（正统民社/小资产阶级社会主义）路线

### 关键私货：

1. **"社会主义不等于马克思主义"**："马克思主义是社会主义，但社会主义不一定是马克思主义。"民族社会主义是另一种社会主义流派——小资产阶级的社会主义。

2. **施特拉塞vs希特勒**：
   - 施特拉塞反对的是"犹太金融资本"而非犹太人（驱逐而非灭绝）
   - 种族优势不在血缘基因，在"是否能实现更先进的社会制度"
   - 希特勒在长刀之夜清洗冲锋队和施特拉塞，选择保护大企业——"小胡子是资本主义经济危机时最野蛮的形态"
   - 施特拉塞认为社会主义比民族主义更重要，希特勒相反

3. **小资产阶级社会主义的经济主张**：
   - 合作社、工人参与企业管理与分红
   - 拆分大农场，土地农民继承不可买卖
   - 国有化和计划经济
   - 但"小资是一种不剥削也不被剥削的状态，掌握一定生产资料但不多，时刻有做大变资本或破产变无产的风险"
   - "合作社自治但不独立，一切利益向民族整体利益让步"
   - 最终评价："经典的第三道路，但实践成果捉襟见肘，很多理论只能停留于空想"

4. **"这不是入侵，这叫团结；这不是扩张，这叫回家"**：用民族主义语言包装帝国主义扩张——组织公投、德奥合并、收回苏台德、闪击波兰。

5. **"谁是我们的敌人，谁是我们的朋友"**：直接引用毛泽东。民族认同的边界随共同敌人扩大，"早晚人类都会上升到世界主义，实现人类种族的团结"。

6. **"柏林莫斯科轴心"**：施特拉塞德国与苏联结盟——"这是同盟国对我们的污蔑"。

7. **军队人民化**：反对职业化军队和军衔等级、贵族特权，主张民兵全民皆兵——"防止内部大资本大地主复辟"。

8. **万宜自述**："我看了将近半个月的关于这方面的书籍才大概了解……读书好啊，历史书得多读，不然别人发表意识形态意见你根本听不懂。现在我们思考的很多问题，历史上已经有所答案了。"

## 与生命论的对接点

1. **名实遮蔽**：资本家改名叫朋友、入侵改名叫团结回家、革命被收编为资本主义企业同盟——名与实的系统性脱节。
2. **革命被收编**："把革命的台尔曼变成德国的台尔曼"在视频2中以"复兴十月革命建立资本主义企业同盟"的形式出现——革命的名被保留，实被替换。
3. **小资产阶级社会主义**：施特拉塞线是"第三条道路"的标本——反大资本也反劳工运动，最终要么向大资本投降（希特勒），要么停留在空想。这对理解当代"中间道路""福利国家"有参考价值。
4. **左派内耗**：工团各派相互攻伐导致公社崩溃、苏维埃各势力自我消耗——革命的反自指不只来自外部敌人，更来自内部的宗派主义。
5. **"可持续性的竭泽而渔"**：反自指正反馈的精确比喻——只要剥削速度≥恢复速度就叫"可持续发展"。
6. **"谁是敌人谁是朋友"**：万宜引用毛泽东，而生命论的判据是M=α·T·N——谁在提高最大多数人的M值，谁在压低它。
7. **单向资源倾斜≠平等**：民族问题的分析对接"阳主阴从"——形式上的倾斜不等于实质上的平等，要看操作权在谁手里。
