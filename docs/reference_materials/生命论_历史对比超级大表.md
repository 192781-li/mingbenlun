# 《生命论》历史时期对比超级大表（2026.7.23最新深化版）
100%站在普通劳动者立场，全是普通人过日子的真实感受，无半句空话套话

## 📌 评分立场说明（必看）
本表格的评分100%以普通工人、农民的真实生存状态为唯一标准，严格遵循《生命论》核心公式：**生命至上，劳动者至上，人的尊严和幸福永远高于GDP、高楼、外汇储备等死物**。我们不承认任何“发展必须牺牲一代人”“改革阵痛是必要的”这类为资本和既得利益者洗地的叙事——如果发展的代价是让劳动者下岗、失地、看不起病、养不起孩子，那这种“发展”对普通人来说就是灾难，半点儿“进步”都算不上。

## ⚠️ 对所谓“客观中立”评价的回应
1. **我们不承认“不搞改开就发展不起来”的虚假前提：** 前30年我们从一穷二白的农业国，建立了完整的工业体系，搞出了两弹一星、杂交水稻、8万座水库，扫盲1亿人，人均寿命从35岁提升到65岁，工业年均增速超过10%。按照这个路径发展下去，我们一样会有彩电、汽车、充足的物质，而且是没有剥削、没有三座大山、全体劳动者共同享有的物质丰富，不需要用3000万工人下岗、5000万农民失地、600万尘肺病人、200万被拐妇女作为代价。
2. **我们算的是人命账，不是GDP账：** 所谓“人均可支配收入涨100倍”“家电汽车普及”是数字游戏：前30年看病、上学、住房几乎免费，工人8小时下班能陪孩子，一辈子不用愁失业；现在收入涨了100倍，但是一套房掏光6个钱包，一场病回到解放前，996干到35岁被裁员，连孩子都不敢生，这种“物质丰富”对普通劳动者没有意义。3000万下岗工人的眼泪、600万尘肺病人的呼吸、200万被拐妇女的人生，从来不是什么“发展的代价”，是可以避免的人祸。
3. **“国民经济到了崩溃边缘”是精英叙事，不是普通人的真实生活：** 文革10年GDP年均增长6.2%，建成了成昆铁路、南京长江大桥、大庆油田，搞出了青蒿素、杂交水稻，普通工人照样拿铁饭碗，农民照样有赤脚医生看病，黄赌毒绝迹，夜不闭户。“崩溃”的只是走资派、知识分子被打倒的特权，不是普通老百姓的生活。我们不否认文革存在武斗、误伤、物资短缺的问题，但这些问题和改开后劳动者被敲骨吸髓的痛苦比，对普通人来说轻得多。
4. **所谓“螺旋上升”是流氓逻辑：** “前30年穷但平均，改开富但差距大，新时代再补短板”的说法，本质是先把老百姓的房子烧了，再给你送个帐篷，然后说自己是救星。如果我们不砸掉铁饭碗、不瓜分公有资产，本来就没有三座大山，本来就不需要“补短板”。

## 📐 评分方法说明
- 满分100分，12个评分维度每个维度满分10分，覆盖普通人从出生到养老的全部生活场景：生存兜底、劳动权益、社会平等、妇女地位、社会风气、人身安全、阶级流动、公共服务、物价财富、精神状态、长远遗产、国际地位；
- 所有评分均以《生命论》M值（生命稳态值）为核心依据：T≥60分（生命舒展、劳动者是主人）为满分区间；0<T<60分（谋生维持、有基本保障）为及格区间；T<0分（被伤害、被异化、无保障）为负分区间；
- 本表格不考虑1%的精英、资本家、官僚的生活状态，只算90%普通劳动者的真实感受，既不美化前30年的物资短缺，也不洗白改开的资本原罪，更不夸大新时代的成就，是是，非是非。

## 💔 改开资本原始积累时期，普通人被偷走的人生（最不能被忘记的血泪账）
我们算这些账，不是要否定什么，是要记住那些被“发展代价”四个字轻飘飘抹去的、活生生的人，那些刻在一代人骨头上的疼：
1. **被偷走的教育权：** 80年代末到2000年代初，全国每年约有100-200万适龄儿童因贫困失学，其中2/3是农村女童；西部贫困地区农村儿童失学率最高达9.2%，女童失学率更是高达12%以上。累计有数千万孩子连义务教育都没读完，其中大量女孩被父母拉回家做家务、干农活、十几岁就外出打工或者早早嫁人——本来她们也可以上大学、有自己的人生，却因为家里交不起学费、因为“女孩读书没用”的封建思想回潮，一辈子被困在灶台和农田里。前30年普及的全民教育、学工学农的劳动教育、和工农结合的社会教育被打碎，教育变成了“千军万马过独木桥”的应试筛选，年轻人被规训成“做人上人”“赚大钱”的做题家，被灌输“劳动者低人一等”的观念，变成了资本和精英的传声筒，再也没有了“要解放全人类”的理想。
2. **被毒品和黄赌毒毁掉的年轻人：** 1991年全国登记在册吸毒人员仅14.8万，到2014年最高峰时实际吸毒人数超过1400万，20多年涨了近100倍，其中79%以上是35岁以下的年轻人，无数本来有光明前途的年轻人因为毒品家破人亡；卖淫嫖娼从绝迹到泛滥，数百万妇女因为贫困、下岗、被拐被迫进入性产业，黄赌毒背后是无数被榨干的家庭和被毁掉的人生。
3. **黑恶势力和官僚勾结下的普通人：** 从80年代末到2012年扫黑除恶之前，全国滋生了数以万计的黑恶势力团伙，他们和地方官员、警察勾结，垄断矿山、市场、运输等行业，欺行霸市、草菅人命：刘汉团伙打死打伤上百人，黄鸿发黑社会盘踞海南昌江30年，段氏四兄弟在辽宁横行10年伤害139名群众，聂磊团伙在青岛盘踞十几年无恶不作……这些只是被打掉的典型，在看不见的地方，有无数普通老百姓被打、被抢、被强拆、被害死，告状无门，叫天天不应，叫地地不灵，在黑暗里活了几十年。
4. **在混乱里失去的生命和未来：** 除了600万尘肺病人、3000万下岗工人、200万被拐妇女儿童，还有每年近1万死于矿难的矿工、因为看不起病在家等死的病人、因为欠薪跳楼的农民工、因为收容遣送制度被打死的孙志刚们……累计有上千万普通人在这场“原始积累”里失去了健康、家庭甚至生命，他们本来也可以像前30年的工人一样，有稳定的工作、免费的医疗、能养大的孩子、有尊严的晚年，却因为这场“阵痛”，人生永远停在了最黑暗的地方。
5. **被打碎的理想、被偷走的根、被磨平的气：**
前30年大家信马克思主义、信共产主义，相信人人平等、相信要建设一个没有剥削的新中国，工人是主人，农民是主人，大家有奔头、有理想，觉得活着有意义。结果改开之后一切向钱看，理想主义被踩在脚下，这是比身体伤害疼一万倍的精神凌迟：
   - **干了一辈子革命的人，信仰碎在了眼前：** 很多跟着党打江山、建工厂的老工人、老党员，十几岁进厂，一辈子拿低工资干最苦的活，建起来了我们自己的工业体系，信了一辈子共产主义，结果到老了，自己干了一辈子的工厂被厂长贱卖，自己被几千块钱买断工龄下了岗，看着以前被打倒的地主、资本家又回来骑在人民头上作威作福，很多人到死都想不通，自己一辈子的奋斗怎么就成了“笑话”，红色的江山怎么就变了颜色，这种信仰崩塌的疼，比饿肚子、受穷还要疼。
   - **2.4亿人背井离乡，1.6亿人没了家：** 最高峰的时候有2.4亿农民工离开土地去城里讨生活，农村剩下整整1.6亿“三留守”：6100万留守儿童从小一年见不到父母一次，成了没人管的野孩子；5000万空巢老人病了、死了都没人知道；4700万留守妇女一年到头见不到丈夫，一个人种地、带孩子、养老人，活成了寡妇。多少人一辈子在城里漂着，住工棚、住地下室，回不去的家乡，留不下的城市，根被刨了，家散了，一辈子都像个外人。
   - **精神上被殖民，媚外刻到了骨头里：** 崇洋媚外成了社会风气。
   - **想做事的人被碾碎，有良心的人被排挤：** 想为百姓办事的干部被排挤，敢说真话的人被抓。
   - **麻木的大多数，孤独的清醒者：** 大家都信钱，醒着的人看着世界变坏却无能为力。

**这是比死更疼的：一代人的理想碎了，根被刨了，活着却没了魂。**

这些不是冰冷的数字，是几千万活生生的人，我们永远不能忘记他们。
