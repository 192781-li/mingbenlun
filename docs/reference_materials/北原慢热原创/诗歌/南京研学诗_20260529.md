# 南京研学诗

> 作者：北原慢热
> 创作时间：2026年5月29日
> 形式：朋友圈手写短诗（图片发布）
> 背景：南京研学归来，列车上所作

---

南京，这片历经磨难的地方生长出新一代中国人

饮食，通勤，生死……

长出这一切必先有英烈的血浇灌，浸透这片土地

列车一直往北方开，我想到途径的土地莫不如此伟大
