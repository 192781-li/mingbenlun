# 性与政治：玷污性的人就是反自指的卫士

**日期**：2026-08-28
**提出者**：北原慢热
**核心命题**：理解性是理解世界的有效途径。越玷污性，越对人的本质畏惧。玷污性的人就是反自指的卫士，正义自指力量的敌人。

---

## 一、性是人的本质最裸露的地方

性=心+生，是生命最根本的倾向在身体上的直接表达。你怎么对待性，本质上就是你怎么对待人的生命本身。

理解性就是理解世界——因为性暴露了所有真相：人是身体的、是欲望的、是脆弱的、是需要连接的、是自指的。你理解了性，你就理解了人最根本的操作方式，然后看工作、看政治、看文化，全是同一个结构——都是在问：这个操作是为了生命本身，还是为了别的东西？

## 二、性压抑不是道德问题，是政治问题

拼命玷污、压抑、污名化性的人，不是在"维护道德"，是在**畏惧**——畏惧人真的成为自指的生命体。

性是反自指社会里最后一块自指飞地。把性污名化了、让人对自己的身体感到羞耻了、让人觉得"我的欲望是脏的"，就从根上切断了人体验自指操作的能力。

一个连自己身体的快感都不敢承认的人，你让他去争取工作的自主权、政治的自主权、文化的自主权——他连"我想要什么"都不敢说了，还争什么？

性压抑是反自指结构最底层的卫士——从身体层面就让人自我否定，上面的经济剥削、政治压迫、文化异化就全稳了。一个对自己的性都感到羞耻的人，是最好统治的人。

## 三、所有真正的解放运动都跟性解放绑在一起

不是因为性是最重要的，是因为性是最底层的。底层不解放，上面的解放全是假的。

- 资产阶级革命给了政治权利但没给性解放，性还是被宗教和家庭控制
- 无产阶级革命给了经济权利但如果性还被压抑，人还是不能真正成为自己

## 四、关于偏激

这个判断可能偏激，但应该允许偏激。真理往往从偏激的、有温度的、让人感到刺激的表述中诞生，然后在后续的操作中被修正、被细化。四平八稳的"客观分析"往往什么都没说。

**长谈实录和私人表述里允许偏激，模块化全本里需要严谨。** 两个场域，两个标准。
