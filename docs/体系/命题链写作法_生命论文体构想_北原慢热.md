# 命题链写作法：《生命论》政治经济学批判的文体构想

> 2026-09-07 ｜ 写作方法论 ｜ 提出者：北原慢热
> 状态：思想启发，留待全本写作时采用

## 一、北原慢热原话（完整记录）

> 马克思写《资本论》几百万字，大家读的太累了，但是呢，我想啊，我能不能创造一种写作方法，每章的标题是，就是说专门比如说出一本或者说出一类的表达方法，它是一个连续的，每章的标题是一个观点，观点连续下来是对某一种大家真正能戳大家心灵和认知的一些思维的颠覆。然后呢，在里实际的写作过程中，以极为严谨的语言去批判、解构以及抒发真正的理论，这个是留作一个思想启发吧。

## 二、方法的核心结构

**传统学术体（《资本论》式）**：章节标题是中性的研究对象（"商品""货币""资本""剩余价值率转化为利润率"），观点藏在正文里，读者要啃几百万字才能拼出全貌。门槛极高，大众进不去。

**命题链写作法（生命论式）**：
1. **每一章的标题本身就是一个完整观点、一记重锤**——不是"论商品"，而是"商品是你被夺走的操作权的第一张面具"；
2. **章标题连起来，本身就是一条连续的认知颠覆链**——读者光读一遍目录，就被完整地"过"了一遍思想，世界观已经被撬动；
3. **正文用极为严谨的语言**去支撑标题那个观点：批判（拆对手）、解构（还原机制）、建构（立生命论自己的）、抒发（有力量的理论表达）四者合一；
4. 标题负责"戳心灵、破认知"，正文负责"立得住、驳不倒"。**锋利在标题，硬度在正文。**

## 三、为什么这个方法成立（生命论根据）

1. **名实相符**：标题直接亮明观点，不藏着掖着，反对教科书式的"中立客观"伪装——没有任何写作是无立场的，与其假装中立，不如把观点摆明、把论证做硬。
2. **F1先于F2**：读者先要在感层面被击中（标题戳到真实的痛和困惑），才愿意进入F2的严密论证。中性标题连F1都唤不醒，正文再硬也没人读。
3. **降低第一哲学的门槛而不降低深度**：《资本论》的深度不该以"读不下去"为代价。命题链让目录成为宣言、让每一章成为一个可以独立传播又彼此咬合的环节。
4. **链条即体系**：观点不是散的，是环环相扣的锁链——前一章的结论是后一章的前提，读完目录就看到整条论证的走向，体系的力量通过链条的严密性显现。

## 四、形式要求

- 标题是**判断句/命题**，不是研究领域名词；
- 相邻标题之间有**明确的逻辑递进**（不是并列罗列）：破一个神话→揭一层机制→立一个替代；
- 每个标题都能**独立成立、单独传播**（像一句句格言），合起来又是严密整体；
- 正文必须配得上标题的锋利：每个颠覆性标题下面，是概念界定、机制还原、证据、对反方最强论证的回应，不许只有情绪；
- 一卷的标题链读完，读者完成一次完整的认知颠覆。
