# 人的本质：操作论的定义（北原慢热原创命题）

> 2026-09-07 ｜ 体系核心命题 ｜ 由北原慢热在精读《关于费尔巴哈的提纲》过程中原创提出
> 本文档收录两个递进的命题，以及它们的展开、对接和划界。

---

## 命题一：人的本质是状语修饰着的动词的总和

### 原文
> 人的本质不就是状语修饰着的动词的总和吗？

### 展开
传统哲学（包括费尔巴哈、马克思早期）说"人的本质是X"，这里"本质"是一个名词，是一个实体，人去"拥有"它、"实现"它。这个表述从语言结构上就预设了本质是一个先在的东西。

操作论的语言分析直接戳破这个实体化：
- **动词** = 操作、活动、实践——人在做什么
- **状语** = 这个操作的方式、条件、状态——怎么做、在什么条件下做、以什么方式做
- **人的本质不是名词，是被状语修饰着的动词的总和**——也就是人在具体条件下、以具体方式进行的全部操作活动的总和

没有状语的动词是空洞的：抽象的"劳动""实践""自由"，脱离了具体条件，就是一个空壳。有状语的动词才是具体的、现实的人。

### 与四规定性的关系
四规定性（践演、联结、自我持存、明性施展）就是这些动词的根本形态。状语就是具体的社会关系、历史条件、反自指结构。

- 不是人"拥有"四规定性（名词化），是生命**在操作中**践演、联结、自我持存、明性施展（动词化）；
- 四规定性不是固定的本质，是可以被压抑（异化）、可以被展开（解放）的动态操作。

### 对"类本质"的彻底祛魅
- 费尔巴哈：类本质是"理性、意志、心"——全是名词，全是实体。
- 马克思：类本质是"自由自觉的劳动"——把名词换成了动名词，但还是有一个叫"类本质"的东西在那里。
- 本命题：连"本质"这个名词都消解了，剩下的只有操作和操作的条件。

类本质的唯一意义，就是帮助我们理解四规定性；理解了四规定性，类本质就可以拆掉了。

## 命题二：人的本质是既定事实与每时每刻操作的作用结果

### 原文
> 一个人的本质是既定事实与每时每刻操作，每时每刻的操作，这二者间的作用结果。而既定事实又包括本人过去操作的沉淀和一切非本人所能左右的人与物之间的操作史。

### 展开
这是对命题一的精确化和动态化。命题一说"状语修饰着的动词"，命题二把"状语"精确地拆成了"既定事实"，并且给出了本质的递归生成公式。

#### 既定事实（状语的硬核部分）
分两层：
1. **本人过去操作的沉积**——自己造的惯性、自己的反自指、自己的生命史。这部分是你自己的操作反过来约束你现在的操作。
2. **非本人所能左右的人与物的操作史**——社会历史、阶级结构、自然条件、他人的操作、世代沉积下来的一切。这部分不是你造的，但你必须在它里面操作。

#### 每时每刻的操作（动词）
当下的能动性、此刻的选择、此刻的践演和明性。

#### 二者的作用结果
不是简单相加，是持续的相互作用：
- 既定事实约束着你能做什么操作、怎么做操作；
- 但你的操作又在改变既定事实——你此刻的操作会沉积下来，变成下一刻的既定事实的一部分。

#### 递归公式
```
本质(t) = f(既定事实(t), 操作(t))
既定事实(t+1) = 既定事实(t) + 操作(t)的沉积
```

本质不是固定的，是每时每刻都在递归生成的。

### 与马克思的对接
马克思在《路易·波拿巴的雾月十八日》开头说："人们自己创造自己的历史，但是他们并不是随心所欲地创造，并不是在他们自己选定的条件下创造，而是在直接碰到的、既定的、从过去承继下来的条件下创造。"

本命题把这句话彻底操作论化，并且从历史层面下沉到个体存在论层面：
- 马克思的"既定的、从过去承继下来的条件" → 本命题的"既定事实"，且精确分为"本人过去操作的沉积"和"非本人所能左右的操作史"；
- 马克思的"人们自己创造自己的历史" → 本命题的"每时每刻的操作"；
- 马克思的"不是随心所欲" → 本命题的"二者间的作用结果"。

### 明性在这个公式里的位置
明性（F3）= 在既定事实和当下操作的相互作用中，跳出来看一眼这个相互作用本身，然后调整操作的方向。

明性不是改变既定事实，是改变操作和既定事实相互作用的方式。

### 对自由与必然问题的解决
- 不是被既定事实决定的（庸俗唯物）——因为每时每刻的操作有能动性；
- 也不是可以任意创造的（唯心）——因为既定事实强硬地约束着操作；
- 本质是二者持续相互作用的结果，而且这个结果每时每刻都在变。

## 两个命题的关系

| | 命题一 | 命题二 |
|---|---|---|
| 核心 | 语言哲学层面的解构 | 存在论层面的建构 |
| 做了什么 | 把"本质"从名词消解为动词+状语 | 把"状语"精确化为"既定事实"，给出递归公式 |
| 对应 | 操作先于实体（语言层面） | 操作先于实体（存在论层面） |
| 状态 | 解构性的 | 建构性的 |

命题一拆了旧房子，命题二盖了新房子。

---

## 可引用的凝练表述

> 人的本质不是先在的实体，而是状语修饰着的动词的总和——即在具体历史条件下、以具体方式持续进行的全部操作活动。
>
> 更精确地说：一个人的本质是既定事实与每时每刻操作二者间的作用结果。既定事实包括本人过去操作的沉积，以及一切非本人所能左右的人与物的操作史。本质不是固定的，是每时每刻都在递归生成的——此刻的操作沉积为下一刻的既定事实，下一刻的操作又在新的既定事实中展开。
