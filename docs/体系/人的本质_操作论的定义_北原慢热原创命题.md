# 人的本质：操作论的定义（北原慢热原创命题）

> 2026-09-07 ｜ 体系核心命题 ｜ 由北原慢热在精读《关于费尔巴哈的提纲》过程中原创提出
> 本文档收录两个递进的命题，以及它们的展开、对接和划界。

---

## 命题一：人的本质是状语修饰着的动词的总和

### 原文
> 人的本质不就是状语修饰着的动词的总和吗？

### 展开
传统哲学（包括费尔巴哈、马克思早期）说"人的本质是X"，这里"本质"是一个名词，是一个实体，人去"拥有"它、"实现"它。这个表述从语言结构上就预设了本质是一个先在的东西。

操作论的语言分析直接戳破这个实体化：
- **动词** = 操作、活动、实践——人在做什么
- **状语** = 这个操作的方式、条件、状态——怎么做、在什么条件下做、以什么方式做
- **人的本质不是名词，是被状语修饰着的动词的总和**——也就是人在具体条件下、以具体方式进行的全部操作活动的总和

没有状语的动词是空洞的：抽象的"劳动""实践""自由"，脱离了具体条件，就是一个空壳。有状语的动词才是具体的、现实的人。

### 与四规定性的关系
四规定性（践演、联结、自我持存、明性施展）就是这些动词的根本形态。状语就是具体的社会关系、历史条件、反自指结构。

- 不是人"拥有"四规定性（名词化），是生命**在操作中**践演、联结、自我持存、明性施展（动词化）；
- 四规定性不是固定的本质，是可以被压抑（异化）、可以被展开（解放）的动态操作。

### 对"类本质"的彻底祛魅
- 费尔巴哈：类本质是"理性、意志、心"——全是名词，全是实体。
- 马克思：类本质是"自由自觉的劳动"——把名词换成了动名词，但还是有一个叫"类本质"的东西在那里。
- 本命题：连"本质"这个名词都消解了，剩下的只有操作和操作的条件。

类本质的唯一意义，就是帮助我们理解四规定性；理解了四规定性，类本质就可以拆掉了。

## 命题二：人的本质是既定事实与每时每刻操作的作用结果

### 原文
> 一个人的本质是既定事实与每时每刻操作，每时每刻的操作，这二者间的作用结果。而既定事实又包括本人过去操作的沉淀和一切非本人所能左右的人与物之间的操作史。

### 展开
这是对命题一的精确化和动态化。命题一说"状语修饰着的动词"，命题二把"状语"精确地拆成了"既定事实"，并且给出了本质的递归生成公式。

#### 既定事实（状语的硬核部分）
分两层：
1. **本人过去操作的沉积**——自己造的惯性、自己的反自指、自己的生命史。这部分是你自己的操作反过来约束你现在的操作。
2. **非本人所能左右的人与物的操作史**——社会历史、阶级结构、自然条件、他人的操作、世代沉积下来的一切。这部分不是你造的，但你必须在它里面操作。

#### 每时每刻的操作（动词）
当下的能动性、此刻的选择、此刻的践演和明性。

#### 二者的作用结果
不是简单相加，是持续的相互作用：
- 既定事实约束着你能做什么操作、怎么做操作；
- 但你的操作又在改变既定事实——你此刻的操作会沉积下来，变成下一刻的既定事实的一部分。

#### 递归公式
```
本质(t) = f(既定事实(t), 操作(t))
既定事实(t+1) = 既定事实(t) + 操作(t)的沉积
```

本质不是固定的，是每时每刻都在递归生成的。

### 与马克思的对接
马克思在《路易·波拿巴的雾月十八日》开头说："人们自己创造自己的历史，但是他们并不是随心所欲地创造，并不是在他们自己选定的条件下创造，而是在直接碰到的、既定的、从过去承继下来的条件下创造。"

本命题把这句话彻底操作论化，并且从历史层面下沉到个体存在论层面：
- 马克思的"既定的、从过去承继下来的条件" → 本命题的"既定事实"，且精确分为"本人过去操作的沉积"和"非本人所能左右的操作史"；
- 马克思的"人们自己创造自己的历史" → 本命题的"每时每刻的操作"；
- 马克思的"不是随心所欲" → 本命题的"二者间的作用结果"。

### 明性在这个公式里的位置
明性（F3）= 在既定事实和当下操作的相互作用中，跳出来看一眼这个相互作用本身，然后调整操作的方向。

明性不是改变既定事实，是改变操作和既定事实相互作用的方式。

### 对自由与必然问题的解决
- 不是被既定事实决定的（庸俗唯物）——因为每时每刻的操作有能动性；
- 也不是可以任意创造的（唯心）——因为既定事实强硬地约束着操作；
- 本质是二者持续相互作用的结果，而且这个结果每时每刻都在变。

## 两个命题的关系

| | 命题一 | 命题二 |
|---|---|---|
| 核心 | 语言哲学层面的解构 | 存在论层面的建构 |
| 做了什么 | 把"本质"从名词消解为动词+状语 | 把"状语"精确化为"既定事实"，给出递归公式 |
| 对应 | 操作先于实体（语言层面） | 操作先于实体（存在论层面） |
| 状态 | 解构性的 | 建构性的 |

命题一拆了旧房子，命题二盖了新房子。

## 命题三：信息时代的既定事实——全面渗透与小孔填实

### 北原慢热原话（一字未改）

> 而且我是极为诚实的，那个你提你提及到的，马克思在什么什么雾月革命什么那篇文章里提及的，说人所能改变的历史，实际，或者说人能改变历史的认识以及理论来源，他不能脱离具体的他们接触到的条件。和，而且条件我想我认为，它必定是包括思想上的认识与和具体的行为的指导的，但是在这个信息时代。呃大量的信息，对吧？无数的方法论，无数的方方面面的思想，从本体论下沉到具体的价值论，太杂了。而且，呃，它还包括各种各样的嗯含糊的取向，各种网络的不同的人群所能接触到的梗，以及所谓的他们每天能刷到的视频，播主，内容类型，以及整个这个互联网经济对他们世界的影响，简直使信息时代的人们，他们的生活是无孔不被入的，无孔不被侵入的。本身孔就挺多的，就被压得喘不动喘不动喘不过气来。然后一些被压碎后的小孔又被填实了。所以说这一困境我表达的很清楚，就是说呃所谓人，呃，为什么我说既定事实和人每时每刻操作的结果呢？哪怕你不能左右一些东西，你哪怕承你你承认它了，你在你以不同的方式在 F1 F2 F3 各层，呃进行具体的现实性的真实施加在你本人身上的呃影响的操作与呃是造成某种既定事实了，那它就会继续成为你下一个呃影响你的呃力量。呃之所以它是一种实在的力量，就级根本是你在这，你活着，你操作，你接触他，你与他有具体的关系，而具体的关系又是组成你个人的部分，你能理解吗？

### 展开：既定事实在信息时代的全面扩张

马克思说的"既定的、从过去承继下来的条件"，主要指物质生产关系、经济基础。北原慢热将其扩展到信息时代的全面渗透：

1. **思想认识层面**：接触到的本体论、价值论、方法论，不管认不认同，只要接触了、思考了，就进入了既定事实。
2. **信息环境层面**：刷到的视频、关注的播主、看到的梗、算法推荐的内容类型——这些不是外在的"信息"，是每天在操作的东西，沉积为认知结构、偏好、注意力模式。
3. **互联网经济层面**：注意力经济、算法系统、内容生态，不是个人选的，但每天都在和它发生具体的操作关系。

### "小孔被填实"的比喻

人本来有很多"孔"：可能性、开放性、未被规定的空间、可以自由生长的地方。但信息时代的海量信息、算法推荐、无孔不入的内容，把这些孔一个一个压碎、填实。人变得越来越密、越来越实，但也越来越喘不过气——因为没有空隙了，没有可以呼吸、可以反思、可以明性闪现的空间了。

### 为什么这些是"实在的力量"

核心机制：**你活着，你操作，你接触它，你与它有具体的关系，而具体的关系又是组成你个人的部分。**

信息不是外在的、中立的"数据"，只要和它发生了操作关系（看了、点了、停留了、思考了、被影响了），它就沉积为你的一部分，变成你的既定事实，然后继续成为下一刻影响你的力量。

这是一个递归的正反馈闭环：
- 浏览信息 → 操作
- 沉积为既定事实（偏好、认知、注意力模式）
- 算法根据既定事实推荐更多类似内容
- 继续浏览 → 新的操作 → 新的既定事实
- 闭环越来越紧，孔越来越少

这就是信息时代的反自指——**自己的操作（点击、浏览、停留）沉积为算法画像和认知惯性，反过来支配看到什么、想什么、感受什么。**

### F1 F2 F3各层的具体表现

- **F1（在感）**：信息直接作用于感受、情绪、注意力。刷到的内容直接塑造在感——焦虑、愤怒、愉悦、麻木，这些不是"自己"的，是信息操作沉积出来的。
- **F2（感-应-操作）**：对信息做出反应，形成操作习惯——刷短视频的节奏、看长文的耐心、对不同观点的反应模式。这些习惯沉积为惯性。
- **F3（明性）**：在这个时代，明性的特殊重要性在于——能不能觉察到"我的在感和操作正在被信息环境塑造"这个事实本身。明性不是拒绝信息，是在信息洪流里留一个孔、留一个空隙，让自己有呼吸和反思的空间。

### 对本质递归公式的完善

在信息时代，既定事实(t)的更新速度极快——因为信息操作的沉积几乎是即时的。今天刷了三个小时短视频，明天的既定事实就已经变了。本质(t) = f(既定事实(t), 操作(t))这个公式，在信息时代运转得比任何时代都快。

承认这个机制本身，就是明性的开始。因为只有先承认"这些信息正在组成我"，才有可能在某个瞬间跳出来，问一句：这真的是我想要的吗？

## 马克思原文对照：《路易·波拿巴的雾月十八日》

### 马克思原文

> 人们自己创造自己的历史，但是他们并不是随心所欲地创造，并不是在他们自己选定的条件下创造，而是在直接碰到的、既定的、从过去承继下来的条件下创造。一切已死的先辈们的传统，像梦魇一样纠缠着活人的头脑。当人们好像刚好在忙于改造自己和周围的事物并创造前所未有的事物时，恰好在这种革命危机时代，他们战战兢兢地请出亡灵来为自己效劳，借用它们的名字、战斗口号和衣服，以便穿着这种久受崇敬的服装，用这种借来的语言，演出世界历史的新的一幕。

### 与生命论"既定事实"的对照

| | 马克思 | 生命论（北原慢热） |
|---|---|---|
| 用词 | 直接碰到的、既定的、从过去承继下来的条件 | 既定事实 |
| 范围 | 物质生产条件、社会关系、历史传统 | 扩展为两层：本人过去操作的沉积 + 非本人所能左右的人与物的操作史 |
| 层面 | 历史层面（宏大叙事） | 下沉到个体存在论（单个人的本质生成） |
| 信息时代 | 未涉及 | 信息、算法、网络文化经由现实操作沉积为既定事实 |
| 模型 | 定性描述 | 递归公式：本质(t) = f(既定事实(t), 操作(t)) |

**共通**：都反对唯心（人不能随心所欲创造），都反对庸俗决定论（是人自身在创造），核心结构都是"能动的活动被先行给定的东西约束"。

**生命论的扩展**：将"条件"拆分为两层，下沉到个体存在论，纳入信息时代的全面渗透，给出递归模型。

## 命题四：本体论的可改变性 vs 历史现实的被锁死

### 北原慢热原话（一字未改）

> 而且我认为这样的方式很有必要。而且我突然意识到，我刚才之所以写刚才那个你认为也很好的话，还是有些犹豫的。因为我所谈及的所谓既定事实，二者之一是人无法改变的，他人与实在事物之间的操作作用的结果总和。但是这也无法左右，我想究其根本呢。到底是所想表达一个事情，就是如果说个人能轻易的改变其所在的国家文明，乃至于整个世界，那么那么我可以讲革命都没有必要了，大家都互相的施展魔法就可以了，开个玩笑。但是确实是这样，就是我的理论是一环套一环的，所谓人无法左右，当然既包括惯性锁子，又包括怎样呢？它又包括你自身对自己的呃奴化，但是呢但是呢就是我所谈及的，它并不是说定义的扭曲。就是我明明已经既说了既定事实已包括人自己操作的沉积，又包括既定事实既定事实的另外一部分，及非个人所能左右的既定既定的沉淀的结果。总而言之这个这些既定事实呃实际上是都可以被人此刻的操作所影响的。如果影响使那些事物发生了质变，那实际上就是发生了改变。其人其其实每个个人，他是都是有改变世界的潜力的，但是但是啊我为什么还是要用所谓至少要有相当一部分是人无法左右的呢？这就是我要为自己辩解的，就是在共产主义社会之前，其实不说百分百，绝大多数人是被惯性锁的死的不能再死的，在思想上的明性也是呃就几乎绝技的，呃当然不排除相当一部分，呃有觉悟的呃年轻人，有觉悟的和知识分子，有觉悟的呃实际的工呃呃那个呃各行各业的具体的呃人，但是啊但是，呃如果说他们是呃不不被其环境所压迫，甚至是呃挤涩的，是不被呃以某种方式逐渐驱离的话。那么共产主义社会其实并不需要生命论，它自己更会到来。所以说我大概赘述了一下，我一些东西吧。

### 展开：两层区分

这一命题澄清了一个容易被误解的关键区分：**"无法左右"不是本体论上的绝对判断，是历史现实层面的诚实判断。**

#### 本体论层面：一切既定事实都可被操作影响

不管是本人过去操作的沉积，还是非本人所能左右的人与物的操作史，只要此刻的操作使它发生了质变，那就是改变了。每个人都有改变世界的潜力——这不是空话，是操作论的必然推论：因为世界本身就是操作沉积出来的，操作当然可以改变操作的沉积。

#### 历史现实层面（共产主义社会之前）：绝大多数人被惯性锁死

不是他们本体论上不能改变世界，是反自指的沉积太厚，他们的明性被压制了，他们的操作被惯性支配了，他们甚至不知道自己可以改变。

"人无法左右"包括：
1. **惯性锁子**：过去操作沉积的惯性，支配当下的操作；
2. **自身对自己的奴化**：反自指的内化，把压迫者的逻辑当成自己的逻辑。

#### 为什么革命是必要的

如果每个人都能轻易改变国家、文明、世界，那革命确实没必要了，大家互相施展魔法就行了——但这不是现实。现实是绝大多数人被锁死了，明性几乎绝迹。

所以革命的必要性不在于人本质上不能改变世界，而在于：**反自指的惯性太厚，大多数人的明性被压制，需要革命来打破惯性，让明性得以展开。**

#### 与毛泽东先锋队理论的对接

- 毛泽东："人民群众是历史的创造者"——本体论层面，人民群众有改变世界的潜力；
- 毛泽东：需要先锋队、党来启发群众觉悟——历史现实层面，群众觉悟被压制，需要有人来启发；
- 生命论：明性在共产主义之前是稀缺的，需要被启发、被保护、被组织起来。如果环境不压迫、不挤涩、不驱离有觉悟的人，那共产主义不需要生命论，它自己就会到来——但现实不是这样。

#### 这不是矛盾，是理论的诚实

- 不承认本体论的可改变性 → 滑入庸俗唯物主义（人被环境决定，无能为力）；
- 不承认历史现实的被锁死 → 滑入唯心主义（人人都能轻易改变世界，革命没必要）；
- 生命论同时承认这两层 → 既不是决定论，也不是唯意志论，是**操作论的历史唯物主义**。

## 可引用的凝练表述

> 人的本质不是先在的实体，而是状语修饰着的动词的总和——即在具体历史条件下、以具体方式持续进行的全部操作活动。
>
> 更精确地说：一个人的本质是既定事实与每时每刻操作二者间的作用结果。既定事实包括本人过去操作的沉积，以及一切非本人所能左右的人与物的操作史。本质不是固定的，是每时每刻都在递归生成的——此刻的操作沉积为下一刻的既定事实，下一刻的操作又在新的既定事实中展开。

*本文档收录北原慢热在精读《关于费尔巴哈的提纲》过程中原创提出的四个核心命题。命题一（语言哲学解构）、命题二（存在论建构）将马克思的"人的本质是一切社会关系的总和"进一步操作论化、动态化、递归化；命题三将"既定事实"扩展到信息时代的全面渗透；命题四澄清"无法左右"的两层含义（本体论可改变性 vs 历史现实被锁死），论证革命的必要性。附马克思《雾月十八日》原文对照。这是生命论（明本论）在人的存在论层面的核心建构。*
