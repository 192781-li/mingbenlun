# 批注系统使用说明

> 本系统用于在纯文本中记录阅读批注，格式固定，未来可直接解析为网页电子书的高亮、波浪线、旁注。

## 标注语法

| 语法 | 含义 | 网页渲染效果 |
|------|------|-------------|
| `【金】文字【/金】` | 金句，极重要 | 红色波浪下划线 |
| `【重】文字【/重】` | 重要段落 | 黄色高亮 |
| `【核】文字【/核】` | 核心概念 | 加粗+变色 |
| `【旁】批注【/旁】` | 旁注/读后感 | 右侧边栏批注 |
| `【划】文字【/划】` | 划线标记 | 蓝色下划线 |

## 使用方式

1. 原文照抄，在需要标注的文字前后加标签
2. 旁注写在段落末尾或单独成行
3. 每个批注文件头部注明：文本来源、批注人、批注时间
4. 文件命名：`作者_作品名_批注.md`

## 示例

见 `王计兵_低处飞行_批注.md`

## 未来迁移

建网页阅读器时，用正则解析以上标签：
- `【金】(.*?)【/金】` → `<span class="gold-quote">$1</span>`
- `【重】(.*?)【/重】` → `<span class="highlight">$1</span>`
- `【核】(.*?)【/核】` → `<span class="core-concept">$1</span>`
- `【旁】(.*?)【/旁】` → `<aside class="margin-note">$1</aside>`
- `【划】(.*?)【/划】` → `<span class="underline">$1</span>`
