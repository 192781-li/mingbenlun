## 通法（四科通用）

- **F1先行**：判板块→定问法→找答案来源
- **F2填充**：阅读回原文定位；作文审题搭论点
- **F3后置**：阅读查原文依据；作文查论点回扣
- **述析评对接阅读**：述=概括提取、析=手法原因分析、评=探究评价

## 二、多文本阅读

### 选择题四陷阱（选项回原文逐字比对）
1. **偷换概念**：A换成B
2. **以偏概全**：部分→全部
3. **强加因果**：原文没因果硬加
4. **无中生有/曲解**：没说编造、意思说反

### 简答题骨架（述为主）
- 概括：分点提取→整合归类→只述不评
- 原因：直接原因（材料）+根本原因（推断）
- 比较：相同点+不同点分点列

## 三、文言文

### 实词推断四法
语境推断 / 课内迁移 / 语法分析（主谓宾定词性）/ 对称推断（对仗位置近义反义）

### 虚词重点（18个高频）
**而**：并列/承接/转折/修饰
**以**：用/凭/因为/来
**之**：代词/的/取独/动词"到"
其余：其、于、为、者、也、焉、何、则、乃、且、若、所、因、与

### 断句三看
看语法（主谓宾完整即断）/ 看标志（夫盖前断、也矣焉耳后断）/ 看对称（排比对仗按结构断）

### 翻译五字诀（直译为主）
**留**（人名地名官名年号）/ **删**（无实义虚词）/ **换**（单音换双音、古今异义）/ **调**（倒装调正常语序）/ **补**（省略成分）
踩分点：关键实词+特殊句式

## 四、古诗鉴赏

### 读诗四步
看标题作者注释 → 找意象（组合成意境）→ 抓情感词尾联 → 辨手法

### 高频手法清单

| 类别 | 手法 |
|------|------|
| 抒情 | 直抒胸臆、借景抒情、情景交融、托物言志、用典、借古讽今 |
| 描写 | 动静、虚实、远近高低、视听、白描、细节、对比、衬托 |
| 修辞 | 比喻、拟人、夸张、对偶、借代、双关、互文 |
| 表现 | 象征、渲染、烘托、欲扬先抑、以小见大、联想想象 |

### 情感题公式（析为主）
**手法 + 诗句分析（景/事）+ 意境效果 + 情感**

### 六类常见情感
- 山水田园：热爱自然、闲适、归隐
- 边塞征战：建功立业、思乡厌战、悲壮
- 咏史怀古：借古讽今、昔盛今衰、怀才不遇
- 送别思乡：不舍、思亲、羁旅愁
- 咏物言志：高洁品格、志向、不遇
- 忧国忧民：家国情怀、感时伤世

### 炼字题骨架
字义→句意（画面）→手法→情感效果

## 五、文学类文本

### 散文：找线索→分层→悟主旨

| 题型 | 骨架 |
|------|------|
| 词句含义 | 表层义+深层义（主旨）+情感 |
| 句段作用 | 内容（写什么+情）+结构（开头/中间/结尾）+读者效果 |
| 形象物象 | 特点分点+象征意义+对主旨作用 |
| 手法赏析 | 手法+文本分析+效果+情感 |
| 主旨探究 | 概括内容+情感倾向+升华 |

### 小说：抓人物、情节、环境、主题四要素

| 题型 | 骨架 |
|------|------|
| 人物形象 | 性格分点（身份+品质）+原文依据 |
| 塑造手法 | 正面（肖像/语言/动作/心理/神态）+侧面（他人/环境） |
| 情节作用 | 对人物+对情节（铺垫伏笔转折）+对主题 |
| 环境作用 | 交代背景+渲染气氛+烘托心情+推动情节+暗示主题 |
| 标题作用 | 线索+概括内容+双关象征+揭示主题+吸引读者 |
| 叙事技巧 | 视角、顺序（顺倒插）、详略、伏笔照应、出人意料 |

## 七、语言文字运用

| 题型 | 方法 |
|------|------|
| 病句 | 六查：语序/搭配/残缺赘余/结构混乱/表意不明/不合逻辑 |
| 补写 | 看逻辑（因果转折并列总分）+抓照应词+主语一致 |

| 词语成语 | 辨语义轻重/对象/色彩/搭配 |

## 九、大作文（50分）

### 审题立意四步（决定档次）
圈关键词 → 抓核心话题 → 挖本质 → 立中心论点（准、深、新）

### 议论文结构（对接论述题）
**亮观点 → 分论点1+论据+分析 → 分论点2+论据+分析 → 分论点3+论据+分析 → 回扣升华**

### 三种分论点展开角度
1. 是什么—为什么—怎么办（递进）
2. 个人—社会—国家时代（范围递进）
3. 正反对照

### 论据使用
- 事实论据（事例/事件/现象）+道理论据（名言/原理）
- **叙例要简、议例要详**（分析论据如何证明论点）
- 高频主题：家国情怀、科技创新、文化传承、青年担当、奋斗、传统与现代

### 提分五要点
- 标题亮观点 / 开头快引材料亮论点
- 分论点置于段首，论据后必有分析
- 结尾回扣+升华到时代青年
- 5-7段、字迹工整
