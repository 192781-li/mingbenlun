## 通法（三科通用）

- **F1先行**：拿到题先判题型写骨架
- **F2填充**：原理+材料分析，每点先写原理再扣材料
- **F3后置**：审查原理有没有用错模块、材料有没有对应
- **述析评**：述=概括材料定性，析=分维度展开，评=升华总结
- **政治答案标准句式**：原理（课本术语）→ 材料分析（扣材料）→ 意义/结果

## 一、经济生活

### 原因题：供需政价四维度

| 维度 | 找什么 | 对应原理 |
|------|--------|---------|
| 供 | 企业增多/技术进步/生产率提高 | 生产决定消费、社会劳动生产率提高 |
| 需 | 需求扩大/场景增多/消费升级/收入提高 | 消费反作用于生产、收入是消费基础 |
| 政 | 政策支持/规划/财政补贴/宏观调控 | 科学的宏观调控、财政政策、产业政策 |
| 价 | 价格下降/成本降低/性价比提高 | 价值决定价格、供求影响价格 |

> 材料给了哪个写哪个，不硬凑。

### 影响/意义题：四层次推导

```
具体做法 → 对企业 → 对产业 → 对经济 → 对民生/国家（升华）
```

- 对企业：降成本/提创新/增竞争力
- 对产业：产业升级/产业链完善/培育新产业
- 对经济：新动能/优化结构/高质量发展/新质生产力
- 对民生：增就业/满足需求/提升国际竞争力

### 措施题：三主体

| 主体 | 做法 |
|------|------|
| 国家/政府 | 宏观调控、政策支持、完善市场秩序、财政补贴 |
| 企业 | 创新、转型升级、诚信经营、提高竞争力 |
| 个人/消费者 | 正确消费观、提高素质、参与监督 |

### 必背原理12条

1. **价值规律**：价值决定价格，供求影响价格
2. **生产与消费**：生产决定消费，消费反作用于生产
3. **企业经营**：正确经营战略、自主创新、诚信经营
4. **宏观调控**：经济手段（财政/货币）、法律手段、行政手段
5. **新发展理念**：创新、协调、绿色、开放、共享
6. **高质量发展**：转变发展方式、优化经济结构、转换增长动力
7. **新质生产力**：科技创新驱动、高科技高效能高质量、符合新发展理念
8. **创新驱动**：创新是第一动力
9. **供给侧改革**：去产能去库存去杠杆降成本补短板
10. **现代化经济体系**：产业/市场/收入分配/城乡区域/绿色/开放体系
11. **实体经济**：一国经济立身之本、财富之源
12. **产业转型升级**：低端→高端、制造→智造、要素驱动→创新驱动

## 二、政治生活

### 主体分析法：7大主体术语

| 主体 | 核心术语 |
|------|---------|
| **党** | 最高政治领导力量、以人民为中心、科学/民主/依法执政、党的建设、先锋模范 |
| **政府** | 人民的政府、五大职能（政治/经济/文化/社会/生态）、为人民服务、对人民负责、依法行政、接受监督、服务型政府 |
| **人大** | 国家权力机关、立法权/决定权/任免权/监督权、民主集中制 |
| **人大代表** | 审议/表决/提案/质询权、密切联系群众、对人民负责 |
| **公民** | 选举权/政治自由/监督权、法律面前一律平等、权利义务统一、个人利益国家利益结合、有序参与 |
| **政协** | 爱国统一战线组织、政治协商/民主监督/参政议政 |
| **国际社会** | 主权国家、国家利益是国际关系决定性因素、和平与发展是时代主题、独立自主和平外交政策、人类命运共同体 |

### 答题句式

```
主体 + 做了什么 + 体现什么原理 + 有什么意义
```

例：政府出台XX政策，履行经济建设职能，有利于促进经济高质量发展。

## 三、文化生活

### 必背原理8条

1. **文化的社会作用**：文化作为精神力量，能在认识改造世界中转化为物质力量
2. **文化与经济政治**：相互影响、相互交融，文化反作用于经济政治
3. **文化对人的影响**：来源（文化环境/文化活动）、特点（潜移默化/深远持久）、优秀文化塑造人生（丰富精神世界/增强精神力量/促进全面发展）
4. **文化传承**：多样性（民族节日/文化遗产）、传播（商业贸易/人口迁徙/教育/大众传媒）、继承（取其精华去其糟粕/推陈出新革故鼎新）
5. **文化创新**：根本途径（社会实践）、基本途径（继承传统推陈出新/面向世界博采众长）、主体（人民群众）
6. **中华文化**：源远流长（汉字/史书典籍）、博大精深（独特性/区域性/民族性）、包容性（求同存异/兼收并蓄）
7. **中华民族精神**：以爱国主义为核心，伟大创造/奋斗/团结/梦想精神
8. **中国特色社会主义文化**：马克思主义指导、文化自信、建设社会主义文化强国

## 四、生活与哲学

### 四大模块原理速查

| 模块 | 核心原理 |
|------|---------|
| **唯物论** | 物质决定意识（一切从实际出发）、意识能动作用、规律客观性普遍性（尊重规律+发挥主观能动性） |
| **认识论** | 实践是认识的基础（来源/动力/检验标准/目的）、真理客观性/具体性/条件性、认识反复性/无限性/上升性 |
| **辩证法** | 联系观（普遍/客观/多样/整体部分/系统优化）、发展观（普遍/实质/前进曲折/量变质变）、矛盾观（对立统一/普遍/特殊/普特关系/主次矛盾/矛盾主次方面/两点论重点论）、辩证否定观（扬弃/创新） |
| **历史唯物主义** | 社会存在与社会意识、社会基本矛盾（生产力生产关系/经济基础上层建筑）、人民群众是历史创造者（群众观点/群众路线）、价值观导向作用、价值判断与选择、人生价值创造与实现 |

### 答题格式

```
原理名称 + 原理内容（一句话） + 方法论 + 材料分析
```

例：物质决定意识，要求一切从实际出发。材料中根据XX实际制定XX政策，体现了一切从实际出发。

> 关键：题干限定哪个模块就只用哪个模块的原理。说"运用辩证法"就不能用唯物论。

## 五、政治与历史差异速记

| | 历史 | 政治 |
|--|------|------|
| 答案格式 | 史实+评价，叙述化 | 原理+材料分析，格式化 |
