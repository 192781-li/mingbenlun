# 高考文科三科背诵计划
> 背诵不是死记，是为答题体系提供弹药。背的每个知识点都要知道"在述析评里用在哪"。
> 维护者：S02高考文科分站 | 创建：2026-09-10

---

## 一、背诵原则

### 1. 先背框架，再背细节
- 历史：先背朝代顺序+每个朝代的阶段特征（政经文三句话），再背具体事件
- 政治：先背模块结构（经济/政治/文化/哲学各有什么原理），再背具体原理内容
- 地理：先背要素框架（地气水土生+市交政劳技），再背具体原理

### 2. 背了就要用
- 每背完一个知识点，立刻想："这个知识点在什么题型里用？怎么用？"
- 例：背了"洋务运动"→想：原因题里怎么用？影响题里怎么用？比较题里怎么用？
- 背了不用=白背，!-沉积压垮νF₂

### 3. 默写优于阅读
- 合上书自己写，写完对照补漏。一个知识点默写三遍胜过读十遍。
- 每天花10分钟默写前一天背的东西。

### 4. 少量多次
- 每天背30-40分钟，分2-3次（早15分钟+晚15分钟），不要一次背2小时
- 艾宾浩斯复习：当天→第2天→第4天→第7天→第15天

## 二、历史背诵计划（优先级最高）

### 第一阶段：中国古代史阶段特征（2周）

每个时期背**三句话**（政治/经济/文化），这是高考答案的核心得分点。

| 时期 | 政治 | 经济 | 文化 |
|------|------|------|------|
| 先秦 | 诸侯割据→变法→中央集权萌芽 | 铁犁牛耕→井田瓦解→土地私有 | 百家争鸣 |
| 秦汉 | 大一统建立→中央集权制度确立 | 小农经济确立→盐铁官营 | 焚书坑儒→独尊儒术 |
| 魏晋 | 分裂动荡→士族门阀→民族交融 | 北方经济恢复→江南开发 | 佛道盛行→玄学→文化多元 |
| 隋唐 | 三省六部→科举制→盛世 | 均田制→租庸调→两税法→商品经济 | 唐诗繁荣→三教并行 |
| 宋元 | 中央集权强化→重文轻武→行省制 | 商品经济繁荣→交子→海外贸易 | 理学→宋词元曲→科技高峰 |
| 明清 | 君主专制顶峰→内阁→军机处 | 资本主义萌芽→海禁→闭关 | 早期启蒙思想→小说→西学东渐 |

**背法**：每天一个时期，先自己默写三句话，再对照补漏。一周过完，第二周复习+深化。

### 第二阶段：中国近现代史（2周）

| 时期 | 核心线索 |
|------|---------|
| 晚清(1840-1912) | 侵略史（鸦片战争/二鸦/甲午/八国）+ 抗争史（太平天国/洋务/戊戌/辛亥）+ 经济结构变动 |
| 民国(1912-1949) | 北洋军阀→国民革命→国共十年对峙→抗日战争→解放战争；民族资本主义曲折发展 |
| 新中国(1949-今) | 过渡时期→全面建设→文革→改革开放→新时代；经济体制演变 |

### 第三阶段：世界史（2周）

| 时期 | 核心线索 |
|------|---------|
| 古代 | 古希腊民主→罗马法 |
| 中世纪 | 封建制度→基督教→城市兴起 |
| 近代 | 文艺复兴→宗教改革→启蒙运动→新航路→殖民扩张→工业革命→资产阶级革命 |
| 现代 | 一战→十月革命→大萧条→二战→冷战→多极化→全球化 |

### 历史必背核心概念（随时穿插）

```
分封制/宗法制/郡县制/三省六部/科举制/行省制/内阁/军机处
小农经济/重农抑商/海禁/闭关/资本主义萌芽
百家争鸣/独尊儒术/理学/心学/经世致用
半殖民地半封建/自然经济解体/洋务运动/民族资本主义
维新变法/辛亥革命/新文化运动/五四运动
工农武装割据/抗日民族统一战线/解放战争
三大改造/人民公社/改革开放/社会主义市场经济
```

## 三、政治背诵计划（第二优先级）

### 第一阶段：经济生活核心原理（1周）

每天背2-3个原理，每个原理背"名称+一句话内容+什么时候用"：

```
第1天：价值规律（价值决定价格，供求影响价格）+ 生产与消费关系
第2天：企业经营成功因素 + 就业与劳动者权益
第3天：按劳分配为主体多种分配方式并存 + 效率与公平
第4天：财政的作用 + 税收
第5天：市场调节 + 宏观调控（经济/法律/行政手段）
第6天：新发展理念（创新协调绿色开放共享）+ 高质量发展
第7天：现代化经济体系 + 新质生产力 + 创新驱动发展战略
```

### 第二阶段：政治生活主体术语（1周）

按主体背，每个主体背"地位+职权/职能+答题术语"：

```
第1天：中国共产党（领导核心/执政方式/执政理念/党的建设）
第2天：政府（性质/职能/宗旨/原则/依法行政/监督）
第3天：人大+人大代表（性质/职权/权利义务）
第4天：公民（权利/义务/参与原则/有序参与）
第5天：人民政协（性质/职能）+ 基层群众自治
第6天：国际社会（主权国家/国家利益/时代主题/外交政策）
第7天：复习全部主体，默写主体→术语对照表
```

### 第三阶段：文化+哲学（2周）

文化生活8条高频原理（见07文档），哲学四大模块原理（唯物论/认识论/辩证法/历史唯物主义）。

哲学重点背：
- 唯物论：物质与意识、规律客观性、一切从实际出发
- 认识论：实践与认识、真理、认识的反复性无限性
- 辩证法：联系观（5个）、发展观（4个）、矛盾观（7个）、辩证否定
- 历史唯物主义：社会存在与社会意识、社会基本矛盾、人民群众、价值观、人生价值

## 四、地理背诵计划（第三优先级，最公式化）

### 第一阶段：自然地理原理（1周）

```
第1天：地球运动（自转/公转/晨昏线/正午太阳高度）
第2天：大气受热过程 + 热力环流 + 气压带风带
第3天：季风 + 天气系统（锋面/气旋/反气旋）+ 气候类型判断
第4天：水循环 + 洋流分布及影响
第5天：内力作用（地壳运动/岩浆/变质）+ 外力作用（风化/侵蚀/搬运/沉积）
第6天：自然带 + 地域分异规律（纬度/经度/垂直/非地带性）
第7天：复习+默写气候类型分布图+洋流模式图
```

### 第二阶段：人文地理原理（1周）

```
第1天：人口增长模式 + 人口迁移 + 人口容量
第2天：城市功能分区 + 城市等级 + 城市化
第3天：农业区位 + 农业地域类型（5种）
第4天：工业区位 + 工业导向型（5种）+ 工业集聚与分散
第5天：交通区位 + 交通方式选择 + 交通对区域影响
第6天：可持续发展 + 环境问题 + 协调人地关系
第7天：复习+默写区位分析万能模板（地气水土生+市交政劳技）
```

### 地理必背模板（随时穿插）

```
特征描述模板（地形/气候/河流/分布）
原因分析模板（自然+人为）
影响评价模板（有利+不利，分自然/经济/社会）
措施建议模板（工程+生物+管理+技术）
比较题模板（相同点+不同点分维度）
```

## 五、每日背诵时间表（建议）

```
早上（15分钟）：默写昨天背的内容（不看书）
晚上（20分钟）：背新内容 + 对照补漏
周末（30分钟）：复习本周所有内容，做1-2道题检验背诵效果
```

**背诵和做题的比例**：前4周背:做=7:3，框架建起来后调整为5:5，最后冲刺3:7。

---

## 六、背诵质量检查

每周末自问：
1. 这周背的东西，能合书写出来吗？
2. 每个知识点，能说出"在什么题型里用"吗？
3. 做过的题里，有没有用到这周背的东西？用对了吗？
4. 有没有背了但从来没用过的？（有就标记，可能是低频考点，优先级降低）
