## 一、这套体系是什么
不是教辅书的答题模板，是用生命论哲学方法论重新发明的一套文科答题系统。核心是三个东西：
1. **F1/F2/F3三层答题法** —— 拿到题先识别题型写骨架（F1），再填充史实完成现象→本质→观点跳跃（F2），最后后置审查（F3）。F1永远先行，F3永远后置，F3不阻塞F1。
2. **述析评三元母版** —— 所有文科主观题的底层结构。述=登场（定性），析=展开（分维度分析），评=完结（升华总结）。从七大题型→三大母版→述析评，是不断收敛的结果。
3. **操作论映射** —— 政治=操作权，经济=操作支撑，文化=操作意义，外部=操作外界。政经文外不是四个死维度，是操作的四个面相。

## 二、核心铁则
| 铁则 | 内容 |
|------|------|
| F1先行 | 拿到题第一件事：圈动词→判题型→写骨架，不许先想内容 |
| F3后置 | 写完才审查，不许边写边质疑自己 |
| 材料完整 | 训练用题必须材料完整、答案可靠，不练半截题 |
| 小本质递归 | 从一道具体题挖到根因，再用根因统摄整个学科，不背大词拼盘 |
| 闭环不许短路 | 做完题必须对答案、必须修正、必须总结，不能"我觉得会了"就跳过 |
| 高考语言 | 内功（操作论）想清楚，外功（高考术语）写出来，阅卷老师看的是外功 |
