# 地理答题体系与通法迁移
> 从历史述析评通法迁移到高考地理（自然地理/人文地理/区域地理）
> 维护者：S02高考文科分站 | 创建：2026-09-09

---

## 一、通法迁移：地理是文科里最"公式化"的

### 核心结论：骨架通用，地理的维度最固定

| 方法论 | 历史 | 政治 | 地理 |
|--------|------|------|------|
| F1/F2/F3 | ✅ | ✅ | ✅ |
| 述析评三元母版 | ✅ | ✅ | ✅ |
| 操作还原读材料 | ✅ | ✅ | ✅（读图表=读材料） |
| 原因题维度 | 政经文外 | 供需政价 | **地气水土生+市交政劳技** |
| 答案风格 | 叙述化 | 格式化（原理+材料） | **模板化（要素+具体分析）** |

**地理最大的特点**：答案几乎是"公式填空"。背了模板，往材料/图表里填具体内容就行。不像历史需要那么多史实积累，也不像政治需要那么多原理记忆。

## 二、地理答题的"万能公式"

### 2.1 自然地理五要素：地气水土生

任何自然地理问题，从这五个要素找：

| 要素 | 包含内容 | 高频考点 |
|------|---------|---------|
| **地**（地形/地质） | 地形类型、地势起伏、地质构造、地貌、海拔 | 地形对气候/河流/人口的影响；地质作用（内力+外力） |
| **气**（气候） | 气温、降水、光照、风、气候类型、气象灾害 | 气候成因（纬度/大气环流/海陆/地形/洋流）；气候对农业/植被的影响 |
| **水**（水文） | 河流、湖泊、洋流、地下水、水循环 | 河流水文特征（流量/汛期/含沙量/结冰期/流速）；洋流影响 |
| **土**（土壤） | 土壤类型、肥力、厚度、酸碱度 | 土壤对农业的影响；水土流失/荒漠化 |
| **生**（生物/植被） | 植被类型、自然带、生物多样性、生态 | 自然带分布；垂直地带性；生态保护 |

### 2.2 人文地理五要素：市交政劳技

任何人文地理（区位分析）问题，从这五个要素找：

| 要素 | 包含内容 | 高频考点 |
|------|---------|---------|
| **市**（市场） | 市场需求、市场距离、消费能力 | 农业/工业/商业区位的市场条件 |
| **交**（交通） | 交通方式、交通便利度、交通枢纽 | 交通对城市/工业/商业布局的影响 |
| **政**（政策） | 国家政策、地方规划、开发区 | 政策对产业/城市发展的影响 |
| **劳**（劳动力） | 劳动力数量、素质、价格 | 劳动密集型/技术密集型产业区位 |
| **技**（技术） | 科技水平、研发能力、技术创新 | 高新技术产业区位；技术对农业的影响 |

### 2.3 区位分析万能模板

**农业区位**：自然（地气水土生）+ 人文（市交政劳技）+ 历史基础
**工业区位**：自然（土地/水源/原料/能源）+ 人文（市交政劳技）+ 环境因素
**城市区位**：自然（地形/气候/河流）+ 人文（交通/政治/军事/宗教/科技/旅游）
**交通区位**：自然（地形/地质/气候/水文）+ 人文（经济/人口/城市/技术/政策）

## 三、地理五大题型骨架

### 3.1 特征描述题（述为主）

**识别**：描述/简述/概括……的特征/特点/分布

**骨架**：先总述（整体特征），再分述（具体要素），最后特殊点

| 描述对象 | 答题角度 |
|---------|---------|
| 地形特征 | 地形类型（以什么为主）+ 地势起伏（哪高哪低）+ 特殊地貌 |
| 气候特征 | 气温（高低/年较差）+ 降水（多少/季节分配）+ 光照/风 |
| 河流特征 | 水文（流量/汛期/含沙量/结冰期/流速）+ 水系（流向/流域/支流/河网密度） |
| 分布特征 | 空间分布（均匀/不均，哪多哪少）+ 时间变化（季节/年际）+ 沿什么分布 |
| 农业特征 | 地域类型+生产规模+机械化水平+商品率+科技水平 |
| 工业特征 | 工业部门+工业布局+工业结构+技术水平 |

### 3.2 原因分析题（析为主）

**识别**：分析/说明……的原因/成因/为什么

**骨架**：自然原因（地气水土生）+ 人为原因（市交政劳技+人类活动）

**高频原因题模板**：

| 问题 | 答题角度 |
|------|---------|
| 气候成因 | 纬度（太阳辐射）+ 大气环流（气压带风带/季风）+ 海陆位置 + 地形（迎风坡/背风坡/海拔）+ 洋流 |
| 洪涝成因 | 自然（降水集中/地势低平排水不畅/河道弯曲/支流多）+ 人为（植被破坏/围湖造田/占用河道） |
| 荒漠化成因 | 自然（气候干旱/大风/植被稀少/地表疏松）+ 人为（过度放牧/过度开垦/过度樵采/水资源不合理利用） |
| 盐渍化成因 | 自然（蒸发旺盛/地势低洼排水不畅/地下水位高）+ 人为（不合理灌溉） |
| 人口迁移原因 | 推力（迁出地劣势）+ 拉力（迁入地优势）+ 中间阻力 |
| 产业转移原因 | 转出地（成本上升/市场饱和/政策）+ 转入地（劳动力/地价/市场/政策优惠） |

### 3.3 影响/评价题（析+评）

**识别**：分析/评价……的影响/作用/意义/利弊

**骨架**：有利影响 + 不利影响（辩证），分自然/经济/社会维度

| 维度 | 有利 | 不利 |
|------|------|------|
| 自然 | 改善生态/保护生物多样性/调节气候 | 破坏生态/环境污染/资源枯竭 |
| 经济 | 促进经济发展/增加收入/带动相关产业 | 成本增加/产业结构单一 |
| 社会 | 增加就业/改善基础设施/提高生活水平 | 移民/社会矛盾/文化冲击 |

### 3.4 措施/建议题（评→操作）

**识别**：提出……的措施/建议/对策/如何做

**骨架**：针对原因提措施，分维度（工程措施+生物措施+管理措施+技术措施）

| 问题类型 | 措施模板 |
|---------|---------|
| 水土流失 | 工程（打坝淤地/修梯田/修水库）+ 生物（植树种草/退耕还林）+ 管理（调整农业结构/合理放牧） |
| 荒漠化 | 合理利用水资源+利用生物和工程措施构筑防护林+调节农林牧用地+解决农牧区能源问题+控制人口增长 |
| 洪涝 | 上游（植树造林/修水库）+ 中游（退耕还湖/裁弯取直）+ 下游（加固大堤/开挖入海河道） |
| 水资源短缺 | 开源（跨流域调水/修水库/海水淡化/合理开采地下水）+ 节流（节约用水/提高利用率/调整产业结构/防治水污染） |
| 产业升级 | 技术创新+产业结构调整+品牌建设+人才培养+政策支持 |

### 3.5 比较题

**识别**：比较/对比……的异同/差异

**骨架**：相同点（1-2点）+ 不同点（分维度对比：位置/地形/气候/水文/植被/经济/人文）

## 四、自然地理核心原理（必背）

### 4.1 地球运动

- 自转：昼夜更替、地方时、地转偏向力（北右南左）
- 公转：四季更替、五带划分、昼夜长短变化、正午太阳高度变化
- 晨昏线：与赤道交点6点/18点，与纬线切点0点/12点
- 正午太阳高度：H=90°-|纬度差|

### 4.2 大气运动

- 热力环流：热上升冷下沉，水平方向高压流向低压
- 气压带风带：7压6风，随季节移动（夏季北移冬季南移）
- 季风：东亚（海陆热力性质差异）、南亚（气压带风带季节移动+海陆热力差异）
- 天气系统：冷锋（冷气团主动，锋后雨）、暖锋（暖气团主动，锋前雨）、气旋（低压，上升气流，阴雨）、反气旋（高压，下沉气流，晴朗）
- 气候类型：以温定带、以水定型

### 4.3 水循环与洋流

- 水循环：蒸发→水汽输送→降水→径流（地表/地下）
- 洋流分布：中低纬北顺南逆，中高纬北逆南无，西风漂流
- 洋流影响：气候（暖流增温增湿，寒流降温减湿）、渔场（寒暖流交汇/上升流）、航行、污染

### 4.4 地质作用

- 内力作用：地壳运动（褶皱/断层）、岩浆活动、变质作用
- 外力作用：风化、侵蚀（流水/风力/冰川/海浪）、搬运、沉积
- 常见地貌：流水侵蚀（V型谷/瀑布/喀斯特）、流水沉积（冲积扇/三角洲/冲积平原）、风力侵蚀（风蚀蘑菇/雅丹）、风力沉积（沙丘/黄土高原）、冰川侵蚀（U型谷/角峰/峡湾）

### 4.5 自然带与地域分异

- 纬度地带性（从赤道到两极）：热量为基础
- 经度地带性（从沿海到内陆）：水分为基础
- 垂直地带性（山地垂直）：水热随海拔变化
- 非地带性：地形/洋流/海陆分布导致

## 五、人文地理核心原理（必背）

### 5.1 人口

- 人口增长模式：原始型（高高低）→传统型（高低高）→现代型（低低低）
- 人口问题：发展中国家（增长快/就业压力/资源环境）、发达国家（老龄化/劳动力不足/社会保障）
- 人口容量：环境承载力（最大）、人口合理容量（最适宜）

### 5.2 城市

- 城市功能分区：商业区（市中心/交通便利）、住宅区（最广泛）、工业区（城市边缘/交通便利）
- 城市等级：等级越高，数量越少，服务范围越大，服务种类越多
- 城市化：标志（城市人口比重上升）、阶段（初期/加速/后期）、问题（交通拥堵/环境污染/住房紧张/就业困难）

### 5.3 农业

- 农业地域类型：季风水田农业（亚洲季风区，小农经营/单产高/商品率低/机械化低）、商品谷物农业（美国/加拿大，规模大/机械化高/商品率高）、大牧场放牧业（阿根廷/澳大利亚，规模大/专业化）、乳畜业（西欧/北美五大湖，市场导向/产品易变质）、混合农业（澳大利亚墨累达令，良性生态/市场灵活）
- 农业区位变化：市场需求变化最关键，交通和保鲜技术扩大市场范围

### 5.4 工业

- 工业导向型：原料导向（制糖/水产加工）、市场导向（啤酒/家具/印刷）、动力导向（炼铝/冶金）、劳动力导向（服装/电子装配）、技术导向（集成电路/航天/生物）
- 工业集聚：共用基础设施/加强协作/降低成本/获得规模效益
- 工业分散：寻找最优区位/降低成本/减少污染

### 5.5 交通

- 交通方式选择：运量/运速/运费/灵活性/连续性
- 交通线区位：自然（地形/地质/气候/水文）+ 人文（经济/人口/城市/技术/政策）
- 交通对区域影响：促进经济发展/加强区域联系/带动沿线发展/可能破坏生态

## 六、地理图表阅读方法

地理题材料大量是图表，读图表=读材料，用操作还原法：

| 图表类型 | 怎么读 |
|---------|--------|
| 等高线图 | 看数值（海拔）、疏密（坡度）、弯曲（山脊/山谷）、闭合（山顶/盆地）、陡崖 |
| 等温线图 | 看数值（气温）、疏密（温差）、弯曲（海陆/地形/洋流影响）、闭合（高温/低温中心） |
| 等降水量线 | 看数值、疏密、走向、闭合 |
| 气候资料图 | 气温曲线+降水柱状，先判断南北半球，再以温定带以水定型 |
| 区域地图 | 先定位（经纬度/海陆轮廓/地标），再看地形/气候/河流/城市/交通 |
| 统计图表 | 看标题/坐标/图例/数据变化趋势/极值/对比 |

**定位是地理题的第一步**。经纬度定位→判断区域→调用该区域的地气水土生知识→结合题目作答。

## 七、三科对比总结

| 维度 | 历史 | 政治 | 地理 |
|------|------|------|------|
| 核心能力 | 时空观念+史实+评价 | 原理+材料分析 | 定位+图表+要素分析 |
| 原因题维度 | 政经文外 | 供需政价 | 地气水土生+市交政劳技 |
| 答案格式 | 史实+评价 | 原理+材料 | 要素+具体分析 |
| 背诵量 | 大（时间轴+史实） | 中（原理+术语） | 小（模板+原理） |
| 最易得分 | 评析题（述析评） | 经济原因题（供需政价） | 原因/措施题（模板化） |
| 最易丢分 | 史实笔误/时空错位 | 原理用错模块/不扣材料 | 定位错误/要素遗漏/图表读错 |

## 八、训练建议

1. **先背模板**：地气水土生+市交政劳技，区位分析万能模板，原因题/措施题高频模板
2. **练定位**：每天看地图，记住重要经纬度（北京116°E/40°N，伦敦0°/51°N， etc.）
3. **练图表**：等高线/等温线/气候图/统计图，每种练5-10道
4. **精做真题**：北京卷地理题，每道题完成"定位→判题型→套模板→填内容→审查"闭环
5. **错题归因**：是定位错了？模板漏了要素？还是图表读错了？
