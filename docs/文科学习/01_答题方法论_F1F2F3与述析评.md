## 一、F1/F2/F3三层答题法
### 核心逻辑
答题不是"想好了再写"，是三层操作依次执行：
| 层级 | 名称 | 干什么 | 什么时候做 |
|------|------|--------|-----------|
| F1 | 题感 | 圈动词→判题型→写骨架 | 拿到题**第一件事**，永远先行 |
| F2 | 分析 | 填充史实，完成现象→本质→观点两个跳跃 | 骨架搭好之后 |
| F3 | 元认知 | 后置审查，检查漏点、史实错误、表述问题 | **写完之后**，永远后置 |
### 铁则
- **F1永远先行**：不许拿到题先想"这道题考什么知识点"，先判题型写骨架
- **F3永远后置**：不许边写边质疑自己"这么写对不对"，写完才审查
- **F3不阻塞F1**：审查发现问题，记下来，下一道题改进，不许倒回去重写导致做不完
### 操作流程
```
拿到题 → F1：圈动词+宾语 → 判题型 → 在草稿纸上写骨架（述析评/政经文外/...）
       → F2：往骨架里填史实（材料提取+课本结合）
       → 写完 → F3：快速审查（史实对不对？得分点踩全没？表述有没有问题？）
       → 下一题
```

## 二、述析评三元母版
### 从七大题型到述析评的收敛
最开始分了七大题型（概括、原因、影响、评析、阐述、论述、比较），后来发现：
- 概括题 = 只述不评
- 原因/影响题 = 只析（分维度展开）
- 评析题 = 述+析+评（最完整）
- 阐述题 = 述+析（按过程/线索展开）
- 论述题 = 述+析+评（亮观点=述，分论点+史实=析，回扣=评）
- 比较题 = 述+析（相同点+不同点）
**所有题型都是述析评的子集或变体。述析评是文科主观题的元结构。**
### 述析评的戏剧四幕理解
| 元素 | 戏剧比喻 | 答题含义 | 操作 |
|------|---------|---------|------|
| 述 | 登场 | 定性：这是什么事/什么现象 | 1句话，从材料提炼本质，不用细节 |
| 析 | 展开 | 分维度分析：政治/经济/文化/外部，或积极/消极 | 主体部分，2-4个要点，每个要点=观点+材料/史实 |
| 评 | 完结 | 升华总结：本质判断/历史地位/经验教训 | 1句话，上升到规律/史观/现实关照 |
### 述析评的操作论深层理解
- **述** = 操作的本质化表达（这个操作是什么性质的操作）
- **析** = 操作的表现（操作在政经文外四个维度上如何展开、如何自反、如何暴露矛盾）
- **评** = 操作的命运总结（这个操作的结构性缺陷是什么，最终走向什么结局）
**答题 = 让历史中那个真实的操作在你的答题卡上再演一遍。述是它登场，析是它展开并自曝矛盾，评是它完结。**

## 三、现象→本质→观点双跳跃
### 所有文科主观题的底层流程
```
材料（现象） →[第一跳]→ 本质（规律/概念/关系） →[第二跳]→ 观点（判断/评价/升华）
```
### 第一跳：现象→本质
- 干什么：从材料的具体事件/数据/表述中，提炼出背后的抽象规律、概念、关系
- 方法：操作还原——谁+做什么+形成什么关系
- 例子：材料说"李经羲为弥补财政不足增加盐价"→本质是"清政府财政危机+专制权力压榨民力"
### 第二跳：本质→观点
- 干什么：在本质分析的基础上，给出判断、评价、升华
- 方法：上升到史观（唯物史观/文明史观/全球史观）或规律（历史必然性/改革的动力/权力的边界）
- 例子：本质是"新旧机构权力冲突"→观点是"封建王朝自上而下的改良缺乏根本动力，反因动荡加速崩溃"
### 常见误区
- **只跳第一跳不跳第二跳**：分析了半天，但没有总结升华，答案停留在"是什么"，没有"所以呢"
- **跳过第一跳直接第二跳**：上来就喊大道理（"这体现了历史必然性"），但没有从材料到本质的分析过程，观点是空的
- **两跳都不跳**：直接抄材料，把材料原话当答案

## 四、材料阅读的操作还原法
### 核心公式
**谁 + 做什么 + 形成什么关系**
读材料时，每一句话都问：
1. **谁**：哪个主体？（皇帝/总督/谘议局/农民/商人/国家/阶级...）
2. **做什么**：什么操作？（立法/征税/战争/贸易/改革/反抗...）
3. **形成什么关系**：这个操作改变了什么权力关系？（谁的权力变大了？谁的变小了？谁和谁冲突了？）
### 操作四维度映射
读完材料后，把提取的信息归入四个维度：
| 维度 | 操作论含义 | 高考术语 | 常见信号词 |
|------|-----------|---------|-----------|
| 政治 | 操作权（谁在行使权力，权力边界在哪） | 政治 | 制度、法律、政府、战争、阶级、权力 |
| 经济 | 操作支撑（权力运行靠什么物质基础） | 经济 | 财政、税收、贸易、农业、手工业、商业 |
| 文化 | 操作意义（权力的合法性来源、意识形态） | 思想文化 | 思想、教育、宗教、科技、文学、艺术 |
| 外部 | 操作外界（与其他系统的互动） | 外部/民族/对外关系 | 外国、民族、外交、战争、文明交流 |
### 注意
- 政经文外不是四个互斥的箱子，是同一个操作的四个面相。一件事可能同时涉及多个维度。
- 高考答案用"政治/经济/文化"的术语写，不用"操作权/操作支撑"的内功术语写。内功想清楚，外功写出来。

## 五、答题空间管理
### 北京卷答题空间规律
- 小问N分，答题卡大约给N+1行
- 8分题≈9行，10分题≈11行
- 每行约14厘米宽，写20-25字
### 空间分配原则
- 述：1行（定性）
- 析：每个要点2-3行（观点+材料/史实），8分题2-3个要点
- 评：1行（总结升华）
- **不要在一个要点上写太多**，8分题3个要点，每个要点最多3行
### 常见空间错误
- 述写太长，占了2-3行，挤压析的空间
- 第一个要点写太多，后面的要点没地方写
- 把背景/起因当独立要点写，占了空间但不得分（背景应该揉进述里）

## 六、审查清单（F3用）
写完答案后，快速过一遍：
1. **史实对不对？** 有没有事实颠倒、时间错误、人物错误？（史实错误直接扣分）
2. **得分点踩全没？** 对照题型骨架，该有的维度都有吗？
3. **材料用没用？** "依据材料"的题，答案里有没有引用材料信息？
4. **结合所学了吗？** "结合所学"的题，有没有课本知识？
5. **有没有答非所问？** 设问问的是"政治统治危机"，你是不是写成了"经济危机"？
6. **表述清晰吗？** 每句话有没有明确的观点？还是在堆砌名词？

*F1/F2/F3 + 述析评 + 现象→本质→观点 = 文科答题的完整操作系统*
*核心：先搭架子再填东西，写完才检查，让历史操作在答题卡上再演一遍*
