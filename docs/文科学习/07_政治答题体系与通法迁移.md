## 一、通法迁移：历史的东西怎么套到政治上

### 核心结论：骨架完全通用，变的只有"析的维度"

| 方法论 | 历史 | 政治 |
|--------|------|------|
| F1/F2/F3 | ✅ 完全一样 | ✅ 完全一样 |
| 述析评三元母版 | ✅ 完全一样 | ✅ 完全一样 |
| 操作还原读材料 | ✅ 完全一样 | ✅ 完全一样 |
| 现象→本质→观点双跳跃 | ✅ 完全一样 | ✅ 完全一样 |
| 概括题（只述不评） | ✅ 完全一样 | ✅ 完全一样 |
| 原因题骨架 | 政经文外 | 经济模块：供需政价 / 政治模块：主体分析 |
| 影响题骨架 | 积极+消极+总结 | 对经济/对产业/对企业/对民生 + 升华 |
| 答案风格 | 叙述化（史实+评价） | 格式化（原理+材料分析） |

### 政治答案的标准句式

政治题答案不是自由叙述，是**"原理+材料分析"**的固定格式：

```
原理：（课本术语，如"供求影响价格"）
材料分析：（扣材料，如"机器人租赁企业数量激增，供给扩大，导致价格下降"）
```

每一点都要先写原理，再用材料内容展开。这跟历史的"史实+评价"结构对应，但更格式化。

## 三、经济生活答题体系

### 3.1 原因题：供需政价四维度

看到"分析……的原因/为什么"，从四个方向找：

| 维度 | 找什么 | 课本原理 |
|------|--------|---------|
| 供 | 供给增加？技术进步？企业增多？生产率提高？ | 生产决定消费、社会劳动生产率提高 |
| 需 | 需求扩大？应用场景多？消费升级？收入提高？ | 消费反作用于生产、收入是消费的基础 |
| 政 | 政策支持？规划？财政补贴？宏观调控？ | 科学的宏观调控、财政政策、产业政策 |
| 价 | 价格下降？成本降低？性价比提高？ | 价值决定价格、供求影响价格 |

**不是每题都全写，材料给了哪个写哪个。**

### 3.2 影响/意义题：四层次推导

看到"分析……的作用/意义/影响"，从近到远推导：

```
具体做法 → 直接改变 → 中间影响 → 升华到高质量发展
```

| 层次 | 写什么 |
|------|--------|
| 对企业 | 降低成本？提升创新能力？增强竞争力？ |
| 对产业 | 产业升级？产业链完善？培育新产业？ |
| 对经济 | 培育新动能？优化经济结构？推动高质量发展？ |
| 对民生/国家 | 增加就业？提升国际竞争力？满足人民需求？ |

**每一点都要从材料的具体优势/做法出发，推导出结果，最后升华到高质量发展/新质生产力/现代化经济体系。**

### 3.3 概括题：只述不评，材料分点

跟历史概括题完全一样。从材料里找核心词，每点"核心词+材料依据"，不发挥、不评价。

### 3.4 经济生活高频原理（必背）

```
1. 价值规律：价值决定价格，供求影响价格
2. 生产与消费：生产决定消费，消费反作用于生产
3. 企业经营：制定正确经营战略、提高自主创新能力、诚信经营
4. 宏观调控：经济手段（财政/货币政策）、法律手段、行政手段
5. 新发展理念：创新、协调、绿色、开放、共享
6. 高质量发展：转变发展方式、优化经济结构、转换增长动力
7. 新质生产力：科技创新驱动、高科技高效能高质量、符合新发展理念
8. 创新驱动发展战略：创新是第一动力
9. 供给侧结构性改革：去产能、去库存、去杠杆、降成本、补短板
10. 现代化经济体系：产业体系、市场体系、收入分配体系、城乡区域体系、绿色发展体系、开放体系
11. 实体经济：一国经济的立身之本、财富之源
12. 产业转型升级：从低端到高端、从制造到智造、从要素驱动到创新驱动
```

### 3.5 措施/建议题：主体+做法

看到"提出建议/措施/如何做"，按主体分点：

| 主体 | 写什么 |
|------|--------|
| 国家/政府 | 宏观调控、政策支持、完善市场秩序、财政补贴 |
| 企业 | 创新、转型升级、诚信经营、提高竞争力 |
| 个人/消费者 | 树立正确消费观、提高素质、参与监督 |

## 四、政治生活答题体系

### 4.1 主体分析法（核心方法）

政治生活题的本质是**"谁在做什么"**。看到题先找主体，每个主体对应一套答题术语。

| 主体 | 核心术语 |
|------|---------|
| 中国共产党 | 党的领导（最高政治领导力量）、执政理念（以人民为中心）、执政方式（科学/民主/依法执政）、党的建设、先锋模范作用 |
| 政府 | 性质（人民的政府）、职能（政治/经济/文化/社会/生态）、宗旨（为人民服务）、原则（对人民负责）、依法行政、自觉接受监督、建设服务型政府 |
| 人大 | 性质（国家权力机关）、职权（立法权/决定权/任免权/监督权）、民主集中制 |
| 人大代表 | 权利（审议/表决/提案/质询）、义务（密切联系群众、对人民负责） |
| 公民 | 权利（选举权/政治自由/监督权）、义务、参与政治生活的原则（法律面前一律平等/权利义务统一/个人利益国家利益结合）、有序参与 |
| 人民政协 | 性质（爱国统一战线组织）、职能（政治协商/民主监督/参政议政） |
| 国际社会 | 主权国家、国家利益（国际关系的决定性因素）、时代主题（和平与发展）、我国外交政策（独立自主的和平外交政策）、人类命运共同体 |

### 4.2 政治生活答题句式

```
主体+做了什么+体现了什么原理+有什么意义
```

例："政府出台XX政策（做了什么），履行了经济建设职能（原理），有利于促进经济高质量发展（意义）。"

## 五、文化生活答题体系

### 高频原理

```
1. 文化的社会作用：文化作为一种精神力量，能够在人们认识世界改造世界的过程中转化为物质力量
2. 文化与经济政治：相互影响、相互交融，文化反作用于经济政治
3. 文化对人的影响：来源（特定文化环境/各种形式文化活动）、表现（交往行为/实践活动/认识活动/思维方式）、特点（潜移默化/深远持久）、优秀文化塑造人生（丰富精神世界/增强精神力量/促进人的全面发展）
4. 文化传承：文化多样性（民族节日/文化遗产）、文化传播（商业贸易/人口迁徙/教育/大众传媒）、文化继承（取其精华去其糟粕/推陈出新革故鼎新）
5. 文化创新：根本途径（社会实践）、基本途径（继承传统推陈出新/面向世界博采众长）、主体（人民群众）
6. 中华文化：源远流长（汉字/史书典籍）、博大精深（独特性/区域性/民族性）、包容性（求同存异/兼收并蓄）
7. 中华民族精神：以爱国主义为核心，伟大创造精神/伟大奋斗精神/伟大团结精神/伟大梦想精神
8. 中国特色社会主义文化：坚持马克思主义指导、坚定文化自信、建设社会主义文化强国
```

## 六、生活与哲学答题体系

### 6.1 四大模块原理

| 模块 | 核心原理 |
|------|---------|
| 唯物论 | 物质决定意识（一切从实际出发）、意识的能动作用、规律的客观性和普遍性（尊重客观规律+发挥主观能动性） |
| 认识论 | 实践是认识的基础（来源/动力/检验标准/目的）、真理的客观性/具体性/条件性、认识的反复性/无限性/上升性 |
| 辩证法 | 联系观（普遍性/客观性/多样性/整体与部分/系统优化）、发展观（普遍性/实质/前进性与曲折性/量变与质变）、矛盾观（对立统一/普遍性/特殊性/普特关系/主次矛盾/矛盾主次方面/两点论重点论）、辩证否定观（实质是扬弃/创新意识） |
| 历史唯物主义 | 社会存在与社会意识、社会基本矛盾（生产力与生产关系/经济基础与上层建筑）、人民群众是历史的创造者（群众观点/群众路线）、价值观的导向作用、价值判断与价值选择、人生价值的创造与实现 |

### 6.2 哲学题答题格式

```
原理名称 + 原理内容（一句话） + 方法论 + 材料分析
```

例："物质决定意识（原理），要求我们一切从实际出发（方法论）。材料中根据XX实际情况制定XX政策，体现了一切从实际出发（材料分析）。"

**哲学题关键：先看题干限定哪个模块，再从该模块里选最贴合材料的原理。** 题干说"运用辩证法知识"就不能用唯物论原理。

## 七、政治与历史的关键差异

| 维度 | 历史 | 政治 |
|------|------|------|
| 答案格式 | 史实+评价，叙述化 | 原理+材料分析，格式化 |
| 时间维度 | 有明确时间轴，时空观念是核心 | 无时间轴，主体/模块是核心 |
| 得分点 | 史实准确+评价到位 | 原理准确+材料对应 |
| 开放性 | 评析题有一定开放空间 | 哲学题原理选择有空间，经济政治较固定 |
| 易错点 | 史实笔误、时空错位 | 原理用错模块、材料不对应、只写原理不扣材料 |

## 八、训练记录

### 训练1：2026西城二模33题（机器人租赁市场原因）
- 题型：经济原因题（供需政价）
- 用户答案：四维度框架正确，材料依据基本到位
- 问题：部分表述泛化（"服务业轻工业"vs材料"门店营销教工辅助"）、个别推论超出材料
- 教训：经济原因题同样要严格扣材料，原理+材料分析的格式不能省

### 训练2：2026东城一模34题（中关村优势+高质量发展作用）
- 题型：概括+影响混合题（8分）
- 用户答案：优势5点+作用5点，方向正确
- 问题：点数过多（8分题4+4即可）、部分作用太笼统、漏了"规模全国领先"硬数据
- 教训：高质量发展是每一点的落脚点，不是最后一句口号；8分题写4+4点，每点写扎实
