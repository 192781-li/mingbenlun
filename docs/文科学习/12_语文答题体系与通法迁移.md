## 二、通法迁移：F1F2F3在语文中怎么用

### F1 题感（先行）：判断题型，写骨架
拿到任何语文题，先问三件事：
1. **考什么板块？**（信息类/文言文/古诗/文学类/语用/作文）
2. **问什么？**（内容理解/手法作用/原因/情感/观点/概括）
3. **从哪找答案？**（原文定位/知识储备/自己组织）

### F2 分析（填充）：定位原文，完成跳跃
- **阅读题**：回原文定位→提取信息→加工成答案（现象→本质）
- **作文**：审题立意→搭分论点→找论据（现象→本质→观点）

### F3 元认知（后置）：审查
- 阅读：答案有没有原文依据？点全不全？有没有答非所问？
- 作文：论点明不明？论据撑不撑得起？有没有回扣题目？

**铁则不变：F1永远先行，F3永远后置，F3不阻塞F1。**

## 三、述析评在阅读中的对应（核心）

历史的述析评母版，在语文阅读题里完全通用：

| 述析评 | 阅读题对应 | 怎么操作 |
|--------|-----------|---------|
| **述**（提取/概括） | 内容概括、信息筛选、思路梳理 | 回原文找→分点提取→只述不评 |
| **析**（分析/展开） | 手法作用、原因分析、词句含义 | 点明手法/原因→结合文本分析→说效果 |
| **评**（评价/探究） | 观点评价、标题作用、主旨探究 | 亮观点→结合文本论证→升华 |

**所有阅读主观题都是述、析、评的单独使用或组合。**

## 四、多文本阅读（信息类）

### 4.1 选择题怎么排雷
**方法：选项回原文比对，找四种陷阱**
1. **偷换概念**：选项把原文的A换成B
2. **以偏概全**：原文"部分/有些"→选项"全部/都"
3. **强加因果/逻辑错位**：原文没有因果关系，选项硬加
4. **无中生有/曲解文意**：原文没说，选项编造或说反

**步骤**：读题干→圈选项关键词→回原文找对应句→逐字比对→排除

### 4.2 主观简答题（述为主）
**识别**：概括/说明/分析……原因/特点/异同
**骨架**：
- 概括题：分点从各材料提取→整合归类→只述不评
- 原因题：材料里找直接原因+结合材料推断根本原因
- 比较题：材料间找相同点+不同点，分点列

**关键：答案几乎全在材料里，考的是筛选整合，不是自由发挥。**

## 五、文言文阅读

### 5.1 实词推断四法
1. **语境推断**：结合上下文猜意思
2. **课内迁移**：课本里学过的义项直接套
3. **语法分析**：看这个词在句中作什么成分（主/谓/宾→名词/动词）
4. **对称推断**：古文多对仗，对应位置的词意思相近或相反

### 5.2 虚词：抓高频18个
之、其、而、以、于、为、者、也、焉、何、则、乃、且、若、所、因、与、也
**重点：而（并列/承接/转折/修饰）、以（用/凭/因为/来）、之（代词/结构助词"的"/取独/动词"到"）**

### 5.3 断句三看
1. 看语法（找主谓宾，一个完整意思断开）
2. 看标志（句首发语词"夫/盖/且夫"前断；句末"也/矣/焉/耳"后断）
3. 看对称（排比、对偶处按结构断）

### 5.4 翻译"信达雅"操作法（直译为主）
**五字诀：留、删、换、调、补**
- **留**：人名地名官名年号原样保留
- **删**：无实义的虚词删掉
- **换**：单音节词换成双音节词（古今异义重点换）
- **调**：倒装句调成正常语序（宾语前置/状语后置/定语后置）
- **补**：省略成分补出来（省主语/宾语）

**踩分点：关键实词、特殊句式各占分，翻译完对照有没有落实。**

## 六、古诗鉴赏

### 6.1 读诗四步
1. 看标题、作者、注释（定基调、知背景）
2. 找意象（景物/事物，意象组合成意境）
3. 抓情感词、尾联（诗眼常在结尾）
4. 辨手法（怎么写的）

### 6.2 高频手法清单

| 类别 | 手法 |
|------|------|
| 抒情方式 | 直抒胸臆、借景抒情、情景交融、托物言志、用典、借古讽今 |
| 描写手法 | 动静结合、虚实结合、远近/高低结合、视听结合、白描、细节描写、对比、衬托（正衬/反衬） |
| 修辞 | 比喻、拟人、夸张、对偶、借代、双关、互文 |
| 表现手法 | 象征、渲染、烘托、欲扬先抑、以小见大、联想想象 |

### 6.3 情感题答题骨架（析为主）
**公式：手法 + 诗句分析（写了什么景/事） + 意境/效果 + 情感**

**常见情感类型**：
- 山水田园：热爱自然、闲适恬淡、归隐之志
- 边塞征战：建功立业、思乡厌战、悲壮苍凉
- 咏史怀古：借古讽今、昔盛今衰、怀才不遇
- 送别思乡：依依不舍、思念亲人、羁旅之愁
- 咏物言志：高洁品格、志向追求、不遇之叹
- 忧国忧民：家国情怀、感时伤世

### 6.4 炼字/词句含义题
**骨架：字义→句意（描绘画面）→手法→情感/效果**
"某字好在哪"= 解释字 + 还原景象 + 意境 + 情感

## 七、文学类文本阅读（散文/小说）

### 7.1 散文阅读
**核心：找线索（物/情/理）→ 分层（写了哪几件事/景）→ 悟主旨（托物言志/借景抒情）**

| 题型 | 骨架 |
|------|------|
| 词句含义 | 表层义（字面）+ 深层义（语境/主旨）+ 情感 |
| 句段作用 | 内容（写了什么+情感）+ 结构（开头总起/中间承转/结尾总结点题）+ 效果 |
| 形象/物象 | 特点（分点）+ 象征意义 + 对主旨作用 |
| 手法赏析 | 手法 + 文本分析 + 效果 + 情感 |
| 主旨探究 | 概括内容 + 情感倾向 + 升华（评） |

**句段作用万能维度：内容上（写什么、表什么情）+ 结构上（开头/中间/结尾的作用）+ 读者效果。**

### 7.2 小说阅读
**抓四要素：人物、情节、环境、主题**

| 题型 | 骨架 |
|------|------|
| 人物形象 | 分点概括性格（外在身份+内在品质）+ 找原文依据 |
| 人物塑造手法 | 正面（肖像/语言/动作/心理/神态）+ 侧面（他人衬托/环境烘托） |
| 情节作用 | 对人物（显性格）+ 对情节（铺垫/伏笔/转折/推动）+ 对主题 |
| 环境描写作用 | 交代背景 + 渲染气氛 + 烘托人物心情 + 推动情节 + 暗示主题 |
| 标题作用 | 线索 + 概括内容 + 双关/象征 + 揭示主题 + 吸引读者 |
| 叙事技巧 | 视角（第一/三人称）、顺序（顺/倒/插叙）、详略、伏笔照应、出人意料 |

## 八、名篇名句默写

- **理解性默写是主流**：不是给上句填下句，而是给情境（"表达诗人忧国忧民的句子是……"）→要理解诗句意思
- **对策**：背的时候要懂每句含义、知道每句写什么；易错字单独标记反复写
- **零失分目标**：这8分是纯下功夫就能拿满的，绝不能丢

## 九、语言文字运用

| 题型 | 方法 |
|------|------|
| 病句辨析 | 六查：语序不当、搭配不当、成分残缺/赘余、结构混乱、表意不明、不合逻辑 |
| 补写句子 | 看上下文逻辑（因果/转折/并列/总分）→ 抓前后照应的关键词→ 主语一致 |
| 压缩概括 | 找陈述对象+核心事件→删修饰留主干→按字数压缩 |
| 语句衔接/排序 | 找首句（总起）→抓关联词、指代词、时间词→逻辑串联 |
| 词语/成语 | 辨语义轻重、适用对象、感情色彩、语境搭配 |

## 十、微写作（10分，三选一，≤150字）

| 类型 | 要点 |
|------|------|
| **应用类**（宣传语/倡议/推荐/解说） | 格式对（称呼/对象）+ 内容全（题目要求的点）+ 语言得体 |
| **描写类**（写场景/人物/画面） | 抓特征 + 多感官 + 细节，生动形象 |
| **抒情/议论类**（小诗/感悟） | 情感真 + 有中心 + 语言凝练 |

**铁则：审题逐条落实要求，字数控制在130-150，先打腹稿再写。**

## 十一、大作文（50分，重中之重）

### 11.1 审题立意（决定档次，最关键）
**步骤**：
1. 读材料/题目，圈关键词
2. 抓核心话题（材料在说什么）
3. 挖本质（现象→本质：这背后是什么道理）
4. 立中心论点（一句话，明确、正向、有深度）

**立意要求：准（不跑题）、深（不止表面）、新（有自己思考）。**

### 11.2 议论文结构（对接历史论述题骨架）
历史论述题是"亮观点→分角度+史实→回扣"，议论文完全同构：

```
亮观点（中心论点，开头明确亮出）
  → 分论点1 + 论据（事例/道理）+ 分析
  → 分论点2 + 论据 + 分析
  → 分论点3 + 论据 + 分析
回扣（总结全文，升华，呼应开头和题目）
```

### 11.3 三种好用的分论点展开角度
1. **是什么—为什么—怎么办**（递进）
2. **个人—社会/集体—国家/时代**（范围递进）
3. **正反对照**（正面论证+反面论证）

### 11.4 论据使用
- 论据类型：事实论据（人物事例/历史事件/社会现象）+ 道理论据（名言/原理）
- **关键：叙例要简（别讲故事），议例要详（分析论据怎么证明论点）**
- 积累方向：家国情怀、科技创新、文化传承、青年担当、奋斗坚持、传统与现代（北京高频主题）

### 11.5 提分要点
- 标题：亮观点，简洁有力
- 开头：引材料/现象→快速亮论点（不绕）
- 每段：分论点置于段首，论据后必有分析
- 结尾：回扣论点+升华到时代/青年/价值
- 卷面：字迹工整、段落清晰（5-7段为宜）

## 十二、四科通法总览（至此完整）

| | 历史 | 政治 | 地理 | 语文 |
|--|------|------|------|------|
| 母版 | 述析评 | 述析评 | 述析评 | 述析评（阅读）/论述结构（作文） |
| 分析维度 | 政经文外 | 供需政价/主体 | 地气水土生+市交政劳技 | 内容/手法/情感/主旨 |
| F1 | 判题型写骨架 | 同 | 同 | 判板块、定问法、找答案来源 |
| F2 | 填史实 | 填原理材料 | 填要素模板 | 原文定位/审题搭论点 |
| F3 | 审查 | 审查 | 审查 | 查依据/查回扣 |
| 最关键 | 史实+评价 | 原理对口 | 定位+要素 | 阅读找原文、作文立准意 |

**一套F1F2F3+述析评，打通文科四科——变的只是每个学科"析"的具体维度，不变的是操作结构。**

## 十三、语文训练路径（下一步）

1. **基础层**：默写篇目滚动过关（零失分）；文言实词虚词+课内知识积累
2. **阅读层**：按板块练，每道主观题走"判断题型→原文定位→述析评骨架→组织答案→对答案"
3. **作文层**：每周1篇完整作文+2个作文提纲；积累主题论据；打磨3个万能结构
4. **真题层**：北京卷真题整套限时训练，对答案找差距
