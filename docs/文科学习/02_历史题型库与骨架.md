## 一、题型判断方法：动词+宾语双重判断
### 为什么不能只看动词
- 同一个动词可以导向不同题型："说明"可以是概括题（说明内容）、原因题（说明原因）、评析题（说明认识）
- 必须**动词+宾语一起看**
### 判断流程
```
1. 圈动词（概括/说明/分析/简析/评析/评述/阐述/论述/比较/指出...）
2. 找宾语（内容/原因/背景/影响/意义/作用/特点/趋势/认识/启示/异同...）
3. 动词+宾语 → 判题型 → 写骨架
```
### 常见宾语→题型映射
| 宾语 | 题型 | 骨架方向 |
|------|------|---------|
| 内容/表现/特点/趋势 | 概括题 | 只述不评，材料分点 |
| 原因/背景/条件 | 原因题 | 政经文外（材料+课本） |
| 影响/意义/作用/危害 | 影响题 | 积极（当时+后世）+消极+总结 |
| 认识/启示/看法/评价 | 评析题 | 述→析（积+消）→评 |
| 过程/演变/发展 | 阐述题 | 按时间/线索分阶段：背景→内容→影响 |
| 观点/论题 | 论述题 | 亮观点→分论点+史实→回扣 |
| 异同/区别/比较 | 比较题 | 相同点→不同点（背景/内容/影响）→总结 |

## 二、6骨架3+3（最终版）
### 什么是"3+3"
- **前3个**：基础骨架（概括、原因、影响）——只做一个动作（述/析）
- **后3个**：复合骨架（评析、阐述、论述）——述析评的不同组合
- 比较题是变体，可归入阐述或评析
### 骨架1：概括题（只述不评）
**识别**：动词=概括/指出/简述/说明，宾语=内容/表现/特点/趋势
**骨架**：
```
①材料分点提取（每点一个核心词+材料依据）
②结合课本补充（如果要求"结合所学"）
③只述不评，不写评价/升华
```
**关键**：从材料中提取的是**现象的本质化表达**，不是照抄材料原文。每点=核心词（本质）+材料依据（现象）。
**空间**：4分题2-3点，6分题3-4点，每点1-2行
### 骨架2：原因/背景题（只析）
**识别**：动词=分析/简析/说明/为什么，宾语=原因/背景/条件
**骨架**：
```
①政治（操作权：制度/政策/阶级/战争）
②经济（操作支撑：财政/税收/生产力/商业）
③思想文化（操作意义：思想/教育/科技/宗教）
④外部（操作外界：外国/民族/外交/文明交流）
```
**关键**：
- 材料里有的先从材料提取，再结合课本补充
- 根本原因=经济基础/生产力/主要矛盾；直接原因=导火索/具体事件
- 北京卷常考"政经文"三维度，外部视题目而定
**空间**：6-8分题3-4点，每点2行
### 骨架3：影响/意义/作用题（只析+小结）
**识别**：动词=说明/分析/指出，宾语=影响/意义/作用/危害
**骨架**：
```
①积极面（当时的影响+对后世的影响）
②消极面（局限性/危害/问题）
③总结（1句话，上升到规律/地位）
```
**关键**：
- 积极面要分"当时"和"后世"两个层次，不要只写当时
- 消极面不是每题都有，但有就必须写（辩证思维）
- 作用题如果是正面事件（如人民群众的作用），消极面可以简化或不写
**空间**：8分题，积极面2-3点，消极面1点，总结1行
### 骨架4：评析/评述题（述+析+评，最完整）
**识别**：动词=评析/评述/评价/谈谈看法，宾语=事件/观点/现象
**骨架**：
```
述：1句话定性（这是什么性质的事件/观点）
析：分维度分析
  - 积极面（合理性/进步性/贡献）
  - 消极面（局限性/问题/危害）
评：1句话总结升华（本质判断/历史地位/经验教训）
```
**关键**：
- 述不是复述材料，是从材料提炼本质（现象→本质第一跳）
- 析的积极面和消极面不是各写一句空话，每个面都要有2-3个具体要点
- 评不是重复析，是上升到史观/规律（本质→观点第二跳）
- 如果题目限定了视角（如"用唯物史观评价"），必须落到那个视角
**空间**：8-12分题，述1行，析4-6行（积极2-3点+消极2点），评1行
### 骨架5：阐述题（述+析，按线索展开）
**识别**：动词=阐述/说明/梳理，宾语=过程/演变/发展/脉络
**骨架**：
```
按时间/线索分阶段：
  阶段一：背景/起因 → 内容/表现 → 影响
  阶段二：背景/起因 → 内容/表现 → 影响
  ...
总结：1句话（整体趋势/规律）
```
**关键**：
- 阐述题的核心是**过程性**，不是静态分析。必须按时间/阶段展开
- 每个阶段都要有"背景→内容→影响"的完整链条
- 如果题目给了视角（如"以文明交流视角"），每个阶段都要扣住那个视角
- 阐述题和概括题的区别：概括是横向分点（同一时间的不同方面），阐述是纵向分阶段（时间线上的演变）
**空间**：8-10分题，2-3个阶段，每阶段2-3行，总结1行
### 骨架6：论述题（述+析+评，亮观点论证）
**识别**：动词=论述/论证/写小论文，宾语=观点/论题
**骨架**：
```
亮观点：1句话（明确的判断句，不是描述句）
分论点1 + 史实论证（2-3个史实）
分论点2 + 史实论证（2-3个史实）
（分论点3，视分值而定）
回扣：1句话（重申观点，升华）
```
**关键**：
- 观点必须是**判断句**（"XX是YY"），不能是描述句（"XX的发展过程"）
- 分论点是支撑观点的不同角度，不是时间顺序
- 每个分论点必须有**具体史实**支撑，不能空喊
- 史实要准确（时间、人物、事件不能错）
- 回扣不是重复观点，是在论证基础上的升华
**空间**：12分题，观点1行，2个分论点各3-4行，回扣1行

## 三、比较题（变体）
**识别**：动词=比较/对比/分析异同，宾语=两个事件/制度/人物
**骨架**：
```
①相同点（2-3个，从背景/内容/影响中找共性）
②不同点（3-4个，分维度：背景不同/内容不同/影响不同/性质不同）
③总结（1句话，异同的本质原因/历史启示）
```
**关键**：
- 相同点和不同点要**对应着写**，不要东一榔头西一棒子
- 不同点优先写：背景、内容、影响、性质四个维度
- 如果题目限定了比较角度（如"比较背景上的异同"），只写那个角度
- 比较题本质是阐述+评析的混合，相同点=述，不同点=析，总结=评

## 四、混合题型判断
### 什么是混合题型
一道题同时包含两种题型的要求，比如：
- "概括XX的特点，并分析其原因" = 概括题+原因题
- "说明XX的影响，并谈谈你的认识" = 影响题+评析题
- "比较XX和YY的异同，并阐述其启示" = 比较题+评析题
### 判断方法
1. 把设问**拆成几个小问**，每个小问单独判题型
2. 每个小问用对应的骨架
3. 注意小问之间的逻辑关系（前一问是后一问的基础）
### 常见混合题型
| 混合题型 | 骨架组合 |
|---------|---------|
| 概括+原因 | 先概括特点（只述），再分析原因（政经文外） |
| 概括+影响 | 先概括内容（只述），再分析影响（积+消+结） |
| 原因+影响 | 先分析原因（政经文外），再分析影响（积+消+结） |
| 比较+认识 | 先比较异同，再谈认识（述析评） |
| 阐述+评价 | 先阐述过程（分阶段），再评价（述析评） |

## 五、北京卷命题特点
### 试卷结构（2025年）
- 选择题：15题，45分
- 非选择题：5道大题，8-9小问，55分
- 大题涵盖：中国古代史、中国近现代史、世界史、史学理论/新考法
### 命题特点
1. **材料新颖**：常引用原始史料、学术观点、新情境（如2025年"点评AI作答"）
2. **跨模块综合**：一道题可能涉及政治、经济、文化多个模块
3. **重视时空观念**：常考时间轴、空间分布、历史地图
4. **开放性增强**：小论文、观点评析类题目占比上升
5. **北京特色**：关注北京地方史、京津冀、大运河、长城等北京元素
6. **不回避热点**：以历史视角回应现实问题（现代化、民族复兴、文明交流等）
### 高频考点
- 中国古代：中央集权制度演变、经济重心南移、儒家思想演变、民族融合
- 中国近代：列强侵华与民族危机、洋务运动/戊戌变法/清末新政、辛亥革命、新民主主义革命
- 中国现代：新中国建设、改革开放、中国特色社会主义
- 世界史：古希腊罗马、文艺复兴/宗教改革/启蒙运动、工业革命、两次世界大战、冷战/全球化
- 史学理论：史料辨析、历史解释、史观运用

| 说明/分析/指出 | 影响/意义/作用/危害 | 影响 | 积极+消极+总结 |
| 评析/评述/评价/认识 | 事件/观点/现象 | 评析 | 述→积→消→评 |
| 阐述/说明/梳理 | 过程/演变/发展/脉络 | 阐述 | 分阶段：背景→内容→影响 |
