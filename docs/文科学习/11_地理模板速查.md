## 通法（三科通用）

- **F1先行**：判题型→写骨架
- **F2填充**：要素+具体分析（模板填空）
- **F3后置**：审查定位对不对、要素漏没漏、图表读没读错
- **地理第一步永远是定位**：经纬度/海陆轮廓/地标→判断区域→调用该区域地气水土生知识
- **地理是最公式化的文科**：背了模板往材料/图表里填

## 一、自然地理五要素：地气水土生

| 要素 | 包含内容 | 高频考点 |
|------|---------|---------|
| **地**（地形/地质） | 地形类型、地势起伏、地质构造、地貌、海拔 | 地形对气候/河流/人口影响；内外力作用 |
| **气**（气候） | 气温、降水、光照、风、气候类型、气象灾害 | 气候成因（纬度/大气环流/海陆/地形/洋流） |
| **水**（水文） | 河流、湖泊、洋流、地下水、水循环 | 河流水文特征；洋流影响 |
| **土**（土壤） | 土壤类型、肥力、厚度、酸碱度 | 土壤对农业影响；水土流失/荒漠化 |
| **生**（生物/植被） | 植被类型、自然带、生物多样性、生态 | 自然带分布；垂直地带性；生态保护 |

## 二、人文地理五要素：市交政劳技

| 要素 | 包含内容 | 高频考点 |
|------|---------|---------|
| **市**（市场） | 市场需求、市场距离、消费能力 | 农业/工业/商业区位的市场条件 |
| **交**（交通） | 交通方式、便利度、交通枢纽 | 交通对城市/工业/商业布局影响 |
| **政**（政策） | 国家政策、地方规划、开发区 | 政策对产业/城市发展影响 |
| **劳**（劳动力） | 数量、素质、价格 | 劳动密集型/技术密集型产业区位 |
| **技**（技术） | 科技水平、研发能力、创新 | 高新技术产业区位；技术对农业影响 |

## 四、五大题型骨架

### 4.1 特征描述题（述为主）
**识别**：描述/简述/概括……特征/特点/分布
**骨架**：总述（整体特征）→ 分述（具体要素）→ 特殊点

| 描述对象 | 答题角度 |
|---------|---------|
| 地形特征 | 地形类型（以什么为主）+ 地势起伏（哪高哪低）+ 特殊地貌 |
| 气候特征 | 气温（高低/年较差）+ 降水（多少/季节分配）+ 光照/风 |
| 河流特征 | 水文（流量/汛期/含沙量/结冰期/流速）+ 水系（流向/流域/支流/河网密度） |
| 分布特征 | 空间分布（均匀/不均，哪多哪少）+ 时间变化 + 沿什么分布 |

### 4.2 原因分析题（析为主）
**识别**：分析/说明……原因/成因/为什么
**骨架**：自然原因（地气水土生）+ 人为原因（市交政劳技+人类活动）

**高频原因模板**：

| 问题 | 答题角度 |
|------|---------|
| 气候成因 | 纬度+大气环流+海陆位置+地形+洋流 |
| 洪涝成因 | 自然（降水集中/地势低平/河道弯曲/支流多）+ 人为（植被破坏/围湖造田） |
| 荒漠化成因 | 自然（气候干旱/大风/植被稀少/地表疏松）+ 人为（过度放牧/开垦/樵采/水资源不合理） |
| 盐渍化成因 | 自然（蒸发旺盛/地势低洼/地下水位高）+ 人为（不合理灌溉） |
| 人口迁移 | 推力（迁出地劣势）+ 拉力（迁入地优势）+ 中间阻力 |
| 产业转移 | 转出地（成本上升/市场饱和/政策）+ 转入地（劳动力/地价/市场/政策优惠） |

### 4.3 影响/评价题（析+评）
**骨架**：有利影响 + 不利影响，分自然/经济/社会维度

| 维度 | 有利 | 不利 |
|------|------|------|
| 自然 | 改善生态/保护生物多样性/调节气候 | 破坏生态/环境污染/资源枯竭 |
| 经济 | 促进经济发展/增加收入/带动相关产业 | 成本增加/产业结构单一 |
| 社会 | 增加就业/改善基础设施/提高生活水平 | 移民/社会矛盾/文化冲击 |

### 4.4 措施/建议题（评→操作）
**骨架**：针对原因提措施，分工程+生物+管理+技术

| 问题 | 措施模板 |
|------|---------|
| 水土流失 | 工程（打坝淤地/修梯田/修水库）+ 生物（植树种草/退耕还林）+ 管理（调整农业结构） |
| 荒漠化 | 合理用水+防护林+调节农林牧用地+解决能源问题+控制人口 |
| 洪涝 | 上游（植树造林/修水库）+ 中游（退耕还湖/裁弯取直）+ 下游（加固大堤/开挖河道） |
| 水资源短缺 | 开源（调水/修水库/海水淡化/采地下水）+ 节流（节水/提利用率/调结构/防污染） |
| 产业升级 | 技术创新+产业结构调整+品牌建设+人才培养+政策支持 |

### 4.5 比较题
**骨架**：相同点（1-2点）+ 不同点（分维度对比：位置/地形/气候/水文/植被/经济/人文）

## 五、自然地理核心原理（必背）

### 地球运动
- 自转：昼夜更替、地方时、地转偏向力（北右南左）
- 公转：四季更替、五带、昼夜长短变化、正午太阳高度变化
- 正午太阳高度：H=90°-|纬度差|

### 大气运动
- 热力环流：热上升冷下沉，水平方向高压流向低压
- 气压带风带：7压6风，夏季北移冬季南移
- 季风：东亚（海陆热力差异）、南亚（气压带风带季节移动+海陆热力差异）
- 天气系统：冷锋（锋后雨）、暖锋（锋前雨）、气旋（低压阴雨）、反气旋（高压晴朗）
- 气候类型判断：以温定带、以水定型

### 水循环与洋流
- 水循环：蒸发→水汽输送→降水→径流
- 洋流：中低纬北顺南逆，暖流增温增湿，寒流降温减湿
- 渔场：寒暖流交汇/上升流

### 地质作用
- 内力：地壳运动（褶皱/断层）、岩浆活动、变质作用
- 外力：风化→侵蚀→搬运→沉积
- 流水侵蚀（V型谷/喀斯特）、流水沉积（冲积扇/三角洲）、风力侵蚀（雅丹）、风力沉积（沙丘/黄土）

### 自然带与地域分异
- 纬度地带性：热量为基础（赤道→两极）
- 经度地带性：水分为基础（沿海→内陆）
- 垂直地带性：水热随海拔变化
- 非地带性：地形/洋流/海陆分布

## 六、人文地理核心原理（必背）

### 人口
- 增长模式：原始型（高高低）→传统型（高低高）→现代型（低低低）
- 人口容量：环境承载力（最大）、人口合理容量（最适宜）

### 城市
- 功能分区：商业区（市中心）、住宅区（最广泛）、工业区（城市边缘）
- 城市等级：等级越高，数量越少，服务范围越大
- 城市化问题：交通拥堵/环境污染/住房紧张/就业困难

### 农业
- 地域类型：季风水田（小农/单产高/商品率低）、商品谷物（规模大/机械化高/商品率高）、大牧场放牧（规模大/专业化）、乳畜业（市场导向）、混合农业（良性生态/市场灵活）

### 工业
- 导向型：原料导向（制糖）、市场导向（啤酒/家具）、动力导向（炼铝）、劳动力导向（服装/电子装配）、技术导向（集成电路/航天）
- 集聚：共用基础设施/加强协作/降成本/规模效益
- 分散：寻找最优区位/降成本/减污染

## 七、图表阅读方法

| 图表类型 | 怎么读 |
|---------|--------|
| 等高线 | 数值（海拔）、疏密（坡度）、弯曲（山脊/山谷）、闭合（山顶/盆地） |
| 等温线 | 数值、疏密（温差）、弯曲（海陆/地形/洋流）、闭合（高温/低温中心） |
| 气候资料图 | 气温曲线+降水柱状，先判南北半球，再以温定带以水定型 |
| 区域地图 | 先定位（经纬度/轮廓/地标），再看地形/气候/河流/城市/交通 |
| 统计图表 | 看标题/坐标/图例/趋势/极值/对比 |
