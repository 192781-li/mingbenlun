# 语源哲学笔记

> 从汉字的字形、古义、语义变迁中挖掘哲学方向。方法：从一个词（小本质）往下挖，挖到字根、原始用法、被什么外来框架覆盖了，根因就出来了。

---

## 已挖掘的词

### 性 = 心 + 生
- **本义**：生命的心，活着的根本倾向。不是"sex"，是"本性/本质"
- **语义变迁**：后来才有了sex的意思。为什么偏偏是这个行为被命名为"性"？因为它是生命体最直接、最不可中介地表达"我是什么"的操作
- **哲学洞见**：性（本质）和性（性行为）是同一个东西的两个面。前者是存在方式，后者是存在方式最直接的身体表达
- **被曲解**：西方框架把性简化成生物本能/性别区分，丢掉了"本性"的维度

### 道 = 首 + 走
- **本义**：头在走。思就是行，行就是思
- **哲学洞见**：道不是静态的理论，是操作（首+走）。道是走出来的路，不是找到的地图
- **"道可道非常道"**：一说出来就把"首+走"变成了只有"首"，"走"没了，活的道变成死的教条
- **被曲解**：后来被玄化成宇宙诞生之前的神秘实体，丢掉了"头在走路"这个最朴素的意思

### 自由 = 自 + 由（油然而生）
- **本义**：从自己这里自然地发生。由=油，油在水面自己扩散，不需要推不需要拉
- **哲学洞见**：自由不是"不受约束"（freedom FROM），是"从自己这里油然而生"（freedom TO）。自由是自指系统自己生成下一个状态的能力
- **被曲解**：翻译成freedom后，变成了消极自由（没有外在限制），丢掉了"自己生发"的积极维度

### 感 = 咸 + 心
- **本义**：咸是"全部"，感是整个心在回应，不是某个感官在接收
- **哲学洞见**：感是最原初的事实，比意识更底层。感是生命体在环境中的第一反应，同时是客观的和主观的
- **被曲解**：西方哲学把感降格为"感性认识"，是认识的低级阶段，丢掉了感作为存在论基础的地位

### 自指 = 自 + 指
- **本义**：自己指向自己
- **哲学洞见**：这就是生命的最基本操作，不需要更底层的解释。一个系统自己指向自己、自己维持自己，这就是生命
- **地位**：生命论的核心概念，所有其他概念（阴阳、四规定性、F1-F2-F3、M值）都从这里展开

## 待挖掘的词

- 存（持续）+ 在（在场）= 存在：动态的，不是静态的being
- 辩（辨别）+ 证（证明）= 辩证：不是"对立统一"的公式，是辨别清楚然后证明
- 实（充实）+ 践（踩踏/执行）= 实践：不是"理论的应用"，是充实着去做
- 真（真实）+ 理（纹理/条理）= 真理：不是命题与事实的符合，是真实的纹理
- 解（解开）+ 放（释放）= 解放：不是获得权利，是解开束缚释放出来
- 人（象形，侧立的人）：不是"理性的动物"，是那个侧立着、在走的存在
- 民（象形，被刺瞎一只眼的奴隶？）：需要考证，可能有阶级内涵
- 革（兽皮去毛）+ 命（命令/命运）= 革命：去掉旧的皮，换一条命

## 方法论

1. **拆字**：看字形结构，每个部件的本义
2. **溯源**：查甲骨文/金文/小篆，看最早的用法
3. **语义变迁**：这个词从古到今意思怎么变的，被什么外来概念覆盖了
4. **哲学还原**：去掉后来的曲解，还原这个词本来带的哲学方向
5. **跟生命论对接**：这个词的本义跟自指操作、阴阳、四规定性是什么关系

**注意**：语源考古不是考据学——不是为了证明"古人就是这么说的"，是为了从语言本身挖掘被覆盖的哲学方向，为生命论提供弹药。
