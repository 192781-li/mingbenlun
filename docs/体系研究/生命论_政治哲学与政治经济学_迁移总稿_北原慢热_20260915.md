## 0. 总纲

生命论从"在感"出发：

``` text
在感 → 操作 → 认识 → 实践 → 社会 → 异化 → 解放 → 格物 → 人文 → 传统 → 形式化
```

核心命题：

``` text
感先于操作，操作先于实体；
自指操作即生命；
异化是自指能力的外移、遮蔽或丧失；
解放是恢复并扩大实际自指能力。
```

生命论作者为北原慢热，AI为协作、形式化、反思工具，最终哲学判断由作者决定。

# 第一编：本体论与政治哲学

## 1. 在感与操作

\[L\]

"在感"是第一人称起点。否定在感的行为本身仍发生于感之中。

``` text
感先于操作
操作先于实体
```

实体可理解为沉积、稳定化后的操作结构；这不是否认物质存在，而是改变认识论起点。

## 2. 自指与生命

\[L\]

生命的形式化入口：

``` text
S = f(S)
νF₂ = F(νF₂)
```

自指不是"系统谈论自己"，而是系统的输出重新成为维持、修正、再生产自身运行的输入。

生命性自指至少涉及：

1.  边界生成
2.  内生目的性
3.  操作再生
4.  环境交互
5.  边界防御与持续存在

## 3. 反自指

\[L\]

设：

``` text
V(S) = 主体 S 的自指能力
```

若结构 P：

1.  使用 S 的操作能力；
2.  使 `V(S)` 持续下降；
3.  同时依赖 S 继续存在；

则可定义 P 对 S 构成反自指关系：

``` text
dV(S)/dt < 0
P = f(S)
P 的持续存在要求 V(S) > 0
```

这是生命论理论定义，不是已经完成经验验证的科学定律。

## 4. 感---应---能---明性

\[L\]

``` text
感 → 应 → 能 → 明
```

-   感：第一人称生命表达
-   应：对他者/环境的直接回应
-   能：改变因果链的实际能力
-   明性：生命对自身操作进行递归意识化

"应"可理解为社会自指的边界机制：

``` text
应 ≈ 社会的细胞膜
```

## 5. 阳---阴

\[L\]

``` text
阳 = 主动、生成、更新
阴 = 沉淀、保存、结构
```

"阳主阴从"是结构关系，不自动等于道德评价。

``` text
只讲打破不讲沉淀 → 唯意志论
只讲沉淀不讲打破 → 保守主义
```

## 6. 生命意义与文明

\[L/A\]

``` text
M = α · T · N
```

T：基线；α：实际递归/自我意识深度；N：自指生产性比率；M：生命意义。

``` text
N < 1 → 损耗
N = 1 → 稳态
N > 1 → 生产性扩张
l' = (1-N) × 100%
```

群体：

``` text
M_group = σ · α · T · N
```

文明：

``` text
C = R - A
```

R 为对生命的支持/资源，A 为异化损耗。

以上均为哲学形式化工具，不是经实验校准的计算器。

## 7. 操作权

\[L\]

政治正义不能只由收入定义：

``` text
O = O_p + O_o + O_s
```

-   `O_p`：生产操作权
-   `O_o`：产出/剩余配置权
-   `O_s`：结构/规则修改权

因此：

``` text
收入 ↑ ≠ 操作权 ↑
```

## 8. 国家与社会自指

\[A/L\]

``` text
S_i ↔ G_i ↔ N_i ↔ W
```

国家可暂定义为：

``` text
超越直接关系规模后，用于维持大规模生命联合的制度化自指结构。
```

必须区分：

``` text
国家自指能力 ≠ 人民自指能力
```

可能出现：

``` text
O_state ↑
O_people ↓
```

即"自指转移"。

## 9. 改革、革命、继续革命

\[L/A\]

``` text
改革 = 在既有结构内恢复/扩大有效反馈。

革命 = 当内部反馈结构性堵塞时，重建操作权与反馈结构。

继续革命 =
持续扩大低层实际操作权
+
持续检测高层结构的自我异化
+
持续修复反馈。
```

``` text
革命胜利 ≠ 解放完成
运动 ≠ 自指
```

长期标准：

``` text
O_people ↑
V_self ↑
A ↓
```

## 10. 历史周期

\[A\]

``` text
生成 → 稳定 → 沉淀 → 固化 → 权力集中
→ 反馈下降 → 异化 → 危机 → 再生成
```

这是理论模型，不是确定性历史定律。

# 第二编：政治经济学

## 11. 根本问题

\[L/A\]

政治经济学研究生命如何组织物质再生产。核心问题：

``` text
谁生产？
谁控制生产资料？
谁决定生产什么？
谁取得剩余？
谁决定剩余如何使用？
谁承担风险？
谁可以退出？
谁能修改规则？
```

因此核心问题：

``` text
谁拥有实际操作权？
```

## 12. 五种"价值"必须分开

### 12.1 使用价值 \[M\]

``` text
U(x) = 商品满足某种需要的能力
```

### 12.2 交换价值 \[M\]

商品之间的交换比例：

``` text
x : y = a : b
```

### 12.3 马克思意义上的价值 \[M\]

``` text
V_M(x) ∝ T_SNL(x)
```

`T_SNL` 为社会必要劳动时间。

个体实际耗时：

``` text
T_individual ≠ T_SNL
```

### 12.4 生命贡献 \[L/A\]

``` text
L(x;S,E) ≈ ΔV_self-reference
```

表示对象 x 对生命系统 S 在环境 E 中维持/扩大自指能力的贡献。

### 12.5 关键区分

``` text
V_M ≠ L
```

可能：

``` text
V_M ↑，L ↓
V_M ↓，L ↑
```

所以：

``` text
经济价值 ≠ 生命价值
```

但经济价值可以被理解为生命物质生产活动的一种历史性社会形式。

# 第三编：劳动---劳动力---剩余价值

## 13. 劳动与劳动力 \[M\]

``` text
劳动力 ≠ 劳动

LP = 劳动的能力
L_b = 劳动力实际发生的活动
```

资本购买的是 `LP`。

劳动力的特殊使用价值：

``` text
其使用可以创造超过其自身价值的价值。
```

## 14. 必要劳动与剩余劳动 \[M\]

``` text
T = T_N + T_S
```

-   `T_N`：必要劳动时间
-   `T_S`：剩余劳动时间

剩余价值：

``` text
s = 剩余价值
```

剩余价值率：

``` text
s/v = T_S/T_N
```

新创造价值：

``` text
V_new = v + s
```

## 15. 绝对与相对剩余价值 \[M\]

绝对：

``` text
T_N 不变
T_S ↑
```

相对：

``` text
T = constant
T_N ↓
T_S = T - T_N ↑
```

生产率提高可以降低必要劳动时间，从而在工作日不变时提高相对剩余劳动。

## 16. 生命论修正

\[L/A\]

不能写：

``` text
s > 0 ⇒ L < 0
```

因为剩余价值关系与生命异化不是同一变量。

应同时观察：

``` text
s
w_r
O_i
V_i
T_free
A_i
```

例如：

``` text
s ↑
w_r ↑
O_i ↑
T_free ↑
V_i ↑
```

不能简单判定生命能力下降。

生命论真正追问：

``` text
剩余如何被占有？
剩余如何反馈到生产者？
生产者的实际操作权是否扩大？
```

# 第四编：资本---积累---竞争

## 17. 资本 \[M\]

资本不是简单的钱、机器或财富，而是价值增殖运动：

``` text
M - C ... P ... C' - M'
```

其中：

``` text
M' = M + ΔM
```

在简化总量分析中：

``` text
ΔM = s
```

但个别企业利润不能简单等同于其直接生产的剩余价值，因为竞争会重新分配社会剩余价值。

## 18. 资本的伪自指 \[A\]

``` text
K_(t+1) = K_t + ρs_t - δK_t
```

-   `K_t`：资本存量
-   `ρ`：再投资比例
-   `s_t`：剩余价值
-   `δ`：折旧/损耗率

若：

``` text
ρs_t > δK_t
```

则：

``` text
K_(t+1) > K_t
```

形成：

``` text
K → 生产 → 剩余 → K' → 更多生产 → 更多剩余
```

形式上类似自指：

``` text
S = f(S)
```

但：

``` text
资本 ≠ 生命
```

资本依赖劳动、生产资料、制度、产权、能源、自然和社会组织。

因此生命论称：

``` text
资本 = 伪自指/派生自指结构
```

## 19. 自指转移

\[A/L\]

``` text
人的自指
→ 劳动
→ 剩余
→ 资本
→ 资本再生产
→ 反过来组织人的劳动
```

可能形成：

``` text
K ↑
V(S_i) ↓
```

即人的生产能力转化为支配人的社会力量。

## 20. 资本积累 ≠ 生命积累

资本：

``` text
s → K → 更多 s
```

生命：

``` text
O_t → 实践能力 → O_(t+1)
```

因此：

``` text
ΔK > 0
```

不能推出：

``` text
ΔV_self > 0
```

# 第五编：竞争、技术、利润

## 21. 竞争

\[M/A\]

资本之间竞争迫使：

``` text
生产率 ↑
成本 ↓
技术升级
劳动强度变化
资本退出/集中
```

因此：

``` text
个体资本家的道德意愿 ≠ 资本关系的结构压力
```

## 22. 市场价值、生产价格、平均利润

\[M\]

必须区分：

``` text
价值 ≠ 市场价格 ≠ 生产价格
```

资本跨部门竞争可以使利润率趋于平均化。

简化利润率：

``` text
p' = s/(c+v)
```

因此：

``` text
个别资本的利润 ≠ 该资本直接生产的剩余价值
```

社会总剩余价值可以通过竞争在不同部门资本之间重新分配。

## 23. 技术

\[M/A\]

劳动生产率：

``` text
P = Q/T
```

技术进步：

``` text
P ↑
→ T_SNL ↓
→ 单位商品价值可能 ↓
```

但：

``` text
Q ↑
```

可以同时发生。

因此：

``` text
单位价值下降 ≠ 社会财富下降
```

技术有两种可能方向：

``` text
技术 → 生产率 ↑ → 资本积累 → 劳动控制 ↑
```

或：

``` text
技术 → 必要劳动时间 ↓ → 工作时间 ↓
→ 自由时间 ↑ → 自指能力 ↑
```

所以：

``` text
技术本身 ≠ 解放
```

## 24. 资本集中与垄断

资本竞争可能导致：

``` text
资本集中 ↑
市场权力 ↑
进入壁垒 ↑
```

垄断应理解为对关键生产、交换、资源或信息入口的显著排他控制，而不是简单"企业很大"。

平台可能同时控制：

``` text
生产入口
交易入口
信息入口
规则入口
```

从而形成：

``` text
O_platform ↑
O_participant ↓
```

这是待经验检验的"平台化自指转移"。

\[A\]

``` text
E_i = 劳动者 i 从当前生产关系中退出或改变关系的有效能力
```



\[A\]

``` text
P⃗ = (P_pos, P_ctrl, P_use, P_surplus, P_exit)
```

``` text
国家能力 ↑ ≠ 人民操作权 ↑
```

## 31. 市场


优点：

局限：

``` text

```

## 32. 计划

计划反馈：

``` text

指标异化
目标替代
地方反馈不足
```

生命论评价不采用"市场/计划二选一"，而采用：

``` text
信息质量
+
反馈速度
+
操作权
+
纠错能力
+
社会目标
```

``` text
利润
```

表面形式：

``` text
M → M'
```

似乎货币自身增殖。

生命论必须指出：

``` text
货币自身并不是凭空创造新价值的生命。
```

``` text
未来剩余
生产收益
```

## 37. 金融化

\[A/?\]

金融活动不能整体视为寄生，应区分：

``` text
支付
信用
风险分散
生产融资
长期投资
```

与：

``` text
纯投机
高杠杆

```

可观察：

``` text
F_t / Y_t
```

``` text
F/Y ↑↑
```

# 第九编：危机

## 38. 危机的多机制模型

\[A\]

``` text
Crisis =
f(
过度积累,
实现问题,
利润率压力,
金融脆弱性,
需求,
技术变化,
生态约束,
制度反馈
)
```

不能把资本主义危机归结为单一原因。

## 39. 生命论危机定义

``` text
经济危机 =
生产、分配、再生产与反馈结构无法维持原有循环。
```

危机后的重组可能是：

``` text
资本重组：
危机 → 资本毁灭/集中 → 新一轮积累
```

或：

``` text
生命重组：
危机 → 恢复反馈 → 操作权重新分配 → 生命再生产恢复
```

因此：

``` text
资本循环恢复 ≠ 社会生命循环恢复
```

# 第十编：中国经验与历史压力测试

## 40. 历史方法

研究历史必须分四层：

``` text
事实
→ 因果解释
→ 理论映射
→ 规范判断
```

不能：

``` text
规范判断 → 反推事实
```

## 41. 毛时代与社会主义建设

重点研究：

``` text
国家组织能力
群众参与
反官僚主义
生产关系

工业化
```

1956--57年前后已存在关于国家、个人、民主与集中、领导与被领导、官僚主义等问题的讨论。

生命论不能只看群众动员强度，还要看：

``` text
日常操作权是否稳定沉淀。
```

## 42. 文化大革命

可以作为压力测试：

``` text
重新打开被官僚结构堵塞的反馈
```

同时必须研究：

``` text
身份化
敌我分类
组织失控
制度性反馈损坏
```

因此：

``` text
运动 ≠ 稳定自指
```


分别如何改变：

同时：

``` text

```

以及：

``` text
专业化
规模化
技术进步
```

之间的张力。


# 第十一编：两个世界与全球政治经济学

## 45. 两世界

\[L\]

两世界不以单纯地缘强弱划分，而以结构性关系：

``` text
谁从谁的劳动、资源与操作能力中获得系统性收益？
```

生命论应同时分析：

``` text
国家内部阶级关系
+
国家之间世界体系关系
```

且不把国家永久固定为单一标签。

## 46. 关系形式

\[A\]

``` text
W_S = {R_ij^self}
W_A = {R_ij^anti}
```

其中：

``` text
R_ij^self
```

表示关系扩大相关生命主体的实际操作能力；

``` text
R_ij^anti
```

表示一方通过系统性抽取另一方操作能力维持自身。

同一国家内部和国家之间均可能同时存在两种关系。

## 47. 世界自指

\[A\]

``` text
W = F({G_i}, R, E)
```

世界操作权：

``` text
O_W =
对世界生产、分配与规则的实际决定能力。
```

因此：

``` text
全球互联 ≠ 世界自指
世界统一 ≠ 世界自指
```

真正的世界自指要求参与者能够：

``` text
理解
影响
修改
```

全球生产与规则。

## 48. 两世界战略命题

\[L\]

``` text
先收回操作权（内）
→
再改变全球反自指结构（外）
```

这里的"外"主要指国际生产、金融、贸易、技术和制度关系的结构改变，而不是把理论简化为暴力扩张。

# 第十三编：核心统一模型

## 50. 四个循环

价值循环：

``` text
劳动 → 价值 → 剩余价值
```

资本循环：

``` text
剩余价值 → 资本 → 积累 → 更多剩余价值
```

生命循环：

``` text
劳动 → 生产 → 生活资料 → 生命再生产 → 劳动
```

自指循环：

``` text
操作权 → 实践能力 → 反馈 → 操作权
```

正常状态：

``` text
四个循环相互增强。
```

异化状态：

``` text
资本循环增强
而
生命循环/自指循环减弱。
```

# 第十五编：严格性与证伪原则

## 53. 公式等级

### Level 1：定义

``` text
O = O_p + O_o + O_s
```

### Level 2：形式推导

``` text
T = T_N + T_S
⇒
T_S = T - T_N
```

### Level 3：理论命题

``` text
资本积累可能形成自指转移。
```

### Level 4：经验命题

``` text
某制度必然降低人民操作权。
```

必须有历史/统计证据。

### Level 5：数学定理

必须：

``` text
定义
+
假设
+
证明
```

需要形式证明时，以 Coq 编译通过为更高标准。

## 54. 理论必须允许失败

如果现实出现：

``` text
生产率 ↑
工资 ↑
工作时间 ↓
O_people ↑
V_self ↑
```

而理论预测相反，则修改理论，而不是修改事实。

核心原则：

``` text
立场可以稳定，判断可以错误。
```

# 第十八编：一句话迁移摘要

``` text
生命论从“在感”出发，把生命理解为具有生产性自指能力的操作系统；政治关系的核心是操作权，经济关系则是这种操作权在劳动、生产、价值、剩余价值、资本、所有制、国家和世界体系中的物质化。马克思的价值—剩余价值—资本理论解释资本主义生产关系如何运转，生命论进一步追问这些关系如何改变生命主体的自指能力。资本可以形成类似自指的增殖循环，但不是独立生命，而是人的生产能力在特定社会关系中形成的派生结构。因此资本积累不等于生命积累，生产力增长不等于生产者操作权增长，国家能力增长不等于人民自指能力增长，收入增长也不等于自由增长。生命论政治经济学的最终判据，是社会生产能力是否转化为普通生命主体实际的操作能力、自由时间、反馈能力和自指能力；革命的长期成功也因此不能仅由政权更替判断，而必须由操作权是否真正回到生命主体来判断。
```
