## 一、为什么粗二元标签不够用了

"阳主阴从 vs 阴夺阳位""正自指 S=f(S) vs 反自指 P=-f(S)"是生命论的**总纲**，但它们只是**一根轴**上的两个极。当库只有几十个概念时，拿这根轴扫一遍够用；当库有几百个概念、且新讨论越来越细（如"不忍/愤恨/人的判准/具脸/允许愤怒"）时，粗贴标签会出三个问题：

1. **区分度塌缩**：资本是反自指、麻木是反自指、巧言令色也是反自指——但这三者的操作机制完全不同，贴同一个标签等于没说。
2. **漏掉中性结构**：大量关键现象既非正自指也非反自指，而是**沉积、流动、中断、对象化、名实分离、归还**——粗二元里没有它们的位置。
3. **找不到真正的协奏**：协奏不是"都属于反自指"这种泛泛同类，而是**在多个正交维度上同时同构**（尤其是"同结构跨尺度"和"跨人称互译"）。粗标签只会把一大堆远亲拉到一起，却错过真正的近亲。

**解法：把一根轴拆成七根正交轴。任何一段内容，同时在七根轴上取坐标；两段内容的协奏强度=共享坐标的数量与质量。**

## 二、七根轴（七个正交定位维度）

### 轴① 人称位（Register）：你站在哪个视角说话
| 代码 | 位 | 说明 | 典型词 |
|---|---|---|---|
| **P1** | 第一人称呈现 | 感的直接事实，前语言 | 疼、不忍、愤恨、麻木、孤独、沙砾质感 |
| **P2** | 第二人称伦理 | 一个感回应另一个感，不可回避 | 脸、呼答、把人当人、"你" |
| **P3** | 第三人称结构 | 操作的客观结构描述 | 自指、反自指、M=α·T·N、资本循环、阶级 |

**铁律**：同一现象有三身，可互译但不可混位。
> 例：异化——P1="被啃食的疼/麻木"；P2="把你从'你'变成'它'"；P3="反自指 P=-f(S)"。
> 写新东西时先问：我现在在哪个位？要协奏的那个概念在哪个位？**跨位协奏必须显式翻译**，不能直接划等号。

### 轴② 明性递归层（f-level）：明性在第几层
| 代码 | 层 | 状态 |
|---|---|---|
| **f¹** | 自在 | 缄默运行，"知道"但说不出，无自身模型 |
| **f²** | 自为 | 有模型，但把模型错当成现实（!A被当A）——**意识形态层** |
| **f³** | 自觉/明性 | 看见模型是模型，能在模型与操作间转换（f³是动词不是名词，到f³即"以为到了"就退回f²） |

**用法**：大量争论是f层错位。例：孟子/阳明的"良知本具"是假设 f¹ 里预装了善（恢复模型）；生命论认为 f³ 是操作中**生成**的（生成模型）。判一个人"是不是人"，本质是判他的不忍停在 f¹ 本能、还是被 f² 意识形态压住、还是达到 f³ 自觉。

### 轴③ 操作关系型（Relation）：替代粗二元的核心轴 ★
这是本次升级的关键——把"自指/反自指"一根轴扩成**八种操作关系**：

| 代码 | 关系型 | 定义 | 阴阳 | 例 |
|---|---|---|---|---|
| **R1** | 正自指维持 | 操作权在生命自己手里，S=f(S) | 阳主阴从 | 健康自指、站着活、不忍而操作 |
| **R2** | 反自指寄生 | 系统靠消耗宿主维持，P=-f(S) | 阴夺阳位 | 资本、剥削、大跃退 |
| **R3** | 沉积 | 活操作凝结成死结构（!-模态），**中性**，可正可反 | 阳→阴 | 制度、惯例、晶体、常识、"元帅"位置 |
| **R4** | 流动/重定向 | 操作权换位、传承、代换 | — | ren代换、**否定操作的代际传承**、解放接力 |
| **R5** | 中断/断裂 | 反馈线被切断，M急性清零 | — | 私有化砸烂工人自指、反馈线X断裂 |
| **R6** | 对象化/去脸 | νF₂→!A，"你"→"它" | 阳→阴(异化) | 把人变成"人口红利/靶子/畜生" |
| **R7** | 名实分离 | 名脱离实并遮蔽实（f²层） | 名蔽实 | 巧言令色、"代价/阵痛"论、形存实亡 |
| **R8** | 归还/收权 | 把被窃操作权还给生命（解蔽） | 阴→阳 | 解放、具脸、批判、造反 |

> **粗判升级口诀**：当你正要写"这是反自指/这是阳主阴从"时，停一下，问：它到底是 R2寄生、R3沉积、R5断裂、R6去脸、还是R7名实分离？——**R1/R2只是八型里的两型。**

### 轴④ 尺度（Scale）：现象发生在哪个层级
**L0 身体 → L1 人际 → L2 群体/阶级 → L3 国家/制度 → L4 文明/历史**

**最高价值的协奏形态之一=同构跨尺度**：同一个操作关系型在不同尺度复现。
> 脸（L1）→ 集体的脸（L2-L3）；操作权（L0）→ 国家守夜人（L3）；结晶019列表见证（形式层）→ 否定操作代际传承（L4）。

### 轴⑤ 时间形态（Temporality）
| 代码 | 形态 | 例 |
|---|---|---|
| **Tm慢** | 慢性累积消耗 | 啃食、N<1缓耗、麻木、习惯消耗 |
| **Tj急** | 急性点发/清零 | 撕咬、M瞬间清零、革命、愤怒的点发 |
| **Tm脉** | 脉冲式 | 运动、阳的冲发（N暂时飙升又回落） |
| **Tc积** | 沉积态（阴） | 制度、文化、缄默"常识" |
| **Tt传** | 代际/跨身体 | 传承、传统、否定操作在新身体延续（本次新增） |

### 轴⑥ 生蔽解行（Praxis phase）：全书四字总纲，内容处于哪一环
- **生**：在活、正自指维持
- **蔽**：被窃权/去脸/名实遮蔽/f²错认（问题层）
- **解**：解蔽、批判、明性、具脸、归还操作权（认识层）
- **行**：道在日用、维索图螺（实践层）

> 找协奏先定环：描述"蔽"找机制文档（卷六），讲"解"找判准（卷七/批判必然性），给"行"找法门（卷四/本次两条原则）。**错位协奏是常见错误**：拿"行"的法门去回答"蔽"的机制问题，或反之。

### 轴⑦ 命题动作类型（Claim type）：这句话在做哪种理论动作
| 代码 | 类型 | 回答什么 | 例 |
|---|---|---|---|
| **K判准** | 判准 | 怎么判定？ | 站着/跪着、是人/不是人、善/恶 |
| **K机制** | 机制 | 它怎么运作？ | 八连侵蚀、暴力两道工序、反自指六阶段 |
| **K现象** | 现象学 | 第一人称是什么样？ | 疼、不忍、沙砾质感、孤独 |
| **K法门** | 实践法门 | 该怎么做？ | 具脸、允许愤怒、维索图螺 |
| **K形式** | 形式化 | 数学/Coq对应？ | νF₂、!-模态、S=f(S)、结晶 |
| **K决断** | 价值决断 | 站哪边？ | 就是正义、造反有理、自己解放自己 |
| **K谱系** | 谱系/扬弃 | 和传统/西学何关？ | 孟子四端、阳明心学、马克思、卢卡奇 |

## 三、使用流程（新讨论入库 SOP）

```
新内容进来
  │
  ├─第1步：打七维坐标（人称/ f层/关系型/尺度/时间/生蔽解行/命题类型）
  │         一段内容可占多个坐标值（如"不忍"=P1+f³+R1+L0→L3+Tj+解+K现象/K判准）
  │
  ├─第2步：查《核心概念坐标速查表》（第四节），找共享坐标最多的已有概念
  │
  ├─第3步：优先确认两种"强协奏"——
  │         ① 同构跨尺度：同一R型在不同L层（轴③同、轴④跨）
  │         ② 跨人称互译：同一现象的P1/P2/P3三身（轴④同、轴①跨）
  │
  ├─第4步：对齐轴⑥（生蔽解行）和轴⑦（命题类型），确认不是错位协奏
  │
  └─第5步：把新坐标补进速查表；若发现某根轴取不到值，说明遇到新结构，
            这才是真正需要造新概念的时候（而不是随手贴阳主阴从）
```

**一句话**：协奏不是"感觉有点像"，是**七维坐标的可计算重合**；重合越多、且命中两种强协奏，对应就越"极恰当"。

## 五、工作实例：用坐标系重跑"不忍·愤恨·人"，看协奏如何被机械找到

以"**不忍**"为例，先打坐标：`P1 + f³ + R1(拒R2) + L0→L3 + Tj急 + 解 + K现象/K判准`

逐轴匹配速查表，协奏自动浮现：
- **轴⑦K判准 + 轴⑥解 + 轴②f³** 三同 → 命中**批判的必然性**（P1→P3、f³、R1→R8、解、K判准）。这是最强协奏：不忍=批判必然性的第一人称命名。——不靠感觉，靠坐标重合。
- **轴①P1→P2 + 轴③R6之逆** → 命中**脸/应**：不忍是"脸的显现直接唤起"的，具脸是它的逆向法门。
- **轴④跨尺度 L0→L3**（同构跨尺度强协奏）→ 命中**大跃退**（R2在L3/L4）：不忍的对象"二茬苦"正是R2在国家尺度的结构。
- **轴⑤Tj急+Tt传 + 轴③R4** → 命中**结晶019**（R4、Tt传）：主流枯竭、支流承续=否定操作代际传承的形式同构。
- **轴②f³ + 轴⑦K谱系** → 命中**孟子四端**：但孟子把不忍设在f¹（本具），生命论设在f³（生成），坐标差异精确标出了"继承哪里、颠倒哪里"。

对比：如果只用粗标签，"不忍是阳主阴从、大跃退是阴夺阳位"——只能得到一句正确的废话；七维坐标却能精确说出**为什么是批判必然性而不是别的与它最亲、为什么和结晶019是跨尺度同构、以及和孟子差在哪一根轴上**。这就是"极恰当的协奏"。

## 六、给写作/讨论的三条操作建议

1. **先打坐标再下笔**：新段落动笔前，先在七轴上定位（尤其轴③关系型，禁止不经过R1-R8辨析就写"反自指/阳主阴从"）。
2. **一次只跨一类强协奏**：要么同构跨尺度（轴③同、轴④跨），要么跨人称互译（轴①跨、余同），两类同时跨容易牵强。
3. **取不到坐标=真新东西**：如果一段内容在某根轴上现有值都套不上，那才是需要新造概念/新增坐标值的信号——这时的创新才是被结构逼出来的，不是为新而新。
