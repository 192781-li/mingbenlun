## 一、split_assoc（OB-015）：用choose_correct + 前缀引理，不用H23_val

### 1.1 已有武器（全部Qed，直接用）

- `split_assoc_cell`（line 2307）：逐位版，`cell_split g g12 g3 → cell_split g12 g1 g2 → exists g23, cell_split g g1 g23 ∧ cell_split g23 g2 g3`
- `choose`（line 2352）+ `choose_correct`（line 2359）：**确定性**逐位见证，不只是exists。choose在左-左格取g2，其余取g。
- `setby`/`get_setby_get`/`get_repeat_None_lt`：构造列表并读取逐位值。

### 1.2 关键数学洞察：见证的前缀连续性（必须先证这个引理）

定义逐位见证函数：
```coq
Definition w (G G12 G3 G1 G2 : ctx) (n : nat) : option (option ty) :=
  choose (get G n) (get G12 n) (get G3 n) (get G1 n) (get G2 n).
```

**引理（前缀连续性）**：在`split G G12 G3 ∧ split G12 G1 G2`下，若`w n = None`则`w (S n) = None`。
- 证明要点：w(n)=None有两种情形：
  - (a) 非左-左格且g=get G n=None（越界）。越界是粘性的：get G n=None → get G (S n)=None。在n+1，若非左-左格则w=g=None；若左-左格则w=g2，而g2=get G2，由H2在n的左-左格结构可推g2越界→w=None。
  - (b) 左-左格且g2=get G2 n=None（越界）。g2越界粘性→get G2(S n)=None。在n+1若仍左-左格则w=g2=None；若非左-左格则由g的越界传播推w=None。
- 这个引理保证：w为None的位置构成一个**后缀**，因此w可以被一个有限列表G23表示（长度=第一个None位置，之前逐位取unwrap(w)）。

### 1.3 证明脚本骨架（DS照抄，只填tactic细节）

```coq
Lemma split_assoc : forall G G12 G3 G1 G2,
  split G G12 G3 -> split G12 G1 G2 ->
  exists G23, split G G1 G23 /\ split G23 G2 G3.
Proof.
  intros G G12 G3 G1 G2 H1 H2.
  (* 第一步：证前缀连续性引理（内联或先单独Qed） *)
  assert (Hprefix : forall n,
    (choose (get G n)(get G12 n)(get G3 n)(get G1 n)(get G2 n) = None) ->
    (choose (get G (S n))(get G12 (S n))(get G3 (S n))(get G1 (S n))(get G2 (S n)) = None)).
  { intros n Hw. unfold choose in *. destruct (excluded_middle_informative _) in Hw;
    [ (* 左-左格：w=g2=None → g2越界粘性 *) destruct Hw as [Hg12 [Hg3 [Hg1 Hg2]]];
      subst; simpl in *; ...
    | (* 非左-左格：w=g=None → g越界粘性 *) ...
    ] }
  (* 第二步：找第一个None位置K（用L作为上界，n≥L时所有get=None→w=None） *)
  set (L := length G + length G12 + length G3 + length G1 + length G2).
  assert (HnoneL : w ... at L = None). { ... all gets None, choose returns None ... }
  (* 用well-founded或直接找最小K≤L使w(K)=None *)
  ...
  (* 第三步：构造G23 = setby f (repeat None K) 0，f n _ = match w(n) with Some t => t | None => None end *)
  (* 第四步：分n<K和n≥K证明两个split *)
  - n<K: w(n)=Some t, get G23 n = Some t = w(n), apply choose_correct.
  - n≥K: w(n)=None, get G23 n = None(越界), apply choose_correct with g23=None.
Qed.
```

### 1.4 备选更简单路线（如果前缀引理证起来太繁）

**对G做结构归纳**，不做逐位提升：
- G=g::G'：destruct四个上下文的头，用split_assoc_cell在位置0得到头元素g23_hd，用split_tl引理（`split A B C → split (tl A)(tl B)(tl C)`，需先证）在尾部应用IH，G23 = g23_hd :: G23_tail。
- G=[]：这是难点。此时H1: split [] G12 G3。可对G12做内层归纳，或直接取G23=G2当G3全越界、取[]当G2全越界，其余情形由split_assoc_cell逐位+有限列表构造。
- **推荐先走这条归纳路线**，因为它天然处理列表长度，不需要前缀引理。16个destruct case中H1在位置0会排除掉大部分，实际只有4-5个有效case。

## 二、weaken_none_head（OB-016）：简单引理，DS过度复杂化了

### 2.1 引理陈述
```coq
Lemma weaken_none_head : forall Gamma' P T,
  typed (None :: Gamma') P -> typed (Some T :: Gamma') P.
```

### 2.2 证明策略：对typed归纳，8个case，不要用ren_id（DS踩的坑）

**核心洞察**：头位置None意味着进程P不使用位置0的资源（否则use要求Some(Some _)，矛盾）。所以把头换成Some T不影响类型化。

```coq
Proof.
  intros Gamma' P T Hty. induction Hty.
  - ty_zero: constructor.
  - ty_var: 变量x若=0则use不可能（get (None::Gamma') 0 = Some None ≠ Some(Some _)），矛盾；若x=S n则get在两个上下文中相同，constructor.
  - ty_tau: 类似ty_var.
  - ty_out: use Gamma x T Gamma1。若x=0则use在None头不成立（destruct Huse，get None头=Some None，矛盾）；若x=S n则use平移到Some T头的S n位置，constructor + apply IHHty.
  - ty_in: 同ty_out处理use.
  - ty_par: split (None::Gamma') G1 G2。头None被分到G1或G2的头（都是None），分别apply IHHty1/IHHty2，再ty_par.
  - ty_res: 偏移到S 0，递归弱化，constructor + IHHty.
  - ty_rep: 类似.
Qed.
```

**DS的具体错误**：它试图用`rewrite IHP`（IHP是`ren id P = P`），方向反了。**根本不需要ren_id**，直接induction Hty，每个case用constructor + IH即可。

### 2.3 给DS的派活指令
```
目标：weaken_none_head Qed。
路线：induction Hty，8 case，逐案constructor+IH。
禁用：ren_id、rewrite方向猜测。
ty_out/ty_in的use位置0矛盾处理：destruct Huse; simpl in *; [discriminate | ...].
2轮不收敛停。
```
