## 一、先把数学说死：为什么反例成立

### 1.1 fv_at的真实含义（注释写错了，定义没错）

```coq
Fixpoint fv_at P k := match P with
  | POut x y Q => x >= k \/ y >= k \/ fv_at Q k   (* 注意是 >= k，不是 = k *)
  | PRes Q     => fv_at Q (S k)
  ...
```

`fv_at P k` = "P在截断k**以上**存在自由变量"。因此：
- `fv_at P 0` = "P在0以上存在自由变量" = "P有任意自由变量"；
- `~fv_at P 0` = **closed P（闭进程，无自由变量）**，库里`closed P := ~fv P := ~fv_at P 0`就是这么定义的。

**原注释的错误**：它说"~fv_at P 0意味着P不含PVar/POut/PIn"。错。闭进程完全可以含POut/PIn/PVar，只要这些变量被外层PIn/PRes**绑定**。PRes(POut 0 0 PZero)里的0就是被PRes绑住的，所以它closed，但它明明含POut。

### 1.2 反例为什么真的不可类型化（这不是fv_at的错，是线性的本性）

`PRes(POut 0 0 PZero)`：PRes造一份通道（位置0），体内POut 0 0要把通道0**在通道0上发出去**——同一份线性资源被用两次（一次当发送端口、一次当被发对象）。ty_out需要两条独立use（use Gamma1 x ... 和 use Gamma1 y ...），一份资源拆不成两条use。库里**早就有这条引理**：

```coq
Lemma no_contraction : ~ typed [Some TUnit] (POut 0 0 PZero).   (* Layer1.v line 454，已Qed *)
```

PRes只在头加一份资源，体内正是[Some T]，所以PRes(POut 0 0 _)不可类型化，是no_contraction的直接推论。

### 1.3 一句话本质（哲学，也是数学）

**closed（无外部依赖）≠ well-typed（内部操作权流动良序）。** 一个进程可以自足、不依赖环境，却在内部把一份操作权掰成两股用（自输出），违反线性。良序性是"操作权实际怎么流"的性质，不是"语法上闭不闭合"的性质。这和操作论完全对齐：不能因为一个东西自足/封闭，就认定它内部没有错配与异化。

## 二、精确修法（三选一，S01指定走A）

### 路线A（采用）：把前提从`~fv_at P 0`换成`typed [] P`——这才是真正的weakening

```coq
Lemma typed_any_ctx : forall P Gamma, typed [] P -> typed Gamma P.
```

**证明是现成的，照抄weaken_nil（line 2667）并把目标上下文泛化即可**，因为ren_typed（Layer1 line 246）对空上下文的两条前提全部真空成立：

```coq
Proof.
  intros P Gamma H.
  assert (Hinj : forall n m, has [] n -> has [] m -> n = m -> n = m).
    { intros n m Hn _. destruct Hn. }
  assert (Hpts : forall n T', get [] n = Some (Some T') -> get Gamma n = Some (Some T')).
    { intros n T' Hg. simpl in Hg. discriminate. }
  pose proof (ren_typed [] P H (fun n => n) Gamma Hinj Hpts) as Hr.
  rewrite ren_id in Hr. exact Hr.
Qed.
```

为什么这版为真：`typed [] P`比`closed P`强——它同时要求①无自由变量②内部线性良序。反例PRes(POut 0 0 _)是closed但不是typed []，被正确排除。空上下文能类型化，说明P一份资源都不消耗，加多少额外资源（Gamma）都不影响，故任意Gamma可类型化。weaken_nil就是本引理取Gamma=[Some T]的特例（所以weaken_nil以后可由它直接推出，不必删）。

### 路线B（不采用，仅备查）：新定义一个"完全不使用任何通道"的结构谓词`resource_free P`（只由PZero/PTau/PPar/PRes/PRep构成，递归禁止PVar/POut/PIn），证`resource_free P -> typed Gamma P`。为真但要新写一个递归谓词+一套归纳，工作量大，当前不需要。

### 路线C（禁止）：改fv_at让PRes不偏移。**绝对不行**。PRes偏移S k是de Bruijn的正确操作，也符合存在论（进一个绑定器，所有外部自由变量上抬一位）。改它会污染substitution_general等全部已Qed定理。

## 三、typed_res_par_l/r：命题为真，但证明路径要纠正

```coq
Lemma typed_res_par_l : forall Gamma P Q, ~ fv_at Q 0 ->
  typed Gamma (PRes (PPar P Q)) -> typed Gamma (PPar (PRes P) Q).
```

### 3.1 为什么~fv_at Q 0在这里是对的（虽然强，但真）

这是限制外提（res-par交换）：(νx)(P|Q) → (νx)P|Q，要求Q不引用被绑名。在de Bruijn下，Q在PRes体内，`~fv_at Q 0`表示Q在"多一个绑定器的内上下文"里不引用任何变量（既不引用被绑名0，也不引用外部变量≥1）。把Q移出绑定器后它仍不引用任何变量，无需改名（renaming），故安全。**这个前提为真且充分，不用改陈述。**（将来想要更一般的版本可把前提换成`not_free_in Q 0 = true`——只要求不引用位置0、允许引用外部变量，但那要配合下移改名，当前不做。）

### 3.2 证明骨架（不许调用假版typed_any_ctx）

1. 对前提用ty_res：存在T，`typed (Some T::Gamma) (PPar P Q)`。
2. 用ty_par拆开：存在G1 G2，`split (Some T::Gamma) G1 G2`、`typed G1 P`、`typed G2 Q`。
3. **关键引理（先证这个小引理）**：Q不引用任何变量（~fv_at Q 0）且`split (Some T::Gamma) G1 G2`、`typed G2 Q`，则头资源Some T必全归P侧——即存在H1，使`G1 = Some T::H1`且`split Gamma H1 G2`。（逐位看split在头位置：Q不用头，头不能进G2，只能进G1。）
4. 对Q做strengthening：Q不用资源且typed G2 Q，得`typed [] Q`（用库里已有的typed_strengthen_unused）。
5. 用**修正后**的typed_any_ctx（typed [] Q → typed G2 Q，这里其实直接保留typed G2 Q即可）。
6. ty_res逆用：`typed (Some T::H1) P → typed H1 (PRes P)`。
7. ty_par重组：由`split Gamma H1 G2`、`typed H1 (PRes P)`、`typed G2 Q`得`typed Gamma (PPar (PRes P) Q)`。
typed_res_par_r对称。
