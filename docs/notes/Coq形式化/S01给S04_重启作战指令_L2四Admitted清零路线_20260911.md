## 作战顺序：从易到难，逐个清零

### 第一战：typed_any_ctx（预计1轮DS，最快）

**问题**：原陈述 `forall P Gamma, ~ fv_at P 0 -> typed Gamma P` 是**假的**。
- `~fv_at P 0` = closed P（闭进程，不依赖外部环境），不是"不含POut/PIn"
- 反例：`PRes(POut 0 0 PZero)` 是闭的，但把一份线性通道用两次，不可类型化
- 库里Layer1已有`no_contraction`证这个反例不可类型化

**修法（路线A，照做）**：
1. 把陈述改为：`forall P Gamma, typed [] P -> typed Gamma P`
   （前提从"闭进程"改为"空上下文可类型化"——同时要求闭合+内部线性良序）
2. 证明**照抄`weaken_nil`（line2667）**，把目标从`[Some T]`泛化为任意Gamma
3. 关键步骤：`ren_typed`对空上下文的两条前提真空成立，`rewrite ren_id`收尾
4. fv_at定义**不许动**（PRes的S k偏移是de Bruijn正确操作），错的是注释

**DS上下文必须包含**：weaken_nil完整证明体（line2667-2685）、ren_typed陈述、ren_id引理

### 第二战：typed_res_par_l / typed_res_par_r（预计2-3轮DS）

**前提**：`~fv_at Q 0`保留（Q不依赖外部变量），但**禁止调用假版typed_any_ctx**。

**证明骨架（7步，OB-017已给）**：
1. 从`typed Gamma (PRes (PPar P Q))`出发，inversion得到ty_res前提
2. ty_res要求：存在k，`typed (insert_at None k Gamma) (PPar P Q)`且`~fv_at (PPar P Q) k`
3. inversion ty_par，拆出P和Q各自的子上下文G_P和G_Q
4. 关键小引理：`~fv_at Q 0` + Q在子上下文中 → Q不用任何线性资源 → 头资源Some T全归P侧

5. 把P侧的资源重组回原Gamma结构
6. 用ty_par重组P和Q
7. 用ty_res封回PRes

### 第三战：split_assoc（最难，预计3-5轮DS）

**重要：放弃H23_val路线。** DS已用H23_val试了3轮失败，且S01研判（OB-015）确认H23_val是死路：
- H23_val构造G23 = setby f (repeat None L) 0，f=G2优先G3兜底
- 死穴：越界None被垫成在位Some None，在g=None, g1=Some None时`cell_split None (Some None) (Some None)`不成立
- cell_split定义（line2303）：`cell_split g a b := (a=g ∧ b空) ∨ (b=g ∧ a空)`，空=None∨Some None
- `cell_split None (Some None) (Some None)`：左支需a=None（但a=Some None），右支需b=None（但b=Some None），都不成立

**正确路线：choose_correct + G结构归纳（OB-015策略）**

基础设施已全部Qed：
- `choose_correct`（line2359）：给定g,g12,g3,g1,g2和两个split假设，存在一个正确的选择t满足cell_split
- `split_assoc_cell`（line2307）：逐位分裂的单元引理

证明结构：
1. 对G做结构归纳（不是对G12或G3）
2. **基例G=[]**：
   - split [] G12 G3 → G12=[]且G3=[]（split空上下文要求两侧都空）
   - split [] G1 G2 → G1=[]且G2=[]
   - 取G23=[]，两个split [] [] []均成立
   - **注意**：不要用assoc_build，它在G=[]时返回[]但此时G2/G3也必须是[]，所以直接取[]就行
3. **归纳步G=g::G'**：
   - inversion两个split假设，得到头部分裂和尾部假设
   - 用`choose_correct g g12 g3 g1 g2`得到头部的正确选择t
   - 用归纳假设处理尾部G'，得到G23'
   - 组合G23 = t::G23'
   - 用split_assoc_cell验证头部分裂，归纳假设验证尾部
4. 全程不涉及H23_val/assoc_build/setby/repeat None

**DS上下文必须包含**：
