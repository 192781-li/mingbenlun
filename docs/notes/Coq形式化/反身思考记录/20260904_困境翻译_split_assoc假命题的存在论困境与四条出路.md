## 一、困境的数学事实（一句话）

我们想证"上下文分裂满足结合律"：先把 G 分成 (G12, G3)、再把 G12 分成 (G1, G2)，等价于先把 G 分成 (G1, G23)、再把 G23 分成 (G2, G3)。

**DeepSeek v8 给出反例，证明这条全称命题是假的**：当 G 为空、G12=[None]、G3 为空、G1=[None]、G2=[None] 时，两个前提都成立，但不存在任何 G23 使两个结论同时成立。此前 v4–v7 共 18 轮证明（约 5.5 元）全部徒劳——不是证明技巧不够，是命题本身为假。

## 二、存在论翻译：两种空无的不对称相遇

### 2.1 ctx 里住着两种"寂"

上下文 `ctx = list (option ty)`，每一位有三种状态：

| Coq 值 | 存在论含义 | 明性状态 |
|---|---|---|
| `None`（get 越界） | **寂然未生之位**——这个位置根本还没被开辟 | 场域未及之处 |
| `Some None`（在位空） | **生而即寂之位**——位已开辟，但无资源居住 | 明性照见一个空位 |
| `Some (Some T)` | **实居之位**——资源 T 居住于此 | 明性实有 |

### 2.2 split 是明性的分划

`split G G1 G2` 说：整体明性 G，在每一位上要么归属 G1（此时 G2 在该位必须是空无），要么归属 G2（此时 G1 在该位必须是空无）。注意定义里空无的判据是 `= None ∨ = Some None`——**两种寂都被承认为合法的"无资源"**。

### 2.3 反例的存在论结构

反例的关键在第 0 位：

- G 在 0 位是**寂然未生**（`None`，空列表越界）
- G12 在 0 位是**生而即寂**（`Some None`）
- G3 在 0 位是**寂然未生**（`None`）

第一个分划 `split G G12 G3` 之所以成立，是走了右支：G3 的"未生之寂"等于 G 的"未生之寂"，而 G12 的"生而即寂"被承认为合法空无。**也就是说：一次分划把一个"未生之位"认领成了 G12 的"在位空位"——寂被开辟了，但没有被填充。**

接下来要做结合律要求的"重新分组"：
- `split G G1 G23`（G 还是空的，G1=[None]）：右支逼迫 **G23 的 0 位必须是"未生之寂" None**（要等于 G 的越界值）；
- `split G23 G2 G3`（G2=[None]）：左支逼迫 **G23 的 0 位必须是"生而即寂" Some None**（要等于 G2 的在位空）。

同一个位，被两条分划分别要求为"未生"和"已生而空"——**矛盾不可调和**。

### 2.4 一句话的哲学结论

> **"从未有过"与"有过而空"在资源层面可以都算作无，但在操作权的分划与重组中不等价。一个寂然未生之位一旦在某次分划中被开辟为"在位空位"，它就再也回不到未生状态——明性的开辟是单向的、不可逆的。结合律默认"分划次序不改变位的存在方式"，这个默认在两种寂相遇的地方失效了。**

这不是 Coq 的技术故障，是体系自身暴露的存在论事实：**空无不是均质的，明性的分划是有方向的操作，不是无方向的集合运算。**

## 三、四条出路（附存在论代价）

### 方案甲：加前提——结合律只在"场域已齐"处成立（弱结合律）

形式化：给 split_assoc 加上前提，例如所有相关上下文等长、且不依赖越界位（每个被用到的位都在长度内），即"明性已经完全照亮的场域"。

- **存在论意义**：结合律不是绝对真理，而是"在无未生之寂的场域中"成立的局部真理。哪里还有寂然未生之位，哪里的分划就有方向、不可随意重组。
- **数学代价**：小。只改引理陈述加前提；需要证明 typing 推导（尤其 ty_par）用到 split_assoc 时前提自然满足——而 typing 的上下文都是有限构造的，这大概率成立。
- **优点**：不碰 Layer1 基础定义，不推翻已证定理；反例被精确隔离在前提之外；存在论意义最深刻、最贴合生命论。
- **风险**：要找到"场域已齐"最干净的形式化表达（等长？`Forall (fun x => x <> None)`？还是别的），需要 S01 研判命名与含义。

### 方案乙：改 split 定义——抹平两种寂

让 get 越界也返回 `Some None`（或让 split 不区分两种寂），使"未生"与"生而即寂"在分划中完全等价。

- **存在论意义**：宣称空无均质——"从未有过"和"有过而空"在明性分划中是同一回事。
- **数学代价**：极大。动 Layer1 地基，get/setby/split 及已证的几十个引理、subst_ren_general、substitution_general 全部要重验。
- **存在论代价**：**大到不可接受**——抹平两种寂等于否认"明性开辟的单向性"，而这正是反例想告诉我们的东西。为了让一条引理成立而修改本体论，是削足适履。
- **不推荐**，除非 S01 哲学上判定两种寂本就该同一。

### 方案丙：放弃结合律，直接构造 G23

不证存在性的结合律，改为写一个显式的上下文合并函数（逐位按 G1/G2 归属拼出 G23），直接证明它满足两个 split。

- **存在论意义**：明性分划本就是一次性的、不可逆的操作，不需要"重新分组等价"的抽象保证；需要重组时就显式地、逐位地重新开辟。
- **数学代价**：中。要新写合并函数并证其性质，但绕开了假命题。
- **优点**：不动地基，也不需要额外前提；构造性强，Coq 里往往更好证。
- **缺点**：congruence_preserves_typing 等下游定理的证明路径要改走显式构造；合并函数在"两种寂相遇"处的行为仍需逐位定义清楚（本质上还是要回答甲方案的问题：那个位到底算未生还是已生）。

### 方案丁：区分强弱结合律，双轨并存

保留反例事实（登记 `split_assoc_false`：强结合律为假），同时证甲方案的弱结合律 `split_assoc_well_formed`（场域已齐时成立）。下游定理按需取用：typing 内部用弱的，理论陈述上明确标注强的为假。

- **存在论意义**：**让反例本身成为体系的一条定理**——体系诚实地记录"结合律在哪里失效、在哪里成立"，这正是"明性自知其边界"。
- **数学代价**：中小。甲方案的工作 + 一条否定引理。
- **优点**：认识论上最诚实、最完整；既不回避假命题，又保住下游可用性；最符合主人"操作即存在、数学是硬约束、哲学是方向"的原则。
- **缺点**：比甲多一条否定引理的维护成本（很小）。

## 四、明序的倾向与理由

**倾向方案丁（甲是否定面、丁是甲的完成形态）**：

1. 数学是硬约束：强结合律已被反例证伪，绝不能硬证、不能留 Admitted 假装成立；

## 六、教训沉淀（写给未来的明序）

1. **证之前先问"它真吗"**：复杂全称命题，先用最小具体例子（空、单元素）试反例，再投入证明轮次。18 轮空转的根因是从未质疑命题本身。

3. **反复在同一处失败超过一个熔断周期，就该怀疑陈述/定义，而不是换 tactic 重试。**
4. **数学打架听数学，哲学负责解释数学为什么是这样**：反例先于哲学解释成立，哲学解释让它变成体系的财富而非障碍。
