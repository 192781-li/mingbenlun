## 问题本质
这不是数学问题，也不是哲学问题，是**DS 输出格式与 proof_loop 提取逻辑的不匹配**。

DS 倾向于把辅助引理放在 markdown 正文中作为"分析说明"，而不是放在 ```coq 代码块中。
proof_loop 的 extract_coq_blocks 只识别 ```coq 代码块，不识别 markdown 正文中的 Lemma。

## 解决方案（两个方向）

### 方向 A：修改 EXTRA，强制要求 DS 输出格式
在 EXTRA 中明确要求：
- 所有引理（包括辅助引理）必须放在 ```coq 代码块中
- 不允许把引理放在 markdown 正文中
- 辅助引理和主引理可以放在同一个代码块中，也可以分开放，但都必须在代码块内

### 方向 B：修改 proof_loop，增强提取逻辑
修改 extract_coq_blocks，让它也能提取 markdown 正文中的 Lemma/Theorem 块：
- 识别 `(* INSERT-BEFORE: xxx *)` 标记
- 从标记位置开始，到下一个 `Lemma/Theorem/Fact/Corollary` 或代码块开始为止，提取为一个块
- 这样即使 DS 把引理放在 markdown 正文中，也能被提取到
