## 一、成功了什么

**PRes case证明通过！** 这是substitution_general中最难的case，之前6种方法全部失败，现在终于证明通过了。

证明策略：
1. **修改证明结构**：用`generalize dependent Gamma T k m`在induction之前generalize，让IHQ成为`forall m k T Gamma, ...`的形式，可以接受不同的Gamma/k/m参数
2. **用res_elim引理，不用inversion**：`apply res_elim in Ht. destruct Ht as [T0 H1].`直接得到T0和H1，Gamma自然保留，没有inversion的等式替换问题
3. **用insert_at_cons_comm重写**：把`Some T0 :: insert_at k T Gamma`变成`insert_at (S k) T (Some T0 :: Gamma)`，恢复IHQ需要的形式
4. **用IHQ的forall形式**：`IHQ (S m) (S k) T (Some T0 :: Gamma) H1 Hget'`，明确指定所有参数

## 二、失败了什么（之前的6次失败）

1. `inversion Ht; subst.`：Gamma变量被替换（等式方向问题）
2. `remember (insert_at k T Gamma) as Gamma'`：仍报错Gamma不在上下文
3. `inversion Ht as [...]`：需要8个分支，模式不对
4. `apply res_elim in Ht`：Gamma仍然消失（因为IHQ不是forall形式，无法指定不同的Gamma）
5. `pose proof (res_elim ...)`：报错变量P不存在
6. OB-008第一轮策略（res_elim→rewrite insert_at_cons_comm→IHQ）：insert_at_cons_comm证明通过，但apply IHQ时报错"No such bound variable Gamma"（因为IHQ不是forall形式）

## 三、策略为什么调整

**根本原因不是inversion的问题，而是证明结构的问题！**

之前的证明结构是：
```coq
intros Gamma T k m Q.
induction Q; intros Ht Hget.
```

这样IHQ的类型是：
```coq
IHQ : typed (insert_at k T Gamma) P -> get Gamma m = Some (Some T) -> typed Gamma (subst_var m k P)
```

Gamma, k, m都是固定的（上下文中的变量），不能改变。所以在PRes case中，当需要用不同的Gamma（Some T0 :: Gamma）、k（S k）、m（S m）调用IHQ时，就失败了。

**解决方案**：修改证明结构，用`generalize dependent`让IHQ成为forall形式：
```coq
intros Gamma T k m Q.
generalize dependent Gamma.
generalize dependent T.
generalize dependent k.
generalize dependent m.
induction Q; intros m k T Gamma Ht Hget.
```

这样IHQ的类型是：
```coq
IHQ : forall m k T Gamma, typed (insert_at k T Gamma) P -> get Gamma m = Some (Some T) -> typed Gamma (subst_var m k P)
```

可以接受不同的m, k, T, Gamma参数！

## 五、哲学判断点

**证明结构的存在论意义**：

之前的证明结构中，Gamma, k, m是"固定的"——它们在induction之前就被引入了，所以在整个证明过程中不能改变。这对应于"操作权分布是固定的，代换不能改变世界"。

但实际上，代换是**世界相关的**——进入PRes绑定器后，世界扩展了（Some T0 :: Gamma），代换参数也偏移了（S k, S m）。所以证明结构必须允许Gamma, k, m改变，这就是为什么需要generalize dependent。

**这对应于悟道书的第六关：绑定器是新世界的入口。进入PRes内部进入新作用域，所有旧操作权位置后移一位，代换参数必须跟着变（S m, S k）。**

证明结构必须反映这个存在论事实：代换不是在一个固定的世界中进行的，而是在不断扩展的世界中进行的。
