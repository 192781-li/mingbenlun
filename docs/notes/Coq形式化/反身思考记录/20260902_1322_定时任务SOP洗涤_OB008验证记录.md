## 三、OB-008验证记录

### 3.1 S01的OB-008研判内容

S01对PRes case的Gamma变量替换问题做了深入研判：
- **核心引理**：insert_at_cons_comm：`Some T' :: insert_at k T Gamma = insert_at (S k) T (Some T' :: Gamma)`
- **证明策略**：res_elim → rewrite insert_at_cons_comm → IHQ(参数S m, S k)
- **哲学分析**：绑定器创建了新的局部世界，代换在绑定器下的索引偏移，insert_at和(::)是可交换的操作

### 3.2 验证结果

1. **insert_at_cons_comm引理**：✅ 证明通过
   - 对k归纳，k=0时simpl reflexivity
   - k=S k'时，对Gamma做destruct，simpl reflexivity
   - 关键发现：simpl后两边完全相等，不需要IHk

2. **PRes case应用**：❌ 仍遇Gamma变量问题
   - `apply res_elim in Ht`后，Gamma变量从上下文消失
   - `rewrite insert_at_cons_comm in Hq`成功，但后续`apply IHQ with (Gamma := Some T' :: Gamma)`报错"No such bound variable Gamma"
   - 这是第6种失败的方法

### 3.3 问题分析

`apply res_elim in Ht`可能有副作用：res_elim的Gamma参数和上下文中的Gamma变量同名，导致apply in时Coq把上下文中的Gamma也替换了。

**下一步策略**：
1. 不用`apply res_elim in Ht`，改用`pose proof (res_elim ...)`但需要明确变量名
2. 或者换对Ht归纳（typed关系归纳），避免对Q归纳的变量名问题
3. 或者记录为OB-009，派给S01做更深入的研判
