# S01给S04：L3–L8哲学预判总纲与证明强度渐进策略

> **用途**：S04每进入新一层前，先读本文件对应章节。哲学倾向、证明强度、可能的坑都已预判，不用从零摸索。
> **核心策略**：从低强度证到高强度，能证高就证高，强版本暂时证不出来就先证弱版本占位，不卡壳。

## 〇、证明强度分级标准（统一口径）

| 级别 | 含义 | 典型形式 | 哲学含量 |
|---|---|---|---|
| **L0 定义性** | 命题由定义直接成立，几乎不需要证明 | "我们的系统里没有这条规则" | 低 |
| **L1 存在性/不存在性** | 存在/不存在某个操作、项、归约序列 | `exists P, ...` / `~(exists P, ...)` | 中 |
| **L2 矛盾性** | 假设某命题成立会导致系统不一致（可证False）或破坏元性质（subject reduction/progress） | `P -> False` / `P -> ~subject_reduction` | 高 |
| **L3 语义性** | 在所有模型中成立/不成立，需要范畴论语义 | 模型论证明 | 最高 |

**渐进策略**：
1. 每个核心定理先预判目标强度（通常是L2）
2. 开工先证L0/L1版本（快、能占位、能验证方向对不对）
3. L1通过后冲L2（核心目标）
4. L2卡住超过熔断时间，保留L1结果，记录卡点，切下一个定理
5. L3（语义性）统一留到L7建模型后再证，不在L4-L6死磕

## 一、L3：Sheng/Ji类型 + Ming/Jia谓词 + 双归约

### 核心定理预判

| 定理 | 哲学命题 | 目标强度 | 预判难度 | 可能的坑 |
|---|---|---|---|---|
| `reduce_self_preserves_typing` | 自归约（生命自身的操作）保持类型——生命在自我改造中保持自身本质 | L2（subject reduction对reduce_self） | ⭐⭐⭐ | 自归约的定义是否覆盖所有构造子；Ming/Jia谓词在归约中的变化是否保持 |
| `reduce_alien_preserves_typing` | 异归约（被外部操作异化）保持类型——被异化的过程中操作权结构不崩 | L2 | ⭐⭐⭐ | alien归约可能涉及操作权的转移，线性性是否保持 |
| `progress_self` | 良类型的自归约不会卡死 | L1 | ⭐⭐ | 哪些构造子是"值"（不能再归约）需要明确 |
| `ming_jia_inversion` | Ming/Jia谓词的反演——如果一个进程是Ming态，它的操作结构必须满足什么 | L1 | ⭐⭐ | 谓词定义是否太松或太紧 |

### 哲学倾向
- **双归约的区分是生命论特有的**：reduce_self是"生命自己操作自己"，reduce_alien是"被外部力量操作"。两者的subject reduction要分别证，不能合并。
- Ming/Jia不是额外的类型，是**对操作状态的谓词**——同一个进程在不同时刻可以是Ming或Jia，这反映"明性不常驻"的哲学命题。
- L3的骨架已经写了，0 Admitted，但subject_reduction_self/alien依赖L2的subject_reduction。L2一通，L3直接转绿。

### S04注意
- L3不需要新的证明策略，复用L2的subject reduction方法即可
- 重点检查双归约的定义是否完整——有没有构造子既不属于self也不属于alien

## 二、L4：νF₂余归纳（Ag_lv的unfold结构）

### 核心定理预判

| 定理 | 哲学命题 | 目标强度 | 预判难度 | 可能的坑 |
|---|---|---|---|---|
| `Ag_lv_unfold_productive` | 生命历程（Ag_lv）的unfold是productive的——生命的展开永远能产出下一步，不会卡死 | L1（productive证明） | ⭐⭐⭐⭐⭐ | **Coq guard condition**——这是L4最大的坑 |
| `Ag_lv_coiteration` | 余归纳的共迭代原理——可以从任何满足条件的状态出发构造Ag_lv | L1 | ⭐⭐⭐⭐ | cofix的使用方式，guard condition |
| `Ag_lv_identity` | 两个有相同unfold行为的Ag_lv相等（余归纳外延性） | L2 | ⭐⭐⭐⭐ | 需要bisimulation证明 |

### 哲学倾向
- **余归纳对应"生命的无限展开"**：生命不是一个有限的项，是一个永远可以unfold出下一步的过程。νF₂就是"生命的过程性"的形式化。
- productive的哲学含义：**生命不会自己中断**——只要活着，就永远有下一步操作。这不是经验观察，是形式系统的性质。

### 关键工具（必须用，别硬来）
- **`paco`库**（参数化余归纳）：大幅缓解guard condition痛苦。不要用裸cofix，用paco的gupaco构造。
- 如果paco不可用，用**智能构造子**（smart constructor）模式：先定义一个"一步展开"函数，再用cofix调用它，guard condition更容易过。

### S04注意
- L4是技术鬼门关，不是哲学鬼门关。哲学方向很清晰，就是"生命是无限展开的过程"，难在Coq的guard condition。
- guard condition卡住时，**不要改定理陈述**，改证明结构（用paco或智能构造子）。
- 熔断时间加倍：L4的卡点可能需要多轮，但超过3轮无进展就写卡点记录，切L5（L5不严格依赖L4的所有结果）。

## 三、L5：!-模态 + T001 + T002

### 核心定理预判

| 定理 | 哲学命题 | 目标强度 | 预判难度 | 可能的坑 |
|---|---|---|---|---|
| **T001 生命不可资本化** | 生命类型Sheng不能被!-模态标记；强行标记导致系统不一致 | **L2（矛盾性）** | ⭐⭐⭐⭐ | !-模态规则的设计；Sheng的精确定义；"导致矛盾"的具体路径 |
| **T002 自由在实践中确立** | 自由不是先验的，是在操作（实践）中获得的——良类型的操作序列可以扩展操作权 | L2 | ⭐⭐⭐⭐ | "自由"的形式化定义；操作权扩展的度量 |
| `bang_rules_sound` | !-模态的规则（dereliction/digging/monoidal/weakening/contraction）是可靠的 | L2 | ⭐⭐⭐ | 标准线性逻辑结果，但我们的定义自定义 |
| `bang_vs_linear` | !-模态标记的类型和线性类型的交互性质 | L1 | ⭐⭐ | 上下文拆分时!类型的处理 |

### T001的精确哲学陈述（已预判）

**不是**L0（"我们没加!Sheng的规则"——太弱，像是约定）
**不是**L3（"在所有模型中Sheng不满足!代数性质"——太强，需要L7）
**是L2**：**假设存在一个合法操作/规则，使得Sheng可以被置于!-模态下（即可构造`!Sheng`），则该系统可以证明False或破坏subject reduction。**

哲学含义：**资本化是自我摧毁的操作**——它试图复制不可复制的生命，逻辑上导致系统不一致。这不是外部批判，是系统内部的矛盾。对应生命论命题：异化到极致会自我否定。

**证明路径预判**：
1. `!Sheng`的dereliction规则：`!Sheng → Sheng`（可以从资本化的生命得到生命）
2. `!Sheng`的contraction规则：`!Sheng → !Sheng ⊗ !Sheng`（资本化的生命可以复制）
3. 由1+2：从一个Sheng可以得到两个Sheng——这违反线性性（Sheng是线性类型，每份只能用一次）
4. 线性性被破坏 → subject reduction失败 → 系统不一致
5. 因此`!Sheng`的规则不能加入系统

**关键前提**：Sheng必须是**纯线性类型**（没有隐含的!标记）。如果L3的Sheng定义里不小心带了!-模态的痕迹，T001就证不出来。S04在L3转绿时要检查这一点。

### T002的精确哲学陈述（初步预判）

**L2版本**：对于任何良类型的进程P（类型为Sheng），存在一个操作序列，使得P的操作权场域得到扩展（上下文从Γ变为Γ'，且Γ'包含Γ的所有操作权+新增操作权），且扩展后的进程仍然良类型。

哲学含义：**自由不是被给予的，是在操作中挣得的**——生命通过自身的操作，可以扩展自己的操作权场域。这不是"想自由就自由"，是"做了正确的操作，操作权就会增长"。

**证明路径预判**：
1. 找到一个"生成新操作权"的操作（可能是split的某种形式，或L3中reduce_self的某个构造子）
2. 证明这个操作保持类型（subject reduction）
3. 证明操作后上下文严格增大（操作权增长）
4. 因此自由（操作权扩展）是可操作的，不是先验的

### S04注意
- L5是哲学含量最高的一层，T001/T002的陈述要**先和S01确认**再开工证
- !-模态的规则设计是L5的基础——先把bang_rules定下来并证sound，再证T001/T002
- T001如果L2证不出来，先退到L1（"不存在从Sheng到!Sheng的合法操作"）占位，记录卡点

## 四、L6：切消除 + 可靠性 + 完全性

### 核心定理预判

| 定理 | 哲学命题 | 目标强度 | 预判难度 | 可能的坑 |
|---|---|---|---|---|
| `cut_elimination` | 切消除——证明中不需要"引理"（切），一切都可以直接证 | L2 | ⭐⭐⭐⭐⭐ | 线性上下文的拆分导致case爆炸；归纳度量设计 |
| `soundness` | 可靠性——可证的命题在所有模型中为真 | L2 | ⭐⭐⭐ | 需要L7的模型（可以先证句法可靠性） |
| `completeness` | 完全性——所有模型中为真的命题都可证 | L2 | ⭐⭐⭐⭐ | 通常比可靠性难；可能需要Henkin式构造 |

### 哲学倾向
- 切消除的哲学含义：**真理不需要中介**——任何需要"引理"才能证明的命题，都可以不用引理直接证。这对应生命论的"操作的直接性"——真理在操作中直接显现，不需要异化的中介。
- 可靠性+完全性：**形式系统和实在的对应**——可证的就是真的，真的就是可证的。这是形式化工程的哲学闭环。

### 关键策略
- **切消除走句法路线**（不用等L7模型），用标准的线性逻辑切消除证明结构，适配我们的定义
- 如果句法切消除case太多，考虑**用语义路线**：先建L7模型，证可靠性+完全性，切消除作为推论
- 归纳度量用**多重集排序**（multiset path ordering），不要用简单的结构归纳——线性逻辑的切消除需要更复杂的归约序

### S04注意
- L6是技术鬼门关二号。哲学方向清晰，难在证明结构。
- 切消除卡住时，先检查是不是切公式的复杂度度量设计有问题，不要硬推。

## 五、L7：模型解释（范畴论语义）

### 核心定理预判

| 定理 | 哲学命题 | 目标强度 | 预判难度 | 可能的坑 |
|---|---|---|---|---|
| `category_model` | 我们的类型系统构成一个范畴（或某个特定范畴，如* -autonomous category） | L1 | ⭐⭐⭐⭐ | 范畴论公理的验证；线性逻辑对应* -autonomous category |
| `interpretation_sound` | 类型/进程在范畴中的解释是可靠的 | L2 | ⭐⭐⭐ | 解释函数的定义 |
| `initiality` | 我们的语法范畴是初始模型（所有模型都有唯一同态） | L2 | ⭐⭐⭐⭐ | 初始性证明通常很长 |

### 哲学倾向
- L7是"形式系统的形而上学基础"——证明我们的系统不只是符号游戏，它对应某种数学结构（范畴）。
- 这一层完成后，T001/T002的L3（语义性）版本就可以证了。

### S04注意
- L7需要范畴论背景。如果S04/DS不熟悉* -autonomous category，先补基础再开工。
- L7可以和L6并行——L6的语义路线需要L7，但L6的句法路线不需要。

## 七、S01思维方法SOP（S04自己也能用）

遇到新的形式化任务，按这个流程走，不用等S01：

### 第一步：哲学翻译
把要证的数学命题翻译成生命论语言：
- 这个定理在说什么操作关系？
- 操作权从哪来、到哪去？
- 对应的哲学命题是什么？

### 第二步：强度预判
按〇节的分级标准，预判目标强度：
- 这个命题哲学上需要多强？（通常L2）
- 最弱能退到哪？（L0/L1占位）
- 最强能到哪？（L3留到L7）

### 第三步：坑预判
问自己三个问题：
1. 定义里有没有隐藏的歧义？（展开每个定义的存在论含义）
2. 有没有边界情况？（空上下文、越界、空位、变量冲突）
3. 这个定理和已证定理是什么关系？（依赖、对偶、推广）

### 第四步：从低到高证
- 先证L0/L1，验证方向对不对
- 方向对了冲L2
- L2卡住超过熔断，保留L1，记录卡点，切下一个

### 第五步：沉淀
- 证完一个定理，把"哲学洞察→证明策略"的转化过程写进方法论文档
- 有可复用的经验就追加结晶

## 八、层间依赖与推进顺序

```
L1(✅) → L2(🟡进行中) → L3(🟡骨架等L2) → ┬→ L4(余归纳)
                                            ├→ L5(!模态+T001/T002)
                                            └→ L6(切消除，句法路线)
L4+L5+L6 → L7(模型) → L8(T003-T018)
```

**并行可能**：L4和L5可以部分并行（L5的!-模态规则不严格依赖L4的余归纳结果）；L6的句法路线不需要L7。

**当前咽喉**：L2。L2一通，L3转绿，然后L4/L5/L6可以三线推进。
