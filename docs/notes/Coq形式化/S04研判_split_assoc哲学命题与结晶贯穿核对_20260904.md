## 一、大白话：彻底讲透它在说什么

### 1. 先认清"上下文"是什么

`ctx = list (option ty)` 不是一张类型表，是**一片操作权场域（明性的分布）**。查第 n 位 `get Gamma n` 有三种状态，必须分清（option 三层级铁表）：

| get 结果 | 存在论含义 | 俗称 |
|---|---|---|
| `None` | 这一位根本不在场（越界，场域没延到这） | 越界之寂 |
| `Some None` | 这一位在场，但里面是空的（曾有/可有空位，现在无操作权） | 在位之寂 |
| `Some (Some T)` | 这一位真有一份类型 T 的操作权可用 | 真实发用 |

**关键：前两种都是"没有操作权流经这一位"，在操作层面等价；只有第三种是真东西。** 这是整个命题为真、以及 DS 反例为假的总开关。

### 2. split 是什么动作

`split G Ga Gb`：对**每一位** n，把 G 这一位的操作权要么判给 Ga（此时 Gb 该位是寂），要么判给 Gb（此时 Ga 该位是寂）。它是**把一整片明性场域逐位切分给两个并行生命过程**的动作——线性要求一份真资源不能同时给两边。

`ty_par`：P、Q 两个过程并行合法，当且仅当存在这样一次切分，P 活在 Ga、Q 活在 Gb。

### 3. split_assoc 说的那件事（人话版）

三个过程 P、Q、R 要并行，需要把整场域 G 切成三份 G1、G2、G3。切三份有两种下刀顺序（括号）：

- **右括号**：先把 G 切成「G12 这一整块」和「G3」，再把 G12 切成「G1」和「G2」。这是两个前提。
- **左括号**：先把 G 切成「G1」和「G23 这一整块」，再把 G23 切成「G2」和「G3」。这是结论。

**定理：只要右括号切得出，左括号就一定切得出——中间那块 G23 一定拼得出来（exists G23），而且两种切法下，每一份真资源归 P/Q/R 的结果一模一样。**

### 4. 为什么 G23 一定拼得出来（这是 DS 没悟到的地方）

G23 不是天上掉下来的现成东西，是**逐位重新聚拢**的产物（见证已在库里：`H23_val`，已 Qed）：

> G23 的第 n 位：G2 在这一位有真资源就拿 G2 的；否则去接 G3 这一位（G3 越界的 `None` 就补成在位空 `Some None`）。

- 真资源位：该归 G2 的 G23 持着、该归 G3 的 G23 也持着，一份不丢、一份不重（split 保证 G2/G3 不抢同一份真资源）。
- **空位怎么办？随便。** 让它越界成 `None` 也行、在位成 `Some None` 也行——反正是寂，没有操作权流经，形态自由，还能主动收摄掉。**DS 以为挡路的那堵"两种空对不上"的墙，其实是一张可以自由收放的幕。** 事故反例参数下直接取 `G23=[]`（整块越界），两个 split 立刻同时成立（coqc 已验证 exit=0）。

## 二、一句话哲学命题（正式表述）

> **明性分划结合律：一个操作权场域开显为多个并行生命时，每份真实发用（Some(Some T)）归于谁，不因下刀次序与括号方式而变；寂然空位（None 越界 / Some None 在位）二态在"无操作权流经"上等价、形态可选、冗余明性可收摄，故换一种括号重分时，中间场域 G23 必可逐位重新构造。**
>
> **它形式化地担保：世界被分为多之后仍能无矛盾地重新组织；多者并行共在的合法性，属于各自的发用与资源归属本身，不属于外部如何捆绑它们。**

没有它，`(P|Q)|R` 与 `P|(Q|R)` 可能要记两本不同的资源账、甚至一个可类型化另一个不可，"并行共在"就沦为依赖碰巧怎么组合的偶然物，而非客观存在方式。它是 ty_par 可嵌套、congruence、交换律与一切多进程理论的地基。

## 三、为真路线（数学骨架，证明正文交 DS 主谋，S04 不写 tactic）

- 见证：`G23 := setby f (repeat None L) 0`，其中 `f n _ := G2 有 Some(Some a) 取 Some a；否则取 G3 该位（越界补 Some None）`。逐位取值恒等式由 **H23_val（已 Qed）** 承担。
- 两个结论 `split G G1 G23`、`split G23 G2 G3` 都逐位 `unfold split; intros n`，按该位 get 三态分情况：真资源位用前提两刀的归属链 + H23_val 定位；空位用"二寂等价/可收摄"选一侧满足。
- 需要的长度 L 取能覆盖 G2/G3 真资源位的上界即可；越界位天然 None，不产生义务（弱引理精神，结晶 001：只逐位论 get，不证整上下文相等）。
- 结晶 007：全程 rewrite H23_val/setby/get 等式，不用 subst 暴力抹平。

> 本节是"操作权怎么流"的地图，不是 tactic 清单。正式 Lemma…Proof…Qed 由 DS 在全量上下文 + 本研判 + 完整 coqc 错误上闭环产出（结晶 014）。
