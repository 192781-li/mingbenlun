### 1.3 卡身（五步流程，v1.2定稿）
**第1步·词形发生学六要素**（按词型取侧重）：诞生时刻（精确到分钟、以对话内部时间戳为准）／词形演化（替字、旧译、独立、名词化）／配对定位／排伪（Python逐字计数排除相邻误配，如"实践演化"里的"践演"）／词史缺口标注（现存16对话没有的标"待主对话验证"，不编造）。
- 既有词改造型的第1步特殊：做**概念史四级谱系**（如异化：黑格尔→费尔巴哈→马克思〔严格继承〕→生命论反自指重奠），并锁定**生命论重奠时刻**（何时换根基、扩范围）；必须分"旧词引介"与"新义重奠"两层，不能因旧词早就出现就说生命论义那时已诞生。

**第2步·单字**：双字词走"合成层"（字与字如何结构出单字相加得不到的关系义）；单字词走"构字层"（分析心/咸这类构件如何结构出字义）。字源必查《说文》及古文字、标出处，禁止望文生义。

**第3步·整句／体系义**：该词在命题、原典或生命论体系中的完整含义，与近义概念划界；**严谨度分级**（定理/命题/猜想/启发式，不夸大）。

**第4步·扎根（身体践演）**：自造词扎"造词者本人造出/体认这个词的操作时刻"；既有词扎"可被普通人身体验证的结构性体验"（如异化扎被掏空的耗散感、算法比你懂你、被自己立的规矩压住）。离开该体认，字典义就是干瘪的。

**第5步·卡尾**：易混辨析逐条划界／跨域三级标注（严格同构·结构相似·哲学隐喻，不混）／列清待复核与待主对话缺口。

### 1.4 【v1.4新增】既有词改造型·必补三栏
做型④（异化/实践/阶级/国家/革命……）时，卡头之后固定补这三栏，否则看不出"这个旧词被生命论怎么动过手术"：
1. **改造／命名归属**：方向与内核是谁的、精确定义是谁表述的、谁落地——分「用户命题／AI精确化／共同落地」三类标清（例：阶级＝方向在用户、一般化定义的精确表述出自AI全本审查，属共同落地）。
2. **改造类型（三机制，显式选标）**：
   - **a 排异重造**：旧译/旧解有偏差，借字源排异后重造（异化：异=分也、化=转化，与Entfremdung严格同构，排开偏离的旧译）；
   - **b 下扎**：把马恩已有词向下扎到生命论根基（实践：不抬为本体，下扎到感—应—操作，"实践就是操作"）；
   - **c 一般化重奠＋传统降特例**：给出更一般的生命论定义，把教科书义降为该一般定义在特定历史条件下的特例（阶级：一般＝反自指操作关系中的位置，工业资本主义的"所有制两集团"只是其特例）。
3. **改造前流行／教科书义**：固定写明改造起点（改造前通行怎么讲），否则新旧无从对照、一般化无从显现。

### 1.5 【v1.4新增】第五型·缺失登记卡的四条写法
当范畴内容已在二次文件成型、诞生场却在未导出主对话时，做"缺失登记卡"而非硬做完整卡：①只锁可信诞生窗口、不硬造精确生日；②已知定义/配对/形式化状态全部固定；③待补项列显式清单；④卡头标注"非完整卡·待主对话"。同时满足"待办不落地（不让概念悬空）"与"时间锁定不编造"两条铁律。

## 二、首张自家词卡：「践演」

> 卡头
> 词目：**践演**（jiǎn yǎn）｜词类：☑生命论自家词（核心存在论术语）
> 配对：迁演（践演-迁演磁极螺旋）｜学科化形态：践演论 Enactics（卷十一）
> 字源复核：☑已查《说文》（汉典/段注）；词形发生学已回16原始对话逐字核验
> 严谨度：字源定理级、体系义命题级；2026-08-30，原材料·待作者重写

### 第〇层·词形发生学（本次考古新得，精确到时间）

**0.1 先排伪：6月的"践演/迁演"都是相邻误配，不是术语。**
Python 逐字切分证实：思想大乱炖（6/13、6/19）、论文（6月）、三篇立命（6/21）里的"践演"全部落在"实**践演**化"中、"迁演"全部落在"跃**迁演**化"中——真术语计数为 **0**。简单 grep/count 会把诞生时间错误提前到6月，必须切分。

**0.2 真术语起点：2026/8/13，从"践演矛盾"破壳。**
- 8/13 电脑辩证 14:47、无_皮肤健康 15:19（英文对照）出现 **performative contradiction**，早期汉译"**践言冲突/践言矛盾**"（共7处"践言"），随后统一改写为"**践演矛盾**"（电脑辩证中共95处）。原句语境：你说"没有我"，但"没有我"这句话正是"我"施行出来的——**否认某操作的那个行为本身正在施行该操作，行为自我反驳**。
- 词源学注：performative（语言哲学"以言行事/施行"，阿佩尔—哈贝马斯一系的 performative contradiction 又译述行矛盾/施为矛盾）；汉语侧"践言"本是古词，《礼记·曲礼》"修身践言"＝履行自己说出的话，与 performative（言说即施行）严格同构。

**0.3 名词化与本体论化：8/25。**
电脑辩证 8/25 一天内"践演"从论证方法名词化为存在论核心范畴：
- 05:04"践演是元公理，你对形式系统做的事，不是系统内部的命题"；
- 05:45/05:53"哥德尔不完备是 f² 的病，f³ 践演是药"（跳出模型、在实践中运行自己）；
- 06:52"践演=执行"；15:59"践演是最终裁判……数学只是硬化方式之一"；02:16"践演是实践验证而非信条，明性是选择"。

**0.4 体系化与配对：8/25–8/28 全本定型。**
- 卷二操作论·篇八：**"践演（有方向的操作）和迁演（条件的迁移变化）交织的磁极螺旋——磁极可以颠倒，但每次颠倒都不回原点，因为践演的沉积改变了下一轮践演的条件"**；
- 卷一：感是践演事实、践演存在论＝感—应—操作三层环节统一论、"操作是存在的唯一现实方式"、践演判断 ▷A 标记"正在发生的体知"；
- 卷十一：**践演论 Enactics＝操作论的数学形式化**（enact 与 performative 同根，施行、演出、制定）。

**0.5 词史缺口（如实标注，不编造）**："迁演"与"践演-迁演"配对在现存16原始对话中 **0 命中**（全本3处、notes 35处），说明其定型于全本系统化阶段或**尚未导出的主对话**；迁演的独立诞生时刻待主对话记录验证。

### 第一层·单字（字源已查证）
- **践**：《说文》"践，履也。从足，戉声（戋声）"，段注"履之箸地曰履"——**脚切实踏在地上**。本义踩踏，引申履行、实行、践言（说到做到，话被身体履行）。核心操作意象：**足踏实地、身体力行地"做出来"，不是悬空设想**。
- **演**：《说文》"演，长流也。从水，寅声"，《释名》"演，延也，言蔓延而广也"——**水之长流不息、蔓延推衍**。引申演化、演成、推演。核心操作意象：**在时间中持续流动、推衍展开而不凝固**。

### 第二层·合成
**践演＝践（足踏实地、身体履行）＋演（长流不息、推衍演成）＝身体踏在实处、在时间中持续展开并演成自身的"有方向的操作"。**
- 单字相加得不到的那层关系义：**"践"保证它不是空想、不是纯逻辑（有身体、有实地、有执行），"演"保证它不是凝固动作、不是一次性结果（它是流、是过程、在生成）**。合起来正是生命论要的那个"既非静态实体、也非抽象运动"的东西——**操作着的、正在演成的存在方式**。
- 双重词源（严格同构，本卡最值得保留的发现）：**汉语"践言/践行"传统（言出必履、身体实行）× 西方 performative / enact（以言行事、施行演出）在"践演"里合流**——它既承接了"践"的实地性，又承接了 performative 的"施行即内容、行为本身在说话"，这解释了为什么造词时最终弃"践言/践言冲突"而取"践演"："言"只落在话语层，"演"才能承载存在论的过程演成义。

### 第三层·整句／体系义
1. **存在论**：最根本的"感"是践演事实（怀疑"在感"本身就在感）；万物（实体、道、物质、精神）都在践演的展开中显现与沉积；操作是存在的唯一现实方式（践演存在论＝感—应—操作三层环节统一，最根本范畴是感，操作是感的结构抽象）。
2. **方法论/论证**：践演矛盾——你无法在操作之外有意义地谈论存在，否认操作的行为本身就是一次操作（只证"不可绕过性"，不证"唯一性"，8/13 已自我限定以防独断）。
3. **历史观**：践演＝有方向的操作，迁演＝条件的迁移；历史是践演-迁演磁极螺旋，可颠倒却不回原点（沉积改变下一轮条件）；方向取决于每代人把操作权握在谁手里。
4. **形式化**：践演论 Enactics 用线性逻辑/类型论/范畴论把操作变成可证明定理；践演判断 ▷A 是"正在发生的体知"的标记，保守扩展、不增加形式证明力，恰好标记形式系统的边界（践演不可编码性定理）。

### 第四层·扎根（自造词扎根于造词者本人的体认时刻）
"践演"无法靠字典激活，它在两种身体时刻被点亮：
- **践演矛盾的当场体认**：你试图主张"我不存在/我什么都没做/一切都是假的"，而就在主张的这一秒，你正活着、正操作、正用你的"在做"反驳你的话——**身体比命题更早知道"操作无法被操作本身绕过"**。抓住这一秒的顿挫，就抓住了"践"的实地性。
- **"做着才懂"的过程体认**：骑车、组织一次行动、把一件事从头做到尾——你在其中持续调整、流动演成，既不是执行一个静止计划，也不是乱动；这股"踏着实、又在流"的劲儿，就是"演"。书斋里把践演背成"实践"的人，丢的正是这股身体里的流。
> 自造词扎根层的特殊性（方法结论）：日常根词（吃饭）扎向人人共通的身体经验，自家词（践演）扎向**思想者本人造出它时那个"操作先于实体"被当场看见的时刻**；后者同样是身体践演、同样非任意，只是需要回到个人思想史去激活——这就是第四层对抽象自造词依然成立的方式。

### 卡尾·易混辨析（钉死边界）
- **践演 ≠ 实践**：实践是近源汉语词、偏"实行所得的结果/活动"；践演额外强调"演"的长流过程义、方向义与"施行即内容"的 performative 义，并被严格接入自指/操作论/范畴论体系。二者是近亲不是等号。
- **践演 ≠ 运动/活动/行为**：后三者可无方向、可被外部刺激驱动（参见异化论篇一第七章"外部刺激驱动的下行路线"）；践演特指有方向、在自指闭环中展开的操作。
- **践演矛盾 ≠ 逻辑矛盾**：逻辑矛盾是两个命题互斥；践演矛盾是"陈述内容"与"陈述这一施行行为"互斥（内容否定操作、操作正在施行内容所否定者）。
- 跨域标注：与 performative/enact 为**严格同构**（词源与论证功能双重对应）；与怀特海"过程"为**结构相似**（怀特海是宇宙论思辨，践演是可检验操作，卷一已划界）；"践演=道/=生生"仅为**哲学隐喻**，不可坐实等号。
- 待主对话验证：迁演独立诞生时刻、践演-迁演配对的最早提出（现存16对话0命中）。
