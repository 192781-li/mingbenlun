## 一、这个分支要解决什么问题

马克思主义、生命论的真理，常常以**抽象概念**的形态存在，群众（甚至学习者本人）"会说这个词，却不真懂这个词"——因为概念脱离了它赖以成立的**身体践演经验**。

生命语义论的任务：**以哲学的眼光、但不必用哲学的黑话，把汉语字词逐层拆开，回溯到它的字义构成、再回溯到身体的"感"与缄默意识，让凝结在语言里的真理重新变得可感、可身体体认，使人重新深入地理解真理、马克思主义、生命论。**

### 思想前史（两条线今晚合流）
1. 小学时：想"从零搞本体论，重新理解一切事物"——本体论线，现已基本走通；
2. 一两年前：想"以哲学眼光解释一切词语"——语义线；
3. 今晚：语义线与生命论（感、缄默意识、践演）合流，方法获得灵魂。

## 二、方法：三层拆解 + 一次扎根（核心操作流程）

对任何一个词/句，走四步：

**第一层·单字训诂**：每个字单独解——字源（《说文》等）、本义、字形里藏的原初经验。
**第二层·合成**：两个字合起来解——字义如何结合、结合后生出什么新义。
**第三层·整句综合**：放回句子和语境，综合出完整意思；若是论断（如"解释世界不如改造世界"），还要解"为什么"。
**扎根层（灵魂，不可省）·身体践演**：联动人的"感"与缄默意识——这个词在什么**真实身体经验**下才被真正理解？没有相应践演（没饿过、没被压迫到想反抗过）的人，为什么只会说而不懂？

> 前三层是"说文解字"的功夫，**第四层才是生命语义论区别于一切字典、训诂学、词源学的地方**：字义最终要扎根到身体践演，否则就是干瘪的!-模态沉积。这与生命论"感是力的生命化""践演先于认识""缄默意识是前语言的身体觉知"一脉相承。

### 三条操作纪律
1. **哲学眼光，日常语言**：深度要哲学，表达要说人话，面向群众，不堆黑话（用户明确要求）。
2. **引字源要查证**：《说文解字》等训诂材料必须核实，不附会、不编造字源（引原话引原文纪律延伸到字源）。
3. **身体经验要真实**：扎根层举的身体经验必须是人人可体认的普遍经验，不搞私人神秘体验。

## 三、首批范例（用用户亲授三例验证方法成立）

### 范例1：「解释世界不如改造世界」（马克思《关于费尔巴哈的提纲》第十一条）

**第一层·单字**
- **世**：《说文》"三十年为一世"，字形是三十（卅）的延续，本义是**时间的绵延、代际的流逝**——时间维度。正对应生命论"践演＝时间流淌"。
- **界**：《说文》"界，境也"，从田，本义是**田亩的边界、空间的划分**——空间维度。对应"迁演＝空间展开"。
- （旁证：佛家《楞严经》"世为迁流，界为方位"，也是时间＋空间，与生命论践演-迁演暗合。）

**第二层·合成**
- **世界＝世（时间绵延）＋界（空间划界）＝人被抛入其中、在其中践演-迁演的整体时空场域。** 世界不是静止的容器，是时间中流淌、空间中展开的活场域。

**第三层·整句与"为什么不如"**
- **解释**＝解（解开、拆解）＋释（放开、陈明）：站在世界**对面**，把对象拆开说明，人是**旁观者**，世界是被反映的对象（!-模态、理论态度、阴）。
- **改造**＝改（变更）＋造（创造、造作）：站在世界**之中**，把对象重新创造出来，人是**参与者**，世界是人的践演产物（线性操作、实践态度、阳）。
- **为什么"不如"**：因为世界在本性上是人的践演持续生成的活场域；"解释"只能把握它已经沉积下来的死截面，"改造"才抓住它活的生成本性——**人正是在改造世界中才真正理解世界、生成自身**。这不是贬低理论，而是说：理论的真理性最终要回到改造的践演才成立、才被证实。阳主阴从，理论（阴）服务于改造实践（阳）。

**扎根层·身体践演**：一个只在书斋里"解释"社会的人，和一个真正动手改变过身边现实（哪怕组织一次成功的集体行动、亲手做成一件事）的人，对这句话的体认深度完全不同——后者身体里知道"世界是可以被我的操作改变的"，前者只在概念上同意。

### 范例2：「吃饭」——你饿的时候才真懂

**第一层·单字**
- **吃**：从口，本义以口接纳外物入身、求取并纳受；
- **饭**：食＋反，食事也，是人赖以维生的食事。

**第二层·合成**：吃饭＝纳食入身以维持生命的活动，表面看是再普通不过的生理动作。

**第三层·整句**：字典定义"摄取食物以维持生命"是抽象的、干瘪的。

**扎根层·身体践演（本例的重点）**："吃饭"这个词**完整饱满的意义，不在字典里，在你真饿了的时候**——胃的空、身体的匮乏、对食物的食欲和急迫，让"吃饭"从一个抽象符号变成带着全部身体紧迫感的真实。**先有身体的饿（缄默意识层面的匮乏感），"吃饭"这个词才被真正激活。** 没挨过饿的人会说"吃饭"，但不真懂"吃饭"里的求生分量。
- 普遍命题：**一切词的完整意义，都需要对应的身体践演经验来激活。** 书斋概念之所以干瘪，正因它被抽离了"感"。这就是生命语义论的第一原理在一个最日常词上的显现。

### 范例3：「武器的批判」——你想打碎的时候它才戳人

**原典**：马克思《〈黑格尔法哲学批判〉导言》："批判的武器当然不能代替武器的批判，物质力量只能用物质力量来摧毁；但是理论一经掌握群众，也会变成物质力量。"

**第一层·单字**
- **武**：止戈为武（《说文》引楚庄王）——武力的终极指向是"止戈"（平息），但前提是先得有"戈"、敢于动武；
- **器**：器具、有形可用之具。

**第二层·合成**
- **批判的武器**＝用概念、理论进行的批判（理论，是"武器"的一种，属!-模态）；
- **武器的批判**＝用物质力量进行的批判（实践、物质力量，属线性操作）。

**第三层·整句**：理论批判替代不了物质实践的批判——现实的物质压迫，最终只能靠物质力量摧毁；但理论掌握了群众，就会转化为这种物质力量。两者不是对立，是"理论→掌握群众→变成物质力量"的转化关系。

**扎根层·身体践演（本例的重点）**：为什么这句话格外"戳人"？用户原话："因为你真的想摧残、打碎一些东西。"——当一个人被反自指结构压迫到极点、身体里升起"非打碎不可"的实践意志时，他才**身体性地**懂得：光靠说理（批判的武器）摧毁不了现实的铁，必须有物质力量（武器的批判）。那种"想打碎"的真实冲动（缄默意识层面的实践意志），让这句话从哲理变成击中身体的真理。
- 革命理论的力量，最终要接通群众被压迫到极点时"非改变不可"的身体性冲动，理论才能"掌握群众、变成物质力量"。这与今晚"批判的必然性：明性被现实呼唤"完全贯通。

## 四、与生命论体系及哲学谱系的关系

### 4.1 内部衔接
- 感是力的生命化（卷一）→ 扎根层的身体之"感"；
- 缄默意识（前语言的身体觉知）→ 字词意义的前语言根源；
- 践演先于认识、!-模态沉积 vs 线性操作 → 字典沉积（阴）与践演激活（阳）；
- 阳主阴从 → 字义训诂（阴）服务于身体践演的激活（阳）；
- 今晚的"反自指八连侵蚀""批判的必然性"→ 革命类字词（武器的批判、打碎）的扎根内容。

**【严格同构：由字通词通道 ≈ 三层拆解】**
戴震的治学纲领（出自《与是仲明论学书》，载《戴东原集》卷九，非《孟子字义疏证》本文，须分清出处）：
> "经之至者道也，所以明道者其词也，所以成词者字也。**由字以通其词，由词以通其道，必有渐。**"
- 字→词→道的逐级上达，与本纲领"单字训诂→合成→整句综合"的前三层**严格同构**；
- 《孟子字义疏证》本身即按"理、天道、性、才、道、仁义礼智、诚、权"等范畴逐字疏证、"由故训以明理义"，形式如一部概念字义字典——与本分支"每词一卡、汇成生命语义字典"的工程形态结构相似。

**【结构相似：理不离欲、血气心知 ≈ 扎根身体践演】**
- 戴震反程朱"存天理灭人欲"，主"理者存乎欲者也""体民之情，遂民之欲，而王道备"（《孟子字义疏证·理》），把"理"从超验天上拉回人的生命情求；本分支把抽象字义拉回解读者的身体践演——方向结构相似：**反对脱离生命的抽象义理**。
- 戴震"血气心知"（人以血气接物、以心知辨理）的两层认识结构，近似本分支"缄默的身体之感（扎根层）＋明性的概念理解"。

**【生命语义论的推进（边界在此，不可把戴震说成已具备这些）】**
1. **终点不同**：戴震"由字通词通道"的终点是还原**经典/孟子的客观本义**（我注六经式还原）；本分支三层之后还有**第四层·扎根到解读者本人当下的、历史具体的身体践演**，终点是真理在每个活人身上的重新激活与再生产，而非回到文本本义。
2. **身体性的历史化**：戴震的"血气/欲"是类层面的一般人性论；本分支的扎根层是**具体的、阶级的实践经验**（真饿过、被压迫到想反抗过），接通马克思实践论与缄默意识，比戴震具体。
3. **多了异化诊断**：戴震没有"概念为何会干瘪、会杀人"的语言存在论机制；本分支用 **!-模态沉积 vs 线性操作、反自指** 解释——抽象概念一旦脱离身体践演，会被礼教/资本收编为压迫工具，这正是"以理杀人"在语言本体论上的当代诊断：戴震诊断了"以理杀人"之果，本分支补其语言—操作之因。
4. **对象与受众不同**：戴震以经学范畴为对象、写给士大夫；本分支以马恩核心词＋生命论自造词＋日常根词为对象，面向群众做大众化激活。

**【跨域三级标注小结】**
- 严格同构：字→词→道的逐级训诂方法 与 三层拆解；
- 结构相似：理存乎欲/血气心知 与 身体践演扎根、反抽象义理的总方向；
- 哲学隐喻（不可坐实）：戴震"道"≠生命论"践演"，戴震"欲/血气"≠缄默意识，勿强行等号。
- 引戴震一律精确到出处：方法论在《与是仲明论学书》，"死于理其谁怜之"在《孟子字义疏证·卷上·理》，"后儒以理杀人"在《与某书》；作者定稿时应据中华书局《戴震集》/何文光校本复核字句。

## 六、严谨度与局限
1. 方法（三层＋扎根）为用户提出、AI结构化，**命题级**；三个范例为AI按方法首次试做，字源（《说文》《楞严经》"止戈为武"等）需逐一复核原典后再定稿。
2. 单字训诂涉及古文字学专业，凡字源结论必须查证《说文》及现代古文字学，禁止望文生义、强行附会生命论（这是最大风险点）。
3. "身体践演扎根"要避免相对主义（不能说"各有各的身体理解所以没有字义客观性"）——字源与社会共同实践提供客观面，身体体认提供激活面，两者结合，后续需专门论证。
4. 分支最终命名待用户拍板。
5. 本纲领为AI整理，**原材料·待作者重写**。
