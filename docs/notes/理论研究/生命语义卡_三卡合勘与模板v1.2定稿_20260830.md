## 二、核心总图：同一个自指生命事实的两侧与递归

```
                  同一个"活的自指操作"事实（生命）
 ┌──────────────────────────────┴───────────────────────────────┐
 第一人称·呈现侧（内部、感）                    第三人称·结构侧（外部、操作）
                                                             
 感（一，心物未分原初事实，最根本范畴）  ──同一事实两面──►  操作（感的结构抽象/第三人称描述）
 │                                                              │
 ├─ 应：一个感呼答另一个感（第二人称，"你"诞生）                  ├─ 自指 S=f(S)、四规定性、f层级
 ├─ 能：感在可能性空间趋避选择（能阳；自觉=自由意志）             ├─ 操作实际运转、有方向地执行 ＝ 践演（道）
 ├─ 做：感引发回应（自觉=实践）                                   ├─ 条件迁移变化 ＝ 迁演
 └─ 内向面递归：                                                  └─ 践演-迁演磁极螺旋 ＝ 历史
      缄默意识（操作内向觉知面，自在-自为-自觉三层）
            └─递归到自觉层"知道自己知道" ＝ 明性（暗→明连续谱的质变）

 桥：感是践演的第一人称呈现（"感是践演事实"）；一生道，道养一（一是感，道是操作运转方式）
 坐实：感·能·明性（＋应·做）践演坐实——你无法站在它们外面质疑，因为质疑本身就在用
```

**读图三句话**：
1. **最根本范畴是感，不是操作，更不是践演**——入口只能是第一人称的感；操作是回头看感的展开时给的结构名字（感的结构抽象），践演是这个操作实际运转起来的过程（有方向的执行）。
2. **第一人称侧是一条递归链**：感（原初）→缄默意识（内向觉知面）→明性（自觉层照亮）；横向还有应（你）、能（选择）、做（实践）。
3. **两侧不是两个世界**：感/应/做/能/操作"不是四个东西，是同一事实的角度"；践演坐实保证它们赖不掉（否认时已在使用）。

## 三、跨卡关系七条（钉死，防混用）
1. **范畴次序**：感（根本）＞操作（感的结构抽象）＞践演（操作的实际运转）。抽象关系是"感→操作"，不是"感→践演"。
2. **同一事实两面**：感（第一人称呈现）↔操作（第三人称描述），非因果、非本质-现象（如同不问"H₂O如何引起水"）。
3. **践演＝运转态**：践演不是比操作更高级的实体，是自指操作"正在运行、有方向"的过程面；与迁演（条件迁移）交织成历史磁极螺旋。
4. **第一人称递归**：感→缄默意识→明性是同一内向面的三个递归层级，不是三个东西；明性是质变（自觉层），非从无到有。
5. **本明/明性＝潜能/现实**：本明是能明的天赋潜能（缄默意识内向面），明性是每步点亮的现实选择（"明不异愚，择异耳"）。
6. **感能同一两面**：第一人称呈现是感，操作推动是能；感是能的根据，能是感的实现（知行本一）；能在人这里经符号插入距离而达自由意志。
7. **自觉的双重性**：明性不止"我明我"（自觉）还有"我明你"（感通）；践演-明性模型＝操作运转与对操作的自觉照亮一体。

## 五、模板 v1.2 定稿：一页可复用拆词流程

**第0步·定词型（决定后续侧重）**
| 词型 | 判据 | 第〇层侧重 | 已验样卡 |
|---|---|---|---|
| 既有词/马恩词 | 汉语/经典本有 | 字书本义＋原典语境 | 世界/吃饭/武器（纲领三范例）、实践（待做） |
| 新造词 | 汉语本无此词 | 词形演化（旧译→定型） | 践演 |
| 单字升格 | 单字、日常高频 | 语义跃迁点＋日常义排伪 | 感 |
| 混合型 | 双字含高频字＋有旧词形渊源 | 再加渊源辨析（误配/旧渊源/新范畴三层） | 明性 |

**第1步·第〇层 词形发生学（自造词必做，既有词可省）**
①诞生时刻（精确到分，以内部时间戳为准，不以文件名）；②词形演化（替字/旧译/名词化）；③配对与体系定位；④排伪（Python逐字切分，防相邻误配，如实践演化/跃迁演化/说明性/自明性）；⑤词史缺口（现存没有就标"待主对话"，禁编造）；⑥混合型加渊源辨析（旧词形只作"结构相似"，不冒血统）。

**第2步·第一层 单字**：逐字查《说文》及古文字（必联网/字书核实，禁望文生义）。双字词进第3步"合成层"（两字合成多出的关系义）；单字词进"构字层"（偏旁构件如何结构字义，如感=心+咸）。

**第3步·第三层 体系义**：该词在全本/命题中的完整含义、与近义概念划界、严谨度分级（定理/命题/猜想/启发式）。

**第4步·第四层 扎根（身体践演）**：既有词扎人人可体认的普遍身体经验；自造词扎**造词者本人造出/体认该词的操作时刻**。离开体认，字典义干瘪。

**第5步·卡尾**：易混辨析逐条划界；跨域三级标注（严格同构/结构相似/哲学隐喻）；待复核与缺口。

**贯穿纪律**：哲学眼光日常语言；字源必查证；语音存疑先标注；AI文字标"原材料·待作者重写"；绝对不说完美、每卡必列局限。
