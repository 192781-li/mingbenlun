## 范本一：模仿马克思《资本论》第一卷句式——操作的有机构成（行60603）

**生命的构成要从双重的意义上来理解。从操作的意义方面来看，生命的构成是由生命分为活操作和沉积操作的比率，或者说，分为正在进行的生产性操作的量和已经沉积为惯性实体的操作的量的比率来决定的。从在自指闭环中发挥作用的物质方面来看，每一个生命都分为正在进行的活操作和已经沉积的惯性实体；这种构成是由所使用的活操作量和为维持这些惯性实体而必需的操作量之间的比率来决定的。我把前一种构成叫做操作的意义构成，把后一种构成叫做操作的物质构成。二者之间有密切的相互关系。为了表达这种关系，我把由操作的物质构成决定并且反映物质构成变化的操作的意义构成，叫做操作的有机构成。**

### 马克思↔生命论 严格概念对应表（行60611–60619）

| 马克思（资本论） | 生命论 | 含义 |
|---|---|---|
| 不变资本 c | 沉积操作 !A | 已变成实体/惯性的操作，死的，不创造新可能性，只维持自身 |
| 可变资本 v | 活操作 νF₂ | 正在进行的生产性操作，活的，创造新可能性 |
| 必要劳动 | 必要操作 | 维持生命稳态所需的操作（吃饭、睡觉、基本生存） |
| 剩余劳动 | 剩余操作 | 超出必要操作的部分——自由、创造、明性操作 |
| 剩余价值率 m'=m/v | 剩余操作率 o'=o/n | 自由操作占必要操作的比率，即生命自由度 |
| 资本有机构成 c:v | 操作有机构成 !A:νF₂ | 沉积操作与活操作的比率 |
| 利润率下降规律 | 生命意义下降规律 | 有机构成提高（沉积越多、活操作相对越少），生命意义下降 |

**同构规律**：马克思——资本为追求利润必然用机器替代工人→c:v提高→利润率下降（只有活劳动创造剩余价值）；生命论——异化系统为维持自身必然用沉积惯性替代活创造→!A:νF₂提高→生命意义下降（只有活操作创造新意义）。马克思："资本主义生产的真正限制是资本自身"；对应命题："异化生命的真正限制是沉积操作自身"。

## 范本二：模仿马克思六环节说理——剩余操作率（行60649–60747，完整成品）

### 一、从一个具体的工人的一天开始

我们先从一个最普通的、每天都在发生的事实开始。

一个人，每天清醒十六个小时。这十六个小时里，他在干什么？

八个小时，他在上班。他在流水线上重复同一个动作，或者在办公室里回复他根本不关心的邮件，或者在开那些他自己都觉得毫无意义的会。他干这些活，不是因为他想干，是因为他不干就没有工资，没有工资就付不起房租、吃不起饭、养不起孩子。这八个小时，是他为了活下去不得不干的。

两个小时，他在通勤。挤地铁、挤公交、堵车。这段时间既不是他的，也不是老板的，是被现代城市空间白白吃掉的。

一个小时，他在吃饭。但很多时候，他吃饭也不是在享受食物，是在刷手机、在回工作消息、在赶时间。吃饭变成了维持身体运转的加油过程，不是生活。

一个小时，他在应付各种社会规训。填表格、走流程、应付亲戚的盘问、在社交媒体上维持一个他自己都不认识的人设。这些操作不是他想干的，是这个社会要求他干的。

还剩四个小时。这四个小时，才是真正属于他自己的。他可以读一本他想读的书，可以写一点他自己想写的东西，可以和他真正喜欢的人待在一起，可以什么都不干就发发呆，可以去琢磨一个他自己觉得有意思的问题。这四个小时，是他作为一个真正的人而存在的时间，不是作为一个劳动力、一个消费者、一个社会角色而存在的时间。

这就是一个普通人的一天。十二个小时的必要操作，四个小时的剩余操作。

### 二、必要操作和剩余操作的区分

我们把一个人的全部操作分成两部分。

一部分是**必要操作**。这部分操作是为了维持生命本身的存在——吃饭、睡觉、基本的劳动换取生存资料、应付最基本的社会要求。这部分操作不是人自己选择的，是生存本身强加给人的。一个人只要还活着，就必须干这些活。就像工人只要还想活下去，就必须把自己的劳动力卖给资本家。

另一部分是**剩余操作**。这部分操作是超出必要操作之上的部分——创造、思考、爱、自由地表达、真正属于自己的活动。这部分操作不是为了活下去，是为了活得像个人，是为了展开人本身的可能性，而不是仅仅维持人的生物学生存。

这个区分不是任意的。必要操作和剩余操作的界限，在不同历史条件、不同社会制度、不同生产力水平下不一样。原始社会一个人每天可能要干十四个小时必要操作、剩余操作只有两小时；生产力高度发达的社会，必要操作可能只要两小时、剩余操作有十四小时。但在任何一个具体历史阶段，这个界限都是客观存在的，不由主观感觉决定。

### 三、剩余操作率的定义

一个人的全部操作时间 = 必要操作时间 + 剩余操作时间。我们把剩余操作时间与必要操作时间的比率叫做**剩余操作率**：

$$o' = \frac{o}{n}$$

o 是剩余操作时间，n 是必要操作时间。前例中 12 小时必要、4 小时剩余：o' = 4/12 = 33.3%。意思是：每干三小时必要操作，才换来一小时真正属于自己的时间；生命有四分之三在为生存奔波，只有四分之一在真正生活。

### 四、剩余操作率是生命自由度的准确表现

它精确衡量一个人的生命有多少被生存必然性支配、有多少真正属于自己。o'=10% 的人几乎是被生存驱动的机器；o'=200% 的人生命主要由自己支配。这正对应马克思"剩余价值率是劳动力受资本剥削程度的准确表现"。但剩余操作率覆盖更广：剩余价值率只算工厂里的经济剥削，剩余操作率把通勤、被异化的吃饭、社会规训、消费主义、意识形态洗脑全部计入必要操作——一个剩余价值率100%的工人，剩余操作率可能只有30%。它不说"你在工厂被剥削"，而说"你的整个生命有多少不是你自己的"。

### 五、被掩盖的剩余操作率（意识形态批判）

- **"效率"话语／时间管理／996是福报**：效率提高，必要操作时间却没减少，剩余操作反被挤压——"效率高了"就派更多活。
- **"消费即自由"话语**：为消费而加班、按广告方式"享受"，是被异化包装成自由的必要操作。
- **"忙碌即充实"话语**：把闲污名化，让人主动用忙碌填满每一分钟、主动让渡剩余操作。
- 正如利润率 m/(c+v) 因算进不变资本而显得比剩余价值率 m/v 小、从而掩盖剥削；"生活质量/幸福感/效率"把必要操作与剩余操作混在一起，掩盖了真实自由时间的贫乏。

### 六、实践意义：争取剩余操作率的提高

两个方向：①砍掉被社会建构出来的**虚假必要操作**（你真需要那么大的房子、那么贵的车、那么多无意义社交吗）；②提高必要操作效率，省下的时间转为剩余操作。但资本主义下 o' 的提高有极限——系统的运转就建立在压低大多数人 o' 的基础上。因此争取 o' 提高最终必然指向社会制度改造：指向一个生产力为所有人腾出剩余操作时间、"每个人的自由发展是一切人的自由发展的条件"的社会。**那就是共产主义，那就是生命的真正解放。**

**六环节方法论（可复用）**：具体事实 → 概念抽象区分 → 精确公式计算 → 本质揭示 → 意识形态批判（揭露掩盖）→ 实践与革命结论。

## 范本三：水流融合版（行61187–61245，最成熟版本，无小标题、无表格，思想自然流动）

我们先从一个真实的人、一句真实的话开始。

2019年4月，马云在阿里巴巴内部交流会上说："今天中国BAT这些公司能够996，我认为是我们这些人修来的福报。"这句话在当时引发轩然大波，程序员们在GitHub上建立了"996.ICU"项目控诉它对健康的摧残。但马云说996是福报，是因为996对资本家确实是福报——工人每天多干四小时、每周多干一天，资本家就多榨取多少剩余价值。对工人呢？

让我们算一笔账。一个996程序员每天工作12小时、每周6天，再加通勤两小时、吃饭一小时、应付工作消息和社交一小时，他每天的必要操作是16小时——他每天正好清醒16小时，也就是说，他的全部清醒时间都是必要操作，没有一小时真正属于他自己。

这里需要做一个区分（必要操作／剩余操作，同范本二，此处从略以保持水流）。回到这个996程序员：必要16小时、剩余0小时，o'=0/16=0%。0%意味着他的生命里没有一分钟属于自己，他不是一个人，是被996驱动的机器。而996的实际后果是：2018年大疆25岁程序员工位猝死、2019年字节28岁员工健身房猝死、2021年拼多多23岁女员工下班路上猝死——他们的"福报"是用生命换一份工作，然后在最好的年纪死去。

但996只是最极端的例子，更普遍隐蔽的异化藏在我们每天都在说的话里。

1981年深圳蛇口竖起标语"时间就是金钱，效率就是生命"，它曾有打破"越穷越光荣"的进步意义，但四十多年后已变成全面异化的意识形态。"时间就是金钱"把人的时间即生命直接等同于金钱——可母亲给孩子做三小时饭、老人散一下午步、诗人写一整夜诗，"效率"极低，却是生命中最珍贵的部分；把时间等同于金钱，就是把生命最珍贵的部分贬为可买卖的商品。"效率就是生命"更危险，它用资本逻辑衡量生命价值——只有能产出、能赚钱、能提高GDP的生命才有价值。它的实际后果是整个社会内卷：效率越高、财富越多，人们的剩余操作时间反而越少，生命越不是自己的。这正是马克思"工人生产的财富越多，他就越贫穷"的当代版本。

再隐蔽一层的，是把生命本身变成需要不断经营的资本——"你的时间花在哪里，就会成为什么样的人""比你优秀的人比你还努力""你怎么过一天就怎么过一生"。它预设你所有时间都必须有产出，这是把资本对工人的要求内化为工人对自己的要求，是马克思说的"工人自己也把自己当作商品"——你不再是人，是需要不断自我投资的人力资本。而且它掩盖了一个事实：业余时间多少不由自己决定，而由必要操作时间决定；让996程序员"早上5点起床自我提升"，是从睡眠时间里再挤血，是进一步的自我剥削。

最后一种，是把人的解放本身变成消费——"你值得拥有更好的""生活需要仪式感""爱自己就买最好的"。消费型资本主义必须让人不断消费才能实现剩余价值，于是把消费包装成爱自己。但消费更多更贵的东西，需要更多钱，需要更多必要操作时间，o'反而更低；消费的满足短暂而欲望无限，你永远追下一个包却永远不满足。真正的品质生活不是消费了多少贵的东西，是你有多少剩余操作时间可以自由地思考、创造、爱、做自己。

从马云的996是福报，到时间就是金钱效率就是生命，到你把时间花在哪就成为什么样的人，到你值得拥有更好的——这些话语看似不同，本质一样：都在掩盖剩余操作率的真实水平，都在让人主动接受甚至追求更长的必要操作，都在让人把生命让渡给资本的逻辑。马克思当年批判西尼耳"最后一小时"、批判混同利润率与剩余价值率的虚假理论；我们今天要批判效率话语、自我提升话语、消费主义话语，它们渗透日常生活每个角落，比马克思时代的经济剥削更隐蔽、更深入、更难反抗。

认识剩余操作率不是书斋数字游戏，而是为了实践：争取解放就是争取提高o'，把时间从必要操作里解放出来——砍掉虚假必要操作、提高必要操作效率。但这两条路在资本主义下都有极限，因为系统正建立在压低大多数人o'之上。所以争取o'提高，最终必然指向对整个社会制度的改造，指向一个生产力为所有人腾出剩余操作时间、必要操作被压到最低、剩余操作成为人的主要存在方式、"每个人的自由发展是一切人的自由发展的条件"的社会。那就是共产主义，那就是生命的真正解放。

## 这份范本沉淀出的"学马克思"方法（行60751–60759）

1. **不是抄句式，是学说理结构**：马克思怎么从一个最普通的事实（商品／工人的一天）逼出概念、公式、规律、批判与结论，就照着这个运动方式分析生命论的对象。
2. **概念必须严格对应**：每个新概念都能在《资本论》找到同构位置（c↔!A、v↔νF₂、m'↔o'），对应不上就是硬套。
3. **批判要针对时代真实的人和真实的话**（行60987 用户提醒）：不批抽象的"资本主义"，批马云"996是福报"、批1981蛇口标语、批具体的时间管理与消费话术，按"引原话→交代背景目的→用剩余操作率分析错处→指出实际后果"四步走。
4. **例子要扎中国文化自己的根**（行61255 用户提醒）：不用泛泛的"一个诗人"，用杜甫《茅屋为秋风所破歌》、曹雪芹"批阅十载增删五次"、陶渊明不为五斗米折腰。
5. **对一切官方数据保持基本怀疑**（行61297 用户提醒，对应马克思用大英图书馆蓝皮书、恩格斯第一手工厂数据）：标注来源、口径、可信度、偏差，并用"小本质大本质大法"专门研究官方"故意不算、故意算错"之处，反向逼近更本质结论。
6. **最高形态是"水流"**：成熟稿去掉小标题、表格、"对比分析"标签，让思想像水一样从一个真实事实一路流到结论，读者感觉不到段落，只被带着往前走。
