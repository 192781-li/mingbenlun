## 一、概念定义

### 1.1 践演（Practice-Evolution）

**践演** = 时间维度上的操作流淌与沉积。

- 践 = 操作、实践、感→应→操作→反馈的闭环
- 演 = 时间流淌、变化、沉积
- 践演是**纵向的**：操作在时间中反复执行，阳的操作沉积为阴的结构

**形式化直觉**：践演对应一个时间序列 `P(t)`，其中 `P(t)` 是时刻 `t` 的操作/过程。操作的反复执行导致结构沉积：`S(t+1) = S(t) ⊕ P(t)`，其中 `⊕` 是沉积操作。

### 1.2 迁演（Migration-Evolution / Spatial-Evolution）

**迁演** = 空间维度上的脉络展开与交织。

- 迁 = 迁移、展开、空间中的移动
- 演 = 变化、交织
- 迁演是**横向的**：多条文明脉络/操作脉络在空间中展开、交织、分叉、汇聚

**形式化直觉**：迁演对应一个空间中的脉络集合 `{C_i(s)}`，其中 `C_i(s)` 是第 `i` 条脉络在空间位置 `s` 的状态。脉络之间可以交织、分叉、汇聚。

### 1.3 磁极螺旋（Magnetic-Pole Spiral）

**磁极螺旋** = 践演与迁演的交织形成的螺旋结构，带有阴阳两极。

- 磁极 = 阴阳两极，阳息阴消 / 阴息阳消
- 螺旋 = 践演（时间）与迁演（空间）的交织形成的三维螺旋
- 螺旋不是闭合的循环，而是**上升的螺旋**：每一圈都比上一圈更高（M值更高/人民更在主位）

**形式化直觉**：磁极螺旋可以参数化为：
```
x(t) = r(t) * cos(ωt)     // 迁演维度（空间展开）
y(t) = r(t) * sin(ωt)     // 践演维度（时间沉积）
z(t) = v * t               // 螺旋上升（M值/人民主位程度）
```
其中 `r(t)` 是螺旋半径，`ω` 是角速度，`v` 是上升速度。阴阳磁极对应螺旋的两个相位：阳相位（M值升）和阴相位（M值降）。

## 二、核心命题（猜想阶段）

### 命题1：践演-迁演同构性

**猜想**：践演（时间沉积）与迁演（空间展开）在结构上是同构的，都是操作→沉积→再操作的循环，只是维度不同。

**数学直觉**：践演的时间序列 `P(t)` 与迁演的空间脉络 `C(s)` 满足相同的递归方程，只是参数解释不同。

**严谨度**：猜想，待证明。

### 命题2：磁极可翻转性

**猜想**：磁极螺旋的阴阳两极可以翻转——阴息阳消可以翻转为阳息阴消，反之亦然。翻转的条件是操作权结构的根本变化（革命）。

**数学直觉**：磁极翻转对应螺旋参数 `r(t)` 或 `ω` 的突变，或者相位的π偏移。

**严谨度**：猜想，待形式化。

### 命题3：螺旋上升性

**猜想**：磁极螺旋不是闭合循环，而是上升的螺旋。每完成一圈（阴阳消长一个周期），M值（人民主位程度）总体趋势是上升的，尽管局部可能下降。

**数学直觉**：`z(t) = v * t` 中的 `v > 0`，即螺旋总体上升。局部下降对应 `dz/dt < 0` 的区间，但长期趋势 `E[dz/dt] > 0`。

**严谨度**：猜想，待证明。

### 命题4：历史不是线性的

**推论**：因为历史是践演-迁演的磁极螺旋，所以历史不是线性的，而是螺旋上升的。历史的"前进"不是直线，而是绕圈上升。

**严谨度**：启发式，是命题3的推论。

## 三、与已有形式化的关系

### 3.1 与ALL pi-calculus（Layer1.v）的关系

Layer1.v 形式化了 ALL pi-calculus 的类型系统和重命名定理。践演-迁演磁极螺旋可以看作是：
- **践演** = pi-calculus 中过程的时间演化（操作的执行序列）
- **迁演** = pi-calculus 中过程的空间分布（并行组合的脉络）
- **磁极螺旋** = 过程演化与分布的交织结构

**待形式化**：将磁极螺旋的概念映射到 pi-calculus 的操作语义中，定义"螺旋"的形式化对应物。

### 3.2 与四规定性的关系

四规定性（边界生成性、内生目的性、操作再生性、环境互动性）可以用来刻画磁极螺旋的"规定性"：
- 边界生成性：螺旋的边界（半径r(t)）是生成的，不是固定的
- 内生目的性：螺旋的上升（z(t)）是内生的，不是外力推动的
- 操作再生性：每一圈操作都再生出新的操作（螺旋的自指性）
- 环境互动性：螺旋与环境互动（磁极翻转的条件来自环境变化）

**待形式化**：用四规定性检验磁极螺旋概念，看是否满足四规定性。

## 四、待形式化的缺口

### 缺口1：螺旋的严格数学定义

当前螺旋的定义是参数化的直觉（x(t), y(t), z(t)），但缺乏严格的范畴论/拓扑学定义。需要确定：
- 螺旋在什么数学结构中？（流形？范畴？拓扑空间？）
- 磁极翻转的严格条件是什么？
- 螺旋上升的度量（M值）如何严格定义？

### 缺口2：践演与迁演的交互机制

践演（时间）与迁演（空间）如何交互？当前只是说"交织"，但缺乏严格的交互机制定义。需要确定：
- 践演如何影响迁演？（时间沉积如何改变空间脉络？）
- 迁演如何影响践演？（空间展开如何改变时间沉积？）
- 交互的数学结构是什么？

### 缺口3：与历史唯物主义的对接

磁极螺旋概念需要与历史唯物主义（生产力/生产关系、经济基础/上层建筑）对接。当前概念是哲学性的，缺乏与历史唯物主义的严格对应。需要确定：
- 磁极螺旋的"阳"对应什么？（生产力？革命？人民？）
- 磁极螺旋的"阴"对应什么？（生产关系？制度？沉积结构？）
- 磁极翻转对应什么？（革命？生产关系变革？）
