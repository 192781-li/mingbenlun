## 三、第一层·单字（字源已查证）
**能**：《说文·能部》"**能，熊屬，足似鹿……能兽坚中，故称贤能；而强壮，称能杰也**"，奴登切。**"能"即"熊"的本字**，金文本象熊形（大嘴利爪、体大善攀）；因熊骨体坚实、强壮有力（"坚中"），遂引申/假借为贤能、能力、能够、能杰；后借义专行，本字反加"火"另造"熊"。
> **字源要害**：汉语"能"不是西文 possible 那种抽象逻辑可能性，而是**从一头强壮的兽身上长出的"有力量、扛得住、做得到、有能耐"**——自带身体性力量感。这与生命论"能阳＝感在可能性空间中实际趋避、把'可'实现为'能'"的力量义、行动义天然契合：能不是"理论上可以"，是"真有本事做到"。

## 四、体系义（卷一为骨）
**1. 能（阳）生于感，感能同一事两面**：从第一人称呈现说叫感，从操作推动说叫能；**感是能的根据，能是感的实现**。灰色宇宙里作用方推来推去但没有"谁"在能、没有"为了自己"的选择；感出现后，自指维持"为了"维持自己而趋避，结构阳才升华为能阳。
**2. 结构阳 vs 能阳（关键二分，防辩证法表面矛盾）**：**结构阳**＝任何操作都有的发用面（风吹石动，风是阳石是阴），灰色宇宙也有，但风不"选择"吹不吹、被因果决定；**能阳**＝感在多种可能性中趋避选择的能力，只在感出现后才有。机械唯物只看见阴（因果决定）、唯意志论只看见能阳（无前提的意志自由），两者都错。
**3. 阴规定可能性空间，阳在其中走且能改地**：可能性空间五层——**物理**（定律，最硬的阴）、**生物**（身体/基因）、**环境**（具体处境）、**社会**（制度关系，奴隶制下奴隶不能"选择"不被奴役）、**符号**（没有"解放"这个词就不能选择解放）。阳不能跳出空间（不能违反物理），但能在空间中选路径，且**能改变空间本身**：劳动改环境、革命改社会、批判改符号。精确关系：**"阴画地，阳在地中走；阳可以改地，但改地也在地中"**（改条件仍需工具资源条件这些阴）——阳主阴从不是征服阴，是在阴的可能性空间中自觉操作。
**4. 能的三层递归**：
- **缄默趋避（细胞）**：趋营养、白细胞趋感染、根向水；第三人称可理化（浓度梯度），但区别在操作**回指自身**（为维持自己而趋，不趋的已死）；是"结构选择"非意识选择，阳只是一点火星。
- **感知行为（动物）**：有记忆情绪欲望。**需要＝结构的缺乏，欲望＝对缺乏的感（"我要"）**；两个来源——本能（基因锁死）与学习（个体扩大空间）；限制：被当下感知推动、不能审视欲望、不能创造新可能；动物不"知道"自己在能，只是能。
- **自觉的能＝自由意志（人）**：符号自指使人不仅能、还知道自己在能，能审视欲望、创造新可能。
**5. 自由＝符号自指在感与行动间插入距离（非不受因果）**：动物"感→行动"（饿了就吃，无距离），人"感→**符号处理**→行动"（"我饿了/我在减肥/这是别人的"）；符号使感可被**审视、比较、延迟、拒绝、升华**，这个处理空间就是自由。人仍在因果网络，但不只是因果一环。**自由四层次**：①选择自由（多中选一）②**审视自由**（反经文化，区分"我真想要"与"别人让我想要"）③创造自由（造工具制度新生活方式＝造新地）④**集体自由**（"我们能"，联合改变社会空间本身＝最大的能）。
**6. 必/可/能三模态（"能，不是必"）**：**必**＝阴完全规定阳、无选择（无生命世界、缄默层几乎必）；**可**＝阴划出空间、阳在其中有选择；**能**＝阳自觉到自己的"可"并实现出来（不只是"可以"，是"能够/有能力/去做"）。**"能，不是必"是与一切决定论、目的论的根本分界**：历史不必然走向解放、资本不必然灭亡、人不必然明性，但这些是"可"的；能不能走成取决于阳（感的自觉、应的联合、做的实践）。**存在论不保证胜利，只告诉人：你能。**若一切必然，斗争就是执行剧本、反成假的。
**7. 敢＝能阳发动的临界**：反自指系统最根本的控制在感层制造恐惧与渺小感（权威/神怒/暴力/资本"别无选择"/"大家都这样"）；F2在显意识拆穿后，若身体仍怕、仍感渺小，能就发动不起来——"道理都懂但做不到"，缺的不是认识，是**敢**（能阳突破恐惧的自觉发动）。
**8. 应改变能（承接迭代24）**：应联合能（个体→集体"我们能"）、应限制能（不以损害他者为代价，麻木者能残忍但其能在萎缩）、应使能自觉（他人回应是能的镜子）、异化的应使能异化（奴隶/工人的能成主人/资本家能的延伸）。
**9. 三个科学/哲学驳论**：①**基因决定论**——基因是阴（生物可能性边界、一阶身体感受），不编码二阶反思、三阶价值、符号自指；节食抗食欲、舍生取义抗求生本能无法用基因解释（必要条件非充分条件，静态边界不能决定动态递归结果）。②**利贝特实验**——无反思随机按键恰是动物层"感→行动"无距离结构，没测量"觉察后撤销/延迟/修改行动"这一自由关键，以偏概全。③**下向因果**（Juarrero）——高层不往低层"推"、不注入能量，而是**约束低层可能性空间、改变概率分布**（如语法约束用词而不推人说话），故符合物理守恒又有因果效力。

## 五、扎根层（新造/升格词＝结构性身体体验）
1. **"能行"的身体感**：说"我能"时身体是提起来、扛得住的劲；说"我不行"时是塌下去的——"能"字那头熊的力量感至今留在身体里，能不是抽象选项，是有没有这股劲。
2. **忍住不吃**：蛋糕在前，动物层"饿→吃"，你在"想吃"和"伸手"之间插进"我在减肥"，手停住——这个被符号撑开的缝隙，就是自由最切近的身体证据。
3. **一个人搬不动、两个人能**：一块巨石单人绝无可能（社会/物理空间画死了地），两个人一合力就起来——"我们能"是集体自由的身体版，能被"应"联合放大。
4. **道理都懂腿却软**：明知该上台发言、该拒绝、该反抗，脑子清楚但身体发紧动不了——这时缺的不是"知"是"敢"，能阳要越过恐惧这个临界点才发得出来。

## 六、易混辨析（钉死边界）
- **能阳 ≠ 结构阳**：结构阳是因果链中的发用面（灰色也有、被决定、无"谁"）；能阳是感的趋避选择（唯生命有、有"为了自己"）。混同则退回机械唯物。
- **自由意志 ≠ 不受因果（唯意志论）**：自由跳不出因果与可能性空间，自由是符号自指在感—行动间撑开的**处理距离**（审视/延迟/拒绝/升华），不是无前提地凭空决定。
- **能 ≠ 必**：能恰恰以"可不这样"为前提；把解放/灭亡说成历史必然，是目的论，取消了斗争的真实性。生命论只说"可"与"你能"，不打包票。
- **能 ≠ 尼采权力意志**：权力意志讲生命自我超越增强（结构相似），但缺"应"对能的限制（不以损害他者为代价）与阶级分析，易滑向强者哲学；生命论的能最高形态是受应约束的**集体自由**，不是超人。
- **自由 ≠ 选项数量多**：消费社会给一百种品牌不是自由的深层；审视被灌输欲望、创造新可能、集体改社会空间才是高层自由。
- **能 ≠ 心理学"能力（ability）"**：能力常被当成个体固定特质；能阳是存在论上持续发生的趋避—实现操作，且被社会空间规定、可被异化也可被联合放大。
- **跨域三级**：亚里士多德 dynamis（潜能）→energeia（现实/实现）＝**结构相似**（"能是感的实现"与之相通，但亚氏带本然目的论，生命论反目的论、"能不是必"）；尼采权力意志＝结构相似（补"应"的限制与集体层）；Frankfurt 一阶/二阶欲望（1971，"想想要什么"、反思认同）＝**严格同构**于"审视自由/符号插入距离"（生命论补被灌输欲望的社会批判与集体自由）；Juarrero 下向因果＝严格同构的机制支持；利贝特实验、基因决定论＝被批判对象（以偏概全/必要当充分）。
