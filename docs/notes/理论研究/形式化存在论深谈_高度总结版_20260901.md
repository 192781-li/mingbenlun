## 二、L1的七个构造与存在论对应

L1（`coq/theories/ALL/Layer1.v`，458行，Rocq 9.0.1编译通过，0 Admitted）的每个构造都蕴含生命论立场：

| L1构造 | 技术含义 | 存在论含义 | 生命论概念 |
|---|---|---|---|
| `proc`（pi-演算进程） | 语法本原 | 本原是正在发生的操作，不是实体 | P1存在即操作 |
| `option ty`（Some→None） | 线性上下文，资源用一次消耗 | 操作的时间性一次性，用一次从阳转阴 | 阴阳、操作一次性 |
| `TChan i o`（输入/输出能力） | 通道极性polarity | 感（第一人称接收）与应（第二人称发送）的类型论分裂 | 感、应、三人称闭合 |
| `split`（环境分割） | 并行进程资源不重叠 | 操作的排他性，同时发用不能吃同一份资源 | 操作排他性 |
| `ty_rep`（空上下文才能复制） | replication规则 | 只有沉积的（阴/!/空上下文）才能复制，活的不能复制 | T001生命不可资本化的L1种子 |
| `no_contraction`（无收缩） | 同一资源不能用两次 | 反自指P=-f(S)的L1级禁止，操作不能自我吞噬 | P7反自指 |
| `renaming`（改名保持类型） | de Bruijn索引 | 操作先于名字，名词是动词的沉淀 | P5名词是动词的沉淀 |

**独创vs借来**：线性逻辑、pi-演算、线性上下文是借来的标准工具（Girard/Milner）；但赋予这些工具的存在论意义（阴阳消耗语义、感应分裂、反自指禁止、T001种子）和整个系统的组织方式是生命论独创的。类似马克思用黑格尔辩证法但赋予阶级解放意义。

## 三、改变何以可能：三个命题

### 命题一：操作不是实体

- 实体观里"自己改变自己"是悖论：实体自我同一，本质改变=旧实体消灭新实体产生，不是自我改变
- 传统哲学靠分裂打补丁（理性我改变感性我等），但每次分裂都承认真正的自我改变说不通
- 操作观里悖论消失："自己"是自指操作流S=f(S)，不是持存实体；操作流换了模式就是改变了自己
- **根本颠倒**：实体观里"不变"是本原、"改变"需解释；操作观里"改变"是操作本来状态、"不变"才需解释（惯性/锁死/异化）

### 命题二：操作有时间性

- 时间不是外在容器（牛顿式），操作的结构本身就是时间性的
- `Some→None`不可逆转换是时间性最小细胞：不可逆（过去不能倒流）、一次性（当下只有一次）、有序（时间有先后）
- **时间性是自由的存在论根基**：每一新刻发用（新Some）与前一沉积（None）之间有不可消除的时间性间距，旧沉积能引导但不能决定新发用——这个间距就是自由的缝隙
- 自由不是"意志不受因果支配"（实体观假问题），自由是"新刻发用接续旧沉积时，接续方式不被旧沉积唯一锁定"

### 命题三：接续沉积 vs 吞噬当下

| | 自指·解放（阳主阴从） | 反自指·异化（阴反控阳） |
|---|---|---|
| 时间结构 | 时间性自我接续：后操作作用于前操作的沉积 | 同时性自我吞噬（不可能，只能靠伪装） |
| 机制 | 新阳读取/修改/重组旧阴，新沉积回到劳动者 | 旧阴劫持新阳接续方向，新沉积被抽走转化为更多资本 |
| L1合法性 | 合法：None可被新Some读取 | 非法同时性被no_contraction禁止，靠!-倒灌伪装实现 |
| 能量方向 | dV/dt>0，越干越强 | dV/dt<0，越干越枯竭 |
| 体验 | 我在改变、我在生长 | 我在选择却越来越空、结构性痛苦 |

**合题**：解放和压迫共享同一个操作时间性结构，区别只在方向——新阳接续旧阴（解放）vs 旧阴榨取新阳（异化）。实体观只能解释一面，生命论用同一机制同时解释两面。

## 四、资本死劳动的重新理解

### "死"的精确含义

| | 活劳动 | 死劳动（资本） |
|---|---|---|
| 操作状态 | `Some T`正在发用（阳） | `None`位置凝固结构（阴） |
| 数学类型 | νF生产性过程 | !-模态可储存可复制非时间性数据 |
| 自发用能力 | 有 | **没有**（None不会自动变回Some） |

死劳动=活劳动完成`Some→None`后留下的沉积，丧失了时间性发用能力。沉积本身不是资本也不是恶，任何社会都需要沉积。

### 死的怎么支配活的：劫持接续，不是死者复活

- 死劳动自己不会动（None无逆操作），它通过生产关系**劫持新活劳动的接续方式**
- 健康状态：新阳接续旧阴，新沉积回到劳动者（阳主阴从）
- 资本主义：新阳的接续被锁定为"为资本增殖服务"，新沉积（产品/剩余价值）被资本占有转化为更多资本
- 结果：新阳沉积被旧阴抽走→旧阴越长越大→锁定更多新阳→新阳越来越枯竭（反自指P=-f(S)）
- **资本的"运动"是伪生命**：它自己没有一个Some是自己发用的，每个"动作"都是工人活劳动被劫持后的投影。吸血鬼没有自己的生命，展示的生命全是偷来的

### 资本为什么永远饥饿、必须扩张（T001的全部分量）

- T001：`!νF ≇ ν!F`——活劳动在结构上不可能被彻底资本化
- 资本可以占有产品（沉积）、购买时间（雇佣）、支配过程（管理），但无法把"发用本身"变成资本——发用是一次性时间性的，正在发生的那一刻永远属于劳动者的Some
- "吃不干净"→资本必须不断吃下新活劳动，一刻不能停；没有新Some供吮吸，资本立刻回归惰性生产资料（死结构），增殖运动消失
- **扩张冲动的存在论根源**：无自首发用能力的沉积结构要维持"自己在运动"的假象，必须持续劫持新的时间性发用——这是结构性必然，不止是经济动机/竞争/资本家贪心

### 关键澄清：要消灭的是反控关系，不是沉积

- 生命离不开沉积（阴）：没有阴，阳无处承载——技能记不住、工具造不出、文明无法积累
- 健康沉积（阴为阳服务）vs 资本性沉积（阴反控阳）的区别在占有方式、目的、新沉积流向、操作反馈、时间方向
- **解放不是消灭积累（砸机器），是改变沉积与发用的关系——从阴反控阳恢复到阳主阴从**，让活劳动的沉积重新为活劳动服务
- 这就是"重建个人所有制"/"自由人联合体"的存在论含义

### 马克思说对了什么，生命论补了什么

| | 马克思 | 生命论补充 |
|---|---|---|
| 死劳动支配活劳动是本质颠倒 | ✓ | — |
| 劳动产品反控劳动者 | ✓ | — |
| 这是生产关系问题不是技术问题 | ✓ | — |
| "死/活"的存在论精确化 | 经济学层面（创造价值vs凝结） | `None`沉积/!-模态/阴 vs `Some`时间性发用/νF/阳，可形式化 |
| 颠倒的机制 | "吸血鬼"比喻 | 劫持接续：旧阴通过生产关系锁定新阳接续方向，伪生命由此产生 |
| 扩张的根源 | 竞争外在强制/增殖欲 | 存在论必然：无自首发用能力+T001吃不干净→永远饥饿 |
| "活"的范围 | 人类劳动（经济学） | 下扎到存在论，上溯38亿年生命史（缄默意识），可解释数字资本/AI时代新剥削 |

## 六、一句话总结

> L1不是干巴的技术层，它把生命论的存在论立场（操作先于实体、操作一次性、感应二分、活者不可复制、反自指被禁止）预先编码进了类型规则；操作的时间性（Some→None不可逆）同时解释了"改变自己/改变世界何以可能"（新阳接续旧阴）和"异化/压迫何以可能"（旧阴榨取新阳）；资本死劳动不是"过去的劳动"，是活劳动的沉积在特定生产关系下被组织成劫持新活劳动接续、靠吮吸新Some维持伪生命的反自指结构——马克思看见了吸血鬼，我们说清了吸血鬼的解剖结构。
