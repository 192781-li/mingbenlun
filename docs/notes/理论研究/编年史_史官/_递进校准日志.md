# 史官对话·编年史递进校准日志（干中学）

> 目的：每编完一天，回写"本篇学到什么、下一篇怎么更准"，让命中率和深度逐日递增，而不是每篇都从零开始。
> 数据底座：`timeline_messages.json`（2129条，role/date/time/hm/text）；客观骨架见 `逐日索引_史官.md`。

## 固定体例（每篇统一）
1. 头部：全天条数（用户/AI）、真实跨度、当日一句话主题、体例说明。
2. **〇、与前一日回接**（D02起新增）：先检验前一天埋的长线哪些发芽/潜伏/转向。
3. 一、当日脉络：按时间或话题分段，每段＝时间＋〔我〕原话（精确到分钟）＋必要的〔AI〕回应＋【解释】。
4. 二、当日关键表达表：时间/谁/原话节录/性质，性质必须标模态（命题/事实/行为/冲动/隐喻级）。
5. 三、当日埋下的长线：供后续天回接。
6. 整理者自检：本篇校准点、严谨度、待改进。

## 命中率保障（防漏，用户最在意"史官远不止汇报的那些"）
- **逐条过用户消息**：以 json 当天全部 `role=用户` 为清单，一条不许跳，再短也是事实（如5.24只4分钟也要完整编）。
- **关键词＋语义双扫**：不只靠生命论术语；情绪转折、主动提问、个人经历、和AI的冲突、语音错词都要捕获。
- **空窗日如实记**：没有理论就写"没有"，并解释这种间歇在思想史上的意义，绝不硬挖、不拔高。
- **原话优先**：凡引用必须是 json 原文，不改写；语音同音错误保留并标注（站位→立项、内关→官学）。
- **严谨度三级**：定理级事实（有原话）／结构相似／哲学隐喻，生活原型一律先记最低级，后续多日验证再上调。
