3. **拯救者悖论是关系存在论的心理模具**——他既想拯救别人（马克思/拯救家人），又渴望被拯救（女孩/姥姥姥爷/真理），这个张力驱动了"关系作为存在论根基"的理论建构。理论本身成为了"第三位"——既不是纯粹的拯救者，也不是纯粹的被拯救者，而是连接二者的中介。
4. **自学方式与哲学方式严格同构**——都是拒绝被体制定义节奏、自己掌握主体性。自学的"在家效率高"和哲学的"批判教科书僵死唯物主义"是同一个姿态的两个侧面。

6. **最终判断（命题级）**：奠基不是在理论著作中完成的，奠基是在你完全有理由不继续存在的那一夜，发现自己仍然选择了继续思考的时候，已经完成了的。
