# 大六壬排盘代码使用说明

> 工具路径：`tools/术数工具包/liuren_paipan.py`
> 大六壬：三式之首，术数之王，占断最详
> 生命论视角：大六壬是特定时空点的能量态势分析（感的层面），不是宿命预言

## v2.0 更新（2026-09-04）

### 1. 涉害法标准算法（修复简化版）

**之前**：涉害法直接取第一个下克上，不准确。

**现在**：标准涉害深度算法——从日干寄宫顺时针数到天盘神的地盘位置，经过的地支中五行克日干的数量即为涉害深度，取最深者为初传。

- 克日干的五行 = 官杀（如日干木，金克木，申酉为官杀）
- 验证案例：2026-08-18 2时感情课，涉害深度2，初传巳（之前简化版初传未，标准算法更准确）

### 2. 年命行年计算

- **年命**：出生年份的地支（如2008年=戊子，年命子）
- **行年**：男命从寅起顺行，女命从申起逆行
  - 男命：一岁在寅，二岁在卯...顺数
  - 女命：一岁在申，二岁在未...逆数
- 命令行参数：`--birth=出生年 --gender=男/女`

### 3. 命令行新用法

```bash
# 带年命行年的排盘
python3 tools/术数工具包/liuren_paipan.py 2026 9 4 0 测试 --birth=2008 --gender=男

# 输出JSON
python3 tools/术数工具包/liuren_paipan.py 2026 9 4 0 测试 --birth=2008 --gender=男 --json
```

## 一、功能概述

本工具实现大六壬完整排盘，输入公历年月日时，输出：

1. **基本信息**：占时、月将（含月将名）、日柱、旬空、驿马
2. **天盘地盘对照**：十二地支天盘排布
3. **四课**：干上、干阴、支上、支阴（天盘+地盘）
4. **三传**：初传、中传、末传（含天将），九宗门起法
5. **十二天将**：贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后
6. **贵人信息**：贵人地支、阳贵/阴贵、顺行/逆行
7. **课体判断**：贼克课、比用课、涉害课、遥克课、昴星课、别责课、八专课、伏吟课、反吟课
8. **空亡分析**：三传是否逢空
9. **生命论解读**：三传=感→应→操作，空亡=名实不符，课体=结构倾向

## 三、核心算法说明

### 1. 月将确定（太阳过宫）

月将以中气为界（不是节气），太阳过宫即换将：

| 中气后 | 月将 | 月将名 |
|--------|------|--------|
| 大寒后 | 子 | 神后 |
| 雨水后 | 亥 | 登明 |
| 春分后 | 戌 | 河魁 |
| 谷雨后 | 酉 | 从魁 |
| 小满后 | 申 | 传送 |
| 夏至后 | 未 | 小吉 |
| 大暑后 | 午 | 胜光 |
| 处暑后 | 巳 | 太乙 |
| 秋分后 | 辰 | 天罡 |
| 霜降后 | 卯 | 太冲 |
| 小雪后 | 寅 | 功曹 |
| 冬至后 | 丑 | 大吉 |

> 已验证14个节气点全部正确。

### 2. 月将加时（天盘排布）

月将加在占时上，天盘顺排：
- 例如：月将巳，占时申，则天盘申位是巳，酉位是午，戌位是未...以此类推

### 3. 日干寄宫

| 日干 | 寄宫 |
|------|------|
| 甲 | 寅 |
| 乙 | 辰 |
| 丙戊 | 巳 |
| 丁己 | 未 |
| 庚 | 申 |
| 辛 | 戌 |
| 壬 | 亥 |
| 癸 | 丑 |

### 4. 四课起法

- **第一课（干上）**：日干寄宫的天盘神
- **第二课（干阴）**：第一课天盘神的地盘位置上的天盘神
- **第三课（支上）**：日支的天盘神
- **第四课（支阴）**：第三课天盘神的地盘位置上的天盘神

### 5. 三传起法（九宗门）

按优先级：

1. **贼克法**：四课中只有一个下克上，取其天盘为初传
2. **比用法**：多个下克上，取与日干比和者为初传
3. **涉害法**：多个下克上且不比和，取涉害深者为初传（当前为简化版，取第一个）
4. **遥克法**：无下克上，有上克下，取被克者为初传（蒿矢/弹射）
5. **昴星法**：四课无克，阳日取酉上神，阴日取酉下神
6. **别责法**：四课不全，取日干合神为初传
7. **八专法**：日支与日干寄宫相同，取日干寄宫上神为初传，顺数三位为中传，再顺数三位为末传
8. **伏吟法**：月将=占时（天盘=地盘），有克取克，无克取马星
9. **反吟法**：月将与占时相冲（天盘与地盘相冲），有克取克，无克取马星

**中传末传**：初传的天盘神为中传，中传的天盘神为末传（三传是天盘的链条）

### 6. 十二天将排布

- **贵人起法**：甲戊庚牛羊（丑未），乙己鼠猴乡（子申），丙丁猪鸡位（亥酉），壬癸蛇兔藏（巳卯），六辛逢马虎（午寅）
- **阳贵/阴贵**：卯时到酉时（5-19点）用阳贵人，其他用阴贵人
- **顺行/逆行**：贵人在亥子丑寅卯辰为顺行，在巳午未申酉戌为逆行
- **十二天将顺序**：贵人、螣蛇、朱雀、六合、勾陈、青龙、天空、白虎、太常、玄武、太阴、天后

### 7. 旬空（空亡）

日柱旬空：根据日柱干支确定所在旬，旬中地支未满的两个为空亡。
- 甲子旬空戌亥、甲戌旬空申酉、甲申旬空午未、甲午旬空辰巳、甲辰旬空寅卯、甲寅旬空子丑

### 8. 驿马

- 申子辰马在寅、亥卯未马在巳、寅午戌马在申、巳酉丑马在亥

## 五、已知限制

1. **涉害法为简化版**：当前涉害法直接取第一个下克上，未实现标准涉害深度计算（从日干寄宫数到天盘地盘位置，经过的克日干地支数）。后续需优化。
2. **节气日期为近似值**：使用固定日期（如雨水=2月19日），实际每年有1-2天波动。精确排盘需接入天文算法或API。
3. **贵人起法为通用版**：部分流派贵人起法有差异（如甲戊庚牛羊 vs 甲戊庚牛羊的阴阳贵人分配），当前采用最通用版本。
4. **课体判断为基础版**：未实现更细的课体分类（如重审课、知一课、八专课的细分等）。
5. **未实现年命、行年**：大六壬占断需结合年命（生年地支）和行年（当年行年地支），当前未实现。
6. **未实现神将五行生克分析**：当前只排盘，未做神将生克、旺衰、类神分析。

## 六、生命论视角的使用原则

1. **大六壬是感的层面，不是命的判决书**：大六壬描述的是特定时空点的能量态势（感），不是注定的结果。三传是感→应→操作的三个阶段，操作（末传之后）决定结果。
2. **空亡不是"没有"，是"名实不符"**：空亡的位置看起来有实际没有，需要操作还原去验证。空亡可填实——通过实际操作让名实相符。
3. **课体是结构倾向，不是结果**：贼克课主有冲突、涉害课主有反复、昴星课主不明朗——这些是结构倾向，不是注定结果。结构硬，操作软，阳主阴从。
4. **三传是能量流转阶段，不是剧情脚本**：初传是当前爆发点（感），中传是过程中的变化（应），末传是操作后的收敛方向。三传告诉你能量往哪走，不告诉你必须怎样。
5. **月将加时是坐标系，不是命运**：月将加时确定的是当前时空点的能量坐标系，在这个坐标系里看四课三传的关系。换一个时辰，坐标系就变了，课也变了——这说明课是"此时此地"的态势，不是永恒的命。

## 七、类神系统（v2.1新增，2026-09-09）

### 7.1 什么是类神

类神 = 占问的那件事在符号系统中的**操作闭包**。

占不同事取不同类神：
- 占感情 → 正财（正缘）、偏财（偏缘）、天后（女方）、青龙（男方）
- 占考试 → 正印（文书/学历）、朱雀（文笔/表达）、青龙（贵人/顺利）
- 占事业 → 正官（稳定工作）、七杀（创业/挑战）、青龙（贵人）
- 占财运 → 正财（稳定收入）、偏财（意外/投资）、青龙（财源）

**类神不是盘给的，是问题决定的。** 同一个盘，问不同的事，取不同的类神，分析完全不同。

### 7.2 自动识别

代码会根据占问内容自动识别占问类型：

```bash
python3 liuren_paipan.py 2026 8 18 2 感情
python3 liuren_paipan.py 2026 9 5 10 考试
python3 liuren_paipan.py 2026 9 5 10 事业
```

支持的占问类型：感情、婚姻、事业、工作、考试、升学、财运、投资、失物、健康、疾病、出行、搬家、官司、口舌、合作、父母、兄弟、子女、贵人、桃花。

如果占问内容不匹配任何类型，返回"通用"分析（日干=自己，日支=对方/环境）。

### 7.3 类神状态分析

每个类神会自动分析：
- **落宫**：类神在哪个地支宫
- **五行**：类神的五行属性
- **旺衰**：旺/相/休/囚/死（以月令为准）
- **空亡**：是否逢空（名实不符）
- **状态**：综合描述（能量充足/不足、名实不符、落宫）

### 7.4 输出示例

```
【类神分析】（占问类型：感情）
  主要类神：
    - 正财（正缘/稳定关系（男占））：丑宫，相，不空，能量充足，在丑宫
    - 偏财（偏缘/短暂关系（男占））：丑宫，相，不空，能量充足，在丑宫
    - 天后（女方/女性）：申宫，死，不空，能量不足，在申宫
    - 青龙（男方/男性）：寅宫，休，不空，能量不足，在寅宫
  辅助类神：
    - 六合（结合/合作通道）：辰宫，相，不空
    - 太阴（暗恋/隐藏感情）：酉宫，死，不空
    - 朱雀（沟通/表达）：巳宫，旺，不空
  综合判断：占感情，主要类神能量不足，适合积累不宜冒进，等旺相窗口再操作。
```

### 7.5 类神系统的生命论意义

1. **类神是操作闭包，不是神秘用神**：类神代表你问的那件事在盘上的投影，不是什么神秘的"用神"
2. **类神旺衰是能量状态，不是吉凶判决**：类神旺=这件事当前能量充足，类神衰=能量不足，不是"成"或"败"
3. **空亡是名实不符，需要操作填实**：类神空亡=看起来有实际没有，需要通过实际操作让名实相符
4. **综合判断是操作建议，不是宿命预言**："适合积累不宜冒进"是操作建议，不是"你一定不行"

### 7.6 硬度分级

| 内容 | 硬度 | 说明 |
|------|------|------|
| 类神定位（占什么事取什么符号） | 硬 | 形式规则，不会错 |
| 类神落宫、五行、旺衰、空亡 | 硬 | 形式运算，可复现 |
| 类神状态描述（能量充足/不足） | 中 | 结构推断，有一定可靠性 |
| 综合判断（操作建议） | 中 | 从结构推操作，需结合具体情况 |
| 类神应期（什么时候应验） | 软 | 象义联想，不可靠 |
