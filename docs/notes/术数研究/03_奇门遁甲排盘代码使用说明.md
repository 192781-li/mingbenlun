## 一、工具概述

`qimen_paipan.py` 是一个奇门遁甲排盘工具，支持：

- 阴阳遁判断（根据节气）
- 拆补法定局（超神接气）
- 天地盘排盘
- 九星、八门、八神排布
- 空亡、马星标注
- 伏吟、反吟判断
- 命主信息输入（可选）

**设计原则**：代码化排盘，消除手工排盘的人为错误，确保排盘结果可复现、可验证。

---

## 二、快速开始

### 2.1 命令行使用

```bash
python3 tools/术数工具包/qimen_paipan.py
```

直接运行会使用当前系统时间排盘，并输出完整的奇门盘。

### 2.2 指定时间排盘

```bash
python3 tools/术数工具包/qimen_paipan.py --year 2026 --month 8 --day 29 --hour 22
```

参数说明：
- `--year`：年份（4位）
- `--month`：月份（1-12）
- `--day`：日期（1-31）
- `--hour`：小时（0-23，24小时制）

### 2.3 指定命主信息

```bash
python3 tools/术数工具包/qimen_paipan.py --year 2026 --month 8 --day 29 --hour 22 --name 北原慢热 --gender male --bazi "戊子 辛酉 戊辰 丙辰"
```

参数说明：
- `--name`：命主姓名（可选，仅用于输出显示）
- `--gender`：性别（male/female，可选）
- `--bazi`：八字（可选，格式"年柱 月柱 日柱 时柱"）

## 三、Python模块调用

### 3.1 导入模块

```python
import sys
sys.path.append('tools/术数工具包')
from qimen_paipan import QimenPan
```

### 3.2 创建排盘对象

```python
# 使用指定时间
pan = QimenPan(year=2026, month=8, day=29, hour=22)

# 使用当前时间
pan = QimenPan()  # 自动使用系统当前时间
```

### 3.3 获取排盘结果

```python
# 获取完整排盘信息（字典）
result = pan.get_pan()

# 打印排盘
pan.print_pan()

# 获取局数
ju = pan.ju  # 如"阴遁4局"

# 获取天地盘

jiuxing = pan.jiuxing    # 九星字典 {宫位: 星名}
bamen = pan.bamen        # 八门字典 {宫位: 门名}
bashen = pan.bashen      # 八神字典 {宫位: 神名}

# 获取空亡和马星
kongwang = pan.kongwang  # 空亡宫位列表

# 判断伏吟反吟
```

## 五、排盘原理

### 5.1 阴阳遁判断

- **阳遁**：冬至到夏至（阳气上升），顺排六仪
- **阴遁**：夏至到冬至（阴气上升），逆排六仪

判断依据：节气。代码内置24节气表，根据日期判断当前节气，确定阴阳遁。

### 5.2 拆补法定局

拆补法是奇门遁甲定局的主流方法，核心是：

1. **符头**：每个节气的第一个甲日或己日为符头
2. **超神**：符头早于节气到来，称为超神
3. **接气**：符头晚于节气到来，称为接气
4. **正授**：符头与节气同一天到来，称为正授

拆补法的局数确定：
- 每个节气分上中下三元，每元5天
- 上元：符头到符头+4天
- 中元：符头+5天到符头+9天
- 下元：符头+10天到符头+14天
- 局数：根据节气对应的局数表确定（如冬至一七四、小寒二八五等）

### 5.3 天地盘排盘

1. **地盘**：根据局数，将六仪（戊己庚辛壬癸）和三奇（乙丙丁）排布在九宫
2. **天盘**：根据旬首（时辰的六甲），将地盘的旬首所在宫位的天干移到值符宫，其他天干按顺序旋转

### 5.4 九星八门八神排布

- **九星**：天蓬星在坎1宫起始，按阳遁顺排、阴遁逆排
- **八门**：休门在坎1宫起始，按阳遁顺排、阴遁逆排
- **八神**：直符在值符宫起始，按阳遁顺排、阴遁逆排

### 5.5 空亡马星

- **空亡**：根据日旬确定，如甲子旬空戌亥、甲戌旬空申酉等
- **马星**：根据日支确定，如申子辰马在寅、亥卯未马在巳等

## 六、使用场景

### 6.1 决策分析

奇门遁甲最适合用于**特定时空下的决策分析**：

- 这件事现在做还是以后做？
- 这个方向有利还是那个方向有利？
- 这个人是贵人还是小人？
- 这个时机是生门还是死门？

### 6.2 事件预测

- 事情的发展趋势（三传/八门的变化）
- 关键时间节点（空亡填实、马星冲动）
- 关键人物（值符、值使、年命落宫）
- 关键方位（九宫位的吉凶）

### 6.3 与大六壬的配合

- **大六壬**：擅长分析事情的整体能量结构和关系网络，适合"这件事会怎样"
- **奇门遁甲**：擅长分析特定时空下的决策和方位，适合"我现在该怎么做、往哪个方向做"

两者配合使用，可以从宏观结构和微观决策两个层面分析问题。

## 七、注意事项

### 7.1 排盘验证

排盘结果需要交叉验证：
1. 局数是否正确（节气、符头、上中下元）
2. 天地盘是否正确（六仪三奇的排布）
3. 九星八门八神是否正确（顺逆方向）
4. 空亡马星是否正确（日旬、日支）

建议与专业排盘软件对比验证，确保代码正确。

### 7.2 解读边界

- **硬的**：局数、天地盘、星门神门的位置、空亡马星（形式运算，不会错）
- **中等的**：从宫位组合推断事情的发展趋势、吉凶倾向（结构推断，有一定可靠性）
- **软的**：从星门神门的象义推断具体事件细节、人物特征（象义联想，不可靠）

**原则**：硬的可以直接说，中等的要说"倾向于"，软的要说"可能是""供参考"。

### 7.3 操作还原

任何奇门判断必须能翻译成具体的操作建议：

- "生门在坎1宫" = 空话
- "当前北方（坎1宫）有生发的能量，适合往北方发展，或做与水相关的事" = 可操作的判断
