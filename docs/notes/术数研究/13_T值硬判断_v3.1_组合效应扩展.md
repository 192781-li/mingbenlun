> 验证：7案例一致率86%（6/7）

## 一、v3.1新增组合

### 1.1 伤官佩印

**条件**（同时满足）：
1. 食伤当令（月令=食伤）或食伤力量 > 30
2. 食伤力量 > 印星力量（伤官旺需要印制）
3. 印星透干
4. 印星有根

**修正**：
- 制住比例 = min(印星力量 / 食伤力量, 0.4)
- 食伤力量 × (1 - 制住比例)

**效果**：伤官泄身被印星制住，泄身力量减少，T值上调。

**为什么需要条件2（食伤>印星）**：
如果印星力量已经大于食伤，印星自然能制住伤官，不需要额外修正。只有伤官旺过印星时，才需要"佩印"来平衡。

### 1.2 财滋弱杀

**条件**（同时满足）：
1. 财星当令或财星力量 > 20
2. 0 < 官杀力量 < 15（官杀弱但有）
3. 官杀有根（地支有官杀本气或藏干≥0.3）

**修正**：
- 滋生比例 = min(财星力量 / 官杀力量, 0.4)
- 官杀力量 + 官杀力量 × 滋生比例

**效果**：财星生弱杀，七杀力量增强，克身力量增加，T值下调。

### 唯一矛盾：鲁迅

鲁迅八字：辛巳 丁酉 壬戌 辛丑
- 壬水日主，酉月金旺（印星当令），印星力量51分
- 传统说"身弱/伤官佩印"——但八字木=0（伤官极弱），"伤官佩印"说法不准确
- 酉月印星当令，壬水得印生，**偏强更合理**
- 可能是传统判断本身有误，或时辰有争议

## 四、组合效应的优先级

当多个组合同时存在时，按以下顺序执行（因为前面的修正会改变力量，影响后面的判断）：

1. **杀印相生**（最常见、最明确）
2. **食神制杀**（和杀印相生互斥——有印化杀就不需要食伤制杀）
3. **伤官佩印**（食伤旺时）
4. **财滋弱杀**（官杀弱时）

实际实现中，每步修正后更新shishen_power，确保后续判断基于修正后的力量。

## 五、生命论翻译

四种组合对应νF₂中四种操作耦合模式：

| 组合 | 生命论对应 |
|------|-----------|
| 杀印相生 | 制约性操作被建构性操作转化——压力变成资源 |
| 食神制杀 | 创造性操作制约破坏性操作——表达化解压力 |
| 伤官佩印 | 过度表达被学习吸收平衡——批判需要知识兜底 |
| 财滋弱杀 | 资源性操作滋养制约性操作——欲望放大压力 |

**核心洞察**：能量不是孤立的，操作之间的耦合改变了系统的能量结构。T值从"力量对比"升级到"关系网络"，对应生命论中"操作的耦合是系统演化的关键机制"。
