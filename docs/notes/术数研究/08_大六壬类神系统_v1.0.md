## 一、类神系统的本质（生命论视角）

### 1.1 什么是类神

传统术数中，"类神"（也叫"用神"）是指**占问某件事时，代表这件事的那个符号**。

比如：
- 占婚姻，取"天后"代表女方、"青龙"代表男方
- 占财运，取"财爻"代表钱财
- 占疾病，取"白虎"代表病症、"天医"代表医生

### 1.2 生命论重新定义

用生命论的语言，类神的本质是：

> **类神 = 你占问的那件事在符号系统中的"操作闭包"。**

它不是一个神秘的"用神"，是你问的那件事本身在盘上的投影。你问婚姻，婚姻这个"操作"在盘上对应"天后+青龙+财爻"；你问事业，事业这个"操作"对应"青龙+官鬼+印绶"。

**类神不是盘给你的，是你问的问题决定的。** 同一个盘，问不同的事，取不同的类神，分析完全不同。

这就是为什么"排盘相同，断事不同"——不是盘不准，是类神取错了。

### 1.3 类神系统的三个层次

| 层次 | 内容 | 硬度 |
|------|------|------|
| **类神定位** | 占什么事取什么符号 | 硬（形式规则，不会错） |
| **类神状态** | 类神在盘上的旺衰、空亡、生克 | 中（结构推断，有一定可靠性） |
| **类神应期** | 类神什么时候填实、冲动、应验 | 软（象义联想，不可靠） |

**原则**：类神定位直接说，类神状态说"倾向于"，类神应期说"可能是""供参考"。

## 二、类神分类表（按占问类型）

### 2.1 感情婚姻类

| 占问 | 主要类神 | 辅助类神 | 生命论对应 |
|------|---------|---------|-----------|
| 男占女友/妻子 | 财爻（正财=正缘，偏财=偏缘） | 天后（女方）、六合（结合）、太阴（暗恋） | 财=现实关系中的"应"的对象 |
| 女占男友/丈夫 | 官鬼（正官=正缘，七杀=偏缘） | 青龙（男方）、六合（结合） | 官鬼=关系中的"制约/承诺"结构 |
| 感情发展 | 六合（结合）、太阴（隐藏）、朱雀（沟通） | 三传（发展过程） | 三传=感情从感→应→操作的流转 |
| 桃花/缘分 | 咸池、桃花、天后 | 玄武（暗昧）、太阴 | 桃花=感的通量增大的时期 |

**关键判断**：
- 正财/正官 = 正缘结构（稳定、承诺、长期）
- 偏财/七杀 = 偏缘结构（短暂、激烈、不稳定）
- 六合 = 结合的通道（有六合=容易在一起）
- 空亡 = 名实不符（看起来有实际没有，需要填实）

## 三、类神状态判断（旺衰、空亡、生克）

### 3.1 旺衰判断

类神的旺衰由以下因素决定：

| 因素 | 含义 | 判断 |
|------|------|------|
| **月令** | 类神五行在当月的旺相休囚死 | 当令=旺，失令=衰 |
| **生扶** | 类神被其他五行生扶 | 生扶多=旺 |
| **克泄** | 类神被其他五行克泄 | 克泄多=衰 |
| **地盘/天盘** | 类神在地盘还是天盘 | 天盘=动，地盘=静 |

**旺相休囚死**（以月令为准）：
- 旺：与月令同五行（如木月见木）
- 相：月令生的五行（如木月见火）
- 休：生月令的五行（如木月见水）
- 囚：克月令的五行（如木月见金）
- 死：月令克的五行（如木月见土）

### 3.2 空亡判断

- 类神逢空亡 = 名实不符，看起来有实际没有
- 空亡不是"没有"，是"还没填实"
- 填实 = 类神对应的地支在流年/流月/流日出现
- 冲实 = 空亡被冲开（如申酉空，寅卯冲）

### 3.3 生克判断

- 类神被生 = 有赋能、有支撑
- 类神被克 = 有制约、有阻碍
- 类神生他 = 消耗、输出
- 类神克他 = 制约、掌控

### 3.4 类神状态的操作建议

| 类神状态 | 操作建议 |
|---------|---------|
| 旺相+不空+被生 | 抓住窗口，主动操作，类神能量充足 |
| 旺相+空亡 | 能量有但名实不符，需要填实（等时间或主动操作验证） |
| 休囚+不空+被生 | 能量不足但有支撑，适合积累，不宜冒进 |
| 休囚+空亡+被克 | 最困难状态，暂停操作，先养能量，等窗口 |
| 被克严重 | 有阻碍，找生扶的方向（贵人/时间/方位） |

## 四、类神与三传的关系

三传是事件的流转过程（初传=感，中传=应，末传=操作），类神是事件的主体。两者结合分析：

| 组合 | 含义 |
|------|------|
| 类神在初传 | 事件刚开始就出现，感的层面就有了 |
| 类神在中传 | 事件发展过程中出现，应的层面 |
| 类神在末传 | 事件收敛时出现，操作的结果 |
| 类神不上三传 | 事件不明显，需要看四课和类神落宫 |
| 类神空亡+在末传 | 结果空，名实不符，需要填实 |
| 类神旺相+在末传 | 结果好，操作有成果 |

## 七、禁忌与边界

1. **类神不是宿命**：类神旺不等于"一定成"，类神衰不等于"一定败"。类神只是告诉你当前能量结构，操作权在人。
2. **类神可以转化**：偏财可以通过长期稳定的操作转化为正财，七杀可以通过纪律化操作转化为正官。能量模式不是固定的，操作可以改变它。
3. **多类神兼看**：占一件事不只看一个类神，主要类神+辅助类神+三传+课体综合判断。
4. **硬度分级**：类神定位是硬的，类神状态是中等的，类神应期是软的。标注清楚，不混淆。
5. **操作还原**：任何类神判断必须能翻译成具体操作建议。"正财旺"=空话，"正财旺相，感情能量充足，适合主动表达，但末传空亡需要时间填实"=可操作判断。
