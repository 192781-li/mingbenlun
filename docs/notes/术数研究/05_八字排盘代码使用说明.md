# 八字排盘代码使用说明

> 工具路径：`tools/术数工具包/bazi_paipan.py`
> 生命论视角：八字是初始能量结构S₀，不是命运判决书。M=α×T×N，操作（N）主导，结构（α+T）从属。

---

## 一、功能概述

本工具实现完整的八字排盘，输入公历年月日时，输出：

1. **四柱八字**：年柱、月柱、日柱、时柱（天干地支）
2. **十神**：天干十神、地支藏干十神
3. **藏干**：各地支本气、中气、余气
4. **纳音五行**：六十甲子纳音
5. **空亡**：日柱旬空
6. **五行统计**：天干+地支藏干加权统计（本气0.6、中气0.3、余气0.1）
7. **日主旺衰分析**：得令、得地、得势三维度评分（简化版）
8. **用神建议**：基于旺衰的喜用忌神
9. **十神统计**：各十神数量加权统计
10. **特殊格局**：从格、五行缺、一字格等检测
11. **大运**：起运年龄、顺逆、8步大运（干支、十神、纳音、起运年份）
12. **流年**：近10年流年（干支、十神、纳音）
13. **生命论解读**：α/T/N/M四维解读

## 三、核心算法说明

### 1. 年柱计算

- 以**立春**为界（一般2月4日左右），立春前算上一年
- 年干：`(year - 4) % 10`
- 年支：`(year - 4) % 12`

### 2. 月柱计算

- 以**节**为界（不是气）：立春、惊蛰、清明、立夏、芒种、小暑、立秋、白露、寒露、立冬、大雪、小寒
- 月支：寅月（立春后）、卯月（惊蛰后）...丑月（小寒后）
- 月干：**五虎遁**——甲己之年丙作首，乙庚之岁戊为头，丙辛必定寻庚起，丁壬壬位顺行流，戊癸何方发，甲寅之上好追求

### 3. 日柱计算

- 基准日：**1900年1月1日为甲戌日**（六十甲子索引=10）
- 目标日干支索引：`(10 + 目标日与基准日的天数差) % 60`
- 天干索引 = 干支索引 % 10
- 地支索引 = 干支索引 % 12

### 4. 时柱计算

- 时支：23-1点=子，1-3点=丑，3-5点=寅...（注意：23点算子时，属于第二天）
- 时干：**五鼠遁**——甲己还加甲，乙庚丙作初，丙辛从戊起，丁壬庚子居，戊癸何方发，壬子是真途

### 5. 十神计算

以日干为"我"，根据五行生克和阴阳同异判断：

| 关系 | 同性 | 异性 |
|------|------|------|
| 同我者 | 比肩 | 劫财 |
| 生我者 | 偏印 | 正印 |
| 我生者 | 食神 | 伤官 |
| 克我者 | 七杀 | 正官 |
| 我克者 | 偏财 | 正财 |

### 6. 地支藏干

| 地支 | 本气 | 中气 | 余气 |
|------|------|------|------|
| 子 | 癸 | - | - |
| 丑 | 己 | 辛 | 癸 |
| 寅 | 甲 | 丙 | 戊 |
| 卯 | 乙 | - | - |
| 辰 | 戊 | 乙 | 癸 |
| 巳 | 丙 | 庚 | 戊 |
| 午 | 丁 | 己 | - |
| 未 | 己 | 丁 | 乙 |
| 申 | 庚 | 壬 | 戊 |
| 酉 | 辛 | - | - |
| 戌 | 戊 | 辛 | 丁 |
| 亥 | 壬 | 甲 | - |

### 7. 五行统计权重

- 天干：权重1.0
- 地支本气：权重0.6
- 地支中气：权重0.3
- 地支余气：权重0.1

### 8. 日主旺衰判断（简化版）

三维度评分：

- **得令**（30分）：日主五行在月令是否旺相。同我者旺（+30），我生者相（+15），生我者休（+10），克我者囚（-10），我克者死（-5）
- **得地**（最高+38分）：日主在地支中是否有根。禄位+15，羊刃+12，墓库+8，藏干同五行+3
- **得势**（最高+15分）：天干是否有比劫帮身（+10）、印星生身（+5）

总评：
- ≥50分：身强
- 20-49分：偏强
- -10~19分：中和
- -30~-11分：偏弱
- <-30分：身弱

> **注意**：旺衰判断是八字中最复杂、最有争议的部分。本算法为简化版，仅供参考。实际分析需结合格局、调候、通关等多维度综合判断。

### 9. 大运计算

- **顺逆**：阳年生男、阴年生女顺排；阴年生男、阳年生女逆排（看年干阴阳，不是日干）
- **起运年龄**：从出生到最近节气的天数 ÷ 3 = 起运岁数（3天=1岁，1天=4个月）
- **大运干支**：从月柱开始顺排或逆排，每步10年

### 10. 空亡计算

- 日柱旬空：根据日柱干支确定所在旬，旬中地支未满的两个为空亡
- 六甲旬：甲子旬（空戌亥）、甲戌旬（空申酉）、甲申旬（空午未）、甲午旬（空辰巳）、甲辰旬（空寅卯）、甲寅旬（空子丑）

## 五、已知限制

1. **节气日期**：使用固定日期（如立春=2月4日），实际每年节气日期有1-2天波动。精确排盘需接入节气算法或API。
2. **旺衰判断**：简化版算法，未考虑格局、调候、通关、从格等复杂情况。仅供参考。
3. **起运时间**：使用"3天=1岁"的简化算法，精确到天。实际流派有"3天=1岁、1天=4个月、1小时=5天"等不同换算。
4. **子时分界**：23点后算子时（第二天），但部分流派认为0点后才算第二天子时。本代码采用23点分界。
5. **真太阳时**：未考虑出生地经度导致的真太阳时修正。精确排盘需根据出生地经度换算。

## 六、生命论视角的使用原则

1. **八字是S₀，不是判决书**：八字给的是初始能量结构和基本操作倾向，不是注定的命运。M=α×T×N，你的每一步操作（N）都在改变M。
2. **身弱不是命不好**：身弱=能量承载力偏弱（T值低），不是能力不行。身弱的人往往感知力强、敏感度高（α值可能不低）。后天加厚T值（睡眠、运动、规律、学习）即可改善。
3. **用神不是救命稻草**：用神是当前能量失衡下需要补的操作方向，不是固定的。大运流年变了，用神也会动态调整。
4. **大运是环境，不是轨道**：大运告诉你在什么能量环境里操作，不是规定你必须怎样。好的大运不操作也会浪费，差的大运操作得当也能逆转。
5. **阳主阴从**：术数是工具（阴），人的明性和操作是本体（阳）。工具不能反过来支配人。永远记住：格局是地图，不是轨道。地图告诉你地形，走哪条路你说了算。
