# 合化与从格专项研究

> 硬度：中等推断（合化争议大，从格判断较明确）
> 配套：T值硬判断标准化 v2.2

---

## 一、合化研究结论

### 1.1 合化的本质

合化不是"凭空增加力量"，是**五行属性的转换**：
- 甲己合化土：甲木的属性变成土，不是木+土同时存在
- 辰酉合化金：辰中乙木的属性变成金，不是木+金同时增加

### 1.2 为什么不加入T值计算

| 问题 | 说明 |
|------|------|
| 条件不统一 | 有的流派要求月令化神，有的要求化神透干，有的要求化神有根 |
| 效果不统一 | 有的说完全改变五行，有的说只增加化神力量，有的说原五行减半 |
| 日主合化争议 | 日主能否被合化？从化格的判断标准各流派差异极大 |
| 转换实现复杂 | 地支六合化涉及藏干的选择性转换，不是整个地支变五行 |

### 1.3 保守处理方案

**合化只记录，不改变五行力量。**

记录格式：`酉辰合(仅记录)`、`甲己合而不化(涉日主)`

后续如果要加入，需要先完成：
1. 梳理3-5个主流流派的合化条件，取交集作为最低标准
2. 建立"转换"而非"增加"的实现（藏干选择性转换）
3. 用10+已知合化案例验证

## 二、从格判断

### 2.1 从格的本质

日主极弱、无根无印，无法自立，只能"从"于命局中最旺的五行。
从格不是"身弱"，是**特殊格局**——身弱的人需要补帮身，从格的人反而忌帮身（帮身破格）。

### 2.2 判断标准（三条件同时满足）

| 条件 | 标准 | 说明 |
|------|------|------|
| 帮身占比 | <25% | 日主+印星力量占总力量<25% |
| 日主无根 | 地支无比劫本气/藏干≥0.3 | 日主在地支没有根气 |
| 印星无根 | 地支无印星本气/藏干≥0.3 | 印星在地支没有根气 |

### 2.3 从格类型

| 类型 | 最旺五行 | 十神 | 特点 |
|------|---------|------|------|
| 从财格 | 财星最旺 | 正财/偏财 | 富命，忌比劫 |
| 从杀格 | 官杀最旺 | 正官/七杀 | 贵命，忌食伤 |
| 从儿格 | 食伤最旺 | 食神/伤官 | 聪明，忌印星 |
| 从势格 | 克泄耗混杂 | 多种 | 随势而行 |

### 2.4 四案例验证

| 案例 | 帮身% | 日主有根 | 印星有根 | 从格 |
|------|-------|---------|---------|------|
| 用户 | 47.0% | 是（辰土） | 否 | 否 |
| 马克思 | 71.8% | 是（辰土） | 是（辰中癸？不，印是火） | 否 |
| 史铁生 | 36.4% | 是（寅木） | 是（丑中癸？不，印是水） | 否 |
| 刘苏贝 | 29.1% | 否 | 否 | 否（帮身>25%） |

**刘苏贝最接近从格**：日主无根、印星无根，但帮身29.1%略高于25%阈值，属于"身弱而非从格"。

## 三、T值判断的完整流程

```
输入八字
  ↓
计算五行力量（v2.2，含六冲力量对比修正）
  ↓
T = 帮身占比×100 - 50
  ↓
┌─ 帮身<25% 且 日主无根 且 印星无根？
│   ├─ 是 → 从格（判断从财/从杀/从儿/从势）
│   └─ 否 → 继续
└─ T值判断
    ├─ T≥15 → 身强
    ├─ 5≤T<15 → 偏强
    ├─ -5≤T<5 → 中和
    ├─ -15≤T<-5 → 偏弱
    └─ T<-15 → 身弱
```

## 四、生命论翻译

- **合化**：关系网络中的"绑定依赖"——两个能量绑定后产生新的属性，但总量不变。对应νF₂中"操作的耦合"——两个操作耦合后产生新的操作模式，但不增加总能量。
- **从格**：初始条件S₀中自我能量极弱，系统无法自指循环，只能依附于外部最强的能量流。对应"!-沉积压垮νF₂"——系统没有自指能力，只能随波逐流。从格的人不是"命不好"，是**操作空间在于顺势而为，而非逆势补强**。
