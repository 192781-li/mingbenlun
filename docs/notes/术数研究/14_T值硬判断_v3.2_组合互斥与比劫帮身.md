# T值硬判断 v3.2：组合互斥 + 比劫帮身

> v3.1基础上加入组合互斥逻辑和比劫帮身。
> 硬度：中等推断
> 验证：7案例，毛泽东T从+3→+6.5（偏强），更接近传统"身强"

---

## 一、组合互斥逻辑

### 1.1 为什么需要互斥

杀印相生和食神制杀是**两种不同的制杀方式**：
- 杀印相生：印星把官杀"化"掉（转化为生身力量）
- 食神制杀：食伤把官杀"制"住（直接削弱）

如果印星已经能化杀，就不需要食伤再制杀——两种方式不应同时触发，否则会重复计算官杀的减少。

### 1.2 互斥规则

**优先级：杀印相生 > 食神制杀**

- 如果杀印相生触发，食神制杀不触发（印已经化杀了）
- 如果杀印相生未触发，才考虑食神制杀

**理由**：印化杀是更根本的转化（官杀→印星→生身），食伤制杀是直接削弱。印化杀成功意味着官杀已经被转化，食伤无杀可制。

---

## 二、比劫帮身

### 2.1 原理

比劫（同五行）可以**分担官杀的克**——官杀不只是克日主，也克比劫。比劫旺时，官杀的力量被比劫分散，日主实际承受的克减少。

### 2.2 条件（同时满足）

1. 比劫力量 > 15（比劫有一定力量）
2. 官杀力量 > 15（官杀有一定力量，才需要分担）
3. 比劫透干或有根（比劫不是虚浮的）

### 2.3 修正

- 分担比例 = min(比劫力量 / 官杀力量, 0.3)
- 官杀力量 × (1 - 分担比例)

**上限30%**——比劫最多分担30%的官杀力量，不能完全替代日主承受克。

### 2.4 效果

官杀（克身）力量减少，T值上调。

---

## 三、完整组合优先级（v3.2）

```
1. 杀印相生（最高优先级，触发后跳过食神制杀）
2. 食神制杀（杀印未触发时）
3. 比劫帮身（独立判断，不与上述互斥）
4. 伤官佩印（独立判断）
5. 财滋弱杀（独立判断）
```

比劫帮身、伤官佩印、财滋弱杀之间不互斥，可以同时触发。

## 五、生命论翻译

- **组合互斥**：操作之间不是独立的，一种操作的成功会改变另一种操作的必要性。印化杀成功后，食伤制杀就成了冗余操作——对应νF₂中"操作的耦合会改变操作空间"。
- **比劫帮身**：同类操作可以分担外部压力。比劫是"另一个自己"，官杀克过来时，比劫先扛一部分——对应"共同体的力量"，个体不是孤立承受压力的。
