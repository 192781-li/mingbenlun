# 八字旺衰裁决重大纠错 · 得令方向对调 + 用神官杀↔财取反：月令第一权重裁决层

> S03 术数研究 · 第23篇 · 2026-09-14
> 配套代码：tools/术数工具包/bazi_paipan.py（修复得令/用神两处方向性 bug + 新增最终裁决层）；tools/术数工具包/chart_regression.py（八字+紫微统一硬回归，32 项全过、1200 随机盘 0 崩溃）。
> 硬度：干支/十神生克/旺相休囚死/数值裁决=**硬运算（代码可复现，回归锁死）**；身弱→性格/事件的翻译=中推断与软联想，本篇不展开。
> 结论先行：旧版 bazi_paipan 存在两个**方向性**硬 bug——①得令"旺相休囚死"两支对调，把"我生月令（被泄、失令）"误判为"相、得令、+15 分"；②用神建议里"官杀（克我）"与"财星（我克）"的五行在身强/身弱/从格三分支全部取反。两 bug 叠加，把主人戊土盘凭空抬成"偏强、用神空缺"。修复并引入"月令第一权重"最终裁决后：**主人戊土偏弱、喜火土、忌木（官杀）金（食伤）水（财星），与多轮确认口径一致；父亲甲木身弱、喜水木，方向全正。** T 值 v3.3 的数学定义一字未改。

## 一、背景：一张盘三套自相矛盾的结论

对确定输入「公历 2008-09-25 辰时(7点) 男」，四柱 `戊子/辛酉/戊辰/丙辰`、日主戊土，旧版同时吐出三个互相打架的结果：

| 模块 | 旧输出 | 问题 |
|---|---|---|
| 传统加权 analyze_wangshuai | 综合 26 分，**偏强** | 与"戊土生酉月失令、身弱"常识冲突 |
| T 值 v3.3 | T=-3.3，**中和**（帮身 50/107=46.7%） | 临界区间过宽，掩盖了失令事实 |
| get_yong_shen | 评级落不到身弱/身强分支，**用神空缺** | 下游拿不到喜忌，等于废盘 |

而休学决策、丙火用神、癸亥大运耗身等一系列判断，都建立在"戊土身弱、喜火土"这个地基上。**工具结论与可靠口径冲突时，不允许用口径去硬套工具，必须回到形式运算层查工具哪里错了。** 逐段审源码，定位到两个方向性 bug。

## 二、硬运算层 bug 一：得令"旺相休囚死"方向对调

### 2.1 正确的五行关系（对日主 X、月令五行 M）

旺相休囚死描述"日主在月令这一最强外场中处于什么位置"，**得令与否只看旺、相两态**：

| 关系 | 判据 | 状态 | 是否得令 | 旧代码 |
|---|---|---|---|---|
| 同我 | M == X | 旺 | ✅ 得令 | +30（对） |
| 月令生我 | GENERATES[M]==X | 相 | ✅ 得令 | **误写成"休 +10"** |
| 我生月令（X 去生 M，被泄） | GENERATES[X]==M | 休 | ❌ 失令 | **误写成"相 +15"** |
| 我克月令（X 去克 M，耗） | OVERCOMES[X]==M | 囚 | ❌ 失令 | 误置到"死"分支、-5 |
| 月令克我 | OVERCOMES[M]==X | 死 | ❌ 失令 | 误置到"囚"分支、-10 |

关键颠倒：**"我生月令"是日主向外输出、被月令盗泄，应为休（失令、扣分）；旧代码却把它当成"相（得令）+15"。** 同时把真正得令的"月令生我（印）"错按成休。一进一出，方向完全反了。

### 2.2 戊土实例：凭空多出约 25 分

戊土生于酉月：土生金，正是"我生月令=休（被金泄）、失令"。旧代码却走"相 +15"；正确应为"休 −10"。**仅月令一项，旧盘就比正确值高挂 25 分**，叠加后把身弱抬成"偏强"。修复后该项 −10，传统加权分量回到"中和"，为最终裁决让出正确位置。

修复同时新增 `result["月令状态"] ∈ {旺,相,休,囚,死,平}`，把判据显式化、可回归。

## 三、硬运算层 bug 二：用神"官杀↔财星"五行取反

### 3.1 十神五行的五个方向（对日主 X，唯一正确式）

| 十神 | 关系 | 唯一取法 |
|---|---|---|
| 印 | 生我者 | 反向查 GENERATES[e]==X |
| 比劫 | 同我 | X 本身 |
| 食伤 | 我生 | GENERATES[X] |
| **财** | **我克** | **OVERCOMES[X]** |
| **官杀** | **克我者** | **反向查 OVERCOMES[e]==X** |

旧代码在身强、身弱、从格三个分支里，把"官杀"写成了 `OVERCOMES[X]`（这本是财），把"财星"写成了反向查找（这本是官杀）——**财与官杀的五行整对对调**。

### 3.2 戊土实例：喜忌标签全错

日主戊土：火生土=印、土=比劫、土生金=食伤、**土克水=财（水）、木克土=官杀（木）**。

- 身弱应"喜印比、忌官杀/食伤/财"，正确忌神为 **木（官杀）、金（食伤）、水（财）**。
- 旧代码身弱分支却输出"忌 水（官杀）、…、木（财星）"——把水误标官杀、木误标财星，方向反了。

修复方式：在 get_yong_shen 开头用 `e_yin/e_bi/e_shi/e_cai/e_guan` 五个局部变量一次性钉死五个方向，全函数只引用这五个变量，从结构上杜绝再次对调。父亲甲木盘同步验证：金克木=官杀（金）、木生火=食伤（火）、木克土=财（土），忌神标签全部归位。

## 四、为什么不改 T 值，只加"月令第一权重"裁决层

T 值 v3.3（`T = 帮身力量/总力量×100 − 50`）已通过大样本校准，阈值区间是统计产物；为了一张盘去改它的数学定义，会污染其余所有盘——**这是用一个特例破坏通用器，禁止。**

主人盘 T=-3.3 落在 [-5,5) 的"中和"带。问题不在 T 的算式，而在**单点 T 值没有体现"月令是旺衰第一权重"这条命理硬规则**。因此在 analyze_wangshuai 末尾、return 之前加一个纯裁决层（不改任何上游数值）：

```
base = T值总评（缺失时退回传统分）
若 base == 中和（临界带）：
    失令 且 帮身占比 < 50%  → 最终=偏弱
    得令 且 帮身占比 > 50%  → 最终=偏强
    其余                    → 维持中和
result["最终"]/["最终依据"]；并把 result["总评"] 回写为最终结论供下游统一取用
```

- 主人：T=-3.3 临界中和，但酉月**休地失令**、帮身仅 46.7%<50% → **最终偏弱**，依据完整留痕。
- 非临界盘（如父亲 T=-21.4 已明确身弱）裁决层原样放行，不产生额外扰动。
- 从格盘 base 为"从X格"，不进中和分支，不受影响。

打印层同步改造：传统加权、T 值都降级为"分量"并列展示，**唯一对外结论是 ★最终裁决（附依据）**，不再让用户同时看到"偏强/中和/偏弱"三个词。

## 六、统一硬回归 chart_regression.py（质量门）

新增八字+紫微统一回归，改动任何排盘文件必须先跑绿：

- **A 双盘锚点断言 28 项**：主人八字 12 项（四柱、日主、失令、最终、喜忌逐条十神标签、时干丙=偏印）、父亲八字 7 项、主人紫微 6 项、父亲紫微 3 项。
- **B 裁决稳定性**：主人盘连算 5 次，最终裁决必须完全一致。
- **C 大样本**：600 随机八字 + 600 随机紫微盘 0 崩溃；并内置**十神五行方向通用不变量**——独立用 GENERATES/OVERCOMES 推导每个随机盘"印比食财官"的期望五行，与 get_yong_shen 实际输出逐条比对，任何"标签五行≠生克方向"立即 FAIL。**这台不变量就是专门用来永久锁死本篇 bug 二这一类方向对调的。**
- 实测：**32 项全过、1200 随机盘 0 崩溃、方向 0 错位**；临界中和/需结合格局盘占比 9.2%（符合预期，正是裁决层存在的意义）。

> 过程留痕：首跑时不变量曾报 2 条"错位"，排查发现是**测试脚本自身**把从格说明文字"印星，克食伤破格"里的"食伤"子串误当标签（子串匹配顺序问题），被测代码本身正确；改为"只取括号内、第一个逗号前的规范标签"后全绿。**回归脚本同样会错，断言本身也要被审查。**

## 八、生命论翻译

- 八字原局是初始条件 S₀，**身强身弱 = T（稳态基准）**，描述系统承载力的初始水位，有天花板但可被操作抬高；它不是"好命/坏命"的判决。
- 本轮两个 bug 的本质，是**关系方向被符号层写反**：把"我向外输出（被泄）"误当成"外场生扶我（得令）"，把"克我者"与"我克者"互换。名实之辨要求——任何术数符号翻译成能量关系时，必须先钉死方向（谁生谁、谁克谁），方向一错，后面整套喜忌全反。
- **月令第一权重 = 当下最大外场对系统的支配优先级**；T 值是内部力量比，裁决层是"内部比 + 当下外场"的合判，对应 νF₂ 对 !-沉积 的重新评估：临界状态下，最大外场的方向（得令/失令）拥有最终一票。
- **阳主阴从不变**：工具（阴）只负责把地形算准——这一版把"身弱喜火土"的地形终于算对了；怎么走、休学与否、何时输出，仍是主人明性操作（阳）决定，N 无天花板，结构从属。

## 九、教训沉淀（供教训库）

1. **方向 > 数值**：生克类代码 review 先查"谁指向谁"，方向反了，加减多少分都没意义。
2. **一个方向变量只定义一次**：印比食财官用五个局部变量钉死、全函数引用，禁止在每个分支重复手写推导（重复手写正是对调温床）。
3. **通用器不为特例改数学**：T 值不动，加独立裁决层；改通用公式前先问会不会污染其他盘。
4. **回归要能抓今天的 bug**：方向不变量（独立推导期望 vs 实际输出）比锚点断言更能防一类错误；且回归脚本自身也要被审查。
5. **结论唯一可见**：多个中间分量可以并列展示，但对外只能有一个"最终裁决"，并附依据，禁止把矛盾结论丢给用户自行取舍。
