## 二、根因定位：ziwei_relative 用错了奇偶判断对象

### 错误代码（v2.0 第98行）

```python
def ziwei_relative(day, ju):
    q, r = divmod(day, ju)
    if r == 0:
        return (q-1) % 12
    b = ju - r          # 补数
    base = q
    return (base-b) % 12 if q % 2 == 1 else (base+b) % 12
    #                  ^^^^^^^^^ 错误：用商 q 的奇偶判断进退
```

### 错误验证

土五局廿六日：q=5, r=1, b=4。
- 错误代码：q=5 是奇数 → 后退 b=4 位 → 偏移 (5-4)%12=1=卯 → 紫微在卯
- 文墨天机：紫微在亥（偏移9）

差8宫（或4宫，取决于方向），完全错误。

### 正确公式

紫微安星的进退由**补数 b** 的奇偶决定，不是商 q：

```
q, r = divmod(day, ju)
若 r == 0：整除，紫微在第 q 宫（寅起，寅=1），偏移 = q-1
若 r != 0：
    b = ju - r          # 补数，使 day+b 能被 ju 整除
    基准宫偏移 = q       # 第 q+1 宫（寅起）
    若 b 为偶数：从基准宫前进 b 位 → 偏移 = (q + b) % 12
    若 b 为奇数：从基准宫后退 b 位 → 偏移 = (q - b) % 12
```

### 正确验证

土五局廿六日：q=5, r=1, b=4（偶数）→ 前进4位 → (5+4)%12=9=亥。
与文墨天机完全一致。

## 四、对之前结论的影响（重要更正）

### 4.1 命宫主星：天相 → 天府

第22篇"天相坐命"的结论**完全作废**。正确命宫主星为**天府**。

- 天府：库藏、包容、稳重、要面子、外表稳内里烧火
- 天相：印星、辅佐、权衡、调和

这是两种完全不同的人格底色。之前基于"天相坐命"的所有性格推断（军师型、调和型、印星兜底）全部需要重新评估。

### 4.2 迁移宫：武曲破军 → 紫微七杀

- 武曲破军：杀破狼格局，外出开创、颠覆、刚猛
- 紫微七杀：紫杀格局，外出有权威、有主见、刚硬但带贵气

用户不是"杀破狼"格局（命宫天府不是杀破狼三方），而是**紫府朝垣/府相朝垣**类格局。之前"杀破狼占比""杀破狼细分"的讨论基于错误命盘，需要重新评估。

### 4.3 夫妻宫：紫微贪狼 → 廉贞破军

- 紫微贪狼：桃花重、对象有魅力、有权威感
- 廉贞破军：对象刚烈、独立、不羁、有冲击力，感情激烈波折

之前基于"夫妻紫微贪狼"的感情推断（对象有魅力、桃花重）需要更正为"廉贞破军"（对象刚烈独立、感情激烈）。这与用户自己描述的"野马"意象更吻合。

### 4.4 福德宫：廉贞七杀 → 武曲贪狼

- 廉贞七杀：内心刚猛、纠结、容易内耗
- 武曲贪狼：内心务实、有欲望、懂享受、能聚财

贪狼化禄在福德，说明内心有财气、有享受欲、精神世界丰富，不是"廉贞七杀内耗"。

### 4.5 官禄宫：空宫借紫贪 → 天相独坐

## 七、生命论翻译

### 7.1 术数是结构论不是宿命论

紫微安星公式的纠错本身就是一个生命论案例：
- **α（格局/命宫）**：天府坐命=初始结构倾向于库藏、包容、稳重
- **T（稳态/福德疾厄）**：福德武曲贪狼化禄=内心有欲望有财气，稳态基准有享受欲支撑
- **N（大运流年/操作）**：当前癸亥大运（14-23岁）=水旺财旺最耗身，N的负熵比率受环境压制
- **M=α×T×N**：成就=初始结构×稳态基准×当前操作。结构是天府（库），但N在癸亥运被耗，M暂时上不去；等丙寅运（44岁后）丙火偏印补齐，N的负熵比率提升，M才真正放大

### 7.2 阳主阴从

术数排盘（阴/工具）给出的是结构倾向，人的明性操作（阳/本体）才是决定因素。天府坐命不代表"注定稳重"——它只是初始能量结构倾向于库藏。用户可以通过操作（写生命论、脱离学校、踢球健身）改变N的负熵比率，从而改变M。

### 7.3 名实之辨

- **象（感的层面）**："天府坐命""库藏型"——符号联想
- **理（操作的层面）**：初始能量结构中收敛性（土）较强，表现为外表稳、内心存东西、不轻易外露
- **命（实体的层面）**：用户实际做了什么——写27万字生命论、脱离学校、和父亲坦白、踢球健身

不能停在象的层面。"天府坐命"不是结论，"初始结构倾向于收敛库藏，操作空间在于把库里存的东西倒出来、建出来"才是结论。

## 八、教训沉淀

1. **安星公式必须用市面软件终验，不能凭记忆写。** 紫微安星的补数奇偶判断是极易出错的细节，必须和文墨天机/元亨利贞等专业软件逐宫对照。
2. **奇偶判断对象是补数 b，不是商 q。** 这是本次错误的直接根因。补数=局数-余数，补数偶数前进、奇数后退。
3. **一个安星错误导致十四主星全部连锁错位。** 紫微是十四主星的定位基准，紫微错4宫，紫微星系6颗+天府星系8颗全部错位，性格结论全部作废。
4. **chart_regression 必须用终验过的期望值，不能用代码自己的输出做断言。** 之前的紫微断言（天相坐命、迁移武曲破军）本身就是错误代码的输出，用错误输出做回归断言等于没有验证。
5. **用户提供的专业软件截图是最硬的终验标准。** 文墨天机专业版经过大量用户验证，比任何AI手写的安星公式都可靠。必须以专业软件为锚点，反向验证代码。
