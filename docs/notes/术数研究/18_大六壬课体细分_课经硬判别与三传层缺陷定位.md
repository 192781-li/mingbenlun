## 一、背景/现状

旧 judge_keti 只按九宗门 method 名贴 9 个粗课（贼克/比用/涉害/遥克/昴星/别责/八专/伏吟/反吟），缺课经标准课名（元首、重审、知一、见机、察微、缀瑕、蒿矢、弹射），也无复合课。本轮补齐，并在补齐过程中用硬规则反向定位了三传层两处缺陷。

## 二、课经主课的硬判别（先贼后克，无克才论遥克）

对四课逐课比较地盘五行 e 与天盘五行 h：
- **下克上（贼）**：e 克 h，即 ELEMENT_KE[e]==h
- **上克下（克）**：h 克 e，即 ELEMENT_KE[h]==e

设下克上数量 nX、上克下数量 nS，判别顺序（不可乱）：

| 条件 | 课名 | 要点 |
|---|---|---|
| 月将=占时 | 伏吟课 | 天盘=地盘 |
| 月将冲占时 | 反吟课 | 天地盘相冲 |
| 四课不全+寄宫=日支 | 八专课 | 结构课 |
| 四课不全+寄宫≠日支 | 别责课 | 结构课 |
| nX==1 | **重审课** | 唯一"下贼上"为用；**不要求无上克下**（先贼后克） |
| nX>1，比和唯一 | 知一课 | 多贼取与日干比和者 |
| nX>1，涉害·初传在四孟(寅申巳亥) | 见机课 | |
| nX>1，涉害·初传在四仲(子午卯酉) | 察微课 | |
| nX>1，涉害·初传在四季/复等 | 缀瑕课 | |
| nX==0 且 nS==1 | **元首课** | 唯一上克下为用 |
| nX==0 且 nS>1 | 见机/察微/缀瑕 | 多"上克下"亦走比用涉害 |
| 四课上下全无克，上神遥克日干 | 蒿矢课 | 神克日 |
| 四课上下全无克，日干遥克上神 | 弹射课 | 日克神 |
| 无克亦无遥克 | 昴星课 | 阳日仰酉、阴日俯酉 |

**关键纠错**：重审只要求"下克上唯一"，旧实现额外要求"无上克下"是错的——2026-11-20 22时戊戌日，下克上、上克下各一，应判重审（已验证）。

## 三、复合课体（本轮新增，规则无争议子集）

- **斩关课**：发用（初传）为辰或戌（魁罡），主冲破关梁。硬判 `first∈{辰,戌}`。
- **三传三合局**：三传地支集合恰为
  - 申子辰→润下课（水）；亥卯未→曲直课（木）；寅午戌→炎上课（火）；巳酉丑→从革课（金）。
- **稼穑课**：三传皆土（辰戌丑未）。
- **游子课暂不硬编码**：其"天马发用+关梁顺布"判定存在流派分歧，属中推断，留人工辨，不写死以免假精确。

## 四、反向定位：get_three_transmissions 的两处缺陷（遗留，待修三传取法）

课体层以四课真实克关系重判后，暴露出三传层问题（本轮只在课名层纠正，**不改初传取法**，避免牵动面过大）：

1. **"遥克"命名错位**：代码把"nX==0 且 nS>0"（四课内的上克下）也命名为 `遥克法(蒿矢/弹射)`。课经中这是元首/多上克下，**不是遥克**；遥克必须四课上下全无克、才论日干与上神的远距离相克。
2. **真遥克被昴星拦截**：四课上下全无克时，代码直接走昴星，跳过了蒿矢/弹射的遥克判断。
   - 实证：2026-03-20 04时癸巳日，四课上下全无克，而干上神戌、干阴未（土）遥克日干癸（水），课经当为**蒿矢**，代码却给"昴星法"。课体层已正确补标蒿矢。
   - **修复方向（遗留）**：在三传函数昴星分支前插入遥克分支——四课无克时先查日干与四课上神：上神克日取之为用（蒿矢）、日克上神取之为用（弹射），全无才转昴星/别责。

## 五、验证（硬）

## 六、生命论翻译

课体是**当前时空关系网络的结构类型**：重审/元首是张力从哪个方向发起（下犯上=重审，上制下=元首）；知一/见机/察微是多个张力并存时的**选择算法**（先比和、再比涉害深浅）；蒿矢/弹射是关系不在紧邻四课、而在远端遥相作用；斩关/三合局是三传阶段的通道形态（破关闭 vs 会局成势）。课体只给"结构是哪一类、张力在哪"，**不给吉凶判决**——同一结构下操作(N)不同，M=α·T·N 的结果不同。阳主阴从：课体是地图（阴），明性操作是走路的人（阳）。
