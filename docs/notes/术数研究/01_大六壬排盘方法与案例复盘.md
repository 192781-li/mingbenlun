## 一、大六壬的基本原理

大六壬是中国古代术数中最古老、最复杂的系统之一，被称为"三式之首"（大六壬、奇门遁甲、太乙神数）。

### 1.1 核心原理

大六壬的本质是：**在特定时空点，以月将加占时，构建天地盘，然后通过四课三传，揭示该时空下人和事的能量关系结构。**

- **月将**：太阳过宫的位置，代表当前时空的能量基准
- **占时**：起课的时辰，代表提问的瞬间
- **天地盘**：月将加时后形成的12地支旋转结构
- **四课**：干上、干阴、支上、支阴——代表事物的四个层次（表面、深层、对方表面、对方深层）
- **三传**：初传、中传、末传——代表事物发展的三个阶段（爆发点、过程、收敛）

### 1.2 课体（发用方式）

四课中找"克贼"（上克下或下贼上），根据克贼的数量和位置确定课体：

| 课体 | 条件 | 含义 | 硬度 |
|------|------|------|------|
| 贼克课 | 有上克下 | 直接对抗，事情有明确爆发点 | 硬 |
| 比用课 | 多个克贼，取与日干比和者 | 事情有多个方向，取与自己相近的 | 硬 |
| 涉害课 | 多个克贼，比和也相同，取涉害深者 | 事情复杂反复，经历艰难 | 硬 |
| 遥克课 | 四课无克贼，日干遥克或被遥克 | 事情距离远，间接作用 | 中等 |
| 昴星课 | 无克贼无遥克 | 事情不明朗，需要观望 | 中等 |
| 别责课 | 四课不全（只有三课） | 事情有缺陷，需要补全 | 中等 |
| 八专课 | 干支同位（如甲寅日） | 事情自我缠绕，内耗 | 中等 |
| 伏吟课 | 天地盘相同（月将=占时） | 能量停滞，事情不动，需要等待 | 硬 |
| 返吟课 | 天地盘相冲（月将冲占时） | 能量反复，事情来回对冲，不稳定 | 硬 |

### 1.3 天将系统

天将是加在地支上的能量性质标签，共12个：

| 天将 | 五行 | 性质 | 生命论对应 |
|------|------|------|-----------|
| 贵人 | 土 | 尊贵、帮助、权威 | 外部资源的赋能 |
| 腾蛇 | 火 | 惊恐、纠结、变化 | 感的波动、不确定性 |
| 朱雀 | 火 | 口舌、文书、信息 | 表达、输出、沟通 |
| 六合 | 木 | 结合、合作、婚姻 | 关系的建立、应的呼答 |
| 勾陈 | 土 | 拖延、纠缠、阻碍 | !-沉积的卡住、惯性 |
| 青龙 | 木 | 喜庆、财富、机会 | 生发的能量、νF₂的启动 |
| 天空 | 土 | 空虚、不实、欺骗 | 名实不符、空亡的显现 |
| 白虎 | 金 | 凶险、冲突、疾病 | 能量的剧烈对抗、克的爆发 |
| 太常 | 土 | 日常、稳定、衣食 | 稳态T的维持、日常操作 |
| 玄武 | 水 | 暗昧、小人、偷盗 | 隐藏的能量、暗中的干扰 |
| 太阴 | 金 | 阴暗、隐藏、犹豫 | 感的潜藏、未明化的状态 |
| 天后 | 水 | 女性、温柔、庇护 | 滋养的能量、印星的赋能 |

### 1.4 六亲系统

以日干为基准，地支与日干的五行关系决定六亲：

| 六亲 | 关系 | 含义 | 生命论对应 |
|------|------|------|-----------|
| 父母（印） | 生我者 | 基础、记忆、吸收、庇护 | 印星=积累、内化、!-沉积的正面 |
| 兄弟（比劫） | 同我者 | 同类、竞争、帮助 | 比肩=同类能量、关系网络中的同级 |
| 子孙（食伤） | 我生者 | 输出、表达、创造、孩子 | 食伤=νF₂的输出、明性的显现 |
| 妻财（财） | 我克者 | 财富、感情、物质 | 财星=欲望、目标、被操作的对象 |
| 官鬼（官杀） | 克我者 | 压力、规则、权威、疾病 | 官杀=外部制约、反自指因素、!-沉积的负面 |

## 二、排盘步骤（标准流程）

```
1. 确定占时：起课的时辰（子丑寅卯...）
2. 确定月将：根据节气确定当前月将（太阳过宫）
   - 雨水后-春分前：亥将（登明）
   - 春分后-谷雨前：戌将（河魁）
   - 谷雨后-小满前：酉将（从魁）
   - 小满后-夏至前：申将（传送）
   - 夏至后-大暑前：未将（小吉）
   - 大暑后-处暑前：午将（胜光）
   - 处暑后-秋分前：巳将（太乙）
   - 秋分后-霜降前：辰将（天罡）
   - 霜降后-小雪前：卯将（太冲）
   - 小雪后-冬至前：寅将（功曹）
   - 冬至后-大寒前：丑将（大吉）
   - 大寒后-雨水前：子将（神后）
3. 月将加占时：把月将放在占时的位置，形成天地盘
4. 排四课：
   - 干上神：天盘上日干对应的地支
   - 干阴神：干上神的天盘位置
   - 支上神：天盘上日支对应的地支
   - 支阴神：支上神的天盘位置
5. 找克贼：四课中找上下相克的关系
6. 定课体：根据克贼情况确定课体（贼克/比用/涉害/遥克/昴星/别责/八专/伏吟/返吟）
7. 发三传：根据课体确定初传、中传、末传
8. 排天将：根据贵人的位置和昼夜，顺排或逆排12天将
9. 标空亡：根据日旬确定空亡的地支
10. 分析：类神、旺衰、生克、冲合、空亡
```

## 三、案例复盘：2026年8月29日宋庄踢球冲突事件

### 3.1 事件背景

- **时间**：2026年8月29日亥时（约20:00-22:00）
- **地点**：北京通州宋庄某足球场
- **事件**：用户约朋友踢球，过程中与对方球员发生口角冲突，差点打起来，最后对方怂了，用户离场
- **关键细节**：
  - 原本约的是另一个场地，到了发现被包了，转场去宋庄
  - 对方有个蓝衣服球员嘴碎，一直不干净
  - 用户状态起来后进了好几个球
  - 对方急了，说用户打着他脸了
  - 用户要求调监控，对方怂了
  - 对方还有个红衣服球员也骂蓝衣服（内部矛盾）
  - 最后用户不踢了，离场

### 3.2 起课

- **占日**：2026年8月29日，查万年历为甲午日（待验证，此处为复盘假设）
- **占时**：亥时
- **月将**：处暑后-秋分前，巳将（太乙）
- **月将加时**：巳将加亥时

### 3.3 课盘结构（复盘分析）

> 注意：以下为基于事件特征的课盘结构复盘，非精确排盘。精确排盘需要代码验证。

**核心结构特征**：

1. **朱雀临干/支**：口舌是非的能量明显，对应场上口角
2. **白虎/勾陈**：冲突、纠缠的能量，对应差点打起来
3. **玄武**：暗中的小人，对应蓝衣服嘴碎
4. **返吟/伏吟**：事情反复，对应转场、来回倒腾
5. **空亡**：冲突最终没有爆发（对方怂了），名实不符——看起来要打，实际没打

### 3.4 结构与事件的对应分析

| 课盘结构 | 事件对应 | 硬度 |
|---------|---------|------|
| 朱雀口舌 | 场上口角、蓝衣服嘴碎 | 硬（结构对应） |
| 白虎冲突 | 差点打起来、肢体接触 | 硬（结构对应） |
| 玄武小人 | 蓝衣服暗中使坏、嘴不干净 | 中等（象义对应） |
| 返吟反复 | 转场、来回倒腾、事情反复 | 硬（结构对应） |
| 空亡 | 冲突没真正爆发（对方怂了） | 硬（结构对应） |
| 蓝衣服/红衣服 | 具体人物的颜色、特征 | 软（象义联想，事前无法锁定） |
| 进了好几个球 | 具体事件细节 | 软（事后附会，事前无法推断） |
| 对方内部矛盾（红衣服骂蓝衣服） | 关系网络的细节 | 中等（课盘有比肩夺财/内部冲的结构可能） |

### 3.5 复盘结论：大六壬能做到什么、不能做到什么

**能做到的（硬的）**：
- 判断事件的整体能量结构（口舌、冲突、反复、空亡）
- 判断事件的发展趋势（初传爆发→中传纠缠→末传收敛）
- 判断哪里有张力、哪里有通道、哪里有阻塞
- 判断应期的大致时间窗口（哪个时辰/哪一天能量倾向是什么）

**不能做到的（软的）**：
- 事前锁定具体人物的外貌、穿着、名字
- 事前推断具体事件细节（进了几个球、谁说了什么话）
- 事前确定"一定打起来"或"一定不打起来"（空亡只是倾向，操作可以改变）
- 把象义联想当成硬推断（"蓝衣服"是从朱雀/玄武的颜色联想，不是必然）

**关键教训**：
- 课盘结构是硬的，象义细节是软的
- 事前只能说"有口舌冲突的能量倾向"，不能说"你会跟一个穿蓝衣服的人吵架"
- 事后复盘时，象义可以对应，但不能因此声称事前就能锁定
- 操作可以改变结果：空亡意味着"看起来有实际没有"，但如果用户真的动手了，空亡就被填实了

## 四、大六壬的常见误区

### 4.1 把象义当必然

"朱雀临干=你会跟人吵架"——这是错的。朱雀只是口舌、信息、表达的能量倾向，你可以用这个能量去写文章、去演讲、去沟通，不一定是吵架。

**正确说法**："当前能量场中表达/沟通的倾向较强，注意口舌是非，适合做需要表达的事。"

### 4.2 把课体当结局

"涉害课=你这事一定艰难"——这是错的。涉害只是说当前能量结构复杂、有多个克贼、需要经历反复，不是说结局一定不好。

**正确说法**："当前事情结构复杂，有多个方向的张力，需要耐心处理，经历反复后才能收敛。"

### 4.3 忽略人的操作

课盘是阴，人的操作是阳。同样的课盘，不同的人操作，结果完全不同。

- 白虎临干：有人被车撞了，有人去健身房练了腿
- 朱雀临干：有人跟人吵架了，有人写了一篇好文章
- 空亡：有人错过了机会，有人主动避开了陷阱

**永远强调：课盘给的是地形，走哪条路你说了算。**

### 4.4 事后附会声称事前能断

这是算命先生最常见的骗术。事后说"我早就看出来了"，但事前根本没说。

**S03的原则**：事前说的话要留痕，事后复盘要诚实——哪些是事前推断的，哪些是事后附会的，分清楚。

## 五、大六壬与生命论的深度对应

### 5.1 三传 = 感→应→操作的三个阶段

- **初传**：感的爆发——你感知到了什么，什么东西触动了你
- **中传**：应的判断——你如何回应这个感知，如何选择
- **末传**：操作的收敛——你做了什么，结果如何，形成了什么新的沉积

这不是"事情的三步结局"，是**一个完整的感-应-操作循环**。

### 5.2 四课 = 操作的四个层次

- **干上神**：你的表面状态——你表现出来的、别人看到的
- **干阴神**：你的深层状态——你内心真实的想法、隐藏的动机
- **支上神**：对方/事情的表面状态——事情看起来是什么样
- **支阴神**：对方/事情的深层状态——事情的本质、隐藏的结构

这就是**名实之辨**在术数中的体现：表面（名）和深层（实）不一定一致。

### 5.3 空亡 = 名实不符的位置

空亡不是"什么都没有"，是**看起来有，实际没有；或者看起来没有，实际有**。这是需要操作还原去验证的位置。

- 财星空亡：看起来有钱，实际没有；或者看起来没钱，实际有
- 官星空亡：看起来有压力，实际没有；或者看起来没压力，实际有
- 感情空亡：看起来有关系，实际没有；或者看起来没关系，实际有

**空亡是邀请你去验证的位置，不是宣判你"没有"的位置。**

### 5.4 伏吟/返吟 = 自指循环的状态

- **伏吟**：自指循环卡住了，能量停滞，需要外部输入打破
- **返吟**：自指循环在反复对冲，能量来回消耗，需要找到稳定点

这对应生命论中的**νF₂（活的自指）和!-沉积（惯性固化）的力量对比**：
- 伏吟 = !-沉积太强，νF₂启动不了
- 返吟 = νF₂在动，但方向反复，没有形成稳定的操作

## 六、使用建议

1. **大事用大六壬**：具体一件事的发展、关系、成败、应期，大六壬最擅长
2. **排盘要验证**：用代码排盘，交叉验证，不要手工排盘出错
3. **分析要分层**：硬判断、中等推断、软联想，分清楚，不要混为一谈
4. **操作要还原**：任何判断都要翻译成具体的操作建议，不说空话
5. **结果要复盘**：事后记录实际结果，对比事前判断，持续改进

## 七、一句话

> 大六壬是特定时空下能量关系结构的快照。它告诉你地形，不替你走路。结构是硬的，细节是软的，结果是操作出来的。
