## 五、渗透方式的分类说明

| 方式 | 适用场景 | 示例 |
|---|---|---|
| **新增段落** | 核心概念首次出现，需要完整论述 | A1真理标准、A3活劳动/死劳动区分 |
| **案例补充** | 抽象论述后需要具体验证 | B2鞍钢宪法作为生产关系革命的案例 |
| **交叉引用** | 一个概念在多卷出现，互相指向 | 卷四讲异化时引用卷十一的T001 |
| **脚注/原文引用** | 需要权威原文支撑 | 马克思四段原文 |
| **数据补充** | 需要量化验证 | B3工业化数据、B5大跃退代价数据 |
| **状态更新** | 工具/方法的进展状态 | C3 Coq形式化的L1/L2状态 |

## 六、关键原则

1. **高层级内容必须多卷渗透**：A1-A4是存在论/认识论突破，不能只放在一个地方，要在卷一（存在论）、卷二（认识论）、卷九（真理论）都有体现
2. **低层级内容不扩散**：D1-D3是技术细节，放在工具文档和附录，不污染正文
3. **交叉引用优先于重复论述**：一个概念在一个地方完整论述，其他地方引用而非重写
4. **私人化表述的思想内核必须保留，表述必须正式化**：用户的口语化表达中包含真实的哲学突破，不能因为表述不正式就丢弃
5. **渗透是持续工程，不是一次完成**：建立索引，每完成一处打勾，逐步推进
