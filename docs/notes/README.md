# docs/notes/ 目录说明

研究笔记、讨论记录、方法论、资料提取的归档目录。

## 子目录

- **方法论/** — 明本学术法、明性辩证法、小本质递归法等核心方法
- **理论研究/** — 哲学命题研究、概念梳理、公式整理
- **历史政治/** — 左翼思想、鞍钢宪法、马恩著作、制度研究
- **讨论记录/** — 与AI的长谈记录、攻防论辩、创作日志
- **工具自动化/** — 自动化流程设计、形式化基础设施
- **资料提取/** — 视频内容提取、画板集、命经备份
- **自动巡检汇报/** — 每日定时任务的巡检报告

## 根目录文件

- **待办与提醒.md** — 长期待办事项和提醒
