## 三、新增内容归位流程（3步）

当库里新增任何文化内容时，必须在24小时内完成归位：

1. **分类**：判断新增内容属于10大类中的哪一类。
2. **登记**：在文化品味总档案对应类别下添加条目。
3. **验证**：确认链接可访问、描述准确、无重复登记。

---

## 四、定期巡检机制

### 巡检频率
- 每周一次：全库文化内容巡检（检查22个目录+关键词搜索）
- 每月一次：文化品味总档案完整性审计（核对所有条目链接可访问、无重复、无遗漏）

### 巡检执行
- 由S00大总站在夜间巡检（23:00）中执行
- 巡检报告输出到：docs/协作机制/巡检报告/

### 巡检发现遗漏时
1. 立即补登到文化品味总档案
2. 记录遗漏原因（为什么之前没发现）
3. 更新检查清单（加入新的目录或关键词）
4. 如发现系统性遗漏，启动专项归位工程

---

## 五、文化品味总档案维护规范

### 条目格式标准
每个条目必须包含：
- 名称：准确的文件/人物/作品名称
- 链接：相对路径，可点击访问
- 一句话描述：核心内容/价值/定位，不超过30字
- 文件大小（可选）：大型文件标注大小

### 分类原则
- 不重复：同一文件只在一个类别下登记
- 不遗漏：所有重要文化内容必须登记
- 不夸大：描述准确
- 可验证：所有链接必须可访问，定期检查失效链接

## 七、快速归位检查命令

```bash
# 1. 列出所有大型md文件（>20KB），可能是重要研究
find docs/ -type f -name "*.md" -size +20k | xargs ls -lhS

# 2. 搜索所有学者/思想家相关文件
grep -rlE "学者|思想家|哲学家|理论家|学说|谱系|统摄|手册" --include="*.md" docs/

# 3. 搜索所有人物相关文件
grep -rlE "人物|评传|研究全编|辨析" --include="*.md" docs/reference_materials/

# 4. 搜索所有音乐/影视相关文件
grep -rlE "乐队|音乐|摇滚|民谣|金属|乐评|电影|导演|视频" --include="*.md" docs/
```
