**日期**：2026-08-27

## 一、鞍钢宪法：被抹去的企业管理革命

### 1.1 什么是鞍钢宪法

1960年3月22日，毛泽东代中央起草批示，将鞍山钢铁公司的管理模式命名为"鞍钢宪法"，要求在全国工业战线推广。

**核心："两参一改三结合"**
- **干部参加集体生产劳动**——管理者不是脱离生产的老爷，必须参加劳动
- **工人群众参加企业管理**——工人不是被管理的对象，是企业的主人
- **改革不合理的规章制度**——制度服务于人，不是人服务于制度
- **工人群众、领导干部、技术人员三结合**——决策不是精英垄断，是三者结合

**其他内容**：加强党的领导、坚持政治挂帅、大搞群众运动、大搞技术革新和技术革命、党委领导下的厂长负责制。

### 1.2 与"马钢宪法"的对立

鞍钢宪法是直接对立于"马钢宪法"（苏联马格尼托哥尔斯克钢铁公司模式）的：

| 维度 | 马钢宪法（苏联模式） | 鞍钢宪法（中国模式） |
|---|---|---|
| 管理主体 | 专家治厂、厂长负责制 | 工人参加管理、三结合 |
| 激励方式 | 物质刺激、奖金挂帅 | 政治挂帅、群众运动 |
| 规章制度 | 专家制定，工人执行 | 工人参与改革不合理制度 |
| 技术革新 | 技术人员垄断 | 干部、工人、技术人员三结合搞 |
| 哲学基础 | 精英主义、技术决定论 | 群众路线、劳动者主体 |

**起源**：一汽的"干部参加劳动、工人参加管理、三结合"经验 + 鞍钢的"改革不合理规章制度"经验 → 邓小平向政治局汇报 → 毛泽东总结命名为"鞍钢宪法"。

### 1.3 鞍钢宪法的生命论意义

鞍钢宪法不是一个管理技巧，是**生产关系的革命**：
- 马钢宪法下，工人是!-模态（被管理、被规训的死劳动）
- 鞍钢宪法下，工人是νF₂（活劳动、参与管理的生命流）
- "工人参加管理" = 承认活劳动是价值创造者，不是被萃取的对象
- "三结合" = 打破脑力劳动/体力劳动的!-模态分裂
- "改革不合理规章制度" = 制度是活劳动的产物，不是活劳动的主人

这是T001（生命不可资本化）在企业管理层面的实践——你不能把工人的活劳动完全变成可复制、可管理的死劳动，工人会反抗、会参与、会创造。

### 1.4 类似鞍钢宪法的制度（毛泽东时代的制度群）

鞍钢宪法不是孤立的，是一整套制度的一部分：

| 领域 | 制度 | 本质 |
|---|---|---|
| 工业 | 鞍钢宪法（两参一改三结合） | 工人参加管理 |
| 农村 | 人民公社、社员代表大会 | 农民参加管理 |
| 政治 | 四大民主（大鸣大放大字报大辩论） | 群众参加政治管理 |
| 医疗 | 赤脚医生、合作医疗 | 劳动者参加医疗 |
| 教育 | 民办教师、开门办学、教育与生产劳动结合 | 劳动者参加教育 |
| 干部 | 干部参加劳动、五七干校 | 管理者不脱离劳动 |
| 知识 | 知青上山下乡、知识分子与工农结合 | 脑力劳动者与体力劳动者结合 |

**共同本质**：打破!-模态的分裂（管理者/被管理者、脑力/体力、城市/农村、专家/群众），让活劳动（νF₂）在各个领域成为主体。

## 二、中国工业化到底从哪奠基的

### 2.1 时间线

| 时期 | 关键事件 | 工业化贡献 |
|---|---|---|
| 1949-1952 | 国民经济恢复 | 接收官僚资本、建立国营经济、恢复生产 |
| 1953-1957 | 一五计划 | **156项重点工程**（苏联援助），初步奠定工业基础 |
| 1958-1960 | 大跃进 | 地方工业体系建立（虽有失误，但铺开了工业布局） |
| 1961-1965 | 调整时期 | 巩固、充实、提高，工业体系完善 |
| 1964-1978 | 三线建设 | 工业布局从沿海向内地转移，建立战略后方 |
| 1966-1976 | 文革时期 | 地方"五小工业"（小钢铁、小煤矿、小机械、小水泥、小化肥）普及 |

### 2.2 关键数据

- 从"一五"到"四五"，国家基本建设投资累计**4956.43亿元**
- 1949年工业产值占工农业总产值的17%，1978年占**72%**
- 1949年钢产量15.8万吨，1978年**3178万吨**（增长200倍）
- 1949年原油产量12万吨，1978年**1.04亿吨**
- 1949年发电量43亿度，1978年**2566亿度**
- 毛泽东时代结束时：**独立的比较完整的工业体系和国民经济体系**
- 能自行设计和批量生产：汽车、飞机、坦克、拖拉机、轮船
- 尖端科技：原子弹（1964）、氢弹（1967）、人造卫星（1970）、杂交水稻（1973）

### 2.3 谁奠基的

**不是资本家个人**——1956年三大改造完成后，民族资产阶级作为一个有产者群体在形式上被改造了。但资产阶级不是固定的实体，是**生产关系的人格化（化生）**——只要活劳动没有彻底占主导、没有完整的维持活劳动的阴阳两面，!-模态（死劳动/资本/资产阶级）就在νF₂（活劳动/社会主义）中重新化生。官僚主义、特权阶层、物质刺激、专家治厂、厂长负责制——这些都是资产阶级在社会主义中的化生形态。毛泽东发动文革，根本原因就是看到了这一点：资产阶级就在共产党内。
**不是外国援助**——苏联援助了156项，但1960年苏联撤走专家后，中国靠自己继续工业化。
**是亿万工人农民的活劳动**——

- 一五计划的156项工程，是工人用血汗建起来的
- 三线建设，是几百万工人、干部、知识分子在深山沟里干出来的
- 农业集体化通过剪刀差为工业提供了原始积累（约6000-8000亿元）
- 鞍钢宪法下的工人技术革新，是工业化的技术来源之一
- 赤脚医生、民办教师提供了廉价的人力资本（健康、教育）

**工业化的真正奠基者是活劳动（νF₂），不是死劳动（资本）。**

### 2.4 大跃退叙事的遮蔽

大跃退时代的主流叙事："改革开放前中国是贫穷落后的，改革开放后才开始工业化。"

**遮蔽了什么**：
- 毛泽东时代已经建立了完整的工业体系
- 大跃退时代的"经济奇迹"是在毛泽东时代的工业基础上发生的
- 大跃退时代的"人口红利"是毛泽东时代的教育普及（识字率从20%→65%）和医疗普及（预期寿命35→65岁）提供的
- 大跃退时代的"基础设施"很多是毛泽东时代建的（水库、铁路、工厂）

## 三、谁真正创造价值

### 3.1 马克思的原文表述

马克思在《资本论》中对"资本家是资本的人格化"有三段严格表述：

**第一段（《资本论》第一卷，《马克思恩格斯文集》第5卷，人民出版社2009年版，第269页）：**
> "作为资本家，他只是人格化的资本。他的灵魂就是资本的灵魂。而资本只有一种生活本能，这就是增殖自身，创造剩余价值，用自己的不变部分即生产资料吮吸尽可能多的剩余劳动。"

**第二段（《资本论》第一卷第一版序言）：**
> "我决不用玫瑰色描绘资本家和地主的面貌。不过这里涉及的人，只是经济范畴的人格化，是一定的阶级关系和利益的承担者。"

**第三段（《资本论》第一卷第四章，货币转化为资本）：**
> "作为这一运动的有意识的承担者，货币所有者变成了资本家。他这个人，或不如说他的钱袋，是货币的出发点和复归点。这种流通的客观内容——价值增殖——是他的主观目的；只有在越来越多地占有抽象财富成为他的活动的唯一动机时，他才作为资本家或作为人格化的、有意志和意识的资本执行职能。"

**第四段（《资本论》第一卷，关于资本家的历史存在权）：**
> "资本家只有作为人格化的资本，他才有历史的价值，才有……'没有任何日期'的历史存在权。"

这四段的共同核心：**资本家不是一个人的个性或道德选择，是资本这个经济范畴的人格化。** 换一个人坐在那个位置上，只要他掌握资本、执行资本的职能，他就是资本家。资本家的"灵魂"不是他个人的灵魂，是资本的灵魂——增殖自身、吮吸剩余劳动。

### 3.2 活劳动是价值的唯一源泉
- 活劳动：劳动者在生产过程中耗费的脑力和体力，是流动状态的劳动
- 物化劳动（死劳动）：凝结在生产资料中的过去劳动，只转移价值，不创造新价值
- 资本（不变资本）：只转移价值，不创造价值
- 劳动力（可变资本）：活劳动的载体，创造新价值（包括剩余价值）

### 3.2 生命论的数学表达

| 概念 | 数学表达 | 价值创造 |
|---|---|---|
| 活劳动/生命流 | 线性资源A / νF₂ | **创造价值**（生产性的、交互的） |
| 死劳动/资本/沉积 | !-模态 !A | **不创造价值**（可复制的、萃取的） |
| 异化 | A→!A（活劳动变成死劳动） | 价值被萃取 |
| 解放 | !A→A（死劳动变回活劳动） | 价值回归创造者 |

**T001（生命不可资本化）的经济学含义**：你可以拿走活劳动的产品（B），可以杀死活劳动（S→I），但你不能把活劳动的持续展开本身（νF₂）变成可复制的死劳动（!νF₂）。活劳动永远在创造新东西，资本永远在追赶。

### 3.3 大跃退叙事的意识形态遮蔽

大跃退时代的主流叙事："企业家创造价值""资本创造价值""精英创造价值""创新来自天才"。

**这是!-模态的意识形态**——把死劳动（资本、企业、专利）说成是价值创造者，把活劳动（工人、农民、普通劳动者）说成是被雇佣的、被动的、可替代的。

**名实不符**：
- 名：企业家创造了就业、创造了财富
- 实：企业家是!-模态的人格化，他的利润来自对活劳动的萃取
- 名：资本是生产要素，和劳动平等
- 实：资本是死劳动，不创造价值，只转移价值并萃取剩余价值
- 名：AI/技术创造价值
- 实：AI是物化劳动（过去活劳动的凝结），只转移价值，最终还是活劳动（程序员、数据标注工、维护工）在创造价值

### 3.4 鞍钢宪法对"谁创造价值"的实践回答

鞍钢宪法不是空谈"劳动创造价值"，是在企业制度层面落实：
- 工人参加管理 → 承认工人是价值创造者，不是被管理的工具
- 三结合搞技术革新 → 技术进步来自工人、干部、技术人员的结合，不是技术人员的独角戏
- 改革不合理规章制度 → 制度是活劳动的产物，活劳动有权改革它
- 干部参加劳动 → 管理者不脱离活劳动，不变成纯粹的!-模态人格化

**鞍钢宪法是"活劳动创造价值"在企业制度层面的制度化。**

## 四、这对大跃退检测和N值分析的校准

### 4.1 毛泽东时代N>1的深层原因

之前的蒙特卡洛模拟显示毛泽东时代N≈1.46（成长态），宏观指标（生育率、信任度、预期寿命）解释了一部分。但深层原因是：

**生产关系为活劳动提供了结构性支撑**：
- 鞍钢宪法让工人参加管理 → 工人的νF₂不只是被萃取，是参与创造
- 公有制让生产资料属于劳动者 → 活劳动不与生产资料分离
- 免费医疗教育住房 → 活劳动的再生产不被市场化萃取
- 妇女解放 → 一半人口的活劳动从封建依附关系中解放
- 群众运动 → 活劳动的主体性被激发

**N>1不是偶然的，是生产关系为活劳动服务的结果。**

### 4.2 大跃退时代N<1的深层原因

大跃退时代N≈0.91（衰退态），生育率暴跌是直接指标。但深层原因是：

**生产关系从为活劳动服务变为为死劳动（资本）服务**：
- 厂长负责制取代鞍钢宪法 → 工人从参与者变回被管理者
- 私有化 → 生产资料与劳动者分离
- 教育医疗住房市场化 → 活劳动的再生产被萃取
- 女性重新商品化/依附化 → 一半人口的活劳动被重新压制
- "企业家创造价值"的意识形态 → 活劳动的主体性被遮蔽

**N<1不是偶然的，是生产关系为死劳动服务的结果。**

### 4.3 名实相符的最终判准

不是看你叫什么（社会主义/资本主义），不是看GDP多少，是看：

**活劳动（νF₂）是主体还是被萃取的对象？**
- 活劳动是主体 → N>1，名实相符
- 活劳动被萃取 → N<1，名实不符
