## 四、给 S04 的可执行工单：P0-1 伪自指 !-余代数翻译（拿来就能做）

> 目标：把 GPT 母稿第12-14、76节的资本函数，逐条对到库内已有范畴论对象，产出"资本=伪自指"的形式化命题链。S05 只给映射，不写 .v。

1. GPT「资本自身不生产，须进入人的活操作」⟶ **T001：! 不穿透 νF₂**。生命流是余归纳最大不动点，bang 模态无法穿透，只能截取。
2. GPT「C→生产资料+劳动力→生产→C′」⟶ **!-余代数 G→!G**：资本是"为复制而复制"的余代数，自身无 F2 代谢，必须寄生宿主 νF₂。
3. GPT「截取生命操作产出为商品/工资/数据」⟶ **! 截取 νF₂ 每步产出 B，沉积为可复制死物**（总纲63行原话）= 资本化的精确定义。
4. GPT「C↑ 而 O_i↓（资本增长与生命脱钩）」⟶ **N(t+1)=(1−β+γ)N，β>γ ⟹ N<1 锁死**；β=萃取率、γ=抵抗率。
5. GPT「长期 dV(S)/dt<0」⟶ **定理40 慢性死亡 M=αT/(1−N)<∞** + **l′=(1−N) 寄生正反馈**（增长看似繁荣实为死亡过程）。
6. GPT「资本倾向≠必然」（76节）⟶ **T001 推论：宿主 N→0 则寄生者亦亡**；但资本会用战争/法西斯续命，不会自死——与卷六04第六阶段反目的论完全一致，可直接引用。
7. 待证新命题（S04 真正要证的唯一新东西）：在上述结构下，**"伪自指"= 一个 !-余代数 P 满足 P=P(νF₂)（依赖宿主）且使宿主 β>γ（N 单调下降）**——把这个写成 Coq 定义并证明它导致 N<1 的不变式。这是拱心石闭环的最后一块。
