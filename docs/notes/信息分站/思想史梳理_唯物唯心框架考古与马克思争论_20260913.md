## 一、核心问题

"谁的本体论是什么、谁唯物谁唯心"这套划界工具——中国学生思维里的标准框架——是什么时候、由谁、以什么方式固定下来的？在这套框架之前，哲学家们自己怎么互相区分？这套体系是人为发明还是自然生长出来的？

## 二、五站链：从"内生区分"到"外来总纲"

| 站 | 时间 | 事件 | 性质 |
|---|---|---|---|
| ① | 前1886 | 哲学家自己分：理念/原子、唯名/唯实、经验/理性、先验综合 | 论题（内生、多元） |
| ② | 1886 | 恩格斯《路德维希·费尔巴哈和德国古典哲学的终结》：哲学基本问题=思维与存在关系，何者第一性 → 唯物/唯心两大阵营 | 纲领化（原话限定欧洲哲学） |
| ③ | 1895起 | "哲学"为日本西周译 philosophy；"唯物/唯心"是和制汉语，经黄遵宪《日本国志》等入华 | 语词（先于理解） |
| ④ | 1908/1947 | 列宁《唯物主义和经验批判主义》强化；日丹诺夫 1947-06-24 定义：哲学史=唯物与唯心"两军对垒"的斗争史 | 定义化 |
| ⑤ | 1950s-60s | 1957 北大哲学史座谈会（100余人，质疑两军对垒）；1963 任继愈主编《中国哲学史》四卷本套用 | 教科书化（中国学生思维定型） |

结论：作为语词和局部分界是"生长"的；作为覆盖一切的总纲+斗争史叙事是"被制造"的——五站各有明确制造者。

## 三、哲学家自己怎么互相区分

- 轴是多元的、跟着具体问题走：本体论（一/多、静/动）、认识论（经验/理性）、共相（唯名/唯实）、宗教（有神/无神）。
- 不全覆盖：亚里士多德、康德、黑格尔拒绝简单归边。
- 哲学史时间方向：问题史/概念展开，无预定胜负（与"斗争史"相反）。

## 四、三个概念的翻译（北原慢热问）

### 1. 抽象继承法（冯友兰，1957-01-08《光明日报》）
- 一个古代命题有"具体意义"和"抽象意义"：具体意义（时代、阶级内容）不能继承；抽象意义（一般道理）可以继承。
- 例："学而时习之，不亦说乎"——具体意义=孔子教的是诗书六艺（贵族教育）；抽象意义=学过的要时常温习实践。
- 后修正为"一般意义/特殊意义"；仍被批"修正主义"，成理论公案。

### 2. "唯物只能继承唯物"的困境
- 日丹诺夫逻辑：哲学史=唯物胜唯心的斗争史 → 唯心=错误=反动=不可继承。
- 但官方路线要求"从孔夫子到孙中山都要总结继承"（毛泽东，1938）→ 中国最大批思想家被划为唯心 → 按框架全不能继承 → 冯友兰用抽象继承法凿出口子：拆两层，具体意义不可继承、抽象意义可继承。是政治夹缝里的逃生术。

### 3. "质疑者与框架同在"
- 1957 座谈会本身就是质疑大会：贺麟（两派关系复杂、相互学习）、石峻（截然对立是教条主义）、冯友兰（打补丁）。
- 质疑在反右后失败，冯友兰被扣帽子，1963 教材仍按框架写。
- 含义：框架不是"被相信"的真理，是"被制度安装"的；质疑从未消失，只是被打压。

## 五、真实哲学史里的针锋相对（有，但轴不同）

| 时代 | 争论 | 轴 |
|---|---|---|
| 古希腊 | 柏拉图 vs 德谟克利特 | 理念 vs 原子 |
| 古希腊 | 亚里士多德 vs 柏拉图学派 | 理念独立还是内在于事物 |
| 中世纪 | 唯名论 vs 实在论 | 共相是否实在 |
| 宗教改革 | 路德 vs 天主教 | 唯信 vs 善功 |
| 近代 | 洛克 vs 莱布尼茨 | 经验 vs 天赋 |
| 近代 | 牛顿派 vs 莱布尼茨 | 绝对 vs 相对时空 |
| 启蒙 | 卢梭 vs 伏尔泰 | 文明进步 vs 堕落 |

没人先声明"我是唯物主义者所以我对"——标签是事后从外面贴的。

## 六、哲学转向 → 文明变化（部分实例）

- 柏拉图理念论 → 奥古斯丁 → 中世纪基督教文明框架
- 亚里士多德13世纪回潮 → 阿奎那 → 经院哲学+大学
- 唯名论（奥卡姆剃刀） → 近代经验科学开路
- 笛卡尔/培根/牛顿 → 科学革命 → 启蒙
- 洛克自然权利 → 美国《独立宣言》；卢梭 → 法国大革命
- 康德 → 现代主体性 → 现代性规划
- 黑格尔 → 马克思 → 社会主义运动 → 20世纪政治版图
- 尼采 → 存在主义/后现代 → 20世纪文艺与价值危机

## 七、学院争论的展开方式

1. 面对面论辩（学园、吕克昂、中世纪大学 disputatio）
2. 著作逐章互批（莱布尼茨《人类理智新论》逐条批洛克）
3. 附"反驳+答辩"一起出版（笛卡尔《第一哲学沉思集》1641首版带七组反驳答辩）
4. 书信论战（莱布尼茨—克拉克 1715-16）
5. 权力介入（布鲁诺火刑、伽利略审判、斯宾诺莎被开除教籍）

## 八、与马克思式争论的异同

| 维度 | 学院式 | 马克思式 |
|---|---|---|
| 对象 | 外部对手（别的学派） | 内部清算（青年黑格尔派、费尔巴哈、蒲鲁东、拉萨尔派） |
| 战场 | 观念/文本/教席 | 物质生产（《资本论》=政治经济学批判） |
| 目的 | 定位（占位置） | 前进（与旧我决裂、改变世界） |
| 对学派 | 建学派传谱系 | "我只知道我自己不是马克思主义者" |
| 输赢 | 读者/教席/政权支持 | 实践是否改变现实 |

最深一层：马克思反框架化，但恩格斯→列宁→日丹诺夫恰恰把哲学史重新框架成"唯物vs唯心斗争史"——把马克思最反对的事施加给哲学史和马克思主义本身。这正是"沉积物夺取操作权"（阴夺阳位）的活标本。

## 九、与生命论的衔接点（S05 整理，待明旭雕琢）

- 唯物/唯心二分是"先选一个组织性问题，再回写整部哲学史"的手术式投影——用生命论语言：框架是沉积物，活的思想是操作；教科书让沉积物夺取了对思想史的操作权。
- 生命论从"操作"出发，绕开了在心物之间必须先选一边的模具——这可能是它对这套两千年框架的超越点。
