## 五、保密边界（与 v2.0 一致，仍需作者知悉）

- **当前与未来版本**：私人内容已撤下且有 .gitignore 防回流。
- **历史提交**：这些文件曾进入公开仓库的 git 历史，历史对象里仍可被翻出；仅删当前树**不能抹除历史**。要彻底从公开历史清除，须 `git filter-repo` 重写历史（改写全部 commit hash、所有分站需重新克隆）——属重大动作，**作者尚未批准，维持不动**。

## 六、回流根因与长效建议

三次迁移（09-02 / 09-12 / 09-14）都是同一根因：**在 .gitignore 规则补齐之前，旧的长寿命分支仍带着大文件，merge/rebase 时把它们带回主树**。

- 本次已把规则补齐到全部 8 个已迁文件，理论上闭环。
- 建议 S05 每日巡检在标题门之外，加一条**大文件防回流断言**：`git ls-files | xargs` 扫描命中 .gitignore 已迁名单即报警，从机制上不再依赖人工发现。是否落地由作者定。
