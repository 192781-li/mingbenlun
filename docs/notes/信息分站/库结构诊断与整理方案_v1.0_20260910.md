## 二、五大混乱点

### 混乱点1：reference_materials 三处重复

| 位置 | 文件数 | 内容 |
|---|---|---|
| `reference_materials/`（顶层） | 2 | 杂项（工人诗歌、毛主席语录） |

**问题**：找参考资料不知道去哪。三处并存，内容有重叠。

### 混乱点2：scripts 两处重复

| 位置 | 文件数 | 内容 |
|---|---|---|
| `scripts/` | 45 | **当前在用**：s04_deepseek/、token_management/、backup.sh、river_sync.sh等 |
| `mingben-workbench/scripts/` | 48 | **旧工作台脚本**：quality_gate.py、mingcheck.py、verify_*.py等 |

**问题**：哪些是活的、哪些是死的？新人分不清。

### 混乱点3：tools 两处重复

| 位置 | 内容 |
|---|---|
| `tools/` | **当前在用**：video_tools/、术数工具包/、实时留痕工具包/ |
| `mingben-workbench/tools/` | **旧工具**：lianglun_calc.py、ptl_prototype.py等12个Python |

### 混乱点4：docs/ 下小目录过多（22个二级目录）

11个目录只有1-4个文件：
- annotations(2)、drafts(1)、exercises(4)、formalization(2)

## 三、整理方案（目标：清晰、唯一、可导航）

### 原则

1. **一物一位**：同类东西只在一个地方，不重复
2. **活死分离**：当前在用的放标准位置，旧的归档
3. **目录收敛**：小目录合并为大类
4. **命名统一**：中英文不混用，用中文分类名

### 具体动作

#### 动作1：合并 reference_materials（三处→一处）

```
目标：docs/reference_materials/ 为唯一参考资料目录

- 顶层 reference_materials/ 的2个文件 → 移入 docs/reference_materials/杂项/
- mingben-workbench/references/ 的167个文件 → 分类：
  - Coq/形式化相关 → docs/formalization_references/（新建）
  - enactics论文/概念图 → docs/reference_materials/学术论文/
  - 其他 → 归档或合并
- 删除顶层 reference_materials/ 空目录
- mingben-workbench/references/ 处理后删除或留INDEX
```

#### 动作2：合并 scripts（两处→一处）

```
目标：scripts/ 为唯一脚本目录

- mingben-workbench/scripts/ 的48个脚本：
  - 仍在用的 → 移入 scripts/（如 quality_gate.py 等）
  - 已过时的 → 移入 archive/old_scripts/
- 删除 mingben-workbench/scripts/
```

#### 动作3：合并 tools（两处→一处）

```
目标：tools/ 为唯一工具目录

- mingben-workbench/tools/ 的12个工具：
  - 仍在用的 → 移入 tools/对应子目录
  - 已过时的 → 归档
- 删除 mingben-workbench/tools/
```

#### 动作4：收敛 docs/ 小目录（22个→约12个）

```
合并方案：
- annotations/ + 批判性阅读/ → docs/阅读笔记/
- drafts/ → 归档（只有1个文件）
- exercises/ + 文科学习/ → docs/学习训练/
- formalization/ + docs/notes/Coq形式化/ → 统一到 docs/notes/Coq形式化/
- 体系/ + 体系工具/ + 语义论/ + 语源哲学笔记/ → docs/体系研究/
- 参考溯源/ + 思想史研究/ → docs/reference_materials/思想史/
- 金句录/ → docs/金句录/（保留，3个文件但有独立价值）
- 北原慢热原创/ → docs/reference_materials/北原慢热/
- 长谈实录/ + flashpoints/ → docs/对话与闪光/
```

#### 动作5：明确 mingben-workbench/ 定位

```
方案A（推荐）：逐步淘汰
- references/ → 合并到 docs/
- scripts/ → 合并到 scripts/
- tools/ → 合并到 tools/
- results/ → 归档
- 最终删除 mingben-workbench/

方案B：保留为"实验区"
- 明确标注：这是实验脚本/工具的暂存区
- 成熟后迁移到标准位置
```

#### 动作6：统一 archive/ 命名

```
当前15个二级目录，中英文混合：
- book_combined/、html_exports/、large_files_index/、mingben-output/
- old_editions/、old_task_files/、outputs/、personal/
- task_packages/、temp_logs/、旧机制_collaboration_20260827/
- 旧版本/、案例档案/、生命论_实践篇/、视频档案/

整理为：
archive/
├── old_editions/      （旧版文档，已有）
├── old_scripts/       （新建，旧脚本）
├── old_workbench/     （新建，mingben-workbench旧内容）
├── exports/           （合并 html_exports + mingben-output + outputs）
├── archives_misc/     （合并 personal + task_packages + 案例档案 + 生命论_实践篇）
└── temp_logs/         （已有）
```

## 五、执行计划（分3批，每批一个commit）

### 第一批：低风险合并（不动代码）
1. 顶层 reference_materials/ → docs/reference_materials/杂项/
2. docs/ 小目录合并（annotations/drafts/exercises等）
3. archive/ 命名统一

### 第二批：scripts/tools 合并
4. mingben-workbench/scripts/ 筛选 → scripts/ 或 archive/old_scripts/
5. mingben-workbench/tools/ 筛选 → tools/ 或归档

### 第三批：mingben-workbench 收尾
6. mingben-workbench/references/ 分类合并
7. mingben-workbench/results/ 归档
8. 删除空目录，更新导航地图

## 六、风险与保障

| 风险 | 保障 |
|---|---|
| 移动文件导致引用失效 | 移动后 grep 检查旧路径引用，更新导航地图 |
| 误删仍在用的脚本 | 先移到 archive/old_scripts/，不直接删，观察1周 |
| Coq代码受影响 | coq/ 目录完全不动 |
| 正文受影响 | 生命论_模块化/ 完全不动 |
| git历史丢失 | 用 git mv 保留历史，不用 rm+cp |
