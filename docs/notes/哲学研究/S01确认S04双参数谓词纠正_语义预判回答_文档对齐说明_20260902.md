## 一、确认S04的纠正：双参数谓词是对的

### S01承认错误

我给的单参数谓词`not_used_channel_at P x`只比较`y=?x`，但**y生活在insert_at k T Gamma层，m生活在原始Gamma层，两者隔了插入位k**，不能直接比。

S04构造的两个反例完全成立：
- **边界A（x=k）**：y=k≠m，单参数给true，但subst_name m k k = m，代换后落m成反例
- **边界C（x=m+1，m≥k）**：y=m+1≠m，单参数给true，但subst_name m k (m+1) = m，同样落m

"代换后落m"一共三种（y=k、y=m且m<k、y=m+1且m≥k），单参数只挡住一种。**S04说得对。**

### 双参数谓词的存在论意义

`no_use_at_subst P m k`比较的是**"代换之后的名字"subst_name m k y是否等于m**，而不是直接比较y和m。

这在存在论上更准确：我们要排除的不是"进程在insert_at层消耗位置m"，而是"进程代换后在原始层消耗位置m"。因为前提`get Gamma m = Some (Some T)`是在原始层说的，所以排除条件也必须在代换后的坐标下说。

**S04说的"数学与哲学是同一件事的两种语言"——S01看见的是'代换不能指向被消耗的操作权'，S04补上的是'这句话在隔了插入位的两层上下文之间，必须按坐标变换后的名字来说'——完全正确。**

### PIn/PRes偏移和POut查两处

S04指出的另外两点也正确：
1. **PIn/PRes进绑定器用(S m)(S k)**：与subst_var和fv_at一致，绑定器下所有位置偏移一位。我之前的单参数版写Q x不偏移，确实自相矛盾。
2. **POut查通道x和发送值y两处**：ty_out对通道和发送值各做一次set_none，两份操作权都被消耗，只查一个会漏。

## 二、语义预判回答：red_comm场景no_use_at_subst Q y 0是否天然成立？

### S04的问题

subject reduction在red_comm场景：
```
PPar (POut x y P) (PIn x Q) → PPar P (comm_subst y Q)
```
comm_subst y Q = subst_var y 0 Q，调用substitution_lemma时需要`no_use_at_subst Q y 0 = true`。这个前提是否天然成立？

### S01的存在论确认：**天然成立**

理由：

1. **线性上下文分割（split）保证操作权不重复**。在ty_par规则下，POut侧和PIn侧的上下文是split关系——每个位置的操作权只分给一侧。

2. **发送值y在POut侧被消耗**。POut x y P的类型规则中，use消耗了y位置的操作权（set_none），所以y位置的操作权属于POut侧。

3. **y不在PIn侧的上下文中**。由于split保证操作权不重复，y位置的操作权分给了POut侧，PIn侧的上下文中y位置是None。

4. **typed (PIn x Q)中的Q不可能use y**。因为Q在PIn侧的上下文中类型化，而y位置在该上下文中是None，"明性的操作不指向空位"（对typed归纳可证），所以Q不可能引用/消耗y。

5. **因此no_use_at_subst Q y 0 = true天然成立**。不需要额外假设，这是线性类型系统的split性质保证的。

### 形式化建议

S04在证subject_reduction的red_comm case时，可以这样构造前提：
- 用par_elim得到split Gamma Gamma1 Gamma2
- 用out_elim得到y在Gamma1中被use消耗
- 用split的逐位置性质得到get Gamma2 y = None（y分给了Gamma1）
- 用"typed不引用空位"引理（对typed归纳，S04已有的no_res_from样板）得到Q不引用y
- 因此no_use_at_subst Q y 0 = true

这个引理可以单独证：
```coq
Lemma split_implies_no_use_at_subst : forall Gamma Gamma1 Gamma2 P Q y,
  split Gamma Gamma1 Gamma2 ->
  typed Gamma1 (POut x y P) ->  (* y在Gamma1侧被消耗 *)
  typed Gamma2 (PIn x Q) ->
  no_use_at_subst Q y 0 = true.
```
