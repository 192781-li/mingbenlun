## 一、命名澄清

| 谓词 | 类型 | 含义 | 已有/新增 |
|---|---|---|---|
| fv_at P k | Prop | P中是否有自由变量 >= k（绑定器深度） | S04已有（Layer2.v第13行） |
| fv P | Prop | fv_at P 0，P是否有自由变量 | S04已有 |
| **uses_at P x** | **bool** | **P是否引用特定位置x的操作权** | **本文档新增** |

两者不同：fv_at P k判断"有没有自由变量在深度k以上"，uses_at P x判断"有没有引用具体的位置x"。

## 二、uses_at定义（引用特定位置谓词）

```coq
Fixpoint uses_at (P : proc) (x : nat) : bool :=
  match P with
  | PZero => false
  | PTau Q => uses_at Q x
  | PVar n => Nat.eqb n x
  | POut y z Q => Nat.eqb y x || Nat.eqb z x || uses_at Q x
  | PIn y Q => Nat.eqb y x || uses_at Q x
  | PRes Q => uses_at Q x
  | PRep Q => uses_at Q x
  | PPar Q R => uses_at Q x || uses_at R x
  end.
```

**存在论意义**：uses_at P x = true 表示进程P在操作中引用了位置x的操作权。这是"操作权被实际使用"的形式化表达。

**注意**：
- POut有两个通道位置（y=输出通道，z=发送值），都算引用
- PIn只有一个通道位置y
- PRes/PRep不增加绑定器深度（和S04的fv_at不同，uses_at不做深度偏移，因为它判断的是绝对位置）

## 三、引理1：subst_var_not_used（不引用k则代换不变）

```coq
Lemma subst_var_not_used : forall P m k,
  uses_at P k = false ->
  subst_var m k P = P.
```

**证明策略**：对P归纳。
- PZero：simpl，reflexivity
- PTau Q：simpl，uses_at (PTau Q) k = uses_at Q k → 归纳假设
- PVar n：uses_at (PVar n) k = (n =? k) = false → n ≠ k → subst_var m k (PVar n) = PVar n
- POut y z Q：simpl，分解uses_at为各部分的或，每个部分用归纳假设
- PIn/PRes/PRep/PPar：类似

**存在论意义**：如果进程不引用某个位置的操作权，那么把那个位置重定向到另一个位置，进程不变。

## 四、引理2：typed_implies_uses_get_some（类型化进程引用的位置必有类型）

```coq
Lemma typed_implies_uses_get_some : forall Gamma P x,
  typed Gamma P ->
  uses_at P x = true ->
  exists T, get Gamma x = Some (Some T).
```

**证明策略**：对typed Gamma P归纳（对推导归纳，不是对P归纳）。
- ty_var：P=PVar n，uses_at=true → n=x → 前提直接给出
- ty_tau：uses_at (PTau Q) x = uses_at Q x → 归纳假设（注意PTau的类型规则）
- ty_zero：uses_at=false，前提矛盾
- ty_out：uses_at (POut y z Q) x = true → y=x ∨ z=x ∨ uses_at Q x
  - y=x：use前提给出get Gamma y = Some (Some (TChan ...))
  - z=x：第二个use前提给出
  - uses_at Q x：归纳假设（Q在Gamma2中类型化）
- ty_in：类似ty_out
- ty_res：uses_at (PRes Q) x = uses_at Q x → 归纳假设
- ty_rep：类似
- ty_par：uses_at (PPar Q R) x = true → uses_at Q x ∨ uses_at R x → 归纳假设

**关键**：generalize dependent x，对typed推导归纳。

**存在论意义**：类型化的进程只能引用有操作权的位置（Some (Some T)），不能引用None位置。

## 五、引理3：strengthening_insert_at（强化引理：不引用扩展位置则可去掉扩展）

```coq
Lemma strengthening_insert_at : forall Gamma T k P,
  typed (insert_at k T Gamma) P ->
  uses_at P k = false ->
  typed Gamma P.
```

**证明策略**：对typed (insert_at k T Gamma) P归纳。
- ty_var：P=PVar n，uses_at=false → n≠k。需要get Gamma n = Some (Some T')。
  - 前提get (insert_at k T Gamma) n = Some (Some T')
  - n≠k，分n<k和n>k，用get_insert_at_lt/gt引理
- ty_tau：归纳假设
- ty_zero：直接apply
- ty_out：use关系分情况（x<k / x=k / x>k）
  - x<k：set_none_insert_at_lt，Gamma1 = insert_at k T (set_none Gamma x)，body用归纳假设
  - x=k：use消耗插入位置k，但uses_at P k=false意味着P不引用k。需要证明use可以调整。
  - x>k：set_none_insert_at_gt，类似
- ty_in：类似ty_out
- ty_res/rep：归纳假设
- ty_par：split分情况，两个子进程用归纳假设

**注意**：x=k的情况是难点。use消耗了插入的T，但P不引用k。这时候use消耗的T在原始Gamma中不存在，需要证明这种情况下typed Gamma (POut y z Q)可以通过其他方式建立。可能需要一个引理：use消耗未被引用的位置时，类型化可以弱化。

**存在论意义**：如果进程不引用某个位置的操作权，那个位置的操作权可以去掉，进程仍然类型化。

## 六、引理4：uses_at_subst_var_redirect（代换后引用重定向）

```coq
Lemma uses_at_subst_var_redirect : forall P m k,
  uses_at P k = true ->
  uses_at (subst_var m k P) m = true.
```

**证明策略**：对P归纳。
- PVar n：uses_at (PVar n) k = true → n=k → subst_var m k (PVar k) = PVar m → uses_at (PVar m) m = true
- PTau/PIn/PRes/PRep：分解uses_at，找到引用k的子项，用归纳假设
- POut：两个通道位置+body，分别处理
- PPar：两个子进程，分别处理

**存在论意义**：代换把对k的引用改成对m的引用。如果P引用k，代换后必然引用m。

## 七、这些引理在OB-009中的应用（取决于主人决定的方向）

### 如果走方向B（改PIn类型规则，body不能引用insert_at位置）
- 用typed_implies_uses_get_some的逆否：如果get Gamma' x = Some None，则uses_at P x = false
- 证明body不能引用S k（因为代换后S k→S m，而S m是None）

### 如果走方向C（改代换定义，目标位置为None时no-op）
- 用subst_var_not_used：当目标位置m是None时，代换是no-op
- 但这需要修改subst_var的定义

### 如果走方向A（加前提，代换目标位置未被消耗）
- 这些引理暂时用不上，但对PPar仍然必要

## 八、这些引理在PPar中的应用

PPar case需要：
1. uses_at定义：判断哪个子进程引用插入位置k
2. subst_var_not_used：不引用k的子进程代换不变
3. typed_implies_uses_get_some：类型化进程不能引用None位置
4. strengthening_insert_at：去掉未使用的插入位置
