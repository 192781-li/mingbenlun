# 生命论模块化总纲 · 政治哲学 × 政治经济学

> **本稿一句话**：把政治哲学与政治经济学两大卷的全部现有知识，拆成**可独立调用、可单独验证、可互相接线**的模块；每个模块用同一套**五问模板**交代清楚（①严格定义 ②标准公式 ③特殊思维 ④异同 ⑤马克思渊源）；再开 N 条研究线路，每条线路 = 目标 + 入口模块 + 依赖 + 判词归属 + 下一步。
>
> **五问模板（每个模块统一回答）**：
> 1. **严格定义是什么？** —— 一词一义，可操作化，不靠比喻。
> 2. **标准公式是什么？** —— 有形式就写形式；无形式就写"待形式化"，不硬造。
> 3. **特殊的思维是什么？** —— 这个模块独有的切入方式（别的理论没有的）。
> 4. **异同是什么？** —— 与相邻概念/相邻理论的同与异。
> 5. **与马克思的渊源是什么？** —— 承袭/修正/扩展/接茬，逐条标 [M]/[A]/[L]/[?]。

---

## 〇、模块化原则（三条）

1. **模块 = 可独立调用的知识单元**：一个模块有唯一名称、唯一符号、一个权威出处；模块之间只通过显式"接线"（指针）连接，不允许互相含混。
2. **五问齐全才算模块**：说不清严格定义、没有公式（或明言待形式化）、讲不出特殊思维、不标异同、不交代马克思渊源的，视为未完成模块，标 [?] 挂账。
3. **线路 = 模块的推进路径**：一条线路由一个"目标"驱动，串联若干模块，有明确的下一步动作和判词归属；线路之间允许共享模块，不允许互相改写模块。

## 第一部分：两大卷总纲（五问速答）

### A. 政治哲学卷（本体论→国家→革命→两世界）

| 五问 | 政治哲学总纲回答 |
|---|---|
| 1. 严格定义 | 政治哲学研究**自指生命如何组织共同体并保持/丧失自身操作权**；核心对象是操作权 O⃗=(O_p,O_o,O_s)，不是权力名号。 |
| 2. 标准公式 | S=f(S)（自指）；反自指三条件 dV(S)/dt<0 ∧ P=f(S) ∧ P依赖V(S)>0；O⃗=(O_p,O_o,O_s)；S_i↔G_i↔N_i↔W（国家循环）。 |
| 3. 特殊思维 | **自指—反自指判据**：政治结构的好坏不以名称/道德判定，以"是否扩大或抽干底层生命自指能力"判定；阴阳（阳主阴从）作结构关系而非道德评价；"革命=操作权回归过程"而非一次性暴力事件。 |
| 4. 异同 | 与自由主义：自由=退出权+权利清单 → 生命论补"有效退出能力 E_i"（形式权≠实际能力）；与马列国家论：列宁"暴力工具"是剥削社会特例，生命论国家=自指共同体操作权沉积结构（阴），可正可反；与西方正义论：正义=操作权分布+反馈质量，不是分配正义单指标。 |
| 5. 马克思渊源 | 马克思贡献阶级分析与社会再生产总框架；生命论保留其分析对象，把"生产关系"接回"生命自指能力"，把"革命"从历史必然性改写为操作权回归的持续过程（[A] 待作者审）。 |

**政治哲学模块索引（M1–M10）**：见第二部分。

### B. 政治经济学卷（价值→资本→制度→世界体系）

| 五问 | 政治经济学总纲回答 |
|---|---|
| 1. 严格定义 | 政治经济学研究**生命如何组织物质再生产**；核心问题=**谁拥有实际操作权**（谁生产/谁控制生产资料/谁决定生产什么/谁取剩余/谁用剩余/谁承担风险/谁可退出/谁改规则）。 |
| 2. 标准公式 | 价值五层 V_M(x)=λ·T_SNL(x) 与 L(x;S,E)≈ΔV_self 分离；T=T_N+T_S；s/v=T_S/T_N；M−C⋯P⋯C′−M′；K_(t+1)=K_t+ρs_t−δK_t；O⃗=(O_p,O_o,O_s)；P⃗=(P_pos,P_ctrl,P_use,P_surplus,P_exit)。 |
| 3. 特殊思维 | **三层价值分离**（经济价值≠生命价值，V_M↑可伴L↓）；**资本=伪自指**（形式 C=f(C) 实为借生命自指完成增殖）；**操作剩余 S_O=O^actual−O^returned**（反馈≠工资）；**"不必然"判据**（资本/市场/国家/社会主义都不必然反自指，须给制度条件）；**评价向量优先于单一数字**（X 十一元）。 |
| 4. 异同 | 与新古典：价格由边际决定 → 生命论沿马克思追问价格背后的社会关系与操作权分布；与凯恩斯：需求管理 → 生命论看反馈结构与操作权；与苏联政治经济学：国有化≠社会化，名义所有≠实际控制；与制度经济学：制度→交易成本 → 生命论看制度对自指能力的净效应。 |
| 5. 马克思渊源 | 逐节承袭：价值/劳动力/必要剩余劳动/剩余价值/资本循环/平均利润/再生产/危机（[M]）；生命论扩展：剩余→操作剩余、资本→伪自指、积累→自指转移、剥削→操作权占有、解放→自指能力扩大（[L]/[A]）。关系=**接茬生长**，不是换词替代。 |

**政治经济学模块索引（E1–E17）**：见第二部分。

## 第二部分：模块化地图（五问齐全，全部带指针）

### 政治哲学模块 M1–M10

#### M1 在感与操作（本体论根基）
- **严格定义**：在感=第一人称起点；感先于操作、操作先于实体；实体=沉积后的操作结构。
- **标准公式**：感→操作→实体（序关系，非等式）。
- **特殊思维**：把"名词是操作的前提"翻转成"名词是操作的沉淀"——从操作出发理解一切沉积物。
- **异同**：与现象学"意向性"近而不同（生命论从感出发，不从意识结构出发）；与唯物主义"物质第一性"不冲突但换认识论起点。
- **马克思渊源**：无直接渊源；为生命论接马克思提供本体论接口（劳动→操作）。
- **状态**：[L] 【指→】迁移总稿 §1；S01在感分析系列

#### M2 自指与生命（核心武器）
- **严格定义**：自指=系统输出重新成为维持/修正/再生产自身运行的输入；生命=具有生产性自指的操作系统。
- **标准公式**：S=f(S)；νF₂=F(νF₂)；生命性五要素（边界生成/内生目的性/操作再生/环境交互/边界防御）。
- **特殊思维**：自指不是"系统谈论自己"，是操作层面的再生；四存在层级（非自指/弱自指/强自指/超自指）。
- **异同**：与系统论"自组织"近；与哥德尔"自指命题"是不同层次（操作 vs 语句）。
- **马克思渊源**：无；是生命论全部政治分析的元结构。
- **状态**：[L] 【指→】迁移总稿 §2；生命语义卡_自指

#### M3 反自指（异化的形式判据）
- **严格定义**：结构 P 使用 S 的操作能力、使 V(S) 持续下降、同时依赖 S 继续存在 ⇒ P 对 S 构成反自指。
- **标准公式**：dV(S)/dt<0 ∧ P=f(S) ∧ P 持续存在要求 V(S)>0。
- **特殊思维**：反自指≠没有自指，是**主动反转正自指的寄生操作**；六阶段（窃权→惯性锁死→名实遮蔽→生命耗散→负反馈锁死→系统崩溃）；异化=迹统治生。
- **异同**：比"剥削"更宽（官僚主义/垄断/金融化/技术异化同构）；比"异化"更可操作（三条件判据）。
- **马克思渊源**：马克思的"死劳动支配活劳动"是反自指的一种历史形式；生命论给出一般判据（[L]，马克思渊源为[L]内部标注）。
- **状态**：[L]（判据已定，充分性待证 [?]）【指→】迁移总稿 §3；公式全编体系一

#### M4 感—应—能—明性（主体能力四阶）
- **严格定义**：感=第一人称生命表达；应=对他者/环境的直接回应（社会自指的边界机制）；能=改变因果链的实际能力；明性=生命对自身操作的递归意识化。
- **标准公式**：感→应→能→明（序）。
- **特殊思维**：把"应"当作社会的细胞膜；明性 f³ 是自指对自指的自觉（反身不常驻）。
- **异同**：与儒家"感而遂通"、列维纳斯"他者"有对话点；明性F3≠生命之光F1/F2（术语铁律）。
- **马克思渊源**：无直接渊源；为"阶级意识/实践"提供生命论底层。
- **状态**：[L] 【指→】迁移总稿 §4；F1F2F3多层含义梳理

#### M5 阴阳（结构关系，非道德评价）
- **严格定义**：阳=主动生成更新；阴=沉淀保存结构；**阳主阴从**是结构关系。
- **标准公式**：阳→阴→阳（健康循环：劳动→产品→生产资料→新劳动）；异化=阴→阳（死劳动支配活劳动）。
- **特殊思维**：只破不淀=唯意志论；只淀不破=保守主义；"阴画地，阳在地中走"。
- **异同**：与道家阴阳近，但生命论明确其为**操作结构**关系；与黑格尔辩证法不同（不自称正反合必然）。
- **马克思渊源**：无马克思原文渊源；"死劳动=阴夺阳位"是库内独有（一级缺口④，批次04未收）。
- **状态**：[L] 【指→】迁移总稿 §5；生命语义卡_国家与革命

#### M6 操作权（政治哲学核心问题）
- **严格定义**：O⃗=(O_p 生产操作权, O_o 剩余配置权, O_s 规则修改权)；向量而非简单加法（量纲纪律）。
- **标准公式**：O⃗=(O_p,O_o,O_s)；经验指数 O\*=w_pO_p+w_oO_o+w_sO_s（Σw=1）。
- **特殊思维**：收入↑≠操作权↑；国家能力↑≠人民操作权↑；名义所有≠实际控制；自指转移 S_i↛N。
- **异同**：比"权力"可操作（三权明确）；比"权利"实质（实际决定能力而非法定资格）。
- **马克思渊源**：马克思的生产资料所有权→生命论拆为操作权三分+所有权五元（[A]）。
- **状态**：[L]（作者三分已定；三分向量化 2026-09-15 已采纳）【指→】迁移总稿 §7；批次04 §11–13

#### M7 国家（自指共同体的沉积结构）
- **严格定义**：国家=超越直接关系规模后，用于维持大规模生命联合的制度化自指结构（阴）；被劫持自我增殖=反自指。
- **标准公式**：S_i↔G_i↔N_i↔W（健康循环）；O_state↑∧O_people↓=自指转移。
- **特殊思维**：国家自指能力≠人民自指能力；列宁暴力工具=剥削社会特例而非国家定义。
- **异同**：与韦伯"暴力垄断"异（生命论看反馈结构）；与列宁"阶级工具"近而宽。
- **马克思渊源**：承马克思国家批判；扩展出"国家所有≠人民所有"的操作权判定（[A]）。
- **状态**：[L]/[A] 【指→】迁移总稿 §8、§30；生命语义卡_国家与革命

#### M8 改革·革命·继续革命
- **严格定义**：改革=既有结构内恢复/扩大有效反馈；革命=反馈结构性堵塞时重建操作权与反馈结构；继续革命=持续扩大低层实际操作权+持续检测高层异化+持续修复反馈。
- **标准公式**：CR=ΔO_low+D_anti-alienation（双因子）；革命成功标准=长期提高普通人生命自指能力。
- **特殊思维**：革命≠一次性暴力事件；运动≠继续革命（运动若致 O_i↓ 则运动本身异化）；解放三阶=解蔽→收权→立序。
- **异同**：与经典革命论异（不以政权更替为成功标准）；与改良主义异（不否认结构性重建）。
- **马克思渊源**：承马克思革命与巴黎公社分析；批次04 33章三压力测试（巴黎公社/苏联/毛时代）为此模块的历史检验位。
- **状态**：[L]/[A] 【指→】迁移总稿 §9；核心命题5–6；批次04 §32–33

#### M9 历史周期（模型非定律）
- **严格定义**：生成→稳定→沉淀→固化→权力集中→反馈下降→异化→危机→再生成。
- **标准公式**：周期链（无等式；明确"理论模型不是确定性历史定律"）。
- **特殊思维**：历史循环非宿命（写作避坑铁律：历史目的论禁止）；周期可被操作权恢复打断。
- **异同**：与汤因比/斯宾格勒循环论异（非文明宿命论）；与马克思历史唯物主义近而更注意反馈细节。
- **马克思渊源**：马克思社会形态论→生命论周期模型（[A]）。
- **状态**：[A] 【指→】迁移总稿 §10；批次04 §31

#### M10 两个世界与全球层
- **严格定义**：两世界以结构性关系分（谁从谁的劳动/资源/操作能力获得系统性收益），不以地缘强弱分。
- **标准公式**：W_S={R_ij^self}／W_A={R_ij^anti}；W=F({G_i},R,E)；O_W=对全球生产分配规则的实际决定能力。
- **特殊思维**：全球互联≠世界自指、世界统一≠世界自指；禁止把国家永久标签化；战略=先收回操作权（内）→再改变全球反自指结构（外）。
- **异同**：与依附论/世界体系论（沃勒斯坦）近而不同（关系矩阵化、不预设中心—边缘固定）；与"文明冲突论"根本异（结构性关系而非文化本质）。
- **马克思渊源**：承《资本论》世界市场与殖民地分析；扩展为关系矩阵（[A]）。
- **状态**：[L]/[A] 【指→】迁移总稿 §45–48；两个世界理论_20260823；批次04 §29–30

### 政治经济学模块 E1–E17

#### E1 价值五层（防混淆总闸）
- **严格定义**：U 使用价值 / E_x 交换关系 / V_M 马克思价值 / L 生命贡献量 / V_M≠L 关系命题——五层分离。
- **标准公式**：U(x;S,E)；x:y=a:b；V_M(x)=λ·T_SNL(x)；L(x;S,E,τ)≈ΔV_self（≈故意不写=）。
- **特殊思维**：V_M↑可伴L↓（奢侈品/投机）；V_M↓可伴L↑（免费公共教育）；两套价值理论并存。
- **异同**：比马克思多"生命贡献量"一维；比效用论多"社会必要劳动"锚点。
- **马克思渊源**：[M] 使用价值/交换价值/价值三分全承袭；[L] 生命贡献量为新增。
- **状态**：[M]+[L] 【指→】迁移总稿 §12；批次04 §1

#### E2 劳动—劳动力（价值理论关键接口）
- **严格定义**：LP=劳动的能力（劳动力）；LB=劳动实际活动；资本购买 LP 而非 LB。
- **标准公式**：LP≠LB；劳动力价值 ∝ 维持与再生产劳动者所需的社会必要劳动量。
- **特殊思维**：劳动力商品的特殊使用价值=其使用可创造超过自身价值的价值。
- **异同**：马克思 [M] 原论；生命论注意"劳动力≈生命操作能力"的对接（见冲突登记 N3 待定）。
- **马克思渊源**：[M] 全承袭（《资本论》第一卷劳动力商品章）。
- **状态**：[M] 【指→】迁移总稿 §13；批次04 §2

#### E3 必要劳动与剩余劳动
- **严格定义**：T=T_N(必要劳动时间)+T_S(剩余劳动时间)；剩余劳动=超过劳动力价值再生产所需的部分。

## 第六部分：一句话收束

**模块化 ≠ 重写理论**。模块是"库内已定知识"的整理形态：每个模块的五问都指向库内权威位，冲突都进登记，线路都等作者发令。**判词铸字归北原慢热**——本稿只是把知识归位、把路标立好，让任何 AI 接手时能"一切皆有把握，一切地图皆有指向"。
