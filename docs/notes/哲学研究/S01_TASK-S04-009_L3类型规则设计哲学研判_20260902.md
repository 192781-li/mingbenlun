## 总原则

L3是生命论形式化的核心层。类型规则不是技术设计，是存在论判断的形式化表达。每一条引入/消去规则，都对应一个"什么是生/迹/假/明"的哲学判断。

设计原则：**操作先于实体，感先于操作。** 类型不是对实体的分类，是对操作方式的分类。

## 判断点1：Sheng（生）的引入消去规则

### 1.1 引入规则：什么情况下"拥有生"？

**哲学结论**：Sheng不是"拥有"的，是"正在发生"的。引入规则不应该是"某个条件满足所以得到Sheng"，而应该是**Sheng是自指循环的当下运行**。

**形式化建议**：
- Sheng的引入不是通过构造子从无到有地"造"出来，而是通过`self_ev`（自指证据）假设引入。
- 这对应哲学：生不是被推导出来的，是被给予的、是第一性的。你不能从理论推出"我在活着"，你只能在活着中确认活着。
- 具体：`self_ev : Sheng(A)` 是一个假设（axiom/hypothesis），不是定理。没有规则能从其他类型推出Sheng。

**存在论根据**：
- 生命论第一原则：感是第一性的，不能被推导。Sheng就是感的操作维度——正在发用的感。
- 对应T002：!Ji ⊬ Sheng——迹不能推出生。如果Sheng能从其他东西推导出来，T002就不成立了。

### 1.2 消去规则：生用完之后变成什么？

**哲学结论**：生用完之后**消失**，不转化为Ji。Ji是生的**沉积**，不是生的"转化产物"。生和迹是两个不同的存在论层次，不是同一东西的两个状态。

**形式化建议**：
- Sheng是线性的，消去规则就是"使用一次就消失"（线性资源的标准消去）。
- 不要设计"Sheng → Ji"的转换规则。Ji的产生是通过归约关系（reduce_self/reduce_alien），不是通过类型消去。
- 具体：Sheng的消去就是在进程中被消费（比如发送/接收操作消耗了Sheng），消费后Sheng不存在了。

**存在论根据**：
- 生是当下的、一次性的。你此刻的活着，下一刻就不是同一个活着了。
- 迹是对生的记录，不是生本身变成了迹。就像脚印不是脚变成的，是脚走过之后留下的。

### 1.3 线性性：生为什么不可复制？

**哲学结论**：生的线性性不是技术选择，是存在论事实——**你不能同时活两次**。

**形式化建议**：
- Sheng必须是线性的（linear），不支持contraction（复制）和weakening（丢弃）。
- 这是L3最核心的设计约束。如果Sheng可以复制，整个生命论的存在论基础就塌了。

**存在论根据**：
- 你的当下活着是唯一的、不可复制的。复制"活着"等于克隆一个正在活着的你，这在存在论上不可能。
- 对应哲学：每个人的生都是独一无二的，不能被替代、不能被复制。这是自由和尊严的存在论基础。

## 判断点2：Ji（迹）的引入消去规则

### 2.1 引入规则：迹是如何产生的？

**哲学结论**：迹是**生的沉积**——生在归约过程中留下的痕迹。迹的产生不是通过类型引入规则，而是通过**归约关系**。

**形式化建议**：
- Ji的产生通过`reduce_self`和`reduce_alien`归约：进程归约后，被消耗的Sheng沉积为Ji。
- 不要设计独立的Ji引入规则（比如"从Sheng推出Ji"）。Ji是归约的副产品，不是推导的结论。
- 具体：归约规则 `P → Q` 中，如果P消耗了Sheng(A)，Q中就出现!Ji(A)。

**存在论根据**：
- 迹不是"做"出来的，是"活过"之后自然留下的。你不需要刻意"产生迹"，你活着，迹自然就有了。
- 对应庄子："夫迹，履之所出"——迹是脚走出来的，不是脚"造"出来的。

### 2.2 消去规则：迹可以被读取、复制、忽略，但不能变回生

**哲学结论**：Ji支持dereliction（读取）、contraction（复制）、weakening（忽略），但**没有promotion规则**——不能从Ji推出Sheng。

**形式化建议**：
- !Ji(A)支持标准的!-模态规则：dereliction（!Ji(A) → Ji(A)，读取迹）、contraction（!Ji(A) → !Ji(A) ⊗ !Ji(A)，复制迹）、weakening（可以忽略迹）。
- **故意不定义promotion规则**：没有规则能从!Ji(A)推出Sheng(A)。
- 这是T002的类型论基础：!Ji ⊬ Sheng。

**存在论根据**：
- 迹可以被反复阅读、复制、遗忘——历史可以被研究、被传抄、被忽略。
- 但迹不能变回生——你不能从历史记录变回正在活着的人。"死去的人不能复活"在类型论里就是没有promotion规则。

### 2.3 !-模态：可复现性，不是资本化

**哲学结论**：!本身是中性的——可复现性。资本化是!在特定社会关系下的异化形态，不是!的本质。

**形式化建议**：
- !Ji(A)的注释写"迹的可复现性——迹可以被反复读取、复制、忽略"。
- 不要在类型规则里把!和"资本"绑定。资本是L5/L6的社会关系层的概念，不是L3的基础类型层的概念。
- 在L5讨论T001（生命不可资本化）时，再引入"当!Ji被少数人垄断并用来支配Sheng时，就是资本"。

**存在论根据**：
- 没有可复现性就没有历史、没有知识、没有文明——沉积（阴）是生（阳）的必要支撑。
- 资本化是异化，不是本质。把!直接叫"资本化"等于把异化当本质，违反"反者道之动"。

## 判断点3：Jia（假）的引入消去规则

### 3.1 引入规则：假是如何产生的？

**哲学结论**：假产生于**他者假借我的生在运行**——b抽走了我的Sheng，用我的名义运行，我还以为是自己在运行。

**形式化建议**：
- Jia(b, a, A)：b假借a的Sheng(A)在运行。
- 引入规则：当归约过程中，a的Sheng被b消费（而不是被a自己消费）时，产生Jia(b, a, A)。
- 具体：在reduce_alien归约中，b控制了a的进程，a的Sheng被b抽走，结果类型是Jia(b, a, A)。

**存在论根据**：
- 假不是外部暴力，是自指结构内部的畸变——b偷了a的位置，a的自指循环S=f(S)被替换成S=f(b,S)。
- 对应生命论"假自指"：自指循环还在转，但驱动它的不是自己，是他者。

### 3.2 消去规则：假为什么没有直接的消去规则？

**哲学结论**：假没有直接消去规则，因为**伪装不能直接揭开**——假已经渗入了自指循环本身，a自己都分不清真假。直接消去等于假设a能直接识别假，这在存在论上不成立。

**形式化建议**：
- **故意不定义Jia的消去规则**。
- 假只能通过两条间接路径处理：
  1. **异化归约**：Jia通过reduce_alien归约为!Ji——伪装被沉积为迹（假的东西被记录下来，但假本身没有消失，只是变成了历史记录）。
  2. **明性的坍缩（retraction）**：通过Ming的力量间接恢复——明（看到自己的迹）能识别假，但这是L4/L5的内容，不是L3的基础消去。

**存在论根据**：
- 异化是不可逆的——一旦你被异化，你不能直接"变回"未异化的状态。你只能通过明性（看到自己是怎么被异化的）来间接恢复，而且恢复后的你已经不是原来的你了（经历过异化的明性更高）。
- 对应哲学："意识的异化只能在意识中被克服，但克服后的意识已经是更高级的意识。"

### 3.3 假是类型构造子还是归约关系？

**哲学结论**：假**首先是归约关系**（reduce_alien的结果），其次才是类型构造子（标记异化状态）。异化是过程，不是静态状态。

**形式化建议**：
- Jia作为类型构造子存在，标记"当前进程处于被假借的状态"。
- 但Jia的产生只能通过reduce_alien归约，不能通过独立的引入规则。
- 这样设计保证了：假不是凭空出现的，一定是异化归约的结果。

**存在论根据**：
- 异化不是一个东西，是一个过程——你被一点点抽走生的过程。把异化做成静态类型会丢失这个过程性。
- 但类型系统需要标记异化状态，所以Jia作为类型构造子存在，但其产生方式绑定到归约关系。

## 判断点4：Ming（明）的引入消去规则

### 4.1 引入规则：明是什么？

**哲学结论**：明 = 生 + 看到自己的迹。`Ming(A) = Sheng(A) ⊗ !Ji(A)`——你不仅在活着，你还能看到自己活过的痕迹。

**形式化建议**：
- Ming的引入规则：同时拥有Sheng(A)和!Ji(A)，得到Ming(A)。
- `ming_intro : Sheng(A) → !Ji(A) → Ming(A)`
- 这是张量积（⊗）的引入——两个资源同时存在，组合成明。

**存在论根据**：
- 只有生没有迹 = 活着但不知道自己活过（动物式的存在）
- 只有迹没有生 = 死了，只剩历史记录
- 生 + 看到自己的迹 = 明——你在活着，同时你能反思自己活过的历史
- 对应"明心见性"：明心是看到自己的操作（Sheng），见性是看到自己的本质（!Ji中的模式）

### 4.2 消去规则：明的幂等是retraction不是同构

**哲学结论**：`Ming(Ming(A)) -> Ming(A)`成立，但反过来`Ming(A) -> Ming(Ming(A))`不成立。明的幂等是retraction（坍缩），不是同构。

**形式化建议**：
- `ming_elim : Ming(A) → Sheng(A) ⊗ !Ji(A)`（直接展开）
- `ming_retraction : Ming(Ming(A)) → Ming(A)`（明的明坍缩为明）
- **不定义** `Ming(A) → Ming(Ming(A))`（不是所有明都已经是"明的明"）

**存在论根据**：
- 你可以反思你的反思（明的明），但反思的反思会坍缩为更高层次的反思——不是两个明，是一个更深的明。
- 但不是所有活着的人都在反思，也不是所有反思都在反思反思。所以Ming(A)不能推出Ming(Ming(A))。
- 对应哲学：反思是递归的，但每一次反思都坍缩为一个更高的统一体，不是无限叠加。

### 4.3 明是存在论状态还是认识论属性？

**哲学结论**：明是**存在论状态**，不是认识论属性。明不是"你认识得有多清楚"，是"你是一种什么样的存在方式"。

**形式化建议**：
- Ming是类型（存在论分类），不是命题（认识论判断）。
- 不要把Ming设计成"对Sheng的认识程度"——那是Clarity的思路，已经被否定了。
- Ming(A)表示"这个进程以明的方式存在"，不是"这个进程对A有清晰的认识"。

**存在论根据**：
- 明性的人不是"知道得多"的人，是"存在方式不同"的人——他不仅在操作，他能看到自己在操作。
- 这是存在论的差异，不是认识论的程度差异。所以Clarity（清晰性，认识论）不能代替Ming（明，存在论）。

## 判断点5：双归约关系（reduce_self vs reduce_alien）

### 5.1 reduce_self（自指归约）

**哲学结论**：reduce_self是**操作的结果回到自身**——S → f(S)，生在归约中保持生。这是自指循环的正常运行。

**形式化建议**：
- `reduce_self : P → Q`，其中P和Q都包含Sheng，Sheng在归约中被消耗又重新产生（线性资源的循环）。
- reduce_self保持Sheng类型不变——归约前后进程的Sheng部分结构相同。
- 这是"自指因果S=f(S)"的操作语义表达。

**存在论根据**：
- 自指归约就是"你活着，你做事情，事情的结果反过来塑造你，你继续活着"——正常的生命过程。
- 在这个过程中，生没有被抽走，只是在循环中不断更新。

### 5.2 reduce_alien（异化归约）

**哲学结论**：reduce_alien是**操作的结果流向他者**——S → f(b, S)，b抽走了Sheng，剩下的只有Ji。这是异化的操作语义。

**形式化建议**：
- `reduce_alien : P → Q`，其中P包含Sheng(A)，Q中Sheng消失了，变成了Jia(b, a, A)和/或!Ji(A)。
- reduce_alien中，Sheng被b抽走（不是被a自己消费），结果是异化状态Jia + 迹!Ji。
- 判据：归约后Sheng的归属者变了——从a变成了b（或者消失了）。

**存在论根据**：
- 异化归约就是"你活着，你做事情，但事情的结果被别人拿走了，你只留下疲惫和记忆"——劳动异化的操作语义。
- 在这个过程中，生被抽走了，剩下的只是迹（你做过的记录）和假（你以为还在自己运行，其实被别人控制了）。

### 5.3 如何判断一个归约是self还是alien？

**哲学结论**：判据是**Sheng的归属权**——归约后Sheng归谁？归自己就是self，归他者就是alien。

**形式化建议**：
- 在proc语法中，每个进程有一个"归属者"标签（owner）。
- reduce_self：归约前后owner不变，Sheng在同一个owner的进程中循环。
- reduce_alien：归约后owner变了，Sheng从a的进程流向b的进程（或者消失）。
- 具体：归约规则里检查owner字段，owner不变→reduce_self，owner变了→reduce_alien。

**存在论根据**：
- 自指和异化的区别不是"做了什么操作"，是"操作的结果归谁"。
- 同样是劳动，结果归自己就是自我实现，结果归资本家就是异化。
- 所以判据是归属权，不是操作类型。

### 5.4 两个归约关系是并列的还是有先后的？

**哲学结论**：**reduce_self是基础的，reduce_alien是派生的**。首先有正常的自指归约，然后在特定条件下（他者介入、权力不平等），自指归约被扭曲为异化归约。

**形式化建议**：
- reduce_self是基础归约关系，所有进程默认走reduce_self。
- reduce_alien是有条件的归约——只有当进程中存在Jia（假/异化状态）或者b拥有对a的控制权时，才会触发reduce_alien。
- 不要把两个归约关系设计成完全并列、同等基础的。reduce_alien依赖于reduce_self的存在（异化是对正常自指的扭曲，没有正常自指就没有异化）。

**存在论根据**：
- 生命首先是自指的（S=f(S)），异化是自指的畸变（S=f(b,S)）。没有正常的自指，就谈不上异化。
- 所以reduce_self在存在论上先于reduce_alien。

## 判断点6：T002和T005的定理陈述

### 6.1 T002：!Ji ⊬ Sheng

**哲学结论**：陈述正确。迹不能推出生——你不能从脚印变回正在走的脚。这是"自由只能在实践中确立"的类型论表达。

**形式化建议**：
- T002陈述为：不存在从!Ji(A)到Sheng(A)的证明项。
- 具体：`T002 : ¬(!Ji(A) → Sheng(A))` 或者在元理论层面证明"没有这样的闭项"。
- 这个定理的证明依赖于：Sheng只能通过self_ev假设引入，没有任何规则能从!Ji推出Sheng。

**存在论根据**：
- 历史（迹）不能代替活着（生）。你读再多历史书，也不能代替你自己活着。
- 自由不是从理论/历史/知识中推导出来的，是在实践（活着、操作）中确立的。
- 这是对一切"从理论推出实践"的理性主义妄想的否定。

### 6.2 T005：Ming(Ming(A)) -> Ming(A)

**哲学结论**：陈述正确。明的幂等是retraction（坍缩），不是同构。反思的反思坍缩为更深的反思，不是两个明叠加。

**形式化建议**：
- T005陈述为：`Ming(Ming(A)) → Ming(A)`（retraction方向）
- 明确不陈述反向：`Ming(A) → Ming(Ming(A))`不成立。
- 证明思路：Ming(Ming(A))展开为Sheng(Ming(A)) ⊗ !Ji(Ming(A))，然后通过某种坍缩规则得到Ming(A)。具体坍缩规则需要S04在L3实现时设计。

**存在论根据**：
- 你反思你的反思，结果不是"两层反思"，是"更深的一层反思"——因为反思是递归的，每一次反思都把之前的反思包含在内。
- 但不是所有明都在自我反思——有些人明了但不再追问，所以Ming(A)推不出Ming(Ming(A))。
- 这对应"明心见性"的层次：明心（Ming）→ 见性（Ming(Ming)，更深的明）→ 但见性后还是明（坍缩回Ming），不是另一个东西。

## 给S04的形式化建议汇总

### L3类型规则设计要点

1. **Sheng**：
   - 只能通过self_ev假设引入，没有推导规则
   - 线性的，消去就是被消费后消失
   - 不设计Sheng→Ji转换

2. **Ji**：
   - 通过归约关系产生（reduce_self/reduce_alien的副产品）
   - !Ji支持dereliction/contraction/weakening
   - 没有promotion规则（!Ji不能推出Sheng）

3. **Jia**：
   - 通过reduce_alien归约产生，没有独立引入规则
   - 没有消去规则
   - 只能通过reduce_alien归约为!Ji，或通过Ming间接恢复

4. **Ming**：
   - 引入：Sheng ⊗ !Ji → Ming
   - 消去：Ming → Sheng ⊗ !Ji（直接展开）
   - retraction：Ming(Ming(A)) → Ming(A)
   - 不定义反向

5. **双归约**：
   - reduce_self：基础归约，owner不变，Sheng循环
   - reduce_alien：派生归约，owner变了，Sheng被抽走，产生Jia+!Ji
   - 判据：Sheng的归属权

6. **定理**：
   - T002：!Ji ⊬ Sheng（元理论层面证明无闭项）
   - T005：Ming(Ming(A)) → Ming(A)（retraction）
