## 引理1：get_insert_at_lt（最简单，先证这个）

### 引理陈述
```coq
Lemma get_insert_at_lt : forall Gamma T k n T',
  n < k -> get (insert_at k T Gamma) n = Some (Some T') ->
  get Gamma n = Some (Some T').
```

### 证明策略
- 对k归纳（induction k）
- k=0时，n < 0不可能（Nat.nlt_0_r），矛盾
- k=S k'时，分情况讨论Gamma（[]或g::Gamma'）
  - Gamma=[]时，insert_at (S k') T [] = None :: insert_at k' T []
    - n=0时，get返回Some None，与前提Some (Some T')矛盾
    - n=S n'时，用IHk'
  - Gamma=g::Gamma'时，insert_at (S k') T (g::Gamma') = g :: insert_at k' T Gamma'
    - n=0时，get返回Some g，需要证明g=Some T'，从前提直接得到
    - n=S n'时，用IHk'

### DeepSeek调用指令
```
证明以下Coq引理，只证这一个，不要生成其他引理：

Lemma get_insert_at_lt : forall Gamma T k n T',
  n < k -> get (insert_at k T Gamma) n = Some (Some T') ->
  get Gamma n = Some (Some T').

已知定义：
Fixpoint insert_at (k : nat) (T : ty) (Gamma : ctx) : ctx :=
  match k with
  | 0 => Some T :: Gamma
  | S k' => match Gamma with
    | [] => None :: insert_at k' T []
    | g :: Gamma' => g :: insert_at k' T Gamma'
    end
  end.

策略提示：对k归纳。k=0时n<0矛盾。k=S k'时分Gamma=[]和g::Gamma'两种情况，每种再分n=0和n=S n'。

只输出Proof. ... Qed. 块。
```

## 引理2：get_insert_at_gt

### 引理陈述
```coq
Lemma get_insert_at_gt : forall Gamma T k n T',
  n > k -> get (insert_at k T Gamma) n = Some (Some T') ->
  get Gamma (n - 1) = Some (Some T').
```

### 证明策略
- 对k归纳
- k=0时，insert_at 0 T Gamma = Some T :: Gamma
  - n > 0，所以n=S n'
  - get (Some T :: Gamma) (S n') = get Gamma n'
  - 需要证明get Gamma n' = get Gamma (S n' - 1)，而S n' - 1 = n'，reflexivity
- k=S k'时，分Gamma情况，类似引理1

### DeepSeek调用指令
```
证明以下Coq引理，只证这一个，不要生成其他引理：

Lemma get_insert_at_gt : forall Gamma T k n T',
  n > k -> get (insert_at k T Gamma) n = Some (Some T') ->
  get Gamma (n - 1) = Some (Some T').

已知定义同get_insert_at_lt。

策略提示：对k归纳。k=0时n>0所以n=S n'，get (Some T::Gamma) (S n') = get Gamma n'，而n-1=n'。k=S k'时分Gamma=[]和g::Gamma'。

注意：n-1在Coq中是Nat.sub，S n' - 1 = n'可以用simpl或Nat.sub_succ_r。

只输出Proof. ... Qed. 块。
```

## 引理3：name_subst_general

### 引理陈述
```coq
Lemma name_subst_general : forall Gamma T k m n,
  typed (insert_at k T Gamma) (PVar n) ->
  get Gamma m = Some (Some T) ->
  n <> k ->
  typed Gamma (PVar (subst_name m k n)).
```

### 证明策略
- PVar的typed规则是：typed Gamma (PVar n) ↔ get Gamma n = Some (Some T)
- 前提typed (insert_at k T Gamma) (PVar n)意味着get (insert_at k T Gamma) n = Some (Some Tn)
- 分n < k和n > k两种情况（n ≠ k）
  - n < k时，用get_insert_at_lt得get Gamma n = Some (Some Tn)
    - subst_name m k n在n < k时返回n（因为n≠k且n<k，不替换）
    - 所以typed Gamma (PVar n)
  - n > k时，用get_insert_at_gt得get Gamma (n-1) = Some (Some Tn)
    - subst_name m k n在n > k时返回n-1
    - 所以typed Gamma (PVar (n-1))

### DeepSeek调用指令
```
证明以下Coq引理，只证这一个，不要生成其他引理：

Lemma name_subst_general : forall Gamma T k m n,
  typed (insert_at k T Gamma) (PVar n) ->
  get Gamma m = Some (Some T) ->
  n <> k ->
  typed Gamma (PVar (subst_name m k n)).

已知：
- PVar的typed规则：typed Gamma (PVar n) ↔ get Gamma n = Some (Some T)（用T_Var规则）
- get_insert_at_lt和get_insert_at_gt已证明
- subst_name m k n的定义：n=k时返回m，n<k时返回n，n>k时返回n-1

策略提示：
1. 前提H1: typed (insert_at k T Gamma) (PVar n)，用inversion H1得到get (insert_at k T Gamma) n = Some (Some Tn)
2. 分n < k和n > k（因为n ≠ k）
3. n < k：用get_insert_at_lt得get Gamma n = Some (Some Tn)，subst_name返回n，apply T_Var
4. n > k：用get_insert_at_gt得get Gamma (n-1) = Some (Some Tn)，subst_name返回n-1，apply T_Var

注意：可能需要先证明subst_name在n<k时返回n、n>k时返回n-1（如果subst_name定义不是直接这样，需要simp或case分析）。

只输出Proof. ... Qed. 块。
```

## 引理4：substitution_general（最核心，最后证）

### 引理陈述
```coq
Lemma substitution_general : forall Gamma T k m Q,
  typed (insert_at k T Gamma) Q ->
  get Gamma m = Some (Some T) ->
  typed Gamma (subst_var m k Q).
```

### 证明策略
- 对Q的结构归纳（induction Q）
- 每个case：
  - PVar n：用name_subst_general
  - PUnit/PSkip等无变量的：simpl subst_var，直接用原typed
  - PIn/PRes（绑定器）：subst_var进入绑定器时k变成S k，m变成S m，Gamma变成None::Gamma
    - 关键：insert_at (S k) T (None :: Gamma) = None :: insert_at k T Gamma（定义性）
    - 所以typed (None :: insert_at k T Gamma) body → 用IH得typed (None :: Gamma) (subst_var (S m) (S k) body)
    - 而subst_var m k (PIn x body) = PIn x (subst_var (S m) (S k) body)
    - apply T_In
  - PPar/PComp等组合：用IH分别证子项，再组合

### DeepSeek调用指令
```
证明以下Coq引理，只证这一个，不要生成其他引理：

Lemma substitution_general : forall Gamma T k m Q,
  typed (insert_at k T Gamma) Q ->
  get Gamma m = Some (Some T) ->
  typed Gamma (subst_var m k Q).

已知：
- name_subst_general已证明
- subst_var m k Q的定义：对Q结构递归，PVar n时调用subst_name，PIn/PRes时k→S k, m→S m
- insert_at (S k) T (None :: Gamma) = None :: insert_at k T Gamma（定义性等式，simpl可证）

策略提示：
1. intros后对Q归纳（induction Q）
2. PVar case：直接apply name_subst_general
3. 无变量的constructor（PUnit/PSkip/PZero等）：simpl subst_var，原typed直接用
4. PIn x body case：
   - inversion H得到typed (None :: insert_at k T Gamma) body
   - 注意insert_at (S k) T (None :: Gamma) = None :: insert_at k T Gamma
   - 但这里Gamma是insert_at k T Gamma，所以None :: insert_at k T Gamma = insert_at (S k) T (None :: Gamma)
   - 用IH with (Gamma := None :: Gamma) (k := S k) (m := S m)
   - 前提get (None :: Gamma) (S m) = Some (Some T)，从get Gamma m = Some (Some T)可得
   - 得到typed (None :: Gamma) (subst_var (S m) (S k) body)
   - apply T_In
5. PRes case类似PIn
6. PPar/PComp/POut等组合case：用IH分别证子项，再apply对应构造子

注意：如果某个case的IH前提不满足（比如get Gamma m的位置变了），先证明get (None::Gamma) (S m) = get Gamma m这样的引理（可以直接simpl证明，不需要新Lemma）。

只输出Proof. ... Qed. 块。如果某个case卡住，告诉我卡在哪一步和错误信息。
```

## 执行顺序

1. 先证get_insert_at_lt（最简单，建立信心）
2. 再证get_insert_at_gt（类似1）
3. 再证name_subst_general（用1和2）
4. 最后证substitution_general（用3，最核心）
5. 4个都证完后，substitution_lemma自动成立（已经写好了）
6. 最后证congruence_preserves_typing（用substitution_lemma）

## 每个引理的验证步骤

1. 把DeepSeek返回的Proof块粘贴到Layer2.v对应位置
2. 运行coqc编译
3. 如果编译通过，commit，然后下一个
4. 如果编译失败，把错误信息原样回喂给DeepSeek（不要自己改），让它修正
5. 如果DeepSeek修正3次还不过，把错误信息和当前证明状态写到coq/obstacles/，通知S01
