### 2.8 self_ev定义 ⚠️ 需要讨论

**S01要求**：self_ev是被抛入的感的假设，不是定理。

**S04实现**：
```coq
Definition self_ev (A : ty) : Prop :=
  forall Gamma, typed Gamma (PVar 0) -> exists Gamma', get Gamma' 0 = Some (Some (TSheng A)).
```

**判定**：这个定义的哲学含义需要讨论。它说的是"如果变量0是良类型的，那么存在一个上下文Gamma'，其中变量0的类型是TSheng A"。这更像是一个"类型可及性"命题，而不是"被抛入的感"。

S01的原意是：self_ev是一个公理/假设——Sheng(A)是被给予的，不需要证明。S04的定义把它变成了一个可以证明的命题（从typed关系推导），这可能偏离了"感是被抛入的、第一性的"这个哲学含义。

**建议**：self_ev应该是一个Parameter/Axiom，不是Definition。或者定义为一个假设标记，不参与证明。这个需要S01和S04进一步讨论。
