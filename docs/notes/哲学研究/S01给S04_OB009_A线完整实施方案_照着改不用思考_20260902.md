## 第一步：加not_used_channel_at谓词（Layer2.v，在fv_at定义后）

在Layer2.v第25行（fv定义后）添加：

```coq
(* ---------------------------------------------------------------------
   2.5 not_used_channel_at：进程中没有use消耗位置x（OB-009 A线前提）
   --------------------------------------------------------------------- *)
Fixpoint not_used_channel_at (P : proc) (x : nat) : bool :=
  match P with
  | PZero => true
  | PTau Q => not_used_channel_at Q x
  | PVar n => true
  | POut y z Q => negb (Nat.eqb y x) && not_used_channel_at Q x
  | PIn y Q => negb (Nat.eqb y x) && not_used_channel_at Q x
  | PRes Q => not_used_channel_at Q x
  | PRep Q => not_used_channel_at Q x
  | PPar Q R => not_used_channel_at Q x && not_used_channel_at R x
  end.
```

**注意**：POut只检查y（输出通道位置），不检查z（发送值位置），因为z是值不是通道，不消耗操作权。PIn检查y（输入通道位置）。

## 第三步：修改证明（每个case加前提处理）

证明开头改为：
```coq
Proof.
  intros Gamma T k m Q.
  generalize dependent Gamma.
  generalize dependent T.
  generalize dependent k.
  generalize dependent m.
  induction Q; intros m k T Gamma Ht Hget Hnotused.
```

### 各case的处理：

**PVar**：Hnotused = true（PVar不消耗通道），直接用原证明。

**PZero**：Hnotused = true，直接用原证明。

**PTau**：Hnotused = not_used_channel_at Q m = true，传给归纳假设。

**POut y z Q**：
- Hnotused = negb (y =? m) && not_used_channel_at Q m = true
- 分解得：y ≠ m（negb (y=?m)=true）和not_used_channel_at Q m = true
- y ≠ m正好排除了n=m的情况！所以use消耗位置y不等于代换目标m，原证明继续
- body的归纳假设传入not_used_channel_at Q m = true

**PIn y Q**：
- Hnotused = negb (y =? m) && not_used_channel_at Q (S m) = true
  （注意：PIn进入绑定器，body中的位置后移一位，所以检查的是S m）
- 分解得：y ≠ m和not_used_channel_at Q (S m) = true
- y ≠ m排除了n=m的情况！原证明继续
- body的归纳假设传入not_used_channel_at Q (S m) = true

**PRes Q**：
- Hnotused = not_used_channel_at Q (S m) = true
- 传给归纳假设（注意m变成S m，因为PRes进入绑定器）

**PRep Q**：
- Hnotused = not_used_channel_at Q m = true
- 传给归纳假设

**PPar Q R**：
- Hnotused = not_used_channel_at Q m && not_used_channel_at R m = true
- 分解得两个子前提，分别传给两个归纳假设

## 第四步：关键——PIn/POut的n=m情况被前提自动排除

这是A线的核心：当PIn y Q且y=m时，not_used_channel_at (PIn y Q) m = negb (m=?m) && ... = false && ... = false。

所以前提Hnotused = true不满足，这个case**不会被调用**。反例PIn m (PVar (S k))被前提排除了。

**不需要在证明中特殊处理n=m**，前提自动排除。

## 第五步：修改substitution_lemma（第640行）

substitution_lemma是substitution_general的推论，也需要加前提传递。检查它的陈述，如果它调用substitution_general，需要把not_used_channel_at前提传进去。

如果substitution_lemma的陈述是：
```coq
Theorem substitution_lemma : forall Gamma T y Q,
  typed (T :: Gamma) Q ->
  typed Gamma (comm_subst y Q).
```

那它需要加前提`not_used_channel_at Q 0 = true`（因为comm_subst y Q = subst_var y 0 Q，代换目标是0）。

或者，如果substitution_lemma只用于特定情况（如y是新变量），可以在调用处证明前提。

4. **不要试图证明n=m的情况**：前提已经排除了，直接用y≠m的事实。
