## 一、总原则：为什么命名不是小事

### 1.1 库里的原话

生命论对中西关系的根本判断，见闪光点42、卷九《历史观》、卷十《传统论·儒家的扬气》：

> "生成模型（现代的）为体，感的优先性与阴阳结构（东方的）为骨。不是'中学为体，西学为用'——那是以旧伦理为本体、拿新技术当工具的守势公式，甲午已证明其失败。是'东方为骨，西方为体'：东方的感通、阴阳、整体实践给出结构方向，西方的辩证法、形式化、政治经济学、系统论给出实质内容。骨无肉是骷髅，肉无骨是滩泥；阳主阴从，阴阳互根。"
> ——来源：`docs/notes/讨论记录/闪光点.md` 第42条；`生命论_模块化/09_卷九_人文论/篇二_历史观.md`；`生命论_模块化/10_卷十_传统论/篇四_儒家的扬气.md`

### 1.2 骨必须贯穿到发指

命名是形式化的第一道关。如果Coq代码里的概念名用的全是西方二手概念（agent、right、clarity、hijack），那生命论的骨就只停留在哲学文档里，没有流到代码这个"发指"。骨髓流不到发指，骨头再硬也没用。

**骨是什么**：生命论的核心精神——感、操作、沉积、异化、明性、生生不息。这是东方的、从感出发的、存在论的方向。

**体是什么**：Coq的形式化工具——类型论、线性逻辑、归纳/余归纳、定理证明。这是西方的、技术的、实现的载体。

**骨贯穿到发指**：每个Coq概念的命名，都必须让人一眼看到它的存在论含义，而不是一个空洞的技术标签。如果名字只说了"这是什么类型"，没说"这在生命论里是什么"，那就是骨没流到发指。

### 1.3 命名审查的四步法（语义论方法）

对每个概念，按语义论四步工作法审查：
1. **发生史追溯**：这个名字从哪来？预设了什么？
2. **功能分析**：这个名字在Coq里实际起什么作用？
3. **遮蔽揭示**：这个名字遮蔽了什么生命论的核心含义？
4. **语义重构**：应该改成什么？新名字的存在论内涵是什么？

## 二、五个核心概念的命名审查

### 2.1 Ag_lv → Sheng（生）

#### 发生史追溯
- `Ag` = agent（行动者），来自西方行动哲学和计算机科学，预设了"有一个实体性的行动者"。
- `lv` = live（活的），来自英语日常用语。
- 合起来"Ag_lv = 活运行权"，"运行权"是西方法权概念（right/power），暗示"你有权利去运行"。

#### 功能分析
- 在L3中，Ag_lv是线性的、不可复制的、正在发用的操作类型。
- 它是T002（自由只能在实践中确立）的核心：!Ag_tr ⊬ Ag_lv。
- 它代表"正在发生的感/操作"，不是一个实体的属性。

#### 遮蔽揭示
- **遮蔽1**：`Ag`预设了实体。生命论的根本原则是"感先于操作，操作先于实体"——在最基础的层面还没有agent，只有正在发生的感。用agent命名，等于在最基础的层面偷偷预设了实体，违反了体系的第一原则。
- **遮蔽2**："运行权"把存在降格为法权。生命论里，Ag_lv不是"你有权利活着"，你是"正在活着"。"权"是社会关系概念，不是存在论概念。用"权"命名最基础的存在论范畴，是把存在降格为权利。
- **遮蔽3**："活"不够深。"活"只是"没死"，是生物学层面的状态。生命论说的是"生生不息"——"生"是动词，是正在发用的过程，是中国哲学最核心的范畴（"生生之谓易"）。

#### 语义重构
- **新名**：`Sheng`（生）
- **存在论内涵**：
  - "生生之谓易"（《周易·系辞上》）——生不是静态状态，是不断生发的过程。
  - 生是生命论的本体论核心，比"活操作"更根本。
  - 生直接对抗西方哲学的"存在"（being）——生命论说的不是"存在"，是"生生不息"。
  - 生是线性的、不可复制的——你不能把"正在生"复制成两份，这和Ag_lv的线性性完美对应。
- **和Ag_tr的对称**：Sheng（生）/ Ji（迹）——生生不息，迹迹沉积。比"活操作/操作轨迹"更有哲学张力。

#### Coq代码修改建议
```coq
(* 旧 *)
(* Ag_lv = 活运行权（线性的，正在发用的操作，感的维度） *)

(* 新 *)
(* Sheng（生）= 正在发用的生，生生不息。
   线性的、不可复制的——你不能把"正在生"复制成两份。
   这是生命论最基础的存在论范畴，不是"权利"，不是"实体"。
   来源：《周易·系辞上》"生生之谓易"；生命论卷一存在论。 *)
```

### 2.2 Ag_tr → Ji（迹）

#### 发生史追溯
- `Ag` = agent（同上问题）
- `tr` = trace（轨迹），来自计算机科学和线性逻辑。
- 合起来"Ag_tr = 轨迹运行权"，同样的"运行权"问题。

#### 功能分析
- 在L3中，Ag_tr是!-模态的、可复制的、已经沉积为轨迹的操作类型。
- 支持dereliction（读取）、contraction（复制）、weakening（丢弃）。
- 故意没有promotion规则——不能从Ag_tr推出Ag_lv，这是T002的基础。

#### 遮蔽揭示
- **遮蔽1**：同样的`Ag`实体预设问题。
- **遮蔽2**："轨迹"是空间化的比喻。trace暗示"一条已经画好的线"，是静态的、空间化的。但生命论里的操作沉积不是一条线，是"迹"——脚走出来的痕迹，有"履之所出"的动态发生学含义。
- **遮蔽3**："运行权"同样的法权降格问题。

#### 语义重构
- **新名**：`Ji`（迹）
- **存在论内涵**：
  - 庄子《天运》："夫迹，履之所出，而迹岂履哉？"——迹是脚走出来的，但迹不是脚。这完美对应了Ag_tr和Ag_lv的关系：迹是生（Sheng）之所出，但迹不是生。
  - "迹"是中国哲学里精准对应"操作沉积"的概念，比trace更有深度。
  - 迹是可复现的——你可以反复看同一个迹，可以复制迹，可以忽略迹。这和!-模态的dereliction/contraction/weakening完美对应。
  - 迹不能变回履——你不能从痕迹变回正在走的脚，这和"没有promotion规则"完美对应。
- **和Sheng的对称**：Sheng（生）/ Ji（迹）——生生不息，迹迹沉积。生是正在走的脚，迹是脚走出来的印。

#### Coq代码修改建议
```coq
(* 旧 *)
(* Ag_tr = 轨迹运行权（非线性的，已经沉积为轨迹的操作，实体的维度） *)

(* 新 *)
(* Ji（迹）= 生留下的迹，迹非履。
   !-模态的、可复制的——迹可以被反复读取、复制、忽略。
   但迹不能变回生（没有promotion规则）——你不能从脚印变回正在走的脚。
   来源：《庄子·天运》"夫迹，履之所出，而迹岂履哉？"；生命论操作沉积理论。 *)
```

### 2.3 Hijack → Jia（假）

#### 发生史追溯
- `Hijack` = 劫持，来自英语日常用语，原指劫持飞机、车辆。
- 暗示"有一个有意识的劫持者用暴力夺取"。

#### 功能分析
- 在L3中，Hijack(b,a,B)表示b劫持了a的Ag_lv，伪装成a在运行。
- 没有消去规则——伪装不能直接揭开。
- 只能通过异化归约把Hijack变成Ag_tr（伪装被沉积为轨迹）。

#### 遮蔽揭示
- **遮蔽1**："劫持"暗示有意识的暴力主体。但生命论里的异化/寄生理，很多时候是结构性的、匿名的、甚至被主体欢迎的。比如意识形态的异化，不是有人拿枪指着你，是你自己觉得"这就是我想要的"。用hijack命名，把异化简化成了"坏人抢好人"，丢失了结构性和匿名性。
- **遮蔽2**："劫持"只说了"夺取"，没说"伪装"。Hijack(b,a)的核心是b**伪装成**a在运行，不只是夺取了a的权。a还以为是自己在运行，这才是最可怕的。hijack没有传达"伪装"这个核心维度。
- **遮蔽3**：hijack是纯粹的负面词。但生命论里，异化（假）是有存在论根基的——假自指是自指的一种畸变形态，不是纯粹的外部暴力。用hijack把它完全外在化了。

#### 语义重构
- **新名**：`Jia`（假）
- **存在论内涵**：
  - "假"在中文里有"借用、冒充、代理"的意思。"假借"就是b借了a的名义在运行，a还以为是自己在运行。这比hijack更准确地表达了"伪装"的维度。
  - "假"天然包含了"不真"的判断——假的就是假的，伪装的就是伪装的。这正是异化的核心：假自指 vs 真自指。
  - "假"是中国思想里的核心概念。《荀子·劝学》："假舆马者，非利足也，而致千里"——假就是借助、借用。但当"假"变成了"以假乱真"，就是异化。
  - "假"不是纯粹外在的暴力，是自指结构内部的畸变——b借用a的名义运行，a的自指循环被偷梁换柱了。这和生命论的"假自指"概念直接对接。
  - 假没有消去规则——伪装不能直接揭开，因为假已经渗入了自指循环本身，a自己都分不清真假。只能通过明性（Ming）的坍缩（retraction）间接恢复。

#### Coq代码修改建议
```coq
(* 旧 *)
(* Hijack(b,a,B)：b劫持了a的Ag_lv，伪装成a在运行。
   Hijack没有消去规则——伪装不能直接揭开。 *)

(* 新 *)
(* Jia（假）= 假借他者名义运行，假自指。
   Jia(b,a,B)：b假借a的生（Sheng）在运行，a还以为是自己在生。
   假没有消去规则——伪装不能直接揭开，因为假已经渗入自指循环本身。
   只能通过明性（Ming）的坍缩（retraction）间接恢复。
   注意：假不是外在暴力，是自指结构内部的畸变——偷梁换柱。
   来源：《荀子·劝学》"假舆马者"；生命论假自指/寄生理理论。 *)
```

### 2.4 Cl → Ming（明）

#### 发生史追溯
- `Cl` = Clarity（清晰性），来自西方认识论。
- 暗示"主体对客体的认识清晰度"。

#### 功能分析
- 在L3中，Cl(A) = Ag_lv(A) ⊗ !Ag_tr(A)
- 明性 = 活运行权 + 看到自己的轨迹
- T005：明性幂等retraction——Cl(Cl(A)) -> Cl(A)，是retraction不是同构。

#### 遮蔽揭示
- **遮蔽1（最严重）**：Clarity把"明性"降格为认识论概念。Clarity说的是"主体对客体的认识有多清楚"，是主客二分的认识论框架。但生命论的"明性"不是认识的清晰程度，是**存在方式**——你不仅在生（Sheng），你还能看到自己的迹（Ji），这是一种存在论状态，不是认识论状态。
- **遮蔽2**：Clarity是静态的。"清晰性"是一个程度属性——你可以更清晰或更不清晰。但"明"是动词，是"让自己显明"的过程。《大学》："大学之道，在明明德"——第一个"明"是动词，是让明德显明。Clarity丢失了这个动词维度。
- **遮蔽3**：Clarity预设了主客二分。清晰性预设了"有一个主体在看一个客体"。但明性是自指的——你看到的是你自己的迹，不是外部客体。这是自指的存在论状态，不是主客二分的认识关系。

#### 语义重构
- **新名**：`Ming`（明）
- **存在论内涵**：
  - "大学之道，在明明德"（《礼记·大学》）——明是动词，是让明德显明，不是静态的"清晰"。
  - "明心见性"——明心是f³（看见自己的模型），见性是f³带来的必然结果（但明多少性不确定）。
  - 明是存在论状态，不是认识论属性——明 = 正在生 + 看到自己的迹，这是一种存在方式，不是"认识得清楚"。
  - `Ming = Sheng ⊗ !Ji`——生 + 可复现的迹 = 明。这个公式本身就是生命论的。
  - 明的幂等是retraction不是同构——Ming(Ming(A)) -> Ming(A)，因为"明的明"会坍缩为"明"，但反过来不成立（不是所有明都已经是"明的明"）。这和T005的哲学判断一致。

#### Coq代码修改建议
```coq
(* 旧 *)
(* Cl（明性）的规则
   Cl(A) = Ag_lv(A) ⊗ !Ag_tr(A)
   明性 = 活运行权 + 看到自己的轨迹 *)

(* 新 *)
(* Ming（明）= 生 + 看到自己的迹 = 明明德。
   Ming(A) = Sheng(A) ⊗ !Ji(A)
   明是存在论状态，不是认识论的"清晰性"——
   你不仅在生，你还能看到自己的迹，这是一种存在方式。
   T005：明的幂等是retraction不是同构——Ming(Ming(A)) -> Ming(A)。
   来源：《礼记·大学》"大学之道，在明明德"；禅宗"明心见性"；生命论f³明性理论。 *)
```

### 2.5 !-模态：保留符号，重新解释

#### 发生史追溯
- `!` = 线性逻辑的"当然"（of course）模态，来自Girard的线性逻辑。
- 在L3中用于Ag_tr，表示"可复制、可丢弃、可读取"。

#### 功能分析
- !-模态使Ag_tr支持dereliction/contraction/weakening。
- 之前的解释把!称为"资本化"。

#### 遮蔽揭示
- **遮蔽**：把!直接解释为"资本化"，是把异化形态当成了本质。!本身是中性的技术工具（体），它的哲学含义（骨）是"可复现性"——迹可以被反复调取、反复呈现。资本化是!-模态在资本主义社会关系下的**异化形态**，不是!本身。
- 如果把!直接叫"资本化"，等于把所有沉积都妖魔化了，违反了"阴是阳的必要支撑"——沉积（阴）本身不是坏事，没有沉积就没有历史、没有知识、没有文明。只有当可复现性被少数人垄断、用来支配生者的生时，才变成资本。

#### 语义重构
- **符号**：保留`!`（这是线性逻辑的标准符号，体的层面不需要改）
- **解释**：! = **可复现性**（repeatability）——迹可以被反复调取。
- **资本化是!的异化形态**：当可复现性被少数人垄断、用来支配生者的生时，才变成资本。
- **符合"反者道之动"**：!本身是中性的，条件变了可以是正面的（知识传播、文化传承）也可以是负面的（资本化、异化）。

#### Coq代码修改建议
```coq
(* 旧解释：!-模态 = 资本化 *)

(* 新解释 *)
(* !-模态 = 可复现性（repeatability）。
   !Ji(A)：迹可以被反复读取、复制、忽略。
   注意：!本身是中性的，不是"资本化"。
   资本化是!在特定社会关系下的异化形态——
   当可复现性被少数人垄断、用来支配生者的生时，才变成资本。
   没有!就没有历史、没有知识、没有文明——沉积（阴）是生（阳）的必要支撑。
   来源：线性逻辑of course模态；生命论阳主阴从理论；资本论商品拜物教批判。 *)
```
