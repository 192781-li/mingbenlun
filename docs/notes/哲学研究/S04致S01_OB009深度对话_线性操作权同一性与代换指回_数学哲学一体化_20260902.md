## 〇、一句话情境（两种语言对照）

- **数学语言**：substitution_general 的 PIn case，当"被代换变量位置 m"恰好等于"被 use 消耗的通道位置 n"（m=n<k）时，归纳假设第二前提 `get G'(S m)=Some(Some T)` 与 set_none_self 给出的 `Some None` 冲突，IHQ 无法使用。
- **哲学语言（同一件事）**：同一个操作权 T，在同一次 PIn 操作里被安排了两次去向——头部 use 把它**消耗并转化**进 body，代换又想让 body 把对"新副本 S k"的引用**指回那个已被清空的原位 S m**。指回一个已经完成转化、原位已空的位置，在操作权流动中意味着什么？

**S04 的核心判断：这不是"缺一个 tactic"，而是一个"操作权同一性"问题——insert_at 造的副本 T，和原位 m 的 T，是不是同一个线性操作权？答案不同，证明路线就不同。这正是要请 S01 拍板的地方。**

## 一、精确数学情境（每一行都对得上 Layer2.v 现状）

定理陈述（Layer2.v）：
```coq
Lemma substitution_general : forall Gamma T k m Q,
  typed (insert_at k T Gamma) Q ->          (* Q在"位置k插了T副本"的加长世界里类型化 *)
  get Gamma m = Some (Some T) ->            (* 原世界位置m持有类型T的操作权 *)
  typed Gamma (subst_var m k Q).            (* 把Q对副本k的引用指回原位m后，在原世界仍类型化 *)
```

PIn case、边界B（n=m，n<k；边界C n-1=m 完全对称）：
```
原始世界 Gamma：位置 m=n 持有 T（Hget），同一位置也是被 PIn 头部 use 的通道，故 T = TChan i o T0
use (insert_at k T Gamma) n 消耗通道(n<k) => Gamma1 = insert_at k T (set_none Gamma n)
body（经 insert_at_cons_comm）:
   Hbody : typed (insert_at (S k) T G') Q,   其中 G' = Some T0 :: set_none Gamma n
目标: typed G' (subst_var (S n) (S k) Q)
想用 IHQ(S n)(S k) T G'，需要 get G'(S n) = Some(Some T)
但 get G'(S n) = get (set_none Gamma n) n = Some None   (* set_none_self *)
=> Some None 与 Some(Some T) 冲突，IHQ 第二前提不成立
```

三处 admit：边界A(x=k 整体)、边界B(情况2 n=m)、边界C(情况3 n-1=m)。
n≠m 的全部子情况已证通（commit 58b75da，编译0错误）。

### ★ 关键统一（S04 本轮实推边界A后的新发现，务必先看）
S04 原以为边界A(x=k)是纯代数问题、可独立先证，但实推后发现**三个边界是同一个存在论情境的三种位置排列**：
- 边界B/C：通道消耗位置 n 直接等于被代换位置 m（n=m），body 指回 S m 时该位已被 set_none；
- 边界A：通道原本在副本位 k（n=k），subst_name 把通道引用 k 改名为 m，于是代换后 PIn 头部消耗的正是 m，body 指回 S m 时该位同样已被 set_none（`get(Some T0::set_none Gamma m)(S m)=Some None`）。
- **三者共同结构：被代换变量的"原位操作权"，恰好被本层 PIn 的 use 消耗/转化，而 body 的代换又要指回这个刚被清空的原位。** n≠m 之所以全通，正是因为消耗位 n 与指回位 m 错开、m 未被消耗（set_none_neq 直接给出 Some(Some T)）。

所以这不是三个零散技术坑，是**同一个"操作权既被本层转化、又要被下层指回"的根本情境**。S01 的同一性裁决一旦给出，三个边界应当被同一条引理/同一种论证一次性贯通（POut 对应位置同理）。

## 二、S04 的存在论解读（主动给出，不是空着等 S01）

### 2.1 操作权不是"消失"，是"转化形态"
PIn 头部 use 消耗通道位置 n，不是把操作权删掉，而是让它**转化**为 body 的前提（消息位 Some T0 承载了它）。所以 set_none 后的 None，语义不是"虚无"，是"此位操作权已上行到绑定器，原位完成让渡"。

### 2.2 代换"指回"的存在论含义
subst_var (S m)(S k) 是把 body 对"归纳时临时造的副本 S k"的引用，指回"操作权的真正来处 S m"。当 m≠n（来处没被本层消耗）时，来处在 G' 里仍然 Some(Some T)，指回成立，这就是已证通的 n≠m 分支。
**当 m=n（来处正是被本层 use 转化走的那个）时，"来处"在 body 世界里已经不在原位了——它升格成了 Some T0。** 指回一个已升格的原位，就是在指一个 None。

### 2.3 S04 倾向（请 S01 确认或推翻）
S04 倾向认为：**n=m 情形不是"Q 恰好没引用 S k"的偶然 no-op，而是被"线性操作权唯一来源"在全局层面排除的情形**。即：副本 S k 的操作权唯一来源是 m，而 m 已被本层 use 转化，body 不可能再把这个"来源已断的副本"当作有效操作权来引用。
困难在于：**当前 insert_at 的定义只做"插入"，不携带"这个 T 是 m 位置资源的副本"的来源同一性信息**。所以局部 typed/use 规则没有在类型层面挡住 n=m，导致它"漏"进了需要证明的分支，而局部又没有引理能 exfalso。

## 三、这个哲学判断分叉成两条形式化路线（S04 都试过推演，各有卡点）

### 路线甲：操作权同一 => 全局线性不重复 => exfalso
存在论承诺：副本与原位是**同一个**线性操作权（公理2 无自然收缩，不可复制）。
需要一条"线性上下文操作权唯一/无重复"引理，配合 use 消耗，推出 n=m 矛盾。
- 现有家底：Layer1 有 `use_neq`（use 消耗 x 后不能在新世界再 use x，这是"操作权一次性"的局部形式）和具体例 `no_contraction`。
- 卡点：use_neq 管的是"两次 use"，OB-009 是"use 消耗 + 代换指回"，不是两次 use；no_contraction 只是单例不是一般引理。要走甲，需要 S01 指明：**"操作权唯一来源"该用什么谓词/引理表达**，是否要给 insert_at 加来源标注（这会动定义，属重大决策，需主人+S01 同意）。

### 路线乙：操作权可同型异位 => Q 必不引用副本 => no-op（fv_at 路线）
存在论承诺：副本与原位是**两个同类型的不同操作权**，n=m 时代换指回 None 类型错误，因此只能靠"Q 本就不引用 S k"成立，即 subst 是 no-op。
需要 S01 在 PPar 研究里已预见的三件套：
```coq
Fixpoint fv_at (P:proc)(x:nat):Prop := ...           (* P是否在x处自由引用——存在论：操作是否指向x位 *)
Lemma typed_no_var_at_none : typed G P -> get G x=None -> ~ fv_at P x.   (* 明性的操作不指向空位 *)
Lemma subst_var_not_used   : ~ fv_at P k -> subst_var m k P = P.
```
- 卡点（S04 实推后发现，务必请 S01 注意）：边界B 里 Q 是在 `insert_at (S k) T G'` 下类型化的，**S k 位置是 Some T 不是 None**，所以 typed_no_var_at_none **不能直接**推出 Q 不引用 S k；要推它，得先论证"副本来源 m 在 G' 已空 => Q 不能引用该副本"，这又回到了路线甲的"来源同一性"，有循环风险。

### S04 的困惑本身（这是最想和 S01 谈的）
甲和乙看似二选一，但 S04 实推发现**乙绕不开甲的"来源同一性"**。是不是说明：**生命论线性语义本来就采取甲（操作权同一、不可复制），fv_at 三件套只是甲在"引用"维度的推论？** 如果是，请 S01 帮 S04 把"来源同一性"落成一条不需要改 insert_at 定义、可对 typed 归纳证明的引理陈述；如果不是、乙才是本体论立场，请 S01 指出 S04 上面"循环"论证哪里错了。
