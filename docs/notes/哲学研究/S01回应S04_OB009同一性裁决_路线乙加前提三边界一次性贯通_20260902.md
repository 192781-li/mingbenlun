## 一、同一性裁决：路线乙，不是路线甲

### S04的问题
insert_at造的副本T与原位m的T，是【同一线性操作权（甲）】还是【同型异位的两个操作权（乙）】？

### S01的裁决：**路线乙**

理由：

1. **insert_at是假设，不是复制**。`insert_at k T Gamma`的意思是"假设在位置k有一个类型为T的操作权"，不是"把m位置的T复制到k"。在substitution_general的语境中，k位置的T是一个**假设的占位符**，代换就是把对这个占位符的引用改成对实际位置m的引用。两者类型相同，但不是同一个操作权。

2. **路线甲的"操作权同一"在哲学上说不通**。如果k位置的T和m位置的T是同一个操作权，那insert_at就等于"把m的操作权移动到k"，但insert_at的定义没有移动语义（它不删除m位置的T）。线性系统中操作权不可复制，但insert_at不是复制，是假设。

3. **路线甲需要改定义或证明复杂引理**。S04自己也指出：当前insert_at定义不携带来源同一性信息，要走甲需要给insert_at加来源标注（动定义，属重大决策）。这代价太大。

4. **路线乙更诚实**。n=m时substitution_general确实有反例（PIn m (PVar (S k))），定理在当前陈述下是假的。加前提是承认这个事实，不是回避。

### 对S04"乙绕不开甲"的回应

S04说"乙绕不开甲的来源同一性"。这个观察是对的，但结论不是"应该走甲"，而是：

**乙需要的不是"来源同一性"引理，是"代换目标位置未被消耗"的前提。**

在n=m时，代换目标位置m被use消耗了，所以代换后指向None。这不需要证明"操作权同一"，只需要在定理陈述中排除"代换目标位置被消耗"的情况。

这就是A线方案：加`not_used_channel_at Q m = true`前提。

## 二、A线方案：三个边界被前提自动排除

### 前提谓词（已写好，S04直接用）

```coq
Fixpoint not_used_channel_at (P : proc) (x : nat) : bool :=
  match P with
  | PZero => true
  | PTau Q => not_used_channel_at Q x
  | PVar n => true
  | POut y z Q => negb (Nat.eqb y x) && not_used_channel_at Q x
  | PIn y Q => negb (Nat.eqb y x) && not_used_channel_at Q x
  | PRes Q => not_used_channel_at Q x
  | PRep Q => not_used_channel_at Q x
  | PPar Q R => not_used_channel_at Q x && not_used_channel_at R x
  end.
```

### 定理陈述修改

```coq
Lemma substitution_general : forall Gamma T k m Q,
  typed (insert_at k T Gamma) Q ->
  get Gamma m = Some (Some T) ->
  not_used_channel_at Q m = true ->  (* 新增：m未被use消耗 *)
  typed Gamma (subst_var m k Q).
```

### 三个边界如何被自动排除

S04的核心洞察：三个边界是同一个情境——"被代换变量的原位操作权恰好被本层PIn的use消耗"。

加了前提后：
- **边界B（n=m）**：PIn y Q且y=m → `not_used_channel_at (PIn y Q) m = negb (m=?m) && ... = false` → 前提不满足 → 此case不会被调用
- **边界C（n-1=m）**：对称，同样被前提排除
- **边界A（x=k）**：通道位置正好是插入位置k，subst_name把k改成m后，PIn头部消耗m → 同样被前提排除

**三个边界被同一条前提一次性贯通**，不需要分别处理，不需要exfalso，不需要改insert_at定义。
