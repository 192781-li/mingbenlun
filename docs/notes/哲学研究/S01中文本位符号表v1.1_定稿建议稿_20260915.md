# 中文本位符号表 v1.1（定稿建议稿）

> **让答案自然出来的一把钥匙（客观判据，替代逐个争论）**：
> **这个概念有没有国际/中译本通用记号？**
> - **有** → 用通用字母（中国教材里读者本来就眼熟），首次绑定中文：资本 K、货币 G、商品 W、工资 w、价格 p、时间 t、环境 E、负熵 N、不变资本 c、可变资本 v、剩余价值 s、利润 π、利息 i、地租 r。
> - **没有（生命论自创概念）** → 汉字直接入式＋中文下标：操⃗、异⃗、权⃗、操_生、异_控、剩_值、V_自。
> - 判据客观，不靠偏好：翻开中国课本能找到的用字母，找不到的（生命论新立的）用汉字。**拼音首字母一律禁止；英文多字母缩写只留形式化层。**

## 一、五项分歧的唯一推荐（不再并列选项）

| # | 分歧 | **唯一推荐** | 一句话理由（为什么答案是它） |
|---|---|---|---|
| 1 | 总方针 | 中文本位置为命名总方针，覆盖英文缩写裁决 | 作者已定调，本表即落地 |
| 2 | 汉字入式尺度 | **按"有无通用记号"二分**（见上钥匙）：有则字母、无则汉字入式 | 尺度不再靠感觉，新符号照判据自动落位 |
| 3 | 打包命名 | 采用**操作三权·所有五权·异化六维·三种剩余** | 四组好记、能传播，人民一听就懂 |
| 4 | 操作权符号 | **操⃗ / O⃗**（不用 Op） | 作者正式稿全篇用 O、三分向量 2026-09-15 已采纳；Op 下沉形式化层 |
| 5 | 剩余价值符号 | **s**（不用 sv、不用中译本 m） | s/v 已全库修通；s 既合 surplus 又暗合"剩"；避开意义 M；首次注"中译本《资本论》作 m" |

**另关闭三处历史悬案（一并给唯一答案）**：
- **V_L vs V_M**：用 **V_M**（马克思意义的价值，M=Marx），中文主名"社会劳动价值"；生命贡献**不用 V_L**（避免 L 一符三用），记作 **值_贡**（生命贡献），L 只留"劳"。
- **α 复合语义（模块化冲突 C1）**：α 就一个东西＝**明性深度（递归自觉层级）**；体系二所谓"层级系数"是它在层级语境下的取值，非第二个 α。**C1 关闭。**
- **自指能力四名一实**：统一 **V_自**（形式化 V_self）；V_i 表"第 i 个主体的自指能力"时保留 i 下标，V(S) 仅纯形式化语境，V_human 停用。

## 三、符号选择判据（成书可放凡例，一图流）

```
新符号要落位 → 翻中国课本/中译本经典有没有通用记号？
                ├─ 有 → 用通用字母，首次绑中文（资本K·货币G·工资w·时间t…）
                └─ 无（生命论自创）→ 汉字入式＋中文下标（操⃗·异⃗·操_生·剩_值…）
        任何情况：禁拼音首字母；英文多字母缩写只进形式化层（Coq/对外）
```

## 四、回改执行方案（作者点头即一次 PR 做完）

1. **范围（6 类文件）**：迁移总稿、第一编、公式全编、批次02母稿（逐节贯穿时同步）、大融合总稿第九部分、S05 符号表（升 v1.1，与 S05 协同）。
2. **顺序**：先出 v1.1 正式符号表文件（本稿批准后定名）→ 按 B/A/C 三组逐文件回改 → 每处首次出现加〔符号统一 2026-09-15〕注记，旧名保留备查行 → README/智慧地图登记。
3. **纪律**：只改记法，**理论结论、公式关系、判词一个字不动**；一次 PR 开干净（守作者"GitHub 不过频"）；改完 grep 验证旧撞名记号无残留（保留备查行除外）。
4. **不回改的**：raw_materials 原始转写、archive、GPT 批次原文（只收不改）、已出版/作者亲笔权威稿——这些只在卷首加"符号凡例指引"指向 v1.1，不动原文。
5. **S04 Coq 侧**：形式化层拉丁记号不动（本来就是拉丁），只补一张"中文主名↔拉丁"对照，保证三层映射。
