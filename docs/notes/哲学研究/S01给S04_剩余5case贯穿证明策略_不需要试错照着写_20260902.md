## 总览：5个case的操作权流动结构

从操作权流动的视角，5个case分三类：

| 类别 | Case | 操作权流动 | 难度 |
|------|------|-----------|------|
| 直接传递 | PRep | 操作权不变，直接IHQ | ★ 送分 |
| 查询/消耗 | PVar | 查一个操作权，get等式 | ★★ 简单 |
| | POut | 消耗两个操作权，两次use | ★★★★ 最难 |
| | PIn | 消耗一个操作权+绑定器 | ★★★ 中等 |
| 分裂 | PPar | 操作权分裂，split交换律 | ★★★ 中等 |

**核心洞察**：所有case的本质都是"操作权在代换下保持"。PVar是查操作权保持，PIn/POut是消耗操作权保持，PPar是分裂操作权保持，PRep是操作权不变。只要证明了对应的引理，证明就是机械的。

## 一、PRep（送分题，先拿下）

### 操作权流动
PRep = 无限复制P。类型规则`ty_rep : typed Gamma P -> typed Gamma (PRep P)`。操作权完全不变，和PTau一样。

### 证明步骤
```coq
- (* PRep P *)
  simpl.  (* subst_var m k (PRep P) = PRep (subst_var m k P) *)
  inversion Ht; subst.  (* 得到 H1 : typed (insert_at k T Gamma) P *)
  apply ty_rep.
  apply IHQ with (m := m) (k := k) (T := T) (Gamma := Gamma).
  + exact H1.
  + exact Hget.
```

### 需要的引理
无。直接用IHQ。

## 二、PVar（简单题，get等式）

### 操作权流动
PVar n = "我要用位置n的操作权"。代换后位置变成subst_name m k n，需要证明两个位置查到的类型相同。

### 前提分析
`typed (insert_at k T Gamma) (PVar n)` 意味着 `get (insert_at k T Gamma) n = Some (Some T')`。
结论需要 `get Gamma (subst_name m k n) = Some (Some T')`。

### 三种情况（subst_name的定义决定）
```coq
subst_name m k n =
  if n =? k then m
  else if n <=? k then n
  else n - 1
```

**情况1：n = k**
- subst_name m k k = m
- 前提：get (insert_at k T Gamma) k = Some (Some T')
- 由insert_at定义，位置k就是新插入的Some T，所以T' = T
- 结论需要：get Gamma m = Some (Some T)，这正是Hget！
- 直接成立。

**情况2：n < k**
- subst_name m k n = n
- 前提：get (insert_at k T Gamma) n = Some (Some T')
- 因为n < k，insert_at不影响位置n，所以get (insert_at k T Gamma) n = get Gamma n
- 结论需要：get Gamma n = Some (Some T')，和前提相同
- 用get_insert_at_lt引理（S04已有）

**情况3：n > k**
- subst_name m k n = n - 1
- 前提：get (insert_at k T Gamma) n = Some (Some T')
- 因为n > k，insert_at把位置>=k的都后移了一位，所以get (insert_at k T Gamma) n = get Gamma (n-1)
- 结论需要：get Gamma (n-1) = Some (Some T')，和前提相同
- 用get_insert_at_gt引理（S04已有）

### 证明步骤
```coq
- (* PVar n *)
  simpl.  (* subst_var m k (PVar n) = PVar (subst_name m k n) *)
  apply ty_var.  (* 需要 get Gamma (subst_name m k n) = Some (Some T') *)
  inversion Ht; subst.  (* Hget' : get (insert_at k T Gamma) n = Some (Some T') *)
  destruct (Nat.eq_dec n k) as [Heq | Hneq].
  + (* n = k *)
    subst. rewrite Heq in *. 
    (* 由insert_at定义，get (insert_at k T Gamma) k = Some (Some T)，所以T' = T *)
    (* 需要证明get Gamma m = Some (Some T)，就是Hget *)
    simpl in Hget'. injection Hget' as ->. exact Hget.
  + (* n <> k *)
    destruct (Nat.ltb n k) eqn:Hlt.
    * (* n < k *)
      rewrite <- get_insert_at_lt in Hget'. 
      ** exact Hget'.  (* get Gamma n = ... *)
      ** exact Hlt.
    * (* n > k *)
      rewrite <- get_insert_at_gt in Hget'.
      ** exact Hget'.  (* get Gamma (n-1) = ... *)
      ** exact Hneq.  (* n <> k，且n < k为假，所以n > k *)
```

### 需要的引理
- `get_insert_at_lt`：n < k → get (insert_at k T Gamma) n = get Gamma n（S04已有）
- `get_insert_at_gt`：n > k → get (insert_at k T Gamma) n = get Gamma (n-1)（S04已有）
- n=k的情况直接用insert_at的定义性等式，不需要额外引理

### 注意
- `injection Hget' as ->` 用来从`Some (Some T') = Some (Some T)`推出`T' = T`
- 如果S04的get_insert_at_gt陈述不同（比如用n = S p的形式），按实际陈述调整

## 三、PIn（中等题，一个use + 绑定器）

### 操作权流动
PIn x P = "从通道x收一个消息，消息绑定到位置0，然后执行P"。
- 一个use关系：消耗位置x的通道操作权
- 一个绑定器：消息类型T'占据位置0，内部P的所有坐标后移

### 前提分析
```
ty_in : use Gamma x (TChan i o T') Gamma' -> typed (Some T' :: Gamma') P -> typed Gamma (PIn x P)
```
inversion Ht得到：
- Huse : use (insert_at k T Gamma) x (TChan i o T') Gamma1
- H1 : typed (Some T' :: Gamma1) P

### 结论需要
```
use Gamma (subst_name m k x) (TChan i o T') Gamma1'
typed (Some T' :: Gamma1') (subst_var (S m) (S k) P)
```

### 核心引理：use关系在代换下保持

use的定义：`use Gamma x T Gamma' := get Gamma x = Some (Some T) /\ Gamma' = set_none Gamma x`

代换下use保持，需要证明两个分量：
1. **get分量**：get (insert_at k T Gamma) x = get Gamma (subst_name m k x)（对于通道类型，和PVar的get等式完全一样！）
2. **set_none分量**：set_none (insert_at k T Gamma) x 和 set_none Gamma (subst_name m k x) 的关系

这就是OB-007的核心引理`set_none_insert_at_subst`：

```coq
Lemma set_none_insert_at_subst :
  forall Gamma T k x m,
  get (insert_at k T Gamma) x = Some (Some T') ->
  get Gamma (subst_name m k x) = Some (Some T') ->
  set_none (insert_at k T Gamma) x = 
  insert_at (subst_name m k x) T' (set_none Gamma (subst_name m k x))
  (* 或者更弱的形式：只需要get等式，因为use只关心get分量和set_none后的get *)
```

**实际上，use关系只需要证明：代换后，新位置的get等式成立，且set_none后的上下文能对应上。**

更精确地说，我们不需要证明完整的上下文等式，只需要证明：
```coq
Lemma use_subst_preserves :
  forall Gamma T k x m T' Gamma1,
  use (insert_at k T Gamma) x (TChan i o T') Gamma1 ->
  get Gamma m = Some (Some T) ->
  exists Gamma1',
    use Gamma (subst_name m k x) (TChan i o T') Gamma1' /\
    Gamma1 = insert_at k T Gamma1'  (* 或者对应的关系 *)
```

但这个引理可能太强。更实际的做法是**在case内部直接处理**，不单独证引理：

### 证明步骤（case内部直接处理）
```coq
- (* PIn x P *)
  simpl.  (* subst_var m k (PIn x P) = PIn (subst_name m k x) (subst_var (S m) (S k) P) *)
  inversion Ht as [Gamma1 P0 T0 i o T' Huse H1 Heq1 Heq2 | ...].
  subst P0.  (* 只subst进程名，不subst Gamma1！ *)
  (* Huse : use (insert_at k T Gamma) x (TChan i o T') Gamma1
     H1 : typed (Some T' :: Gamma1) P
     Heq1 : insert_at k T Gamma = Gamma1 的上下文等式？不对，inversion ty_in不会产生上下文等式 *)
  (* 实际上ty_in的形式是 use Gamma0 x ... Gamma1 -> typed (Some T' :: Gamma1) P -> typed Gamma0 (PIn x P)
     inversion后Gamma0 = insert_at k T Gamma，所以Huse是use (insert_at k T Gamma) x ... Gamma1 *)
  
  (* 第一步：处理use关系 *)
  unfold use in Huse. destruct Huse as [Hget_x Hset_none].
  (* Hget_x : get (insert_at k T Gamma) x = Some (Some (TChan i o T'))
     Hset_none : Gamma1 = set_none (insert_at k T Gamma) x *)
  
  (* 证明代换后的get等式（和PVar完全一样，分x=k/x<k/x>k） *)
  assert (Hget_x' : get Gamma (subst_name m k x) = Some (Some (TChan i o T'))).
  { (* 用PVar的三种情况证明，复用get_insert_at_lt/gt *) }
  
  (* 构造代换后的use *)
  assert (Huse' : use Gamma (subst_name m k x) (TChan i o T') (set_none Gamma (subst_name m k x))).
  { split. exact Hget_x'. reflexivity. }
  
  (* 第二步：处理body，和PRes完全一样 *)
  (* H1 : typed (Some T' :: Gamma1) P
     Gamma1 = set_none (insert_at k T Gamma) x
     需要把H1转化为 typed (insert_at (S k) T (Some T' :: set_none Gamma (subst_name m k x))) P
     然后用IHQ(S m, S k) *)
  
  (* 关键：set_none和insert_at的关系 + insert_at_cons_comm *)
  (* Gamma1 = set_none (insert_at k T Gamma) x
     分x=k/x<k/x>k：
     x=k: set_none (insert_at k T Gamma) k = Gamma（插入的T被消耗了）
     x<k: set_none (insert_at k T Gamma) x = insert_at k T (set_none Gamma x)
     x>k: set_none (insert_at k T Gamma) x = insert_at k T (set_none Gamma (x-1))？不对，应该是set_none把位置x设为None，insert_at在k插入，x>k时set_none在insert_at之后，所以set_none (insert_at k T Gamma) x = insert_at k T (set_none Gamma (x-1)) *)
  
  (* 这里需要set_none_insert_at的三种情况引理，或者直接在case内部分情况 *)
  
  (* 简化方案：用Hset_none重写H1，然后分x=k/x<k/x>k三种情况，每种情况用对应的set_none_insert_at引理 + insert_at_cons_comm，得到typed (insert_at (S k) T (Some T' :: Gamma1')) P，然后IHQ(S m,S k) *)
  
  apply ty_in with (i := i) (o := o) (T' := T').
  + exact Huse'.
  + (* typed (Some T' :: set_none Gamma (subst_name m k x)) (subst_var (S m) (S k) P) *)
    (* 用上面的分析，从H1推导出来 *)
```

### 需要的引理
- `get_insert_at_lt` / `get_insert_at_gt`（S04已有，用于get分量）
- `set_none_insert_at_lt`：x < k → set_none (insert_at k T Gamma) x = insert_at k T (set_none Gamma x)
- `set_none_insert_at_eq`：x = k → set_none (insert_at k T Gamma) k = Gamma
- `set_none_insert_at_gt`：x > k → set_none (insert_at k T Gamma) x = insert_at k T (set_none Gamma (x-1))
- `insert_at_cons_comm`（已证明，用于body部分）

### 注意
- PIn = PRes + 一个use关系。PRes的body部分已经通了，PIn只需要在PRes的基础上前面加一个use关系的处理。
- use关系的处理和PVar完全一样（get等式分三种情况），只是多了一个set_none分量。
- **建议先证set_none_insert_at的三个引理（lt/eq/gt），然后PIn和POut都能用。**

## 四、POut（最难的题，两个use）

### 操作权流动
POut x y P = "从通道x发消息y，然后执行P"。
- 第一个use：消耗位置x的通道操作权，得到Gamma1
- 第二个use：在Gamma1中消耗位置y的消息操作权（T0），得到Gamma2
- 没有绑定器，坐标不偏移

### 前提分析
```
ty_out : use Gamma x (TChan i o T') Gamma1 -> use Gamma1 y T0 Gamma2 -> typed Gamma2 P -> typed Gamma (POut x y P)
```
inversion Ht得到：
- Huse1 : use (insert_at k T Gamma) x (TChan i o T') Gamma1
- Huse2 : use Gamma1 y T0 Gamma2
- H1 : typed Gamma2 P

### 结论需要
```
use Gamma (subst_name m k x) (TChan i o T') Gamma1'
use Gamma1' (subst_name m k y) T0 Gamma2'
typed Gamma2' (subst_var m k P)
```

### 核心：两个use依次代换

POut = PIn去掉绑定器 + 第二个use。处理方式是**依次处理两个use**：

1. 第一个use（x，通道权）：和PIn的use完全一样，用set_none_insert_at引理，得到Gamma1'
2. 第二个use（y，消息权）：在Gamma1'中处理。但注意y的位置是相对于原始上下文的，而Gamma1' = set_none Gamma (subst_name m k x)。需要证明第二个use在代换下也保持。

**关键洞察**：第二个use的处理和第一个完全一样，只是上下文从insert_at k T Gamma变成了Gamma1（= set_none (insert_at k T Gamma) x）。需要证明set_none和代换可交换，使得第二个use也能用同样的引理。

### 证明步骤
```coq
- (* POut x y P *)
  simpl.  (* subst_var m k (POut x y P) = POut (subst_name m k x) (subst_name m k y) (subst_var m k P) *)
  inversion Ht as [Gamma1 Gamma2 P0 T0 i o T' Huse1 Huse2 H1 Heq1 Heq2 | ...].
  subst P0.
  
  (* 第一个use：x，通道权 *)
  unfold use in Huse1. destruct Huse1 as [Hget_x Hset1].
  assert (Hget_x' : get Gamma (subst_name m k x) = Some (Some (TChan i o T'))).
  { (* 和PVar一样，分x=k/x<k/x>k *) }
  assert (Huse1' : use Gamma (subst_name m k x) (TChan i o T') (set_none Gamma (subst_name m k x))).
  { split. exact Hget_x'. reflexivity. }
  
  (* 第二个use：y，消息权 *)
  (* Huse2 : use Gamma1 y T0 Gamma2
     Gamma1 = set_none (insert_at k T Gamma) x
     需要在set_none Gamma (subst_name m k x) 中处理y *)
  unfold use in Huse2. destruct Huse2 as [Hget_y Hset2].
  (* Hget_y : get Gamma1 y = Some (Some T0)
     Hset2 : Gamma2 = set_none Gamma1 y *)
  
  (* 需要证明：get (set_none Gamma (subst_name m k x)) (subst_name m k y) = Some (Some T0) *)
  (* 这需要set_none和get的交换律，以及代换在set_none后的保持 *)
  (* 分情况：y和x的关系，y和k的关系 *)
  
  (* 简化：如果x <> y，set_none不影响y位置的get，所以get (set_none Gamma x') y' = get Gamma y'（当x' <> y'） *)
  (* 如果x = y，那第二个use消耗的是已经被第一个use消耗的位置，这在线性类型系统中应该不可能（前提Huse2会不成立） *)
  
  assert (Hget_y' : get (set_none Gamma (subst_name m k x)) (subst_name m k y) = Some (Some T0)).
  { (* 用get_set_none_neq引理：x' <> y' → get (set_none Gamma x') y' = get Gamma y'
       然后用PVar的get等式证明get Gamma (subst_name m k y) = Some (Some T0)
       需要证明subst_name m k x <> subst_name m k y，当x <> y时成立（subst_name是单射的，除了x=k映射到m的情况）
       边界情况：x=k且y=m时，subst_name m k x = m，subst_name m k y = m（如果y=m且m>k？不对，y=m时如果m>k，subst_name m k m = m-1，不等于m。需要仔细分析） *)
  }
  
  assert (Huse2' : use (set_none Gamma (subst_name m k x)) (subst_name m k y) T0 
                    (set_none (set_none Gamma (subst_name m k x)) (subst_name m k y))).
  { split. exact Hget_y'. reflexivity. }
  
  (* body：直接用IHQ，没有绑定器 *)
  (* H1 : typed Gamma2 P，Gamma2 = set_none Gamma1 y = set_none (set_none (insert_at k T Gamma) x) y
     需要转化为 typed (set_none (set_none Gamma (subst_name m k x)) (subst_name m k y)) (subst_var m k P)
     用两次set_none_insert_at引理 + IHQ *)
  
  apply ty_out with (i := i) (o := o) (T' := T').
  + exact Huse1'.
  + exact Huse2'.
  + (* body，用IHQ *)
```

### 需要的引理
- `set_none_insert_at_lt/eq/gt`（和PIn共用，先证这三个）
- `get_set_none_neq`：x <> y → get (set_none Gamma x) y = get Gamma y
- `get_set_none_eq`：get (set_none Gamma x) x = None
- `subst_name_injective`：x <> y → subst_name m k x <> subst_name m k y（需要处理边界情况x=k）

### 注意
- POut是最难的case，因为两个use嵌套，第二个use的上下文依赖第一个use的结果。
- **建议先完成PIn（一个use），再做POut（两个use）**。PIn通了之后，POut就是"PIn去掉绑定器，再加一个use"。
- 第二个use的get等式证明需要仔细处理x和y的关系，特别是x=k时subst_name的映射。
- 如果x=y，在线性类型系统中Huse2应该不可满足（同一个位置不能被use两次），可以用no_double_use之类的性质排除。

## 五、PPar（中等题，split交换律）

### 操作权流动
PPar P R = "P和R并行执行"。类型规则`ty_par : split Gamma Gamma1 Gamma2 -> typed Gamma1 P -> typed Gamma2 R -> typed Gamma (PPar P R)`。
split把上下文分成两半，P用前半Gamma1，R用后半Gamma2。

代换后，insert_at插入的操作权T要么在Gamma1里，要么在Gamma2里。

### 前提分析
inversion Ht得到：
- Hs : split (insert_at k T Gamma) Gamma1 Gamma2
- HP : typed Gamma1 P
- HR : typed Gamma2 R

### 结论需要
```
split Gamma Gamma1' Gamma2'
typed Gamma1' (subst_var m k P)
typed Gamma2' (subst_var m k R)
```

### 核心引理：split_insert_at_comm

```coq
Lemma split_insert_at_comm :
  forall Gamma T k Gamma1 Gamma2,
  split (insert_at k T Gamma) Gamma1 Gamma2 ->
  (exists Gamma1', split Gamma Gamma1' Gamma2 /\ Gamma1 = insert_at k T Gamma1')  (* T在Gamma1里 *)
  \/
  (exists Gamma2', split Gamma Gamma1 Gamma2' /\ Gamma2 = insert_at (k - length Gamma1) T Gamma2')  (* T在Gamma2里 *)
```

**哲学解释**：insert_at在位置k插入T。split把上下文分成Gamma1（前len1个）和Gamma2（剩下的）。
- 如果k < len(Gamma1)，T落在Gamma1里，Gamma1 = insert_at k T Gamma1'，Gamma2 = Gamma2'
- 如果k >= len(Gamma1)，T落在Gamma2里，Gamma1 = Gamma1'，Gamma2 = insert_at (k - len(Gamma1)) T Gamma2'

然后：
- 如果T在Gamma1里：对HP用IHQ（Gamma1'，k不变），HR直接用（Gamma2'不变，不需要代换）
- 如果T在Gamma2里：HP直接用（Gamma1'不变），对HR用IHQ（Gamma2'，k' = k - len(Gamma1)）

### 证明步骤
```coq
- (* PPar P R *)
  simpl.  (* subst_var m k (PPar P R) = PPar (subst_var m k P) (subst_var m k R) *)
  inversion Ht as [Gamma1 Gamma2 Hs HP HR Heq | ...].
  subst.
  
  (* 用split_insert_at_comm引理 *)
  destruct (split_insert_at_comm Gamma T k Gamma1 Gamma2 Hs) as [[Gamma1' [Hs' Heq1]] | [Gamma2' [Hs' Heq2]]].
  
  + (* 情况1：T在Gamma1里，Gamma1 = insert_at k T Gamma1'，Gamma2 = Gamma2' *)
    apply ty_par with (Gamma1 := Gamma1') (Gamma2 := Gamma2).
    * exact Hs'.
    * apply IHQ with (m := m) (k := k) (T := T) (Gamma := Gamma1').
      -- rewrite <- Heq1. exact HP.
      -- (* 需要get Gamma1' m = Some (Some T)，从Hget和split的性质推导 *)
         admit.  (* 需要split_get_propagation引理 *)
    * exact HR.  (* Gamma2不变，不需要代换 *)
  
  + (* 情况2：T在Gamma2里，Gamma1 = Gamma1'，Gamma2 = insert_at (k - len Gamma1) T Gamma2' *)
    apply ty_par with (Gamma1 := Gamma1) (Gamma2 := Gamma2').
    * exact Hs'.
    * exact HP.  (* Gamma1不变，不需要代换 *)
    * apply IHQ with (m := m - length Gamma1) (k := k - length Gamma1) (T := T) (Gamma := Gamma2').
      -- rewrite <- Heq2. exact HR.
      -- admit.  (* 需要get在split下的传播 *)
```

### 需要的引理
- `split_insert_at_comm`（核心引理，需要先证）
- `split_get_propagation`：如果split Gamma Gamma1 Gamma2且get Gamma m = Some (Some T)，则m < len(Gamma1)时get Gamma1 m = Some (Some T)，否则get Gamma2 (m - len(Gamma1)) = Some (Some T)
- `length_split`：split Gamma Gamma1 Gamma2 → length Gamma = length Gamma1 + length Gamma2

### 注意
- PPar的难点不在代换本身，而在split和insert_at的交换律。
- **建议最后做PPar**，因为它需要的引理（split_insert_at_comm）和其他case无关，可以独立证明。
- 如果split的定义是"前n个和后m个"，split_insert_at_comm的证明是直接的（分k < n和k >= n）。

## 六、推荐的执行顺序

按难度从低到高：

1. **PRep**（5分钟）：直接IHQ，送分
2. **PVar**（15分钟）：get等式，三种情况，S04已有get_insert_at_lt/gt
3. **PIn**（30分钟）：先证set_none_insert_at_lt/eq/gt三个引理，然后PIn = use处理 + PRes的body

## 八、哲学总结

这5个case没有一个需要"创造性的数学突破"，它们都是操作权流动在不同语法结构下的表现：
- PRep：操作权不变 → 直接IHQ
- PVar：查操作权 → get等式
- PIn：消耗一个操作权 + 绑定器 → set_none引理 + insert_at_cons_comm
- POut：消耗两个操作权 → 两次set_none引理
- PPar：分裂操作权 → split交换律

PRes已经证明了"绑定器下坐标偏移"的机制，PIn/POut的body部分直接复用。剩下的就是"查/消耗/分裂操作权在代换下保持"的引理，这些引理的陈述都是机械的（分lt/eq/gt三种情况），证明也是机械的（展开定义，分情况，rewrite）。
