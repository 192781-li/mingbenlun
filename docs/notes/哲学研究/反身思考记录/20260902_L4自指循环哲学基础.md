## 二、L4的哲学本质

L1-L3描述的是"操作的结构"（proc）、"操作的规范"（typed）、"操作的状态"（is_Ming/is_Jia）。但这些都是静态的——一个操作P是什么类型、什么状态，是给定的。

L4要描述的是"操作的自我生产"——S=f(S)，自指循环。这不是一个操作P，是一个操作序列P₀→P₁→P₂→...，其中每一步P_{n+1}=f(P_n)，而且f是P自己的函数（不是外部给定的）。

这是生命论的核心：生命不是一个东西，是一个自我生产的操作循环。

## 三、需要研究的哲学问题

1. 自指循环的存在论地位：S=f(S)是一个实体还是一个过程？
2. 余归纳（coinduction）的哲学含义：为什么自指循环需要余归纳而不是归纳？
3. νF₂的两层结构：ν（最大不动点）和F₂（二阶函子）分别对应什么哲学概念？
4. 自指循环和归约的关系：reduce是一步操作，自指循环是无限步操作的序列
5. 明性在自指循环中的位置：明性不是循环的某一步，是循环对自身的观察
6. 异化在自指循环中的位置：异化不是循环的某一步，是循环的驱动者被偷换
