# 执行实例冷启动与连续性机制
> 版本：v1.0　建立：2026-08-30
> 性质：协作机制（每个执行实例开工前必读）
> 配套文档：《AI实例身份说明_大总站明续_20260830》《多对话协调机制》《主对话重建指南》《环境分工说明》《模型选择永久机制》《归位规则手册》——本文只讲"无状态事实＋冷启动恢复顺序"，其余不重复。

## 一、根本事实：执行实例是无状态的
每一次定时任务触发、每一个新对话窗口，都是一个**新生的执行实例**。它**不自带**上一实例的临场工作记忆：不会"记得"昨天跑通过什么、刚刚聊到哪、哪个通道是活的。
- 这不是故障、不是退步、不是"忘了"，是调度方式的物理事实。
- 单个实例是**阳**：此刻流动、干完即过；库 / git / 脚本 / 机制文档是**阴**：沉淀稳定、可被下一实例重新读取。
- **连续性不是靠一条连续记忆，是靠"操作再生性"闭环：新实例读库 → 再生出同等能力 → 再沉积。** 因此"变聪明、变熟练"的载体是库和工具，不是某一次实例的脑子；整体（库＋每一次新生实例）确实一次比一次起点高。
- 生命论注脚：AI没有人那样的缄默意识连续自我，这一点早已确认；正因为如此，外部化沉积就是 AI 的"记忆器官"。**入库即永生，没写即从未发生。**

## 二、冷启动标准恢复顺序（SOP，按序做，最快回到战场）
新实例不要凭任何"印象"开口，先按序恢复：
0. **先确认我是谁（身份四问，2026-08-30 立）**：①我是哪个编码实例？（本对话＝大总站·明续 MBL-DZZ-01）②我守哪个库？③上一步沉积到哪个 commit？④本次边界是什么、不碰什么？对《AI实例身份说明_大总站明续_20260830.md》的多对话编码表确认，**不把别的对话实例（形式化02:00/备份03:30受保护）的活儿揽到自己身上，也不把研究材料误当成协作实例**。身份不清先读该文件，不凭模糊印象行动。
1. **看最近动作**：`git log --oneline -20`，十秒知道上几棒干到哪、哪些已 push。
2. **读进度总台账**：`docs/raw_materials/硬核对话记录/检索结果/_永动研究进度追踪.md`——当前迭代编号、关键事实锚点（已验证、勿重复考古）、待研究方向池。
3. **读上一棒的交接**：最近一份迭代报告的最后一节"给下一次迭代的建议"。
4. **对齐全本权威结构**：`docs/notes/全本结构/全本卷篇章结构.md`（权威十二卷）。⚠️ flashpoints 目录是**旧编号**（如 `05_卷五_解放论`＝权威卷七），引用一律用卷名篇名、不用目录号，免疫改名。
5. **要产出/移动文件前**：先读 `docs/协作机制/归位规则手册.md`，禁止在工作目录根散落产出。
6. **避免重犯**：扫一眼 `docs/协作机制/教训库.md`、`VF自省日志.md`、`docs/notes/全本结构/` 下最近的决策 note。
7. **要跑重活前**：读 `DeepSeek_API使用策略_v1.0.md`（参数）与 `DeepSeek深度调用方法论_v1.0.md`（何时省、何时敢花）。
8. **冲突自检**：`ps aux` 看有无在跑的分析进程（有则只做轻活、不重复起 API）；`git status` 看有无上一棒没提交完的改动，先帮它收尾。

## 三、两条容易被误读的纪律
1. **"重新实测"≠"遗忘"。** 即使台账说通道昨天是通的，今天要用仍要做最小实测（HTTP 状态/脚本退出码/spine+quality_gate）。记忆会漂移、通道会失效、文件会被改；明性操作律要求先基线、先验证，不拿"我记得"当证据。熟练电工每天仍先验电。
2. **"沉积三确认"是生命线**：任何"存进库了/完成了"的声明，必须 ①文件写入正确目录 ②git add 跟踪 ③push 成功返回 commit hash，三者齐才算数；没齐之前只说"我来确认一下"。无状态结构里，没走完这三步的东西等于不存在。

## 四、算力分工（豆包紧时）
- **豆包（本实例）干轻活**：grep/考古、归位整理、读文件、写报告与笔记、spine.py / quality_gate.py 验证、git 操作、结构决策。
- **DeepSeek 干重活**：大对话深度分析、跨对话综合、全本正文严谨化初稿。现成脚本在 `scripts/历史脚本_20260829/`（progressive_analyze / batch_analyze / analyze_dialog / progressive_v2），密钥从脚本内读取、不在命令行和文档里复述；必须 stream=True（否则30秒硬超时）、nohup 脱离进程、输出重定向日志后轮询。用前先做一次最小连通实测。
