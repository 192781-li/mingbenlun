# 生命论模块化文件命名规范 v1.0

> 制定：2026-09-11 · S05信息分站
> 原则：**任何系统、任何APP、任何排序方式下，文件顺序永远正确**

---

## 一、为什么需要这套规范

源文件曾用中文篇号命名（`篇一_xxx.md`、`篇二_xxx.md`），但阅读APP按Unicode编码排序，
中文"一~七"的编码顺序不是数字顺序，导致目录显示为：第一篇→第七篇→第三篇→第二篇...

**解决方式：数字前缀强制排序。**

---

## 二、目录命名（卷级）

```
生命论_模块化/
├── 00_卷首_命经/          # 两位数字_卷X_卷名
├── 01_卷一_存在论/
├── 02_卷二_操作论/
├── ...
├── 11_卷十一_践演论/
├── 12_附录/
└── 项目文档/              # 不纳入合订本的工作文档
```

规则：`两位数字_卷X_卷名`，数字从00开始。

---

## 三、文件命名（篇级）

### 3.1 卷标题文件
```
00_卷标题.md              # 每卷第一个文件，内容是 # 第X卷 卷名
00_附录标题.md            # 附录卷
```

### 3.2 普通篇
```
01_篇一_篇名.md           # 两位数字_篇X_篇名
02_篇二_篇名.md
...
12_篇十二_篇名.md
```

### 3.3 子篇（篇一之二）
```
01_篇一_主篇名.md
01a_篇一之二_子篇名.md    # 主篇号+字母(a=子篇1,b=子篇2...)_篇X之Y_篇名
01b_篇一之三_子篇名.md
02_篇二_主篇名.md
```
> **为什么用字母不用数字？** `01-2_`中`-`(ASCII45) < `_`(ASCII95)，导致子篇字典序排在主篇前面。改用`01a_`后`a`(97) > `_`(95)，保证主篇在前、子篇在后。

### 3.4 篇零（前置篇）
```
00_篇零_篇名.md           # 篇零排在卷标题之后、篇一之前
00a_篇零之二_篇名.md
01_篇一_篇名.md
```

### 3.5 附录
```
00_附录标题.md
01_附录一_篇名.md
02_附录二_篇名.md
...
07_附录七_篇名.md
```

### 3.6 卷首根文件
```
生命论_模块化/
├── 00_全书导言.md
├── 00_体系总纲.md
├── 00_推导链总览.md
└── 00_尾声.md
```

## 四、文件内标题规范

| 层级 | Markdown | 示例 |
|---|---|---|
| 卷 | `#` (H1) | `# 第一卷 存在论：从操作出发` |
| 篇 | `##` (H2) | `## 第一篇 在感：唯一无需怀疑的起点` |
| 子篇 | `##` (H2) | `## 第一篇之二 劳动价值论的正面奠基` |
| 章 | `###` (H3) | `### 一、操作的定义` |
| 节 | `####` (H4) | `#### 1. 自指操作` |

**篇号格式统一为"第X篇"，子篇为"第X篇之Y"，篇零为"篇零"。**

## 五、吸附机制

新文件放入卷目录后，运行吸附脚本自动归位：

```bash
python3 scripts/normalize_filenames.py          # 预览（dry-run）
python3 scripts/normalize_filenames.py --apply   # 实际执行
```

脚本会：
1. 检测没有数字前缀的篇文件
2. 自动添加正确的数字前缀
3. 统一文件内第一个标题的篇号格式
4. 报告所有变更

---

## 六、CI强制检查

GitHub Actions 的 quality-check.yml 包含文件名规范检查：
- 篇文件必须有数字前缀
- 文件内标题层级必须正确（卷=H1，篇=H2）
- 不规范则CI失败，阻止合并

---

## 七、排序规则速查

| 文件名前缀 | 排序位置 |
|---|---|
| `00_` | 卷标题/篇零/卷首文件 |
| `00a_` | 篇零之二 |
| `01_` | 第一篇 |
| `01a_` | 第一篇之二 |
| `01b_` | 第一篇之三 |
| `02_` | 第二篇 |
| ... | ... |
| `12_` | 第十二篇 |

**核心：文件名字典序 = 阅读顺序，任何系统都不会乱。**
