> 维护者：S01哲学分对话（初始创建），S05信息分站（日常维护）
> 最后更新：2026-09-02
> 用途：每个分站定时任务触发时，先读本地图中分配给自己的文档，再开始干活

## 怎么用这个地图

1. 每个分站的定时任务SOP里加一步："读智慧地图中分配给本站的文档"
2. 新任务创建时，在任务描述里标注"参考智慧地图中的XXX文档"
3. 新智慧文档产出后，维护者（S01/S05）立即更新本地图
4. 文档太长时，先读摘要（如果有），再按需读全文

## 六、智慧传递机制（怎么让新智慧流到分站）

### 6.1 新智慧产出后的三步注入

1. **更新智慧地图**：新文档产出后，维护者（S01/S05）立即在本地图中添加条目
2. **注入任务描述**：如果新文档和某个pending任务相关，在该任务的description最前面加"【必读】XXX文档"
3. **更新分站运行状态机**：如果新文档是某分站的长期必读，在该分站运行状态机的"必读文档"章节添加

### 6.2 分站定时任务SOP模板（每个分站都要加）

```
【第一步：智慧注入】
1. 读智慧地图（docs/协作机制/明旭智慧地图_分站必读文档索引.md）中分配给本站的文档
2. 读当前任务描述中标注的【必读】文档
3. 读教训库最近3条
【第二步：开始干活】
...
```

### 6.3 智慧萃取（S05负责）

- 长文档（>500行）由S05萃取成100字摘要，写入智慧地图的"一句话摘要"列
- 摘要不是概述，是"这个文档能帮你解决什么问题"
- 分站先读摘要，判断是否需要读全文
