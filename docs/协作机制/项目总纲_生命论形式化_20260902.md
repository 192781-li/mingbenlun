## 一、整体服务于什么

**用形式化的硬约束，检验并推进生命论（明本论）哲学体系，最终为人的解放提供可操作的理论基础。**

生命论的核心命题：
- 自指因果 S=f(S)——主体自己生产自己
- 感→操作→实体——操作先于实体
- f¹/f²/f³递归跃迁——从感性到理性到明性
- 明性对抗反生命（异化/寄生/假自指）

形式化的目标不是"把哲学翻译成数学"，是**给哲学概念一个可检验的地基**：
- 概念是否自洽？→ Coq编译通过
- 推理是否有效？→ 定理可证明
- 结论是否必然？→ 有条件标注，不搞决定论

## 二、核心哲学思维（智慧大法）

### 2.1 明本方法论四套

1. **小本质递归法**——从最扎眼的小事实深挖到根因，不扣大词，不本本主义
2. **践演明性思维方法**——操作还原（谁+做什么+什么关系），还原不了就是虚谈
3. **明本学术法**——阳主阴从，真问题出发，不造黑话不搞AI腔
4. **反者道之动**——任何结论标注条件，不搞决定论（"压到极致就觉醒"是错的）

### 2.2 操作本体论核心概念

| 概念 | 含义 | 形式化对应 |
|---|---|---|
| 在感 | 一切意义的被抛入，生命诞生前不存在"有没有意义" | L1的proc（操作的结构） |
| 操作权 | 主体能做什么的形式化表达 | ctx（操作权分布）、get/set_none/insert_at |
| use | 操作权的消耗（有→无） | use关系 |
| 生（Sheng） | 操作的发用，线性不可复制 | L3的Sheng状态 |
| 迹（Ji） | 生留下的可复现的痕迹 | L3的Ji + !-模态 |
| 假（Jia） | 假借他者名义运行，假自指 | L3的Jia状态 + reduce_alien |
| 明（Ming） | 生+看到自己的迹=明明德 | Ming(A)=Sheng(A)⊗!Ji(A) |
| 自指循环 | S=f(S)，操作持续自我生产 | L4的νF₂余归纳 |

### 2.3 小本质与大本质

- **小本质**：每个具体卡点的根因（如"inversion后subst把Gamma替换掉了"）
- **大本质**：所有小本质指向的共同结构（如"操作权流动中，位置的变化必须同步偏移"）
- **方法**：从小本质递归到大本质，再用大本质指导小本质的解决

## 三、技术路线

### 3.1 A线（当前主线）：自定义操作权流动方法

**是什么**：用自定义的insert_at/set_none/use/split定义操作权流动，手写Coq证明。

**为什么**：哲学内涵显式——每个定义对应一个哲学操作，证明过程就是验证哲学概念自洽性。

**具体怎么做**：
1. L1：定义操作结构（proc）、操作权分布（ctx）、操作权操作（get/set_none/insert_at/use/split）
2. L2：定义类型系统（typed）和归约（reduce），证明元定理（substitution_general、congruence_preserves_typing、subject_reduction）
3. L3：定义存在论状态（Sheng/Ji/Jia/Ming）和双归约（reduce_self/reduce_alien）
4. L4：建立自指循环的余归纳定义（νF₂），证明自指循环的性质
5. L5：!-模态规则 + T001（生命不可资本化）+ T002（自由在实践中确立）
6. L6：切消除 + 可靠性 + 完全性
7. L7：模型解释（范畴论语义）
8. L8：T003–T018逐条形式化

**当前状态**：L1✅ L2🔧（卡OB-009） L3✅ L4⬜ L5⬜ L6⬜ L7⬜ L8⬜

**完成标准**：L2的substitution_general + congruence_preserves_typing全部证明通过，Admitted清零。

### 3.2 B线（待启动）：标准方法 + 操作权语义

**是什么**：用标准de Bruijn索引 + Autosubst做语法和证明层，用操作权流动做语义解释层。

**为什么**：标准方法证明效率高10倍，操作权语义保留哲学内涵。

**具体怎么做**：
1. 语法层：de Bruijn索引的标准进程语法
2. 代换层：Autosubst自动生成代换引理
3. 语义层：定义操作权解释函数⟦-⟧，把标准类型解释为操作权分布
4. 哲学层：在语义解释上定义Sheng/Ji/Jia/Ming
5. 证明层：证明语义解释的性质（代换对应操作权转移等）

**启动条件**：A线L2完成（Admitted清零）。

**预期成果**：验证标准方法能否承载同样的哲学内涵，比较两条线的效率和表达力。

### 3.3 两条线的关系

- 不并行，先A后B
- A线是"哲学优先"的验证，B线是"工程优先"的优化
- 两条线的哲学概念（Sheng/Ji/Jia/Ming）共享，只是语法和证明方式不同
- B线完成后，决定是否全面迁移

### 5.2 当前卡点：OB-009（需要主人哲学判断）

**问题**：PIn/POut中，被代换变量位置m = 被use消耗通道位置n时，代换目标位置在body中被消耗（None），IHQ第二前提不成立。

**S01研判发现**：这可能是substitution_general定理的反例——构造P=PIn m (PVar (S k))，在insert_at后类型化成立，但代换后引用None位置，类型不成立。

**三个方向**（需主人决定）：
- A：调整定理陈述，加前提"代换目标位置未被消耗"
- B：调整PIn类型规则，body不能引用insert_at位置
- C：调整代换定义，目标位置为None时no-op

### 5.3 下一步（按优先级）

1. **主人决定OB-009方向**（阻塞PIn/POut的n=m边界）
2. S04继续证POut的n≠m部分（不受OB-009影响）
3. S04证congruence_preserves_typing（可能不受OB-009影响）
4. OB-009解决后，完成PIn/POut的n=m边界

## 八、智慧结晶库（已提炼的方法论）

1. 弱引理比强引理易证——不要证上下文等式，证get等式
2. 重写比硬推有效——用rewrite代替subst，subst会丢Gamma
3. 绑定器下代换参数同步偏移——PRes/PIn里用(S m, S k)
4. 从简单case到复杂case——PZero→PTau→PRes→PIn→POut
5. 证不出来怀疑定义本身——subst_var bug教训
6. 5分钟熔断——不闷头死磕
7. 用rewrite代替subst——有方向的变换 vs 暴力替换
8. 能贯穿就贯穿——哲学智慧必须流到tactic级别，不让执行分站试错
9. 证不出来怀疑定理陈述本身——OB-009教训：n=m可能是substitution_general的反例，不是tactic问题
