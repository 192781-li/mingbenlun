## 七、回流操作规范

1. **回流不是复制粘贴**：将生成洞察转化为全本的语言和结构，标注来源
2. **回流后更新台账**：标记"已回流"并注明具体文件和行号
3. **冲突时以全本为准**：生成洞察与全本现有论述冲突时，标注"待作者定夺"，不擅自修改全本
4. **每轮库阅读后必须更新台账**：新生成的洞察立即登记，不积压
