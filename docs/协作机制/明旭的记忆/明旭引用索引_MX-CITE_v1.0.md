## 一、这是什么

每次聊完一系列东西，用户说"总结"后，AI 不只入库，还登记一个**唯一符号**（形如 `MX-CITE-YYYYMMDD-NNN`）。用户只需把这个符号复制给另一个对话/分站，对方凭符号就能从库里精确取出对应内容——不用转述、不用翻目录。

## 二、怎么用（给所有分站与对话，必读）

**收到符号时（接收方）：**
0. **先 pull 最新 main**（`git checkout main && git pull origin main`）——不 pull 会查到旧库、误判"条目不存在"（2026-09-13 已发生一次：S00 未同步就探查，报"无此条目"，实际已在 main）
1. 在本文件"索引表"中查该符号 → 得到 `文件路径`
2. `Read` 该文件，即获得发送方想让你理解的内容
3. 找不到符号 → 在 `docs/notes/信息分站/` 与 `docs/协作机制/` 下按主题 `grep` 兜底

**产生新总结时（发送方）：**
1. 内容入库（commit + push）
2. 在本文件索引表顶部登记一行：`符号 | 日期 | 主题 | 文件路径 | 入库人`
3. 把符号原样发给用户

## 三、符号规则

- 格式：`MX-CITE-YYYYMMDD-NNN`（日期 + 当日序号，从 001 起）
- 符号**永不重复**；同一主题多次总结用新符号，不覆盖旧符号
- 符号本身不携带内容，只是"库内地址"；内容永远以库为准
