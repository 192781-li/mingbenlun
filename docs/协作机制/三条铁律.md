# 三条铁律（写作与研究的硬约束）

> 来源：mingbenlun-modular九卷版·创作总纲
> 定位：所有分站写作、研究、代码的底线纪律

## 一、术语铁律

**绝不说"物质自己会活"。**

- 活的是生命，不是物质
- 生命物质才是活的——因为生命是活的，所以构成生命的物质才呈现活性
- 违反此条＝倒向旧唯物主义/机械论，体系根基崩塌
- 机器校验：`scripts/verify_iron_rule.py`

## 二、数据铁律

**数字须核验、带出处、不冒充事实。**

- 引用数据前必须核验来源
- 估算数据必须标注"估算"和口径
- 不得把AI生成的数字当事实
- BESIII胶球数据、婴儿游泳反射等已核验案例可作范例

## 三、立场铁律

**追立场先查AI自己、不装中立。**

- 这套哲学替活的生命说话、反异化、反资本病毒
- 不假装"客观中立"——中立本身就是一种立场
- 写之前先问：我在替谁说话？
- 体系不升级，锋芒会钝、根会松、漏洞会被渗透

---

## 校验方式

```bash
python scripts/verify_iron_rule.py <目标文件.md>
```

守不住这三道，体系再漂亮也是沙上楼。
