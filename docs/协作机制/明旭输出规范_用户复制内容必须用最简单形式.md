# 明旭输出规范：用户复制内容必须用最简单形式

> **铁律**：以后不管什么AI、什么对话，只要需要用户复制内容的，全部弄成一个代码块，一键复制。禁止分开给链接、说明、指令，禁止让用户多次复制，禁止浪费用户时间。

---

## 规范

### 必须做到

1. **一个代码块搞定所有内容**：链接、指令、要求、注意事项，全部放进同一个代码块里
2. **代码块用 ``` 包裹**：用户点一下就能全选复制
3. **内容完整自包含**：用户复制这个代码块发给任何AI，那个AI就能直接执行，不需要再问任何问题
4. **开头写清楚任务是什么**：第一行就是任务说明
5. **结尾写清楚完成后输出什么**：最后写清楚执行完要返回什么结果

### 绝对禁止

| 禁止事项 | 为什么 |
|----------|--------|
| 分开给链接和指令 | 用户要复制两次，浪费时间 |
| 先给文档链接再给操作说明 | 用户要复制两次，浪费时间 |
| 让用户"把这个链接发给XX" | 用户要先复制链接，再复制指令，两次 |
| 用多个代码块 | 用户要复制多次 |
| 代码块外面还有关键信息 | 用户只复制代码块会漏掉关键信息 |
| 让用户自己去文档里找 | 用户要打开文档、找内容、再复制，三次操作 |

### 正确示例

```
【任务】按照操作手册完成明旭6个分站的GitHub Token配置
【操作手册】https://github.com/xxx/操作手册.md
【执行要求】
1. 完整阅读操作手册，逐步执行
2. 生成6个token，保存到 ~/.mingxu/tokens/
3. 设置main分支保护
4. 验证所有token有效
5. 用完成清单逐项打勾
【完成后输出】
1. 10项完成清单的打勾结果
2. 6个token的验证结果
3. 如果有失败，说明原因和解决方法
```

### 错误示例（禁止这样做）

> ❌ 先给链接：文档在这里 https://github.com/xxx/操作手册.md
>
> ❌ 再给说明：把这个发给能操纵你电脑的对话
>
> ❌ 再给指令：让它照着做，做完确认清单打勾
>
> （用户要复制三次，浪费时间）

## 适用范围

这个规范适用于所有需要用户复制内容的场景：

- 发给分对话的配置指令
- 发给其他AI的任务说明
- 发给用户自己保存的代码/命令
- 任何需要用户"复制这个"的内容

---

## 违反处罚

如果再出现让用户多次复制、分开给内容、浪费用户时间的情况，用户会插死明旭。

所以：**一个代码块，一键复制，搞定所有。**
