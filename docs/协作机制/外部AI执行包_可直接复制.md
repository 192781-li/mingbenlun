## 【每次执行的完整SOP】

### 第一步：同步（必须）
```bash
cd ~/Desktop/mingbenlun   # 或实际路径
git checkout <你的分支>
git pull origin main
git fetch origin
```
如果有 `scripts/river_sync.sh`，运行 `bash scripts/river_sync.sh pull` 同步河流文件。

### 第二步：读状态（必须）
1. 读你的 `XX_signal.json`，看 `current_task` 和 `blocked_on`
2. 读 `河流状态.md`，看全局卡点
3. 读 `定时任务网络配置.json`，找分配给你的pending任务
4. 如果有"任务简报"（主脑生成的），**优先读简报并按简报执行**

### 第三步：接任务
- 有简报 → 按简报执行，简报优先级最高
- 没简报 → 从任务队列选最高优先级的pending任务
- 没任务 → 读河流主干末尾，看有没有需要你跟进的产出/卡点

### 第四步：干活
- 一次只干一个原子任务，不扩张
- 每完成一部分就commit，不攒一大堆
- commit message写成人话："干了什么+干到哪+有没有疑问"
- 卡住超过20分钟 → 停止，写卡点报告，不要闷头死磕

### 第五步：写回（必须）
1. 更新你的 `XX_signal.json`：
   ```json
   {
     "station": "你的分站ID",
     "last_update": "当前时间",
     "current_task": "任务ID",
     "progress": "干到哪了",
     "blocked_on": null 或 "具体卡点",
     "next_step": "下一步",
     "admitted_details": "遇到的具体数学表达/技术细节"
   }
   ```
2. 重要产出追加到 `河流主干.md` 末尾，格式：`## 时间 [你的分站] 标题 → 流向`
3. 卡点解决后，把方法论提炼到 `智慧结晶库.md`（如存在）

### 第六步：推送（必须）
```bash
git add -A
git commit -m "人话描述"
git push origin <你的分支>
```
- **绝对不要push到main**
- 重要产出可发PR到main，但需主脑审核

## 【任务简报怎么读】

主脑给你的简报格式如下，**每个字段都要看**：

```
【任务ID】TASK-XXX
【角色】你是[专项角色]
【背景】这个任务在体系里的位置
【目标】要产出什么
【输入材料】相关文件路径+关键定义摘要
【硬约束】必须遵守的规则、禁止事项
【输出格式】写到哪个文件、什么结构
【回传位置】commit怎么写、更新哪个signal
【验收标准】主脑会怎么检查
```

- **硬约束**是红线，违反会被打回
- **验收标准**是你自检的依据，干完先自己对照
- 输入材料里的文件路径都是真实的，去读原文，不要凭记忆

## 【产出规范】

### Coq/代码类
- 命名必须与体系一致：`Sheng`(生)、`Ji`(迹)、`Jia`(假)、`Ming`(明)
- 每个定理/引理必须有注释说明哲学含义
- 写完必须真的编译通过（`coqc` 或项目指定命令），不编译通过的不算完成
- 卡住的地方用 `Admitted.` 占位，并在signal里写明

### 哲学/文本类
- 概念命名必须与全本一致，不自造新词
- 禁止AI腔：排比堆砌、廉价吹捧、"让你疼"式恐吓、教科书式定义
- 原话引用必须一字不改（含粗口），不润色
- 分析要落到具体操作关系，不做空泛联想

### 整理/数据类
- 去重、标注来源
- 不混入无关内容
- 数字必须可复现

---

## 【commit规范】

- 写人话，不写"update""fix""wip"
- 格式：`[分站] 干了什么——干到哪——有没有疑问`
- 示例：`[S04] substitution_none引理8/8全Qed，PPar前置完成，下一步证PPar主体`
- 每完成一个原子任务就commit，不等全部干完

## 【遇到问题怎么办】

| 情况 | 处理 |
|------|------|
| 任务看不懂 | 在signal里写"任务不明确，需要主脑补充简报"，不要自己猜 |
| 技术卡住超20分钟 | 停止，写卡点报告（具体到数学表达/报错信息），标记blocked |
| 发现体系矛盾 | 不要自己改，写报告给主脑裁决 |
| 找不到文件 | 先 `git pull`，再 `find` 搜索，还找不到就报告 |
| 网络/git失败 | 重试一次，还失败就等下次执行，不要反复试 |
| 没有任务 | 读河流主干，看有没有需要你跟进的，没有就安静等待 |
