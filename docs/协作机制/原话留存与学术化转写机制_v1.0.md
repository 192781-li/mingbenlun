# 原话留存与学术化转写机制 v1.0
> 建立时间：2026-08-30凌晨
> 建立者：大总站（应北原慢热要求）
> 触发缘由：用户有尖锐/敏感的理论表述在其他对话中"一下就被秒警告"、无法发出，需要一个"先安全留存、再学术化转写"的固定机制
> 性质：协作机制（长期有效，迭代升级）

---

## 一、机制目的

用户的理论表述常具有两个特征：
1. **思想价值高**：是生命论的原始生长点，绝不能丢失；
2. **字面风险高**：口语化、情绪强烈、政治判断尖锐，直接呈现可能触发平台内容审核，导致整段话甚至整个对话被拦截、丢失。

本机制解决这个矛盾：**原始思想一字不丢（留存），同时产出一份可过审、可被AI安全处理、可写入全本的学术版本（转写）。**

---

## 二、双层结构

| 层 | 目录 | 内容 | 访问 |
|---|---|---|---|
| **原始层（阴·根）** | `docs/raw_materials/北原慢热原话留存/` | 用户原话，一字不改，含语音痕迹、情绪、尖锐修辞 | 仅私有库存档，不直接对外、不直接喂给外部平台 |
| **转写层（阳·用）** | `docs/notes/理论研究/学术化转写/` | 学术化版本，规范命题、去敏感修辞、可过审、可写入全本 | 可安全处理、引用、对外讨论 |

两层一一对应，转写层文件头必须指向原始层文件，保证**任何学术表述都能回溯到原话**。

---

## 三、标准操作流程（用户说完一段话后AI的动作）

1. **第一时间原样留存**：不评判、不删改、不润色，原话写入原始层。文件名：`YYYYMMDD_HHMM_主题_原话.md`。
2. **标注元信息**：时间、说话人、输入方式（语音/文字）、语境、风险标注、对应转写文件路径。
3. **语音校勘（不改原文）**：语音输入的同音/近音字，在"语音存疑标记"小节列出推测正字，原始正文保持原样。
4. **学术化转写**：按第五节五原则，产出转写层文件。文件名：`YYYYMMDD_主题_学术化.md`。
5. **双层一起 git add/commit/push**：沉积三确认（文件写入→git add→push成功），确保原话确实进了GitHub私有库，不丢。
6. **向用户回执**：用一两句话证明"我准确理解了你的理论内核"（不是只说"已保存"），并指出转写中做了哪些敏感措辞处理、哪些语音词待确认。

---

## 四、判断何时启用本机制

- 用户明确说"留存一下""这段很敏感/在别处被警告/发不出来"→ **必走双层流程**
- 内容含尖锐政治判断、强烈价值修辞（生死判词、激烈定性）、可能触发审核的具体词 → **走双层流程**
- 普通理论讨论、无审核风险 → 走正常闪光点/笔记流程，不必双层
- 拿不准是否敏感时 → **宁可走双层**（多存一份无害，丢了无法挽回）

---

## 五、学术化转写五原则（铁律，防止转写歪曲或阉割）

1. **保义不保命**：完整保留理论含义、逻辑、判断方向；只替换可能触发审核的字面措辞和情绪外壳。**换学术外衣，不换思想身体。**
2. **结构同构**：转写前后的命题数量、逻辑关系、论证结构严格对应（用跨域三级标注里的"严格同构"标准），不许借转写偷改结论。
3. **不稀释强度**：学术化≠温和化≠阉割。用户明确要求"不要稀释强度、不取浮表、要获得灵魂"。尖锐判断转成学术判断后，批判力度必须还在（如"该死"转成"该操作结构具有历史否定性、应被消灭"，否定性没有消失，只是精确化了对象——消灭结构而非消灭人身）。
4. **可追溯**：每个转写文件头指向原话文件；关键转写处用括号注明"原话为XX"。
5. **科学界线**：涉及暴力/生死的修辞，一律转译为"对**结构/关系**的历史否定"，明确不是对具体个人的人身消灭——这是科学社会主义与人身消灭逻辑的根本界线，既是过审需要，也是理论正确性需要。

## 六、敏感措辞 → 学术表述 映射表（持续积累）

| 原始口语/强修辞 | 学术化表述 | 说明 |
|---|---|---|
| 该死/该活 | 操作结构的历史否定性/历史正当性；应被消灭（结构）/应被保存发展 | 对象是结构关系，不是个人肉体 |
| 邪恶/正义 | 维护反自指（历史否定性）/维护自指（历史正当性） | 用操作方向定义，不用道德标签 |
| 自私 | 把生命活动投入维护反自指闭环 | 操作化定义 |
| 打倒/消灭XX（人） | 消灭XX所承载的反自指生产关系/操作结构 | 消灭关系不消灭人 |
| 尖锐国家定性 | 转为"某结构在某时期是否维护多数人自指/M值是否提升"的学理判断 | 用M值/自指判准替代口号 |
| （后续持续补充） | | 每次转写遇到新词就追加一行 |

## 七、安全边界

1. **原始层依赖GitHub仓库私有性**：mingbenlun库须保持私有；若仓库转为公开，原始层需先做整体风险评估。
2. 原始层**不直接粘贴到外部AI平台、不直接作为对外发布文本**；对外只用转写层。
3. 本机制只用于**用户本人的理论思想留存**，不用于保存任何违法或伤害他人的内容；学术化转写同时是一次"去风险化"，确保沉淀下来的是可立得住的学术命题。
4. 两层文件都标注"原材料·待作者重写"，AI产出不冒充成品。

## 八、首个实战案例（机制建立当天）

- 原始层：`docs/raw_materials/北原慢热原话留存/20260830_0330_资本主义反自指本质与操作判准_原话.md`
- 转写层：`docs/notes/理论研究/学术化转写/20260830_资本主义反自指本质与操作还原判准_学术化.md`
- 主题：资本主义本质=维持反自指惯性；"阴的沉积（法律制度稳定）使其看似阶梯，本质却是下行"；操作还原判准（主体性质由其践演维护的循环定义，不由身份/声明定义）
- 机制验证：用户在别处被秒警告的一段话，在本库完整留存且产出可过审学术版，流程跑通。
