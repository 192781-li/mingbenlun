# 经典溯源对照机制·马恩原文与生命论命题 v1.0
> 确立时间：2026-08-30
> 性质：研究方法机制（不是结论本身，是生产结论的方法）
> 范例1：docs/notes/理论研究/马恩论公有制完整规定性_经典原文摘编_20260830.md（commit c21e6cc）
> 哲学含义：这是"实先于名"在思想史层面的落实——先有生命论从具体经验中长出来的活命题，再去经典中找它的结构同构，而不是先背经典再套命题。经典是依据和校验，不是枷锁。

---

## 一、机制定位（为什么做）

1. **用户（北原慢热）的一切核心观点，马克思恩格斯几乎都有过提法或萌芽**——哪怕用户没有系统读过马恩，两个命题在思想结构上客观同构。
2. 本机制做的是**命题结构对照**，不是**思想影响史考证**：不需要证明用户读过马恩，只需要证明两个命题在结构上同构/相似/超越。这是严谨的思想史方法，不是附会。
3. 目的有三：
   - **给生命论命题提供经典依据**：让每个核心命题都能找到马恩本人的绝对性表达作为支撑，不悬空。
   - **精确标出生命论的发展与超越**：哪些是马恩已有、哪些是马恩有萌芽未展开、哪些是马恩未想清楚或有局限而生命论推进了。
   - **防止两种错误**：①把生命论的新东西倒灌给马恩（"马克思早就说过生命论"）；②因为马恩说过就说生命论只是复述（"这没什么新的"）。

---

## 二、严格的四级对应标注（核心，禁止混淆）

每个生命论命题对照马恩原文后，必须判定为以下四级之一，标注在产物开头：

| 层级 | 判定标准 | 标注用语 |
|---|---|---|
| **L1 严格同构** | 马恩有明确、完整的表述，与生命论命题在核心结构上一致 | "马恩已有明确表述（严格同构）" |
| **L2 萌芽未展开** | 马恩有方向性提法、有概念种子，但未系统展开；生命论把它展开、体系化了 | "马恩有萌芽，生命论展开" |
| **L3 超越/新增** | 马恩未涉及、或触及但未想清楚；生命论提出了马恩没有的新规定性 | "生命论的超越/新增" |
| **L4 修正局限** | 马恩的表述有时代局限或理论缺口；生命论在保留其合理内核的基础上修正了 | "生命论修正了马恩的X局限" |

**铁律**：
- 不允许用"马克思早就说过"一笔带过——必须落到具体篇章节的原文。
- 不允许把L2/L3冒充L1——萌芽就是萌芽，超越就是超越。
- 马恩本人的话、列宁的发展、后人的阐释，三者必须分开标注（如"社会主义＝共产主义第一阶段"是列宁命名，不是马克思本称，见范例1术语澄清）。

---

## 三、操作规范

1. **起点是生命论命题，不是经典**：先把生命论的命题用自己的话表述清楚（它在解决什么问题、核心规定性是什么），再去马恩原文中找对应。禁止反过来从经典出发套生命论。
2. **原文必须精确**：
   - 用中央编译局标准译文（《马恩选集》第2/3版、《马恩全集》中文第1/2版）。
   - 精确到著作名、篇/章/节、写作年份。
   - 能给卷次页码的给，不同版本页码不同时至少给卷次+篇目。
   - 禁止凭记忆编造引文。拿不准的先检索核对（用搜索工具查标准译文），核对通过再写入。
3. **区分作者**：马克思本人、恩格斯本人、马恩合著、列宁、其他后人，分别标注。涉及"社会主义/共产主义"术语时必须做术语澄清（见范例1〇）。
4. **每个命题一份独立摘编**，放在 `docs/notes/理论研究/经典对照_<命题简称>_<日期>.md`。
5. **总索引**：所有对照产物登记到 `docs/notes/理论研究/经典对照总索引.md`，按命题名、层级、马恩出处、完成日期登记。

```

> 生命论命题表述：（用生命论自己的话，一句话说清核心规定性）
> 对照日期：YYYY-MM-DD

## 一、马恩原文（按主题分条，每条精确出处）
### 1.1 <子主题>
> "原文……"
> ——马克思/恩格斯《著作名》篇/章/节（年份），《马恩选集》第X卷

## 二、对应分析（简短，不发挥）
- 哪些是马恩已有（L1部分）
- 哪些是生命论展开/超越（L2/L3/L4部分）
- 马恩的局限或未想清楚之处（如有）

## 三、术语澄清（如涉及易混术语）
（如"社会主义"命名权、"异化"在不同文本的含义差异等）

## 四、对全本的用途
- 本对照可用于全本卷X篇X的哪一节，作为经典依据
```

## 六、与全本写作的衔接

1. 全本每一卷的核心命题，原则上都应有一份经典对照摘编作为依据层。
2. 全本正文引用马恩时，直接引用对应摘编中已核对过的原文，不再临时凭记忆写。
3. 全本正文中涉及"马克思说过X"的表述，必须能在经典对照总索引中找到对应条目；找不到的，要么补做对照，要么改写为"生命论认为"（不挂马恩的名）。
4. 这是"引原话引原文"工作原则的制度化延伸。
