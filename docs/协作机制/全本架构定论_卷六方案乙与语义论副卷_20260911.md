# 全本架构定论（一）：卷六"方案乙"与语义论副卷的位置

> 定稿日期：2026-09-11　性质：**架构定论，各分站（S00/S01/S04/S05…）与一切新对话一律遵循，不再发起"是否拆分卷六""是否升格语义论"的重复讨论。** 若将来作者本人明确改判，以作者最新原话为准，并回改本文件、`manifest.json`、对应卷标题三处。

## 定论一：卷六《异化论》采用"方案乙"——内分上下两篇，不另立卷

卷六是全本唯一在一卷之内分上下两篇的卷，**不拆成两卷、不新增卷号**。

- **上篇·政治经济学批判**：篇零至篇三。顺着"商品—价值—货币—资本—剩余价值—积累—再生产—平均利润—价格—金融—增长—分配"的范畴链条严密推演，把被冻成"永恒规律"的东西还原回历史地发生的操作关系。
  - 篇一/篇二/篇三各带"之X"子篇（如篇一之二劳动价值论正面奠基、篇二之二再生产与危机、篇三之二至之六价格/金融/增长/分配/企业家神话拆解）。
  - 另设 `00_篇零`（市场拜物教终审）、`00a_篇零之二`（理性经济人终审）与 `00_上篇` 扉页。
- **下篇·异化形态批判**：篇四至篇十二。从反自指展开的一般机制（窃权、锁死、遮蔽、耗散、负反馈、崩溃）出发，看它如何蔓延到反抗收编、数字技术、自然、世界体系（帝国主义）、生命政治、被异化的良善、辩经术与历史复辟（大跃退）。
- 扉页顺序由构建脚本硬性校验：**卷标题 → 上篇扉页 → 篇零 → …… → 下篇扉页 → 篇四 → …… → 篇十二**。

一句话：**上篇拆"资本的范畴"，下篇拆"异化的世界"，合起来才是完整的异化论。**

## 定论二：语义论是"13_副卷"，暂不升格为第十二正卷

- 语义论目录号为 `13_副卷_语义论`，与十一正卷并列、但**不同位**：它是衍生的、服务性的，工作是为第一哲学清理语言地基，保证正卷核心概念（操作、在感、感应、异化、明性）都经过语义校准。
- **暂不升格为第十二正卷。** 它主要服务于正卷建构，将来可不断扩充语义专篇；是否、何时升格，只有作者能拍板。
- 不要因它"发生史上最早"就主张它应居正卷前列：发生次序与叙述次序是两件事。其发生学链条为：**爱 → 痛苦 → 语义论的不自觉实践 → 旧惯性论 → 缄默意识 → 生命论 → 新惯性论。**

## 权威数据源（改结构只认这三处，且必须同步）

1. `生命论_模块化/manifest.json`——**卷级唯一数据源**（卷目录、卷号、卷名；卷六与副卷的架构注记也写在这里的 `note` 字段）。
2. `生命论_模块化/manifest.txt`——**合订本收录清单**，按 `build_combined_book.py` 的 `chapter_sort_key` 排序、路径为仓库真实路径；2026-09-11 已按磁盘事实整体校准（此前是 08-27 旧快照，漏卷六全部子篇、漏整个副卷、附录为旧名）。
3. 各卷 `00_卷标题.md` / 副卷 `00_副卷标题.md`——卷内总纲与上下篇说明。

> 合订本由脚本**直接扫目录**构建，不靠 manifest.txt 决定收录；但任何 AI/人对照全本结构时以 manifest 为准。**新增、改名、移动任何篇，必须同步 manifest.txt，否则清单失真。**

## 对各分站的硬约束

- **跨卷引用一律用卷名+"卷"（如"异化论卷""存在论卷"），不用卷号**；卷号只在 manifest 与卷标题出现。旧材料里的"旧九卷"编号按《全本结构审查与重组方案》的映射换算（旧卷二认识→卷三、旧卷四异化→卷六、旧卷五解放→卷七、旧卷六实践→卷四、旧卷七格物→卷八、旧卷八人文→卷九、旧卷九术数传统→卷十）。
- 描述人的操作用"**扬气**"，不用"扬弃"；"扬弃"仅限认识论事后描述，操作论层面非法（生命不能被生命以外的主体操作）。卷十篇四为"儒家的**扬气**"。
- 明性 = F3 反身自觉、不常驻，不与 F1 在感、F2 生命之光混用。
- 卷六篇序、副卷归属有疑问时，回到本文件与三个权威数据源，不凭记忆、不另起炉灶。
