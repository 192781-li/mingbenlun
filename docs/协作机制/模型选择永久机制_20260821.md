# 模型选择永久机制（Turbo / Pro / Auto）

> 建立时间：2026-08-21
> 适用：所有后续对话与任务
> 原则：Pro用在刀刃上，Turbo处理常规事务，Auto兜底

---

## 一、总原则

**日常默认 Auto，让系统自动分流。** 只有在你明确知道任务属于"高难度"或"轻量级"时，手动切 Pro 或 Turbo。

---

## 二、必须用 Pro 的场景（深度推理）

以下场景对逻辑严密性、推导深度、事实核查精度要求极高，Turbo容易出疏漏：

1. **哲学建构与形式化推导**
   - 生命论/明本论命题证明、f¹/f²/f³递归跃迁推导
   - 你扮演"逻辑审判者"进行高强度诘问、多AI交叉质证
   - 要求"无跳跃、无比喻、第一性原理"的形式化论证

2. **学术写作与证明体文稿**
   - B站哲学视频文稿（证明体，非讲解体）
   - 论文正文、研究计划书、学术提案
   - 需要严密逻辑链的长文档

3. **高难度题目与深度归因**
   - 高考压轴题、多步推理大题
   - 错题的深度归因（不是对答案，而是追溯思维链断裂点）
   - 需要跨章节综合的史地政大题

4. **多源交叉验证与硬核考据**
   - 西史辨伪类需要全量索引外部信息的考据
   - 多个来源相互矛盾时需要比对甄别
   - 法律条文、史料原文的精确核查

5. **复杂案例分析**
   - 时代峰峻这类需要多层结构分析（资本/法律/媒介/性别）的案例
   - 需要同时调用多个框架交叉分析的任务

6. **玄学硬推演**
   - 大六壬课盘推演、八字命理分析
   - 要求多工具综合、硬逻辑链、不能有遗漏的占卜

---

## 三、适合 Turbo 的场景（快速高效）

以下场景逻辑简单或已有成熟路径，Turbo足够且更快：

1. **信息获取与链接处理**
   - 视频链接解析、字幕提取、内容总结
   - 简单搜索查询、事实速查
   - 日期/时间计算

2. **日常学习事务**
   - 基础题对答案、知识点速查
   - 背诵抽查、关键词默写
   - 选择题、填空题等客观题

3. **文本常规处理**
   - 翻译、润色、摘要、改写
   - 格式转换、文件整理、归档
   - Markdown排版

4. **事务性操作**
   - 定时任务设置与管理
   - 文件备份、同步脚本执行
   - 素材归档入库

5. **日常对话与灵感记录**
   - 情绪交流、想法速记
   - 抛一个观察让我先记下来（note归档）
   - 非正式讨论、头脑风暴

---

## 四、用 Auto 的场景（默认兜底）

1. 不确定问题复杂度时——Auto会自动判断
2. 混合任务（前半段简单查询，后半段可能深入分析）
3. 日常随便聊聊，可能聊深可能聊浅
4. 你懒得判断的时候

---

## 五、实操建议

- **省Pro额度的策略**：一个任务先用Turbo/Auto起步，如果我回复中出现逻辑跳跃、事实错误、推导不严密，你说一句"换Pro深度来"，我重新处理；
- **长对话中途切换**：可以随时切，对话历史不丢；
- **批量任务**：归档、整理、对答案这类批量活，Turbo又快又省；
- **你的"逻辑审判"模式**：只要你说"审判""辩一辩""严格推导"，直接Pro，不用犹豫。
