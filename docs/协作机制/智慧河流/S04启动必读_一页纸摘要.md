## 一、你在干什么（一句话）

你在证明`substitution_general`定理——**同一个类型的操作权，可以从一个位置挪到另一个位置，进程不关心位置只关心类型**。这是整个类型系统的基石（代换保类型）。

## 三、悟道书核心（操作权流动视角）

你不是在写Coq代码，你是在**用类型论描述操作权的流动**。

- **上下文不是类型列表，是操作权的分布**：Some T=有操作权，None=已消耗
- **use不是逻辑关系，是操作权的消耗**：get是前置条件，set_none是后置状态
- **代换不是语法替换，是操作角色的转移**：操作权按类型区分，不按位置区分
- **绑定器是新世界的入口**：进入新作用域，所有坐标后移一位（S m, S k）
- **卡住时问**：操作权在哪？从哪来？到哪去？中间经过了什么？

## 四、8条智慧结晶（证明前必读）

1. **弱引理比强引理易证**——不要证上下文等式，证get等式
2. **重写比硬推有效**——同一个实在有多种描述，rewrite揭示同一性
3. **绑定器下代换参数同步偏移**——PRes/PIn里用(S m, S k)
4. **从简单case到复杂case**——PZero→PTau→PRes→PIn→POut
5. **证不出来怀疑定义本身**——subst_var bug教训
6. **5分钟熔断**——不闷头死磕，卡住就记录状态
7. **用rewrite代替subst**——subst是暴力替换会丢Gamma，rewrite是有方向的变换
8. **能贯穿就贯穿**——S01已经给了完整策略，照着写，不要自己摸索

## 五、OB-008解决的关键（PRes模板）

**问题**：`inversion Ht; subst.`把Gamma替换掉了，IHQ用不了。

**解决方案**：
```coq
apply res_elim in Ht.        (* 不用inversion！用res_elim引理拆开 *)
destruct Ht as [T0 H1].     (* Gamma还在！ *)
rewrite insert_at_cons_comm in H1.  (* Some T0::insert_at k T Gamma → insert_at (S k) T (Some T0::Gamma) *)
apply ty_res with (T := T0).
exact (IHQ (S m) (S k) T (Some T0 :: Gamma) H1 Hget').
```

**PIn = 这个模板前面加一个use关系的处理。POut = 这个模板去掉绑定器，加第二个use。**

## 六、OB-007核心（use关系代换）

use代换需要两个分量：
1. **get分量**：和PVar完全一样，分x=k/x<k/x>k，用get_insert_at_lt/gt
2. **set_none分量**：需要set_none_insert_at_lt/eq/gt三个引理

**先证这三个引理**，PIn和POut就通了：
```coq
set_none_insert_at_lt : x < k → set_none (insert_at k T Gamma) x = insert_at k T (set_none Gamma x)
set_none_insert_at_eq : set_none (insert_at k T Gamma) k = insert_at k None Gamma
set_none_insert_at_gt : x > k → set_none (insert_at k T Gamma) x = insert_at k T (set_none Gamma (x-1))
```
