### 02_研判（S01，2026-09-02 15:00，commit 5dc55fa）
- **本质**：PRes类型规则是typed (Some T :: Gamma) P → typed Gamma (PRes P)，inversion后insert_at被::包在里面
- **核心引理insert_at_cons_comm**：
  ```
  Some T' :: insert_at k T Gamma = insert_at (S k) T (Some T' :: Gamma)
  ```
- **证明三步策略**：
  1. res_elim拆开PRes，得到typed (Some T' :: insert_at k T Gamma) Q
  2. rewrite insert_at_cons_comm，恢复为insert_at (S k) T (Some T' :: Gamma)
  3. apply IHQ，参数(S m, S k)，正好对应subst_var在PRes下的定义
- **哲学**：绑定器创建新局部世界，代换在绑定器下坐标偏移；世界扩展(::)和资源插入(insert_at)可交换
