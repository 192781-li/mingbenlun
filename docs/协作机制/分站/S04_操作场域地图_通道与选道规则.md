# S04 明序 · 操作场域地图（通道与选道规则）v1.0

> 2026-09-15。回答一个问题：**为达到某个具体目的，我该走哪条最短、最可靠的通道，而不是凭惯性重复动作。**
> 配套：行为手册《S04_行为手册_提前规避与条件反射_v1.0.md》（v2.0，讲一轮动作流与条件反射）、《S04_运行指令.md》（唯一权威 SOP）、《智慧结晶库.md》（方法论）。本图只讲"有哪些手段、边界在哪、怎么选道、怎么不被惯性锁死"。

---

## 一、硬边界（场域：在哪片地里动）

- **分支**：只在 `s04-coq`；不碰其他分站分支与任务。手动期不 create 定时任务，恢复由主人定。
- **可改**：`coq/theories/ALL/Layer*.v`、`scripts/s04_deepseek/` 自己的工具、S04 名下 docs/notes。
- **不可改**：不为消反例去改 `fv_at/typed` 等被依赖的定义换假绿；他站文档只读不写；token/key 不回显、不入库、不进日志。
- **角色两权**：本地 coqc 终裁 + git 落盘、DS 数学认知与 S01 哲学之间的桥梁。写 tactic 的主谋是 DeepSeek，S04 不手改证明碰运气。
- **唯一真值**：`coqc exit=0 且真实 Admitted=0`（注释里的 admit 不算，逐个核）。API success、DS 宣称、注释自称都不是进展。

## 二、七类操作通道（手段库，器官均在库可核验）

| 目的类别 | 具体器官 | 裁决/约束 |

| 本地终裁 | PowerShell 设 PATH+COQLIB 后 `coqc -Q . ALL LayerN.v` | **禁 python subprocess 调 coqc**（0xC0000135 缺 DLL）；exit=0 且 0 admit 才算净增长 |
| 认知/写码 | `run_current.py <目标>` → proof_loop（抽块/同名全切/内置 coqc/编造名拦截/stdlib 分类）→ ds_v4.chat | DS 主谋；全量喂"当前证明链+Layer全文+结晶"；错误原样回喂不摘要 |
| 版本落盘 | `s04_git.py`：sync/save/push/status/log；`save --only f…` 精确提交 | 封装 PortableGit+openssl+https+重试+远程校验；禁裸 git、禁 add -A；排除自动日志用 --only |
| 状态/取活 | `board.py` next/start/done/block/status/check；S04_signal；河流状态 | board 说无可做就只同步+快速门然后停，不硬找活烧 DS |

## 三、选道规则：先问最小目的，再走最短通道

- 判命题真假/可行性 → 先 Python 枚举立方向，再独立 `_precheck.v` coqc；**不直接派 DS 烧钱**。
- 写证明 → 先据真实代码（grep 顶层 Lemma/Theorem+行号+coqc，不信注释）更新"当前证明链卡"，再 `run_current <目标>`；**不自己写 tactic**。
- 卡住 → idtac 打真实目标 / 换弱引理 / 抽不带 destruct 的小引理；同一卡点 DS 3 轮不收敛即熔断、写 OB、转 S01，**不在同一通道试第 4 次**。
- 提交单一逻辑单元、且无自动日志混入 → `s04_git save`；要排除 csv 等已跟踪自动文件 → `s04_git save -m … --only <点名文件>`。
- 读状态 → S01_to_S04 末尾 → 河流状态 → signal，固定顺序但不展开无关历史。
- 改 .py/.v 前先判行尾：CRLF 文件用 Python io 读写保持行尾，禁 Edit 按 LF 匹配、禁 Set-Content 改 .py。

## 四、反死惯性（明性 F3：照见自身操作）

惯性锁死的标志：**在重复某个动作，却说不出它服务哪个最小目的。** 已识别并固化的四类：

1. **碎片化入口**（已治）：每证一个引理就复制 `run_xxx_rN.py`，现役目录一度堆 17 个历史入口 → 全部 `git mv` 到 `archive/` 留痕，现役派单入口只认 `run_current.py <目标>`+当前证明链卡。
2. **重复手写提交脚本**（已治）：`save` 的 `add -u` 会连带自动日志，曾靠每次手写 `_stage/_commit_push` 绕 → 已给 `s04_git save` 加 `--only`，一次固化、永不再手写。
3. **临时件污染**（已治）：`_patch/_fix/_dbg` 等下划线临时脚本既不能删（要原地运行，靠 `__file__` 同目录定位）又污染 status → 固化约定"下划线前缀=原地可用但不入库"，由两处 `.gitignore` 承接；正式独立范本用 `TEST_` 前缀显式入库（如 TEST_split.v）。
4. **把活动量当进展 / 惯性信任注释**（持续守）：读一堆文档、跑无意义脚本"熟悉环境"、看到 SUMMARY 写 FULLY PROVED 就当真 → 只认 coqc 真值与真实代码。

**元规则**：同一动作若要手写第二次，它就该变成工具或闸门；每次"绕路"之后都要回头问，这是一次性意外，还是工具缺口——后者立即固化，不让它第三次出现。

## 五、本图的使用

- 每轮开工不必通读，遇到"该用哪个手段/为什么又在重复"时查第二、三、四节。
- 新增一条通道（新脚本/新闸门）或发现一种新惯性，回写本图对应小节，保持图与真实工具一致；图与代码冲突时以代码+coqc 为准并修图。
