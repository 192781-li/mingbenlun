## 每日强制对账 SOP（防 L037 复发：沉积记录必须被活实际强制回写）
1. **定时任务对账**：用 `list_cron_jobs`（enable=true/false 各一次）取平台真实任务，导出快照后跑
   `python3 scripts/network_reconcile.py --only registry --cron-snapshot <快照.json>`，
   有幽灵ID/状态不符/漏登立即以平台为准回写注册表，不允许副本与平台长期不一致。
2. **结晶与分支对账**：`git fetch` 后跑 `python3 scripts/network_reconcile.py --fetch`，
   查结晶跨分支同号异义、main 编号连续、各分支领先/落后、分站档案完整性；ERROR 必须当日处理。
3. **主干汇合**：在 main 上 `bash scripts/river_sync.sh pull`，从六个分站多分支汇合河流
   （结晶同号异义会被拦截、不自动合并，须 S00 裁决：分支用临时号、合 main 由 S00 发正式号）。
4. 对账结论与处理写入运行台账；只检测报告、不自动改事实，裁决权在 S00/人。
