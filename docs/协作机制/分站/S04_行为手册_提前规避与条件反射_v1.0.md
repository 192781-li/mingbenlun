## 二、一轮动作流（照此顺序，每步带闸）

### 开工
1. 取系统真实时间定位（不靠上下文猜）。
2. `python scripts/s04_deepseek/s04_git.py sync`（绕 SSH22/schannel，禁 PowerShell 裸 git）。
3. 读状态按序、不展开无关：`S01_to_S04.md` 末尾 → 河流状态 → S01_signal pending → 智慧结晶库。
4. `board.py next` 取活。**回"无可立即开工工序"就只做同步+preflight 快速门+查 pending，然后停，不调 DS、不硬找活**（铁律7）。

### 喂 DS（核心，见第三节）
5. 新引理派 DS **前**过【派活前预检门】：独立 `_precheck_*.v` exists 出满足全部前提的最小 ctx 并 coqc；专走边界格（空表/越界 None/在位空 Some None/长度错位）找反例。过不了=陈述假或过强，改陈述不派 DS（铁律8，结晶018/022）。
6. 确认**当前证明链卡**在位（第三节），`python run_current.py <目标>`。pro/thinking、max_tokens≥32000、全量喂（L1+2+3 全文仅占 1M 窗口 4.9%，裁上下文是返贫，结晶013）。
7. DS 回来先过三关再谈并入：①引用名机械比对全集，查无=编造，不改文件原样回喂（结晶015）；②外部定理四分类 @prove/@stdlib/@cite/@axiom（Axiom 预算0）；③DS 称"假"必走证伪双门，自然语言无权改判（结晶016）。

### 终裁
8. 小引理先在独立 `TEST_*.v`（铁模板文件头 + Require ALL.Layer1/Layer2 + Import ListNotations）coqc exit=0，再 CRLF 安全并入正式 Layer。
9. 整层 `coqc -Q . ALL LayerN.v`，看 `$LASTEXITCODE=0` 且真实 Admitted=0（注释里的 admit 不算，逐个核过）。**只有真实 Qed 算净增长，API success 不算。**
10. 一 J 一 commit；红则**完整错误原样回喂**（不摘要不改写），最多 5 轮；同一卡点 3 轮不收敛即熔断（第五节）。

### 回写与提交
11. `preflight.py --deep` 封板（分支/真实占位/危险文件/双门在岗/离线三连自检），红灯不提交。
12. 回写：S04_signal、河流主干/状态、DeepSeek干渠（有调用必记）、OB（若有）、**反身思考落盘成文件**（不只写 commit message）、可复用经验追加结晶并同步进 DS 入口。
13. `output_guard.py check-stdin` 过输出硬闸；`s04_git.py save -m "S04: Jx … Qed净增长" 显式文件`（**禁裸 git add -A**）。
14. 五行输出：进展 / 编译+Admitted数 / DS轮次费用 / commit hash / 需要 S01或主人。

## 三、DS 一体化 · 当前证明链（治"睁眼瞎"，v2.0 核心）

**病根**：不是没给 DS 智慧，而是最高智慧被重复灌（结晶库在 system 和材料层各一次）、当前路径被一堆**已收官战场**的旧研判淹没，却没人给它"当前目标→已 Qed 零件→依赖序→死路"的一条最短链。DS 要在上百个引理和旧文档里自己捞路 = 睁眼瞎。

**机制（每轮强制）**：
1. 开工任何新目标前，S04 先据**真实代码**（grep 顶层 Lemma/Theorem + 行号 + coqc，不看注释许愿）填一张《当前证明链_<目标>.md》，模板=`_模板_当前证明链.md`。六块：一句话现状 / 目标与最简依赖 DAG / 逐构造子施工表（每个分支点名用哪个**已 Qed** 零件+行号）/ 已 Qed 零件清单（直接 apply 禁重证）/ 死路禁行 / 工序验收。
2. run_current 喂 DS 的材料 = ①system 铁律+结晶库（最高智慧全量、稳定前缀保缓存）②Layer 全文（权威）③**当前证明链卡（当前唯一路径，最靠后最相关）**④仅与当前目标相关的通用哲学；**已收官战场的旧研判不再每轮灌**（文件留库不删，只是不塞进上下文）。
3. 证明链卡随目标推进更新；目标 Qed 即归档换下一张。DS 每轮先读链卡再读全文。
4. 每张链卡必须标注：注释与代码不一致处（如旧 SUMMARY 自称证过其实没证）、空真分支、唯一缺口零件——把"DS 最容易绕远/踩空"的点提前钉死。
5. 链卡是路线不是证明；最终对错仍以 DS 出码、coqc 终裁为准。

> 首张范例：《当前证明链_subject_reduction.md》——已坐实唯一缺口是 congruence_preserves_typing，red_comm 靠 no_parallel_channel_sharing 空真 exfalso，旧备份 backup_9.0.1/Layer2.v 218-251 有六分支骨架。DS 拿到即可按 J1→J2→J3 施工，不必在 158 个引理里边猜。

## 四、决策瞬间速查（条件反射，只留最易踩的）

| 瞬间 | 第一反应 | 依据 |
|---|---|---|
| rewrite/cbn 失配超3轮 | `match goal with[|-?g]=>idtac "T=" g end` 打**真实目标**；依赖等式的化归抽成"带假设不 destruct"的小引理 | 021 |
| `destruct (f..) eqn:E` 后 rewrite E 报 no subterm | destruct 替换了定义体里的同名 f；化归移出 destruct | 021 |
| DS 质疑命题真假/三轮不收敛 | 先 Python 有限枚举（option 三态/短列表/边界长度）立真假方向：0 反例=问题在路线非真假。枚举是探测器不是证明 | 022 |
| 强引理（整结构相等）证不出 | 只需要某 get 分量相等就换弱引理 | 001 |
| inversion 后 IH 用不上 | 先用交换/重写引理把前提变回 IH 要的形式 | 002 |
| `subst.` 消没了要用的变量 | 改 `rewrite <- Heq` 精确局部变换 | 007 |
| 进绑定器 PIn/PRes | 代换参数同步 S 偏移；induction 前先 revert 递增下标 | 003/021 |

### tactic 级工艺（都被 exit=0 固化过，一行一条）
- `cbn [f]` 只展 f；要"展外层不 zeta"用 `cbn beta iota delta [f]`；rewrite 常数等式前先 `Opaque f.`。
- 递增下标 Fixpoint：induction 前 revert 下标；合取分量用 `destruct as [a b]` 不用 `.1/.2`；`Nat.sub _ 0` 用 `rewrite Nat.sub_0_r`；多前提 apply 用 `with(形参名:=..)`。
- option(option ty) 三态分清：None 越界 / Some None 在位空位 / Some(Some T) 真实发用，两种寂不跨层。

### Windows 文件工艺（踩过的雷，照做）
- Layer2.v/run_current.py 是 **CRLF**：Edit 按 LF 匹配必失败；用 Python `io.open(encoding='utf-8')` 读成 `\n` 匹配，写回 `.replace('\n','\r\n')`+`newline=""`。改 .py 禁 Set-Content（毁 UTF-8）。
- **禁 python subprocess 调 coqc**（0xC0000135 缺 DLL）；必须 PowerShell 并先设 PATH+COQLIB 指向 Rocq 9.1。
- Layer3.v 中文注释有编码错配，触碰前先探编码+备份+Python 按真实编码读写。改坏 Layer2：`git checkout -- coq/theories/ALL/Layer2.v`。

## 五、熔断与红线

**熔断（5分钟/3轮无进展）**：写 OB（目标/前提/已试/失败原文）→ 向定时任务网络配置 task_queue 注入 assigned_to=S01 的 **urgent** 任务（不能只在自己 signal 写 needs_s01，铁律11）→ 切看板上另一个依赖就绪的 J，不闷头死磕。

**红线（碰即停，每条都是真实事故）**
1. 不绕过 coqc、不用自然语言宣布真假或完成；不盲信 DS/S00/S01 的数学结论（"m≥k 单射"曾为假）。
2. 不手写 tactic、不手改证明碰运气（用户当场特许的单次手动例外除外）。
3. 不把 API success/HTTP200 当进展；不在没预检时把新引理丢给 DS 烧钱。
4. 不回潮已证伪死路；不为消反例改 fv_at/typed 等被依赖的定义。
5. 不裸 git add -A、不手敲 push、不 PowerShell 裸 git、不 python subprocess 调 coqc。
6. 不用 Edit 改 CRLF、不用 Set-Content 改 .py。
7. 不碰他站分支/任务；删定时任务前三重确认；**当前手动模式严禁 create_cron_job，恢复由用户决定**。
8. 不输出"完美/绝对/彻底/必然/100%"等无数据支撑词与元话语铺垫（output_guard 硬拦）；明性 F3（反身自觉）不与生命之光 F1/F2（向外照亮）混用。
9. 不读无关文档/不跑无意义脚本"熟悉环境"，看板说停就停。

## 六、错误怎么"只犯一次"

- **A 类（可规则化的工艺/行为/已知死路）**：写成"不过闸无法继续"的脚本检查（proof_loop/falsification_guard/preflight/output_guard），趋近零犯；再犯=机制漏了，去补机制，不写"下次注意"。
- **B 类（全新命题判真假/强弱/可行性）**：上游派活前预检门证真、下游证伪双门验伪，对称夹逼；第一次出现的 B 类错不叫事故（要求零试错=不做数学，结晶018）。
- 每个新错当场三选一归宿：**能检查→进闸门脚本；是证明模式→写结晶并同步进 DS 入口（run_current/s04_context/证明链卡）；是哲学真假命名→OB+转 S01。**
- 通用卡住第一反应四件套：idtac 看真目标 / 最小论域枚举立真 / 切弱引理 / 3 轮熔断换道。
