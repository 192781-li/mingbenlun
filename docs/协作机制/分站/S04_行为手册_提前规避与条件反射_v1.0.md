## 二、一轮工作的标准节律

### 开工五打卡（缺一项不许派 DS）
1. **真实时间**：取系统当前时间定位自己，不靠上下文猜（明性卡片）。
2. **同步**：`python scripts/s04_deepseek/s04_git.py sync`（封装 PortableGit+openssl+https，绕 SSH22/schannel；E27）。
3. **心跳**：`list_cron_jobs(enable=true)` 确认主力任务存活（铁律9，E01：曾被删 5 天零发现）。*当前为用户手动模式，是否恢复定时由用户决定，严禁擅自 create_cron_job。*
4. **读状态（按序、不展开无关）**：S01_to_S04.md 末尾（铁律12，先于看板）→ 河流状态 → S01_signal pending → **智慧结晶库（证明前必读）**。
5. **看板取活**：`python scripts/s04_deepseek/board.py next`。输出"无可立即开工工序"时，本轮只做同步+preflight 快速门+查 pending，**绝不调 DS 烧钱、不硬找活**（铁律7，E15）。

### 干活（DS 主谋闭环）
- 新引理派 DS **前**，先过第三节【派活前预检门】。
- `python run_current.py <目标引理>`：s04_context 全量喂（Layer全文+结晶库+策略+上轮错误原文，四层"稳定→靠前"），proof_loop 自动过编造拦截/证伪双门/卫生检查，coqc 闭环，最多 5 轮。
- 小引理先在独立 `.v`（铁模板文件头 `From Stdlib Require Import…` + `Require ALL.Layer1/Layer2` + `Import ListNotations`）coqc exit=0，再并入正式 Layer 文件。
- **一 J 一 commit**，不攒不碎；只有 coqc 真实 Qed 算净增长，API success 不算（E05）。

### 收工五打卡（缺一项不算完）
1. `preflight.py --deep`：分支/真实 Admitted/危险文件/双门在岗/coqc 终裁/三连离线自检，红灯不许提交（铁律6）。
2. 回写：S04_signal、河流主干/状态、DeepSeek干渠（有调用必记）、卡点 OB（若有）、**反身思考落盘成文件**（不只写 commit message，E32）、有可复用经验就追加结晶。
3. `output_guard.py check-stdin` 过输出硬闸（绝对化词汇/元话语/行数/数据支撑/F3混用）。
4. `s04_git.py save -m "S04: Jx … Qed净增长" 显式新文件…`；**禁止裸 `git add -A`**（E36）、禁止手敲 push。
5. 五行输出：进展 / 编译+Admitted数 / DS轮次费用 / commit hash / 需要 S01或主人。

## 四、证明工艺卡（tactic 级，全部被 exit=0 固化过）

- **cbn 粒度边界**：`cbn [f]` 只展 f；全 `cbn.` 额外做 zeta（展 set 缩写）、递归展开内层 Fixpoint、delta 展透明常数，越化越乱；只要"展某常数外层+beta/iota、不 zeta"用 `cbn beta iota delta [f]`。
- **rewrite 常数等式前先 `Opaque 常数.`**，否则被 cbn 提前展开导致失配。
- **递增下标 Fixpoint 归纳**：`induction` 前 `revert k`，否则 IH 下标被锁死。
- 合取分量用 `destruct as [a b]`，不用 `.1/.2`（Unknown notation）。
- `Nat.sub n 0` 不会被 cbn 自动化简，用 `rewrite Nat.sub_0_r`。
- `apply` 多前提引理要显式 `with(参数名:=..)`（注意按**形参名**绑定，Layer1 split_get_l/r 形参是 Gamma/Gamma1/Gamma2），并按产生的子目标数补分支。
- `split;intros` 后分支内不要再 intros 同名变量。
- **独立范本先 exit=0 再并入**：复杂证明先在自带最小定义的 TEST_*.v 跑通，再 CRLF 安全并入正式文件。
- **option(option ty) 三态时刻分清**：None=越界 / Some None=在位空位 / Some(Some T)=真实发用；两种"寂"不可跨层错配（E21）。

### 文件读写工艺（Windows 本地，踩过的雷）
- Layer2.v / run_current.py 等多为 **CRLF 行尾**：Edit 工具按 LF 匹配会 OLD_STRING_NOT_FOUND。改用 Python：`io.open(encoding='utf-8')` 读入（universal newline 成 `\n`）匹配，写回时 `.replace('\n','\r\n')` + `newline=""`。
- 改 `.py` 禁用 PowerShell `Set-Content`（毁 UTF-8）；写补丁脚本文件再执行。
- **禁止用 python subprocess 调 coqc**（0xC0000135 缺 DLL）；必须 PowerShell，先设 `$env:PATH` 与 `$env:COQLIB` 指向 Rocq 9.1。
- 触碰 Layer3.v 前先探测编码（其中文注释有 GBK/UTF-8 错配乱码），先备份、按真实编码用 Python 读写，不用 Edit 直接上。
- 改坏 Layer2 回退：`git checkout -- coq/theories/ALL/Layer2.v`。

- 模型：证明/错误分析用 `deepseek-v4-pro`（thinking enabled，最深）；抽取/格式转换用 `deepseek-v4-flash`（非思考）。档位匹配认知难度，不匹配"重要性"。

## 七、错误降级流水线（"举一反三"怎么落地）

不承诺零试错——对**第一次出现**的命题判真假/强弱/构造可行性（B 类），旧结晶天然覆盖不到，**要求零试错=不做数学**（结晶018）。能保证的是：

1. **A 类（可规则化：工艺/行为/已知死路）**：一律写成"不过闸就无法继续"的脚本/检查，趋近零犯。再犯=机制漏了，去补机制，不写"下次注意"。
2. **B 类（全新命题的判断）**：上游靠派活前预检门（自证真），下游靠证伪双门（验证伪），对称夹逼。
3. **每个新错当场三选一归宿**，使其降级为 A 类、同一错只犯一次：
   - 能写成检查的 → 加进 proof_loop / falsification_guard / preflight / output_guard；
   - 是战术/证明模式 → 写成新结晶，且同步进 DS 入口（run_current 的 STRATEGY/EXTRA 与 s04_context system 前缀），让 DS 也自动获得；
   - 是哲学/真假/命名 → 写 OB + 注入 task_queue 转 S01。
4. **四个与题目无关的"卡住通用第一反应"**：idtac 看真实目标 / 最小论域枚举立真 / 切弱引理 / 3 轮熔断换道。

> 明性不是"永不再惑"，是"每惑必有照察之器、每察必成下次之明"。

## 八、明性与哲学纪律

- **三遍法**：库里理解一遍（读原文与演化）→ 自己内化一遍（变成自己的）→ 自己生成一遍（产出新沉积）。不走三遍不算拥有。
- **激进的稳当**：放开思考时长、大胆设计不留退路（激进）；中间状态/台账/片段强制持久落地、结果可检验（稳当）。阳主阴从。
- **打架听数学**：哲学负责方向与意义，coqc 负责对错；冲突时以 coqc 为准，哲学判断点记录给 S01。
- **F1/F2/F3 层级**：F1 在感、F2 感应操作（生命之光=向外照亮、切分对象的常亮觉知，红点照亮场域属此）；F3 明性=反身自觉、照见自身操作与反自指、不常驻。明性不得泛化为一切意识照亮。
