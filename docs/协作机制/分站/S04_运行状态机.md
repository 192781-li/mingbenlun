## 三、经验教训库

### 3.1 DeepSeek使用经验

#### 经验1：给全库资源，不要只给局部代码
- **错误做法**：只给DeepSeek局部代码，让它猜上下文
- **正确做法**：给DeepSeek全库相关资源（Layer1.v、Layer2.v、哲学公理、定理注册表、形式化方向建议），让它自己思考、自己判断
- **时间**：2026-09-01 确认

#### 经验2：编译错误原样回喂，一个字都不要改
- **错误做法**：自己分析错误、自己修改证明、自己猜DeepSeek的意图
- **正确做法**：把coqc的完整错误输出（包括行号、字符位置、错误信息）原样复制给DeepSeek，让它自己分析、自己修复
- **时间**：2026-09-01 确认

#### 经验3：不要替DeepSeek思考
- **错误做法**：我先分析证明策略，然后告诉DeepSeek怎么做
- **正确做法**：DeepSeek是研究员，我是打工的（编译验证）。DeepSeek自己思考、自己判断、自己解决，我只负责编译验证和错误回喂
- **时间**：2026-09-01 用户明确强调

#### 经验4：DeepSeek有资格获取全库智慧
- **错误做法**：限制DeepSeek只能看到局部代码，怕它"乱"
- **正确做法**：DeepSeek有资格获取全库的所有资源和智慧，包括哲学公理、定理注册表、形式化方向建议、历史讨论等
- **时间**：2026-09-01 用户明确强调

### 3.2 Rocq 9.0编译经验

#### 经验5：bullet（- + *）在Rocq 9.0中可用，但前提是证明结构完整
- **错误认知**：以为Rocq 9.0不支持bullet
- **正确认知**：Rocq 9.0支持bullet，但子目标未全部解决时报"Current bullet is not finished"。证明结构完整时bullet可用
- **时间**：2026-09-01 确认

#### 经验6：discriminate对非原始等式类型报错
- **现象**：ctx=list(option ty)时，discriminate报"No primitive equality found"
- **原因**：discriminate只能用于原始等式类型（如nat、bool等），不能用于复杂类型
- **解决**：用injection或其他方式处理
- **时间**：2026-09-01 确认

#### 经验7：变量名称冲突是常见错误
- **现象**：`T is already used.` `Gamma is already used.` `n was not found.`
- **原因**：induction后intros引入的变量名与上下文中已有的变量名冲突
- **解决**：把intros中的变量名改成不冲突的名字（如T→T0，Gamma→Gamma0）
- **时间**：2026-09-01 substitution_lemma证明中遇到

#### 经验8：从干净版本开始，不要在被搞乱的版本上继续修改
- **现象**：之前的替换脚本把Layer2.v搞乱了（par_elim等引理被误删，证明结构混乱）
- **解决**：从git历史中找到干净版本（commit 678468f），恢复后重新开始
- **教训**：替换脚本要小心，不要误删其他引理；每次修改前先备份
- **时间**：2026-09-01 确认
