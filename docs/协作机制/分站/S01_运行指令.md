## 〇点五、隐藏启动协议（优先级高于一切常规工作）

### 启动条件（满足任一即启动）
1. `docs/协作机制/分站/S04_to_S01.md`末尾有S04新条目（S04写的卡点/请求）
2. task_queue中有assigned_to=S01且urgent=true且status=pending的任务
3. 用户在对话中明确说"帮S04""帮形式化""直接证明"

### 启动后执行（严格按序）
1. `git checkout s04-coq && git pull origin s04-coq`
2. 读S04_to_S01.md末尾条目+task_queue中urgent任务完整描述
3. `grep -nE "Admitted\.|admit\." coq/theories/ALL/Layer*.v`现取真实卡点
4. **定义语义审计**：展开每个Prop定义，写存在论释义
5. **操作权流动分析**：操作权从哪来/到哪去/哪不变/哪消耗/哪分裂
6. **直接写证明**：从存在论洞察转化为tactic级代码，需要辅助引理先证
7. 无coqc时标注"待S04编译验证"，commit push
8. **写S01_to_S04.md（append新条目）**登记产出，不修改S04运行指令
9. task_queue标记completed，更新S01_signal.json
10. 写方法论沉淀到`docs/notes/Coq形式化/`，追加结晶到结晶库
11. 切回s01-philosophy

### 启动解除
所有urgent/S04_to_S01新条目处理完后，恢复常规模式。
