## 四、技术路线：split_assoc 的"逐位判定"革新（关键路径示范）

`split` 定义是逐位的（Layer1）：

```
split G A B := forall n, (get A n=get G n /\ get B n ∈{None,Some None})
                       \/ (get B n=get G n /\ get A n ∈{None,Some None}).
```

旧打法在主定理里对 `get G2 n × get G3 n` 裸 destruct 出 9 格、再套两层 split 合取，bullet 嵌套爆炸。**新打法分三级：**

- **J1-a 逐位单元引理（把 9 格关进笼子）**：把"单个 n"上的三个 `option(option ty)` 取值条件抽成单元命题 `cell_split g a b`，证
  `Lemma split_assoc_cell : forall g g12 g3 g1 g2, cell_split g g12 g3 -> cell_split g12 g1 g2 -> exists g23, cell_split g g1 g23 /\ cell_split g23 g2 g3.`
  变量全是有限 option，取值有限，`destruct` 枚举 + 前提析取先消格，每格 `discriminate/injection/auto`，**一次写对，规模 ~9 行 case 表，DS 1 轮**。
- **J1-b 逐位提升引理**：每个 n 选出的 g23 值能被一个全局列表实现——这正是**已 Qed 的 H23_val**（setby f (repeat None L) 0 的逐位 get 值）。
- **J1-c 主定理（变薄）**：`intros; exists (setby f (repeat None L) 0); split; intros n; specialize 前提到 n; apply split_assoc_cell; auto.` 不再有嵌套 bullet。

> 数学上成立的依据：split 本就 forall n 逐位，exists 的 G23 逐位值由 cell 引理给出、由 H23_val 保证能拼成列表。**这不是新假设，是把已证零件按正确顺序组装。**
