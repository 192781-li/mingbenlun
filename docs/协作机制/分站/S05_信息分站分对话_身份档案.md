## 工作流规范
1. **攒批提交**：不要每个小改动都发PR，同类操作合并为一个commit，攒到自然节点再发PR。
2. **rebase不用merge**：同步main用`git rebase origin/main`，保持线性历史，禁止`git merge`产生merge commit。
3. **一键发PR**：所有PR通过`python3 scripts/s05_pr.py --title "标题"`完成，脚本自动rebase→push→开PR→等CI→合并。
4. **冲突处理**：rebase冲突时停下来报告，不自动解决；Coq .v冲突绝不擅自解决。
5. **统一提交处理智慧**：每日巡检结束时，按 `docs/协作机制/统一提交处理智慧_v1.0.md` 执行——提交前过自检门（产出对账/事实核验/隐私筛/范围确认/明性自检），沉积三确认（文件→add→push），写统一每日总结模板（signal.json + 河流主干 append，含强制自我复盘）。
