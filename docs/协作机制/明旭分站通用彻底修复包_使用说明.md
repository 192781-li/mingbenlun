# 明旭分站通用彻底修复包 使用说明

## 概述

`scripts/token_management/mingxu_fix_all.sh` 是一个云电脑/本地电脑通用的一键修复脚本，自动诊断并修复分站常见的网络/git/token/配置问题。

**适用环境**：云电脑（Linux）、本地电脑（Mac/Windows Git Bash）

## 自动修复的10类问题

1. token丢失/无效/错误
2. git remote URL错误
3. git网络配置未优化（pull/push超时）
4. git锁文件
5. 未提交改动阻塞
6. 分支不存在/错误
7. push冲突（远程有新提交）
8. 仓库未克隆/路径错误
9. git user未配置
10. 代理/SSL/credential问题

## 使用方法

### 方式1：修复单个分站（推荐）

```bash
cd ~/Desktop/mingbenlun  # 或者你的仓库路径

# 修复S04 Coq分站（把S04改成你的分站ID即可）
TOKEN_S04="你的token" bash scripts/token_management/mingxu_fix_all.sh S04
```

### 方式2：一次性修复所有分站

```bash
cd ~/Desktop/mingbenlun

TOKEN_S00="S00的token" \
TOKEN_S01="S01的token" \
TOKEN_S02="S02的token" \
TOKEN_S03="S03的token" \
TOKEN_S04="S04的token" \
TOKEN_S05="S05的token" \
bash scripts/token_management/mingxu_fix_all.sh ALL
```

### 方式3：token已保存在本地时

如果token已经保存在 `~/.mingxu/tokens/S04.token`，可以直接运行：

```bash
bash scripts/token_management/mingxu_fix_all.sh S04
```

## 脚本执行的9个步骤

1. **验证Token有效性** — 调用GitHub API验证token，无效则报错
2. **定位/克隆仓库** — 自动搜索常见位置，找不到则自动克隆
3. **清理Git锁文件** — 删除 `.git/*.lock`，解决"无法获取锁"错误
4. **配置Git Remote** — 用对应分站的token更新remote URL
5. **优化Git网络配置** — 大buffer(500MB)、长超时(999999秒)、HTTP/1.1、credential store
6. **处理未提交的改动** — stash保存（不会丢失），修复后自动恢复
7. **切换到专属分支** — 本地没有则从远程创建，远程没有则从main新建
8. **合并main最新代码** — 自动解决push冲突，冲突时保留当前版本
9. **测试Push** — 创建空提交测试push，成功后回滚测试提交

## 常见问题

### Q: 运行后还是push失败怎么办？

A: 检查以下几点：
1. 网络是否正常（`ping github.com`）
2. token是否有repo权限（https://github.com/settings/tokens 检查）
3. 分支是否受保护（GitHub仓库设置 → Branches）
4. 是否有防火墙/代理干扰

### Q: token会被泄露吗？

A: 不会。token只保存在：
- 环境变量（运行时）
- `~/.mingxu/tokens/*.token`（本地文件，权限600）
- git remote URL（本地git配置）

**绝对不会**写入库内任何文件或commit message。

### Q: 本地电脑和云电脑都能用吗？

A: 能。脚本自动检测操作系统（Linux/Mac/Windows Git Bash），自动适配路径和命令。

### Q: 修复后原来的改动会丢失吗？

A: 不会。未提交的改动会被stash保存，修复完成后自动恢复。如果恢复时有冲突，脚本会提示手动解决。

## 修复后的日常使用

修复完成后，正常干活：

```bash
git add -A
git commit -m "你的提交信息"
git push origin 你的分支名
```

**记住**：
- 每次干活前先 `git pull origin main`
- 每干完一步就 commit + push，不要攒一大堆
- 再遇到任何网络/git/token问题，重新运行修复脚本即可
