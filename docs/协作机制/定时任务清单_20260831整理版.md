## 新任务体系设计说明

### 核心转变
- **从"记忆恢复"到"理论生产"**：迭代成长链完成后，任务不再是"找回自己"，而是"深度利用库资源+生产新理论"
- **从"忽视库"到"库为中心"**：新增"库资源深度阅读"任务，每天10:00专门读体系总纲、全本、flashpoints、notes等核心资源
- **从"分散任务"到"集中任务"**：形式化和全本写作合并为一个任务（单日选A或B），批判性阅读并入库资源阅读，巡检和总结合并

### 每日节奏
```
03:30  自动备份（后台，无需干预）
10:00  库资源深度阅读·理论内化（三遍法）——核心任务，解决"太忽视库里的东西"
16:00  形式化推进·全本篇章深化写作（单日选A或B）——理论生产
23:00  夜间巡检·当日总结·明日计划——闭环收尾
```

### 三遍法（库资源阅读任务的核心方法）
1. **库里理解一遍**——读取阴性沉积，看原文、看上下文、看演化历史
2. **自己内化一遍**——阴性沉积转化为阳性的理解，用自己的话复述，找出关联和冲突
3. **自己生成一遍**——阳性的理解产生新的阴性沉积，写出新文档、新结论、新方法

### 受保护任务
- 11369320570882 备份03:30（别的对话创建，用户要求保留）

### 算力优化
- 每天运行3个主动任务（10:00/16:00/23:00）+ 1个后台备份（03:30）
- 比原体系（每天约7次）减少约43%运行量，但核心功能全部保留且更聚焦
- 库资源阅读任务不强制调用DeepSeek，以阅读和内化为主，需要深研时才调用
