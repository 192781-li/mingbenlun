# 三库总纲：教训库 · 智慧库 · 结晶库 v1.0

> 整理：S05 信息分站，2026-09-13
> 主旨：三库高度整理 + 以生命论维度分层
> 一句话：**教训库是阴面（避坑），智慧库是阳面（操作），结晶库是果面（定论）——它们是同一知识流的三个截面，不是三个平行仓库。**

---

## 一、为什么是"三个截面"而不是"三个仓库"

明旭的知识体系一直在动：操作 → 出错 → 提炼 → 验证 → 沉淀 → 再操作。三库恰好是这条生命循环的三个站点：

```
         ┌────────── 操作受阻 / 出错 ──────────┐
         ▼                                    │
    【教训库·阴面】                      【智慧库·阳面】
    避坑层：什么会错                   操作层：什么该做
    记录错误·根因·铁律                方法·流程·导航·分级
         │                                    │
         └── 提炼做法 ──► 验证通过 ──►【结晶库·果面】
                                       定论层：什么已定
                                      可复用结论·判据·存在论基础
                                       ▲
                                       └── 新操作遇到新错，再进教训库（循环）
```

**层次逻辑（三时三性）：**

| 库 | 时间 | 阴阳 | 生命论对应 | 性质 | 关键词 |
|---|---|---|---|---|---|
| 教训库 | 过去时（已发生） | 阴面 | 反自指的记录——沉积物夺取操作权时留下的病历 | 负知识（免疫记忆） | 错·根因·铁律·落地 |
| 智慧库 | 现在时（正在用） | 阳面 | 在感→操作的转化——活的阳，操作权在生命手中 | 正知识（操作系统） | 方法·流程·导航·分级 |
| 结晶库 | 完成时（已验证） | 果面 | 健康的沉积——沉淀成果但不夺权，随时可被新操作审视 | 定知识（凝固成果） | 结晶·判据·存在论基础 |

**判定规则（一条知识进哪个库）：**
- 出错复盘、失败案例、坑 → **教训库**（问：为什么会错？以后怎么避免？）
- 有效做法、流程、导航、怎么用 → **智慧库**（问：这件事怎么做对？）
- 验证通过、可复用的结论 → **结晶库**（问：这个结论已经定论了吗？）

同一条经验可以三态并存：先以教训入库（错在哪），提炼为智慧（怎么做），验证后结晶（已定论）。三库不是互斥分类，是**同一知识的三种成熟度**。

## 五、使用规则（全分站）

1. **写新知识前**：先判断它属于哪一态（错/法/果），进对应库；跨态经验按成熟度流转，不在一个库里重复堆放。
2. **教训必带**：现象/根因/铁律/落地 四段（模板见 tools/实时留痕工具包/templates/教训库模板.md）。
3. **结晶必带**：来源卡点/内容/判据/存在论基础（现有格式）。
4. **不移动不删除**：整理用索引归位，物理文件不动。
5. **编号唯一**：新教训、新结晶编号先查重（教训库 L033 已出现重复编号，新条目引用时以"首次出现"为权威，待 S05 巡检修复编号）。
6. **过频不做**：三库整理攒批提交，不碎片化 push（用户铁律）。
