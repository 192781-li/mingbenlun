二、五大纵贯线索（北京卷高频大题线）

线索 1 · 中央集权演变

分封制 → 郡县制 → 推恩令 → 三省六部 → 二府三司 → 行省制 → 废丞相 → 军机处
大势：皇权不断强化、相权不断削弱；中央对地方控制不断加强。
一句话：地方从"世袭割据"走向"垂直任命"，到军机处皇权达顶峰。

线索 2 · 选官制度演变

世官制(血缘) → 军功爵(秦·战功) → 察举制(汉·品行) → 九品中正制(魏晋·门第) → 科举制(隋唐-明清·才能)
大势：标准从血缘→军功→品行→门第→才能；选拔权从地方贵族收归中央。
北京卷爱问：科举制为何是"制度创新"？——打破门第限制、扩大统治基础、选官权收归中央。

线索 3 · 赋税制度演变

井田制 → 初税亩(春秋·按亩) → 租庸调(唐前) → 两税法(唐中) → 一条鞭法(明) → 摊丁入亩(清)
大势：征税标准从人丁为主转向土地财产为主；人头税逐渐取消；实物向货币过渡。
一句话：人头税越来越轻、土地财产税越来越重——商品经济发展在制度上的倒影。

线索 4 · 经济重心南移

东晋南朝(开始) → 隋唐(加速) → 南宋(完成)
表现：南方户口、赋税比重超过北方；谚语"苏湖熟、天下足"。
原因（大题模板）：北方战乱→南迁带来劳动力＋技术→南方自然条件优越→政策支持。

线索 5 · 儒学 / 思想演变

百家争鸣 → 焚书坑儒(秦) → 独尊儒术(汉) → 佛道冲击(魏晋隋唐) → 理学(宋) → 心学(明) → 批判＋西学东渐(明末清初)
大势：儒学从"诸子之一"→官方正统→吸收佛道→哲学化(理学)→内在化(心学)→被批判质疑。
暗线：思想控制与统治需要同步——焚书坑儒、独尊儒术、八股取士、文字狱，一个比一个细。

三、易错点清单（丢分重灾区）

  1. 1郡国并行＝郡县＋封国，不是纯分封；推恩令是"化整为零"削封国，不是直接废
  2. 2九品中正制是魏晋，不是汉朝；察举制才是汉
  3. 3科举制隋朝创立、唐朝完善，不是唐朝才有
  4. 4两税法取消了租庸调，按土地财产征税，标志人头税向财产税过渡
  5. 5经济重心南移完成在南宋，不是隋唐（隋唐只是加速）
  6. 6行省制是元朝首创，明朝继承发展
  7. 7废丞相＝明太祖，设内阁＝明成祖以后；军机处＝清雍正，皇权顶峰
  8. 8一条鞭法是明，摊丁入亩是清，别混
  9. 9理学＝客观唯心（理在事先），心学＝主观唯心（心外无物），北京卷爱考这层区别
  10. 10焚书坑儒≠独尊儒术：一个灭儒，一个定儒为一尊，方向相反

四、北京卷考向提示

  • 重"制度创新与延续"：爱考"为什么这个时候出现这个制度""这个制度解决／制造了什么新问题"
  • 重"变与不变"：唐宋变革（门阀解体、市民兴起、科举普及）是高频视角
  • 重"材料＋解释"：题干给一段经济／政治现象，让你用制度演变逻辑解释，不是死背书
  • 一条万能思路：任何制度变化 ＝ 旧制度运行出现新问题 → 新制度回应 → 又产生新问题 → 再变。用这条线看线索1-5，全通。
