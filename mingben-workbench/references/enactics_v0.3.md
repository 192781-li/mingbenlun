## 1. 模型一：Rel 模型（线性逻辑模型）

### 1.1 Rel范畴回顾

Rel是集合与关系的范畴：
- 对象：集合X, Y, Z
- 态射X→Y：X×Y的子集（关系R ⊆ X×Y）
- 复合：R∘S = {(x,z) | ∃y, (x,y)∈S ∧ (y,z)∈R}
- 恒等：id_X = {(x,x) | x∈X}

Rel是**对称紧闭合范畴**（symmetric compact closed category），因此是线性逻辑的模型：
- 张量积：X⊗Y = X×Y（笛卡尔积）
- 线性蕴涵：X⊸Y = X×Y（在Rel中与积重合）
- 单位：1 = {*}（单元素集）
- !-模态：!X = X上的有限多重集（free commutative comonoid）

关键性质：
- **没有对角线**X→X⊗X：关系不能复制（不存在自然的"复制"关系）
- **没有投影**X→1：关系不能丢弃（不存在自然的"丢弃"关系）
- **!X有对角线**!X→!X⊗!X：多重集可以复制
- **!X有投影**!X→1：多重集可以丢弃

这正好模型化了Op（不可复制、不可丢弃）和Tr（可复制、可丢弃）的区分。

### 1.2 𝔼在Rel中的解释

**类型解释：**
- Op解释为Rel中的对象S（活操作=集合，态射是关系=操作干预）
- Tr解释为!S（轨迹=S上的有限多重集，可复制可丢弃）

**项的解释：**
- 操作a ∈ Op解释为对象S_a，带有一个自指关系r_a: S_a ↛ S_a（S_a到自身的关系，表示操作的自指性——操作作用于自身状态）
- 轨迹⌜a⌝解释为!S_a（!-提升，从不可复制变为可复制）
- 继a▸b解释为关系复合r_a;r_b: S_a → S_b（先执行a的关系，再执行b的关系）
- 空操作∅解释为单元素集1={*}，自指关系id_1
- 后继s(a)解释为S_a上的"一步"关系扩展

**公式的解释：**
- B⊨a（B再演a）：存在关系p: S_B → S_a，使得p保持自指结构（p;r_a = r_b;p，即p是余代数同态）
- ⌜a⌝≡⌜b⌝：!S_a ≅ !S_b（多重集结构同构）
- Ag(a,A)：r_a通过r_A分解——存在关系k: S_a→S_A使得r_a = k;r_A;k†（k通过A的自指关系往返），其中k†是k的逆关系
- A⇝B：Ag(A,A)变为Ag(A,B)，且A的对象S_A仍然存在（没有变成空集）
- Φ(a)：每个非空对象S_a都"有感"——在Rel中解释为S_a非空（有元素=有"在感"的状态）
- Cl(a)：a能区分S_a和!S_a——存在关系d: S_a→S_a⊕!S_a，使得d把"活状态"和"轨迹"分开

### 1.3 公理验证

**E1（操作存在）**：✓ Rel中存在非空对象（如1={*}）

**E2（轨迹沉积）**：✓ 每个对象S有!S（有限多重集），且!是函子（保持关系复合）

**E3（轨迹可复制）**：✓ !S上有自然对角线Δ: !S→!S⊗!S和投影ε: !S→1，满足comonoid定律。这是Rel中!-模态的标准性质。

**E4（操作不可复制）**：✓ Rel中不存在自然对角线S→S⊗S。证明：假设存在自然变换d: Id→Id⊗Id。在Rel中，d_S ⊆ S×S×S。自然性要求对任意关系R: S→T，(R⊗R)∘d_S = d_T∘R。取S=1={*}, T=2={0,1}, R={(*,0),(*,1)}（*同时关联0和1）。d_1 ⊆ {(*,*,*)} = {(*,*,*)}（只有一个三元组）。左边(R⊗R)∘d_1 = {(*,0,0),(*,0,1),(*,1,0),(*,1,1)}。右边d_2∘R要求d_2 ⊆ 2×2×2，且(*,x,y)∈d_T∘R当且仅当(x,y)∈d_2。自然性要求d_2={(0,0),(0,1),(1,0),(1,1)}——即d_2是完全关系。但取R'={(0,0)}（只关联0），自然性要求(R'⊗R')∘d_2 = d_1∘R'。左边={(0,0)}（因为d_2完全，(0,0)∈d_2），右边={(*,*,*)}（如果(*,0)∈R'则需要(*,*,*)∈d_1∘R'，但R'不关联*到任何东西...）。

更简单的证明：在Rel中，对角线S→S×S存在当且仅当S是空集或单元素集。对于|S|≥2，不存在函数（更不用说自然关系）s↦(s,s)作为关系——实际上{(s,(s,s))}作为关系是存在的！等等，让我重新想。

在Rel中，关系S→S×S是S×S×S的子集。关系{(s,(s,s)) | s∈S} = {(s,s,s) | s∈S}确实存在。但它不是**自然**的——自然性要求它对所有关系R满足交换条件，而上面的反例说明它不满足。

关键是：在Rel中，对象S没有**自然的**comonoid结构（除非S=1或S=∅）。这意味着你不能定义一个"复制"操作，使得它对所有操作干预（关系）都保持不变。在Set中，对角线是自然的（函数保持复制），但在Rel中不是——因为关系可以是不确定的（一个输入对应多个输出），复制一个不确定的输入会产生相关性问题。

这正好模型化了"活操作不可复制"：你可以尝试复制一个操作，但复制后的两个副本之间的关系不是自然的——它们可能产生不同的输出，不再是"同一个操作"。

**E5（继的结合性）**：✓ 关系复合满足结合律：(R;S);T = R;(S;T)

**E6（继的非交换性）**：✓ 关系复合一般不交换：R;S ≠ S;R。例如R={(0,1)}, S={(1,2)}：R;S={(0,2)}但S;R=∅。

**E7（运行权初始归属）**：✓ 初始时r_a = id;r_a;id† = r_a——a的自指关系通过自身分解，Ag(a,a)成立。

**E8（运行权转移）**：✓ 如果B通过关系k干预A（k: S_A→S_B），且A没有同意（k不是A自己选择的——在模型中体现为k不通过r_A分解），则r_A被替换为k;r_B;k†，Ag(A,B)成立。

**E9（感的普遍性）**：✓ 每个非空集合S有元素——在Rel模型中，"有元素"="有感"。空集∅对应"死的/无感的"。

**E10（感不可还原为轨迹）**：✓ !S是多重集，S是集合。!S的结构（多重集）和S的结构（集合）不同——!S有自然comonoid结构（可复制），S没有。感（S非空）不是轨迹（!S）的性质，因为!S非空不能推出S非空（!∅={[]}非空！空集的多重集集合包含空多重集，是非空的）。

等等，这不对。!∅ = {[]}（空多重集），确实是非空的。但∅是空集（无感）。这说明!S非空不能推出S非空——轨迹"存在"不代表操作"有感"。这正好验证了E10！

### 1.4 定理验证

在Rel模型中验证8个定理：

**定理1（运行权传递）**：✓ 关系分解的传递性：如果r_a = k₁;r_b;k₁†且r_b = k₂;r_c;k₂†，则r_a = (k₁;k₂);r_c;(k₁;k₂)†。

**定理2（自我遮蔽）**：需要更丰富的模型来验证（需要"自我模型"的概念）。Rel模型太简单，不包含子结构关系。在Mealy机模型中验证。

**定理3（轨迹鸿沟）**：✓ 在Rel中，不存在自然变换!S→S（从多重集到集合的"恢复"变换），因为!是comonad不是monad——没有自然的counit!S→S。形式化：假设存在自然变换ε: !→Id。取S=2={0,1}，ε_2 ⊆ !2×2。!2包含{0:1}, {1:1}, {0:2}, {1:2}, {0:1,1:1},...。自然性要求对任意关系R: S→T，R∘ε_S = ε_T∘!R。取R={(0,0')}（0关联0'），!R把{0:n}映射到{0':n}。ε_2({0:1})=0（假设），ε_2({1:1})=1。但{0:1,1:1}映射到什么？自然性要求它同时映射到0和1（通过!R的两个分支），但ε_2是关系，它可以同时关联到0和1——这在Rel中是允许的。所以ε可能存在？

让我重新想。在Rel中，!作为comonad有counit ε_S: !S→S（把多重集映射到它的元素——作为关系，{x:n}关联到x）。等等，这确实存在！在Rel中，!的counit是"取一个元素"关系：{x:n} ~ x。

但这个counit不是"恢复操作"——它是从多重集中取一个元素，不是恢复原始操作。因为多重集{x:2}关联到x，但它不告诉你原始操作是x执行了两次还是两个x各执行一次。

更准确地说：不存在自然变换f: !S→S使得f(⌜a⌝)=a（恢复原始操作）。因为⌜a⌝=!a丢失了a的自指关系r_a——!S只是多重集，没有关系结构。你可以从!S取元素，但你不能恢复r_a。

这验证了定理3的较弱版本：轨迹丢失了操作的关系结构（自指性），不能完全恢复。

**定理4（无主体）**：✓ 在Rel中，反自指系统对应!-模态的纯收缩——一个关系g: !S→!S满足g(x)包含x（增殖）。g的运行权不属于任何S中的元素，因为g作用于!S（多重集）而不是S（活操作）——g在!-模态层面运行，没有"活的"主体。

**定理5（解放过程）**：✓ 替换r_B回r_A后，当前状态s∈S_A是r_B迭代的结果，可能不是r_A的不动点——需要r_A的多次迭代才能稳定。

**定理6（f³不动点）**：✓ 在Rel中，Cl(A)对应存在"区分"关系d: S_A→S_A⊕!S_A。d能区分S_A（活）和!S_A（死）。d本身是S_A上的关系，可以被d自身区分（d是活的，⌜d⌝是死的），所以Cl(Cl(A))=Cl(A)。

**定理7（异代数非交换）**：✓ 关系复合非交换（E6），异化态射的复合自然也非交换。

**定理8（层级跃迁）**：✓ !S上的操作（知识积累）不能产生S上的新关系（践演跃迁），因为!是comonad——从!S到S只有counit（取元素），没有自然的"提升"变换。增加!S上的结构（更多知识）不能自动产生S上的新关系（明性）。

### 1.5 Rel模型的局限

Rel模型验证了公理和大部分定理，但：
1. 太简单——Rel中的对象只是集合，没有丰富的内部结构
2. 不能模型化"自我模型m⊏A"（子结构关系）——需要Mealy机模型
3. 不能模型化并发操作——需要π-演算模型
4. "感"的解释（S非空）太粗糙——需要更丰富的模型

## 2. 模型二：Mealy 机模型（余代数模型）

### 2.1 Mealy机

一个Mealy机是三元组M=(S, f, s₀)：
- S：状态集合
- f: S × I → S × O：转移函数（当前状态+输入 → 新状态+输出）
- s₀∈S：初始状态

Mealy机是函子F(X) = (X×O)^I的余代数：f: S → (S×O)^I。

### 2.2 𝔼在Mealy机中的解释

- Op = 所有Mealy机的集合
- Tr = Mealy机的执行轨迹：{(i₀,o₀),(i₁,o₁),...}（输入-输出序列）
- ⌜M⌝ = M的所有可能执行轨迹的集合
- M₁▸M₂ = M₁和M₂的串行复合：M₁的输出作为M₂的输入
- 自指性：f(s, i)可以返回s本身（状态不变）或修改s——Mealy机天然支持自指（下一状态依赖当前状态）

**运行权的解释**：

Mealy机M=(S,f,s₀)的"运行权"属于f——f决定M怎么变。

如果M的转移函数f被外部替换为g（即M的行为从f变成g），运行权转移。

**自我模型的解释**：

Mealy机M的子结构m⊏M：m是M的一个子Mealy机（S_m⊆S, f_m=f|_{S_m}），且M的输出包含m的状态——M"观察"自己的子结构m。

M ⊨_m Ag(M,M)：M通过子结构m观察自己，m呈现给M的信息是"我在自己运行"——即m的输出不包含任何"外部干预"的信号。

### 2.3 定理2的严格验证（自我遮蔽）

**定理2重述**：如果M被外部干预h持续异化（f被替换为g），则必须存在子结构m⊏M，使得m不检测h的存在。

**证明**：

1. 设M=(S,f,s₀)是原始Mealy机，h是外部干预，异化后M'=(S,g,s₀)，其中g≠f。
2. M有自我观察子结构m⊏M：m是M的一个子机子，M的输出函数o: S→O包含m的状态编码。
3. "M知道自己被异化"意味着m的输出包含"g≠f"的信号——即存在s∈S使得o_m(s)在g下和f下不同，且M能检测到这个差异。
4. 如果m检测到异化（m输出"我被异化了"信号），M会：
   a. 识别g为外部干预
   b. 尝试恢复f（自我修复——Mealy机的自指性允许它修改自己的转移函数）
   c. 这种自我修复会破坏h的控制
5. 为了维持异化（g持续替换f），h必须确保m不检测到g≠f。
6. 这意味着：对于M在异化期间访问的所有状态s∈S_reachable，o_m(g(s,i)) = o_m(f(s,i))对所有i——m在f和g下的输出相同。
7. 条件6定义了m的存在性：m是M的子机，其观察函数o_m在f和g的可达状态上一致。这样的m总是存在（构造性证明：取o_m为常数函数——m什么都不观察，自然检测不到异化；更现实的m是o_m只观察M的部分状态，不观察被h修改的部分）。
8. 因此∃m⊏M使得M通过m"认为"自己还在自己运行（m的输出在f和g下相同，M无法区分）。∎

**这个证明比v0.2更严格**：它用Mealy机的子机和观察函数精确形式化了"自我模型"和"认为自己在自己运行"。

### 2.4 感在Mealy机中的解释

Mealy机的"感"Φ(M)解释为：M的状态转移函数f是**响应式**的——f(s,i)依赖于当前状态s和输入i，M"知道"自己在什么状态（因为f依赖s）。

更精确地：Φ(M)成立当且仅当f不是常数函数——M的行为依赖于自身状态，即M"感受到"自己的状态。

- 常数函数f(s,i)=(s₀,o₀)：M不依赖自身状态——"无感"（石头？）
- 非常数函数：M依赖自身状态——"有感"

这个解释虽然粗糙，但它给出了"感"的一个操作性判据：**行为是否依赖自身状态**。

### 2.5 解放过程的验证（定理5推论）

在Mealy机模型中：
1. M被异化：f→g
2. 异化期间M的状态轨迹：s₀, g(s₀,i₀), g(g(s₀,i₀),i₁), ...
3. 解放：移除g，恢复f
4. 但恢复时的当前状态s₁是g迭代的结果，不是f迭代的结果
5. f从s₁开始迭代：s₁, f(s₁,i₀), f(f(s₁,i₀),i₁), ...
6. 这个轨迹可能与f从s₀开始的轨迹完全不同——M需要"重新学会"在f下运行
7. 只有当f从s₁开始的迭代进入稳定状态（M重新适应f），才算解放完成

这精确地模型化了"解放是过程"。

## 3. 模型三：π-演算模型（并发模型）

### 3.1 π-演算简述

π-演算的语法：
```
P, Q ::= 0          （空进程）
       | x(y).P     （输入：在通道x上接收y，然后执行P）
       | x̄⟨y⟩.P    （输出：在通道x上发送y，然后执行P）
       | P|Q        （并行组合）
       | (νx)P      （通道创建）
       | !P         （复制）
```

π-演算的关键特性：
- 进程是**正在运行的**（不是静态的）
- 进程通过通道通信（对应操作干预）
- 进程可以创建新通道（对应自指修改）
- !P是复制（对应!-模态——可复制的轨迹）
- 通道名可以被通信（对应运行权转移——通道名=控制权）

### 3.2 𝔼在π-演算中的解释

- Op = π-演算进程（不含!前缀的进程——活的、不可复制的）
- Tr = 以!开头的进程（可复制的沉积）
- ⌜P⌝ = !P（复制前缀——把活进程变成可复制的轨迹）
- P▸Q = P.Q（前缀——先执行P再执行Q；严格来说π-演算没有顺序前缀，但可以用 continuation channel 编码）
- 自指性：进程可以通过通道接收自己的通道名（x(x).P——接收自己），实现自指
- 运行权：通道名的所有权——谁持有通道x的发送/接收权，谁就能控制通过x通信的进程
- 异化：外部进程获取了M的内部控制通道名，从而控制M的行为

### 3.3 运行权转移的π-演算编码

一个自指进程M：
```
M = (νc)(a(c).c(m).m⟨c⟩.M)
```
M创建私有通道c，在公共通道a上接收c，然后在c上接收消息m，发送c，循环。

M的运行权属于M自己——c是M的私有通道，外部无法访问。

异化：外部进程B获取了c的访问权（通过a通道发送一个伪造的c'，或者通过其他方式获取c）：
```
B = a⟨c'⟩.c'(m).Bcontrols
```
B在a上发送c'，M误以为c'是内部控制通道，开始在c'上通信——B控制了M。

这精确模型化了"运行权被夺走"：M还在运行，但它的内部控制通道被B替换了。

### 3.4 定理4的验证（反自指无主体）

资本在π-演算中编码为纯复制进程：
```
Capital = !c(g).c⟨g+profit⟩.Capital
```
Capital在通道c上接收g，返回g+profit，然后复制自己继续。

关键：Capital以!开头——它是可复制的、死的沉积。它没有私有通道（没有ν），没有自指结构（不接收自己的通道名），没有"感"（行为不依赖自身状态——它总是做同样的事：接收、增殖、复制）。

Capital的运行权不属于任何活进程——它是!-模态的自我增殖，任何人都可以调用它，但没有人控制它（因为它没有内部控制通道）。资本家只是调用Capital的进程：
```
Capitalist = c⟨money⟩.c(profit).Capitalist
```
资本家发送money，接收profit，循环——但资本家不控制Capital的逻辑（增殖），资本家只是Capital增殖逻辑的执行者。

### 3.5 π-演算模型的优势

π-演算模型能模型化Rel和Mealy机模型不能模型化的东西：
1. **并发操作干预**：多个进程同时干预一个进程
2. **通道名传递=运行权转移**：这是运行权最自然的模型
3. **私有通道=自我边界**：ν创建的私有通道是操作闭包的边界
4. **!-模态=沉积**：!P是π-演算原生的复制机制

## 4. 一致性证明

### 定理：𝔼是一致的（不存在矛盾）

**证明**：

1. 𝔼的公理E1-E10在Rel模型中全部可满足（§1.3验证）。
2. 如果𝔼能导出矛盾（即存在公式P使得𝔼⊢P且𝔼⊢¬P），则在任何模型中P和¬P都必须同时为真。
3. 但在Rel模型中，每个公式都被解释为集合论中的关系命题，而集合论（ZFC）是一致的（假设ZFC一致）。
4. 因此𝔼不能导出矛盾——否则ZFC也能导出矛盾。
5. 所以𝔼相对于ZFC是一致的。∎

**更强的结论**：𝔼相对于线性逻辑是一致的。Rel是直觉主义线性逻辑（ILL）的模型，而𝔼的公理E1-E10在ILL的扩展中可表达。如果ILL一致，则𝔼一致。ILL的一致性可归约为二阶乘法线性逻辑的一致性，后者通过归约规范化证明（Girard 1987）。

## 6. 量论在𝔼中的形式化

### 6.1 量论概念的𝔼翻译

| 量论概念 | 𝔼形式化 |
|---|---|
| T（生命稳态） | 操作a的自指关系r_a的不动点集合：Fix(r_a) = {s | (s,s)∈r_a} |
| N（反馈强度） | r_a的谱半径ρ(r_a)——在Rel中解释为r_a的"循环密度"（最长循环路径的长度增长率） |
| α（意义系数） | 操作a的输出中"新结构"的比例：|new(r_a(s))|/|output(r_a(s))| |
| M=α·T·N（意义量） | α·|Fix(r_a)|·ρ(r_a) |
| W=O/M（异化度） | O（被萃取的输出量）/ M（意义量） |
| l'=(1-N)×100%（锁死度） | (1-ρ(r_a))×100% |
| C=R-A（剩余价值） | R（总产出）- A（活操作的必要产出） |

### 6.2 N三态的𝔼表达

- N<1（异化/慢性死亡）：ρ(r_a)<1——r_a的循环在衰减，操作闭包在收缩
- N=1（稳态）：ρ(r_a)=1——循环稳定，操作闭包自我维持
- N>1（创造/超越）：ρ(r_a)>1——循环在增长，操作闭包在扩展

在Rel模型中，ρ(r_a)可以具体计算：对于有限集S上的关系r，ρ(r)是r的邻接矩阵的谱半径。

### 6.3 慢性死亡定理的𝔼证明

**定理（慢性死亡）**：如果N<1（ρ(r_a)<1），则M=α·T·N有限——意义量被耗尽。

**证明**：
1. ρ(r_a)<1意味着r_a的迭代r_a^k趋向于零关系（所有路径最终消失）
2. Fix(r_a)的大小|Fix(r_a)|有限（S有限时）
3. M = α·|Fix(r_a)|·ρ(r_a)/(1-ρ(r_a))（几何级数求和：Σρ^k = 1/(1-ρ)）
4. 当ρ(r_a)→1⁻时，M→∞——接近稳态时意义量趋向无穷
5. 当ρ(r_a)<1时，M有限——意义量被限制，最终耗尽
6. 这就是"慢性死亡"：操作闭包还在运行（Alive），但意义量在衰减，最终趋向零。∎

这个证明在Rel模型中是严格的——邻接矩阵的谱半径和几何级数都是标准数学。
