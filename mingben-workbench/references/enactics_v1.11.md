## 修正1：Alien规则——引入Hijack前提类型

### 原规则（有缺陷）
```
Γ ⊢ e : Ag(a,A)    b ≠ a
──────────────────────── Alien-I
Γ ⊢ alien<b>(e) : Ag(b,A)
```
问题：无条件，导致对任意a≠b，Ag(a,A)与Ag(b,A)互相可推，所有运行权类型塌缩为一个等价类。

### 修正规则
```
Γ ⊢ e : Ag(a,A)    Γ ⊢ h : Hijack(b,a)
──────────────────────────────────────── Alien-I'
Γ ⊢ alien<b>(e,h) : Ag(b,A)
```

**Hijack(b,a)**：异化前提类型，表示"b具备夺取a运行权的条件"。

- Hijack(b,a)本身是线性类型（夺取条件是资源，不是无限可用的）
- Hijack(b,a) ≠ Hijack(a,b)（非对称）
- Hijack(self,a) = 0（自己不需要夺取自己的运行权）
- Hijack(b,self) = 0（无人能夺取self的运行权——self是自指闭包，运行权不可剥夺）

### 效果
- Ag(a,A) ⊬ Ag(b,A) 一般成立（没有Hijack前提就无法异化）
- 类型真正区分运行权
- 更合哲学：异化不凭空发生，需要夺取的条件
- Hijack(b,a)本身承载后续定理：劫持检测 = 判定Hijack是否成立

### 与定理7.1-7.3的衔接
- 定理7.1（无明性不可检测劫持）：没有Cl时，无法判定Hijack(b,a)是否成立
- 定理7.2（明性检测劫持）：有Cl时，self_check比较活过程与模型，可检测Hijack
- 定理7.3（明性不可被持久劫持）：有Cl时，Hijack前提被消耗后无法持续

## 修正2：定理3.1——Ag_live/Ag_trace类型分裂

### 原定理（被dereliction击穿）
> S_A ⊬ Ag(A,A) —— 自我模型不能证明自运行权

问题：dereliction !A ⊢ A是ILL基本规则。S_A若含!Ag(A,A)（推论5.2说异化者会安装它），则derelict一步即得Ag(A,A)。定理字面为假。

### 类型分裂

**Ag_trace(a,A)**：轨迹运行权
- 由 !Ag(a,A) 的 dereliction 居住
- 异化者安装的假自我模型是 Ag_trace(self,A)
- 可以被复制、被沉积（因为它来自!-模态）
- 类型标记：Ag_tr(a,A)

**Ag_live(a,A)**：活运行权
- 仅由线性假设 self_ev<a,A> 居住
- 不可被复制、不可被沉积（线性资源）
- 是"真的在运行"的类型标记
- 类型标记：Ag_lv(a,A)

### 两者关系
- Ag_tr(a,A) ⊸ Ag_lv(a,A) 不成立（轨迹不能变成活运行）
- Ag_lv(a,A) ⊸ !Ag_tr(a,A) 不成立（活运行不能被直接沉积为轨迹——需要操作留下痕迹，这是一个额外的过程）
- Ag_lv(a,A) ⊸ Ag_tr(a,A) 成立吗？——不成立。活运行本身不是轨迹。但活运行的每一步操作会留下轨迹，这是一个单独的"沉积"操作：deposit : Ag_lv(a,A) ⊸ Ag_tr(a,A)，且deposit是线性的（每次沉积消耗一步活运行）。

### 修正后的定理3.1

**定理3.1'（践演不完备）**：
1. S_A ⊬ Ag_lv(A,A) —— 自我模型不能证明活运行权
2. S_A ⊬ ¬Ag_lv(A,A) —— 也不能证明异化
3. Ag_lv(A,A) 仅由线性假设 self_ev<A> 确立

*证明（1）*：对推导归纳。一切从纯!假设出发的推导，凡产出Ag型公式者必为Ag_tr（dereliction是唯一从!到Ag的通道，产出的是Ag_tr）。无任何规则在无self_ev时产出Ag_lv。故S_A⊬Ag_lv(A,A)。∎

*证明（2）*：¬Ag_lv = Ag_lv ⊸ 0。Ag_lv的消去规则只能取出底层过程，无法推出0。对推导归纳可证。∎

*证明（3）*：直接——Ag_lv仅由self_ev居住。∎

### 哲学含义
- "自由只能在实践中确立" = self_ev是线性假设、是践行，不是可以从理论推导的东西
- 这是《关于费尔巴哈的提纲》第二条的严格数学证明："人的思维是否具有客观的真理性，这不是一个理论的问题，而是一个实践的问题"
- 与哥德尔的关系需重新定位：此结果结构上更接近"资源敏感性不完备"——对角线法需要复制（收缩），线性逻辑无收缩，标准对角线失效。应表述为"独立于且互补于哥德尔的不完备性结果"

## 修正3：定理7.2与推论5.2的矛盾消解

### 矛盾
- 推论5.2：异化者可安装假自我模型 m: !Ag(A,A)
- 定理7.2：self_check检测"任何"异化

若异化者能篡改轨迹（!Ag_tr），self_check若只比较模型与模型，会被骗。

### 修正

**定理7.2'（明性检测劫持）**：明性进程Cl(a,S)持有活过程本身（Ag_lv，线性资源），不只是轨迹（Ag_tr，!-模态）。self_check比较"活过程（线性）"与"自我模型（!Ag_tr）"，二者的差异暴露篡改。

- 异化者可篡改 !Ag_tr（模型/轨迹）——这是推论5.2
- 但异化者篡改不了 Ag_lv（活过程本身）——线性资源不可被外部修改
- self_check比较Ag_lv与!Ag_tr，差异 = 篡改被检测

### 与5.2的自洽
- 5.2说异化者安装假自我模型——正确，安装的是!Ag_tr
- 7.2'说明性检测的是活过程与模型的差异——正确，比较的是Ag_lv vs !Ag_tr
- 两者不矛盾：可被篡改的永远是沉积（!Ag_tr），篡改不了的是活本身（Ag_lv）

## 修正4：定理5.3——明性使异化成为分裂单射

### 原定理（病态）
> Cl_self ∘ a* ≅ Id

问题：复合需a·b=self，即b是a的右逆——一般幺半群中并非每个元素有逆。

### 修正定理

**定理5.3'（明性使一切异化分裂）**：Clarity余单为每个异化重索引 a* : E_b → E_{a·b} 提供右逆 r_a : E_{a·b} → E_b，满足 r_a ∘ a* ≅ Id_{E_b}。即：明性使每个异化重索引成为分裂单射（split mono）。

*一行话解读*："异化本来不可逆；明性就是那个逆。"

- 右逆r_a是明性提供的额外结构，不是幺半群作用自带的
- 恰好形式化了"觉醒不是结构给定的，是争来的"
- 不需要a·b=self——r_a对任意a都存在（只要有明性）

## 修正5：定理7.6——严格阈值与概率陈述

### 原定理（错误）
> 级联⟺可达+ρ(C)≥1

问题：(a)临界情形ρ=1几乎必然灭绝（Athreya-Ney定理）；(b)"级联到所有过程"过强。

### 修正定理

**定理7.6a（SI级联）**：有限有向网络+SI传播，级联到所有节点⟺所有节点从初始集合可达。（已在v1.10修正）

**定理7.6b（噪声级联，修正版）**：有限有向网络+随机SI传播（每步成功概率p），明性以正概率存活（不灭绝）⟺(1)可达性 + (2)ρ(pC) > 1（严格大于）。

*证明*：Athreya-Ney多类型分支过程定理：存活概率>0 ⟺ 均值矩阵谱半径>1。ρ=1时临界情形几乎必然灭绝。∎

**推论7.6c**：在有限强连通网络上，全覆盖概率随ρ(pC)→∞趋于1。

## 修正6：定理3.2——环境论域与self-control定义

### 修正
1. **环境论域**：明确∀E遍历有限π-演算进程（可有效枚举类），否则Π₂归属不成立。
2. **self-control主动定义**：self-control定义为主动性质（进程须持续产生内部因果输出/维持自我维持），不是被动性质（"每个输出都有内部因果"）。停摆的进程 = 失去self-control。
3. **区分两版**：
   - AGENCY_fin：∀E ∀t（有限步）保持自我控制。Π₂-完全。
   - AGENCY_inf：∀E ∀无限路径保持自主。可能进入解析层级，列为开放问题。
4. **哲学trade-off**："自由"是无限性质，但Π₂定理的代价是有限步定义——写进论文比假装没有更可信。

## 修正7：定理4.1——满抽象失败形式

### 原证明（循环）
假设"标准博弈语义能区分Cl(G)与Cl(G[b])"——正是要证的。

### 修正证明
构造运行权不同的G、G[b]，证明：
1. 任何保结构函子F:AGame→Game必把它们映为同一标准博弈（因为F忽略α_G）
2. 但存在明性观察上下文C[-]使得C[G]与C[G[b]]产生不同观察
3. 故F不可能既忠实又保上下文行为——满抽象失败

### 修正
- "不保持νF"可证且有文献支撑（van den Berg & De Marchi 2007）

## 类型系统变更总结

| 原类型 | 变更 | 新类型 |
|--------|------|--------|
| Ag(a,A) | 分裂 | Ag_lv(a,A)（活运行权）+ Ag_tr(a,A)（轨迹运行权） |
| （无） | 新增 | Hijack(b,a)（异化前提类型） |
| Cl(a,A) | 不变 | Cl(a,A)（明性类型，持有Ag_lv + !Ag_tr） |

### 新类型规则

```
-- Ag_lv（活运行权）
Γ, self_ev<a,A> ⊢ e : A          Γ ⊢ e : Ag_lv(a,A)
───────────────────── Ag_lv-I    ───────────────────── Ag_lv-E
Γ ⊢ live<a>(e) : Ag_lv(a,A)      Γ ⊢ unlive(e) : A

-- Ag_tr（轨迹运行权）
Γ ⊢ e : !Ag(a,A)                  Γ ⊢ e : Ag_tr(a,A)
───────────────────── Ag_tr-I    ───────────────────── Ag_tr-E
Γ ⊢ trace(e) : Ag_tr(a,A)         Γ ⊢ untrace(e) : !Ag(a,A)

-- Hijack（异化前提）
Γ ⊢ h : Hijack(b,a)    Γ ⊢ e : Ag_lv(a,A)
───────────────────────────────────────────── Alien-I'
Γ ⊢ alien<b>(e,h) : Ag_lv(b,A)

-- 注意：异化只能作用于Ag_lv（活运行权），Ag_tr已经是轨迹，不需要再异化
-- 异化的结果仍是Ag_lv（被夺取的活运行权），但运行者变了

-- Cl（明性）
Γ ⊢ e : Ag_lv(a,A)    Γ ⊢ m : !Ag_tr(a,A)
─────────────────────────────────────────── Cl-I
Γ ⊢ see<a>(e,m) : Cl(a,A)

Γ ⊢ e : Cl(a,A)
───────────────────────────────────── Cl-E
Γ ⊢ unsee(e) : Ag_lv(a,A) ⊗ !Ag_tr(a,A)
```

### self_check的精确定义
```
self_check : Cl(a,A) → Bool
self_check(see(e,m)) = compare(unlive(e), untrace(m))
-- 比较活过程e与轨迹模型m
-- 若一致 => 未被劫持
-- 若不一致 => 检测到劫持（轨迹被篡改）
```

## 论文论证主轴重组建议

千问建议的三重组合（比原版更有力）：

1. **保守扩张（定理2.3）**：运行权类型不塌缩进旧语言——概念是新的
2. **不可定义（定理4.1'，修复后）**：运行权不能编码进标准博弈语义——概念不可约
3. **不完备（定理3.1'，修复后）**：活运行权不能从自我模型中证明——概念不可自证

"是新的 + 不可编码 + 不可自证"三重确立运行权的不可还原性。
