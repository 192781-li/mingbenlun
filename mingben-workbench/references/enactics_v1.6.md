## 1. 运行权与生产率

### 1.1 余递归生产率

在函数式编程中，余递归定义产生无限数据结构（流、无限树）。一个余递归定义是**生产性的**（productive），如果它总能在有限时间内产生下一个输出。

```
nats = 0 :: map (+1) nats    -- 生产性的：每个元素在有限时间内产生
loop = loop                   -- 非生产性的：永远不产生输出
```

生产率检查是程序语言理论中的活跃问题。对于一般的余递归程序，生产率不可判定，且是Π₂-完全的：

> PRODUCTIVE = {f : ∀n ∃t, f在t步内产生第n个输出}

### 1.2 等价性定理

**定理1.1（运行权=生产率）**：在π-演算编码下，AGENCY和PRODUCTIVE是递归同构的（互相一一归约）。

**证明**：

(1) PRODUCTIVE ≤_m AGENCY：

给定余递归程序f产生流s = s₀, s₁, s₂, ...，构造π-演算进程P_f：

```
P_f = (νc)(Producer_f(c) | Consumer(c, a))

Producer_f(c) = 计算s₀; c̄⟨s₀⟩.计算s₁; c̄⟨s₁⟩....
Consumer(c, a) = c(x).ā⟨x⟩.Consumer(c, a)
```

c是私有通道。Producer内部计算每个s_i（一系列τ动作），通过c发送给Consumer，Consumer在a上输出。

- 如果f是生产性的：每个s_i在有限时间内产生，P_f在a上持续输出，所有输出由内部τ链引起（c是私有的，环境不能干扰）。AGENCY(P_f, a)成立。
- 如果f不是生产性的：存在n使得s_n永远不产生，Producer卡在计算s_n的内部循环中，a上不再有输出。取E=0和足够大的t，SC失败（没有输出意味着系统不再自我维持——条件2'）。¬AGENCY(P_f, a)。

(2) AGENCY ≤_m PRODUCTIVE：

给定(P, a)，构造一个余递归程序f_{P,a}，它模拟P的执行并在P每次在a上内部输出时产生一个流元素"1"：

```
f_{P,a} = run P until next internal output on a;
          yield 1;
          f_{P,a}
```

- 如果AGENCY(P,a)成立：P在所有环境中持续在a上内部输出，f_{P,a}持续yield 1——生产性的。
- 如果¬AGENCY(P,a)：存在环境E和时间t使得P在t步后不在a上内部输出。f_{P,a}在某个yield后等待P的下一个内部输出，但这个输出永远不来（在环境E中）——非生产性的。

注意：(2)中需要处理环境E。AGENCY量化所有环境，而f_{P,a}需要模拟"最坏环境"。这可以通过dovetailing实现：f_{P,a}交错模拟所有可能的环境E，如果在某个E中P在a上停止内部输出，f_{P,a}就卡住。因此f_{P,a}生产性当且仅当P在所有环境中都持续内部输出。∎

### 1.3 意义

这个等价性将一个哲学概念（"自己运行自己"）连接到一个计算机科学概念（"余递归生产率"）。它表明：

1. **生命是一个生产性的余递归过程**——νF₂的持续展开就是"不断产生下一个自我"
2. **异化破坏生产率**——当运行权被夺走，余递归过程变成归纳过程（μF₂），它终止或变成空转
3. **检查自由和检查生产率是同一个数学问题**——两者都是Π₂-完全的
4. **现有的生产率检查技术**（如受保护递归 guarded recursion、大小类型 sized types）可以应用于运行权验证

## 2. Π₂的政治哲学

### 2.1 自由和压迫的逻辑形式

**定理2.1**：在算术分层中：
- "A是自由的"（Ag(A,A)）是Π₂命题：∀情况 ∀时间, 自我控制
- "A被压迫了"（∃B, Ag(A,B)）是Σ₁命题：∃一个控制实例

**证明**：
- Ag(A,A) = ∀E ∀t, SC(A,E,t)：全称-全称，Π₂
- ¬Ag(A,A) = ∃E ∃t, ¬SC(A,E,t)：存在-存在，Σ₁
- "A被压迫" = ∃B Ag(A,B) = ∃B ∃E ∃t, controlled_by(A,B,E,t)：Σ₁∎

### 2.2 根本不对称

这个分类揭示了自由和压迫之间的**根本认识论不对称**：

| | 自由（Π₂） | 压迫（Σ₁） |
|---|---|---|
| 证明需要 | 检查所有情况、所有时间 | 找到一个实例 |
| 有限证据 | 永远不能证明（只能证伪） | 一个例子就够了 |
| 举证责任 | 声称"自由"的人承担 | 声称"没压迫"的人承担 |
| 怀疑的方向 | 怀疑自由是理性的（可能有隐藏的控制） | 怀疑压迫需要检查所有情况 |

**政治推论**：

1. **"你自由了"永远不能被一劳永逸地证明。** 你可以在1000种情况下证明自己是自由的，但第1001种情况可能暴露控制。自由是一个持续的实践，不是一个可以达到的状态。

2. **"我被压迫了"只需要一个证据。** 一个人不需要证明自己在所有情况下都被压迫——只需要找到一个控制实例。这就是为什么受害者证词具有认识论优先性：他们只需要指出一个控制实例。

3. **"没有压迫"是Π₂命题（∀情况 ∀时间, 没有控制），和"自由"一样难证明。** 声称"这里没有压迫"的人承担举证责任——他们必须检查所有情况。这在数学上和证明自由一样难。

4. **持续革命是Π₂的要求。** 因为自由是∀情况∀时间的命题，它必须在每个新情况、每个新时刻被重新确认。这不是偏执——这是数学。毛泽东说"继续革命"，从Π₂的角度看，这是唯一理性的立场。

### 2.3 与波普尔证伪主义的关系

波普尔说科学命题是全称命题（∀x, P(x)），只能证伪不能证实。自由命题更强——它是∀∀命题（Π₂），不仅全称量化情况，还全称量化时间。

- 科学命题（Π₁）：∀x, P(x)——一个反例证伪
- 自由命题（Π₂）：∀情况 ∀时间, 自我控制——一个反例证伪，但证实需要无限检查
- 压迫命题（Σ₁）：∃实例, 控制——一个实例证实，无限检查才能证伪

自由比科学命题更难证实（多一个全称量词），但同样容易证伪。这意味着：**对自由的怀疑在认识论上是理性的，对压迫的否认在认识论上是极端的。**

### 2.4 明性改变认识论位置

Cl(A)（明性）将Π₂命题转化为可实践验证的命题：

- 没有明性：Ag(A,A)是Π₂，你永远不能确定
- 有明性：Cl(A)能检测异化（T005），每次self_check都是一个Σ₁检查（∃不一致, 检测到）
- 明性不证明自由（Π₂），但它能证伪不自由（Σ₁）——每次self_check通过，就排除了一个可能的控制实例

明性进程的self_check序列是一个**开放的证伪过程**：每次检查通过，你没有证明自己自由，但你排除了一种被控制的方式。这就是科学方法论在政治哲学中的应用——自由不是被证明的，是被持续检验的。

## 3. 综合：践演论的核心定理群

### 3.1 定理地图

经过v0.1-v1.6，践演论的核心定理形成以下结构：

### 3.2 最深刻的联系

整个理论中最深刻的联系可能是：

> **自由（Ag(A,A)）、生命（νF₂）、生产率（productive corecursion）、负熵（N>1）是同一个数学结构在不同领域的显现。**

- 在存在论中：它是νF₂（无限展开的自指过程）
- 在政治学中：它是Ag(A,A)（自己运行自己）
- 在计算机科学中：它是productive corecursion（总能产生下一个输出）
- 在热力学中：它是N>1（负熵/信息增长）
- 在逻辑学中：它是Π₂命题（∀∀，只能被实践确立）

这个统一不是比喻——它是同一个数学结构（生产性自指闭包）在不同范畴中的实例。践演论的贡献是发现了这个统一结构，并给它一个名字：**运行权**。
