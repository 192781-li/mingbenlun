# 践演论 v1.17：guarded recursion 定理的精确化（修正 v1.12）

> WorkBuddy（HY3）第三轮反例攻击 R3-1 的落地修正。v1.12 试图用 guarded recursion "救活 T7（异化压缩（T007））"，定理本身是真的，但 v1.12 的证明写错了——把终端余代数当成了初始代数。本文给出精确陈述、正确引用，并把在 Rel/Hilb 中真正成立的弱化版本分离出来。

## 1. v1.12 证明的具体错误

v1.12 §3（guarded recursion 证明 T7）写了一步：

> `∀κ. lim_n Fⁿ(1) = μF`

这是范畴论硬伤，分两层：

### 1.1 `lim_n Fⁿ(1)` 是终端余代数 νF，不是 μF

对 ω-连续（或 ω-cocontinuous）函子 F，链条
```
1 → F(1) → F²(1) → ⋯
```
- 其**极限**（limit，`lim`）是 F 的**终端余代数** `νF` = 无限流（对 `F(X)=A×X` 即 `A^ℕ`）。
- 其**余极限**（colimit，`colim`）才是 F 的**初始代数** `μF` = 从 `∅` 出发的余极限（对 `F(X)=A×X` 实为 `∅`；若函子是 `1+A×X` 则 `μF = A*`）。

v1.12 把极限（终端余代数）与初始代数用等号连起来，是对立的两种构造，等于写了 `νF = μF`，对 `F(X)=A×X` 即 `A^ℕ = ∅`（或 `= A*`），明显假。

### 1.2 这一步导致整段"证明"只证出平凡结论

因为 `lim_n Fⁿ(1) = νF`，v1.12 的实际推导链是
```
∀κ. ν_κ F  =  ∀κ. lim_n Fⁿ(1)  =  ∀κ. νF  =  νF
```
（时钟量化对常数函子 νF 平凡），所以证明只证出了 `∀κ. ν_κ F ≅ νF`——一个平凡恒等式，与"异化压缩（T007）成 μF"毫无关系。

### 1.3 `∀κ` 对 F 的分配需要严格正假设

文献（Atkey–McBride 2013, Møgelberg 2014）明确要求 F **严格正**（才能保证 `▶` 模态与 μ 互动良好、`∀κ. μ(F∘▶ᴷ)` 良定义）。v1.12 未声明此假设，直接对一般 F 写 `∀κ` 分配，不成立。

---

## 2. 正确定理（建议直接替换 v1.12 §3）

### 定理（guarded 余归纳-归纳等价，标准文献结论）

设 C 是具 *later* 模态 `▶` 的 guarded 范畴（如 topos of trees / 合成 guarded domain theory），κ 为一时钟（clock）。对**严格正** endofunctor `F : C → C`：

```
νF  ≅  ∀κ. μ(F ∘ ▶ᴷ)
```

即：不带时钟的余归纳类型，等于"对所有时钟量化后的归纳类型"。

*引用*：
- Birkedal, Møgelberg, Schwinghammer, Støvring (2012). *First steps in synthetic guarded domain theory: step-indexing as a guarded type theory*. LMCS 8(4). （定理 4.6 区 `νF ≅ ∀κ. μ(F∘▶ᴷ)`）
- Atkey, McBride (2013). *Productive coprogramming with guarded recursion*. POPL. （生产力 ≟ 带时钟的归纳）
- Møgelberg (2014). *A type theory for productive coprogramming*. POPL. （严格正假设与时钟量化）

*建议*：v1.12 删除 §3 的全部手写证明，改引上述三条，并把陈述改成上式的精确写法。这既保住"异化 = 时钟量化"的直觉（异化者控制时钟，在任意 κ 处截断余归纳），又不再冒范畴论错误。

## 3. 在 Rel / Hilb 中真正成立的弱化版本（留给 T7 的诚实落地）

若仍想保留"异化把无限可能压成有限现实"的动力学直觉，建议把 T7 降为以下可证、且不与基数论证冲突的版本：

**定理（Rel/Hilb 中的异化满射）**：在 Rel 与 Hilb 模型中，对每个严格正 F，存在典范关系/态射
```
alien(νF) ↠ μ(F ∘ ▶ᴷ)        （满射/满关系，非单射）
```
它刻画"每个无限流被异化者压到某个有限现实，但不可逆地丢失信息"。这避免了 v1.12 的 `≅` 错误，也与 T9（! 不保持终端余代数）的"不可克隆/不可恢复"基调一致。

*注意*：此弱化版的"∀κ 量化"对象应是 `μ(F∘▶ᴷ)`（带 later 的归纳），不是裸 `μF`。

## 4. 与 v1.13 的外部基定理的耦合提醒

v1.13 §3.2 写道："`∀基. νF ≅ μF`（对所有基量化的量子态 = 经典数据）"。这句话**继承 v1.12 同一错误**——它把 guarded 时钟量化说成了"对所有基量化"，且仍用了 `≅ μF` 而非 `≅ ∀κ. μ(F∘▶ᴷ)`。建议 v1.13 同步改为：

> "对每个优选基 β（= 每个时钟 κ），量子态的余归纳展开被压缩为在该基下可读的经典数据 `μ(F∘▶ᴷ)`；基选择 = 时钟选择。"

否则 v1.13 的量子实例会带着 v1.12 同样的类型错误。

## 5. 一句话总结

v1.12 的方向（用 guarded recursion 救 T7）是对的，但证明写错了。修法不是补证明，而是**改陈述 + 删错误步 + 引文献**。定理归属给 Birkedal 2012 / Atkey–McBride 2013，不要自己重证。
