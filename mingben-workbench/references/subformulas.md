# 量论子公式形式化

> 主公式 M=α·T·N 之下，T和N各有内部结构。本文档形式化子公式，明确K和Ω的位置。
> 原则：只给结构，不拍脑袋给函数形式。具体函数须有数据标定，否则只写关系方向。

---

## 一、T的子公式：原生稳态基准

T衡量个体生理稳态的完整程度，范围[0,100]，有界。

### 内部结构

T由四个分量构成：

| 分量 | 符号 | 内容 | 方向 |
|---|---|---|---|
| 睡眠恢复 | T_s | 睡眠时长、质量、节律 | T_s↑ → T↑ |
| 代谢健康 | T_m | 营养、内分泌、免疫、脏器功能 | T_m↑ → T↑ |
| 环境暴露 | K | 污染、毒素、噪声、居住条件、辐射 | K↑(恶化) → T↓ |
| 应激负荷 | T_k | 慢性压力、焦虑、创伤、过劳 | T_k↑(负荷大) → T↓ |

### 结构关系

```
T = f(T_s, T_m, K, T_k)
```

**约束条件：**
1. 任何一个分量为零（长期失眠T_s=0、脏器衰竭T_m=0、剧毒环境K→∞、极端应激T_k→∞），T→0。这是生命系统的性质——器官衰竭可以导致整体死亡。
2. K和T_k是**侵蚀项**：它们不直接构成稳态，而是侵蚀T_s和T_m。好的环境（K低）和低应激（T_k低）让T_s和T_m自然达到遗传上限；坏的环境和高应激压低它们。
3. T有遗传上限T₀（约100），不被K和T_k侵蚀时T→T₀。医学和生物技术可以在有限程度上提高T₀，但不能取消物理约束。

### K（环境系数）的精确定义

K不是独立维度，是T的内部参数。它衡量环境对生理稳态的侵蚀程度：
- K=0：环境零侵蚀（清洁空气水、安静、适宜温度、无毒）
- K→∞：环境致命（剧毒、高辐射、极端温度）
- K的具体测量：空气污染指数、水质指标、噪声分贝、居住密度、职业病暴露时间等

K进入T而不是进入N，因为它直接作用于生理基准——污染让人生病，这是T在跌，不是N在跌。但K和N有交互：N<1的社会（资本逐利）往往K也高（污染外部化），这是反自指在环境和身体上的双重消耗。

## 二、N的子公式：负熵比率

N = 劳动产出的负熵 ÷ 劳动消耗的负熵，范围(0,∞)，N=1为持平线。

### 内部结构

N由四个分量构成：

| 分量 | 符号 | 内容 | 方向 |
|---|---|---|---|
| 产出返回率 | N_r | 劳动产出中返回劳动者自身的比例（vs被抽走） | N_r↑ → N↑ |
| 公共服务 | N_p | 免费医疗、教育、住房、养老对消耗的补偿 | N_p↑ → N↑ |
| 劳动保护 | N_l | 工时限制、安全条件、休息权对过度消耗的阻止 | N_l↑ → N↑ |
| 群体共生 | Ω | 互助、信任、共同体支持对个体消耗的分摊 | Ω↑ → N↑ |

### 结构关系

```
N = Ω × g(N_r, N_p, N_l)
```

**约束条件：**
1. Ω是乘数：Ω=0时（原子化社会，没有任何互助），即使N_r/N_p/N_l不错，N也被压低——因为个体独自承担所有风险。Ω→1时（紧密共同体），互助和分摊显著降低个体的净消耗。
2. N_r是核心：如果劳动产出全部被抽走（N_r=0，奴隶制），N→0，不管其他项多高。这是为什么生产资料所有制是根本——它决定N_r。
3. N_p和N_l是补偿项：公共服务和劳动保护不直接增加产出返回，但它们减少劳动者的必要消耗（免费医疗减少健康支出，8小时工作制防止过劳消耗），从而提高净比率。
4. Ω不只是"社会资本"——它有存在论根基：Ω衡量的是应（第二人称呼答）在社会结构中的实现程度。人和人之间真实的呼-答越多，互助越有效，Ω越高；互相监视、互相消耗、原子化，Ω越低。

### Ω（群体共生系数）的精确定义

Ω不是独立维度，是N的内部乘数。它衡量社会关系对个体净负熵的放大或缩减：
- Ω→0：原子化社会，人人互相防备，没有互助，个体独自承担一切风险
- Ω=1：持平——社会关系既不放大也不缩减个体净负熵
- Ω>1：互助共生——共同体分摊风险、共享产出，个体的净收益被社会关系放大
- Ω可以大于1（和N一样无上限），因为"1+1>2"的协作效应是真实的：两个人互助生存的概率高于两个孤立个体之和

Ω的具体测量指标：社会信任度、互助网络密度、社区参与率、合作社覆盖率、公共空间使用频率等。

## 三、子公式与六维框架的对应

| 六维框架 | 量论对应 | 位置 |
|---|---|---|
| 个体稳态 | T | 主公式 |
| 生产关系公平 | N（核心是N_r） | 主公式 |
| 环境承载 | K | T的子参数 |
| 共同体 | Ω | N的子参数 |
| 异化程度 | l′=(1-N) | 主公式派生 |
| 青年希望 | 激活因子（乘法项） | 独立于M但乘入社会总健康 |

社会总健康 H = M × A_youth，其中A_youth∈[0,1]是青年希望系数。A_youth=0时H=0（年轻人没有希望的社会是死路一条），A_youth=1时不抑制M。

---

## 四、形式化纪律

1. **不拍脑袋给函数形式。** f()和g()的具体形式需要真实数据标定，在没有数据之前只写约束条件和方向。
2. **不假装精确。** T_s、T_m、K、T_k、N_r、N_p、N_l、Ω的测量方法需要各自的研究纲领，不是哲学能给的。
3. **子公式服从主公式。** K和Ω归位在T和N内部，不独立出来和α、T、N并列——阴不压阳，结构不反客为主。
4. **子公式也是可错的。** 以上结构是当前最好的猜想，被数据证伪就改。
