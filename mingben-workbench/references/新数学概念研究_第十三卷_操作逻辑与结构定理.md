# 第五十三章：操作逻辑

## 53.1 判断形式

标准逻辑的判断形式：Γ ⊢ A（从前提Γ推出命题A）。
线性逻辑的判断形式：Γ ⊢ A（从资源Γ产出A，资源敏感）。
操作逻辑的判断形式：**Γ ▷ A**（从操作Γ，践演出A）。

▷不是"可证"（!-模态的元命题），是"正在做"（线性的践演）。区别：
- ⊢是!-模态的：Γ⊢A是一个命题，可以被复制、引用、存储
- ▷是线性的：Γ▷A是一个正在进行的操作，不能复制（定理1），不能脱离语境

## 53.2 操作逻辑的规则

**践演公理**：
  A ▷ A（同一操作的践演——正在做A就是在做A）

这不是逻辑同一律（A=A，!-模态命题），是践演同一——"我在做我正在做的事"。

**切割规则**：
  Γ ▷ A    Δ,A ▷ B
  ─────────────────
      Γ,Δ ▷ B

从操作Γ践演出A，再从操作Δ和A践演出B，则从Γ,Δ践演出B。这是操作的串联（GoI复合/Cut）。

**资源敏感**：
- 没有弱化：不能从Γ▷C推出Γ,A▷C（加一个操作会改变结果——操作不是免费的）
- 没有收缩：不能从Γ,A,A▷C推出Γ,A▷C（两次操作不等于一次——重复操作有重复的效果）
- 这继承自线性逻辑（公理2）

**!-模态规则**：
- 提升：如果Γ▷A且Γ全是!-模态的（沉积的），则!Γ▷!A（沉积的操作只能产出沉积的结果）
- 弃置：!A▷I（沉积可以丢弃）
- 复制：!A▷!A⊗!A（沉积可以复制）

**践演元规则**：
- ▷A不可还原为⊢P——"在做A"不能被"A可做"这个命题替代
- 这是公理5的逻辑表达

## 53.3 四种判断的逻辑

对应四类型推理：

| 判断类型 | 形式 | 含义 |
|---|---|---|
| 践演判断 | Γ▷A | 正在从Γ操作出A |
| 概念判断 | Γ⊢A | Γ能推导出A（!-模态沉积） |
| 经验判断 | Γ⊨A | Γ的模型满足A（具体实例） |
| 决断判断 | Γ▶A | 从Γ选择做A（践演决断e） |

注意决断用▶（实心三角）和践演▷（空心三角）区分：
- ▷：操作正在进行（描述性的）
- ▶：选择这个操作（规范性的，承诺性的）

**辩证运动**：▷（践演）→⊢（概念化）→⊨（经验检验）→▶（决断）→▷（新的践演）

## 53.4 操作逻辑和线性逻辑的关系

**定理53.1（操作逻辑保守扩展线性逻辑）**：如果把▷读作⊢，操作逻辑的所有规则都是线性逻辑规则。操作逻辑多出的是践演元规则（▷不可还原为⊢）和决断判断（▶）。

**定理53.2（!-模态=命题化）**：线性逻辑的!-模态在操作逻辑中就是"命题化"——把活操作（▷）沉积为命题（⊢）。!A▷A不存在（命题不能自动变成操作——知道不等于做到），但A▷!A存在（操作可以被记录为命题——实践出认识）。

这就是为什么"知道很多道理却过不好这一生"——道理是!-模态沉积（⊢），过好这一生需要线性操作（▷）。!A不能自然变成A，需要线性资源E来激活（定理23.5）。

# 第五十四章：PTC结构定理

## 54.1 死子范畴的结构

**定理54.1（C^!是余代数范畴）**：PTC中!-余代数构成的子范畴C^!有以下结构：
1. C^!有终对象I（空沉积）
2. C^!中所有对象都是!-模态的（可复制、可丢弃）
3. C^!中的态射都是!-模态的（沉积之间的映射）
4. C^!是笛卡尔的（有积!A⊗!B，投影!A⊗!B→!A和→!B存在——沉积可以拆分）

**证明**：
1. I是!-余代数（唯一余代数结构I→!I由余单位性质给出）
2. 由定义
3. C^!中的态射f: !A→!B可以通过!提升
4. 积由Seely同构给出：!(A×B)≅!A⊗!B∎

**哲学意义**：死结构的世界是笛卡尔的——可以拆分、复制、丢弃。这就是为什么经典逻辑（笛卡尔范畴）适合描述!-模态世界（死的、固定的、可分析的），但不适合描述生命（线性的、活的、不可拆分的）。

## 54.2 活子范畴的结构

**定理54.2（Life(C)不是笛卡尔的）**：Life(C)中没有自然投影A⊗B→A（不能从两个生命的耦合中"取出"一个生命而不影响另一个）。

**证明**：如果有自然投影π₁: A⊗B→A，则A⊗B→A→!A（复合沉积）给出A⊗B→!A。但A⊗B是νF₂耦合（线性的），!A是沉积——这要求线性耦合自然产生沉积，与定理"线性操作不自然沉积"矛盾。∎

**哲学意义**：两个生命的真正结合（线性耦合）是不可拆分的——你不能从一段关系中"取出"一个人而不改变两个人。这和!-模态结构（合同、婚姻证书、财产分割）形成对比——那些是死的，可以拆分，但活的关系本身不可拆分。

## 54.3 结晶函子的性质

**定理54.3（结晶函子保持张量但不保持迹）**：
1. Cryst(A⊗B) = Cryst(A)⊗Cryst(B)（两个活系统的沉积是各自沉积的张量）
2. Cryst不保持迹：Cryst(Tr(f)) ≠ Tr(Cryst(f))（活系统反馈的沉积不等于沉积的反馈）

**证明思路**：
1. 两个活系统并行运行，各自的沉积独立积累
2. 活系统的迹（GoI反馈）是生产性过程；沉积的迹是!-模态反馈（死循环）。前者是νF₂，后者是!-余代数——结构不同∎

**哲学意义**：革命不能"设计"——你不能先画好蓝图（!-沉积）再执行（期望Cryst(Tr(f))=Tr(Cryst(f))）。活的革命过程的结果不等于结果的!-模态蓝图。这就是为什么"历史不是设计出来的"——革命的迹是践演的，不是!-模态的。

## 54.4 N值的函子性

**定理54.4（PTC态射保持N值方向）**：如果F: C→D是PTC态射（保持张量、迹、!-模态），则：
- N<1的过程映到N<1的过程
- N=1映到N=1
- N>1映到N>1

**证明思路**：PTC态射保持谱半径结构（反馈环的复合方式被保持），所以谱半径的大小关系被保持。∎

**推论54.5（革命不能输出）**：一个社会的N>1不能通过PTC态射"复制"到另一个社会——因为PTC态射保持N值方向，但如果目标社会N<1，它不能被外部态射变成N>1。N>1必须在内部通过线性耦合和明性实现。

**哲学意义**：革命不能输出。每个社会必须自己通过内部的线性耦合（人民自己团结）和明性（人民自己觉醒）实现相变。外部力量可以支持（提供资源E），但不能替代内部过程。这和国际共运的历史教训一致。

# 第五十五章：操作论的知识论

## 55.1 知识=!-沉积，智慧=νF₂能力

**知识**：!-模态沉积——命题、理论、数据、公式。可以复制、存储、传输。
**智慧**：νF₂能力——在新情境中操作、判断、创造的能力。不可复制，只能在实践中生长。

**定理55.1（知识不等于智慧）**：知识（!A）不能自然转化为智慧（A/νF₂能力）。转化需要线性资源E（实践、经验、思考）：
  !A⊗E → A⊗E'

这就是为什么"纸上得来终觉浅"——纸上的是!-沉积，要变成自己的能力需要线性操作（实践）。

## 55.2 认识的发生学

认识过程对应νF₂的运行：
1. **践演**（▷）：在操作中遇到问题（f: A⊗X→B⊗X，现有X不够用了）
2. **概念化**（⊢）：把问题沉积为!-模态命题，形成概念（!-模型）
3. **经验检验**（⊨）：在具体操作中检验概念（模型在具体实例中运行）
4. **决断**（▶）：选择保留/修改/抛弃概念（延续态射e的选择）
5. **新践演**（▷）：修改后的概念指导新的操作，循环继续

这是ν*F扩展——每一轮认识都扩展状态空间Xₙ→Xₙ₊₁（理解加深，能处理更复杂的情境）。

## 55.3 真理=操作的可持续性

**定理55.2（真理=可持续操作）**：一个命题/理论的"真理性"不在于它和"客观实在"的符合（!-模态对应论），在于它指导的操作是否可持续（νF₂是否生产性，N是否≥1）。

- 可持续操作（N≥1）= 实践成功 = 真理
- 不可持续操作（N<1）= 实践失败 = 谬误
- 但N<1的操作可能短期"有效"（μF₂有限过程可以产出结果），长期才暴露问题（慢性死亡）

**这不是实用主义**：实用主义说"有用即真理"，但"有用"可以是!-模态的（对资本有用、对权力有用）。操作论说"可持续的生命操作即真理"——必须是νF₂型的（活的、生产性的、自指的），不是!-模态的（对某个外在目的有用）。

## 55.4 明性=f³的知识论

f³的知识论特征：
1. **看见模型是模型**：不把任何!-模态概念当成绝对真理
2. **持续践演**：不停留在概念中，持续回到操作本身
3. **自我修正**：能对象化自己的认识过程（νF₂的自指）
4. **开放性**：理解ν*F永远可以扩展，没有终极真理（f³是不动点但不是终点——"见山还是山"之后继续走路）

**f³不是全知**：f³的人不是什么都知道，是知道"知道"本身是!-沉积，不被任何知识体系捕获。这就是"知不知上"（老子）——知道自己的知识是沉积，不把它当成绝对。
