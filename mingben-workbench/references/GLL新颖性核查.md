# GLL新颖性核查报告

## 核查日期
2026-08-26

## 核查范围
子结构逻辑、线性逻辑、类型论、进程演算、博弈语义中是否已存在"增长"（growth）作为结构规则，或等价的运行时类型空间扩展机制。

## 已有工作（按相关度排序）

### 1. π-calculus 的 restriction 算子 (νx.P) — 最接近
- **来源**：Milner, Parrow, Walker (1992)
- **做了什么**：(νx)P 创建一个新名字x（通信通道），在P内部使用。类型规则(Nu)允许在语境中添加新名字。
- **与GLL的关系**：这是"语境增长"的一种形式——新名字被添加到语境中。
- **关键区别**：
  - π-calculus的新名字都是通道类型（同一类型），不扩展**状态空间的维度**
  - 没有生产性保证（进程可以死锁/空转）
  - 没有线性资源控制（session types部分解决，但不完整）
  - 没有第一人称位置
  - νx是**名字生成**，ν*F是**能力/类型成长**——前者是"有了一个新的同类东西"，后者是"有了一个以前不存在的类别的能力"

### 2. 动态可扩展安全格 (Dynamically Extensible Security Lattice)
- **来源**：Kobayashi类型信息流分析的扩展（2026年Moonlight综述）
- **做了什么**：运行时向安全格添加新级别，保持类型安全
- **与GLL的关系**：运行时类型结构扩展，非常接近ν*F
- **关键区别**：
  - 只扩展安全级别（全序/格结构），不扩展过程的状态空间
  - 没有线性资源敏感性
  - 没有生产性保证
  - 应用领域是信息流控制，不是通用编程

### 3. 守护递归 / 大小类型 / Clocked Type Theory (CloTT)
- **来源**：Nakano (2000), Bahr et al. (2018)
- **做了什么**：▻（later）模态保证生产性，递归调用必须在构造子下
- **与GLL的关系**：GLL的生产性检查直接基于此
- **关键区别**：
  - 类型空间在编译时固定，不增长
  - ▻是"下一步可用"，不是"下一步长出新能力"
  - 没有线性资源控制（可以与线性类型结合，但那是独立工作）

### 4. 行多态 (Row Polymorphism)
- **来源**：Rémy (1989), Gaster & Jones (1996)
- **做了什么**：记录类型可以有"更多字段"，通过行变量表达
- **与GLL的关系**：ν*F的fields可以看作行
- **关键区别**：
  - 完全静态：所有字段在编译时已知
  - 没有运行时成长
  - 没有生产性保证

### 5. 线性类型 / Rust所有权系统
- **来源**：Girard (1987), Wadler (1990), Rust (2010)
- **做了什么**：资源必须用恰好一次，不能隐式复制/丢弃
- **与GLL的关系**：GLL的线性维度直接基于此
- **关键区别**：没有增长，没有生产性（Rust不检查无限循环是否产出）

### 6. CHERI / 线性能力系统
- **来源**：Watson et al. (Cambridge)
- **做了什么**：硬件级线性能力，不能复制/伪造，可以委托和撤销
- **与GLL的关系**：线性资源控制的硬件实现
- **关键区别**：能力在编译时/加载时确定，不在运行时成长出新类型

### 7. CRDT G-Set（单调增长数据结构）
- **做了什么**：只增不删的集合，单调增长
- **关键区别**：数据结构层面的增长，不是类型系统层面；没有线性/生产性

### 8. 混合逻辑 / 认知逻辑中的学习算子
- **做了什么**：模态算子表示"在某个世界/状态下为真"，认知逻辑有"知道"算子
- **关键区别**：逻辑层面，不是类型论；没有线性/生产性；不涉及类型空间成长

## 结论

### GLL中不是新的部分（前人已做）
1. **线性类型**：Girard线性逻辑、Rust所有权 → 成熟
2. **生产性检查**：Nakano守护递归、CloTT、Agda余归纳 → 成熟
3. **语境添加新名字**：π-calculus ν算子 → 成熟
4. **可扩展记录**：行多态 → 成熟
5. **运行时结构扩展**：动态安全格 → 有先例
6. **单调增长**：CRDT → 数据结构层面

### GLL中新的部分（文献中未找到）
1. **线性 + 生产性 + 运行时类型空间增长三者同时成立**：
   - 没有任何系统同时保证：资源不可复制（线性）、每步必须产出（生产性）、状态空间可以在运行时获得新类型的能力（增长）
   - π-calculus有线性+新名字但没有生产性和类型维度增长
   - 守护递归有生产性但类型空间固定
   - 行多态有扩展但是静态的

2. **ν*F作为余极限的范畴论语义**：
   - ν*F = colim(νF₀ → νF₁ → νF₂ → ...)
   - 增长链上的终余代数余极限
   - 文献中未找到此构造

3. **!与ν*F的对偶性**：
   - !管收缩（多→一，沉积/复制）
   - ν*F管增长（一→多，扩展/成长）
   - 定理：!不穿透ν*F（定理20的推广）
   - 这个对偶在文献中未找到

4. **第一人称位置（践演位置）**：
   - 博弈语义中的Player位置是已知的
   - 但将其作为公理系统的践演根基（公理0），并与线性+生产性+增长结合，是新的

5. **"增长"作为子结构逻辑的第四结构规则**：
   - 传统三规则：弱化（丢弃）、收缩（复制）、交换（重排）
   - GLL提出：增长（扩展）——单调地向语境添加新类型的能力
   - 这在子结构逻辑文献中未被提出为结构规则

### 新颖性评级
- **组合新颖性**：高。五个特性的组合没有先例。
- **构造新颖性**：中高。ν*F余极限构造和!-ν*F对偶是新的数学对象，但建立在成熟的范畴论（余极限、余代数、余单子）之上。
- **风险**：中。可能有未检索到的相关工作（特别是俄语/法语/日语文献，或1990年代线性逻辑黄金期的未被引用的工作）。建议在arXiv发布前请线性逻辑/类型论专家审阅。
