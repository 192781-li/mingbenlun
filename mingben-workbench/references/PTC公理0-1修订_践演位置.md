# PTC公理系统修订：公理0（践演位置）与公理1（交互闭结构）

## 1. 问题

旧公理1直接预设闭范畴：Hom(A,B) ≅ Hom(1, A⊸B)。这意味着操作被当作对象——操作可以被"物化"。

但"感先于操作"要求：在操作被物化之前，必须先有一个见证操作的**位置**（第一人称）。旧公理系统从第三人称结构开始，把第一人称丢了。

这导致：
- 定理20证明了"生命不可还原"，但说不出不可还原的是什么——因为感在数学里没有位置
- 公理的践演根基（"在感"是公理能被陈述的前提）没有被形式化
- 与旧哲学犯了同样的错误：用第三人称结构描述一切

## 2. 修订方案

### 2.1 从范畴到复范畴

**旧起点**：范畴（对象+态射，闭结构被预设）
**新起点**：**带位置的复范畴**（positioned polycategory）

复范畴（Szabo 1975, Cockett-Seely 1997）中：
- 复合是原初的（不是对象之间的派生概念）
- 对象是复合的端点，不是先在的实体
- 张量积⊗和内部同态⊸是**构造出来的**（当可表性条件成立时），不是预设的

这对应哲学：
- 操作（复合）是原初的
- 实体（对象）是操作稳定模式的物化
- 物化（⊸的构造）是有条件的，不是必然的

### 2.2 位置（Position）

**公理0（践演位置）**：

每个复范畴中的态射 Γ →_p Δ 都发生在一个**位置** p。

位置满足：
1. **自反性**：每个位置p有平凡见证 id_p（在感本身）
2. **复合性**：如果 f: Γ →_p Δ 且 g: Δ →_q E，则 g∘f: Γ →_{p;q} E（位置沿复合传递）
3. **不可物化**：位置p本身不是范畴的对象。不存在对象P使得 Hom(p, q) 对应位置之间的态射。位置是态射的**维度**，不是态射的**端点**。

位置的数学实现：**博弈语义中的Player位置**。

在博弈语义中（Hyland-Ong, Abramsky-Jagadeesan-Malacaria 1994）：
- 游戏A有Player（P，我方/第一人称）和Opponent（O，环境/第三人称）的着法
- 策略σ是P的着法规则——它 inherently 是第一人称的
- 线性蕴涵A⊸B是一个博弈：P通过回应A中的O着法并在B中出招
- **策略就是"从P位置看"的交互过程**

感 = Player位置。不是一个东西，是"有一个P位置"这回事。

### 2.3 交互闭结构

**公理1（交互闭结构）**：

在带位置的复范畴中，当可表性条件成立时，构造内部同态：

A ⊸_{p→q} B := 从位置p到位置q的交互博弈

这不是预设的，是从复范畴的复合结构中**构造**出来的。

关键定理（从公理0推出）：

**定理0（位置不可物化）**：不存在自然变换将位置p本身表示为一个对象。

证明思路：假设存在对象P_p表示位置p。则任何从p位置见证的态射f: A→B都可以被表示为P_p⊗A→B（位置被物化为资源）。但位置是见证的维度，不是额外资源——把它变成资源意味着可以复制它（通过!），而同一个第一人称位置不能被复制（这将意味着有两个"我"）。矛盾。∎

**哲学对应**：感不是实体，不能被对象化。你不能把"在看"变成一个"被看的东西"。这就是"感先于操作"的数学表达。

### 2.4 与旧公理的关系

旧公理1（闭范畴）是新公理0+1的**特例**：
- 当我们忽略位置（取"上帝视角"，即没有固定P位置）时
- 当可表性条件成立时
- 带位置的复范畴退化为闭范畴

这意味着：旧公理系统没有错，它是新系统在"第三人称抽象"下的投影。但它遗漏了位置维度——而这个维度恰恰是感、自由意志、不可还原性的数学根基。

## 3. 对已有定理的影响

### 3.1 定理20的推广

旧定理20：!不穿透νF₂（生命不可资本化）

新表述：**从任何位置p，!都不能把νF₂过程还原为p位置上的对象。**

更强的推论：
- 不仅"生命不可复制"（定理20）
- 而且"生命的第一人称维度不可对象化"（定理0）
- 这两个不可还原性是**同一个结构事实的两个面向**：!只能作用于对象（物化的东西），但νF₂过程的核心——它的Player位置——根本不是对象

### 3.2 f³（明性）的数学定义

旧定义：f³是"看见模型是模型"，是f层级的不动点。

新定义：**f³ = 位置转换**。

- f¹（自在）：在位置p中操作，不知道p
- f²（自为）：在位置p中操作，有p的模型（p被表示为对象）
- f³（自觉/明性）：从位置q看见位置p本身——包括看见"看见p"的位置q

f³不是"更高级的状态"，是**位置的自指**：p位置看见p位置。这在博弈语义中对应：策略不仅对O的着法回应，而且意识到自己在博弈——可以修改自己的策略。

**定理（f³不动点）**：f³之后没有f⁴，因为位置转换已经是最大的——从q看见p之后，你可以从r看见q，但这只是同一个自指结构的迭代，不是新的质变。

### 3.3 感通量G的重新定义

旧定义：G是过程之间的交互强度。

新定义：**G(p,q) = 从位置p到位置q的博弈中P着法的信息流量。**

感不是一个量，是**位置之间的通达关系**。G高意味着两个第一人称位置之间有真正的交流（线性耦合），G低意味着只有!-模态的单向传输（异化）。

## 4. 与博弈语义的精确对应

| 生命论概念 | 博弈语义对应 |
|---|---|
| 感 | Player位置（第一人称） |
| 操作/运行 | 策略（P的着法规则） |
| 环境/他者 | Opponent着法 |
| 交互（F₂） | A⊸B博弈中的P-O交替 |
| 生产性（νF₂） | 策略必须对每个O着法有P回应（ totality） |
| 线性（不可复制） | 策略是线性的（资源敏感） |
| 成长（ν*F） | 策略在博弈中获得新的着法（学习） |
| 明性（f³） | 策略可以修改自身（位置转换） |
| 反自指（!-寄生） | O的策略被复制而不回应P（死锁/空转） |
| 定理20 | P策略不能被!复制（复制的是着法记录，不是策略本身） |
| 定理0 | P位置不能被对象化为游戏中的一个着法 |
| 异化 | P的策略被O的!-模态策略取代（P不再出招） |
| 解放 | P重新获得出招权（γ≥β） |

## 5. 新公理系统完整列表

- **公理0（践演位置）**：每个态射发生在位置p；位置不可物化（定理0）
- **公理1（交互闭结构）**：复范畴中可表的交互构造为A⊸_{p→q}B
- **公理2（资源敏感）**：无自然收缩/弱化（线性）
- **公理3（指数余单子）**：!允许受控的收缩/弱化（Seely同构）
- **公理4（不动点）**：μ（归纳/有限）和ν（余归纳/无限）
- **公理5（守护递归）**：▷模态保证生产性
- **公理6（增长）**：ν*F允许位置p的语境单调扩展（GLL增长规则）

公理0是新增的。公理1从"预设闭范畴"改为"复范畴中构造闭结构"。公理2-5不变。公理6是GLL的增长规则。
