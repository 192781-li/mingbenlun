# 一般刻画定理：哪些函子可被!提升

> 操作范畴论 v0.6
> 2026-08-25
> 本章将定理13从Mealy机函子推广到一般多项式函子，刻画"!可分配"与"!不可分配"的精确边界。

---

## 1. 定义

在直觉主义乘法加法指数线性逻辑（IMAELL）中，**多项式函子**由以下语法生成：

$$F(X) ::= X \mid C \mid F_1 \otimes F_2 \mid F_1 \oplus F_2 \mid F_1 \& F_2 \mid F_1 \multimap F_2 \mid !F$$

其中$C$是不含$X$的常量公式。

**定义（分配律）**：称$F$**允许!-分配**，如果存在自然变换$\lambda^F: !F(X) \to F(!X)$，即矢列

$$!F(X) \vdash F(!X)$$

在IMAELL中可证。

---

## 2. 数据函子：!可分配

**定义（数据函子）**：多项式函子$F$称为**数据函子**，如果它由以下语法生成：

$$D(X) ::= C \mid X \mid D_1(X) \otimes D_2(X) \mid D_1(X) \& D_2(X) \mid !D(X)$$

即：只使用张量积$\otimes$、加法与$\&$和!模态，不使用$\oplus$，也不使用$X$出现在后件中的线性蕴含$\multimap$。

**定理15（数据函子的!-分配）**：对任意数据函子$D$，分配律$\lambda^D: !D(X) \to D(!X)$存在。

**证明**：对$D$的结构归纳。

- **$D(X) = C$（常量）**：$!C \to C$由弃置$\varepsilon_C$给出。✓
- **$D(X) = X$**：$!X \to !X$是恒等。✓
- **$D(X) = D_1 \otimes D_2$**：
  $$!(D_1 \otimes D_2) \xrightarrow{\mathrm{str}} !D_1 \otimes !D_2 \xrightarrow{\lambda^{D_1} \otimes \lambda^{D_2}} D_1(!X) \otimes D_2(!X) = D(!X)$$
  其中$\mathrm{str}$是余单子的monoidal strength（$!(A\otimes B) \multimap !A \otimes !B$在线性逻辑中可证：弃置得$A\otimes B$，$\otimes L$拆分，分别promote为$!A$和$!B$，$\otimes R$合并）。✓
- **$D(X) = D_1 \& D_2$**：
  $$!(D_1 \& D_2) \xrightarrow{\pi_1} !D_1 \xrightarrow{\lambda^{D_1}} D_1(!X)$$
  $$!(D_1 \& D_2) \xrightarrow{\pi_2} !D_2 \xrightarrow{\lambda^{D_2}} D_2(!X)$$
  其中$\pi_i$是：弃置$!(D_1\&D_2)$得$D_1\&D_2$，$\&L$投影得$D_i$，promote回$!D_i$（前提全是!模态）。再用$\&R$合并为$D_1(!X)\&D_2(!X)$。✓
- **$D(X) = !D_1(X)$**：
  $$!!D_1(X) \xrightarrow{\varepsilon} !D_1(X) \xrightarrow{\lambda^{D_1}} D_1(!X) \xrightarrow{\mathrm{promote}} !D_1(!X) = D(!X)$$
  promote合法：$\lambda^{D_1}$的结论是$D_1(!X)$，其前提$!D_1(X)$是!模态的，promote后得$!D_1(!X)$。✓

∎

## 3. 计算函子：!不可分配

**定理16（线性蕴含后件阻止!-分配）**：设$F(X) = A \multimap G(X)$，其中$X$在$G(X)$中出现且不在!辖域内（即$G$包含$X$的自由出现，且该出现不在任何$!$的辖域中）。则$F$不允许!-分配，即矢列

$$!(A \multimap G(X)),\ A \vdash G(!X)$$

不可证。

**证明**：结论$G(!X)$的结构取决于$G$。我们证明：无论$G$是什么（只要$X$在$G$中非!-模态地出现），该矢列都不可证。

关键观察：在$!(A \multimap G(X)), A \vdash G(!X)$的任何证明中，要得到$G(!X)$中的$!X$，必须通过promotion规则（这是唯一在右侧引入!的规则）。promotion要求所有前提都是!-模态的。

从$!(A \multimap G(X))$和$A$出发：
- 弃置$!(A \multimap G(X))$得$A \multimap G(X)$
- 与$A$通过$\multimap L$和eval得$G(X)$
- 但$G(X)$中的$X$是线性的（不在!辖域内），要将其变为$!X$需要$X \to !X$，而定理2.1证明这不存在

更形式化地：考虑$G(X)$中$X$的位置。要在右侧得到$G(!X)$，必须在证明的某一点将$G(X)$转化为$G(!X)$。这要求将$G(X)$中的每个$X$替换为$!X$。但$G(X)$是通过消耗$A$运行函数$A \multimap G(X)$得到的线性结果——它是"计算出来的"，不是"直接给出的"。线性结果中的$X$不能被promote，因为promotion要求所有上下文都是!模态的，而产生$G(X)$的过程消耗了线性资源$A$。

具体到$G(X) = X \otimes B$（定理13的情况），四种$\otimes R$拆分已在定理13中穷尽。对于一般的$G$，论证相同：$G(X)$是线性的（非!-模态），其中的$X$无法提升为$!X$。∎

**定理17（加法析取阻止!-分配）**：设$F(X) = F_1(X) \oplus F_2(X)$，其中$X$在$F_1$或$F_2$中非平凡出现。则$F$不允许!-分配。

**证明**：以$F(X) = X \oplus B$为例。需证$!(X \oplus B) \vdash !X \oplus B$不可证。

结论$!X \oplus B$的主连接词是$\oplus$，最后一步是$\oplus R_1$或$\oplus R_2$：
- $\oplus R_1$：需证$!(X \oplus B) \vdash !X$。promotion要求$!(X \oplus B) \vdash X$。弃置得$X \oplus B \vdash X$，$\oplus L$需要$X \vdash X$（成立）和$B \vdash X$（不成立，$B$是不同原子）。
- $\oplus R_2$：需证$!(X \oplus B) \vdash B$。弃置得$X \oplus B \vdash B$，$\oplus L$需要$X \vdash B$（不成立）和$B \vdash B$（成立）。

两种情况都不可证。对于更一般的$F_1 \oplus F_2$，论证类似：弃置后$\oplus L$要求两个分支都能证明结论，但包含$X$的分支无法将线性$X$提升为$!X$。∎

## 4. 二分法

**定理18（!-分配二分法）**：对多项式函子$F$，$F$允许!-分配当且仅当$F$是数据函子（由$X$、常量、$\otimes$、$\&$、$!$生成，$X$不出现在$\multimap$后件中，不出现在$\oplus$分支中）。

**证明**：
- ($\Leftarrow$) 定理15。
- ($\Rightarrow$) 如果$F$包含$\oplus$且$X$在其中出现，定��17阻止分配。如果$F$包含$A \multimap G(X)$且$X$在$G$中非!出现，定理16阻止分配。如果$F$同时包含两者，至少一个阻止。因此$F$必须是数据函子。∎

## 5. 哲学解读

### 5.1 数据与计算

定理18给出了一个精确的二分：

| 函子类型 | 结构 | !-分配 | 哲学对应 |
|---------|------|--------|---------|
| $X$ | 直接数据 | ✓ | 简单物 |
| $D_1 \otimes D_2$ | 数据组合 | ✓ | 复合数据 |
| $D_1 \& D_2$ | 数据选择 | ✓ | 有限记录 |
| $!D$ | 可复制数据 | ✓ | 沉积/资本 |
| $A \multimap G(X)$ | 交互计算 | ✗ | 生命/劳动过程 |
| $F_1 \oplus F_2$ | 不透明分支 | ✗ | 未知/未来 |

**核心命题：资本（!）可以复制数据结构，但不能复制计算过程。**

- 一本书（!-模态数据）可以无限印刷——!分配给$\otimes$和$\&$
- 一个读书并理解的人（$A \multimap (X \otimes B)$，交互式计算）不能被复制——!不分配给$\multimap$后件
- 一个人的未来可能性（$\oplus$，开放分支）不能被资本捕获——!不分配给$\oplus$

### 5.2 生命是计算，不是数据

生命位点$S = \nu X. (A \multimap (X \otimes B))$的函子$F(X) = A \multimap (X \otimes B)$是计算函子（定理16），不是数据函子。因此：

1. 生命不能被!-模态化（定理11.1）
2. 生命的自复制结构不能被!提升（定理13）
3. 生命作为交互计算过程，本质上不可复制（定理18）

这三条是同一个数学事实的不同表述：**活操作是线性的、交互的、计算性的；资本是!-模态的、可复制的、数据性的。两者之间没有自然变换。**

### 5.3 形式从属/实际从属（加强版）

定理18加强了定理14：资本不仅必须将$F_2$改造为$F_1$（定理14），而且必须将**所有计算函子改造为数据函子**。这意味着：

- 资本必须将开放的交互式劳动（$\multimap$，需要判断和输入）改造为封闭的数据操作（$\otimes$，重复固定动作）
- 资本必须将开放的未来可能性（$\oplus$，不可预测的分支）改造为封闭的有限记录（$\&$，可枚举的选项）
- 这就是"去技能化"的完整数学表述：不仅是去技能，是**去交互化**和**去开放化**

### 5.4 共产主义（加强版）

共产主义不仅是去除!在生产资料上的僭越（定义11.3），更是恢复计算函子对数据函子的主导：

- 生产是$A \multimap (X \otimes B)$（交互式的、需要判断的、创造性的），不是$X \otimes B$（非交互的、重复的）
- 未来是$\oplus$（开放的、不可预测的），不是$\&$（封闭的、可枚举的）
- 生命作为$\nu F_2$（交互余代数）自由展开，不被强制为$F_1$（数据函子）

## 6. 与严格正性和聚焦的关系

### 6.1 严格正性

定理18中的"$X$不出现在$\multimap$后件中"与类型论中归纳类型的**严格正性条件**（strict positivity）精确对应：

- 在Coq/Agda中，归纳类型$\mu X.F(X)$要求$X$在$F$中严格正（不出现在函数类型的域中……等等，严格正性要求$X$不出现在函数类型的**箭头左边**，即$X$不能在domain中）

等等，让我仔细核对。在归纳类型中：
- 严格正性：$X$不能出现在$\to$的**左边**（domain），即$X$不能作为输入
- 例如，`data Evil = Evil (Evil -> Bool)` 被拒绝，因为$X$在domain中

但在我们的定理中，阻止!-分配的是$X$出现在$\multimap$的**右边**（codomain），不是左边！

这是一个有趣的**对偶**：
- 归纳类型（$\mu$，阴）：$X$不能在$\multimap$的domain中（严格正性）——否则导致非良基递归
- !-分配（资本化）：$X$不能在$\multimap$的codomain中——否则无法复制计算结果

**阴（归纳/沉积）禁止X作为输入；阳（!-分配/资本化）禁止X作为输出。**

生命$F(X) = A \multimap (X \otimes B)$中，$X$在codomain中（作为输出/新自我），所以：
- 作为归纳类型$\mu F$：$X$在codomain中是严格正的，$\mu F$存在（但$\mu F$是有限数据，不是生命）
- 作为余归纳类型$\nu F$：$X$在正位置，$\nu F$存在（这才是生命）
- 作为!-分配：$X$在codomain中，!不分配（不可资本化）

### 6.2 聚焦

定理18与线性逻辑的**聚焦定理**（Andreoli 1992）相关：
- 数据函子（$\otimes$, $\&$, $!$）对应**异步/否定**连接词（可任意分解，不需要选择）
- 计算函子（$\oplus$, $\multimap$后件）对应**同步/肯定**连接词（需要选择/输入，不能被!穿透）

!是一个否定模态，它可以穿透否定连接词（$\&$）但不能穿透肯定连接词（$\oplus$, $\multimap$的codomain）。这不是巧合——!的否定性决定了它只能分配给否定结构。
