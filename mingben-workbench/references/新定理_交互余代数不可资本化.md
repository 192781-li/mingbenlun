# 新定理：交互余代数不可资本化

> 操作范畴论 v0.5 新增
> 2026-08-25
> 本章证明一个新定理：线性指数余单子!不提升到交互余代数（Mealy机）范畴，但提升到非交互余代数范畴。这给出了"生命不可完全资本化"的更强形式，并精确刻画了马克思"形式从属/实际从属"的范畴论结构。

---

## 1. 问题

余单子!能否提升到函子F的余代数范畴CoAlg(F)？即：给定余代数$f: X \to F(X)$，能否自然地得到余代数$!X \to F(!X)$？

这需要一个**分配律**（distributive law）$\lambda: !F \Rightarrow F!$，即自然变换：
$$\lambda_X : !F(X) \to F(!X)$$

如果$\lambda$存在，则$!$提升为余代数函子$!_F: \mathbf{CoAlg}(F) \to \mathbf{CoAlg}(F)$，将$(X, f)$映射为$(!X, \lambda_X \circ !f)$。

生命论问题：**资本（!）能否将一个生命系统（交互余代数）整体资本化？**

---

## 2. 两种自复制函子

### 2.1 非交互自复制：F₁(X) = X ⊗ B

$F_1(X) = X \otimes B$描述没有输入的自复制：状态X直接产生新状态和输出B。

**命题1**：对$F_1(X) = X \otimes B$，分配律$\lambda^1: !F_1 \Rightarrow F_1!$存在。

**证明**：幺半余单子!具有monoidal strength：
$$!(X \otimes B) \xrightarrow{\mathrm{str}} !X \otimes !B \xrightarrow{\mathrm{id} \otimes \varepsilon_B} !X \otimes B$$

其中$\mathrm{str}$是余单子的monoidal结构（$(!X \otimes !B \to !(X \otimes B))$的逆方向——实际上在线性逻辑中，$!(A \otimes B) \multimap !A \otimes !B$可证：通过弃置$!(A\otimes B)\vdash A\otimes B$，分别投影/拆分为$!(A\otimes B)\vdash A$和$!(A\otimes B)\vdash B$，再promote为$!(A\otimes B)\vdash !A$和$!(A\otimes B)\vdash !B$，最后用$\otimes R$合并）。$\varepsilon_B: !B \to B$是弃置。复合给出$!(X\otimes B) \to !X\otimes B = F_1(!X)$。∎

### 2.2 交互自复制：F₂(X) = A ⊸ (X ⊗ B)

$F_2(X) = A \multimap (X \otimes B)$描述有输入的自复制：给定输入A，产生新状态X和输出B。这是Mealy机/开放系统——生命的数学模型。

**定理2（主要定理）**：对$F_2(X) = A \multimap (X \otimes B)$，其中A、B是任意非!-模态对象（线性资源），分配律$\lambda^2: !F_2 \Rightarrow F_2!$**不存在**。

即：在直觉主义线性逻辑的矢列演算中，矢列
$$!(A \multimap (X \otimes B)),\ A \vdash\ !X \otimes B$$
不可证。

---

## 3. 证明

### 3.1 证明策略

在直觉主义线性逻辑（IMLL + !）的矢列演算中，通过对最后一条规则的情况分析证明不可证性。

目标矢列：$\Gamma \vdash !X \otimes B$，其中$\Gamma = !(A \multimap (X \otimes B)), A$。

### 3.2 情况分析

结论$!X \otimes B$的主连接词是$\otimes$，因此最后一条规则只能是$\otimes R$：
$$\frac{\Gamma_1 \vdash !X \qquad \Gamma_2 \vdash B}{\Gamma_1, \Gamma_2 \vdash !X \otimes B}$$
其中$\Gamma_1 \cup \Gamma_2 = \Gamma = \{!(A \multimap (X \otimes B)), A\}$（多重集不交并）。

$\Gamma$有两个公式，因此$\Gamma_1, \Gamma_2$的分配有三种可能：

**情况1**：$\Gamma_1 = \{!(A \multimap (X \otimes B)), A\}$，$\Gamma_2 = \emptyset$
- 右前提$\emptyset \vdash B$不可证（B是原子类型，无公理$B\vdash B$因为B不在前提中）。
- 排除。

**情况2**：$\Gamma_1 = \emptyset$，$\Gamma_2 = \{!(A \multimap (X \otimes B)), A\}$
- 左前提$\emptyset \vdash !X$不可证（promotion要求所有前提都是!-模态，而上下文为空——空上下文全是!-模态是vacuously true，但promotion要求$\vdash X$，而$\emptyset\vdash X$不可证）。
- 排除。

**情况3**：$\Gamma_1 = \{!(A \multimap (X \otimes B))\}$，$\Gamma_2 = \{A\}$
- 右前提$A \vdash B$：A和B是不同的原子类型，不可证。
- 排除。

**情况4**：$\Gamma_1 = \{A\}$，$\Gamma_2 = \{!(A \multimap (X \otimes B))\}$
- 左前提$A \vdash !X$：右侧!X只能由promotion引入，promotion要求所有前提都是!-模态，但A不是!-模态。不可证。
- 右前提$!(A \multimap (X \otimes B)) \vdash B$：弃置得$A \multimap (X \otimes B) \vdash B$，但需要A来应用$\multimap L$，而A不在上下文中。不可证。
- 排除。

所有可能的上下文分配都不可证。因此目标矢列不可证。∎

### 3.3 为什么非交互情况可以而交互情况不行

关键区别在于$\otimes$和$\multimap$的不同：

- $F_1(X) = X \otimes B$：X是"直接给出的"——!的monoidal strength可以把!(X⊗B)拆成!X⊗!B，再弃置!B得到!X⊗B。
- $F_2(X) = A \multimap (X \otimes B)$：X是"被计算出来的"——要得到X，必须消耗A来运行函数。运行函数产生的是线性的X（一次性的），无法变成!X（可复制的）。

用证明论的话说：在$F_1$中，X出现在$\otimes$的直接下面（正位置，可通过strength访问）；在$F_2$中，X出现在$\multimap$的后件中（正位置但被线性蕴含"保护"——要访问它必须消耗A，而消耗A产生的是线性X，不能promote为!X）。

## 4. 哲学与政治经济学解读

### 4.1 生命不可资本化（加强版）

定理11.1证明了不存在态射$S \to !S$（生命不能完全资本化）。定理2更强：

- 定理11.1说：你不能把一个生命**对象**变成资本对象。
- 定理2说：你甚至不能把生命的**自复制结构**（余代数）变成资本的自复制结构——!不提升到交互余代数范畴。

这意味着：**资本化不仅不能捕获生命的"内容"（对象），也不能捕获生命的"形式"（自复制方式）。** 生命的自复制是交互性的（需要输入、消耗输入、产生新自我），而资本的自复制是非交互性的（M→M'，"钱生钱"，隐藏了劳动输入）。

### 4.2 形式从属与实际从属

马克思区分了资本对劳动的两种从属：

- **形式从属**（formal subsumption）：资本接管现有的劳动过程，但不改变其技术性质——工匠变成雇佣工人，但工作方式不变。
- **实际从属**（real subsumption）：资本改造劳动过程本身——分工、机器、流水线，使劳动过程适应资本增殖的需要。

定理2给出了这一区分的范畴论表述：

- 资本**想要**做形式从属：将交互余代数$f: S \to A \multimap (S \otimes B)$直接!-提升为$!S \to A \multimap (!S \otimes B)$。但定理2证明这不可能——!不提升。
- 因此资本只能做**实际从属**：将交互函子$F_2(X) = A \multimap (X \otimes B)$**替换为**非交互函子$F_1(X) = X \otimes B$——把需要技能和判断的交互式劳动（工匠），变成不需要输入判断的重复性劳动（流水线）。流水线工人不需要"输入"——他们重复固定动作，$F_1(X) = X \otimes B$，!可以提升，资本可以自我增殖。

**Braverman的"去技能化"（deskilling） thesis在范畴论中得到了精确表述：资本必须将交互式自复制（F₂）改造为非交互式自复制（F₁），才能实现增殖——这不是资本的选择，而是数学结构的强制。**

### 4.3 为什么M-C-M'看起来是"钱生钱"

在基范畴$\C$（生产领域）中，资本流通$!G \otimes A \to !G'$需要线性中介A（劳动力）——没有劳动，资本不能增殖。

但在共Kleisli范畴$\C_!$（流通领域）中，同一个态射表现为$G \to G'$（M→M'）——线性中介A被遗忘了（定理12.2，商品拜物教）。

$G \to G'$的类型是$F_1(G) = G \otimes B$（非交互自复制）——!可以提升。所以在流通领域，资本看起来像$F_1$（"钱生钱"，不需要输入），但在生产领域，它实际上需要$F_2$的交互结构（劳动输入）。

定理2说：你不能在生产领域中把$F_2$变成$F_1$而不改变系统本身——你必须实际改造劳动过程（实际从属），而不仅仅是在市场上购买劳动力（形式从属）。

### 4.4 共产主义的范畴论表述（加强版）

定义11.3说共产主义是去除!模态在生产资料上的僭越。定理2补充：

共产主义不仅是去除$!C$的僭越，更是**恢复$F_2$（交互式自复制）作为生产的主导结构**——劳动者作为交互的、有判断的、需要输入的生命主体，而非$F_1$式的可复制零件。

在共产主义下：
- 生产资料$C$是线性的（使用即消耗，不自我增殖）
- 劳动者$A$保持$F_2$式的交互自复制（需要输入、判断、创造）
- 不存在$F_2 \to F_1$的强制改造（没有去技能化）
- 余代数$S = \nu F_2$自由展开（生命在交互中自我维持）

## 5. 推广与猜想

### 5.1 更一般的函子类

定理2处理了$F_2(X) = A \multimap (X \otimes B)$。更一般地，猜想：

**猜想D1**：对任意形如$F(X) = A_1 \multimap A_2 \multimap \cdots \multimap A_n \multimap (X \otimes B_1 \otimes \cdots \otimes B_m)$的"交互函子"（X出现在n重线性蕴含的后件中，且不在!辖域内），分配律$!F \Rightarrow F!$不存在。

**猜想D2**：对任意形如$F(X) = X \otimes B_1 \otimes \cdots \otimes B_m$的"非交互函子"（X直接出现在张量积中），分配律存在。

### 5.2 与深层自我复制的关系

$f^3$层（自觉/明性）的函子是$F_3(X) = (X^X \otimes O)^I = I \multimap ((X \multimap X) \otimes O)$。

这里$X$出现在$X \multimap X$中（既有正位置又有负位置）。猜想：!对$F_3$的分配律也不存在，而且$X$在负位置的出现使得$f^3$层的不可资本化比$f^1/f^2$层更强——这与命题4.3（$f^3$是异化唯一可能的层级）形成辩证关系：正因为$f^3$最不可资本化，资本对它的劫持（通过!-模态的自我模型）才产生最深刻的异化。

## 6. 定理级别评估

**定理2的数学性质：**
- 陈述是新的：据我们所知，没有人证明过"线性指数余单子不提升到Mealy机余代数范畴"
- 证明技术是标准的：矢列演算中的情况分析，任何学过线性逻辑证明论的人都能验证
- 证明长度：约半页
- 数学深度：中等——不是难题，但不是平凡结论（需要区分F₁和F₂两种函子）
- 哲学/跨学科价值：高——给出了马克思形式从属/实际从属和Braverman去技能化的精确数学表述

**与已知结果的关系：**
- Benton 1995证明了共Kleisli范畴是CCC（已知）
- 关于comonad提升到coalgebra范畴有一般性理论（Barto 2010s关于comonadic distributive laws），但!不提升到Mealy coalgebra这个具体结果似乎未被陈述过
- 这可以作为一篇关于"线性逻辑中的交互性与复制"的论文中的一个定理
