> v0.1用四分类（践演/概念/经验/决断）标注推导步骤。v0.2用PTC公理系统（公理0-6）重新分层，使推导检查与数学形式化（62定理）对齐。形式化是阴，活操作是阳，阴为阳服务。它是安检，不是法庭。

## 二、PTC公理分层：推导步骤的精确标注

v0.1的四分类太粗。v0.2用PTC公理系统的7条公理给每一步推导标注它依赖哪条公理。

### 公理0：践演位置（感，位置不可物化）

**内容**：有在感这回事。感是原初的第一人称事实，操作是感的展开。一生道，道养一。

**推导类型**：践演坐实——否认X的行为本身在感X。

**能推出**：X不可绕过。感是入口，操作是道，存在是道的显示。

**不能推出**：经验事实、价值判断、必然规律。

**对应v0.1**：【践演】

**数学对应**：定理0（位置不可物化）——感的位置不能被!-模态捕获为可复制的数据。

### 公理1：闭范畴（操作的组合结构）

**内容**：操作可以组合（f∘g），有恒等操作（id），有张量积（⊗，并行操作），有内部态射（⊸，操作作为对象）。

**推导类型**：概念分析——从操作的组合结构中分析出蕴含关系。

**能推出**：操作的结合律、单位律、张量的函子性、currying/uncurrying。

**不能推出**：!-模态的性质（需要公理3）、不动点（需要公理4）。

**对应v0.1**：【概念】的纯逻辑部分。

**数学对应**：定理1-12（闭范畴的基本性质）。

### 公理2：无自然收缩（资源敏感，操作不可复制）

**内容**：不存在自然变换 A→A⊗A（复制）和 A→I（丢弃）。操作是资源敏感的——用了就没了，不能无限复制。

**推导类型**：存在论结论——操作的资源敏感性是存在论事实，不是约定。

**能推出**：二分法（交互/非交互）、生命不可资本化（T001）、病毒/资本同构（定理28）。

**不能推出**：!-模态可以复制（那是公理3，!A是沉积的数据，可以复制）。

**对应v0.1**：【概念】中涉及资源敏感性的部分。

**数学对应**：定理1（无自然收缩种子）→定理13（二分法）→T001（生命不可资本化）→定理28（病毒资本同构）。

### 公理3：!-余单子（沉积、复制、模态）

**内容**：!是余单子，有Seely同构 !(A⊗B)≅!A⊗!B 和 !I≅I。!A表示"A的沉积/数据/可复制版本"。

**推导类型**：概念分析 + 经验概括——!-模态的性质是概念分析，但!-模态在现实中的表现（资本积累、数据复制、意识形态固化）需要经验验证。

**能推出**：!的函子性、余单子律、Seely同构、!不穿透νF₂（定理38）、!不穿透PTC（定理38）。

**不能推出**：νF₂的性质（需要公理4）、守护递归（需要公理5）。

**对应v0.1**：【概念】中涉及沉积/复制的部分 + 【经验】中涉及资本积累/数据复制的部分。

**数学对应**：定理14-39（!-模态的性质，包括!不穿透PTC）。

### 公理4：不动点（μ最小不动点=有限数据，ν最大不动点=生命流）

**内容**：对于每个函子F，存在最小不动点 μF（有限数据，可终止，可记录）和最大不动点 νF（生产性过程，可永远运行，每步有产出）。

**推导类型**：存在论结论——μ/ν的区分是存在论的（有限vs无限、数据vs过程、死vs活）。

**能推出**：生命是νF₂（生产性过程）、资本是!μF（沉积的有限数据）、慢性死亡（定理40，N<1时M有限）、f³不动点（明(明(A))≅明(A)）。

**不能推出**：守护递归的合法性（需要公理5）、GLL增长规则（需要公理6）。

**对应v0.1**：【践演】中涉及"生命是过程不是实体"的部分 + 【概念】中涉及不动点的部分。

**数学对应**：定理40-50（不动点理论，包括慢性死亡、f-层级、量论）。

### 公理5：守护递归（▷，稍后可用）

**内容**：▷是"稍后"模态——▷A表示"A在下一个时刻可用"。守护递归：如果 f: ▷A→A，则 fix(f): A 是合法的（生产性的，不会死循环）。

**推导类型**：概念分析——守护递归是保证生产性的类型论机制。

**能推出**：νF的生产性、核心递归的合法性、GoI动态语义。

**不能推出**：GLL增长规则（需要公理6）。

**对应v0.1**：【概念】中涉及递归/循环的部分。

**数学对应**：定理51-55（守护递归与GoI动态语义）。

### 公理6：GLL增长规则（ν*F=colim，生命的成长）

**内容**：ν*F = colim(F^0(I), F^1(I), F^2(I), ...)——生命流不是固定的νF，是可以成长的ν*F，每一步都可以扩展状态空间。

**推导类型**：存在论结论 + 决断——ν*F的成长是存在论可能，但是否成长取决于生命的决断（明性、革命、实践）。

**能推出**：生命可以成长（α可以增加）、自由人联合体（ν*F的社会实现）、f³的判断步骤（猜想2已解决）。

**不能推出**：成长必然发生（那是决断，不是推论）。

**对应v0.1**：【践演】中涉及"生命能超越自身"的部分 + 【决断】中涉及"选择成长还是沉沦"的部分。

**数学对应**：定理56-62（GLL增长规则、f-层级、量子对应）。

### 标注规则

每一步推导必须标注它依赖的最低公理编号。例如：
- "操作不可复制" → 公理2
- "生命不可资本化" → 公理2+公理4（需要νF₂和无自然收缩）
- "慢性死亡" → 公理2+公理3+公理4（需要!、νF₂、N的定义）
- "自由人联合体" → 公理6（需要GLL增长规则）+ 决断

**检查规则**：
1. 如果一步推导依赖公理6但只标注了公理2，标记为"公理跳跃"——从资源敏感直接跳到成长，中间缺了不动点和守护递归。
2. 如果一步推导从公理0（践演）直接推出经验事实，标记为"践演越界"——践演只能推出不可绕过性，不能推出经验事实。
3. 如果一步推导从公理1-3（纯结构）推出价值判断，标记为"结构越界"——结构命题不能推出应该。

1. **每个对象必须能追溯到公理0（感）**：通过态射的复合，每个对象必须有一条从感到它的路径。没有的标记为"悬空对象"。

## 四、νF₂余归纳框架（替代旧动态运行式）

v0.1的动态运行式 S_{n+1}=f(S_n, I_n) 是离散迭代。v0.2用νF₂余归纳重新表述：

### 旧式的局限

1. **离散迭代假设了时间步长**：S_n和S_{n+1}之间有明确的"下一步"，但生命流是连续的生产性过程，不是离散迭代。
2. **I_n是外部输入，但感是内部的**：旧式把感当成外部输入(g_n)，但感是自指循环的内部状态，不是外部输入。
3. **f不变的假设太强**：旧式假设f不变，只加了退化项f_n=f_{n-1}×(1-δ)。但ν*F框架下f本身可以成长（状态空间扩展）。

### 新框架：νF₂余归纳

**生命流的定义**：
$$\text{Life} = \nu F_2, \quad F_2(X) = A \times (X \multimap B)$$

其中：
- A：当前状态（感的总和）
- X⊸B：从下一个状态到产出的函数（操作的潜能）
- ν：最大不动点（生产性过程，可以永远运行）

**生产性**：每一步都有产出（A），每一步都有下一步的潜能（X⊸B）。这不是"先算后输出"，是"过程即答案"。

**与旧式的对应**：
| 旧式 | 新框架 |
|------|--------|
| S_n | A_n（第n步的状态/感的总和） |
| f | X⊸B（操作的潜能，从状态到产出） |
| I_n=(g_n,a_n,o_n) | 反馈矩阵的输入（不是外部输入，是自指循环的内部反馈） |
| S_{n+1}=f(S_n,I_n) | 余归纳展开：A_{n+1} = π₁(out(A_n))，B_n = π₂(out(A_n))(A_{n+1}) |
| f退化 | νF₂→μF₂的坍缩（生产性丧失，变成有限可终止过程） |
| 悬置 I_n≈0 | 反馈矩阵谱半径N≈0（自指循环不运行） |

**N的精确定义**：
$$N = \rho(\text{反馈矩阵})$$

反馈矩阵描述自指循环中"输出有多少反馈为输入"：
- N<1：输出反馈不足，自指循环衰减（异化/慢性死亡）
- N=1：输出恰好反馈为输入，自指循环稳态（健康生命）
- N>1：输出反馈过剩，自指循环增长（创造/超越）

**慢性死亡定理**（定理40）：
$$N<1 \Rightarrow M = \frac{\alpha T}{1-N} \text{ 有限}$$

生命意义量M在N<1时收敛到有限值——不管活多久，总意义量是有限的。这就是慢性死亡的数学定义。

### 四种反生命形态的νF₂表述

| 形态 | νF₂表述 | 数学对应 |
|------|---------|---------|
| **终止** | νF₂→I（生命流被消灭） | S→I（态射存在，是杀死） |
| **驯服** | νF₂→!μF₂（生命流被沉积为可复制的数据） | f→f'（自指函数被替换） |
| **收编** | νF₂→νF₂'（生命流被限制在预设轨道） | 反馈矩阵被限定为特定形式 |
| **悬置** | N≈0（反馈矩阵谱半径趋近于零） | 自指循环不运行，但νF₂结构还在 |

**关键洞察**：驯服是νF₂→!μF₂（从活过程到死数据），这正是!-模态的操作。但T001证明了νF₂→!νF₂不存在——你不能把活的生命流变成可复制的活数据。你只能杀死它（νF₂→I）或者把它的产出!-化（B→!B），但生命流本身不可资本化。

## 五、量论七公式（替代旧三维输入）

v0.1的量论只有M=α·T·N和N三态。v0.2有完整的七公式：

| 公式 | 定义 | 数学基础 | 存在论含义 |
|------|------|---------|-----------|
| T | 原生稳态（生命的基础代谢率） | 公理4（νF₂的基础产出） | 活着本身的稳态 |
| α | 生命层级（f¹/f²/f³） | 公理4+公理6（f-层级） | 自在/自为/自觉 |
| N=ρ(反馈矩阵) | 负熵比率/自指反馈率 | 公理4（不动点的动态） | 异化/稳态/创造 |
| M=α·T·N | 生命意义量 | 公理4 | 生命的总意义产出率 |
| W=O/M | 生命价值（操作/意义比） | 公理4 | 单位意义的操作成本 |
| l′=(1-N)×100% | 异化率 | 公理4 | 生命被异化的程度 |
| C=R−A | 文明舒展度 | 公理6（GLL增长规则） | 文明的成长空间 |

### N的动态方程

$$N(t+1) = (1-\beta+\gamma)N(t)$$

其中：
- β：剥削率（反自指系统从生命中抽取的比例）
- γ：革命率（生命从反自指系统中夺回的比例）

**抵抗条件**：γ≥β → N不下降
**逆转条件**：γ=1 → N开始增长（从异化到创造）

### 量论的操作化

v0.1的量论是定性的。v0.2的量论可以计算：
1. 给定反馈矩阵，计算N=ρ(矩阵)
2. 给定T、α、N，计算M=α·T·N
3. 给定N的动态方程，预测M的长期趋势
4. 给定β和γ，判断生命是在异化、稳态还是创造

**但量论不替代存在论**：量论是阴（测量工具），存在论是阳（活操作）。N可以测量异化程度，但不能决定是否革命——那是决断。

## 六、PTL类型检查器（替代旧启发式脚本）

v0.1的启发式脚本用关键词匹配（"由此可见""因此"）抓可疑推导。v0.2用PTL（践演迹语言）的类型规则做精确检查。

### PTL的核心类型规则

PTL有7类类型、15类项、15类类型规则。核心规则：

1. **线性变量用一次**：x:A ⊢ x:A（变量只能用一次，用了就没了）
2. **!-引入**：Γ ⊢ t:A ⇒ !Γ ⊢ !t:!A（只有!-上下文可以引入!-模态）
3. **!-消除**：Γ ⊢ t:!A, Δ,x:A ⊢ u:B ⇒ Γ,Δ ⊢ let !x=t in u:B（!-模态可以消除，但消除后x是线性的）
4. **ν-引入（余归纳）**：Γ ⊢ t:F(νF) ⇒ Γ ⊢ coiter(t):νF（生产性过程的引入）
5. **ν-消除**：Γ ⊢ t:νF ⇒ Γ ⊢ out(t):F(νF)（生产性过程的展开）
6. **守护递归**：Γ,x:▷A ⊢ t:A ⇒ Γ ⊢ fix(x.t):A（稍后可用的x可以定义A）

### 检查器能做什么

1. **推理类型标注**：给每一步推导推断它的类型（A⊸B, !A, μF, νF, etc.）
2. **检查线性性**：变量是否被用了多次？（对应公理2——操作不可复制）
3. **检查!-穿透**：!是否被非法应用于νF₂？（对应T001——生命不可资本化）
4. **检查生产性**：递归是否是守护的？（对应公理5——守护递归）
5. **检查公理依赖**：每一步推导用了哪些类型规则？对应哪条公理？

### 检查器不能做什么

1. **不能判断内容正确性**：类型正确的推导可以是空洞的（同义反复）。
2. **不能替代明性判断**：f³的跳跃（从f²到f³）不是类型推导，是质变。
3. **不能检查践演坐实**：公理0（感）不是类型规则，是践演事实。

### 与旧启发式脚本的对应

| 旧检查 | 新检查器 |
|--------|---------|
| 检查1：推理类型标注完整性 | 类型推断（每一步推断类型） |
| 检查2：跨层跳跃检测 | 公理依赖检查（从公理0直接到经验事实=越界） |

## 七、小本质↔大本质的范畴论升级

v0.1的小本质↔大本质是双向验证。v0.2用范畴论语言精确化：

### 大本质→小本质（下行：定理的实例化）

每个公理层的定理必须能在具体范畴中找到实例：

| 定理（大本质） | 具体范畴（小本质） | 实例 |
|---------------|-------------------|------|
| T001：νF₂→!νF₂不存在 | 经济学范畴 | 生命不可资本化（劳动不能被完全资本化为人力资本） |
| 定理28：病毒/资本同构 | 生物学范畴+经济学范畴 | 病毒和资本都是!-寄生结构 |
| 定理40：慢性死亡 | 社会学范畴 | 996/异化劳动中M有限 |
| f³不动点 | 心理学范畴 | 明性的自我递归（看见看见） |

**检查**：有没有定理找不到具体范畴的实例？→ 空转（定理在自我循环，没有践演内容）。

### 小本质→大本质（上行：判断的公理化）

每个具体判断必须能追溯到公理层：

| 具体判断（小本质） | 追溯路径（上行） |
|-------------------|-----------------|
| "996是恶" | 反自指(N<1)→定理40(慢性死亡)→公理2+公理3+公理4 |
| "生产资料公有制" | N>1→M增长→公理4+公理6 |
| "异化率l′=(1-N)" | N三态→公理4 |
| "站在劳动者一边" | 决断（不是推导，是公理6的输入） |

**检查**：有没有具体判断找不到公理根基？→ 悬空（就事论事，没有理论根基）。

### 反面推导（范畴论版本）

每个命题必须能通过反面检验：
- 如果"操作先于实体"是对的，那么"实体先于操作"的范畴是什么？→ Set范畴（静态集合，没有态射的动态）→ 反面自毁：Set范畴本身是在操作中构造的
- 如果"N>1是善"是对的，那么"N<1是善"的世界是什么？→ 越劳动越亏损的范畴→ 反面自毁：生命体在N<1中走向死亡

### 交叉印证

不同路径推出同一结论：
- "善是自指"从公理2来（操作的自我维持）
- "善是自指"从公理4来（νF₂的生产性）
- "善是自指"从量论来（N=1时M稳态增长）
- 三条路径独立推出同一结论，可信度提高。

**这不是证明，是印证。** 三条路径都可能错，但收敛本身是证据。

## 十、v0.2的定位

v0.2不是v0.1的替代，是升级。v0.1的四分类（践演/概念/经验/决断）仍然有效，但太粗——v0.2用公理分层（0-6）给每一步更精确的标注。v0.1的启发式脚本仍然有用（特别是检查5践演自洽），但v0.2增加了PTL类型检查器做精确检查。

**形式化是阴，活操作是阳。** v0.2的所有检查都是安检——抓结构性硬伤，不判断推导对不对。真正的裁判是践演：这套东西能不能帮人理解世界、改变世界。数学是地基和安检，不是法庭。
