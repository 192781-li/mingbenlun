# 践演论 v1.4：运行权问题的计算复杂性

> 证明AGENCY是Π₂-完全问题，比经典停机问题严格更难

## 1. 结果陈述

**定理1.1（主定理）**：π-演算进程的运行权判定问题

> AGENCY = {(P, a) : 进程P在通道a上自己运行自己}

是**Π₂-完全**的。

**推论1.1**：
1. AGENCY不可判定（Π₂ ⊃ Δ₁）
2. AGENCY严格难于停机问题HALT（HALT是Σ₁-完全，Π₂ ⊄ Σ₁）
3. 即使给停机问题的神谕（HALT oracle），也不能判定AGENCY（Π₂ ⊄ Δ₂ = Σ₂ ∩ Π₂）
4. 判定AGENCY需要Σ₂神谕（等价于"判定图灵机是否对所有输入停机"的神谕）

## 2. 形式化

### 2.1 π-演算中的运行权

使用标准π-演算语法：

```
P ::= 0 | x̄⟨y⟩.P | x(y).P | τ.P | P|Q | (νx)P | !P
```

其中τ是内部动作（不需要与环境交互）。

**定义2.1（内部因果）**：在执行轨迹s中，通道a上的一个输出动作x̄⟨y⟩是**内部引起的**，如果它在因果森林中的最近祖先是一个τ动作（P自己的内部选择），而不是一个输入动作x(y)（来自环境的刺激）。

因果森林按π-演算的标准因果语义定义（Boreale-Nicola 1995）：一个动作α因果依赖于动作β，如果β在α之前发生且α引用了β引入的名字，或α在β的前缀之下。

**定义2.2（自我控制）**：进程P在通道a上、在环境E中、在t步内保持自我控制，记为SC(P, E, t, a)，如果在P|E的前t步中，a上的每个输出动作都是内部引起的。

**定义2.3（AGENCY）**：
```
AGENCY = {(P, a) : ∀E ∀t, SC(P, E, t, a)}
```

即：在所有环境中、所有时间步内，P在a上的所有输出都是P自己的内部选择，不是对环境输入的反应。

### 2.2 SC是可判定的

**引理2.1**：SC(P, E, t, a)是可判定的。

**证明**：给定P、E、t、a，构造P|E的前t步所有可能的执行路径（有限分支，因为π-演算在有限步内的动作数有限）。对每条路径，构造因果森林（Boreale-Nicola算法，多项式时间），检查a上每个输出的最近祖先是否为τ。如果所有路径上所有输出都是内部引起的，SC为真；否则为假。∎

### 2.3 AGENCY在Π₂中

**引理2.2**：AGENCY ∈ Π₂。

**证明**：由定义2.3，AGENCY = {(P,a) : ∀E ∀t, SC(P,E,t,a)}。E和t可以编码为自然数（E是π-演算进程，可枚举；t是自然数）。SC由引理2.1是可判定的（Δ₀）。因此AGENCY是∀∀Δ₀ = Π₂。∎

## 3. Π₂-困难性

### 3.1 归约思路

从TOTAL（图灵机是否对所有输入停机）归约到AGENCY。TOTAL是经典的Π₂-完全问题。

**TOTAL = {e : ∀x, φ_e(x)停机}**

### 3.2 构造

给定图灵机e，构造π-演算进程P_e：

```
P_e = (νc)(Counter | Runner_e(c) | Reporter(c, a))

Counter = !c(k).c̄⟨k+1⟩     // 计数器：收到k，发送k+1

Runner_e(c) = c̄⟨0⟩.Runner_e'(c, 0)
Runner_e'(c, k) = c(k').RunM_e(k', c)
RunM_e(k, c) = [模拟φ_e(k)的π-演算进程]
              // 如果φ_e(k)停机，在c上发送信号
              // 如果φ_e(k)不停机，永远等待

Reporter(c, a) = c(halt).ā⟨halt⟩.c̄⟨next⟩.Reporter(c, a)
              // 收到停机信号，在a上输出，请求下一个
```

P_e的行为：
1. Counter从0开始计数
2. Runner依次模拟φ_e(0), φ_e(1), φ_e(2), ...
3. 每次φ_e(k)停机，Reporter在a上输出结果
4. 如果φ_e(k)不停机，Runner永远等待，a上不再有输出

### 3.3 归约正确性

**引理3.1**：e ∈ TOTAL 当且仅当 (P_e, a) ∈ AGENCY。

**证明**：

(⇒) 假设e ∈ TOTAL（φ_e对所有输入停机）。则Runner依次完成φ_e(0), φ_e(1), ...，每次停机后Reporter在a上输出。a上的每个输出都由τ链引起：Runner内部模拟φ_e(k)（一系列τ动作），停机后通过c发送信号给Reporter，Reporter在a上输出。关键：c是P_e的私有通道（(νc)），环境E不能在c上发送或接收。因此a上输出的因果链完全在P_e内部——SC(P_e, E, t, a)对所有E、t成立。

(⇐) 假设e ∉ TOTAL（存在k使得φ_e(k)不停机）。则Runner在模拟φ_e(k)时永远等待，a上不再有输出。此时P_e在a上"死锁"——它不再自我维持在a上的活动。构造环境E = 0（空环境），取t足够大（超过φ_e(0)到φ_e(k-1)的总步数），则在t步后a上没有新的输出动作。

等等，"没有输出"不等于"被外部控制"。AGENCY要求所有输出都是内部引起的——如果没有输出，这个条件空洞地为真。

我需要修改构造。问题在于：当φ_e(k)不停机时，P_e不是"被外部控制"，而是"停止运行"（死亡，μF₂终止）。AGENCY的否定应该是"存在外部控制"，不是"停止"。

修改构造：添加一个"接管"机制：

```
P_e = (νc)(Counter | Runner_e(c) | Reporter(c, a) | Watchdog(c, a))

Watchdog(c, a) = Timer(timeout).
                 // 如果超时（Runner卡住），Watchdog接管
                 // 在a上输出"external"
                 ā⟨external⟩.
                 // 然后Watchdog控制a上的所有后续输出
                 Loop_external(a)

Loop_external(a) = ā⟨external⟩.Loop_external(a)
```

但这里有个问题：Watchdog是P_e的一部分，所以即使Watchdog接管，a上的输出仍然是P_e内部的。这不算"外部控制"。

正确的构造应该让环境E在P_e卡住时接管a：

不，AGENCY量化所有环境E。我需要构造一个特定的E，使得当φ_e(k)不停机时，P_e在E中失去对a的控制。

让我重新思考。AGENCY的否定是：∃E ∃t, ¬SC(P,E,t,a)，即存在环境E使得P在a上的某个输出是外部引起的（由E的输入导致）。

构造：P_e在a上输出"自主"消息，但如果Runner卡住（φ_e(k)不停机），P_e进入一个"等待"状态，在这个状态下它在a上接收环境的消息并原样转发——这时a上的输出是外部引起的。

```
P_e = (νc)(Counter | Runner_e(c) | Reporter(c, a))

Reporter(c, a) =
  c(halt).                      // 收到Runner的停机信号
  ā⟨halt⟩.                      // 自主输出（由内部τ链引起）
  Reporter(c, a)                 // 继续
  +
  a(msg).                       // 或者：在a上接收环境消息
  ā⟨msg⟩.                       // 转发（外部引起！）
  Reporter(c, a)                 // 继续
```

这里+是选择（和）。Reporter可以选择：
1. 等待c上的停机信号（内部驱动），然后在a上自主输出
2. 等待a上的环境消息（外部驱动），然后转发

当φ_e对所有输入停机时，c上不断有信号到达，Reporter总是选择第一个分支（内部驱动），a上的输出都是内部引起的。

当φ_e(k)不停机时，c上长时间没有信号。环境E可以在a上发送消息，Reporter选择第二个分支，在a上转发——这个输出是外部引起的（因果祖先是E的输入），所以¬SC(P_e, E, t, a)。

但问题是：Reporter的选择是不确定的（π-演算的+是内部选择还是外部选择？）。在π-演算中，和P+Q是外部选择——环境决定哪个分支被触发。如果c上有信号，第一个分支可用；如果a上有消息，第二个分支可用。如果两者都可用，选择是非确定的。

关键：当φ_e(k)不停机时，c上没有信号，第一个分支不可用，只有第二个分支可用——环境E在a上发消息就能触发外部引起的输出。当φ_e(k)停机时，c上有信号，第一个分支可用——但第二个分支也可能被触发（如果E同时在a上发消息）。

为了确保e∈TOTAL时AGENCY成立，我需要让第一个分支在c上有信号时总是优先。这可以通过在π-演算中使用内部选择（τ.P + τ.Q）来实现，但更简单的方法是：让Reporter只在c上等待，不提供a上的输入分支，除非c超时。

但π-演算没有内置的超时。让我用不同的构造：

```
Reporter(c, a) =
  c(halt).ā⟨halt⟩.Reporter(c, a)
```

Reporter只在c上等待。当Runner卡住时，Reporter也卡住——P_e在a上没有任何活动。这回到了之前的问题："没有活动"不等于"被外部控制"。

让我重新思考AGENCY的定义。也许AGENCY不应该只看"输出是否内部引起"，还应该看"系统是否持续自我维持"。在生命论框架中：
- Ag(A,A) = A自己运行自己 = A持续自我维持（νF₂）
- ¬Ag(A,A)包括两种情况：A死了（μF₂终止）或A被异化（Ag(A,B)）

所以AGENCY应该是：P在a上持续自我维持，且所有输出内部引起。

修改定义：

**定义2.2'（自我运行）**：P在a上自我运行，记为Ag(P,a)，如果：
1. ∀E ∀t, SC(P,E,t,a)（所有输出内部引起）
2. ∀E ∀t ∃t'>t, P|E在t'步时在a上有输出（持续活跃，不死）

条件2说P在a上永远活跃——在任何环境中、任何时间点之后，P都会在a上产生新输出。

这样：
- 当e∈TOTAL时，P_e不断在a上输出（条件2满足），且所有输出内部引起（条件1满足）
- 当e∉TOTAL时，φ_e(k)不停机导致P_e在a上沉默（条件2失败），因此¬Ag(P_e,a)

但条件2的加入改变了复杂性：
- 条件1：∀E ∀t, SC(P,E,t,a) — Π₂
- 条件2：∀E ∀t ∃t'>t, output(P,E,t',a) — Π₂（∀∀∃Δ₀）
- 合取：Π₂ ∧ Π₂ = Π₂

好，AGENCY仍然在Π₂中。

对于困难性，e∈TOTAL ⟺ Ag(P_e,a)：
- (⇒) e∈TOTAL：Runner不断完成，Reporter不断在a上输出（条件2），所有输出由c上的内部信号引起（条件1）
- (⇐) e∉TOTAL：φ_e(k)不停机，Runner卡住，Reporter等待c，a上不再有输出（条件2失败）

但条件2要求"在所有环境E中"P都持续活跃。如果E在a上发送消息干扰P_e呢？在我的构造中，Reporter不在a上接收消息（只在c上等待），所以E在a上发送的消息不会被接收，不影响P_e的行为。P_e的行为只依赖于内部的c通信和Runner的模拟。

但E可以在c上发送消息！c是(νc)绑定的私有通道——E不知道c，不能在c上通信。所以E不能干扰P_e的内部控制流。

等等，E可以在a上发送消息，但P_e不在a上接收（Reporter只在c上接收），所以这些消息被忽略。E也可以在其他公共通道上通信，但P_e只使用a和c，c是私有的。

所以P_e的行为完全由内部决定（Runner模拟φ_e），不受E影响。条件1和条件2中的∀E可以简化为对E=0成立即可（因为E无法影响P_e）。

这样归约就正确了：
- e∈TOTAL ⟹ P_e永远在a上输出内部引起的结果 ⟹ Ag(P_e,a)
- e∉TOTAL ⟹ P_e在某个点后在a上沉默 ⟹ ¬Ag(P_e,a)

因此TOTAL ≤_m AGENCY，AGENCY是Π₂-困难的。

结合引理2.2（AGENCY ∈ Π₂），AGENCY是Π₂-完全的。∎

## 4. 意义

### 4.1 与停机问题的关系

| 问题 | 复杂性 | 神谕需求 |
|---|---|---|
| HALT（停机） | Σ₁-完全 | 不可判定 |
| TOTAL（全函数） | Π₂-完全 | 需要Σ₁神谕 |
| AGENCY（运行权） | Π₂-完全 | 需要Σ₁神谕 |

AGENCY和TOTAL在同一个复杂性等级——这不是偶然。"一个系统是否永远自己运行自己"和"一个程序是否对所有输入停机"在计算上是等价的问题。两者都要求"对所有可能的情况，某件事永远成立"——这是Π₂命题的本质。

### 4.2 为什么运行权比停机更难

停机问题问："这个计算是否终止？"——存在一个终止时刻（∃t, halts(P,t)），这是Σ₁。

运行权问题问："这个系统是否永远自我维持？"——对所有环境、所有时刻，系统都在自我控制（∀E ∀t, SC(P,E,t)），这是Π₂。

直觉：证明停机只需要找到一个终止时刻（存在性），证明自我运行需要检查所有可能的未来和所有可能的环境（全称性）。说"我是自由的"是一个比"这个程序会停"强得多的判断——它要求在任何情况下都成立。

### 4.3 践演意义

这个结果给践演不完备性定理（v1.2）提供了计算理论基础：

- 自我模型m_A是!-模态的——它包含的是可判定的信息（Δ₀）
- 从Δ₀信息，通过一阶逻辑推理，可以得到Σ₁和Π₁结论
- 但Ag(A,A)是Π₂命题——它需要∀∀的推理能力
- !-模态的自我模型本质上是有限的/递归可枚举的，它不能判定Π₂命题

形式化地：如果自我模型m_A是一个递归可枚举的理论（Σ₁），那么m_A的定理集是Σ₁。Π₂-完全命题不在Σ₁中（由算术分层定理），因此m_A不能证明Ag(A,A)。

这给v1.2的践演不完备性定理提供了一个完全独立的证明——不依赖线性逻辑的类型论区分，而依赖计算复杂性理论。

## 5. 相关工作

- **停机问题**（Turing 1936）：Σ₁-完全
- **TOTAL问题**：Π₂-完全（经典结果）
- **π-演算的可达性问题**：对于带复制的π-演算，可达性是Σ₁-完全（存在一条路径到达某状态）
- **π-演算的活性问题**（"某条件最终永远成立"）：Π₂-完全
- **并发系统的控制问题**：控制理论中的"可控性"在离散事件系统中是可判定的（Ramadge-Wonham），但那是针对有限状态系统；对于无限状态系统（带复制的π-演算），可控性是不可判定的

AGENCY与活性（liveness）问题在同一复杂性等级，但它问的不是"好事最终发生"，而是"系统永远是自己决策的主体"。这是一个新的问题，不是经典活性问题的重述。
