## 2026-08-23（追加：检查6）

### 新增：检查6 本性→应该跳跃检测

**背景**：用户提出日后写作中可能会把决断写成必然性——"出于人之为人的本性""最优选择""本质上"等存在论表述推出规范判断（应该/必须/要）。

**判定逻辑**：
- 本性侧触发词：本性、人之为人、出于本性、本质上、从根本上、必然选择、最优选择、合乎本性、天生、与生俱来、人的本质、作为人、为人之本、本性上、本然
- 规范侧触发词：应该、必须、应当、需要、要去、要选择、要追求、要实现、要解放、要站在、要反对
- 两侧同时出现 → 检查白名单
- 白名单：已有【决断】或⊩ₘ中介 → 跳过；条件句（"如果X就必须Y"是工具必然）→ 跳过；纯描述（只有本性词没有规范命令词）→ 跳过

**原理**：从"本性是X"到"应该X"中间站着一个活人——本性可能被异化、合乎本性的路径可能不止一条、"应该"涉及特定历史条件下的价值排序。这是决断不是演绎，可以论证"这是最合乎本性的选择"【概念+决断】，但不能写成"这是必然的"。

**当前状态**：推导链总览中0处命中。脚本已升级为检查1-6。

## 2026-08-23（任务4：量论公式双向验证）

### 完成内容

**任务4：量论公式小本质↔大本质双向验证** —— 完成

对量论公式体系（M=α·T·N、W=O/M、l′=(1-N)×100%、C=R-A、N三态）做四维度双向验证：

1. **下行验证（存在论→量论显现）**：4个存在论命题均在量论中有精确显现
   - 操作存在论 → M=α·T·N（T对应闭包完整度，α对应嵌套层级，N对应再生方向）
   - 反自指存在论 → l′=(1-N)×100%（基准线N=1对应反自指永久性，非完美最大值）
   - 主客关系存在论 → W=O/M（M主体侧，O客体侧，W关系属性）
   - 社会存在论 → C=R-A（R社会自指出产，A社会反自指侵蚀）

2. **上行验证（量论判断→存在论根基）**：4个量论判断均可完整追溯
   - N>1是善 → 自指操作自我增强（dV/dt>0）
   - N<1是恶 → 反自指寄生操作（dV/dt<0）
   - M无上限 → 自指操作递归开放性（无完成态）
   - 混淆M/W是颠倒 → 主客关系反自指化（客体支配主体）

3. **反面推导（公式不成立→存在论矛盾）**：4个反面推导均证明公式是存在论必然
   - 如果M有上限 → 存在论退化为柏拉图主义（本质先在论）
   - 如果l′基准是完美最大值 → 反自指永久性和继续革命根据消失
   - 如果W=O（价值=客体固有属性） → 存在论退化为实体本体论
   - 如果N只有两态（无持平态） → 自指操作"维持"状态和异化率零点无法定义

4. **交叉印证（公式间自洽）**：5组交叉印证均无矛盾
   - M与l′共享N，从不同角度描述dV/dt方向
   - M与W从主体侧和主客关系侧描述明性觉知程度
   - l′与C从个体层面和文明层面描述社会反自指影响
   - N三态与所有公式自洽
   - α/σ/K/Ω四个系数各归其位，无越位无重复

### 验证结论

**量论公式体系无结构性硬伤。** 公式与存在论之间的对应是严格的、双向的、必然的，不是任意构造或比喻性关联。

2. R和A的子公式权重待实证标定

## 2026-08-25（v0.3 新增：自指循环动态运行式与悬置严格化）
### 完成内容
**将 S=f(S) 从静态封闭等式推进为动态分步运行式，加入外部输入维度，严格定义悬置，区分四种反生命操作形态。**

写入 `formalization-v0.1.md` 第九节，包含六个子节：

1. **9.1 从 S=f(S) 到 S_{n+1}=f(S_n, I_n)**
   - 原公式局限：封闭等式无外部输入位置
   - 动态运行式：加入 $I_n$ 外部输入向量
   - $I_n$ 三维分解：$I_n=(g_n, a_n, o_n)$（感输入/应输入/操输入）
   - 三维独立悬置：只切 $g_n$=麻木，只切 $a_n$=盲从，只切 $o_n$=无力，全切=完全悬置

2. **9.2 悬置的严格定义**
   - $I_n\approx0 \Rightarrow S_{n+1}\approx S_n$
   - 关键区分：f 未替换、S 未消灭、但循环不运行
   - 四种反生命形态对照表（终止/驯服/收编/悬置），按对 f/I_n/S 的作用和可逆性区分
   - 悬置比驯服阴险：驯服留撕裂感，悬置连被压迫的感受都产生不出

3. **9.3 f 的退化：长期悬置的不可逆损伤**
   - 退化项：$f_n = f_{n-1} \times (1-\delta \cdot \mathbb{1}[I_{n-1}\approx0])$
   - 每步悬置 f 衰减一点，长期悬置后即使输入恢复 f 已退化
   - 悬置解除危机：长期悬置者自由到来时以扭曲方式运行
   - 与量论对应：f 退化 → α（生命层级）下降

4. **9.4 虚假空间 A' 的运行式**
   - 不是切断输入而是替换输入：$S_{n+1}=f'(S_n, I_n')$
   - $I_n'\neq0$ 但全是系统预设的虚假输入
   - 虚假空间的二阶性：对运行者=真实本身，仅二阶视角可识别
   - 东京模式=虚假空间巅峰，衡水模式=悬置典型

5. **9.5 与量论的打通**
   - $o_n$ ↔ N（操作率）
   - $g_n$ → 待量化为 G（感通量）
   - $a_n$ → 待量化为 A（应自主度）
   - f 退化 ↔ α 下降
   - 完全悬置 = N≈0 且 G≈0 且 A≈0
   - 待推进：G 和 A 的操作化定义与测量方法

6. **9.6 小本质↔大本质验证**
   - 下行：悬置→衡水/996/孤独死；虚假空间→东京/资本市场/高考
   - 上行：衡水有效→悬置定义→自指需输入→S=f(S)开放性→操作先于实体
   - 反面推导：如果悬置不存在→人可在真空中活着→反面自毁
   - 交叉印证：悬置从动态运行式/量论/感三条路径独立推出

### 发现的问题
- 无硬伤。动态运行式与既有 S=f(S)、量论公式、四规定性框架均自洽。
- 新增待推进项：感通量 G 和应自主度 A 的操作化定义（量论从操作层扩展到感层和应层的关键）。
