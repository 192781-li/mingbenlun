## 2026-08-23（追加：检查6）

### 新增：检查6 本性→应该跳跃检测

**背景**：用户提出日后写作中可能会把决断写成必然性——"出于人之为人的本性""最优选择""本质上"等存在论表述推出规范判断（应该/必须/要）。

**判定逻辑**：
- 本性侧触发词：本性、人之为人、出于本性、本质上、从根本上、必然选择、最优选择、合乎本性、天生、与生俱来、人的本质、作为人、为人之本、本性上、本然
- 规范侧触发词：应该、必须、应当、需要、要去、要选择、要追求、要实现、要解放、要站在、要反对
- 两侧同时出现 → 检查白名单
- 白名单：已有【决断】或⊩ₘ中介 → 跳过；条件句（"如果X就必须Y"是工具必然）→ 跳过；纯描述（只有本性词没有规范命令词）→ 跳过

**原理**：从"本性是X"到"应该X"中间站着一个活人——本性可能被异化、合乎本性的路径可能不止一条、"应该"涉及特定历史条件下的价值排序。这是决断不是演绎，可以论证"这是最合乎本性的选择"【概念+决断】，但不能写成"这是必然的"。

**当前状态**：推导链总览中0处命中。脚本已升级为检查1-6。

## 2026-08-23（任务4：量论公式双向验证）

### 完成内容

**任务4：量论公式小本质↔大本质双向验证** —— 完成

对量论公式体系（M=α·T·N、W=O/M、l′=(1-N)×100%、C=R-A、N三态）做四维度双向验证：

1. **下行验证（存在论→量论显现）**：4个存在论命题均在量论中有精确显现
   - 操作存在论 → M=α·T·N（T对应闭包完整度，α对应嵌套层级，N对应再生方向）
   - 反自指存在论 → l′=(1-N)×100%（基准线N=1对应反自指永久性，非完美最大值）
   - 主客关系存在论 → W=O/M（M主体侧，O客体侧，W关系属性）
   - 社会存在论 → C=R-A（R社会自指出产，A社会反自指侵蚀）

2. **上行验证（量论判断→存在论根基）**：4个量论判断均可完整追溯
   - N>1是善 → 自指操作自我增强（dV/dt>0）
   - N<1是恶 → 反自指寄生操作（dV/dt<0）
   - M无上限 → 自指操作递归开放性（无完成态）
   - 混淆M/W是颠倒 → 主客关系反自指化（客体支配主体）

3. **反面推导（公式不成立→存在论矛盾）**：4个反面推导均证明公式是存在论必然
   - 如果M有上限 → 存在论退化为柏拉图主义（本质先在论）
   - 如果l′基准是完美最大值 → 反自指永久性和继续革命根据消失
   - 如果W=O（价值=客体固有属性） → 存在论退化为实体本体论
   - 如果N只有两态（无持平态） → 自指操作"维持"状态和异化率零点无法定义

4. **交叉印证（公式间自洽）**：5组交叉印证均无矛盾
   - M与l′共享N，从不同角度描述dV/dt方向
   - M与W从主体侧和主客关系侧描述明性觉知程度
   - l′与C从个体层面和文明层面描述社会反自指影响
   - N三态与所有公式自洽
   - α/σ/K/Ω四个系数各归其位，无越位无重复

### 验证结论

**量论公式体系无结构性硬伤。** 公式与存在论之间的对应是严格的、双向的、必然的，不是任意构造或比喻性关联。
