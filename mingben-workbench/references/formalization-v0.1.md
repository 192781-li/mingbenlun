# 推导形式化尝试（v0.1）

> 这是尝试，不是经文。目标不是把哲学变成公理系统，是让推导的结构可以被检查——哪里有跳跃、哪里有偷换、哪里把决断伪装成了存在论结论。形式化是阴，活操作是阳，阴为阳服务。

## 一、为什么要形式化，以及为什么不能彻底形式化

### 为什么要

自然语言哲学有一个结构性的弱点：推导链条太长时，中间的跳跃会被流畅的文字掩盖。写的人觉得顺，读的人觉得顺，但"顺"不等于"通"——可能是修辞在搭桥，不是论证在搭桥。

代码已经在做文本结构的检查（章号、引用、manifest）。推导形式化想做的是下一层：**让论证结构也可以被检查**。

### 为什么不能彻底

1. **践演坐实不是公理。** 公理是设定的、不可质疑的起点；践演坐实是"你否认它就在使用它"的实事——它是活的，不是设定的。你不能把"在活着"写成公理然后演绎，因为演绎本身就是活着的一种方式，它在公理之下，不在公理之后。

2. **存在论给不出"应该"。** 从"是"到"应该"中间站着一个活人——一个在受苦、在判断、在选择的活人。这个跳跃不能被形式化消除，只能被显式标注：这里有一个决断，不要假装它是逻辑结论。

3. **哲学论证的有效性不只是形式有效性。** 一个论证可以形式上完美但空洞（同义反复），也可以形式上有跳跃但真正抓住了东西（跳跃被践演坐实）。形式检查能抓硬伤，不能代替明性判断。

4. **形式系统自己也是操作。** 哥德尔已经证明足够强的形式系统不能证明自己的一致性。生命论的形式化如果声称自己完备无矛盾，就犯了它批判的独断论错误。

**结论：形式化检查"推导有没有结构性硬伤"，不判断"推导对不对"。它是安检，不是裁判。**

## 二、推导的四种合法步骤

生命论中任何一步推导，只能是以下四种类型之一：

### 【践演】践演坐实

**形式**：否认X的行为本身在使用X。
**能推出**：X不可绕过。
**不能推出**：X是永恒真理、X是唯一可能的起点、从X可以演绎经验事实。
**例**："怀疑操作本身就是操作"→"操作不可绕过"。不能推出"操作是宇宙的终极实体"。

### 【概念】概念分析

**形式**：从已定义的概念中分析出结构关系。
**能推出**：概念之间的蕴含、排斥、层级关系。
**不能推出**：经验事实、价值判断。
**例**："反自指的三条判据"→"癌细胞是反自指"。不能推出"癌症在道德上是恶的"（恶需要感的受苦作为中介）。

### 【经验】经验概括

**形式**：基于观察、研究、历史的概括。
**能推出**：在证据范围内的趋势性判断。
**不能推出**：必然规律、存在论结论。
**可错性**：高——新证据可以推翻。
**例**："苏联官僚制退化"→"没有民主监督的专政会变质"。不能推出"一切专政必然变质"（那是超验化）。

### 【决断】政治决断/生存选择

**形式**：在事实判断的基础上，选择站在哪一边。
**能推出**：行动方向、立场表态。
**不能推出**：伪装成存在论定理或经验结论。
**例**："站在劳动者一边"是决断，不是从"操作先于实体"演绎出来的。必须显式标注，不能用"由此可见"糊过去。

## 三、推导有效性的四条判据

一个推导是"结构上有效的"（不是"内容上正确的"），当且仅当：

### 判据1：前提可追溯

每个前提必须能追溯到以下之一：
- 践演坐实的事实（标注【践演】）
- 概念分析的命题（标注【概念】）
- 有来源的经验证据（标注【经验】+来源）
- 明确的政治决断（标注【决断】）

**违规**：前提是"常识"、"不言自明"、"众所周知"——这些是未检验的惯性，不是前提。

### 判据2：推理类型匹配

- 【践演】只能推出不可绕过性，不能推出经验事实
- 【概念】只能推出结构关系，不能推出价值判断
- 【经验】只能推出趋势性判断，不能推出必然命题
- 【决断】只能推出立场和方向，不能伪装成存在论结论

**违规**：用经验概括推出存在论命题（"苏联变质了所以无产阶级专政必然变质"）；用概念分析推出价值判断（"阳主阴从所以应该革命"）。

### 判据3：中介显式

从"是"到"应该"、从存在论到社会分析、从社会分析到立场选择，每一个跨层跳跃必须有显式的中介步骤：

- 存在论→社会分析：需要经验材料（⊩ₑ）
- 社会分析→规范立场：需要阶级决断（⊩ₘ）

**违规**：用"由此可见""因此""不言而喻"把跳跃糊成无缝整体。

### 判据4：践演自洽

推导本身不能犯它批判的错误：
- 用独断的方式反对独断论
- 用经文的方式反对经文化
- 用阴压阳的方式论证阳主阴从
- 站在操作外面声称"操作之外无可说"
- 用"必然规律"代替"生命能胜"

**这条最难自动化**，但可以设计启发式检查（见第五节）。

## 四、概念依赖图

核心概念的依赖关系（箭头表示"依赖于"）：

```
操作 ──→ 自指(S=f(S)) ──→ 四规定性 ──→ 善/恶(自指/反自指)
  │              │
  │              ├──→ 感(第一人称) ──→ 应(第二人称) ──→ 伦理
  │              │
  │              ├──→ 阴阳 ──→ 阳主阴从(结构描述)
  │              │
  │              └──→ 反自指(P) ──→ dV/dt<0 ──→ 异化
  │
  ├──→ 明性(感递归到自觉) ──→ 真理(指导操作成功的预期)
  │
  └──→ 量论:
         T(原生稳态) ──→ M=α·T·N(生命意义)
         α(生命层级) ──↗
         N(负熵比率) ──↗     ├──→ W=O/M(生命价值)
         N>1/=1/<1 ──→ l′=(1-N)×100%(异化率)
         C=R-A(文明舒展度)
```

**检查规则**：
- 每个概念必须能追溯到"操作"这个根节点，否则是悬空概念
- 不能有循环依赖（A依赖B，B依赖A）——除非这个循环是践演坐实的（S=f(S)本身就是循环，但它是起点不是推导出来的）
- 量论概念依赖存在论概念，不能反过来用量论概念定义存在论概念（阴不压阳）

## 五、可代码化的检查（启发式）

以下检查可以用脚本实现，但都是启发式的——抓可疑模式，不做最终判决：

### 检查1：推理类型标注完整性

扫描推导链总览，每一步是否有【践演】【概念】【经验】【决断】标注？没有标注的步骤标记为"未分类"。

### 检查2：跨层跳跃检测

搜索"由此可见""因此""所以""不言而喻"等词，检查它连接的前后文是否在同一层（存在论/社会分析/规范立场）。跨层的标记为"需显式中介"。

### 检查3：经验命题超界检测

搜索从经验判断推出必然结论的模式："X必然""X一定""X不可能"——如果前提是经验概括，标记为"经验超界"。

### 检查4：决断伪装检测

搜索"存在论证明""从操作存在论推出""因此必须"等模式，如果后面跟着规范判断，检查是否有显式的【决断】标注。

### 检查5：践演自洽启发式

- 批判"教条"的段落是否本身在用教条的语气？（"必须""不容置疑""唯一正确"）
- 批判"经文"的段落是否把自己的概念写成了不可质疑的？
- 论证"阳主阴从"时是否用阴（形式结构）完全压过了阳（活操作）？

### 检查6：概念依赖完整性

检查每个核心概念是否在推导链中有定义步骤，是否有概念在未定义的情况下被使用。

## 六、小本质↔大本质的递归验证

这是用户的方法论，形式化为双向检查：

### 大本质→小本质（下行）

每个存在论命题必须能在具体领域显现：
- "反自指"必须能在资本、癌细胞、官僚制中找到具体实例
- "阳主阴从"必须能在劳动、语言、制度中找到具体表现
- "M=Meaning"必须能在具体生活（996、自由人联合体）中找到对应

**检查**：有没有大本质没有小本质显现？→ 空转（概念在自我循环）

### 小本质→大本质（上行）

每个具体判断必须能追溯到存在论根基：
- "996是恶" → 反自指（dV/dt<0）→ 四规定性坍塌 → 操作先于实体
- "生产资料公有制" → N>1 → M增长 → 生命意义舒展
- "异化率l′=(1-N)" → N三态 → 负熵比率 → 操作的自我维持

**检查**：有没有小本质找不到大本质根基？→ 悬空（就事论事，没有理论根基）

### 反面推导

每个命题必须能通过反面检验：
- 如果"操作先于实体"是对的，那么"实体先于操作"的世界会是什么样？（石头的世界——S=f(E)，没有目的，没有善）→ 反面自毁：主张"实体先于操作"本身就是操作
- 如果"N>1是善"是对的，那么"N<1是善"的世界会是什么样？（越劳动越亏损，越操作越衰弱）→ 反面自毁：生命体在N<1中走向死亡

### 交叉印证

不同路径推出同一结论：
- "善是自指"从概念分析来（四规定性全）
- "善是自指"从感来（感在舒展时是善）
- "善是自指"从量论来（N>1时M增长）
- 三条路径独立推出同一结论，结论的可信度提高

**这不是证明，是印证。** 三条路径都可能错，但它们独立地指向同一个方向，这个收敛本身是证据。

## 九、自指循环的动态运行式与悬置（v0.2 新增）

> 本节将 S=f(S) 从静态封闭等式推进为动态分步运行式，加入外部输入维度，严格定义悬置，并区分四种反生命操作形态。

### 9.1 从 S=f(S) 到 S_{n+1}=f(S_n, I_n)

**原公式的局限**：S=f(S) 是一个封闭的自指等式——S 自己产生自己，没有外部输入的位置。但实际上自指循环不是完全封闭的，它需要外部输入才能运行：感需要对象，应需要参照，操作需要空间。

**动态运行式**：

$$S_{n+1}=f(S_n, I_n)$$

其中：
- $S_n$：第 n 步的自指状态
- $f$：自指函数（感→应→操作的递归结构）
- $I_n$：第 n 步的外部输入向量

**$I_n$ 的三维分解**：

$$I_n = (g_n, a_n, o_n)$$

- $g_n$（感输入）：能感受到什么——感的对象、感的强度、感的质量
- $a_n$（应输入）：有什么判断参照——价值标准、认知框架、社会规范
- $o_n$（操输入）：有什么操作空间——行动余地、资源、时间、身体条件

**三维独立悬置**：
- 只切断 $g_n$ → **麻木**（感不到了，感被驯化）
- 只切断 $a_n$ → **盲从**（不会判断了，应被接管）
- 只切断 $o_n$ → **无力**（想做但做不了，操作被封死）
- 三个全切断 → **完全悬置**

### 9.2 悬置的严格定义

$$I_n \approx 0 \Rightarrow S_{n+1} \approx S_n$$

**悬置**：反生命操作通过切断感-应-操作的全部输入通道，使自指循环进入 $I_n \approx 0$ 的停滞状态。

**关键区分**：
- $f$ 未被替换（自指能力还在）
- $S$ 未被消灭（人还活着，精神没崩溃）
- 但循环不运行了（没有输入，自指无法迭代）

**悬置 vs 其他三种反生命形态**：

| 形态 | 对 f 的作用 | 对 I_n 的作用 | 对 S 的作用 | 可逆性 | 典型案例 |
|------|-----------|--------------|------------|--------|---------|
| **终止** | - | - | 消灭 S | 不可逆 | 死亡、精神彻底崩溃 |
| **驯服** | 替换 f→f' | 保留 | 保留但运行 f' | 可逆但难 | 意识形态洗脑、宗教狂热 |
| **收编** | 不变 | 保留但限定轨道 | 保留 | 可逆 | 亚文化商业化、反抗被消费 |
| **悬置** | 不变 | 切断→≈0 | 保留但不运行 | 可逆但解除时扭曲 | 衡水模式、996耗竭、孤独死前期 |

**悬置比驯服阴险**：驯服至少留撕裂感（f 和 f' 的冲突会产生痛苦），悬置连"被压迫"的感受都产生不出——因为感的输入被切断了，连痛苦都感受不到。

### 9.3 f 的退化：长期悬置的不可逆损伤

公式 $S_{n+1}=f(S_n, I_n)$ 假设 f 不变，但长期悬置会导致 f 本身退化——就像肌肉长期不用会萎缩。

**退化项**：

$$f_n = f_{n-1} \times (1 - \delta \cdot \mathbb{1}[I_{n-1} \approx 0])$$

其中：
- $\delta$：单次悬置的退化率（小量，取决于悬置时长和个体韧性）
- $\mathbb{1}[I_{n-1} \approx 0]$：指示函数，上一步是否处于悬置状态

**含义**：每一步悬置，f 都会衰减一点。长期悬置后，即使 $I_n$ 恢复，f 已经退化了，无法正常运行。

**悬置解除危机**：长期悬置者只学会了"被悬置地运行"，自由到来时以扭曲方式运行——因为 f 已经退化了，感麻木了、应盲从了、操作无力了，恢复输入后这些退化的功能无法立刻恢复正常。

**与量论的对应**：f 的退化对应 $\alpha$（生命层级）的下降——长期悬置者的生命层级降低，即使操作量恢复，M=α·T·N 也因为 α 下降而无法恢复。

### 9.4 虚假空间 A' 的运行式

悬置是 $I_n \approx 0$，但虚假空间型反生命操作不是切断输入，而是**替换输入**：

$$S_{n+1} = f'(S_n, I_n')$$

其中：
- $f'$：虚假自指函数（边界、规则、评价标准由系统预设）
- $I_n'$：虚假输入（一切连接须付费、关系须不打扰、欲望须被消费满足）

**关键**：$I_n' \neq 0$，输入是充足的，但所有输入都是系统预设的虚假输入。自指在运行，但运行的是系统设定的轨道，不是运行者自己的轨道。

**虚假空间的二阶性**：$S'$ 对运行者=真实本身。虚假性仅在二阶视角成立——空间内部没有"虚假"范畴，运行者在里面感受到的一切都是真实的（痛苦是真实的，快乐是真实的，焦虑是真实的）。只有跳出空间从二阶视角看，才能识别其虚假性。

**东京模式 = 虚假空间的巅峰**：一切空间都给，一切连接须付费；"低欲望"不是选择，是自指衰竭到无法产生欲望的存在论状态。

**衡水模式 = 悬置的典型**：不是替换输入，是切断输入——没有感受时间、没有判断机会、没有操作空间。

### 9.5 与量论的打通

量论目前只量化了操作层（M=α·T·N，N=操作率），感层和应层还没有量化指标。动态运行式提供了打通方向：

| 动态运行式 | 量论 | 关系 |
|-----------|------|------|
| $o_n$（操输入） | N（操作率） | $o_n$ 充足 → N 高；$o_n$ 切断 → N≈0 |
| $g_n$（感输入） | 待量化 | 感的强度/质量目前无量论指标，可设 $G$（感通量） |
| $a_n$（应输入） | 待量化 | 应的独立性目前无量论指标，可设 $A$（应自主度） |
| $f$ 退化 | $\alpha$（生命层级） | 长期悬置 → f 退化 → α 下降 |
| $I_n \approx 0$（悬置） | N≈0 且 G≈0 且 A≈0 | 完全悬置 = 三维输入全切断 |

**待推进**：感通量 G 和应自主度 A 的操作化定义与测量方法。这是量论从操作层扩展到感层和应层的关键一步。

### 9.6 小本质↔大本质验证

**下行（存在论→具体领域）**：
- 悬置公式 → 衡水中学（$I_n$ 全切断）、996 耗竭（$o_n$ 过载但 $g_n,a_n$ 被切断）、孤独死（长期 $I_n≈0$ → f 退化 → S 慢性衰竭）
- 虚假空间公式 → 东京消费社会（$I_n'$ 充足但全预设）、资本市场（f'=增值逻辑）、高考应试（$I_n'$=标准答案轨道）

**上行（具体判断→存在论根基）**：
- "衡水模式有效" → $I_n≈0 \Rightarrow S_{n+1}≈S_n$ → 悬置定义 → 自指循环需要外部输入 → S=f(S) 的开放性 → 操作先于实体
- "东京低欲望" → $S_{n+1}=f'(S_n,I_n')$ → 虚假空间 → f' 替换 f → 自指运行权被夺 → 反自指四规定性坍塌

**反面推导**：
- 如果悬置不存在（$I_n≈0$ 不影响 S），那么自指循环不需要外部输入 → S=f(S) 是完全封闭的 → 人可以在真空中活着 → 反面自毁：否认输入必要性本身就是一种操作，需要输入（至少需要氧气、信息）

**交叉印证**：
- 悬置从动态运行式来（$I_n≈0$）
- 悬置从量论来（N≈0 且 G≈0 且 A≈0）
- 悬置从感来（感不到了=麻木）
- 三条路径独立推出同一结论

## 十、边界：形式化不能做什么

1. **不能判断一个洞见的深浅。** "操作先于实体"和"奶茶先于吸管"在形式上可能结构相同，但深浅完全不同。形式化看不出深浅。

2. **不能代替践演坐实。** "在活着"不需要形式化来证明——你在读这句话的时候就在活着。形式化可以标注它是【践演】，但不能代替读者亲自践演。

3. **不能消除决断。** "站在劳动者一边"永远是一个决断，不是定理。形式化能做的是确保这个决断不被伪装成定理。

4. **不能发现新东西。** 形式化检查已有的推导，不产生新的洞见。新洞见来自活操作——来自受苦、思考、斗争、对话。

5. **自己也是可错的。** 这套形式化框架本身是操作的产物，可以被修正、被推翻。如果它变成了新的经文——用它来压活的思考——它就应该被砸碎。
