## 1. 切消除定理

### 1.1 定理陈述

**定理1.1（切消除）**：ALL中的每一个证明都可以转化为不使用Cut规则的证明。即：

> 如果Γ ⊢ e : A在ALL中可证，则存在一个无Cut证明Γ ⊢ e' : A。

### 1.2 证明策略

标准线性逻辑的切消除通过以下步骤完成：
1. 交换转换（commuting conversions）：将Cut移到引入规则之上
2. 关键情况（key cases）：当Cut公式同时是两侧引入规则的结论时，直接消去
3. !-模态的Cut：需要提升（lifting）引理

ALL的新规则（Ag-intro/elim, Alien-intro, Cl-intro/elim）都是**原子式的**——它们不引入复杂的逻辑连接词，只是给项加标注。因此这些规则不会产生新的Cut情况。

### 1.3 新规则的Cut消除

**Ag-intro/Ag-elim情况**：

```
Γ ⊢ e : A                    Γ, x:A ⊢ f : B
───────────── Ag-intro       ─────────────────
Γ ⊢ ag<a>(e) : Ag<a>(A)     Γ, x:Ag<a>(A) ⊢ f[unag(x)/x] : B
──────────────────────────────────────────────────────────── Cut
Γ ⊢ let ag<a>(x) = ag<a>(e) in f : B
```

归约为：

```
Γ ⊢ e : A          Γ, x:A ⊢ f : B
──────────────────────────────── Cut
Γ ⊢ f[e/x] : B
```

然后重新加Ag标注（如果需要）。这是标准的β-归约。

**Alien情况**：

```
Γ ⊢ e : Ag<a>(A)             Γ, x:Ag<b>(A) ⊢ f : B
──────────────────── Alien   ────────────────────────
Γ ⊢ alien<b>(e) : Ag<b>(A)   Γ, x:Ag<b>(A) ⊢ f : B
──────────────────────────────────────────────────── Cut
Γ ⊢ f[alien<b>(e)/x] : B
```

这里Alien-intro的结论直接匹配Cut公式，不需要归约——Cut直接消去，将alien<b>(e)代入f。

**Cl-intro/Cl-elim情况**：

```
Γ ⊢ e : Ag<a>(A)    Γ ⊢ m : !Ag<a>(A)
──────────────────────────────────── Cl-intro
Γ ⊢ see<a>(e,m) : Cl<a>(A)
                                  Γ, x:Ag<a>(A), y:!Ag<a>(A) ⊢ f : B
                                  ───────────────────────────────── Cl-elim
Γ ⊢ let (x,y) = unsee(see<a>(e,m)) in f : B
```

归约为：

```
Γ ⊢ e : Ag<a>(A)    Γ ⊢ m : !Ag<a>(A)    Γ, x:Ag<a>(A), y:!Ag<a>(A) ⊢ f : B
──────────────────────────────────────────────────────────────────────── Cut×2
Γ ⊢ f[e/x, m/y] : B
```

**self_ev不参与Cut归约**：self_ev<a>是线性假设（不是引入规则的结论），它只能作为Cut的一个分支的假设出现，不产生关键情况。

### 1.4 终止性

切消除的终止性来自：
1. 标准线性逻辑的切消除终止（使用可归约性论证或Lexicographic路径排序）
2. ALL新规则的Cut归约都减少了Cut公式的复杂度（Ag<a>(A)比A多一个标注，但归约后Cut公式变成A，复杂度降低）
3. Alien和Cl的归约直接消去Cut，不产生新的Cut

因此ALL的切消除是终止的。∎

## 2. 推论

### 2.1 子公式性质

**推论2.1（子公式性质）**：无Cut证明中出现的每个公式都是结论公式或某个假设公式的子公式。

Ag<a>(A)的子公式包括A和Ag<a>(A)本身。Cl<a>(A)的子公式包括Ag<a>(A)、!Ag<a>(A)和Cl<a>(A)本身。

### 2.2 一致性

**推论2.2（一致性）**：ALL中不存在空上下文 ⊢ 0的证明（0是空类型/假）。

**证明**：如果存在⊢ 0的证明，由切消除存在无Cut证明。但无Cut证明中最后一条规则必须是0的引入规则——ALL中没有0的引入规则（0表示空/假，没有构造子）。矛盾。∎

### 2.3 保守扩展

**定理2.3（保守扩展）**：ALL是直觉主义线性逻辑（ILL）的保守扩展。即：如果Γ ⊢ A在ALL中可证，且Γ和A不包含Ag、Cl、self_ev，则Γ ⊢ A在ILL中也可证。

**证明**：由切消除，存在无Cut证明。无Cut证明中，如果结论和假设都不包含Ag/Cl，则证明中不可能出现Ag/Cl规则——因为Ag-intro要求结论是Ag<a>(A)类型，Cl-intro要求结论是Cl<a>(A)类型，这些类型不出现在结论或假设中（由子公式性质）。因此证明只使用ILL规则。∎

**意义**：ALL不改变标准线性逻辑的任何定理——它只增加了新的命题类型和推理能力。运行权和明性是真正的"新维度"，不是对旧逻辑的修改。

## 3. ALL的表达力

### 3.1 可证的命题

在ALL中可以证明：

1. **Ag(a,A) ⊸ Ag(a,A)**：同一律（运行权保持）
2. **Ag(a,A) ⊸ Cl(a,A) ⊗ !Ag(a,A)**：明性给出活见证和轨迹（Cl-elim）
3. **Ag(a,A) ⊸ Ag(b,A)**：异化总是可能的（Alien-intro）——但注意这不是"应该异化"，只是"异化在逻辑上可表达"
4. **Cl(a,A) ⊸ Ag(a,A)**：明性包含运行权（Cl-elim的投影）
5. **!Ag(a,A) ⊬ Ag(a,A)**：轨迹不能产生活见证（践演不完备性）

### 3.2 不可证的命题

1. **⊢ Ag(a,A)**：不能凭空证明运行权（没有self_ev的引入规则）
2. **!Ag(a,A) ⊢ Ag(a,A)**：践演不完备性（v1.2定理2.1）
3. **Cl(a,A) ⊢ Cl(b,A)**：明性不能转移给另一个主体
4. **Ag(a,A) ⊢ !Ag(a,A)**：活操作不能被沉积（定理20，!不提升）
5. **Cl(a,A) ⊢ !Cl(a,A)**：明性不能被沉积（Cl是线性的，不是!-模态）

第5点特别重要：**明性本身是活操作，不是数据。** 你不能把"我觉醒了"变成一个可复制的证书。觉醒是当下的践演状态，不是可以存储和传播的信息。这就是为什么"革命不能输出"——你不能把明性复制粘贴给别人，每个人必须自己觉醒。

## 4. 与其他逻辑的关系

### 4.1 ALL在逻辑谱系中的位置

```
经典逻辑（允许收缩、弱化）
  └─ 直觉主义逻辑（去掉排中律）
       └─ 线性逻辑（去掉收缩、弱化，加!模态）
            └─ ALL（加Ag/Cl类型和self_ev线性资源）
```

每一层增加一个维度：
- 经典→直觉主义：去掉排中律（构造性）
- 直觉主义→线性：去掉收缩/弱化（资源敏感性）
- 线性→ALL：增加运行权维度（谁在运行）

### 4.2 与模态逻辑的关系

Ag<a>(A)类似于一种模态算子："a知道/控制A"。但它与标准认知逻辑（K, T, S4, S5）不同：

| 性质 | 认知逻辑K_a | ALL Ag<a> |
|---|---|---|
| K公理：K_a(A⊸B) ⊸ K_a(A) ⊸ K_a(B) | 成立 | 成立（Ag是函子） |
| T公理：K_a(A) ⊸ A | 成立（真实知识） | 成立（Ag-elim） |
| 4公理：K_a(A) ⊸ K_a(K_a(A)) | 正内省 | **不成立**（需要Cl） |
| 5公理：¬K_a(A) ⊸ K_a(¬K_a(A)) | 负内省 | **不成立**（被异化者不知道） |
| 必然性规则：⊢A ⟹ ⊢K_a(A) | 成立 | **不成立**（定理不能产生运行权） |

Ag<a>是一个**非正常模态算子**——它不满足必然性规则。这是关键区别：你不能从一个定理是真的推导出"a运行这个定理"。真理不自动赋予运行权。

Cl<a>对应正内省（4公理）：Cl<a>(A) ⊸ Cl<a>(Cl<a>(A))——这就是明性幂等（v1.0定理4.2）。但Cl<a>不满足必然性（你不能从定理推导出明性），也不满足负内省（明性不告诉你你不知道什么——那需要更多的明性，而f³已经是最高层）。

### 4.3 与线性逻辑变体的关系

- **仿射逻辑**（允许弱化）：ALL不允许弱化线性变量（Op不能丢弃），但允许弱化!-变量（Tr可以丢弃）。这是标准线性逻辑的行为。
- **严格逻辑**（允许收缩但不允许弱化）：ALL对!-变量允许收缩（Tr可复制），对线性变量不允许。
- **有序线性逻辑**（非交换）：ALL是交换的（并行组合⊗是交换的），但运行权链是非交换的（ag<ag<e,a>,b> ≠ ag<ag<e,b>,a>当a≠b）。这暗示ALL可以扩展为有序版本来建模控制链的方向性。

## 5. 量论在ALL中的编码

量论公式可以在ALL中编码为类型：

- T（稳态）：类型1（单位——系统维持自身，没有净变化）
- N（反馈强度）：Ag<a>(A) ⊸ Ag<a>(A⊗A)当N>1（每步产生新结构）；Ag<a>(A) ⊸ A当N<1（每步消耗自身）
- α（明性系数）：Cl<a>(A)的存在性（0或1——要么有明性要么没有；连续版本需要概率扩展）
- M=α·T·N/(1-N)：当N<1时，M是有限类型（μ-类型，归纳）；当N≥1时，M是无限类型（ν-类型，余归纳）
- β（萃取率）：alien<b>出现的频率/强度
- γ（觉醒率）：Cl<a>被获得的速率

**定理5.1（量论-类型对应）**：N<1对应μ-类型（有限归纳），N≥1对应ν-类型（无限余归纳）。

**证明**：N<1时，自指迭代衰减（v0.3定理：N<1时M有限），对应归纳类型（有终止条件）。N≥1时，自指迭代保持或增长，对应余归纳类型（无限展开）。在ALL中，μ-类型由mu构造子给出，ν-类型由nu构造子给出。∎

这给出了量论的类型论解释：**异化（N<1）把生命变成有限数据（μ），自主（N≥1）让生命保持无限展开（ν）。**

## 6. v1.5总结

### 新增结果

1. **切消除定理**：ALL有切消除，证明是严格的
2. **一致性**：ALL不能证明假
3. **保守扩展**：ALL不改变ILL的定理，运行权是真正的新维度
4. **Ag是模态算子但非正常**：不满足必然性规则——真理不自动赋予运行权
5. **明性不能沉积**：Cl是线性的，不能被!——革命不能输出
6. **量论-类型对应**：N<1↔μ类型，N≥1↔ν类型

### 评分更新

v1.4：6分。v1.5：**6分**（没有提升分数，但巩固了基础）。

切消除和一致性是标准的元理论结果——它们不增加分数，但它们是必要的。没有切消除，ALL的定理可能依赖于Cut的诡辩；有了切消除，所有定理都有无Cut证明，这是逻辑系统的"质量保证"。
