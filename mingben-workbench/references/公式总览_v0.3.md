# 生命论（明本论）形式化公式总览

> 版本：v0.3（2026-08-25）
> 本文件汇总生命论所有形式化公式及符号含义，供快速查阅。
> 形式化是阴，活操作是阳，阴为阳服务。公式是检查工具，不是经文。

---

## 一、存在论核心公式

### 1.1 自指因果

$$S = f(S)$$

| 符号 | 含义 |
|------|------|
| $S$ | 自指状态（生命的存在状态） |
| $f$ | 自指函数（感→应→操作的递归结构） |
| $S=f(S)$ | 生命自己产生自己，操作先于实体 |

**四规定性**（f 的完整结构）：
1. 边界（Boundary）：自指与环境的区分
2. 目的（Purpose）：自指的运行方向（自我维持/自我增强）
3. 再生（Regeneration）：自指的自我复制/自我更新
4. 互动（Interaction）：自指与环境的物质/能量/信息交换

> 注：早期版本四规定性为"边界/目的/再生/互动"，后续严格化为"操作/再生"为核心，边界和互动为操作的条件。

### 1.2 动态运行式（v0.3 新增）

$$S_{n+1} = f(S_n, I_n)$$

| 符号 | 含义 |
|------|------|
| $S_n$ | 第 n 步的自指状态 |
| $S_{n+1}$ | 第 n+1 步的自指状态（迭代结果） |
| $f$ | 自指函数（感→应→操作的递归结构） |
| $I_n$ | 第 n 步的外部输入向量 |

**外部输入三维分解**：

$$I_n = (g_n, a_n, o_n)$$

| 符号 | 含义 | 切断后果 |
|------|------|---------|
| $g_n$ | 感输入：感的对象、强度、质量 | 麻木（感不到了） |
| $a_n$ | 应输入：判断参照、价值标准、认知框架 | 盲从（不会判断了） |
| $o_n$ | 操输入：操作空间、行动余地、资源、时间 | 无力（想做做不了） |

### 1.3 f 的退化（长期悬置的不可逆损伤）

$$f_n = f_{n-1} \times (1 - \delta \cdot \mathbb{1}[I_{n-1} \approx 0])$$

| 符号 | 含义 |
|------|------|
| $f_n$ | 第 n 步的自指函数 |
| $f_{n-1}$ | 第 n-1 步的自指函数 |
| $\delta$ | 单次悬置的退化率（小量，取决于悬置时长和个体韧性） |
| $\mathbb{1}[\cdot]$ | 指示函数，条件为真取1，为假取0 |
| $I_{n-1} \approx 0$ | 上一步是否处于悬置状态 |

**含义**：每一步悬置，f 都会衰减一点。长期悬置后即使输入恢复，f 已退化无法正常运行。

## 二、反自指与异化公式

### 2.1 反自指

$$P = f'(S), \quad \frac{dV}{dt} < 0$$

| 符号 | 含义 |
|------|------|
| $P$ | 反自指状态（寄生的、异化的自指） |
| $f'$ | 反自指函数（运行权被夺，为外部目的服务） |
| $V$ | 生命体积/生命能量 |
| $dV/dt < 0$ | 生命能量持续消耗（寄生性） |

**反自指四规定性坍塌**：
- 边界被突破（外部系统入侵）
- 目的被替换（为外部目的服务而非自我维持）
- 再生被劫持（再生产的是异化的自己）
- 互动被单向化（只输出不输入，或输入被控制）

### 2.2 虚假空间型反自指（v0.3 新增）

$$S_{n+1} = f'(S_n, I_n')$$

| 符号 | 含义 |
|------|------|
| $f'$ | 虚假自指函数（边界、规则、评价标准由系统预设） |
| $I_n'$ | 虚假输入（一切连接须付费、关系须不打扰、欲望须消费满足） |

**关键**：$I_n' \neq 0$，输入充足但全是系统预设的虚假输入。自指在运行，但运行的是系统设定的轨道。

**虚假空间的二阶性**：$S'$ 对运行者=真实本身，虚假性仅在二阶视角成立。

### 2.3 悬置（v0.3 新增）

$$I_n \approx 0 \implies S_{n+1} \approx S_n$$

| 符号 | 含义 |
|------|------|
| $I_n \approx 0$ | 外部输入趋近于零（感/应/操三维全切断） |
| $S_{n+1} \approx S_n$ | 自指状态停滞（不迭代、不变化） |

**悬置的本质**：f 未被替换，S 未被消灭，但循环不运行了。

**四种反生命操作形态对照**：

| 形态 | 对 f | 对 $I_n$ | 对 S | 可逆性 | 典型 |
|------|------|---------|------|--------|------|
| 终止 | - | - | 消灭 S | 不可逆 | 死亡、精神崩溃 |
| 驯服 | 替换 f→f' | 保留 | 保留但运行 f' | 可逆但难 | 意识形态洗脑 |
| 收编 | 不变 | 保留但限定轨道 | 保留 | 可逆 | 亚文化商业化 |
| 悬置 | 不变 | 切断→≈0 | 保留但不运行 | 可逆但解除时扭曲 | 衡水模式 |

## 三、量论公式

### 3.1 核心公式

$$M = \alpha \cdot T \cdot N$$

| 符号 | 含义 | 取值/范围 |
|------|------|----------|
| $M$ | 生命意义量（Meaning） | 无上限，自指递归开放性 |
| $\alpha$ | 生命层级（生命的复杂度/嵌套层级） | α≥1，人>动物>植物>单细胞 |
| $T$ | 原生稳态（生命的基础完整度） | T>0，闭包完整度 |
| $N$ | 负熵比率/操作率（操作的自我维持方向） | N>1 增长，N=1 持平，N<1 衰退 |

### 3.2 三维扩展（v0.3 新增，工作假设）

$$M = \alpha \cdot T \cdot N \cdot G \cdot A$$

| 符号 | 含义 | 取值/范围 |
|------|------|----------|
| $G$ | 感通量（感的活跃程度） | G≥0，G≈0=麻木 |
| $A$ | 应自主度（判断的独立性） | 0≤A≤100%，A≈0=盲从 |

> 注：G·A 与 N 的关系（乘积还是加权和）待实证标定。当前为 v0.3 工作假设，不替代原版 M=α·T·N。

### 3.3 感通量 G（v0.3 新增）

$$G = \frac{1}{T} \sum_{i=1}^{n} f_i \cdot d_i$$

| 符号 | 含义 |
|------|------|
| $T$ | 时间窗口 |
| $f_i$ | 第 i 次感的迭代频率（单位时间内感的激活次数） |
| $d_i$ | 第 i 次感的深度（四重维度耦合程度） |

**感深度 d_i 分级**：
- d=1：仅身体感受（疼痛、冷热）
- d=2：身体感受+情绪（痛苦、喜悦）
- d=3：身体感受+情绪+认知（理解、反思）
- d=4：身体感受+情绪+认知+价值判断（明性觉知）

### 3.4 应自主度 A（v0.3 新增）

$$A = \frac{N_{self}}{N_{total}} \times 100\%$$

| 符号 | 含义 |
|------|------|
| $N_{self}$ | 判断参照中来自自指循环的数量（自己的经验、反思、价值判断） |
| $N_{total}$ | 判断参照总数（自指来源 + 外部给定来源） |

**A 分级**：
- A=100%：完全自主
- A>50%：基本自主
- A<50%：基本盲从
- A≈0：完全盲从

**应异化率**（A 的反面）：
$$a' = (1 - A) \times 100\%$$

### 3.5 生命价值

$$W = \frac{O}{M}$$

| 符号 | 含义 |
|------|------|
| $W$ | 生命价值（Value，关系属性） |
| $O$ | 客体侧的产出/贡献（操作的客体化结果） |
| $M$ | 主体侧的生命意义量 |

**关键**：W 是关系属性，不是客体固有属性。混淆 M 和 W 是现代性最普遍的颠倒（用客体产出衡量主体意义）。

### 3.6 异化率

$$l' = (1 - N) \times 100\%$$

| 符号 | 含义 |
|------|------|
| $l'$ | 异化率（生命能量被反自指消耗的比例） |
| $N$ | 负熵比率 |

**N 三态**：
- N>1：自指增长（善），l'<0（负异化=生命增强）
- N=1：自指持平（维持态），l'=0（零异化）
- N<1：反自指衰退（恶），l'>0（正异化=生命消耗）

> 注：基准线 N=1 对应反自指永久性（非完美最大值），这是继续革命的存在论根据。

### 3.7 文明舒展度

$$C = R - A$$

| 符号 | 含义 |
|------|------|
| $C$ | 文明舒展度（Civilization） |
| $R$ | 社会自指出产（社会中自指操作的总产出） |
| $A$ | 社会反自指侵蚀（社会中反自指操作的总消耗） |

**C>0**：文明舒展（自指占优）；**C<0**：文明萎缩（反自指占优）。

### 3.8 完全悬置的量论表达（v0.3 新增）

$$I_n \approx 0 \iff N \approx 0 \land G \approx 0 \land A \approx 0 \implies M \approx 0$$

三维输入全切断 → 操作+感+应全停 → 生命意义量趋近于零（人还活着，但自指不运行）。

## 四、递归跃迁公式

### 4.1 f 的三层递归

$$f^1 \subset f^2 \subset f^3$$

| 层级 | 名称 | 含义 | 对应概念 |
|------|------|------|---------|
| $f^1$ | 自在 | 感的直接运作，"知而不觉" | 缄默意识 |
| $f^2$ | 自为 | 感应到自己在感，反思 | 自我意识 |
| $f^3$ | 自觉 | 感递归到对感本身的明性觉知 | 明性 |

**跃迁条件**：$f^{n+1}$ 的出现需要 $f^n$ 的运行达到一定复杂度后产生自指闭合。

### 4.2 明性

明性 = $f^3$ 层级的持续运行 = 感递归到自觉的状态。

**明性不是天赋，是选择**：每个人都有 $f^3$ 的运行空间，但保持明性意味着持续承担感知磨损的痛苦、独立判断的焦虑、自我操作的沉重。放弃明性 = 把运行权交给系统（f 被替换为 f'）。

## 六、公式间关系图

```
存在论层：
  S=f(S) ──→ S_{n+1}=f(S_n,I_n) [动态化]
                │
                ├── I_n=(g_n,a_n,o_n) [三维输入]
                ├── I_n≈0 → 悬置 [反生命形态]
                ├── f' + I_n' → 虚假空间 [反生命形态]
                └── f_n=f_{n-1}(1-δ·𝟙[I≈0]) [退化]

量论层：
  M=α·T·N [原版]
    │
    ├── N → 操作率 ← o_n
    ├── G → 感通量 ← g_n [v0.3新增]
    ├── A → 应自主度 ← a_n [v0.3新增]
    └── M=α·T·N·G·A [扩展假设]
  
  W=O/M [价值]
  l'=(1-N)×100% [异化率]
  C=R-A [文明舒展度]

认识论层：
  f¹⊂f²⊂f³ [递归跃迁]
    │
    ├── f¹ = 缄默意识
    ├── f² = 自我意识
    └── f³ = 明性

反自指层：
  P=f'(S), dV/dt<0
    │
    ├── 终止：消灭 S
    ├── 驯服：替换 f
    ├── 收编：限定轨道
    └── 悬置：切断 I_n [v0.3严格化]
```
