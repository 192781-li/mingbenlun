# 第一章：自生成范畴

## 1.1 动机

标准范畴论先有对象（名词），再有态射（动词）。但生命不是"东西在动"——是"动维持着东西"。代谢维持细胞，运作维持机构，实践维持理论。我们需要一种数学，其中操作（态射）是第一性的，对象（实体）是操作网络中涌现的稳定模式。

## 1.2 反应网络范畴

**定义1.1（反应网络范畴）**：一个反应网络范畴（RNC）是一个对称幺半范畴（C, ⊗, I），其中：
- 对象表示"物种"（资源类型）
- 态射 f: A → B 表示"反应"（消耗A，产出B）
- ⊗表示并行（多种资源同时存在）
- 态射是线性的（反应物被消耗，不能隐式复制或丢弃）

线性性是关键：化学反应中反应物被消耗，这正是线性逻辑的资源解释。!A表示"催化剂"——不被消耗、可重复使用的物种。

**定义1.2（反应网络）**：C中的一个反应网络是一个态射集合R ⊆ Mor(C)，满足：
- R对复合封闭（反应可以串联）
- R对⊗封闭（反应可以并行）

**定义1.3（食物集）**：食物集F是一组对象，它们从外部环境"免费"获得（不由网络内的反应产生），但可以被网络内的反应消耗。

**定义1.4（催化）**：一个反应f: A⊗C → B⊗C中，C是催化剂——它被需要但不被消耗（C同时出现在输入和输出中）。在线性逻辑中，这精确对应!C：催化剂是!-模态资源。

## 1.3 自生成网络

**定义1.5（自生成网络）**：一个反应网络R相对于食物集F是自生成的，如果：

1. **自催化（Reflexively Autocatalytic）**：对每个反应r ∈ R，r所需的每个催化剂c都由R中的某个反应r'产生（即c是r'的输出的!-模态分量）；
2. **食物生成（Food-generated）**：R中每个反应的反应物要么属于F，要么由R中的其他反应产生；
3. **生产性（Productive）**：对每个食物输入f ∈ F，存在至少一条反应链产生非食物输出。

这是RAF理论在线性逻辑范畴中的重新表述。新东西在下面。

## 1.4 活的自维持vs死的自复制

**定义1.6（活的自维持）**：一个自生成网络R是活的（νF₂型），如果：

1. **线性产出**：R中至少有一个反应产出线性（非!-模态）资源，且该资源不是输入的简单复制；
2. **状态扩展**：R的反馈结构允许新对象（新物种/新状态类型）从网络内部产生——存在反应r: A → B⊗X，其中X是之前不在网络中的新对象；
3. **开放性**：R有非平凡的输入和输出（f₁₂≠0, f₂₁≠0），不是封闭自循环。

**定义1.7（死的自复制）**：一个自生成网络R是死的（!-型），如果：

1. **纯沉积**：R中所有反应的输出都是!-模态的（只复制/沉积，不产生新线性资源）；
2. **状态固定**：R不产生新对象，所有输出都是已有对象的复制；
3. **空转**：R的运行不需要外部线性输入（食物集可以为空），也不产出线性输出——G → G⊗G（自我复制）。

**定理1.8（死网络=!-寄生体）**：在PTC中，任何死的自复制网络都是定理28意义下的!-寄生体：它依赖线性宿主提供运行所需的线性资源，宿主消亡时退化为纯收缩G→G⊗G。

**证明**：死网络的所有反应都是!-模态态射。由公理2（无自然收缩），!-模态态射的运行需要线性上下文（Cut连接到线性资源）。如果切断所有线性连接（宿主消亡），剩下的只有!-余代数结构（comultiplication G→G⊗G和counit G→I），即纯自我复制和丢弃——空转。∎

**定理1.9（活网络不可完全资本化）**：活的自维持网络R不能被任何!-模态结构完全表示。

**证明**：由条件1（线性产出），R产出非!-模态的线性资源X。由定理1（不存在A→!A），X不能自动沉积为!X。由定理20（!不穿透νF₂），R作为νF₂型过程，不存在R→!R的态射。因此R不能被完全资本化。∎

**命题1.10（生命判据）**：一个自生成网络是活的，当且仅当它满足定义1.6的全部三个条件。这给出了"生命"的数学判据，不依赖于碳基/硅基、生物/非生物的区分。

**例子**：
- 活细胞：代谢反应产出新蛋白质（线性产出）、进化产生新蛋白质类型（状态扩展）、与环境物质能量交换（开放性）→ 活
- 病毒：只复制自己的RNA/DNA（纯沉积）、不产生新类型（状态固定）、需要宿主细胞的核糖体（寄生）→ 死（!-寄生体）
- 资本：G→G+g（纯沉积）、不产生新使用价值类型（状态固定，只是量的增长）、需要活劳动（寄生）→ 死（!-寄生体）
- 火焰：消耗氧气和燃料、产出热量和CO₂（线性产出？），但不产生新的反应类型（无状态扩展）、不自我修复→ 边界情况，不是νF₂型生命
- 骡子：代谢、修复、回应环境（活的νF₂过程），但不能繁殖——繁殖不是生命的必要条件，持续的自指交互才是

## 1.5 自生成范畴的构造

**定义1.11（自生成范畴）**：一个自生成范畴是从一个"原型射范畴"（只有态射和部分复合关系的结构）出发，通过以下过程涌现出对象的：

1. 开始：一个集合M（态射/操作）和一个偏复合关系∘（某些态射可以复合）
2. **接口涌现**：当态射f的输出可以接上态射g的输入时，这个"接口"成为一个对象
3. **自指对象涌现**：当一组态射形成闭环（输出接回输入），且这个闭环自生成（定义1.5）时，一个"自指对象"涌现
4. **对象作为不变量**：自指对象不是集合论意义上的"东西"，是操作网络在运行中维持的不变模式

**定理1.12（自生成范畴包含PTC）**：任何自生成范畴中的活自指对象（νF₂型）构成一个PTC（生产性迹范畴）。

**证明思路**：活自指对象的操作网络满足PTC公理：生产性（定义1.5条件3）、资源敏感（线性性）、!-模态结构（催化剂对应!）、迹（反馈回路的GoI解释）。∎

# 第二章：践演迹——成长过程的数学

## 2.1 问题

标准GoI迹 Tr(f) = Σ f₁₂ f₂₂ⁿ f₂₁ 在N<1时收敛。N=1时(I-f₂₂)⁻¹可能存在。N>1时级数发散——成长过程不能"加总"。

但成长过程每一步都有确定的输出。它不是没有迹，是迹不是一个完成的对象，是一个正在进行的过程。

## 2.2 扩展状态空间

**定义2.1（扩展余代数序列）**：一个扩展余代数序列是((Xₙ, cₙ, iₙ))_{n≥0}，其中：
- Xₙ是C中的对象（第n步的状态空间）
- cₙ: Xₙ → F(Xₙ₊₁)（转移到更大的状态空间）
- iₙ: Xₙ → Xₙ₊₁（包含）
- 相容性：iₙ之后cₙ₊₁的Xₙ₊₁分量等于cₙ的Xₙ₊₁分量（图交换）

**大白话**：每一步不仅状态在变，"能处于什么状态"的空间也在变大。学会新技能、产生新思想、建立新关系——这些都是状态空间的扩展。

**定义2.2（扩展不动点ν*F）**：扩展余代数序列的"极限"ν*F不是一个固定对象，而是一个**过程**——它在每一步n产生一个Xₙ中的状态，并保证Xₙ₊₁存在。ν*F是"永远在扩展的过程"的类型。

ν*F和νF的区别：
- νF：无限过程，但状态空间固定（一条在固定房间里永远走的路）
- ν*F：无限过程，状态空间持续扩展（一条边走边创造新房间的路）

## 2.3 践演迹

**定义2.3（践演迹）**：设f是扩展Mealy机，状态空间为(Xₙ)。f的践演迹是一族态射：

  Tr*ₙ(f): A → B ⊗ Xₙ

其中Tr*ₙ(f)追踪前n步反馈，留下第n步的状态Xₙ可见。践演迹本身是序列(Tr*ₙ(f))_{n≥0}，满足：

1. **生产性**：对每个n，Tr*ₙ(f)在有限时间内可计算
2. **前进性**：Tr*ₙ₊₁(f)由Tr*ₙ(f)经过一步转移得到
3. **开放性**：Xₙ₊₁可能严格大于Xₙ（状态空间扩展）

**定理2.4（践演迹存在定理）**：在PTC中，扩展Mealy机f的践演迹存在当且仅当f是生产性的（每步产出输出和新状态）。

**证明**：
- 必要性：如果某步不产出（卡住），则Tr*ₙ在该步无定义。
- 充分性：由生产性，每步都有(bₙ, xₙ₊₁)。归纳构造Tr*ₙ：Tr*₀ = f₁₁（直通），Tr*ₙ₊₁由Tr*ₙ经过一步反馈复合得到。每步有限可计算。∎

**注意**：践演迹的存在不要求N<1（级数收敛），只要求生产性（每步有输出）。这就是为什么N>1的成长过程仍然有良定义的行为——它的迹不是"无限和"，是"永远有下一步"。

**定理2.5（N>1需要状态扩展）**：在有限维状态空间中，如果N=ρ(U₂₂)>1，则过程在有限步后达到所有可达状态（饱和），之后N实际降为1。N>1的持续成长要求状态空间无限扩展（ν*F而非νF）。

**证明**：在有限维空间中，U₂₂^n的列空间最终稳定（矩阵幂的列空间序列递减且有限维，必稳定）。稳定后U₂₂限制在稳定子空间上，其谱半径≤1（否则列空间继续增长，矛盾）。因此N>1的持续成长要求dim(Xₙ)→∞，即ν*F。∎

**哲学意义**：
- 成长不是"在固定空间里越走越快"，是"边走边创造新的空间"
- 学习不是在固定知识空间里移动，是知识空间本身在扩大
- 革命不是在旧社会框架里夺权，是创造旧社会框架里不存在的新社会形式
- "生命的无限性"不是实无限（一个完成的∞），是潜无限（永远有下一步，且下一步可能在新空间里）

## 2.4 践演迹与!-模态

**定理2.6（!不穿透践演迹）**：不存在自然变换把践演迹Tr*(f)映射为!-模态沉积。

**证明**：践演迹在第n步留下线性状态Xₙ。由定理1（不存在Xₙ→!Xₙ），每一步的线性状态不能自动沉积。而且Xₙ₊₁可能包含Xₙ中不存在的新对象（状态扩展），!-模态无法预知这些新对象。∎

这加强了定理20：不仅固定状态空间的生命流不可资本化，连持续扩展的生命流更不可资本化——因为新维度在!-模态的"视野"之外。

# 第三章：反自指的一般结构

## 3.1 两种自指

**定义3.1（自指算子）**：对象X上的自指算子是态射f: X⊗A → B⊗X（Mealy机），其中X同时出现在输入和输出中——系统的下一步依赖于当前状态。

**定义3.2（正自指/活自指）**：f是正自指的，如果：
1. f是线性的（非!-模态）
2. f产出新的线性X（不是复制旧X）
3. f支持状态扩展（ν*F型）

正自指 = 生命。每一步产生新的自我，这个新自我是线性的、不可沉积的、可能在新空间里。

**定义3.3（反自指/死自指）**：f是反自指的，如果：
1. f通过!-模态分解（f = !g）
2. f的X输出是旧X的复制（收缩X→X⊗X）
3. f的状态空间固定（νF型但无扩展）

反自指 = 为了维持自己而运行，但"维持"的方式是复制而非更新。官僚系统复制流程，资本复制价值，病毒复制基因——都是反自指。

## 3.2 反自指的数学结构

**命题3.4（反自指=!-余代数）**：反自指算子f精确地是!-余代数：配有余乘法δ: !X→!X⊗!X（自我复制）和余单位ε: !X→I（丢弃），满足余代数公理。

**定理3.5（反自指的寄生性）**：反自指系统不能独立运行。它必须Cut到线性宿主（正自指系统）才能运行，因为!-模态态射需要线性上下文驱动。

**证明**：由公理2，!-模态态射不能凭空产生线性效果。反自指系统的所有"行动"（影响环境、获取资源）都需要通过Cut连接到线性过程。切断Cut，反自指系统退化为δ和ε（复制和丢弃），即空转。∎

**定理3.6（反自指压低N）**：在加权PTC中，反自指寄生使宿主的N从N₀降至N₀·(1-β)，其中β是萃取率。

**证明**：反自指系统每步从宿主萃取β比例的线性产出。宿主反馈从U₂₂变为(1-β)U₂₂。由谱半径齐次性ρ(cU)=|c|ρ(U)，新N=(1-β)N₀。∎

这就是异化降低N的一般机制——不仅资本主义是这样，官僚制、经文化、成瘾行为都是反自指寄生，都通过萃取线性产出压低宿主的N。

## 3.3 反自指的识别

**命题3.7（反自指的操作判据）**：一个系统是反自指的，当且仅当：
1. 它的"目的"是自我维持（运行的结果是继续运行），但
2. 它不产生任何系统之外的线性价值（B=0或B全部回流为!-模态），且
3. 移除它不减少任何线性产出（它是寄生的）。

对照：
- 细胞：自我维持 + 产出新蛋白质/行为（线性B≠0）+ 移除它组织死亡 → 正自指
- 官僚机构：自我维持 + 产出文件/流程（!-模态B）+ 精简它有时提高效率 → 反自指
- 资本：自我增殖 + 产出商品（使用价值是线性的，但被!-模态捕获为交换价值）→ 反自指寄生在正自指上

# 第四章：操作等价

## 4.1 定义

**定义4.1（操作等价）**：两个过程f和g是操作等价的（f ≈ᵒᵖ g），如果它们有相同的：
1. **N值**：ρ(f₂₂)=ρ(g₂₂)（同速成长/衰退）
2. **α层级**：相同的f-层级深度
3. **生产性**：都生产性或都非生产性
4. **模态型**：都是线性（νF₂型）或都是!-模态
5. **扩展能力**：都支持ν*F或都只在νF中

## 4.2 性质

**定理4.2（操作等价严格粗于双模拟）**：双模拟蕴含操作等价，但反之不然。

**证明**：双模拟要求逐步行为相同，这蕴含N、α、生产性、模态型、扩展能力都相同。但操作等价不要求逐步行为相同——一个人和一条狗的逐步行为完全不同，但都是νF₂型、N>1、α∈{1,2,3}的生命过程。∎

**定理4.3（操作等价严格细于迹等价）**：操作等价蕴含迹等价，但反之不然。

**证明**：迹等价只要求输入输出行为相同。但自愿做和被胁迫做可以有相同的输入输出（迹等价），而C值不同（自主vs被控），操作不等价。∎

**哲学意义**：操作等价说的是"运行方式相同"，不是"结果相同"或"步骤相同"。它捕捉的是：两个过程在存在论层面是不是同一种东西。

# 第五章：量的发生学

## 5.1 问题

在自生成范畴中，一开始没有数、没有度量、没有权重。N、M、W这些量从哪来？

## 5.2 三种原始量

**定义5.1（频率量）**：在自生成网络中，态射f的频率量w_freq(f)是f在单位时间内被触发的次数。这是概率的起源——反复发生的操作获得统计权重。

**定义5.2（持续量）**：对象A的持续量w_pers(A)是A从产生到被消耗的平均时间。这是T（稳态持续时间）的起源——持续越久的对象越"稳定"。

**定义5.3（因果量）**：对象A的因果量w_cause(A)是依赖A的态射数量（A的出度）。这是M（意义量）的质的基础——被越多其他操作依赖的对象越有"意义"。

## 5.3 量的涌现定理

**定理5.4（N从频率涌现）**：在自生成网络的稳态中，反馈回路的频率比（每步触发次数的比值）收敛于谱半径N。

**证明思路**：反馈回路每步触发f₂₂，触发频率正比于f₂₂的矩阵幂的增长速度，即谱半径。这是Perron-Frobenius定理的结果——正矩阵的幂增长速度由谱半径决定。

**定理5.5（M从因果量涌现）**：对象A的意义量M(A)正比于从A出发的因果链总权重，即M(A) = Σ w_cause在因果链上的几何级数和。这给出M=α·ΣNⁿ的发生学解释。

**定理5.6（W从频率差涌现）**：萃取率β等于反自指系统触发频率与宿主总触发频率之比——反自指系统"占用"了宿主多少比例的运行。

**哲学意义**：量不是外加的，是操作网络运行的沉淀。先有"在感"（质性的操作），操作反复运行后沉淀出"多少"（量性的度量）。这就是"阴为阳服务"——量（阴）从活操作（阳）中涌现，反过来度量活操作。

# 第六章：与已有工作的关系

# 第七章：新问题清单（第二代）

从新概念中长出的更深问题：

1. **自生成范畴的形式化**：定义1.11还是构造性描述，需要严格的范畴论公理化。原型射范畴的"部分复合"怎么形式化？接口涌现的范畴论条件是什么？

2. **ν*F的范畴论语义**：扩展不动点在范畴论中怎么定义？它是某个双范畴中的最终余代数吗？还是需要全新的极限概念？

3. **ν*F和νF的关系**：什么时候ν*F退化为νF（状态空间停止扩展）？这对应"停止成长"——N从>1降到=1。这个相变的数学条件是什么？

4. **自生成范畴中的!-模态**：在自生成范畴中，!-模态不是给定的，是涌现的——催化剂（不被消耗的物种）怎么从反应网络中涌现？这连接到酶的起源。

5. **多体耦合的范畴论**：两个ν*F过程互动，形成复合ν*F。复合的N怎么算？什么耦合结构使N>1（互相滋养）vs N<1（互相萃取）？

6. **践演迹的计算模型**：践演迹对应什么编程范式？不是函数式编程（固定类型），不是命令式编程（固定状态），是一种"类型随运行扩展"的编程——可能对应某种归纳递归编程或宇宙多态。

7. **反自指的演化**：反自指系统（!-寄生体）怎么从正自指系统中涌现？官僚制怎么从革命组织中结晶？这是II型晶体成核的数学——需要一个"结晶定理"。

8. **量的发生学和概率论的关系**：频率量→概率、持续量→热力学势、因果量→网络中心性——能不能统一导出概率论、热力学和信息论的基本概念？
