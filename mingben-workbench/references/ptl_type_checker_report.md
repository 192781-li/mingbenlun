## 五、检查器局限与待推进

### 当前局限
1. **模式匹配而非完整类型推断**：当前用正则表达式匹配，不是真正的类型推断器
2. **误报率可能较高**：线性性和生产性检查是启发式的，需要人工复核
3. **不检查完整推导链**：只检查单行，不检查多行推导的类型一致性
4. **不检查Coq代码**：Coq形式化在coq/目录，由coq_verify.py检查

### 待推进方向
1. **完整PTL类型系统实现**：在Coq中形式化PTL的类型规则和类型检查器
2. **多行推导链检查**：跟踪变量在多行推导中的使用，检查线性性
3. **!-穿透精确检查**：基于类型上下文判断!是否非法穿透νF₂
4. **守护递归精确检查**：基于▷模态判断递归是否守护
5. **与Coq形式化对接**：PTL类型检查器的规则与coq/theories/ALL/对齐
