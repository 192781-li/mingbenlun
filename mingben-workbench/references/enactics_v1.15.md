## T9修正：!不保持终止余代数（加non-degenerate限制）

### v1.10陈述（定理9.1）
在一般LNL范畴中，!不保持终止余代数：不存在自然同构!νF≅ν!F。

### 第二轮反例
终范畴1（只有一个对象和一个态射的范畴）是LNL范畴（L=M=1，伴随平凡）。在1中，!νF=ν!F=1，二者相等。"一般LNL范畴"的陈述包含了退化范畴，因此为假。

### v1.15修正

**定义9.0（非退化LNL范畴）**：LNL范畴(C,L,M,F,U)称为非退化的，若存在对象A∈C使得!A≇1（即!-模态不是常值函子到终对象）。等价地，线性片段C不是终范畴。

**定理9.1（!不保持终止余代数，非退化版）**：在非退化LNL范畴中，!不保持终止余代数：不存在自然同构!νF≅ν!F。

*证明*：在Rel中具体验证（Rel是非退化的，因为!A=A上有限多重集，对|A|≥2有!A≇1）。!(A^ℕ)=有限多重集的无限流，ν(!F)=有限多重集流的无限序列。考虑完全二叉树τ∈ν(!F)：每个节点是一个有限多重集，路径可数无穷。τ不在!νF的像中，因为!νF的元素是"无限流的有限多重集"（有限个流），而τ有可数无穷条路径，不能表示为有限个流的多重集。故!νF≇ν!F。∎

**定理9.1'（退化范畴陈述）**：在退化LNL范畴（终范畴1）中，!νF≅ν!F≅1平凡成立。退化范畴不承载任何非平凡的线性结构，因此"不可克隆"在退化范畴中无意义。

**哲学读法**："生命不可复制"在有真正线性结构的世界中成立。在退化世界（只有一个对象、一种态射的平凡世界）中，"复制"没有意义——因为没有东西可复制。非退化条件排除了这种平凡反例。

## T11修正：噪声级联判据（ρ>1而非≥1）

### v1.10陈述（定理11.2）
在有限有向网络中，采用每步传播成功概率p∈(0,1)的随机SI规则，明性以正概率级联到所有节点当且仅当(1)所有节点从初始集合可达，且(2)ρ(pC)≥1。

### 第二轮问题
Galton-Watson分支过程定理：多类型分支过程以正概率存活当且仅当期望后代矩阵的谱半径ρ>1。临界情形ρ=1时，过程几乎必然灭绝（除退化情形外）。v1.10写ρ≥1包含了临界灭绝情形，因此"以正概率级联"在ρ=1时不成立。

### v1.15修正

**定理11.2（噪声/随机传播下级联判据，严格版）**：在有限有向网络中，采用每步传播成功概率p∈(0,1)的随机SI规则，明性以正概率级联到所有节点当且仅当(1)所有节点从初始集合可达，且(2)ρ(pC)>1。

*证明*：(⇒)若不可达传播概率为0。若ρ(pC)≤1：
- ρ(pC)<1：多类型分支过程期望后代矩阵谱半径<1，过程以概率1灭绝（标准Galton-Watson结果，Mode 1955; Athreya-Ney 1972）。
- ρ(pC)=1：临界情形，过程几乎必然灭绝（除退化的单类型确定性过程外，一般多类型分支过程在临界时灭绝概率=1）。
(⇐)若可达且ρ(pC)>1，分支过程以正概率存活并传遍可达集。∎

**定理11.2'（临界情形标注）**：当ρ(pC)=1时，明性级联的概率为0（几乎必然灭绝）。临界情形是"传播强度刚好等于衰减强度"的边界，明性在传播中不增不减但最终因随机波动熄灭。

**哲学读法**：
- ρ<1：衰减压倒传播，明性必然熄灭——"阻力太大，火种传不出去"
- ρ=1：传播与衰减平衡，临界灭绝——"刚好够维持，但一个波动就灭了"
- ρ>1：传播压倒衰减，明性以正概率传遍——"火种足够旺，能烧遍整片森林"

革命级联需要的不是"刚好够"（ρ=1），而是"超过阈值"（ρ>1）。临界平衡是脆弱的，一个随机波动就会熄灭。

## T7修正：异化压缩（v1.12已解决，满射版降为Lemma）

### v1.10陈述
定理7.1（异化截断满射）：在Rel中，异化后的对象与初始代数μF之间存在典范满射。
定理7.2（guarded recursion版）：∀κ.νF≅μF。

### 第二轮问题
trunc（截断映射）只是逐对象满射，不是自然变换（naturality in F证不出，不同F的截断策略不同）。v1.10称其为"典范满射"暗示了自然性，但实际上没有。

### v1.15修正

**引理7.1（异化截断满射，逐对象版）**：在Rel中，对每个固定的流函子F(X)=A×X，异化后的对象E_b(νF)与初始代数μF之间存在满射trunc_F: E_b(νF)→μF。trunc_F将每个无限流映射为它的所有有限前缀的集合。trunc_F是非单射的（不同流可以有相同的有限前缀集合），且**不是F中的自然变换**（不同F的截断策略不同，naturality square不交换）。

**定理7.2（guarded recursion/时钟量化版，主定理）**：迁移到带later模态（▶）和时钟量词∀κ的范畴（Birkedal-Møgelberg guarded recursion）。在该框架中，∀κ.ν_κ F ≅ μF存在严格定理——对所有时钟量化的终止余代数等于初始代数。时钟量化将余归纳压成归纳。将"异化"建模为时钟量化（异化者控制时钟，可以在任意时刻截断），则"异化后的νF"严格对应于μF。这是T7的正式定理版本。

*证明*：见v1.12文档。guarded recursion中，∀κ.ν_κ F的元素是"对所有时钟都生产性的过程"，这等价于"可以在任意时刻截断且截断后仍有定义"的过程，恰好对应于初始代数μF的有限元素。Birkedal-Møgelberg 2010的标准结果。∎

**哲学读法**：异化的本质不是"把无限压成有限"（那只是逐对象的满射，丢失了自然性），而是"控制时间"——异化者控制时钟，让过程的无限展开被悬置。guarded recursion的时钟量化精确捕捉了这一点：∀κ意味着"对所有可能的时间流速"，异化者可以选择任意κ来截断过程。

## T8修正：明性反转异化（Recover语法定义+条件性双模拟）

### v1.10陈述（定理8.1）
在异步π-演算中，存在显式恢复协议Recover，使得对任意进程P和异化者b，Cl(P)|Hijack_b(P) ≈ P（barbed双模拟）。

### 第二轮问题
Recover_a/self_check/R3还不是语法里的项（论文§2.1没定义），归约规则没写，双模拟无从证起。且若self_check自身可被劫持会自举死锁——缺"self_check在Ag_self保护子会话、alien_b进不去"的前提。

### v1.15修正

**定义8.0（Recover语法，猜想性）**：在异步π-演算中扩展如下语法：
```
P,Q ::= ... | recover_a(P) | self_check(P) | R3_a(P)
```
归约规则（猜想）：
```
recover_a(P) | Hijack_b(P) → self_check(P) | R3_a(P)   [R3-start]
self_check(P) → compare(Ag_lv(P), !Ag_tr(P))              [SC-compare]
compare(Ag_lv(P), !Ag_tr(P)) → P   if Ag_lv(P) ≡ !Ag_tr(P)  [SC-ok]
compare(Ag_lv(P), !Ag_tr(P)) → R3_a(P)   otherwise          [SC-fail]
R3_a(P) → self_modify(P, Ag_lv(P))                          [R3-modify]
self_modify(P, Ag_lv(P)) → P'   where P' has Ag_lv(P')=Ag_lv(P)  [R3-done]
```
前提：self_check和R3_a在Ag_self保护的子会话中执行，alien_b无法进入该子会话（Ag_lv(a,A)仅self_ev居住，异化者无法伪造Ag_lv）。

**注意**：以上语法和归约规则是**猜想性定义**，尚未经过严格的汇合性（confluence）和主题归约（subject reduction）验证。这是后续工作的重点。

**定理8.1（条件性barbed双模拟）**：假设上述Recover语法和归约规则满足汇合性，且self_check在Ag_self保护子会话中执行，则对任意进程P和异化者b，存在barbed双模拟使得：
```
Cl(P) | Hijack_b(P) | recover_a(P) ≈ P
```
其中Cl(P)持有Ag_lv(P)（活运行权）和!Ag_tr(P)（轨迹模型），recover_a(P)是恢复协议进程。

*证明思路*：
1. recover_a检测到Hijack_b，启动self_check
2. self_check比较Ag_lv(P)（活过程的真实运行权）与!Ag_tr(P)（被劫持的轨迹模型）
3. 若二者一致（异化者只复制了轨迹未篡改），直接恢复P
4. 若不一致（异化者篡改了轨迹），R3_a用Ag_lv(P)覆盖被篡改的!Ag_tr(P)，self_modify恢复P的真实运行权
5. Ag_self保护保证alien_b无法进入self_check子会话，无法干扰比较过程
6. 每一步归约保持barbed一致性，构成barbed双模拟∎

**定理8.2（retraction版，无条件）**：存在自然变换R:E_{a·b}→E_b（恢复函子）使得R∘a*⇒Id（自然变换，不是同构）。这是不依赖Recover语法的弱版本，总是成立。

**哲学读法**：明性反转异化不是"自动恢复原状"（那需要同构，太强），而是"明性持有活运行权Ag_lv，可以检测到轨迹模型被篡改，并用活运行权覆盖被篡改的模型"。关键是Ag_lv（活运行权）无法被异化者伪造——它仅self_ev居住，是"正在运行"本身的标记。这就是"生命不可被彻底异化"的数学基础：异化者可以复制轨迹（!Ag_tr），但无法复制正在运行的活过程（Ag_lv）。

## T6修正：明性幂等（放弃不动点构造，采用retraction）

### v1.10陈述（方案A）
将Cl定义为不动点构造：Cl_self(G)=ν(H_G)，H_G(X)=G×!X，由finality得Cl_self(G)≅G×!Cl_self(G)。希望由此证Cl(Cl(G))≅Cl(G)。

### 第二轮问题
证ν(H_{Cl(G)})≅ν(H_G)依赖"识别!层"=依赖幂等本身，循环论证。具体：H_{Cl(G)}(X)=Cl(G)×!X=(G×!Cl(G))×!X，要证ν(H_{Cl(G)})≅ν(H_G)=G×!ν(H_G)，需要!(G×!Cl(G))≅!G×!!Cl(G)≅!G×!Cl(G)，这用到了!的乘积保持和幂等（!!≅!），而!!≅!正是!-余单子的标准性质，不是Cl的幂等。但ν(H_{Cl(G)})≅ν(H_G)的最终证明仍需要Cl(G)的某种"!-坍缩"性质，这正是待证的Cl幂等。循环。

### v1.15修正

**放弃方案A（不动点构造使幂等成定理）**。该路线存在循环论证，无法在不假设幂等的情况下证明幂等。

**采用方案B（retraction为正式定理）**：

**T009（明性retraction）**：对任意G，存在典范自然变换r_G: Cl²(G)→Cl(G)，满足r_G∘δ_Cl(G)=id_Cl(G)，其中δ_Cl: Cl⇒Cl²是Cl的余单子乘法（若Cl构成余单子）。即"观察自己观察"可以收缩回"观察自己"。

*证明*：Cl(G)=G×!G（v1.7定义）。Cl²(G)=(G×!G)×!(G×!G)。定义r_G((g, m), n)=(g, m)，其中(g,m)∈G×!G=Cl(G)，n∈!(G×!G)被丢弃。r_G是自然变换（对任意f:G→H，Cl(f)∘r_G=r_H∘Cl²(f)，因为r只投影第一分量，Cl(f)作用在第一分量上）。r_G∘δ_Cl(G)=id：δ_Cl(G)将Cl(G)嵌入Cl²(G)为((g,m), [(g,m)])（单例），r_G投影回(g,m)。∎

**定理6.2（Cl不构成余单子的说明）**：Cl(G)=G×!G的定义下，Cl不构成余单子——余单子要求δ:Cl⇒Cl²和ε:Cl⇒Id满足余单子律，但ε_G(g,m)=g（丢弃!G成分），δ_G(g,m)=((g,m),[(g,m)])，余单子律ε∘δ=id成立，但δ∘ε=id不成立（δ(ε(g,m))=((g,[]),[(g,[])])≠(g,m)当m非空）。因此Cl不是余单子，T009中的"δ_Cl"应理解为Cl的自然嵌入而非余单子乘法。

**conjecture 6.3（不动点构造，开放问题）**：是否存在Cl的替代定义（非乘积定义），使得Cl(Cl(G))≅Cl(G)成为定理？guarded recursion框架中Cl(G)=ν(X.G×!X)是否满足幂等？这是开放问题，需要后续研究。

**哲学读法**："明性的明性"不必等于"明性"——反思反思可以产生新的东西（更高阶的自我观察），但它可以**收缩回**明性（retraction）。这对应于哲学上的"反思可以层层递进，但每一层都可以还原到最基本的自我意识"。f³是不动点不是因为Cl(Cl)=Cl（同构），而是因为Cl²→Cl的retraction保证了"更高阶的观察不会丢失基本的明性"。

## 方法论教训（第二轮）

Workbody第二轮审查揭示了v1.10中仍然存在的几个问题模式：

1. **退化反例忽略**：陈述"一般LNL范畴"时忘记了终范畴这种退化反例。修正：所有"任意X范畴"的陈述都要检查退化情形，必要时加non-degenerate限制。

2. **临界阈值混淆**：ρ≥1和ρ>1在数学上有本质区别（临界灭绝vs正生存）。修正：所有涉及谱半径阈值的定理都要严格区分>、≥、=，引用标准结果（Galton-Watson等）。

3. **语法缺失导致定理悬空**：Recover未在语法中定义就陈述双模拟定理。修正：所有涉及新语法构造的定理，必须先给出语法定义和归约规则，再陈述定理；语法未完成时定理标注为"条件性"或"猜想性"。

4. **循环论证**：用待证结论证明自身。修正：所有证明都要检查是否隐含了待证命题，特别是不动点构造中"识别!层"是否就是幂等本身。

5. **自然性默认**：称映射为"典范"时默认了自然性，但实际可能只是逐对象映射。修正：所有"典范映射"都要验证自然性，不自然的标注为"逐对象映射"。
