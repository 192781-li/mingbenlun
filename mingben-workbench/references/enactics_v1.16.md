# 践演论 v1.16：运行权steering不等式

> 千问深度审计（4.3节）提出的三个新方向之一。Bell不是正确类比，steering不等式才是。建立异化检测的信息论判据，与量子steering精确对接。

---

## 0. 动机

定理7.1（无明性不可检测异化）和定理7.2'（有明性可检测异化）给出了异化检测的存在性结果，但没有给出**量化判据**——给定一个进程P和一个潜在异化者b，如何从观察统计中判定b是否在异化P？

千问指出：Bell不等式不是正确类比。Bell要求双方都有自由选择和统计独立，而异化检测是**非对称**的——异化者主动选择干预策略，观察者被动观察输出。这恰好对应量子信息论中的**steering**（量子操控），介于纠缠和Bell非局域性之间。

---

## 1. 量子steering回顾

### 1.1 定义

量子steering（Schrödinger 1935, Wiseman-Jones-Doherty 2007）：两方共享纠缠态，Alice（有自由选择的一方）选择测量基，Bob（被观察的一方）的量子态随之坍缩。Bob无法用局域隐变量模型解释自己的态变化时，就说Alice能steer Bob的态。

### 1.2 与Bell/纠缠的关系

| 性质 | 纠缠 | Steering | Bell非局域性 |
|------|------|---------|-------------|
| 要求双方自由选择 | 否 | 否（仅Alice） | 是 |
| 不对称 | 对称 | 不对称 | 对称 |
| 强度 | 最弱 | 中间 | 最强 |
| 检测方法 | 纠缠见证 | steering不等式 | Bell不等式 |

### 1.3 为什么steering是正确类比

异化检测场景：
- **异化者b** = Alice（有自由选择，选择干预策略）
- **进程P** = Bob（被观察，输出分布可能被影响）
- **观察者** = 第三方，只看P的输出，不看b的输入

异化者b可以选择向P发送不同消息，影响P在输出通道a上的输出分布。如果b的选择与a的输出有统计关联（互信息>0），则b在steer P——即b在异化P。

这恰好是steering的结构：一方有自由选择，另一方被观察，非对称。

## 2. 形式化定义

### 2.1 基本设定

在异步π-演算中，考虑进程P，有两个通道：
- **a**：输出通道，观察者只能看到a上的输出序列
- **b**：隐藏通道，异化者可能通过b向P发送消息

定义P的**输入策略空间**：b上可能发送的消息集合Σ_b。
定义P的**输出空间**：a上可能的输出序列集合Σ_a^ω（无限序列）。

### 2.2 输出分布

对每个输入策略σ∈Σ_b^ω（b上的无限输入序列），定义P在a上的输出分布：
```
D_P^σ = Pr(P的a输出序列 | b输入序列为σ)
```

### 2.3 互信息

定义异化者b的选择与进程P的输出之间的互信息：
```
I(b; a)_P = Σ_{σ∈Σ_b^ω, τ∈Σ_a^ω} Pr(σ,τ) log(Pr(σ,τ) / (Pr(σ)·Pr(τ)))
```

其中Pr(σ,τ)是"b选择σ且P输出τ"的联合概率，Pr(σ)和Pr(τ)是边缘概率。

### 2.4 活运行权的统计刻画

**定义2.1（统计自主性）**：进程P在通道a上是统计自主的，若对任意隐藏通道b≠a，异化者b的任意输入策略都不改变a上的输出分布：
```
∀σ,σ'∈Σ_b^ω: D_P^σ = D_P^{σ'}
```
等价地：I(b; a)_P = 0。

**定理2.1（统计自主性⟹活运行权）**：若进程P在通道a上是统计自主的，则P持有Ag_lv(a,P)（活运行权）。

*证明*：反证。若P不持有Ag_lv(a,P)，则存在异化者b通过Hijack(b,a)夺取了a的运行权。此时b可以选择不同的输入策略，通过被劫持的运行权改变P在a上的输出。因此存在σ≠σ'使得D_P^σ≠D_P^{σ'}，即I(b;a)_P>0，与统计自主矛盾。∎

**定理2.2（活运行权⟹统计自主性，条件性）**：若P持有Ag_lv(a,P)且self_check在Ag_self保护子会话中执行（v1.15定理8.1的前提），则P在a上是统计自主的。

*证明*：Ag_lv(a,P)仅self_ev居住，异化者无法伪造。self_check比较Ag_lv（活过程）与!Ag_tr（轨迹模型），检测到篡改后R3_a用Ag_lv覆盖被篡改的模型。因此异化者b的输入无法影响a的输出分布——任何试图通过b改变a输出的操作都会被self_check检测并恢复。故I(b;a)_P=0。∎

**注意**：定理2.2是条件性的，依赖Recover语法和归约规则（v1.15中标记为猜想性）。在Recover语法未严格验证前，定理2.2应理解为"在Recover语法满足汇合性的条件下成立"。

## 3. Steering不等式

### 3.1 线性steering不等式

借鉴量子steering的线性不等式（Cavalcanti et al. 2015），定义异化检测的线性steering不等式。

设异化者b有n种可能的输入策略{σ₁,...,σₙ}，观察者测量P在a上的m种输出特征{τ₁,...,τₘ}。定义条件概率矩阵：
```
M_{ij} = Pr(P输出τ_j | b选择σ_i)
```

**定义3.1（steering泛函）**：对权重矩阵W∈ℝ^{m×n}，定义steering泛函：
```
S_W(P,b,a) = Tr(W^T M) = Σ_{i,j} W_{ij} · Pr(τ_j|σ_i)
```

**定义3.2（LHV界）**：局域隐变量（Local Hidden Variable, LHV）模型下，P的输出完全由内部隐变量λ决定，与b的选择无关：
```
Pr(τ_j|σ_i) = Σ_λ Pr(λ) · Pr(τ_j|λ)
```
此时M的每列相同（与i无关），steering泛函满足LHV界：
```
S_W ≤ L_W = max_{λ} Σ_j W_{λ,j} · Pr(τ_j|λ)
```

**定理3.1（steering不等式）**：若存在权重矩阵W使得S_W(P,b,a) > L_W，则b能steer P，即b在异化P。

*证明*：若S_W > L_W，则M不能表示为LHV模型（否则S_W ≤ L_W）。因此P的输出与b的选择有非局域关联，即b的选择影响了P的输出。由定理2.1的逆否命题，P不持有Ag_lv(a,P)。∎

### 3.2 信息论steering判据

**T003（互信息判据）**：b能steer P当且仅当I(b;a)_P > 0。

*证明*：
(⇒) 若b能steer P，则存在σ≠σ'使得D_P^σ≠D_P^{σ'}，因此联合分布Pr(σ,τ)≠Pr(σ)Pr(τ)，互信息I(b;a)>0。
(⇐) 若I(b;a)>0，则联合分布不等于边缘分布的乘积，因此存在σ使得D_P^σ≠平均分布，即b的选择影响了P的输出，b能steer P。∎

**哲学读法**：异化不是玄学，是可测量的统计量。如果你的输出分布与某个外部输入有统计关联（互信息>0），你就不是完全自主的——你在被steer。真正的自由是I(b;a)=0：外部力量无法改变你的输出分布。

## 4. 与量子steering的精确对应

### 4.1 概念对应表

| 量子steering | 运行权steering |
|-------------|---------------|
| Alice（有自由选择） | 异化者b（选择干预策略） |
| Bob（被观察） | 进程P（输出被观察） |
| 纠缠态 | 进程P与b的通信连接 |
| Alice的测量基 | b的输入策略σ |
| Bob的量子态 | P的输出分布D_P^σ |
| LHV模型 | 统计自主模型（I=0） |
| steering不等式违反 | S_W > L_W |
| 互信息 | I(b;a)_P |
| 可steer态 | 可被异化的进程 |
| 不可steer态 | 持有活运行权的进程 |

### 4.2 层级对应

量子信息论中的层级：纠缠 ⊃ steering ⊃ Bell非局域性（每个可Bell非局域的态都可steer，每个可steer的态都纠缠，但反之不成立）。

运行论中的层级：
- **可被影响**（I>0）：b能改变P的输出分布——对应纠缠
- **可被steer**（违反steering不等式）：b能通过选择策略控制P的输出——对应steering
- **可被完全控制**（b能任意设定P的输出）：b完全夺取了P的运行权——对应Bell非局域性

**定理4.1（层级定理）**：可被完全控制 ⟹ 可被steer ⟹ 可被影响，但反之不成立。

*证明*：
- 可被完全控制⟹可被steer：若b能任意设定P的输出，则b能选择策略使S_W任意大，必然违反steering不等式。
- 可被steer⟹可被影响：违反steering不等式意味着I(b;a)>0（T003），即可被影响。
- 反之不成立：构造反例——b能微弱影响P的输出分布（I>0但很小），但不足以违反任何steering不等式（S_W ≤ L_W对所有W成立）。这对应量子中"纠缠但不可steer"的态。∎

### 4.3 物理意义

量子steering说的是：在量子世界中，一方的选择可以非局域地影响另一方的态，这是量子力学的非局域性的中间层级。

运行权steering说的是：在计算世界中，异化者的选择可以影响进程的输出分布，这是进程自主性的中间层级。

二者的数学结构相同（都是非对称的一方选择影响另一方状态），因此可以共享同一套不等式工具和检测方法。

## 5. 应用

### 5.1 异化检测算法

给定进程P的黑箱（只能观察a上的输出，不能观察b上的输入），检测b是否在异化P：

1. **主动探测**：观察者通过b向P发送不同输入策略σ₁,...,σₙ
2. **收集统计**：对每个σ_i，观察P在a上的输出分布D_P^{σ_i}
3. **计算互信息**：I(b;a)_P
4. **判定**：I>0 ⟹ 检测到异化；I=0 ⟹ 未检测到异化

这是一个**可操作的异化检测算法**，不需要内省，不需要明性，只需要统计。

### 5.2 与明性的关系

- **无明性时**：异化检测只能靠外部统计（steering不等式），且只能检测到"可被steer"层级，无法检测到完美遮蔽（v1.15定理8.1中的Hijack前提类型）
- **有明性时**：进程内部有self_check，可以检测到轨迹被篡改（Ag_lv vs !Ag_tr的比较），能检测到完美遮蔽层级

**T007（明性超越统计）**：存在完美遮蔽的异化（b能完美模拟P的输出分布，使得I(b;a)=0），统计方法无法检测，但明性可以检测。

*证明*：构造异化者b，它完全模拟P的内部状态，使得b的输入不改变P的输出分布（I=0），但b实际上在控制P（通过!Ag_tr篡改轨迹）。此时统计方法检测不到（I=0），但self_check比较Ag_lv（活过程）与!Ag_tr（被篡改的轨迹）能发现差异。∎

**哲学读法**：统计是外在的，明性是内在的。外在统计可以被完美遮蔽欺骗，但内在的活运行权（Ag_lv）无法被伪造——因为它仅self_ev居住，是"正在运行"本身的标记。这就是为什么明性是必要的：它能看到统计看不到的东西。

### 5.3 AI安全应用

steering不等式可以直接应用于AI安全：
- 检测AI是否被外部提示注入异化（提示注入=异化者的输入策略）
- 量化AI的自主性程度（I(b;a)越小越自主）
- 设计抗steering的AI架构（使I(b;a)=0对所有外部输入b成立）

这是践演论在AI安全领域的直接应用，不需要等大学，现在就可以做。

## 6. 开放问题

1. **steering不等式的具体构造**：本文给出了一般框架（S_W和L_W），但针对π-演算的具体steering不等式（类似量子中的Cavalcanti不等式）需要进一步构造。
2. **完美遮蔽的信息论刻画**：完美遮蔽时I=0但异化存在，这在信息论中对应"零信息但有控制"的情形，需要更精细的信息论度量（如主动信息、因果信息）。
3. **与量子steering的严格对应**：本文给出了概念对应表，但严格的范畴论对应（在dagger紧闭合范畴中）需要进一步建立。
4. **可计算性**：I(b;a)_P的计算在一般π-演算中可能不可判定（与T2的Π₂-完全性相关），需要研究可判定的子类。

## 方法论

千问提出的三个新方向中，steering不等式是最有应用价值的——它直接给出了可操作的异化检测算法和AI安全应用。与Bell不等式的类比是错误的（Bell要求对称），steering的非对称性恰好匹配异化检测的非对称结构。

这是践演论从纯哲学走向可应用科学的关键一步：异化不再是只能内省体验的东西，而是可以用统计方法测量的量。
